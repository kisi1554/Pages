# こうじょう けんがく 🏭 ― もの が できる まで

まいにち つかう もの は どう やって できて いる の？
**えんぴつ・かみ・チョコレート・ペットボトル の リサイクル・ガラス** の こうじょう を けんがく して、
ライン の きかい を じぶん で うごかして かんせい させる あそび です（年長〜小学4年むけ）。

`index.html` を ブラウザ で ひらく だけ で あそべます。外部ライブラリ・CDN なし。音 は WebAudio の 合成音 だけ。

## あそびかた

1. こうじょう を えらぶ（かみ は「き から」と「ふるい かみ から（リサイクル）」の 2 ライン）。
2. ステーション ごと に カメラ が すすむ。ベルトコンベア が ごとごと うごいて つぎ へ。
3. 各 ステーション で ミニ そうさ。うまく いかなくても「↺ やりなおし」で すぐ もどれる。
4. さいご に **じゅんばん パズル**：ばらばら の こうてい カード を タップ して じゅん に ならべる。
   こたえあわせ で あたり は のこり、はずれ だけ もどる。1かいめ で ぜんぶ ○ なら ★3、2かいめ ★2、それ いがい ★1。
5. かんせい した もの は「ぼく の こうじょう たな」に かざられる。えんぴつ は じぶん で えらんだ いろ で らくがき できる。

| そうさ | やりかた | つかう ところ（れい） |
| --- | --- | --- |
| ぐるぐる（stir） | まるく なぞる（ぎゃく まわり も OK） | まぜる・すりつぶす・まく・けずる |
| シュッ（swipe） | したへ なぞる | おしだす・きる・くだく・しぼる |
| ちょうど（timing） | はり が みどり の とき「ストップ」 | テンパリング・ガラス を きる |
| はこぶ（drag） | ゆび で つかんで うつす | しん を はさむ・かた に ながす・あつめる |
| ゆする（shake） | よこ に いったり きたり | あみ で すく・ねる・あらう |
| ポンポン（tap） | ボタン を れんだ | くうき を ふきこむ・あわ で インク を とる |
| おしつづける（hold） | ボタン を ながおし | いる・にる・かわかす・ひやす |
| みて いよう（watch） | 「おねがい！」で おとな が うごかす | とても あつい かま・ろ |
| しわけ（sort） | ただしい はこ を タップ | キャップ・ラベル・ボトル、ゴミ とり |
| えらぶ（pick） | すきな もの を タップ | えんぴつ の いろ、ボトル か ふく か |
| しらべる（find） | ひび の ある もの を タップ | ガラス びん の けんさ |

## こうてい の かんがえかた

- こうてい は いっぱんてき な つくりかた（きょうかしょ・ぎょうかい だんたい の こども むけ しりょう に そう）。
- **じつざい の 会社名・商品名・ロゴ は つかわない**（`test.js` の NG リスト で しらべる）。
- おんど や じかん は「やく 1000ど（えんぴつ の しん を やく）」「やく 1500ど（ガラス を とかす）」
  「やく 260ど（ペット を とかす）」「やく 130ど（カカオ を いる）」「やく 30ど（テンパリング）」の ように まるめる。
- あつい もの・はもの の こうてい には「⚠️ おとな」の かんばん と
  「ほんもの の きかい は おとな が うごかす よ。まね しないでね。」を だす。とても あつい ところ は こども は ボタン で おねがい する だけ。
