# いのちの タイムトンネル 🦕

**地球の 生きものが、長い 時間を かけて うつりかわってきた 大きな 流れ** を、
トンネルを むかし → いま へ 進みながら 知る あそび（分野：れきし）。

対象：5さい〜。`index.html` を ひらくだけで あそべます（外部ライブラリなし・1ファイル）。

## あそびかた（1かい 1〜3ぷん）

1. ▶ しゅっぱつ → トンネルを ワープ。年数の カウンターが まわる（時間が 長い ところほど ワープも 長い）
2. 時代ごとに 生きものを **3つ 見つけて タップ** → カードが 出て ずかんに 入る
   （7びょう 見つからないと 1ぴき 光って ヒント）
3. 「すすむ ▶」か **ひだりへ スワイプ** で つぎの 時代へ（3つ 見つける 前は すすめない）
4. さいごに カードを **ふるい じゅんに タップ** する クイズ（まちがえても 何回でも やりなおせる）
   - はじめは 4まい、1かい クリアすると 6まい（6つの 時代 ぜんぶ）
5. 「トンネルの ながさ くらべ」… 1ます＝100まんねんの トンネルを 6600まんねん まえまで もどり、
   「きょうりゅうは ひとより ずっと ずっと まえ」を 長さで 見る
6. ⭐ と かみふぶきで おいわい

## 6つの 時代と 生きもの

| 時代 | ころ | 生きもの |
| --- | --- | --- |
| うみの ちいさな いきもの | 35おくねん いじょう まえ から | さいしょの いのち（バクテリア）・シアノバクテリア・さんようちゅう |
| さかなの じだい | やく 4おくねん まえ（デボン紀） | ダンクルオステウス・シーラカンス・アンモナイト |
| りくに あがる | やく 3おく6000まん〜3おくねん まえ | イクチオステガ・メガネウラ・リンボク |
| きょうりゅうの じだい | やく 2おく3000まん〜6600まんねん まえ | ティラノサウルス・トリケラトプス・プテラノドン（よくりゅう） |
| ほにゅうるいの じだい | 6600まんねん まえ から | パラケラテリウム・スミロドン・ケナガマンモス |
| ひと | やく 700まんねん まえ から いま | アウストラロピテクス・ホモ・エレクトス・ホモ・サピエンス |

きょうりゅうは `kyoryu-hakkutsu/` と 重ならないよう 1時代ぶんだけ。

### 事実の あつかい

- 年代は 国際年代層序表（ICS）と 一般的な 図鑑の 値に そろえた おおよその 数字（「やく」つき）。
- クイズは **時代が はっきり 前後する カードだけ** を 使う。年代が 重なる もの
  （イクチオステガと ダンクルオステウス、マンモス・むかしの ひとの なかま と スミロドン など）は
  `quiz: false` で クイズに 出さない。ひとの 時代からは ホモ・サピエンスだけが 出る。
- プテラノドンは「きょうりゅうとは べつの なかま（よくりゅう）」、とりは「きょうりゅうの しそん」と 書いている。
- ながさくらべの「220ばい」は 6600まんねん ÷ 30まんねん、「50ばい いじょう」は 38おくねん ÷ 6600まんねん ≒ 57。
