# ろせんず タイムマシン ⏳🚂

**タイムマシンの レバーを うごかすと 年が すすみ、東京・横浜の ろせんずに 線が 1本ずつ のびていく** あそび。
さいしょの 1本（新橋〜横浜）から、何十年も かけて 線が ふえてきた ことを 地図で しる（分野: ろせんず・れきし・ちり）。

対象：5さい〜。`index.html` を ひらくだけで あそべます（外部ライブラリなし・1ファイル）。

## あそびかた（1かい 1〜3ぷん）

1. 「しゅっぱつ！」→ 新橋〜横浜の 1本だけの 地図。じょうき きかんしゃが ぽっぽー
2. レバーを うごかすと 年が びゅーんと すすみ、あたらしい 線が のびる
3. とちゅうで ストップ →「つぎに できるのは どの 線？」を 3つから えらぶ（3かい）
   - まちがえても その こたえが うすく なるだけ。なんどでも えらびなおせる
4. いまに つくと 線で いっぱいの 地図。さいしょの 1本が きらっと 光り、ほしと かみふぶき

わらいどころ（どれも 線が できた あと／答えあわせの あとに でる）:
線が ふえるたびに 小人が「また ふえた！」と 地図を ひろげる／ちかてつで もぐらが びっくり／
いまの 地図で 小人が 線に からまって ぐるぐる。

## しくみ

- データは `index.html` の `STATIONS`（駅）・`SEGS`（線の かけら。`at` で でてくる ステップ、`until` で きえる）・`STEPS`（できごと）の 1か所
- 線は SVG の パスを stroke-dashoffset で のばす。ちかてつは 白い 点線、しんかんせんは 白い 線を 重ねて 見わける
- 音は WebAudio の 合成音。🔊 おと・🗣 こえ（ブラウザの よみあげ）を オン/オフ
- 記録は localStorage `rosenzu-timemachine-v1`（いまに ついた 回数・さいこうの ほし・設定）
- たてスマホは 地図が うえ、よこタブレットは 地図が ひだり
