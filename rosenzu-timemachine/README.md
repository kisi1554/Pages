# ろせんず タイムマシン ⏳🚂

**タイムマシンの レバーを うごかすと 年が すすみ、東京・横浜の ろせんずに 線が 1本ずつ のびていく** あそび。
さいしょの 1本（新橋〜横浜）から、何十年も かけて 線が ふえてきた ことを 地図で しる（分野: ろせんず・れきし・ちり）。

対象：5さい〜。`index.html` を ひらくだけで あそべます（外部ライブラリなし・1ファイル）。

## あそびかた

ホームで たびを えらぶ:

| たび | できごと | クイズ | めやす |
| --- | --- | --- | --- |
| 🚂 みじかい たび | 8つ ＋ いま | 3もん（わっか・ちかてつ・しんかんせん） | 2ふん |
| ⚓ よこはまの たび | 12こ ＋ いま（横浜線・相鉄・南武線・田園都市線・ブルー/グリーンラインなど） | 3もん（しんかんせん・あおい ちかてつ・みどりの ちかてつ） | 4ふん |
| 🗼 とうきょうの たび | 15こ ＋ いま（山手線・中央線・銀座線・丸ノ内線・副都心線・上野東京ラインなど） | 5もん（わっか・ちかてつ・モノレール・しんかんせん・うんてんしさんが いない でんしゃ） | 4ふん |
| 🚄 ぜんぶの たび | 25こ ＋ いま（21ろせん） | 7もん | 7ふん |

1. 新橋〜横浜の 1本だけの 地図から しゅっぱつ。じょうき きかんしゃが ぽっぽー
2. レバーを うごかすと 年が びゅーんと すすみ、あたらしい 線が のびる（でんしゃが 線の さきを はしる）
3. とちゅうで ストップ →「つぎに できるのは どれ？」。まちがえると「もう できて いるよ」「もっと あとで できるよ」
   「リニアは いま つくって いる ところ」と おしえて、えらびなおせる
4. いまに つくと 線で いっぱいの 地図。さいしょの 1本が きらっと 光り、ほしと かみふぶき
5. 地図の 線を タッチすると **ろせんず ずかん**（21ろせん：できた 年・まめちしき・おもな えき）。
   たびで 見た 線が ずかんに はいる（ホームから いつでも ひらける）

わらいどころ（どれも 線が できた あと／答えあわせの あとに でる）:
小人が「また ふえた！」と 地図を ひろげる（モノレールで「レール 1ぽんで だいじょうぶ？！」、ゆりかもめで「うんてんしさん どこ〜？」、
みなとみらい線で「あれっ、ちょっと へった？」など）／ちかてつが できるたびに もぐらが とびだす／いまの 地図で 小人が 線に からまって ぐるぐる。

## しくみ

- データは `index.html` の `STATIONS`（駅）・`LINES`（ずかん）・`SEGS`（線の かけら。`ev` で でてくる できごと、`until` で きえる）・`EVENTS`（できごと。`s` が みじかい たび、`sts` は 駅だけの できごと、`q.qIn` で クイズを だす たびを しぼる）・`COURSES`（たびごとの できごと）の 1か所
- 駅は「みえて いる 線に 名前で のって いる」ときだけ でる（とおるだけの 点は 座標で かく）
- 線は SVG の パスを stroke-dashoffset で のばす。ちかてつは 白い 点線、しんかんせんは 白い 線、モノレール・ゆりかもめは 白い こまかい 点を 重ねて 見わける
- 音は WebAudio の 合成音。🔊 おと・🗣 こえ（ブラウザの よみあげ）を オン/オフ
- 記録は localStorage `rosenzu-timemachine-v1`（いまに ついた 回数・たびごとの クリア回数・さいこうの ほし・ずかんで 見た 線・設定）
- たてスマホは 地図が うえ、よこタブレットは 地図が ひだり
