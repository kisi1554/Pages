# 保護者のための中学受験算数（講義ノート）

難関中学の算数を、1回1分野ずつ講義形式で扱う **保護者（大人）向け** のノート。
リポジトリの他アプリと違い、読み手は子どもではなく親。ふりがなは付けない。

## 各回の構成

1. **道具の紹介** — 中学受験ではその分野をどんな「型」で処理するか
2. **数学の目で見ると** — その型が数学的には何をやっているのか（大人向けの裏付け）
3. **演習** — 基礎〜難関校レベル。解答は `<details>` で折りたたむ
4. **子どもへの仕込み** — 幼児〜低学年のうちに日常で埋めておく「芽」
5. **宿題** — 3問前後

各回の `<style>` は全回で同一に保つ（第1回からコピーする）。図のクラスを共有しているため、
片方だけ直すと図の見え方がずれる。

各回の HTML は CSS 込みで自己完結させる（外部ライブラリ・CDN は使わない）。

## 図について

解説の図はすべて **手書きのインライン SVG**（`<figure class="dg">` ＋ `<figcaption>`）。
画像ファイルも作図ライブラリも使わない。

- 線・文字は `currentColor`、塗りは `.bxa` / `.bxm` / `.bxk`（accent / math / kid の淡色）と
  `.fila` / `.film`（べた塗り）のクラスで指定する。ライト／ダーク両対応にするため、
  SVG 内に色を直書きしない。
- べた塗りの上に載せる文字は `.tb`（＝背景色）にする。
- 線の上に文字を置くときは、`fill="var(--card)"` の小さな矩形を下敷きにして線を隠す。
- `<marker>` の `id` はページ内で一意にする（第1回は `ar1`…、第2回は `b1`… と回ごとに接頭辞を変える）。
- **線に色をつけるときは `class="la"`（accent）／`class="lm"`（math）を使う。**
  `stroke="var(--accent)"` のような presentation attribute は `svg .s2{stroke:currentColor}` に
  負けて黒いままになる。
- 図の主張は `<figcaption>` に1文で書き、`aria-label` にも同じ内容を入れる。

見え方の確認はヘッドレス Chromium でできる。

## 回を追加する

1. `lesson-NN-<分野>.html` を追加する（既存回をコピーして中身を差し替えるのが早い）
2. `index.html` に `<a class="lesson">` を1つ足す
3. 次回予告のブロックを更新する

## 図形の回の作図

三角形などは `<polygon points="...">` で座標を直接書く。分点や交点の座標は手で計算するため、
**書いたあとに Python で検算する**こと（分点の比、交点が2直線の両方に乗っているか）。
`sapix-lesson/lesson-04-heimen.html` の図3・図6・図7・図8 がその例。

## 答えの検算

演習・宿題の数値は、**書いたあとに Python の総当たりで確かめる**こと。
とくに場合の数と図形は、手計算だと取り違えに気づけない。
第5回では宿題2（通行止めのある道順）の答えを、この検算で誤りと分かって直している。

## 予定している分野

比 → 速さ → 割合と相当算 → 平面図形（面積比・相似）→ 立体図形 → 場合の数 →
数の性質 → 規則性 → 特殊算（つるかめ・差集め・ニュートン算）
