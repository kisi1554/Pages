# 保護者のための中学受験算数（講義ノート）

難関中学の算数を、1回1分野ずつ講義形式で扱う **保護者（大人）向け** のノート。
リポジトリの他アプリと違い、読み手は子どもではなく親。ふりがなは付けない。

## 各回の構成

1. **道具の紹介** — 中学受験ではその分野をどんな「型」で処理するか
2. **数学の目で見ると** — その型が数学的には何をやっているのか（大人向けの裏付け）
3. **演習** — 基礎〜難関校レベル。解答は `<details>` で折りたたむ
4. **子どもへの仕込み** — 幼児〜低学年のうちに日常で埋めておく「芽」
5. **宿題** — 3問前後

## 図について

解説の図はすべて **手書きのインライン SVG**（`<figure class="dg">` ＋ `<figcaption>`）。
画像ファイルも作図ライブラリも使わない。

- 線・文字は `currentColor`、塗りは `.bxa` / `.bxm` / `.bxk`（accent / math / kid の淡色）と
  `.fila` / `.film`（べた塗り）のクラスで指定する。ライト／ダーク両対応にするため、
  SVG 内に色を直書きしない。
- べた塗りの上に載せる文字は `.tb`（＝背景色）にする。
- 線の上に文字を置くときは、`fill="var(--card)"` の小さな矩形を下敷きにして線を隠す。
- `<marker>` の `id` はページ内で一意にする（第1回は `ar1`…、第2回は `b1`… と回ごとに接頭辞を変える）。
- **線に色をつけるときは `class="la"`（accent）／`class="lm"`（math）を使う。**
  `stroke="var(--accent)"` のような presentation attribute は `svg .s2{stroke:currentColor}` に
  負けて黒いままになる。
- 図の主張は `<figcaption>` に1文で書き、`aria-label` にも同じ内容を入れる。

見え方の確認はヘッドレス Chromium でできる。

## 回を追加する

2. `index.html` に `<a class="lesson">` を1つ足す
3. 次回予告のブロックを更新する

## 図形の回の作図

三角形などは `<polygon points="...">` で座標を直接書く。分点や交点の座標は手で計算するため、
**書いたあとに Python で検算する**こと（分点の比、交点が2直線の両方に乗っているか）。
`sapix-lesson/lesson-04-heimen.html` の図3・図6・図7・図8 がその例。

## 立体の図

立方体などは等角図（前面・上面・右面の3枚のポリゴン）で描く。座標を手で並べると崩れるので、
**Python で座標を計算して SVG を生成**し、それを HTML に貼る（`lesson-06-rittai.html` の図1・図6・図8）。

面の濃淡は `fill="var(--accent)" fill-opacity="0.18 / 0.38 / 0.58"`（上面・前面・右面）とする。
`fill-opacity` は線の色に影響しないので、ライト／ダークどちらでも同じ立体感になる。

## 実戦編

`jissen-NN-<学校>.html`。1回につき1問だけを、自力で解く時間つきで扱う。

| 回 | ファイル | 題材 |
| --- | --- | --- |
| 実戦編 第1回 | `jissen-01-azabu.html` | 麻布の型 — 裏返しと不変量（8マスの石、となりあう2個を裏返す） |
| 実戦編 第2回 | `jissen-02-azabu2020.html` | 麻布 2020年度 大問3 — mod2 と mod3 が作る輪（実物の過去問） |

**過去問の本文は載せない。**入試問題は学校の著作物なので、扱いかたは2通りだけ。

1. **自作問題**（第1回）— その学校の出題形式・思想に沿って自分で作り、そのことを冒頭に明記する
2. **実物の過去問**（第2回）— **本文を転載せず**、公開されている出典 PDF へのリンクを置き、
   こちらには**条件の要約と解答・解説だけ**を書く。要約は原文の言い回しをそのまま使わない
   （書いたあと、原文の特徴的な語句が入っていないか grep で確認する）

実物を扱えるのは **WEB で公開されている過去問に限る。**

構成は 0.その学校の算数は何を見ているか → 1.問題（小問4つ、ここで手を止めさせる）→
2.解答と解説（`<details>` で1問ずつ）→ 3.数学の目で見ると → 4.発展 → 5.子どもへの仕込み →
6.持ち帰ってほしいこと。

**数値はすべて Python で総当たり検証してから書く。**第1回は到達可能な状態を BFS で全列挙し、
最短手数の公式2通り（累積和の重み／ペア間隔の和）が BFS の結果と128状態すべてで一致することを
確認している。

図は講義編と同じ作法（インライン SVG、`<figure class="dg">`、marker id はページ内で一意）。
石のマス目は `fila`（黒）と `s`（白の輪郭）で描く。

## 答えの検算

演習・宿題の数値は、**書いたあとに Python の総当たりで確かめる**こと。
とくに場合の数と図形は、手計算だと取り違えに気づけない。
第5回では宿題2（通行止めのある道順）の答えを、この検算で誤りと分かって直している。

## 扱った分野（全9回・完了）

比 → 速さ → 割合と相当算 → 平面図形（面積比・相似）→ 場合の数 → 立体図形 →
数の性質 → 規則性 → 特殊算（つるかめ・過不足・消去・ニュートン算）

当初予定していた分野はすべて揃った。以降に回を足すなら、分野の掘り下げ
（速さのダイヤグラム応用、図形の難問演習など）や、学年別のロードマップになる。
