SAPIX 難関校クラス／保護者のための算数　実戦編

実戦編 第1回　麻布の型
— 裏返しと、変わらないもの

対象：保護者／所要 30分（自力で15分 ＋ 解説15分）／道具：紙とえんぴつだけ

はじめに

これは麻布の過去問そのものではありません。入試問題は学校の著作物なので、ここには載せません。 かわりに、麻布の出題形式と思想に沿って作った問題を1問置いています。 「計算はごく軽い」「誘導の小問で規則を発見させる」「最後は説明を書かせる」という性格は本物に寄せてあります。

本物を解きたくなったら、市販の過去問集（声の教育社の『麻布中学校』など）を手に入れてください。 ここで身につけてほしいのは、そういう問題の前でどう手を動かすかのほうです。

0. 麻布の算数は、何を見ている試験か

60分で大問6題前後。計算量は最難関校のなかでいちばん軽いのに、偏差値は最上位です。 つまり計算力ではまったく差がつかない。差がつくのは次の3つです。

麻布が見ているものふだんの勉強で鍛わらない理由
初見の設定を、自分で整理できるか塾のテキストは分野名が書いてある。麻布の問題文には書いていない
手を動かして規則を見つけられるか解法暗記は「見つける」作業を飛ばしてしまう
「なぜそう言えるか」を書けるか答えだけ合っていればよい練習を積むと、いちばん弱くなる

今回の問題は、この3つを1問で全部通ります。とくに最後の小問は、 「できない」ことを証明させるという、中学受験でもっとも大人の数学に近い形をしています。

1. 問題

設定

横一列に8個のマスがならんでいて、左から順に 1番、2番、…、8番と呼びます。 それぞれのマスには石が1個ずつ置いてあり、はじめはすべて白い面が上を向いています。

石は裏返すことができ、白の裏は黒、黒の裏は白です。 ただし裏返しかたには決まりがあって、1回の操作では、となりあう2個をえらんで、その両方を裏返す—— これしかできません。はなれた2個を同時に裏返すことはできず、1個だけ裏返すこともできません。 操作は何回でもくりかえせます。

(1)手を動かす

2番と5番だけが黒く、ほかの6個は白い——この状態を作りなさい。 また、そのために必要な操作の回数は、いちばん少なくて何回ですか。

(2)規則を見つける

1番と8番だけが黒い状態を作るには、いちばん少なくて何回の操作が必要ですか。

(3)できないことを示す

黒い石がちょうど1個だけの状態は、操作を何回くりかえしても作ることができません。 そのわけを説明しなさい。

(4)数えきる

操作をくりかえして作ることのできる石のならびかたは、はじめの状態もふくめて全部で何通りありますか。

ここで一度、手を止めてください。紙に8個の四角を書いて、実際に塗ってみるのがいちばん早道です。 (1)(2) は5分、(3) は考えこんでかまいません。(3) が見えると (4) は自動的に落ちます。

目標時間は全部で15分。麻布の本番なら、この1問に使えるのはおよそ10分です。

2. 解答と解説

(1) の解答 — 3回

「2番と5番を黒くしたい」ので、2番から5番へ向かって、となりあう2個ずつを順に裏返していきます。

ポイントは間のマスが2回裏返されることです。3番は「2番と3番」の回と「3番と4番」の回の2回、 4番も2回。2回裏返すと元にもどるので、間は白のまま残り、両はしの2番と5番だけが黒くなります。

回数は 5 − 2 = 3 回。これより少なくできないことは、(3) と同じ考え方（次ページの図6）で確かめられます。

(2) の解答 — 7回

やることは (1) とまったく同じで、はしからはしまで伸ばすだけです。

8 − 1 = 7 回。

ここで(1) と (2) を見くらべるのが、この問題の誘導の意図です。 黒2個の位置を a 番と b 番とすると、 最短の回数はいつも b − a。これはあとで効いてきます。

そして右の列の黒の個数を見てください。0個 → 2個 → 2個 → 2個 → … と動いていて、 一度も奇数になっていません。(3) はここに気づけるかどうかの問題です。

(3) の解答 — 黒の個数の偶奇は、ぜったいに変わらないから

1回の操作でえらぶ「となりあう2個」は、色の組み合わせが次の3通りしかありません。

  • 白白を裏返す → 両方黒になる。黒の個数は ＋2
  • 黒黒を裏返す → 両方白になる。黒の個数は −2
  • 白黒（または黒白）を裏返す → 入れかわるだけ。黒の個数は ±0

どの場合も変化は ＋2、−2、0 のどれかで、すべて偶数です。 偶数に偶数を何回足しても偶数のままなので、 黒の個数が偶数か奇数かは、操作では決して変えられません。

はじめは黒が0個、つまり偶数です。したがって、どれだけ操作しても黒の個数はつねに偶数のまま。 黒がちょうど1個（奇数）の状態には、絶対にたどりつけません。（証明終わり）

書き方の注意

ここで「いろいろ試したけれどできなかった」は答えになりません。 できないことを示すには、試すのではなく、ぜったいに変わらないものを1つ見つけて示す—— これが唯一の道です。麻布はこの一点だけを採点しています。

(4) の解答 — 128通り

(3) から、作れるのは黒が偶数個のならびだけだと分かりました。あとは2つのことを言えば終わりです。

① 黒が偶数個なら、どんな配置でも作れる。 黒くしたいマスを左から順にならべて、1番目と2番目、3番目と4番目、…と2個ずつ組にします。 黒は偶数個なので、あまりは出ません。 各組について (1) と同じやり方で左から右へ裏返していけば、その組の両はしだけが黒くなります。 組の区間どうしは重ならないので、おたがいに邪魔をしません。

② 黒が偶数個のならびは何通りあるか。 1番から7番までの色は自由に決めてよいので 2 × 2 × … × 2 ＝ 2⁷ ＝ 128 通り。 最後の8番の色は、黒の合計が偶数になるように1通りに決まってしまいます （7番までの黒が偶数個なら8番は白、奇数個なら8番は黒）。

よって 128通り。全部で 2⁸ ＝ 256通りあるならびかたの、ちょうど半分です。

おまけ — 最短手数を一目で出す方法

(1)(2) で「最短は b − a」と書きましたが、黒が4個や6個のときはどうなるでしょうか。 実は、次のようにするとどんな配置でも一目で分かります。

マスとマスの境目7か所に、「その境目より左にある黒の個数」が偶か奇かを書きます。 すると、1回の操作（i番とi+1番を裏返す）は、i番目の境目の印だけをちょうど1か所入れかえ、 ほかの境目はすべて変えません。

だから最短手数 ＝ 「奇」と書かれた境目の数。 2番と5番が黒なら奇は3か所で3回、1番と8番が黒なら奇は7か所で7回。 黒が 2・4・6・8番なら奇は4か所で4回です。

そして8番目の境目（＝右はし、全部の黒の個数の偶奇）だけは、どの操作でも変わりません。 これが (3) で見つけた「変わらないもの」の正体です。

3. 数学の目で見ると

不変量 ＝ 保存量

(3) でやったことは、物理でいう保存則から選択則を導く論法そのものです。 「その過程で変わらない量」を1つ見つけ、始状態と終状態でその値が違うことを示せば、 途中の経路を一切調べずに、遷移が起こりえないと言い切れる。 パリティが保存するから、この崩壊は禁止される——あれと同じ構造です。

中学受験の世界ではこれを「不変量」と呼び、難関校の「作れないことを示せ」型の問題は、 ほぼすべてこの1つの型に収まります。探すべきは手順ではなく、変わらない量。

線形代数として

石のならびを、0（白）と1（黒）を成分とする8次元ベクトル v ∈ 𝔽₂⁸ と見ます（𝔽₂ は 1+1=0 の世界）。 「i番とi+1番を裏返す」は、ベクトル eᵢ + eᵢ₊₁ を足す操作です。 順番も回数も関係なく、同じものを2回足せば消える——これが「2回裏返すと元にもどる」の正体です。

したがって作れる状態の全体は、7本のベクトル e₁+e₂, e₂+e₃, …, e₇+e₈ が張る部分空間 W。 この7本は一次独立なので dim W = 7、要素数は 2⁷ = 128。 (4) の答えは、部分空間の次元を数えただけのことでした。

いっぽう (3) の不変量は、線形写像 σ(v) = v₁ + v₂ + … + v₈（成分の総和、𝔽₂ で）です。 どの生成元も σ の値が 0 なので σ は操作で不変であり、W = ker σ。 次元定理 dim ker σ = 8 − 1 = 7 からも 128 が出ます。

符号理論の言葉なら、W は偶数重み符号 [8, 7, 2]。 パリティビットを1個つけた、あのエラー検出符号そのものです。

おまけの図6は、離散の積分だった

境目に書いた「偶・奇」は、累積和 uᵢ = v₁ + v₂ + … + vᵢ（𝔽₂ で）です。 つまり v を離散的に積分したもので、逆に v は u の階差（離散微分）—— 第8回でやった階差数列の関係が、そのまま出てきています。

この座標変換のもとで、操作は uᵢ ← uᵢ + 1、つまり1か所だけを反転するただの操作に化けます。 しかも u₈ = σ(v) には手が届かない。 「となりあう2個しか裏返せない」という束縛が、座標を取りかえた瞬間に 「u₁〜u₇ は自由、u₈ だけ固定」という見通しのよい形になるわけです。

最短手数が「奇の個数」になるのも同じ理由で、u のハミング重みがそのまま必要な操作回数になります。 変数変換で束縛条件をほどく——解析力学で一般化座標を取りかえるときにやっていることと、発想は同じです。

4. 発展 — 自分で作りかえてみる

麻布の問題は、解いたあと設定を1か所変えてみると、いちばん力になります。2つだけ置いておきます。

発展1ルールを変える

操作を「となりあう2個」ではなく「1つとばしの2個（i番と i+2番）」に変えます。 このとき、作れる石のならびかたは全部で何通りですか。

発展1 の解答 — 64通り

1つとばしなので、奇数番（1・3・5・7）と偶数番（2・4・6・8）が完全に分断されます。 操作は奇数番の中だけ、あるいは偶数番の中だけで閉じていて、両者は行き来しません。

それぞれのグループは「4個ならびの、となりあう2個を裏返す」のと同じ構造なので、 もとの議論がそのまま使えて 2³ = 8通り ずつ。 独立なので 8 × 8 = 64 通りです。

不変量が1個から2個に増えたのがポイントです。 「奇数番の黒の個数の偶奇」と「偶数番の黒の個数の偶奇」が別々に保存されます。 線形代数でいえば、部分空間の次元が 7 から 6 に落ちた（2⁶ = 64）ということ。 物理でいえば、保存量が1つ増えたぶんだけ到達できる状態が半分になった、ということです。

発展2一般化する

マスの数を8個ではなく n 個にします（となりあう2個を裏返すルールは同じ）。 作れるならびかたは何通りですか。

発展2 の解答 — 2ⁿ⁻¹ 通り

議論はまったく変わりません。黒の個数の偶奇が不変で、偶数個のものは全部作れる。 1番から n−1 番までを自由に決めれば n 番が自動で決まるので 2ⁿ⁻¹ 通り。 全体 2ⁿ のちょうど半分です。

n = 2 なら2通り（白白／黒黒）、n = 3 なら4通り。手で確かめられます。

ここで「ちょうど半分」が n によらないのが気持ちのよいところで、 これは不変量 σ が取りうる値が「偶」「奇」の2つしかないことの直接の帰結です。 保存量の値でラベルづけされた部屋が2つあって、そのうち1部屋にしか入れない、という絵になっています。

5. 子どもへの仕込み

幼児〜低学年

この問題は、おはじきが8個あれば今日からできます。ルールを教えて、あとは触らせるだけ。

  • 裏返しごっこ。オセロの石でも、片面に丸を描いた牛乳キャップでもかまいません。 一列にならべて「となりのと2つセットでひっくり返す」だけのルールで遊ばせる。 「1個だけ黒にしてみて」と言うのがこの遊びの全部です。何度やってもできない、という経験が残ればそれで十分。
  • 「ぜったいムリ」と「まだできてないだけ」はちがう。 子どもが「できない！」と言ったときに、「ほんとうに絶対ムリ？　それともまだ見つかってないだけ？」と聞き返す。 この区別がつく子は、高学年で証明に強くなります。急いで答えを教えないこと。
  • 偶数・奇数を「ペアが作れるかどうか」で入れる。 おはじきを2個ずつくっつけて、あまりが出るか出ないか。 「偶数＝2で割り切れる数」と教えるより、ペアにしたときあまらないという体感のほうが、 この問題のような場面でそのまま使えます。

低学年のうちに効くのは、解き方ではなく「答えの出ない問題の前で、機嫌よく手を動かし続ける態度」だけです。 この問題はそれを育てるのに向いています。

6. この1問で持ち帰ってほしいこと

まとめ
  1. 「できない」と言うには、変わらないものを1つ見つける。 試して見つからないのは証明ではありません。不変量を1つ示して終わり——これが唯一の形です。
  2. 数えるときは、自由に決めてよい部分と、自動で決まる部分に分ける。 (4) の「1〜7番は自由、8番は自動」は、そのまま次元を数える作業でした。
  3. 見通しが悪いときは、座標を取りかえる。 境目に偶・奇を書く（＝累積和をとる）だけで、束縛のきつい問題が「1か所ずつ反転するだけ」に化けました。

そして麻布の性格として、この3つはどれも計算力ではないということ。 だからこの学校は、計算が速いだけの子をきれいに落とします。

この問題の難易度：難易度ランキングでいう麻布は 発想5・処理量2・記述5・時間2。今回の問題も、計算はほぼ0で、書く量が答えの中心でした。
