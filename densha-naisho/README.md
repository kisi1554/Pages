# でんしゃの ないしょばなし 🌙🚄

よるの しゃこで、**ほんもの そっくりの でんしゃ**と おはなし する アプリです（5さい〜）。
おはなしの なかに ことば・かず・かたち・しぜん・でんしゃの ちしきが まざって いて、
あそんで いる うちに しぜんに おぼえられます。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリ・画像ファイルなし）。

## ほかの アプリと ちがう ところ（えの つくり）

- **よるの けしき＋ひかり**で えがく、しゃじつてきな え。ステンレスの つや・ガラスの うつりこみ・
  ヘッドライトの にじみ・レールの はんしゃを SVG の グラデーションだけで だして います。
- でんしゃに **かお（め・くち）は かきません**。ほんものの でんしゃと おなじで、
  **ヘッドライトが「め」**。しゃべると ライトが ゆれ、まばたきし、うれしいと はねます。
- もんだいの ずは、でんしゃが **ライトで よぞらに うつします**（しゃりょうの れんけつ・かたち・つき・とけい など）。

## でてくる でんしゃ（7だい）

まず よこはまの みぢかな 4つ、そのあとに「そのほか」が ならびます。

| でんしゃ | せいかく | その でんしゃ だけの ないしょばなし |
| --- | --- | --- |
| ブルーライン（3000V） | やさしい | ちかてつ、3ぼんめの レール、B01〜B32、よこはま |
| けいひん とうほくせん（E233けい） | しっかりもの | 「けいひん」の いみ、そらいろ、かいそく、47えき |
| とうよこせん（とうきゅう 5050けい） | おしゃれ | 「とうよこ」の いみ、かくえき・きゅうこう・とっきゅう、ちゅうかがいへ ちょくつう、TY01〜TY21 |
| やまのてせん（E235けい） | あかるい | わっかの せんろ、30えき、うぐいすいろ、うちまわり・そとまわり |
| はやぶさ（E5けい） | げんきで はやい | 320キロ、15メートルの はな、3つの いろ、ほっかいどう |
| ドクター イエロー（923がた） | ていねいな おいしゃさん | せんろの けんさ、きいろの わけ、7りょう |
| デゴイチ（D51 498） | ものしりな おじいちゃん | せきたんと みず、「D」の いみ、90ねん まえ、てんしゃだい |

でんしゃを ふやす ときは `core.js` の `TRAINS` に 1つ たし、`art.js` の `train()` に えを たします。

## あそびかた

1. 「しゃこへ いく」→ でんしゃを えらぶ。
2. でんしゃが はなしかけて くるので、**ボタン**で こたえる（つかえる たんまつでは **🎤 こえ**でも）。
3. 「ライトを タップして」など、**でんしゃの ぶひんを さわる** もんだいも あります。
   ふだんも ライト・まど・パンタグラフ・えんとつを タップすると うごきます。
4. おはなしが 1つ おわると よぞらに **ほしが 1つ** ふえます（5こ ごとに ながれぼし）。

まちがえても げんてんは ありません。1かいめは ヒント、2かいめは こたえの ボタンが ひかります。
「すきな いろ・たべもの」などは おぼえて いて、あとの おはなしに でて きます。

- 🗣️ こえ（よみあげ）の オン/オフ、🔊 こうかおんの オン/オフ
- こえが でない たんまつでは「つぎへ ▶」ボタンで すすみます
- きろくは localStorage（`densha-naisho-v1`）。「おうちの ひとへ」で よびかたの へんこうと リセット

## ジャンルの ふやしかた

1. `genre-〇〇.js` を つくり、`Naisho.addGenre({...})` を かく。
2. `index.html` の `<script src="genre-…">` の ならびに 1ぎょう たす（`app.js` より まえ）。

これだけで メニューに ボタンが ふえ、「おまかせ」にも まざります。

```js
Naisho.addGenre({
  id: 'eigo', name: 'えいご', emoji: '🔤', color: '#ff922b',
  talks: [
    { id: 'iro', f: function (c) {           // c = { n: なまえ, t: でんしゃ, mem: おぼえた こと }
      return [
        S('{me}の いろは えいごで なんて いうかな。', { fx: 'beam' }),
        QA('あおは えいごで?', 'ブルー', ['レッド', 'グリーン'], { hint: '…', yes: 'ブルー{da}。' }),
      ];
    } },
    // only: ['blue'] … その でんしゃ だけ / need: (c) => … じょうけん
  ],
});
```

| ぶひん | いみ |
| --- | --- |
| `S(ぶん, o)` | でんしゃが しゃべる |
| `QA(ぶん, せいかい, [まちがい…], o)` | こたえの ある しつもん（ならびは まざる） |
| `QN(ぶん, かず, たんい, o)` | かずの 3たく（ちかい かずを じどうで つくる） |
| `QO(ぶん, [えらぶもの…], へんじ, o)` | どれも せいかいの しつもん。`o.save` で おぼえる |
| `T(ぶん, ぶひん, o)` | でんしゃの ぶひんを タップ（`light` `window` `nose` `panta` `door` `plate` `chimney`） |

- `o.show` … ライトで うつす ず: `{e:'🍎🍎'}` `{cars:[3,2]}` `{cars:[5],off:2}` `{shape:'maru'}` `{shapes:[…]}`
  `{moon:'half'}` `{clock:7}` `{word:'せんろ',hi:-1}` `{bars:[3,6]}` `{txt:'ドア'}`
- `o.fx` … `horn` `beam` `wiper` `rain` `snow` `shoot` `rainbow` `steam` `spark` `dark` `third`
  `sig-ao` `sig-ki` `sig-aka` `moon-full` `moon-half` `moon-crescent` `couple` `door` `gatan` `crossing`
- ことばづかい（でんしゃ ごとに かわる）: `{n}` なまえ / `{me}` ぼく・わたし・わし /
  めいしの あと `{da}` `{dane}` / どうし・けいようしの あと `{yo}` `{ne}` `{nda}`
