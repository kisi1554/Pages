# うどんやさん たいけん ― セルフの うどんやさんで はたらこう 🍜

セルフ式の さぬきうどん店の **てんいんさん** に なって、めんを うつ → ゆでる → ゆきり → もりつけ →
てんぷらを あげる → おかいけい までを ゆびで ぜんぶ やってみる おしごと たいけん アプリです。
対象は 年中〜小学3年。1日の えいぎょうは 3〜5分（おきゃくさん 5〜10人）。

まなび: しごとの じゅんばん（てじゅん）、ちゅうもんを おぼえる、タイミング、おかねの けいさん（たしざん・おつり）、
「いらっしゃいませ！」「ありがとうございました！」の おもてなし。

`index.html` を ブラウザで ひらくだけで あそべます（ビルドも サーバーも 不要。外部ライブラリなし）。
絵は SVG、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。

## オリジナルの お店です

**お店は オリジナルの「てうち うどん こむぎや」**。セルフうどん店の **ながれ**
（カウンターで ちゅうもん → めんを うけとる → てんぷらを じぶんで とる → さいごに おかいけい）だけを モデルにしていて、
実在の お店の 名前・ロゴ・制服・メニュー名・店内デザイン・キャッチコピーは つかって いません。

- のれんは あい色に こむぎの マークだけ（もじは なし）。かんばんの もじは「こむぎや」
- てんいんさんは オリジナルの **みどりの エプロン＋オレンジの はちまき**（むねに こむぎの マーク）
- メニュー名は 一般名（かけ・ぶっかけ・ざる・かまあげ・えびてん など）。ねだんも この アプリ用
- test.js で 実在の 店名が はいって いない ことを しらべて います

## あそびかた

ひょうしで **むずかしさ**・**てんいんさんの みため**（はだの いろ 4・かみがた 3）を えらんで、モードを えらびます。

| モード | なかみ |
| --- | --- |
| 🍜 えいぎょう | あさの めんうち → かいてん → へいてん。1日 ずつ すすむ。5日目・10日目に てんちょうから ほめられる |
| 🥣 めんうち だけ | めんうちを なんども |
| 💴 レジ れんしゅう | おかいけい だけ 5もん（やさしい: 2しな・ちょうど／ふつう: 3〜4しな・おつり あり／てんちょう: おつりの がくも じぶんで） |
| 📒 おしごと ずかん | メニューと ねだん、「ほんものの うどんやさんでは…」の まめちしき（おしごとを すると ひらく） |

### あさ: めんうち

まぜる（こむぎこ・しおみず を タップ）→ こねる（ぐるぐる なぞる）→ ふむ（ひだり・みぎ こうごに タップ）→
のばす（めんぼうを うえ・したに スワイプ）→ きる（たてに なぞる。はばが そろうと ◎）。
できで「きょうの こし」★1〜3（しっぱいは ない）。

### えいぎょう: 5つの ばしょ

下の タブ（よこもちでは となりの ばしょを タップ）で いどう します。よこ タブレットでは お店が よこに ならんで カメラが すべります。
ちゅうもん カード（どんぶりの え＋なみ／だい＋トッピング＋てんぷら）は いつも 見える ところに あります。

| ばしょ | おしごと |
| --- | --- |
| 🗣 ちゅうもん | 「いらっしゃいませ！」で ちゅうもんを きく（ふきだしの え＋よみあげ。がいこくの おきゃくさんは えカードだけ） |
| ♨️ ゆでる | めんを かまへ ドラッグ（なみ 1たま／だい 2たま）→ ⏱ → **ゲージが みどりで てぼを タップ** → てぼを うえ・したに ふって ゆきり（3かい）→ ざるは つめたい みずで 2かい ひやす → うつわへ |
| 🍲 もりつけ | つゆの ポットを **ながおし**（メーターの みどりで はなす）→ つけつゆ → ねぎ・てんかす・しょうが を ドラッグ（うつわの トッピングを タップで とれる）→ できあがり |
| 🍤 てんぷら | おきゃくさんが たなから じぶんで とる。なくなったら ざいりょうを ころもへ → あぶらへ → **きつねいろで ひきあげ**（しろい ＋2・きつねいろ ＋3・こげ は もういちど） |
| 💴 おかいけい | トレーの しなものを 1つずつ タップで たす → もらった おかねから おつりの コインを トレーへ ドラッグ → 「ありがとうございました！」 |

しゅるいで てじゅんが ちがいます（`menu.js` の `recipe`）:

| うどん | なみ | だい | てじゅん |
| --- | --- | --- | --- |
| かけうどん | 300えん | 400えん | ゆでる → ゆきり → もる → あったかい つゆ → トッピング |
| かまあげうどん | 300えん | 400えん | ゆでる → もる → ゆでじる → つけつゆ → トッピング（**ゆきり しない！**） |
| ぶっかけうどん | 350えん | 450えん | ゆでる → ゆきり → もる → つめたい つゆ（すこし）→ トッピング |
| ざるうどん | 350えん | 450えん | ゆでる → ゆきり → **ひやす** → もる → つけつゆ → トッピング |

てんぷら: えびてん 150・ちくわてん 100・いもてん 100・かしわてん 150・かきあげ 200、おにぎり 100（ぜんぶ 10えん たんい）。
日が すすむと メニュー（2日目 ぶっかけ・いもてん・おにぎり、3日目 ざる・かしわ・かきあげ）と おきゃくさんが ふえます。

**まちがえても おこられません。** 「あれ？ かまあげは ゆきり しないよ。おゆが ないよ！」の ように やさしく いわれて、
トッピングの まちがいは その ばで、それ いがいは ゆでる ところから やりなおせます。ゲームオーバーは ありません。
おきゃくさんの ニコニコ（1〜3）は やりなおし・ゆでかげん・つゆの りょう・まち じかん・さいごの ごあいさつ で かわります（さいていでも 1）。
へいてんで うりあげ・だした うどんの かず・ニコニコの かず が でて、スタンプ カードに はんこ。
