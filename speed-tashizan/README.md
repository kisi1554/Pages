# スピードたしざん

10もんの たしざんを なんびょうで ぜんぶ とけるか きそう ゲーム。

- こたえは 1〜15 の ボタンから えらぶ（まちがえると ブブー → もういちど。タイムは とまらない）
- モードごとに ベストタイムを localStorage に ほぞん
- おと（WebAudio の ごうせいおん）は オン/オフ できる

## モード

| id | なまえ | もんだい |
| --- | --- | --- |
| `plus3` | たす 1・2・3 | 〇 ＋ 1〜3（こたえは 15 まで） |
| `plus4` | たす 4 | 〇 ＋ 4（こたえは 15 まで） |

## モードの ふやしかた

`index.html` の `MODES` に 1つ たす。`make()` が `{ a, b, op, ans }` を かえせば OK
（`ans` は 1〜15 におさめる）。ボタン・タイマー・ベスト記録は そのまま つかえる。
