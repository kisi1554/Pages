# はなしが長いブルくん 🚇

ブルーラインの でんしゃキャラクター **ブルくん** が、おはなしの「ひきだし」から
まめちしきを ながーく はなしてくれる アプリ。
`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。絵は インライン SVG、
音は WebAudio の 合成音 ＋ ブラウザの よみあげ）。

## あそびかた

1. たんすの **ひきだし**（10しゅるい）を タップ → おはなしを えらぶ。🎲 おまかせ でも OK。
2. ブルくんが 1ぶんずつ はなす。**つぎ ▶** で すすむ（▶▶ じどう で かってに すすむ）。
3. ✂️ **みじかく！** を おすと、ブルくんが しぶしぶ ひとことで まとめる。
4. さいごに **おぼえてるかな？クイズ**（3たく）。せいかいで **まめちしきカード** が もらえる。
5. おわると「あっ、そういえば！」と べつの おはなしに **だっせん** しようとする
   （きく！ で つぎの おはなしへ。はなしが おわらない）。

## ひきだし（4わ ずつ、ぜんぶで 40わ）

| ひきだし | おはなし |
| --- | --- |
| 🚇 ブルーライン | ブルーラインの ひみつ／トンネルの ほりかた／ちかてつなのに おそと／かいそく |
| 🚃 でんしゃ | うごく しくみ（パンタグラフ・だいさんきじょう）／ガタンゴトン／しんかんせん／ふみきり |
| 🪐 うちゅう | たいよう／つきの かたち／わくせい／うちゅうステーション |
| 🦒 いきもの | チーター／キリン／ペンギン／もぐら |
| 💪 からだ | しんぞう／ほね／みみ／は |
| 🌈 てんき | にじ／くも／かみなり／きせつ |
| 🏯 むかし | きょうりゅう／よこはまと てつどうの はじまり／ピラミッド／おかね |
| 🔢 かず・かたち | ゼロ／いちばん おおきい かず／カレンダー／まると さんかく |
| 🍙 たべもの | おこめ／パン／たまご／なっとう |
| 🌏 せかい | エベレスト／ちきゅう／せかいの こんにちは／いちばん ながい かわ |

- 🃏 **カードずかん**: あつめた カードを みる。タップで もういちど きける。
- 🔊 おと（効果音 と よみあげ）の オン/オフ。
- ほぞん（きいた おはなし・カード・きいた ぶんの かず）は localStorage（キー `buru-nagabanashi-v1`）。

## おはなしを ふやす

`index.html` の `STORIES` に 1こ たす。
`{ id, d: ひきだし, e: えもじ, t: だいめい, n: だっせん先の id, l: [ぶん...], s: まとめ, q: [しつもん, [せいかい, はずれ, はずれ]] }`
（`q` の 1ばんめが せいかい。ひょうじは シャッフル される）
