# ドカーン ブロックくずし 🧱

はでな ブロックくずし。年長〜小学生むけ。外部ライブラリ・CDN なし、描画は Canvas（ブロック・ボスは ぜんぶ コードで かく）。
音は WebAudio の 合成音だけ（効果音 と BGM、どうじ発音 14こ まで、オン/オフ あり）。

公開URL: https://kisi1554.github.io/Pages/block-kuzushi/

## あそびかた

- パドルの したの「ゆびの ばしょ」を よこに なぞる → パドルが ゆびの すこし うえで ついてくる。タップで ボール はっしゃ
- パドルの はし に あてるほど ななめに はねる（さいだい 62°）。ボールは だんだん はやく なる（じょうげん あり）
- コンボ: つづけて くずすと 5こ ごとに とくてん ばいりつ アップ（×9 まで）、がめんに「×5！」。カン・コン の おとも あがる

| ブロック | もじ | とくちょう |
| --- | --- | --- |
| ふつう | 1〜7 | 1かいで こわれる |
| かたい | H / X | 2かい / 3かい。ひびが はいる |
| ばくだん | B | まわり 8マスを まきこむ → れんさ |
| こおり | I | はねかえりが よわく、めんに そって すべる |
| うごく | M | よこに いったり きたり |
| かべ | # | こわれない |
| アイテム いり | m w l f s c u ? | こわすと アイテムが おちてくる |

アイテム: マルチボール（×3、とるたび さらに ぶんれつ、さいだい 30こ）・ワイド・レーザー（タップで れんしゃ）・
ファイア（つらぬく）・スロー・キャッチ（くっつけて ねらう）・+1 ライフ

ボス（10・20・30・40）: よこに うごく かいじゅう。**くち（したがわ の まんなか）が じゃくてん**。
ときどき たまを おとす（パドルに あたると すこし みじかく なるだけ。だんだん もどる）。

ライフ 3。やさしい モード: ボールが ゆっくり・パドルが ながい・ボスが よわい・したに 1かいだけ まもる バー。

## あんぜん

- がめん ぜんたいの てんめつ は しない。ボスの ひかりは ボスだけ・0.34びょう に 1かい まで（1びょう 3かい いか）
- がめんの ゆれ は せってい で オフに できる
