# てつどう ちずちょう

実際に行った駅を、関東の鉄道地図の上で塗りつぶしていく「のりつぶし地図帳」です。
子ども向け（ひらがな中心・ふりがな付き）。

## あそびかた

`index.html` をブラウザで開くだけで使えます（オフラインOK）。

- **ちず** … 本物の地図（緯度経度どおり）に、関東の駅 1,970・路線 156 を描いています。
  ピンチ・ホイールで拡大、ドラッグで移動。駅の丸をタップ →「🎉 いった！」で赤く塗れます。
  となり合う2駅をどちらも塗ると、そのあいだの線路が路線の色で太く塗られます。
- **ろせん** … しんかんせん / JR / ちかてつ / してつ / そのほか から路線をえらぶと、駅が路線図のように並びます。
  丸をタップで1駅ずつ、「✏️ まとめて ぬる」で「のった駅 → おりた駅」の2回タップで、あいだの駅をまとめて塗れます。
- **さがす** … ひらがな（カタカナ・漢字も可）で駅名を検索。
- **いまここ** … 位置情報から近い駅を6つ出します。その場で塗れます（位置情報は端末の中だけで使います）。
- **きろく** … 塗った駅の数、県ごとの割合、路線の全駅制覇メダル 🏅、駅数メダル 🎖️、最近行った駅。
  記録のバックアップ（ファイルに保存 / 読みこみ）もここから。

ヘッダーの「あ / 漢」で地図の駅名をひらがな・漢字で切りかえ、🔊 で音のオン/オフ。

## データ

- 鉄道: 国土数値情報 鉄道データ（N02-24、国土交通省）
- 県境: 国土数値情報 行政区域 由来の [dataofjapan/land](https://github.com/dataofjapan/land)
- 駅名の読み: Wikidata（CC0）＋ 手入力の補い

`data.js` は `tools/tetsudo-chizucho/build.py` で作っています（手で直さない）。
路線名は国土数値情報の正式な線名なので、たとえば「山手線」は品川〜新宿〜田端の区間だけで、
東京駅側は「東海道線」「東北線」に入っています。

## ほぞん

localStorage（`tetsudo-chizucho-v1`）に、行った駅を「駅名・位置・日付」で保存します。
データを作りなおしても、駅名と位置で照らし合わせて記録を引きつぎます。
