# がんじんの ふなたび すごろく ⛵

**とうの くにから にほんの ならを めざす すごろく。5かい「ふりだし」に もどっても、6かいめで かならず つく。**
10本シリーズ「じだい たんけん」の なら じだい編（5才〜）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

## あそびかた

### ⛵ ふなたび すごろく（メイン・1回 2〜3分）

1. はじめに がんじんの おはなし（「だれも いかないなら、わたしが いこう」）。
2. サイコロを タップで ふる。ようしゅう（スタート）→ みなと → うみ → さつま → だざいふ → なにわ → なら（16マス）。
3. 1〜5かいめは かならず「⚡ たいへん マス」に とまって ふりだしへ（「また ふりだし〜！」で ふねが くるっと ずっこける）。
   たいへんの なかみは 史実どおり: 役人に止められる／嵐で船がこわれる／また止められる／弟子が泣いて止める／大嵐で南の島へ。
4. もどるたびに なかまが はげまし、ふねが パワーアップ（ほが おおきく → じょうぶに → にもつと はた → なかまが ふえる）。
5. 5かいめの あと、がんじんの 目が 見えなく なった ことに やさしく ふれ、けんとうしの ふねへ。
   6かいめは **きんの サイコロ**（4・5・6 しか でない）。⚡ マスも「へっちゃら！」。
6. にほんに つくと あるいて ならへ。ならの しかが ついてきて、🍘 せんべいを あげると おじぎ。

サイコロの目は ふつうに 見えるが、1〜5かいめは その回の「たいへん マス」に ぴったり とまるように えらんでいる
（ほかの ⚡ マスは とびこえる）。

### 🏯 ゴール

へいじょうきょう → だいぶつさまが ずずーんと おでむかえ → てのひらに のって「ひろーい！」（ズーム）→
しかが ぺこり・がんじんが 戒を さずけた はなし → ゴール。

### ✨ だいぶつ みがき（ミニゲーム）

ほこりで まっくろの だいぶつを ゆびで こすって みがく（canvas の destination-out）。85% みがくと きんいろに ぴかぴか。
1回 ならに つくと タイトルからも あそべる。

## れきしの あつかい

- 鑑真（688〜763年）。742年に栄叡・普照の招きに応じ、743年から5回失敗、753年（6回目）に遣唐使の第二船（大伴古麻呂）で薩摩へ、754年に平城京へ。
  東大寺大仏殿の前で聖武上皇らに戒を授け、759年に唐招提寺を開く。
- 5回の失敗理由は『唐大和上東征伝』にそって「嵐」だけでなく「止められた」も入れた（保護者むけの小さい字に年つき）。
- 「誰も行かないなら私が行く」は 東征伝に伝わる言葉として。失明は「〜と伝わる（程度には諸説）」。
- 大仏: 743年 造立の詔、752年 開眼供養。手のひら約2.6m・高さ約15m（東大寺の公表値）。今の頭部などは江戸時代の再建。
  **手のひらに乗るのは演出**（画面にも「ほんとうは のれないよ」）。
- 奈良の鹿は春日大社の言い伝え（白鹿に乗って来た神）として。鹿せんべいは江戸時代ごろから と言われる ＝ 演出と明記。
- 正倉院（756年〜）、平城京（710年遷都・長安にならう・人口は推定）。年号は 保護者むけの 小さい字だけ。

## つくり

- `index.html` 1枚。え は インライン SVG、音は WebAudio の 合成音（右上の 🔊 で オン/オフ）。
- 保存は localStorage `nara-ganjin-sugoroku-v1`（音・カード・ゴール回数・みがき回数）。
- 画面の 下に シリーズ共通の「じだいの ものさし」（なら が 光る）。おわりに 次の「へいあん じだい」を 1文で 予告。
- `?fast` を つけると アニメが はやおくり（Playwright での かくにん用）。`window.__nara` に 状態。
