## あそびかた

1. よこから みた ステージ。🚩スタートに ボール、ゴールに 🔔ベル。
2. 下の **どうぐばこ** で ぶひんを えらんで、ステージを タップして おく。
   - おいた ぶひんは **ドラッグで 移動**、**タップで 回転**（15° きざみ。シーソーは 0°/15°/−15°、バケツは 左右 反転）
   - **ゴミばこ（🗑️）へ ドラッグで 削除**（かずが もどる）。🧹 どける で ぜんぶ どける
3. **▶ スタート** で 物理シミュレーション。ベルに なにかが あたると チーン＋紙ふぶき で クリア。
   **⏹ もどす** で おいた 配置に もどる（何回でも ためせる）。
4. グレーの ぶひん（ねじの しるし）は 動かせない。つかえる ぶひんの かずは ステージごとに きまっている。

| モード | ないよう |
| --- | --- |
| ステージ 1〜5 | たりない ぶひんを 1つ おく（いた・ばね・かべ・ドミノ・ファン） |
| ステージ 6〜10 | 2〜3こ おく（いた2まい、ばね＋かべ、ドミノ3まい、ファン＋かべ、いた＋ばね） |
| ステージ 11〜15 | シーソー・ドミノ・バケツ を くみあわせる（さいごは ドミノ→バケツ→とびら→シーソー の だいそうち） |
| じゆうに つくる | ぶひん 無制限。5スロットに ほぞん（localStorage に JSON、プレビューつき） |

クリアすると つぎの ステージが ひらく。進捗・音・スロットは localStorage `korokoro-souchi-2-v1`（読み書きは try/catch）。

## 物理エンジン（`physics.js`・自作）

- 剛体は **円** と **回転する長方形**（複数を くみあわせて 1つの からだにも できる。シーソーの ふち、バケツの U字）。
- 衝突: 円-円、円-長方形（線分に太さ）、長方形-長方形（SAT ＋ 参照面での クリッピングで 最大2点）。
- **固定タイムステップ 1/120秒**。速度インパルス（反発係数・摩擦、10回くりかえし）→ 位置補正（3回）。
- **ねむり**: とまった ものは 計算しない。うごいている ものに ふれると おきて、おきた ものが さらに となりを おこす
  （シーソーに のった ボールが じゃまを しないように）。
- `Math.random` を つかわないので **決定的**（同じ 配置なら 毎回 同じ 結果）。
