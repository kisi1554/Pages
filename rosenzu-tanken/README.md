# 5ろせん ろせんずたんけん

路線図が すきな 子（5歳）むけの、駅を おぼえる アプリです。
ブルーライン・京浜東北線（大宮〜大船）・山手線・東横線・京急線（品川〜浦賀の本線）の
5路線 156駅が、1枚の 路線図に つながって います。

`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリなし）。

## あそびかた

- **🗺 たんけん**: 駅を タップすると、よみ・駅番号・のりかえ・となりの駅が 出て、音声でも 読みます。
  タップした駅は「みつけた駅」として 数えます（🚉 の かず）。
- **🎮 あそぶ**: 6種類、各5問。さいしょの 答えで 正解なら ⭐1つ。まちがえても やり直せます。

| あそび | すること |
| --- | --- |
| 📖 よみかた | 漢字の 駅名の よみを 3つから えらぶ |
| 🔍 えきさがし | よみ（音声つき）を きいて、路線図の 駅を タップ |
| ➡️ つぎの えき | 「A → B → ？」の つぎの駅を えらぶ |
| 🔢 いくつ すすむ？ | 2つの駅の あいだを かぞえる |
| 🔁 のりかえ | 2路線を のりつぐ ときの のりかえ駅を えらぶ |
| 🎨 なにせん？ | 駅が どの路線か えらぶ |

- 上の ボタンで 路線を しぼれます（ぜんぶ＋5路線）。
- 路線図は ゆび1本で うごかし、2本（または ＋－ボタン）で 大きさを かえます。
- 🔊 ボタンで 効果音と 読み上げを まとめて オン/オフ できます。
- ⭐・みつけた駅・音の 設定は 端末に 保存します（localStorage の `ao-rosenzu`）。

## データの きまり

- のりかえ駅は 1つの駅として えがきます（横浜は 4路線）。
- 弘明寺は ブルーラインと 京急線で べつの駅です（のりかえ駅に しません）。
  クイズでも、答えが 2つに ならないよう 選択肢から はずして います。
- 京急線の 色は、京浜東北線の 水色と 見分けるため 赤系に して います。
- 「のりかえ」は、いちばん 近い のりかえ駅が 1つに 決まる 組み合わせだけ 出します。
