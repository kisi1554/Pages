# ぴょこっと にっぽん リズム 🎵

**おんがくに のって、とどうふけんの「なまえ」と「ばしょ」を おぼえる リズム ちず アプリ。**
年長〜小学校低学年、都道府県が はじめての 子むけ。県の 形・県庁所在地・名産 は あつかわず、
いちばん さいしょの「名前 と 位置」だけに しぼっています。

`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし、音声ファイル なし）。

公開URL: https://kisi1554.github.io/Pages/pyokotto-nippon/

---

## あそびかた（1ステージ ＝ 1地方）

地方ごとに ズームした 地図で あそびます（ほっかいどう・とうほく／かんとう／ちゅうぶ／きんき／
ちゅうごく／しこく／きゅうしゅう・おきなわ）。BGM は とぎれず、4つの あそびかたが 小節の あたまで つながります。

| | あそびかた | すること |
| --- | --- | --- |
| 1 | 👂 **きく** | 拍に あわせて 県が 光り、ぴょこが とびだして「あおもり！」。地方の 県を 2しゅう。2拍で 1けん（1拍目で 光って よぶ、2拍目で ぴょこが はねる） |
| 2 | 👆 **まねっこ** | 名前が よばれて 光っている 県を タップ。まちがえても ヒントが つよく なって まってくれる |
| 3 | 🥁 **リズム テスト** | 名前だけ よばれる（光らない）。2拍後の「こたえる拍」に あわせて タップ → **ぴったり！／いいね！／おしい！**。4拍 たっても タップ できないか、まちがえたら、その県が やさしく 光って **もう1回 同じ県** が でる（2回 まちがえると 3回目は ヒントつき） |
| 4 | 🔤 **ぎゃく** | 県が 光る → 名前を 3つの ボタン（ひらがな）から えらぶ。よめる子むけ（せっていで オフ／とちゅうで とばせる） |

- 地方 クリアで **ぴょこたちの ダンス**。
- 7地方 ぜんぶ クリアで **ぜんこく メドレー**（47けんを 北から南へ 1きょくで。地方が かわると
  カメラが うごいて、メロディと 楽器が その地方の ものに かわる）。「きく」と「タップ」の 2つ。
- テンポは 3だんかい（ゆっくり 84／ふつう 100／はやい 118 BPM）。リズムテストで 1回目の 正解が 85% 以上、
  タイミングも よければ、その地方は つぎから **4 BPM はやく**（最大 +12。せっていで オフ にできる）。

## キャラ「ぴょこ」

47けん それぞれ、**県の 形 そのものが からだ** の オリジナル キャラ（「あおもり ぴょこ」など）。
`chara.js` が その県で いちばん 大きな 島の 形に、目・口・ほっぺ・手足を コードで 描きます。

- かおは 形の なかで ふちから いちばん とおい 点（polylabel）に おくので、どんな 形でも からだに おさまる。
- 手足は かおから 外へ のばした 線が ふちに ぶつかる ところから 生える。
- 表情は おぼえ度で かわる: ★0 ねむい → ★1 ふつう → ★2 にこにこ → ★3 げんき（キラキラ）。
  よばれた とき・正解した ときは バンザイして はねる。
- 実在の ご当地キャラ・ゆるキャラは つかっていません。

## 地図と 当たり判定

- 形は [日本地理たんけん](../nihon-chiri-tanken/) の `map-data.js` を そのまま コピー（同じ 地図で 見た目を そろえる）。
- 地方ごとの 表示範囲は `data.js` の `view`。となりの 地方は うすい 色で、さわれない。
- **沖縄** は 九州・沖縄の 画面で 南西に 点線の 枠を つくって その中に 表示（「ほんとうは みなみの うみ」）。
  右上の **小さな 案内図** では 沖縄を ほんとうの 位置に 描いて、いま あそんでいる 地方を 色で しめす。
- **当たり判定**（`chara.js` の `Geo.hitTest`）
  1. 形の 中、または 中心の まわり **44px 角**（東京・神奈川・大阪・京都・奈良・香川・佐賀・滋賀・埼玉 は **56px 角**）に 入る 県を あつめる
  2. その中で **中心に いちばん 近い 県** を えらぶ（となりと かさなる ところは 中心が 近い ほう）
  3. どこにも 入らなければ、ふちから 12px 以内の いちばん 近い 県（海を ちょっと タップ しても ひろう）
  - 「中心」は 形の 内がわの 点（polylabel）なので、かならず その県の 上に ある。
  - 沖縄の 枠の 外に はみでる 島（先島 など）は さわれない。

## 曲と 音

- BGM は **WebAudio で 合成する オリジナル の 4小節 ループ**。地方ごとに メロディ・キー・楽器・ドラムが ちがう
  （ゆきの ふえ／ぴこぴこ まち／やまの マーチ／ことの おまつり／もりの マリンバ／みかんの くちぶえ／みなみの しまうた）。
  ペンタトニック（九州・沖縄は りゅうきゅう音階）で 明るく。楽譜は `data.js` に 文字で 書いてある。
- 拍は **AudioContext の 時計** で きざむ 先読みスケジューラ（`audio.js`）。画面の へんかは その時刻に rAF で おこし、
  タップの 判定も 同じ 時計（出力の おくれ `outputLatency` を ひいた 時刻）で くらべる。setTimeout の ずれは つかわない。
- 県名の こえは `speechSynthesis`（日本語の 声）。**ひらがな で わたす**（「おおいた」「おかやま」など よみまちがい しない）。
  しゃべりだすまでの おくれを はかって、拍より その ぶん まえに 予約する。
  日本語の 声が ない 端末では 県名を **大きな 文字** で 出す だけに する。
- 音量は **おんがく・こえ・こうかおん の 3つ別々** の スライダー、**まとめて ミュート**（🔊 ボタン）も。

## きろく（localStorage `pyokotto-nippon-v1`）

- 県ごとの おぼえ度 ★0〜3:
  ★1 … まねっこ で タップ できた／★2・★3 … リズムテスト・ぎゃく で 1回目に 正解（テストで まちがえると 1つ もどる。★1 より 下がらない）
- まちがいが 多い 県は、つぎの リズムテストで 多めに 出る（最大 3けん 追加）。
- **ずかん**: 47ぴょこ。★3 は 金色の ふち。タップで 名前を よんで くれる。
- **おうちの かたへ**: 地方ごとの おぼえ度、まだの 県（★2未満）の 一覧、きろくの 消去。
- **全47県 無料。課金・広告 なし。**

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | 画面（タイトル・地方えらび・あそぶ・クリア・ずかん・おうちの かたへ・せってい） |
| `style.css` | 見た目（縦もち スマホ／横もち タブレット） |
| `map-data.js` | 47都道府県の 形（`nihon-chiri-tanken/map-data.js` の コピー。直接 編集しない） |
| `data.js` | 地方・県名の よみ・曲の 楽譜・テンポ |
| `audio.js` | 拍の スケジューラ・楽器・効果音・こえ |
| `chara.js` | 形の 計算（polylabel・当たり判定）と ぴょこ の 描画 |
| `map.js` | 地図の 表示・カメラ・ぴょこが とびだす アニメ・タップ |
| `game.js` | 4つの あそびかた・メドレー・きろく・ずかん・せってい |

テスト用に `?bpm=200` のように つけると テンポを 固定できます。`window.__pyoko` に 状態と 県の 中心座標を 返す
関数が あり、Playwright で 47県の 中心タップ判定と 1地方の 自動クリアを 確認しています。

## 地図データの 出典

`map-data.js` は [dataofjapan/land](https://github.com/dataofjapan/land)（国土交通省 国土数値情報 の
行政区域データ 由来）の 都道府県境界を、`tools/japan-map/generate_map.py` で SVG パスに 変換した もの
（日本地理たんけん と 同じ。メルカトル図法、小さな 離島は 間引き、沖縄は インセット）。

「地図エイリアン」のような リズムで 県名を 聞いて タップする しくみを 参考に していますが、
名前・キャラ・曲・画面・言いまわしは すべて オリジナルです。
