# えき の ホームがかり 🧑‍✈️

えき の ホーム で はたらく **えきいん さん** に なる ゲーム（年中〜小学4年）。
でんしゃ が つく → ドア が あく → **おりる ひと が さき** → のる ひと → **あんぜん を たしかめて** から「しゅっぱつ OK！」の あいず。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。えき・でんしゃ は CSS で かいた オリジナル）。

- まなび: でんしゃ の マナー と あんぜん、まわり を よく みる こと、こまって いる ひと を たすける こと
- ほぞん: localStorage `home-gakari-v1`（さいこう の ★、おと の せってい）

## 1ぽん の でんしゃ の ながれ

| ばめん | そうさ |
| --- | --- |
| ① はいって くる | ❗ の ひと（きいろい せん の そと）を タップ → うちがわ へ。みんな さがる まで でんしゃ は はいって こない |
| ② ドア が あく | おりる ひと が さき。ドア の まえ を ふさぐ ひと を タップ →「わき へ どうぞ」。ふさがれた ドア から は おりられない |
| ③ のる | 🧑‍🦽 くるまいす の ひと → 🛝 スロープ を その ドア へ ドラッグ（タップ で えらんで ドア を タップ でも OK）。👵👩‍🍼 は ゆっくり まつ |
| ④ たしかめる | ドア に はさまった 🌂👜 を タップ。🏃 かけこみ の ひと を タップ →「つぎ の でんしゃ を どうぞ」（つぎ の でんしゃ に のる）。👉 ゆびさし かくにん（ドア → しんごう → とけい） |
| ⑤ しゅっぱつ | 📣 あいず を ながおし（0.8びょう）→ ピーッ → はっしゃ メロディ → ドア が しまる → でんしゃ が でる |

あぶない まま あいず を ながおし すると「まって！ まだ ○○ が いるよ」と とまる（じこ は おきない）。

## ルール

- **1にち の しごと** = でんしゃ 9ほん: 🌅 あさ（ラッシュ・ドア の まえ に ひと）3 → ☀️ ひる（すいて いる・くるまいす・まいご・おとしもの）3 → ☔ ゆうがた（あめ・かさ が はさまる）3。
- **れんしゅう** = すきな じかん の でんしゃ 1ぽん（ひる は くるまいす・まいご・おとしもの が かならず でる）。
- ★（3つ）:
  - あんぜん: 「まって！」に なった でんしゃ が 1ぽん まで（れんしゅう は 0ぽん）
  - ていじ: おくれ（めやす の じかん より ながく かかった ぶん）が ぜんぶ で 4びょう×ほんすう いない
  - しんせつ: くるまいす・まいご・おとしもの の 8わり いじょう を たすけた
- めやす の じかん は おりる・のる ひと の かず、ゆっくり な ひと、くるまいす、はさまり、かけこみ で のびる。
- 📖 えき の しごと: ホームがかり・ゆびさし かくにん・きいろい せん・おりる ひと が さき・かけこみ・かいさつ・アナウンス・おとしもの・ほあん。

## しらべた こと（ないよう の ねらい）

- かけこみ じょうしゃ は ケガ や じこ の もと（[近鉄 マナー](https://www.kintetsu.co.jp/gyoumu/manner/)）。
  「おりる ひと を またず に のりこむ」「かけこみ」は 日本民営鉄道協会 の 迷惑行為 ちょうさ でも 上位（[乗りものニュース](https://trafficnews.jp/post/125126)）。
- ゆびさし かくにん（指差喚呼・指差呼称）: たいしょう を みて、ゆびさして、こえ に だして たしかめる。
  もと は 国鉄 の 運転士 の しんごう かくにん。鉄道総研 の 1994年 の 実験 では ゆびさし＋こえ で 押し間違い が 約 1/6 に
  （[厚生労働省 職場のあんぜんサイト](https://anzeninfo.mhlw.go.jp/yougo/yougo72_1.html)）。
- きいろい せん は 視覚障害者誘導用ブロック（てんじ ブロック）。
- **あいず の やりかた・ゆびさし の じゅんばん は「この ゲーム の やりかた」**。ほんもの は 鉄道会社 ごと に ちがう（あそびかた・ずかん に かいて ある）。
- えき（どんぐり えき）・でんしゃ（どんぐり せん）・はっしゃ メロディ は オリジナル。実在 の えき の メロディ は つかって いない。

## おと

WebAudio の 合成音 だけ: はっしゃ メロディ（オリジナル）、ドア の ぷしゅー、あいず の ピーッ、でんしゃ の はしる おと、せっきん チャイム。
アナウンス（「まもなく でんしゃ が まいります…」など）は ブラウザ の よみあげ。🔊 こうかおん・🗣️ よみあげ を それぞれ オン/オフ。

node home-gakari/test.js [シード の かず（きほん 40）]   # しくみ

  はし に ひと が いる と でんしゃ が こない、おりる ひと が さき、ゆびさし の じゅんばん、スロープ、
  1にち 9ほん、★ の けいさん（ていねい ★3・うっかり／しんせつ なし／おそい で それぞれ ★ が へる）、シード、ふりがな。
