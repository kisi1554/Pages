# たしざんとっくん！（5歳児向け たし算ゲーム）

「５たす３」「６たす３」だけに特化した、5歳の子ども向けの楽しいたし算特訓ゲームです。

## あそびかた

1. `index.html` をブラウザで開くだけで遊べます（インストール不要・オフラインOK）。
2. 「はじめる」を押すとスタート。
3. りんご🍎とみかん🍊（またはぶどう🍇とレモン🍋）の数を見ながら、答えの数字ボタンをタップ。
4. わからないときは「👉 いっしょに かぞえよう」ボタンで、ひとつずつ数えて答えを確認できます。
5. 正解すると星⭐がたまり、紙吹雪が舞います。まちがえても何度でも挑戦できます。
6. 全10問（5+3と6+3をそれぞれ5回ずつ、ランダムな順番）を終えるとクリア画面が出ます。

## 工夫したポイント（5歳児向け設計）

- 文字が読めなくても遊べるよう、音声読み上げ（Web Speech API）とかわいい効果音付き。
- 数字の暗記だけでなく、絵（果物）を実際に数えることで「たし算の意味」を理解できるようにしています。
- ボタンは大きく、間違えてもペナルティなしで安心して挑戦できます。
- 追加ファイル・ネット接続不要（単一HTMLファイルで完結）。

## 動作環境

モダンブラウザ（Chrome, Safari, Edge など）で動作します。音声読み上げは対応ブラウザのみ有効です（非対応でも他の機能は問題なく遊べます）。
