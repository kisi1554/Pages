# でんしゃ どこだ？ 🔍

ひろい まち の えほん の なか に かくれた **いろいろ な てつどう** を さがす さがしもの ゲーム。
つうきん でんしゃ・しんかんせん・ろめん でんしゃ・モノレール・ケーブルカー・SL・かもつ れっしゃ …
みつけたら ずかん に ペタッ。ゆび で ひろげて こまかい ところ まで のぞける。年少〜小学2年。

公開URL: https://kisi1554.github.io/Pages/densha-dokoda/

## あそびかた

1. まち を えらぶ（6まい）。がめん いっぱい の よこ に ながい え を **ドラッグ で うごかす**・**2ほん ゆび で ひろげる**（＋－ ボタン・マウス ホイール でも）。
2. した の「さがす もの」カード 5まい（シルエット＋なまえ）。え の なか で みつけて タップ → きらっ と ひかって カード に ✅、なまえ と ひとこと を よみあげ。
3. **カード を ながおし** → だいたい の ばしょ が ぼんやり ひかる（3びょう）。カード を タップ すると なまえ を よみあげ。
4. 5つ ぜんぶ みつけたら、まち の でんしゃ が いっせい に はしりだす（ファンファーレ・ふみきり・きてき）。
5. **おまけ さがし**: ねて いる ねこ・とけい に ぶらさがる さる・コンテナ に はいった ぞう・まちがえて のった うし など、へんな もの も かくれて いる。
6. 「もういちど」で ばしょ が いれかわる（おなじ まち でも あそべる）。

## まち と さがす もの（30しゅるい）

| まち | さがす もの | おまけ |
| --- | --- | --- |
| 🏙️ おおきな えき の まち | しんかんせん・つうきん でんしゃ・かもつ れっしゃ・マルタイ・ちかてつ の いりぐち | ねこ・さる |
| 🏞️ やま の まち | ケーブルカー・トンネル・アプト しき・ロープウェイ・てっきょう | くま |
| 🌊 みなと の まち | モノレール・しんこうつう システム・コンテナ・いれかえ きかんしゃ・フェリー（ひっかけ） | ぞう |
| 🏯 むかし の まち | トロッコ・SL・じんりきしゃ（ひっかけ）・ろめん でんしゃ・ばしゃ てつどう | かえる |
| ❄️ ゆき の まち（よる） | ラッセル しゃ・ロータリー しゃ・ねだい とっきゅう・ディーゼル カー・ストーブ れっしゃ | ペンギン・ゆきだるま |
| 🎡 ゆうえんち | ジェットコースター（でんしゃ？）・かんらんしゃ（ひっかけ）・こども でんしゃ・ミニ SL・タイヤ の きしゃ（ひっかけ） | うし |

ひっかけ（でんしゃ では ない もの）は みつけると「でんしゃ じゃ ないよ」と おしえる。
せつめい は しゅるい の とくちょう を ただしく（ろめん でんしゃ＝みち の うえ、モノレール＝1ぽん の レール、
ケーブルカー＝ケーブル で ひっぱる、アプト しき＝はぐるま で きゅう な さか、ロープウェイ＝ほうりつ では てつどう の なかま（さくどう））。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `art.js` | え（ぜんぶ オリジナル の SVG）。さがす もの・おまけ・まち の かざり |
| `scenes.js` | まち ごと の はいけい・かざり・さがす もの の ばしょ の こうほ（`spots`）・ずかん の せつめい。まいかい こうほ から 1つ えらぶ |
| `app.js` | パン・ピンチ ズーム（1〜3ばい、さかい で とまる）、タップ はんてい（あたり は え より 18 おおきめ）、ヒント、ごほうび、ずかん |
| `audio.js` | ぴろりん・きてき・ベル・ふね の きてき・ふみきり・まち の ざわざわ（WebAudio の ごうせい）、よみあげ |

- ピンチ ズーム は え の なか だけ（え に `touch-action: none`、ブラウザ は ズーム しない）。ダブルタップ は タップ 2かい として あつかう。
- おと・こえ（よみあげ）は それぞれ オン/オフ できる。
- ほぞん: localStorage `densha-dokoda-v1`（`found` ずかん・`omake` おまけ・`clears` まち ごと の クリア かいすう・おと/こえ の せってい）。
