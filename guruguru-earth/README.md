# ぐるぐるアース

たいようと ちきゅうを 立体（3D）で まわして、**ひると よるが どうして うまれるのか**を
あそびながら まなべる、こども向けの ゲームです。

ブラウザだけで うごきます（インストール不要・外部ライブラリなし）。

## あそびかた

| そうさ | できること |
| --- | --- |
| **くにを タップ** | **その国が 光って、なまえを 読みあげる。いまの じかんも わかる** |
| ちきゅうを ドラッグ | じてん（よこ＝まわす／たて＝みる かくど） |
| なにもない ところを ドラッグ | カメラを まわす |
| ホイール / 2ほんゆびで ピンチ | ズーム |
| ← → キー | ちきゅうを まわす |
| 「アップ」「ぜんたい」 | ちきゅうの アップ ⇄ たいようも みえる ぜんたい |
| 「はる／なつ／あき／ふゆ」 | ちきゅうが たいようの まわりを いどう（きせつ） |

- **ミッション（全14ステップ／2しょう）**
  - 第1しょう「ひるとよる」… あさ・おひる・よるを つくる → クイズ → 時差 → きせつ
  - 第2しょう「せかいの国」… にほんを さがす → あさの国・よるの国を さがす → クイズ → 6か国あつめる
  - クリアすると ⭐ が たまり、さいごに「ひるよる はかせ」に なれます。
- **くにの ずかん** … タップした国は ずかんに たまります（77か国）。
  5・10・20・40・60・77 こで ⭐ が 1つずつ もらえます。ドックの 📗 でひらけます。
- **じゆうモード** … すきなだけ まわして たんけん。⭐ と すすみぐあいは ブラウザに ほぞんされます。
- **触れる地球儀** … 国境つきの世界地図。国をタップすると光って、名前を読みあげ、その国の
  いまの時刻（昼か夜か）を教えます。海岸線ぎりぎりの場所や太い指のために、
  少し外れても1.5°以内なら いちばん近い国を選びます。
- **🛰️ ほんものの ちきゅう** … 右上の ボタンで、えいせいが とった ほんものの しゃしんを みられます。
  - **ひまわり（いま）** … 気象衛星ひまわり9号が 10ぷんごとに とる 地球（やく40ぷん まえの もの）。
    「にほん」の しるし つき。▶ で 24じかんぶんを 1じかん おきに うごかすと、ひると よるの さかいめが
    ちきゅうの うえを うごいていくのが みえます。とまっている ときは こまかい がぞう（1100×1100）に きりかわります。
  - **NASA（まんまる）** … 150まんキロ さきの DSCOVR（EPIC カメラ）が とった、ひるがわ まるごとの 地球。
    ▶ で 1にちぶんの じてんが みえます。
  - **ISS（ライブ）** … 国際宇宙ステーションから NASA が流している ライブえいぞう（YouTube）と、
    いま ISS が どこを とんでいるかの せかいちず（よるの がわは くらく、すぎた みち／これからの みち つき）。
    「いま ISSは ○○の うえ」「ひるの がわ／よるの がわ」「たかさ・はやさ」を 5びょうごとに こうしん。
  - インターネットが ないと みられません（そのときは メッセージが でます）。
- **まる窓（ちじょうビュー）** … えらんだ まちの そら。たいようの みちすじ（てんせん）、
  ひがし／にし、まちの あかり、こどもの ようすが かわります。

## しくみ（大人向けメモ）

- **ほんものの ちきゅう（`real.js`）** … ひまわりは NICT の `himawari8-dl.nict.go.jp/himawari8/img/D531106/{1d,2d}/550/…png`
  を `<img>` で直接よむ（CORS なし）。未公開の時刻も「No Image」画像が 200 で返り判別できないため、
  現在時刻の 35分前を 10分単位で切り捨てた時刻を最新とし、全球観測のない 02:40 / 14:40 UTC は 10分ずらす。
  「にほん」の位置は静止衛星（東経140.7°）からの透視投影で計算。EPIC は `epic.gsfc.nasa.gov/api/natural`
  （CORS あり）から最新日の一覧をとる。
  ISS は `api.wheretheiss.at`（CORS あり）で現在位置を5秒ごと、軌道（前45分〜後50分・5分おき）を5分ごとに取得。
  真下の国は `countryAt()`、名前なしの国は大陸名、海は緯度経度のおおまかな範囲で判定。
  ライブ映像の YouTube ID は `real.js` の `ISS_VIDEO`（NASA が配信を立て直して ID が変わったら差し替える）。

- 3D は **素の WebGL**（ライブラリなし）。地球は緯度経度テクスチャを `<canvas>` で
  その場で生成（海・バイオーム帯・国境線・夜の街あかり）。海岸線と国境は
  Natural Earth 1:110m（`countries.js`）。選んだ国のハイライトだけ別テクスチャ（1024×512）を
  タップのたびに1枚更新。フラグメントシェーダで
  昼夜の境（ターミネータ）、朝焼け・夕焼けの帯、海の反射、大気の縁光を計算。
- 太陽は fbm ノイズによる粒状表面＋加算合成のグロー、光線、公転軌道リング。
- **時刻・太陽高度は実際の球面三角法で計算**しています。
  - 地軸の傾き 23.4°、地軸は公転面に対して固定 → 季節で昼の長さが変わる
  - 地方時 = 12 + (経度 − 南中点の経度) / 15
  - 太陽高度 sin(h) = sin(緯度)sin(赤緯) + cos(緯度)cos(赤緯)cos(時角)
  - 検証済み: 東京の春分の南中高度 54.3°（= 90 − 35.7）、日の出は方位 90°（真東）で 6:01、
    ロンドンの夏の昼 16.4 時間・冬 7.6 時間、南半球（シドニー）は逆転
- 音は WebAudio の合成音のみ（音声ファイルなし）。「おと」ボタンで オフにできます。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | 画面の骨組みだけ |
| `style.css` | 見た目 |
| `data.js` | 海岸線・まち・きせつ・ミッションの定義（データ） |
| `world.js` | 3D（すうがく・テクスチャ生成・WebGL・カメラ・そうさ） |
| `sky.js` | まる窓の地上ビュー・音・クリア演出 |
| `missions.js` | ドックのUI・ミッションの進行・メインループ |
| `countries.js` | **自動生成**の国データ（国境線・国名・タップ判定用ポリゴン） |

外部ライブラリ・CDN は使っていません。`index.html` を開くだけで動きます。

### 国データの作りなおし

`countries.js` は手で編集せず、生成スクリプトを回します。

```bash
node tools/guruguru-earth/build-countries.mjs
```

もとデータは world-atlas の TopoJSON（Natural Earth 1:110m、パブリックドメイン）。
1/4度に量子化してポリライン符号化し、30KB ほどに収めています。
生成時に「まちの座標が正しい国に入るか」を16都市で検算します。

### 回帰テスト

```bash
node tools/guruguru-earth/verify.mjs
```

ヘッドレス Chromium で、天文計算・ミッションの通し・レイアウトのはみ出しを確認します
（グローバル導入の playwright を使います）。機能を足したら、ここに項目を足してください。
