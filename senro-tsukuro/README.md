# せんろ つくろう！（プラレールみたいに線路をつくるアプリ）

指でなぞるだけで青い線路がのび、電車が走りだします。メニューのボタン1つで、
**数千枚・数百メートル分（プラレール換算）の巨大コース**も自動でつくれます。

## あそびかた

| どうぐ | できること |
| --- | --- |
| 👆 みる | 指でスクロール。ポイントの ▶ をタップすると行き先が切りかわる。電車をタップすると とまる／はしる |
| ✏️ せんろ | なぞると線路ができる。まがり角は自動でカーブに、交わるとクロス、つなぐとポイントになる。タップで回転 |
| 🚃 でんしゃ | 6種類（しんかんせん3色・通勤電車2色・きかんしゃ）と長さ（1〜16両）を選んで線路をタップ |
| 🚉 えき / ⛰️ トンネル / 🚧 ふみきり | まっすぐの線路をタップ・なぞると変わる。駅では停車してチャイム、踏切は電車が近づくと閉まってカンカン |
| 🌳 き・いえ | 草のところに木や家をおく |
| 🧽 けす | なぞったところを消す。電車をタップすると電車を消す |

- 上のボタン：↩️ もどす（60回まで）／🔭 ぜんぶみる／🎥 おいかける（電車に追従）／速さ3段階／🔊 音オンオフ／🌏 メニュー
- 🌏 メニュー：「おおきい」「とても おおきい」「きょだい！」で、いまの線路の となりに 自動コースを生成
- 2本指でズーム・移動（PC はホイール、右ドラッグで移動）
- 線路のおわりには車止めが出て、電車はそこで折り返す
- 画面左上に線路の枚数と長さ（プラレールのまっすぐ1本 ≒ 21.6cm で換算）を表示

## しくみメモ

- 1マス＝線路1枚。各マスは「どの辺とどの辺をつなぐか」のパス（最大3本）を持つ。
  パスが辺を共有するとポイント、共有しない直線2本ならクロス。
- なぞった順にマスを並べ、前後のマスへの向きからまっすぐ／カーブを決める。
  既存の線路の「行き止まり側」に触れたらそのままつなぎ、つながっている線路なら分岐を足す。
- 電車は車両ごとに前後2つの台車がパス上を同じ距離だけ進む。ポイントでは先頭が選んだ道を
  後ろの台車が引き継ぐので、途中でポイントを切りかえても編成がちぎれない。
- 背景（線路）は視点が変わったときだけ描きなおし、電車は前面キャンバスに毎フレーム描く。
  ズームアウト時は簡略表示に切りかえるので、数千枚の線路でも動く。
- 進捗（線路・電車・視点・設定）は localStorage（`senro-tsukuro-v1`）に自動保存。
- 外部ライブラリなし・音は WebAudio の合成音のみ。
