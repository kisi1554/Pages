# ブルーライン みんなで のろう 🚇

はこの うえに おいた ブルーラインが、**湘南台 ⇄ あざみ野** を はしるのを みて たのしむ アプリ（ゲームでは ない）。
`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音 ＋ よみあげ）。

## おはなし

1. ブルーラインが まっすぐ ならんだ **はこの うえ** で まっている。とおくの おかで **ゾンビ** が おうえん、ホームで **にょこすけ** と **つくぼう** も おうえん。
2. えきで まっている ひとが みんな のって、しゅっぱつ しんこう！
3. つぎの えきが ちかづくと「あっ！ にょこくんが みえてきた！」→ にょこくんが「ぼくも のる！」と のる。つくぼうも とんで のってくる。
   **ゾンビは のらない**（とおくから おうえん）。
4. **よる** は でんしゃが ねむくて おそく なる → にょこくんが **おなら「ブー！」** で びゅーんと はやく する
   （じどうで でるし、💨 ボタンでも だせる）。
5. しゅうてんで みんな おりて「たのしかった〜！」。かえり（はんたい むき）にも のれる。

## えらべる こと

| | |
| --- | --- |
| むき | 湘南台 → あざみ野 ／ あざみ野 → 湘南台 |
| じかん | あさ・ひる・ゆうがた・よる（はしってる とちゅうも 上の ボタンで かえられる） |
| とまる えき | ⭐ とくべつな えき（高島町・横浜・新羽・仲町台 ＋ はじっこ）／ ぜんぶの えき（32こ） |

- 📖 **スタンプちょう**: とまった えきの スタンプが たまる（32こ）。タップで なんかい とまったか・のりかえ が みられる。
- 🗺️ **ろせんず**: B01〜B32 の えき、とまる えき、スタンプ、いま どこ を ひょうじ。したの ろせんバーを タッチしても ひらく。
- ⏩ はやおくり、🔊 おと（よみあげ も）オン/オフ。
- がめんを タッチ: でんしゃ → ファーン、にょこくん・つくぼう・ゾンビ → おしゃべり。

## しくみ

- `index.html` / `style.css` / `app.js`。えき データは `app.js` の `ST`、とくべつな えきは `SPECIAL`。
- にょこすけ は「わらって いもほり」、つくぼう は「つくぼうの せみ がっしょう」、ゾンビ は「てつだま」の 絵を canvas で かきなおしたもの。
- 進捗は localStorage `blueline-minna.v1`（スタンプ・のった かいすう・せってい）。
- URL に `#debug` で `window.__blue`（`mult(4)` で 4ばいそく）。
