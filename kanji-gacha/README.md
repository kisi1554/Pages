# かんじ ガチャ おもちゃばこ（kanji-gacha）

小学1〜3年むけ。漢字クイズで **コイン** をあつめ、**ガチャガチャ** をまわして **おもちゃ** を
手に入れ、その場で **あそべる**。おもちゃは「おもちゃばこ（たな）」にならぶ。

公開URL（同期後）: https://kisi1554.github.io/Pages/kanji-gacha/

## あそびかた

1. **クイズで コイン** … 5もんで 1セット。せいかい 1もんに コイン 1まい、3もん れんぞく せいかいからは 2まい。
   セットを さいごまで やると +1、ぜんもん せいかいなら さらに +2（ぜんぶ せいかいで 11まい）。
   - よみ: 漢字 → よみを 3択（「竹」→ たけ。おくりがなつきの字は「休む」→ やすむ）
   - かき: よみ → ただしい漢字を 3択（にた字を まぜる: 木/本/休、大/犬/太 …）
   - ことば: おもちゃの なまえの □ に入る漢字（「□とんぼ」→ 竹。絵と よみが ヒント）
   - まちがえた字は おなじセットの さいごと、つぎからの セットで もう一度でる。
     せいかいすると へっていく（せっていで いま のこっている字が みられる）。
2. **ガチャ** … コイン3まい。ハンドルを 3かい ぐるぐる まわす（タップでも まわる）→ ガチャン！ →
   カプセルが ころころ → タップで パカッ。ぎん（レア）・きん（スーパーレア）カプセルも ある。
   ハンドルは ほんものの ように 30どごとに「カチッ」と とまる ラチェット（12カチで 1しゅう、3しゅうで でる）。
   まわすと なかの カプセルが ゴロゴロ うごき、まわりの 12この ランプ（1こ＝4ぶんの1しゅう）で のこりが わかる。
   ぎゃくには まわらない（ガッと とまる）。とちゅうで 手を はなしても つづきから まわせる。
   さいごの 3カチは おもく、3しゅうで「ガチャン」（Android は ぶるっと ふるえる）。
   でた おもちゃの なまえを 大きく ふりがなつきで だし、漢字を 1字ずつ せつめいする
   （「竹＝たけ　1年生で ならう」「鏡＝かがみ　4年生で ならう・クイズには でないよ」）。
   おなじ おもちゃが でたら コイン 1まい かえす。
3. **おもちゃで あそぶ** … 147しゅるい。あそびかたは 33とおり（`play.js` の `TYPES`）。
   竹とんぼ（こすって とばす）、風車・水車・歯車・地球儀・回転木馬（なぞって まわす）、
   こま（ひもを ひく。ながく まわると ★）、けん玉（タイミング）、紙風船・手まり（つく）、
   水鉄砲、電車・汽車・新幹線（えきに ぴったり とめる）、太鼓（ドン／カッ）、
   笛・木琴・鉄琴・草笛・鳥笛（ドレミ。「かえるの うた」ガイドつき）、万華鏡、
   起き上がりこぼし・赤べこ、だるま落とし、磁石、虫眼鏡（かくれた むしを さがす）、
   竹馬、羽子板、凧、糸電話、人形・ぬいぐるみ、木馬、積み木、風鈴、花火、自動車、船、
   紙飛行機、輪投げ・玉入れ・弓矢、金魚すくい、貝がら、双六、福笑い、シャボン玉、
   お手玉、野球盤、色えんぴつ。
   - **都道府県の ピース**（47しゅるい）… かおつきの 都道府県の かたち。ピースを つまんで
     日本ちずの ただしい ばしょへ はこぶと ぴったり はまる。2かい まちがえると 地方の ヒント、
     3かいで その ばしょが ひかる。もっている ピースは ちずに いろが つき、「ピース n/47」で かぞえる。
4. **おもちゃばこ** … あつめた おもちゃが たなに ならぶ（まだの ものは シルエット）。
   タップで しょうかい → あそぶ。

## 漢字データ

- `data.js` の `grades` は 文部科学省「学年別漢字配当表」（小学校学習指導要領 別表、
  2020年度〜）の 第1〜3学年（80・160・200字）と、第4学年の うち 都道府県の なまえに つかう
  31字（愛 茨 媛 岡 潟 岐 熊 香 佐 埼 崎 滋 鹿 縄 井 沖 栃 奈 梨 阪 阜 群 富 賀 徳 城 府 静 兵 良 児）。
- `yomi` は 471字ぜんぶの よみ。さいしょの よみが クイズの こたえ（小学校で ならう よみ中心）。
- おもちゃの なまえに 4年生いじょう・中学・常用外の字（鏡・磁・眼・幹・華・鼓・砲・凧 …）が
  あるときは `extra` に 学年を かき、クイズには ださず ふりがなつきで みせるだけ。
- せっていで「1年／2年／3年 まで」「4年生の 地名も」を えらぶと、クイズに でる字と、ガチャで でやすい
  おもちゃ（なまえの 漢字が その学年までの もの）が かわる。
  4年の 地名の 字は「4年生の 地名も」の ときだけ クイズに でる（それいがいは ふりがなで みせるだけ）。
- 都道府県名の とくべつな よみ（宮城［ぎ］・神奈川［か］・滋賀［し］・奈良［ら］・鳥取［とっとり］・
  愛媛［えひめ］・大分［いた］・鹿児島［ご］）は チェックの `SPECIAL` に いれている。
- チェック: `python tools/check-kanji-gacha.py`
  （字数・かさなり・かんじカードの1年と おなじか・よみの かきかた・おもちゃの ふりがなが
  その字の よみか・`extra` の 学年 など）

## ほぞん

localStorage の `kanji-gacha-v1`（コイン・おもちゃばこ・まちがえた字・学年せってい・おと）。
読み書きは try/catch。せっていの「さいしょから やりなおす」で けせる。

## ファイル

```
kanji-gacha/
├── index.html  がめんの ほねぐみ（ガチャの きかいは SVG）
├── style.css   みため
├── data.js     漢字（学年・よみ・にた字）と おもちゃの いちらん
├── sound.js    こうかおん（WebAudio で その場で つくる）
├── pref.js     都道府県の かたち（自動生成。tools/kanji-gacha-prefs.py）
├── art.js      おもちゃの 絵（Canvas に コードで かく）
├── play.js     おもちゃで あそぶ ミニあそび
└── app.js      クイズ・ガチャ・たな・せってい・ほぞん
```

外部ライブラリ・CDN・画像／音声ファイルは つかっていない。

都道府県の かたちは `nihon-chiri-tanken/map-data.js`（国土数値情報 由来の 都道府県境界データ、
https://github.com/dataofjapan/land）から `python3 tools/kanji-gacha-prefs.py` で かんたんにして つくる。
