# ろせんず たんけん！（路線図を読むゲーム）

実在の路線図を「資料」として読み、駅をさがす・駅数をかぞえる・乗りかえを見つける
ゲームです。地理の下地づくりと、**資料から読み取って答える力**を狙っています。

横浜駅を 🏠 として、東急東横線・JR根岸線・みなとみらい線・JR横浜線・東急新横浜線・
東急田園都市線・東急目黒線を実際の位置関係と路線色で描いています。

## あそびかた

1. `index.html` をブラウザで開くだけで遊べます（インストール不要・オフラインOK）。
2. ステージを選ぶとスタート。全6問。
3. ステージごとに問われることが変わります。

| ステージ | 地図 | 問題 | 答えかた | 目安 |
|---|---|---|---|---|
| 🟢 えきを さがす | 2路線・16駅／**ひらがな表示** | 「じゆうがおか」はどこ？ | 地図をタップ | 年中〜小1 |
| 🔵 いくつめ？ | 5路線・25駅 | 綱島から東横線で自由が丘は何番目？ | 数字ボタン | 小1〜小3 |
| 🟣 のりかえは どこ？ | 7路線・33駅 | 三軒茶屋から山手へ。最初に乗りかえる駅は？ | 地図をタップ | 小3〜 |

わからないときは 👉 ヒント。ステージによって「その駅がある路線を光らせる」
「道すじを光らせる」「乗りつぐ路線の順番を教える」と、出す助けが変わります。

## 工夫したポイント

- **資料そのものが育つ**: ステージが上がると地図に路線が増えます。年中は東横線と
  根岸線だけの見やすい地図から始まり、最後は7路線が交差する本物の密度になります。
  読み取る資料が難しくなっていくこと自体が、このゲームの難易度設計です。
- **選択肢ではなく地図を触って答える**: えきさがしと乗りかえは、地図の上を直接
  タップします。選択肢から選ぶ形にすると地図を読まずに解けてしまうためです。
- **まちがえた駅の名前を教える**: 別の駅を押したら「そこは『しぶや』だよ」と返します。
  不正解を、ほかの駅を覚える機会に変えています。
- **答えが1つに決まる問題しか出さない**: 乗りかえ問題では、同じ乗換回数・同じ駅数で
  別の駅でも乗りかえられてしまう組み合わせ（例：大岡山→日本大通りは多摩川でも日吉でも
  同じ手間）を自動で除外しています。全1056通りを検査して、出題される732通りすべてで
  答えが一意であることを確認済みです。
- **正解のあと道すじを数えて見せる**: 「いくつめ？」では、正解すると駅から駅へ順番に
  番号が出ながら光っていきます。数えた過程が地図の上に残ります。
- 音声読み上げつき。ひらがなステージは文字が読めなくても遊べます。

## しくみ（実装メモ）

- 乗りかえ探索は、状態を「駅 × いま乗っている路線」として、**乗りかえ回数を第一、
  通る駅数を第二**の優先度で最短探索しています。乗りかえ0回の直通も正しく求まります。
- 実在ルートの検算：横浜→山手（聖光学院の最寄り）は根岸線で直通4駅、横浜→渋谷は
  東横線で直通10駅、横浜→新横浜は菊名で乗りかえ3駅。いずれも実際と一致します。
- 複数の路線が同じ区間を走るところ（田園調布〜日吉の東横線と目黒線など）は、区間ごとに
  垂直方向へずらして描き、両方の路線色が見えるようにしています。

## 動作環境

モダンブラウザ（Chrome, Safari, Edge など）で動作します。タッチ・マウスの両方に対応。
音声読み上げは対応ブラウザのみ有効です（非対応でも他の機能は問題なく遊べます）。
