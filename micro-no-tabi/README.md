# ミクロの たび 🔬

ゆびで ひろげる（アプリの なか だけ の ズーム）と **て → ゆびの もよう → ダニ → かみのけ → さいぼう → さいきん → ウイルス → DNA → げんし**、
すぼめると **こうえん → がっこう → まち → にほん → ちきゅう → つき → たいよう → たいようけい → ぎんがけい** へ。
10ばい ごとに 1だん、ぜんぶで **32だん**（10⁻¹⁰m 〜 10²¹m）の おおきさの たび。小学1〜6年むけ（年長は 絵を 見て たのしむ）。
`index.html` を ひらく だけで あそべる（外部ライブラリ・CDN なし。絵は オリジナル SVG、音は WebAudio の 合成音）。

## あそびかた

| モード | なかみ |
| --- | --- |
| 🚀 たび | ピンチ／ホイール／1ぽんゆびで うえ・したに なぞる／🔍＋・🔭− ボタン で すすむ。だんに つくと 📍 が ひかり、タップで 1ぎょうの せつめい（よみあげ）。 |
| 🔎 かくれんぼ | 「ダニを さがして！」→ じぶんで ズームして その だんで 📍 を タップ。20もん。ヒント「もっと ちいさい せかい だよ」。ベストタイムを ほぞん。 |
| ⚖️ おおきさ くらべ | 「さいぼう と かみのけ、どっちが おおきい？」「ちきゅうを 1cm に したら つきまでは？」など 10もん。 |
| 📕 パスポート | たずねた だんに スタンプ。32こ ぜんぶで「ミクロ・マクロ はかせ」。スタンプを タップすると その だんへ とぶ。 |

がめんの すみに「ものさし」（いまの がめんで 10cm／1mm／1km … が どの ながさか）と「がめんの はば ＝ こどもの せの ○ばい／○ぶんの1」。
ひだりの たての バーで いま どの あたりに いるかが わかる。

## しくみ

- すけーる L は log10 の あたい（-10 〜 21）。L＝e で だん e が ちょうど よく 見える。
- だん e の え（`scales.js`、viewBox -50..50、10^e m ＝ 15）の なかの `at` の ばしょに、ひとつ ちいさい だんの え が 1/10 で
  まるく ぼかして はいっている（3だん さき まで いれこ）。いまの L の 1つ うえの だんの え を **viewBox だけ かえて** えがくので、
  どこまでも なめらか・くっきり。だんを またいでも おなじ え が つづく。
- ブラウザの ズームは させない（`#stage` は `touch-action: none`、ピンチは pointer イベントで うけて L だけ かえる。共通の NO-ZOOM ブロックつき）。
- 音: ズーム中の ひゅーん（ちいさい せかい ほど たかい）、だんに つく ぽーん、ちきゅうより そとで しずかな パッド。🔊 で オン/オフ。
- ほぞん（localStorage `micro-no-tabi-v1`、try/catch）: スタンプ・かくれんぼ ベスト・クイズ ベスト・おと。

| ファイル | なかみ |
| --- | --- |
| `scales.js` | だんの データ（なまえ・おおきさ・せつめい・え）、たんいの ひょうじ、たとえクイズの もと |
| `quiz.js` | クイズ・かくれんぼの もんだい づくり（DOM なし） |
| `audio.js` | WebAudio の おと と よみあげ |
| `app.js` | がめん・そうさ・ほぞん |

## テスト

```bash
node tools/micro-no-tabi/test.js    # だんが 10ばい ずつ（となりと 1±0.5けた）・ふりがな・たんい・クイズの こたえ
node tools/micro-no-tabi/check.js   # 3がめん で ピンチ（visualViewport.scale は 1 の まま）・ボタン・かくれんぼ・クイズ・JS エラー
ALL=1 node tools/micro-no-tabi/check.js  # ぜんぶの だん（と とちゅう）の スクショ
```

おおきさは だいたいの あたい（げんし 0.1nm、さいぼう 20μm、ちきゅう 1まん2700km、ぎんがけい 10まん こうねん など）。
絵の なかの たいよう・つき・わくせいは 見えるように おおきく かいている。
