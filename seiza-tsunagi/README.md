# せいざ つなぎ ⭐

よぞらの ほしを ゆびで つないで、せいざを かんせいさせる 点つなぎ ＋ せいざ ずかん。
未就学〜小学生むけ。

公開URL: https://kisi1554.github.io/Pages/seiza-tsunagi/

## あそびかた

1. ホームで レベル（かんたん／むずかしい）を えらび、せいざを タップ。
2. **かんたん**: ほしに ばんごう。1→2→3… と ほしから ほしへ ドラッグ（または じゅんに タップ）。
   つぎに つなぐ ほしが みどりの わで ひかる。
   **むずかしい**: ばんごう なし ＋ かんけい ない ほしも まじる。💡ヒントで うすい せんが 4びょう でる。
3. ただしい せんは ひかって のこる（キラン）。まちがいは うすい ピンクの せんが きえる（やさしい おと）。
4. ぜんぶ つながると、せいざの え（SVG の せんが）が ふわっと かさなり、なまえ・みえる きせつ・
   みじかい おはなし・おもな ほしの なまえ を ひょうじ。ずかんに とうろく。
5. ボーナス: はくちょう・こと・わし を クリアで「なつの だいさんかく」、
   オリオン・おおいぬ・こいぬ を クリアで「ふゆの だいさんかく」が でる。

## こんやの そら

端末の 月と 時刻から、こんや 20時ごろ（夜なら いまの 時刻）に よこはまで みえる せいざを 3つ おすすめ。
月ごとの 対応表は `data.js` の `SEIZA_TONIGHT`。夜の時刻は「2じかん ≒ 1かげつ」で ずらして えらぶ。

### せいざ データ

- `stars`: `[なまえ, x, y, とうきゅう]`。x, y は じっさいの 赤経・赤緯を 接平面（gnomonic）投影し、
  0〜1 に 正規化した あたい（ひがしが ひだり、きたが うえ の よぞらの むき）。
- `path`: ほしの ばんごうの ならび。`-1` で ペンを はなす。となりどうしが 線に なり、
  はじめて でてきた じゅんが「かんたん」の ばんごう に なる。
- `art`: えの パーツ。`["s",とじる,x,y,...]` なめらかな線（Catmull-Rom）、`["l",x,y,...]` おれ線、
  `["c",x,y,r]` まる、`["t",x,y,"もじ"]` もじ。ざひょうは `stars` と おなじ。

## しくみメモ

- 外部ライブラリ・CDN・フォント なし。おとは すべて WebAudio の ごうせい（キラン音・やさしい まちがい音・
  かんせいの ファンファーレ・しずかな 和音の パッド BGM）。🔊 で オン／オフ。
- ほしの あたりはんけいは みための ほしより おおきい（16〜38px、となりの ほしとの きょりの はんぶん まで）。
- せいざは がめんに あわせて 縮尺・中央寄せ。あそぶ あいだは ほしだけで、かんせい後は え も はいる ように なめらかに ズーム。
- ほぞんは localStorage（`seizaTsunagi.v1`）。クリア（かんたん⭐／むずかしい🌟）・おと・レベル。読み書きは try/catch。
- デバッグ: `index.html?play=orion` で すぐ あそぶ、`?detail=orion` で ずかんの しょうさい。
