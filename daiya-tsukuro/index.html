📖 ダイヤ の よみかた

  • よこ は じかん。みぎ へ いく ほど あと の じかん。たて は えき。
  • ななめ の せん ＝ はしって いる。かたむき が きゅう な ほど はやい（オレンジ の せん が きゅうこう。オレンジ の まる の えき に だけ とまる）。
  • よこ に まっすぐ の ところ ＝ えき で とまって いる。
  • せん が まじわる ところ ＝ すれちがい・おいこし。きいろ の たんせん（せんろ 1ぽん）では、えき の なか で しか すれちがえない（みどり の まる）。
  • えき の よこ の ▮▮ は ホーム の かず。1つ の えき では すれちがい・おいこし が できない。

✍️ せん の ひきかた

  • せん を タップ → 🗑 で けせる。↩ で ひとつ まえ に もどる。
