# 📈 ダイヤ を つくろう

でんしゃ の じこくひょう の もと に なる **ダイヤグラム**（よこ＝じかん、たて＝えき）に、ゆび で **でんしゃ の せん** を ひいて
まち の ダイヤ を つくる パズル。**たんせん**（せんろ 1ぽん）では えき で まって すれちがわないと ぶつかる！
できた ダイヤ は **▶ はしらせる** で、した の せんろ ず を でんしゃ が うごいて たしかめられる。
対象: 小学2〜6年（てつどう ずき の おとな も）。まなび: グラフ の よみかき（じかん と きょり）、はやさ＝かたむき、
すれちがい・おいこし の しくみ、じこくひょう。

せんろ・えき は オリジナル（4〜7 えき）。じっさい の てつどう がいしゃ の ダイヤ は つかって いない。

公開URL: https://kisi1554.github.io/Pages/daiya-tsukuro/

## あそびかた

- うえ の **おだい**（れい: 「ふつう A→D 8:00〜8:05 に でる 0/1」）。ずひょう の でる えき の よこせん に、
  でて よい じかん が いろ の わく で でる。⏰ は「この じかん までに つく」。
- でる えき の よこせん を タップ → **ななめ に なぞる** と、でんしゃ の はやさ で せん が のびる（かたむき は しゅるい で きまる。かってに まがらない）。
  えき の ところ で ゆび を **よこ** に うごかす と、その ぶん **とまる**。ゆび を はなす と その えき が しゅうてん
  （えき の あいだ で はなした ときは はんぶん いじょう なら つぎ の えき まで）。
- ふつう は ぜんぶ の えき に 1ぷん とまる。きゅうこう（オレンジ）は オレンジ の まる の えき に だけ とまる。
- ぶつかる ところ は あか ＋ 💥「ぶつかる！」。たんせん で むかいあわせ、おなじ せんろ で おいこし、ホーム が たりない（えき の よこ の ▮ が ホーム の かず）。
- せん を タップ → 🗑 けす、↩ もどす、💡 ヒント（こたえ の れい を てんてん で だす）。
- おだい を みたして ぶつからなければ「✨ できた！」→ **▶ はしらせる** で さいご まで はしれば クリア。
- ★1 クリア、★2 まち じかん（よぶん に まった ぷん）が めやす ＋3 いない、★3 めやす いない ＋ とくべつ おだい（のりかえ・でんしゃ の かず）。
- よみかた の しょう は もんだい に こたえる（まちがい 0 で ★3、1かい で ★2）。
- 📖 で ダイヤ の よみかた（ななめ＝はしる、かたむき が きゅう＝はやい、よこ＝とまる、まじわる＝すれちがい・おいこし）。

| しょう | なかみ |
| --- | --- |
| 1. ダイヤ を よもう | できて いる ダイヤ を みて「① は なんじ に C えき？」「どれ が いちばん はやい？」「どこ で すれちがう／おいこされる？」 |
| 2. ふくせん | のぼり・くだり べつ の せんろ。じかん どおり に ひく。おなじ えき に おなじ ぷん は だめ |
| 3. たんせん | えき で まちあわせ（すれちがい）。ホーム 1つ の えき では すれちがえない |
| 4. きゅうこう | きゅうこう が ふつう を おいこす（ホーム 2つ の えき だけ）。のりかえ べんり で ★3 |
| 5. いそがしい あさ | 10ぽん いじょう・しゃこ（C えき 🏠）から の でんしゃ・おりかえし（でんしゃ の かず に かぎり） |

## しくみ

- `diagram.js`（DOM なし）: でんしゃ ＝ [えき, つく じこく, でる じこく] の ならび。じこく は 1ぷん きざみ。
  くかん ごと に たんせん／ふくせん。しょうとつ は
  - たんせん の くかん に ぎゃく むき の 2ほん が どうじ に いる（ひらいた はば: つく ぷん に はんたい が でる のは OK）
  - おなじ むき で くかん の なか で じゅんばん が いれかわる（おなじ ぷん に でる／つく も だめ）
  - えき の ホーム の かず を こえる（とじた はば。ふくせん に となりあう えき は むき ごと に p ほん）
  ほか に、ゆび の あと → でんしゃ（`trace`／`finish`）、ずひょう ⇄ じこく・えき（`view`）、
  でんしゃ の かず（おりかえし 3ぷん）、おだい の マッチング、よみかた もんだい の こたえ。
- `stages.js`: 5 つ の せんろ と 25 ステージ。おだい（でる じかん の はば・つく じかん・でんしゃ の かず）と
  てがき の かいとう（`ANS`。`node tools/daiya-tsukuro/solve.js --write <番号>` で さがして かきこめる）。
- `render.js`: canvas 2D で ダイヤグラム と せんろ ず（ホーム の わりあて つき）。
- `audio.js`: WebAudio の ごうせいおん だけ（しゃーっ・ぽん・ブブー・がたんごとん・オリジナル の チャイム）。🔊 で オン/オフ。
- `app.js`: がめん・なぞり（pointer イベント、`touch-action: none`）・はしらせる アニメ・よみかた もんだい・
  ほぞん（localStorage `daiya-tsukuro-v1`、try/catch）。
