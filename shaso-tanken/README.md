# しゃそう たんけん ビンゴ 🚃

**鉄道好きの 4〜8さい向け**。本物の でんしゃに のっている あいだ、まどから みえた もので あそぶ ビンゴです。
みつけた ものは「じぶんの ずかん」に きろくされ、おうちに かえってから まめちしき と 3たく クイズで ふかぼりできます。
画面を みつめるのではなく、**まどの そとを みることが あそび**に なります。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリ なし）。

公開URL: https://kisi1554.github.io/Pages/shaso-tanken/

---

## 1かいの ながれ

1. のる まえに **ろせんを えらぶ**
2. その ろせん向けの **3×3 ビンゴ** が でる（ろせんで みられそうな ものから 9こ ランダム）
3. みつけた マスを **1タップ** で「みつけた！」スタンプ（もう1かい タップで とりけし）
4. たて・よこ・ななめが そろうと **「たんけん たいちょう」バッジ**（効果音・紙ふぶき・よみあげ）
5. おうちで **ずかん** を ひらくと、みつけた ものの まめちしき・しくみの え・3たく クイズ・きろく

| ろせん | みられそうな もの | ひとこと |
| --- | --- | --- |

| どこでも ビンゴ | 30しゅるい | どの でんしゃでも あそべる よく みる もの |

## みつける もの（40しゅるい）

| ぶんるい | もの |
| --- | --- |
| 🌿 しぜん | かわ・ふじさん・うみ・やま・たんぼ・はたけ・もり・とり・くも・はな |
| 🚆 のりもの | しんかんせん・かもつれっしゃ・すれちがう でんしゃ・バス・トラック・ショベルカー・ふね・ひこうき・じてんしゃ・きゅうきゅうしゃ |
| 🏢 たてもの | てっきょう・トンネル・ふみきり・えき・てっとう・すいもん・ビル・こうじょう・じんじゃ・がっこう |
| 🛠️ しごと | クレーン・はたけの ひと・せんろを まもる ひと・たくはいびん・えきいんさん・うんてんしさん・ごみしゅうしゅうしゃ・パトカー・ソーラーパネル・せんたくもの |

絵は 絵文字 と インラインSVG（かもつれっしゃ・トンネル・ふみきり・てっとう・すいもん・ショベルカー・ソーラーパネル）。
1つずつに こども向けの まめちしき（2〜3文）、しくみの え（絵文字の ながれ図）、3たく クイズ1もん が あります。

## じぶんの ずかん

- 40しゅるいの 一覧（みつけていない ものは シルエット）。ぶんるいごとの タブ
- みつけた もの: まめちしき（🔈 よみあげ つき）・しくみの え・3たく クイズ（せいかいで ⭐）・「いつ・どの ろせんで」みつけたかの きろく
- みつけていない もの: どの ろせんで みつかりそうか を ヒント表示
- **ろせんごとの たっせいりつ**（駅スタンプラリーのように うまっていく）
- **たんけん かいすう**: でんしゃに のって スタンプを おした「日」の かず。毎日でなくても とぎれません
- **ガタンくんの たんけん おはなし**: いちばん さいきんの たんけんの 日を、でんしゃの ガタンくんが みじかい おはなしに して よみあげます（`speechSynthesis`）

## おうちの方へ

- **一度ページを開けば、電波のない区間でも動きます。**データはすべて `index.html` の中にあり、読み込んだ後は通信しません。
- **位置情報・カメラ・マイクは使いません。**
- **音が出ます。**右上の 🔊 ボタンで 効果音と読み上げを まとめてオフにできます（車内では オフ がおすすめです）。
  効果音は Web Audio API の合成音で、音声ファイルはありません。
- 読み上げはブラウザの音声合成（日本語）を使います。日本語の音声がない端末では読み上げされませんが、文章は画面に表示されます。
- 記録（みつけたもの・バッジ・クイズ・いまのビンゴカード）は この端末のブラウザ（localStorage）にだけ保存されます。
- 車内では座っているか、つり革につかまっているときに遊ぶよう声をかけてください。
- 「ろせんで みられそうな もの」は目安です。季節・天気・座る側によって見えないこともあります。

## つくり

- `index.html` 1ファイルで完結（CSS・JS・データ・SVG すべて内蔵）
- 保存キー: `shaso-tanken-v1`（読み書きは try/catch）
- 縦持ちスマホ: 情報 → ビンゴ → ボタン の たて並び。横持ちタブレット: 左に情報とボタン、右に ビンゴ
- 漢字は `{漢字|かんじ}` と書くと ふりがな（`<ruby>`）つきで表示し、読み上げは かなで読みます

### 見つけるものを ふやすには

`ITEMS` に `{ id, cat, e(絵文字) または svg, name, fact, flow, q: [もんだい, せいかい, はずれ, はずれ] }` を足し、
`ROUTES` の `pool` に `id` を足します。
