# いろまぜ ラボ 🎨

**えのぐを まぜて、おきゃくさんに たのまれた いろを つくる あそび。**
未就学〜小学校低学年むけ。`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/iromaze-lab/

## あそびかた

1. えのぐの チューブ 5本（あか・きいろ・あお・しろ・くろ）を タップすると、おさらに 1てき ぽとん。
   いれた てきすうは おさらの したの ドットと、チューブの バッジで わかります（12てき まで）。
2. 「🌀 まぜる」か、おさらを ゆびで ぐるぐる なぞると まざって いまの いろに なります。
3. おきゃくさん（どうぶつ）の みほんと おなじ いろが できたら「✨ できた！」。
   - みほんとの ちがい（ΔE）が 10みまん ★3、20みまん ★2、30みまん ★1。
   - とおいときは「ぶぶー」と ヒント（「もうすこし きいろ を たして みよう」）。すすめた チューブが ぴょこぴょこ うごきます。
4. ↩ ひとつ もどす、🗑 あらう（からっぽ）。

## モード

| モード | ないよう |
| --- | --- |
| 🐰 おきゃくさん | ステージ 15こ。①2しょく まぜ（1〜6）→ ②3しょく まぜ（7〜9）→ ③しろ・くろ で こさ ちょうせい（10〜15）。まえの ステージで ★1 いじょうで つぎが ひらく |
| 🧪 じゆうに まぜる | つくった いろに なまえを つけて「いろ ずかん」に のこす（12こ まで） |
| 📖 いろ ずかん | のこした いろと その レシピ（ドット）。✕ を 2かい タップで けす |
| 🖍️ ぬりえ | でんしゃ・さかな・はな・おうち（SVG を コードで かいた せんが）を、ずかんの いろ＋きほんの 5しょく で タップぬり |
| 🔦 ひかりの いろ | あか・みどり・あお の ライトを かさねると しろ（かほう こんしょく）。まるは ドラッグで うごかせる |

## いろの けいさん（`color.js`）

- RGB の たんじゅん へいきん は つかわない（あお＋きいろ が はいいろに なるため）。
- てきすう `[あか, きいろ, あお, しろ, くろ]` から、あか・きいろ・あお の **わりあい**（いちばん おおい いろ＝1）を
  Gossett & Chen (2004) の **RYB 立方体の 8かど を つかった 3次元補間** で RGB に する。
- そのあと しろ は「いろの えのぐ と しろ の わりあい」で しろに よせ、くろ は ぜんたいの わりあいで かけざんで くらく する。
- はんていは sRGB → XYZ(D65) → **Lab** に じぶんで へんかんして **ΔE（CIE76）**。
- ヒントは さきよみ: いまの おさらに「たすだけ」で とどく くみあわせ（12てき まで）を ぜんぶ しらべ、
  いちばん ちかい くみあわせに たりない えのぐを すすめる。たすだけで ★3 に とどかないときは「おおすぎる えのぐ」か「あらう」を すすめる。
- **みほんは ぜんぶ レシピ（てきすう）から けいさん** して つくるので、かならず つくれる。

| みほん | レシピ |
| --- | --- |
| だいだいいろ / みどり / むらさき | あか1 きいろ1 / きいろ1 あお1 / あか1 あお1 |
| みかんいろ / きみどり / あおむらさき | あか1 きいろ2 / きいろ2 あお1 / あか1 あお2 |
| ちゃいろ / おうどいろ / あずきいろ | あか2 きいろ2 あお1 / あか1 きいろ3 あお1 / あか3 きいろ1 あお2 |
| ピンク / そらいろ / はいいろ | あか1 しろ2 / あお1 しろ1 / しろ1 くろ1 |
| クリームいろ / ふかみどり / ラベンダー | きいろ1 しろ3 / きいろ1 あお1 くろ1 / あか1 あお1 しろ3 |
