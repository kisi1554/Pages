# えのでん まちなか チンチン 🚋

藤沢〈ふじさわ〉から 鎌倉〈かまくら〉まで、江ノ電〈えのでん〉を うんてんする アクションゲーム（5さい むけ）。
家の のきさきすれすれ・道路の 上（ろめん きどう）・うみぞいを 走り、まわりを よく 見て すすむ 大切さを 体験する。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

## あそびかた

- **すすむ ボタン**（または 画面）を おしている あいだ すすむ。はなすと とまる。キーボードは スペース／→。
- 前に くるま・じてんしゃ・ねこ・はと・かもめが いたら とまる。**🔔 チンチン**（B／↑）で ねこや とりに あいず → どいたら また すすむ。
  - 線路で ねている ねこ（ごろーん）は 3かい チンチンして やっと どく。
- 駅の **きいろい ところ**（とまる 位置 ±70）で とまると おきゃくさんが のりおり。ずれても OK、いきすぎたら 自動で すこし もどる。
- ぶつかりそうに なっても 自動で ぽよんと とまるだけ（こわれる・けがの 絵は なし）。ゲームオーバー・時間切れは なし。タイムは 記録だけ。
- はやさは 🐢ゆっくり／🐇ふつう。

わらいどころ: のきさきの せんたくもの（パンツ）が 屋根に ひっかかって なびく → つぎの 駅で かえす／ねこが ベルで ごろーん／うみぞいで かもめが 屋根に ずらり。

## たしかめた 事実（江ノ島電鉄 公式・国土交通省 関東運輸局 資料ほか）

- 駅（15駅）: 藤沢・石上・柳小路・鵠沼・湘南海岸公園・江ノ島・腰越・鎌倉高校前・七里ヶ浜・稲村ヶ崎・極楽寺・長谷・由比ヶ浜・和田塚・鎌倉。全長 約10km。
- 江ノ島〜腰越の あいだは 自動車道の 中央に 線路が ある 併用軌道（ろめん きどう）。
- 1902年（明治35年）9月1日 藤沢〜片瀬（現・江ノ島）で 開業、1910年（明治43年）11月4日 鎌倉まで 全通。
- 鎌倉高校前駅は 海の すぐ そばの 駅。極楽寺〜長谷の あいだに トンネル（極楽洞）が ある。

会社の ロゴ・公式マーク・車両の 公式デザイン・発車メロディは 使わない。電車は みどりと クリーム色の オリジナル。
