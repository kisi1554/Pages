# きめつクエスト ⚔️

鬼滅の刃の おはなしを もとにした、ドラクエ3ふうの コマンドRPG（**ファンメイド・非公式**）。
すこしずつ おはなしを ふやしていく。いまは **だい1わ「はじまりの ゆき」**（漫画 第1話、とみおか ぎゆう と であうまで）。

公開URL: https://kisi1554.github.io/Pages/kimetsu-quest/

## だい1わの ながれ

1. かまどけ … おかあさんから すみ 3つ と おにぎり を もらう
2. やまみち … けもの（たぬき・からす・きつね・いのしし）と たたかって レベルアップ
3. ふもとの まち … すみを 3にんに うる。どうぐや・おちゃや（やすむ）
4. かえりみち … さぶろう じいさんに とめられて こやに とまる
5. つぎの あさ … いえで… → ねずこを せおって やまを おりる
6. おにに なった ねずこ と たたかう（「よびかける」で こころを とりもどす）
7. **とみおか ぎゆう と たたかう**（ふつうに こうげきしても あたらない。
   「おのを なげあげる」→ つぎの ターンに「いしを なげる」で しかけが きまる。
   まけても その ばで やりなおせて、ヒントが でる）

こわい ひょうげんは しない（ち は でない。けものは「にげていった」）。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `engine.js` | いどう・はなす・メニュー・たたかい・おと（WebAudio ごうせいおん）・セーブ。おはなしに よらない ぶぶん |
| `data.js` | キャラの みため、てき、どうぐ、てきの ドットえ、きょく |
| `ep1.js` | だい1わの マップ・ひと・イベント。`EP` に フックを いれる |

- がめんは 240×176（16px タイル 15×11）の Canvas。キャラも タイルも コードで ドットえを かく（がぞう ファイル なし）
- セーブは localStorage（`kimetsu-quest-v1`）。マップを うつる たびと イベントの あとに じどうで きろく
- **つぎの おはなしを たすとき**: `ep2.js` を つくり、マップと イベントを かく。`index.html` で よみこむ ep を きりかえる
  （つよさ・どうぐは `G` を そのまま ひきつぐ）
