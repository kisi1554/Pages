# めぶんりょう チャレンジ 📏

どうぐ を つかわず「**だいたい**」で こたえる あそび（年長〜おとな）。
「ちょうど 10cm の せん を ひいて」「とけい を みないで 1ぷん たったら おして」「まめ は なんこ？」。
こたえる と ものさし・とけい・かぞえ が でて、**どれだけ ちかいか** が わかる。
`index.html` を ひらくだけで うごきます（外部ライブラリなし）。

公開URL: https://kisi1554.github.io/Pages/mebunryo/

## チャレンジ（5しゅるい）

| しゅるい | もんだい | こたえあわせ |
| --- | --- | --- |
| 📏 ながさ | ちょうど 2〜17cm の せん を ドラッグ で ひく（ななめ OK）／1えんだま 3こ ぶん・はがき・えんぴつ 1ぽん | ひいた せん に ものさし を あてて 🚩 を みせる。ずれ を mm で |
| ⏱️ じかん | とけい を みないで 5〜60びょう で おす（とちゅう は びょう も こちこち も なし） | とけい の はり が まわる アニメ（ここ だけ こちこち）。ずれ を びょう で |
| 🫘 かず | まめ・ほし・ひと が 3びょう だけ うつる（10〜300こ）→ すうじ ボタン で こたえる | 10こ ずつ いろ を かえて かぞえる |
| 📐 かくど・まんなか | せん・まる・しかく の まんなか を タップ／ちょっかく を つくる | ほんとう の まんなか・ちょっかく を かさねる |
| ⚖️ おもさ | どっち が おもい？／りんご 1こ と つりあう のは たまご いくつ？ | てんびん アニメ。「やく 300g」と まるめた データ |

## がめん の 1cm（キャリブレーション）

CSS の px は ほんとう の ながさ では ない ので、さいしょ に **1えんだま（ちょっけい 20mm）** を がめん に おいて
まる の おおきさ を あわせる（＋／− と スライダー）。1mm ＝ まる ÷ 20 px を ほぞん。
あわせて いない あいだ は ながさ もんだい が「わく の よこはば の はんぶん」など わりあい の もんだい に なる。

## あそびかた

- **ひとりで**: 5もん で 1セット（しゅるい を えらぶ か 🎲 いろいろ）。ずれ が 5% いない 🎯 ぴったり・15% 👍 おしい・30% 🙂 まあまあ。
  てんすう は 100 − ずれ% × 2。ベスト を ほぞん。
- **みんなで**: 2〜6にん の なまえ を いれて、おなじ もんだい を じゅんばん に（まえ の ひと の こたえ は かくす）。
  みんな できたら いっせい に はっぴょう → いちばん ちかい ひと に 👑。3もん か 5もん で 👑 の かず を くらべる。
- **まいにち 1もん**: ひづけ で きまる もんだい。🔥 れんぞく ひすう。
- **からだ ものさし**（せってい）: てのひら・ゆび の はば を はかって おくと、ながさ もんだい の 💡 ヒント に「てのひら やく 1こ と はんぶん ぶん だよ」。
