# かんじモンスター ずかん（kanji-monster）

漢字の字形をそのまま体にした、5ひきのモンスター。1体＝1枚の SVG ファイルで、
`index.html` はそれを並べて見比べるためのずかんページです。

公開URL（同期後）: https://kisi1554.github.io/Pages/kanji-monster/

## 5ひき

| 名まえ | 漢字 | どこが何になっているか | ファイル |
| --- | --- | --- | --- |
| タツノスケ | 竜 | 上の「立」が顔、下の「乚」がしっぽ。うろこ＋長いひげ＋枝角 | `monsters/tatsunosuke.svg` |
| オニマロ | 鬼 | 上の「田」が顔（4つのマスの上段が両目）、頭のはらいが一本角、右下の「厶」が金棒 | `monsters/onimaro.svg` |
| カメじい | 亀 | 左上のはらいが首と頭、下の四角が甲羅（六角の甲板＋こけ）、下のはねが尾と足 | `monsters/kamejii.svg` |
| トリベエ | 鳥 | 左にくちばし、頭にとさか、下の「灬」が足と尾ばね | `monsters/toribee.svg` |
| ロウすけ | 狼 | 左のけものへんが顔（上の2つの先が耳）、右の「良」が胴と後ろ足、はらいの先がしっぽ | `monsters/rousuke.svg` |

名前は「〜のすけ」「〜まろ」「〜じい」「〜べえ」「〜すけ」でそろえてあります。

## ファイル

```
kanji-monster/
├── index.html          ずかんページ（カードを押すと説明が出る）
├── README.md
└── monsters/
    ├── tatsunosuke.svg
    ├── onimaro.svg
    ├── kamejii.svg
    ├── toribee.svg
    └── rousuke.svg
```

SVG は 512×512 の `viewBox`、背景は透過。外部ファイルもフォントも参照していないので、
`<img>`・`background-image`・他のアプリの素材として、そのまま貼って使えます。

## どうやって「リアル」に見せているか

写真のような描き込みではなく、SVG の機能だけで立体感と質感を出しています。

- **字形**: IPAゴシックのグリフをアウトライン化したパス。字の形はいじっていないので読める
- **立体**: 字画の内側に、右下＝影・左上＝ハイライトを入れるフィルタ（`feComponentTransfer`＋`feGaussianBlur`＋`feComposite`）
- **ふちの落ち込み**: 字画の輪郭をぼかした線でなぞって、へこみと厚みを出す
- **質感**: うろこ／羽／毛／甲羅の六角板は `<pattern>`、肌のざらつきは `feTurbulence`
- **生き物らしさ**: `feDisplacementMap` で輪郭をわずかにゆらす（狼は毛羽立って見えるよう強め）
- **目**: 白目・虹彩・虹彩の繊維・瞳孔・まぶたの影・ぬれた光の6層

## 作り直すとき

```sh
python3 tools/gen-kanji-monsters.py
```

字形データはスクリプトに埋め込み済みなので、フォントも外部ライブラリも要りません。
色や角・ひげの形を変えたいときは `tools/gen-kanji-monsters.py` の各モンスターの関数を直します
（SVG を直接手で直してもかまいませんが、次に生成すると上書きされます）。

字形の出典は IPAゴシック（IPA Font License 1.0）。文字をアウトライン化して図案に使ったもので、
フォントそのものは同梱していません。
