# 併願プランをつくる（heigan-plan）

2月1日から5日までの午前・午後（全10枠）に受験校を並べ、
**それまでに合格が出ているかどうか**で次に受ける学校を切り替える併願プランを組み立てる。

公開URL: https://kisi1554.github.io/Pages/heigan-plan/

## 考え方

分岐の条件は「どこかに1つでも合格しているか」だけ。どの学校に合格したかまでは区別しない。
そのため樹形図は指数的に広がらず、**2本のレーン**に収まる。

| レーン | 色 | 意味 |
| --- | --- | --- |
| まだ合格なし | 赤 `--a: #8E1226` | まだどこにも受かっていない状態で進むルート |
| すでに合格あり | 青 `--b: #1A4E8C` | 押さえが取れたあとに進むルート |

左（赤）の枠で合格すると、その**次の枠から**右（青）へ移る。
2/1午前は必ず未合格から始まるので、この枠の「合格あり」は選べない（`disabled`）。

## 画面

1. **日程を組む** — 10枠 × 2レーンの `<select>`。受けない枠は空のまま。
2. **流れを確かめる** — 2レーンの樹形図。両方とも空の枠は表示しない。
3. **まとめ** — ぜんぶ不合格だった場合の受験回数／最初の受験で合格した場合の受験回数／「合格あり」で受ける枠数。

ボタンは「ぜんぶ消す」（確認ダイアログあり）と「『合格あり』列に左をコピー」の2つ。

## 学校データ

`SCHOOLS` 配列に19校。`{ k:キー, n:校名, t:男子校/共学/公立・共学, yt:四谷大塚（男子・80%） }`。
四谷の偏差値の降順に並べてある。

**この19校は [`../docs/commute-routes.html`](../docs/commute-routes.html) と同じ顔ぶれ。**
通学ルート比較に学校を足したら、こちらの `SCHOOLS` にも足すこと（校名・種別・四谷の値を合わせる）。

## 保存

`localStorage` キー `heigan-plan:v1`。読み書きはどちらも try/catch で囲んである。

```json
{ "d1am": { "a": "kaisei" }, "d1pm": { "a": "shibak", "b": "seiryo" } }
```

枠IDは `d<1-5><am|pm>`。両レーンとも空になった枠はオブジェクトごと消す。

## 注意

**入試日の妥当性は検査していない。** 「その学校がその日のその時間帯に入試を行うか」は
各校の募集要項で確認する必要がある。アプリ内にも警告を出している。

## 決まりごと

- `index.html` だけで完結。外部ライブラリ・CDN なし。
- 個人情報（住所・氏名）は書かない。
- ダークモードは `prefers-color-scheme` と `[data-theme]` の両方に対応。
- 34rem 以下で1カラムに畳む。畳んだときは各 `<select>` の上にレーン名を出す。
