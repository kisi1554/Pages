# 併願プラン（heigan-plan）— 引っ越しました

中身は [`../tsugaku-route/`](../tsugaku-route/) の `#plan` セクションに移した。
★を付けた学校がその場で日程表に効くように、通学ルート比較と1枚にまとめたため。

このフォルダに残っているのは、古いURLやブックマークから `../tsugaku-route/#plan` へ
送るための転送ページだけ。**中身を直すときは [`../docs/commute-routes.html`](../docs/commute-routes.html)**
（住所入りの原本）を編集して、`tsugaku-route/index.html` に反映する。

組んだ日程は `localStorage` の `heigan-plan:v1` に入っていて、キーは変えていないので
移行の前後でそのまま引き継がれる。

仕組みの説明は [`../tsugaku-route/README.md`](../tsugaku-route/README.md) にまとめてある。
