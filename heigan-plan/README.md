# 併願プランをつくる（heigan-plan）

2月1日から5日までの午前・午後（全10枠）に受験校を並べ、
**それまでに合格が出ているかどうか**で次に受ける学校を切り替える併願プランを組み立てる。

公開URL: https://kisi1554.github.io/Pages/heigan-plan/

## 考え方

分岐の条件は「どこかに1つでも合格しているか」だけ。どの学校に合格したかまでは区別しない。
そのため樹形図は指数的に広がらず、**2本のレーン**に収まる。

| レーン | 色 | 意味 |
| --- | --- | --- |
| まだ合格なし | 赤 `--a: #8E1226` | まだどこにも受かっていない状態で進むルート |
| すでに合格あり | 青 `--b: #1A4E8C` | 押さえが取れたあとに進むルート |

左（赤）の枠で合格すると、その**次の枠から**右（青）へ移る。
2/1午前は必ず未合格から始まるので、この枠の「合格あり」は選べない（`disabled`）。

## 画面

1. **日程を組む** — 10枠 × 2レーンの `<select>`。受けない枠は空のまま。
2. **流れを確かめる** — 2レーンの樹形図。両方とも空の枠は表示しない。
3. **まとめ** — ぜんぶ不合格だった場合の受験回数／最初の受験で合格した場合の受験回数／「合格あり」で受ける枠数。

ボタンは「ぜんぶ消す」（確認ダイアログあり）と「『合格あり』列に左をコピー」の2つ。

## 学校データ

`SCHOOLS` 配列に20校、のべ52枠。

```js
{ k:'mita', n:'三田国際科学学園', t:'共学', yt:60,
  s:{ d1am:[49], d1pm:[52], d2pm:[51], d3pm:[55,'MST'], d4pm:[55] } }
```

| フィールド | 中身 |
| --- | --- |
| `k` | 内部キー。localStorage に入るのはこの値 |
| `n` `t` | 校名と種別（男子校／共学／公立・共学） |
| `yt` | 四谷大塚の予想偏差値（男子・80%）。**学校そのものの目安** |
| `s` | 入試を行う枠。`枠ID: [サピックス偏差値, 回次の呼び名]` |

**`s` が肝。** 同じ学校でも回次ごとに日程も難度も違うので、枠ごとに偏差値を持たせている
（高輪なら 2/1午前 45 ／ 2/2午前 48 ／ 2/2午後 55（算数）／ 2/4午前 46）。
`IN_SLOT` が枠→学校の逆引きを作り、各 `<select>` は**その枠に入試がある学校しか出さない**。
選択肢はサピックス偏差値の降順。

`yt`（四谷）と `s` の値（サピ）は**尺度が違う**。開成は四谷72／サピ68。混ぜないこと。

元データは [`../docs/exam-schedule-matrix.html`](../docs/exam-schedule-matrix.html)
（偏差値×日程のマトリクスと、学校ごとの受験日一覧）。

**この20校は [`../docs/commute-routes.html`](../docs/commute-routes.html) と同じ顔ぶれ。**
通学ルート比較に学校を足したら、こちらの `SCHOOLS` にも足すこと（校名・種別・四谷の値を合わせ、
`s` に入試日を入れる）。マトリクスには20校以外に13校ぶんの日程が載っているので、
そこから引ける（筑波大駒場・麻布・駒場東邦・海城・慶應中等部・芝・鎌倉学園・法政二・
中大横浜・神奈川大附属・都市大等々力・公文国際・横国横浜）。

## 保存

`localStorage` キー `heigan-plan:v1`。読み書きはどちらも try/catch で囲んである。

```json
{ "d1am": { "a": "kaisei" }, "d1pm": { "a": "shibak", "b": "seiryo" } }
```

枠IDは `d<1-5><am|pm>`。両レーンとも空になった枠はオブジェクトごと消す。

読み込み時に `prune()` が走り、**その枠に入試のない学校を指している値を落とす**。
日程データを入れる前に組んだプランや、あとで `s` を直した場合に効く。
落としたぶんはその場で黙って書き戻す（保存メッセージは出さない）。

保存する値は学校キーだけで、回次は持たない。枠が決まれば回次も一意に決まるため
（同じ学校が同じ枠に2回出ることはない）。

## 注意

**日程は手元の一覧表から入れたもの。** 年度によって動くので、出願前には各校の募集要項で
日程・出願期間・発表時刻を確認する必要がある。アプリ内にも注意書きを出している。

## 決まりごと

- `index.html` だけで完結。外部ライブラリ・CDN なし。
- 個人情報（住所・氏名）は書かない。
- ダークモードは `prefers-color-scheme` と `[data-theme]` の両方に対応。
- 34rem 以下で1カラムに畳む。畳んだときは各 `<select>` の上にレーン名を出す。
