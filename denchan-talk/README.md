# でんちゃんと おしゃべり 🚃

こどもが かいた **田園都市線（でんえんとしせん）の でんしゃの え** から うまれた キャラクター
**「でんちゃん」** と、こえで おしゃべり できる アプリです（未就学〜小学生むけ）。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリなし）。

## えの とおりに つくった ところ

- みどりの ふちの しかくい かお、ひだりうえの まど、め・まゆ・にっこり くち
- ひだりに ふみきり（バッテン・あかい ランプ 2つ・やじるしの ほうこうしじき・きいろと くろの しゃだんかん）
- しゃだんかんの「2020」の ふだ（でんちゃんは 2020けい）と、したの あかい **ひじょうボタン**

## あそびかた

1. なまえを いれて「おはなし する」。
2. **🎤 はなす** で こえで はなしかける。もじでも、したの ボタン（チップ）でも OK。
3. ふみきり・ひじょうボタン・でんちゃんを タップしても はんのう する。

| いうこと | でんちゃんの へんじ |
| --- | --- |
| しゅっぱつ しんこう | ドアが しまって はしり、つぎの えきに とうちゃく（えきめいひょう・アナウンス）。おわりの えきで おりかえす |
| 〇〇まで つれてって | その えきまで ノンストップ |
| 〇〇って どんな えき？／〇〇の つぎは？ | しぶや〜ちゅうおうりんかん 27えきの まめちしき・となりの えき |
| ふみきり みせて | カンカン → しゃだんかんが おりて でんちゃんが とおる |
| クイズ だして | つぎの えき／ヒントで えきあて／えきの かず の 3たく。せいかいで ⭐ |
| じゃんけん しよう | ✊✌️✋（あいこ あり） |
| なまえは？・なんさい？・なにいろ？・ともだちは？ | 2020けい の じこしょうかい、5000けい・8500けい などの なかま |
| すきな たべものは？・すきな えきは？ | ききかえして、こどもの こたえを ひろう |
| ぜんぶの えき いって | 27えきを ぜんぶ いう |

  （カンカン・けいてき・ガタンゴトン・ドアチャイム・ブレーキ）
