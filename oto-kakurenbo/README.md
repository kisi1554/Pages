# おとの かくれんぼ 👂

くさむらに かくれた むしを、**なきごえの 大きさ と みぎ・ひだりの きこえかた だけ** で さがす あそび。
未就学〜小学生むけ。`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・音声ファイル なし）。

🎧 イヤホンが おすすめ（みぎ・ひだりが よく わかる）。

## あそびかた

1. レベルを えらぶ（この タップで AudioContext を はじめる）。
2. がめん いっぱいの くさむらの どこかに むしが かくれている。
3. ゆびで なぞる（PC は マウスを うごかす）と、ゆびの いちが「みみ」に なる。
   - ちかいほど おとが 大きく、こもりが とれる（とおいと lowpass で こもる）
   - むしが ゆびより みぎなら みぎから きこえる（StereoPannerNode）
4. 「ここだ！」と おもったら うごかさずに タップ。はずれたら「もうすこし みぎ かも」などの ヒント。チャンスは 3かい。
5. みつけた じかん と かいすうで ★1〜3。みつけた むしは ずかんに とうろく。

## レベル

| レベル | ようす | でてくる むし |
| --- | --- | --- |
| 1 ☀️ ひる | むし 1ぴき。むしの まわりの くさが そっと ゆれる | キリギリス・ミンミンゼミ・ツクツクボウシ |
| 2 🌇 ゆうがた | 2ひきが どうじに なく。「〇〇を さがして」の ほうを みつける（🔊 おてほん つき） | 7しゅるい ぜんぶ |
| 3 🌙 よる | くらい。くさの ゆれ ヒント なし | スズムシ・エンマコオロギ・マツムシ |

## おと オフ ＝ みる モード

🔇 に すると「みる モード」。ゆびの ちかくの くさが、むしに ちかいほど よく ゆれて、
ゆびから でる わもんが 大きく・はやく なる。おとが なくても あそべる。
