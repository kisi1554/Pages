# あしたの てんきやさん 🌤️

**ほんものの てんきよほう**を 見ながら、**雨や 雲が できる しくみ**を まなべる
子どもむけ（未就学〜小学生）の 天気アプリです。
`index.html` を ブラウザで ひらくだけで うごきます（ビルドも サーバーも 不要）。

- 文字は **ひらがな中心**、漢字には **ふりがな**（`app.js` の `rubyize()` が じどうで つけます）
- 音は **WebAudio の合成音のみ**（音声ファイルなし）。右上の 🔊 で オン/オフ
- スタンプ・よそうの きろくは **localStorage** に ほぞん（読み書きは try/catch）
- たて持ちスマホ／よこ持ちタブレット どちらでも レイアウトが くずれません

---

## 4つの タブ

| タブ | なにが できる | なにが わかる |
| --- | --- | --- |
| 🌤️ **よほう** | 10の 町の 天気を 見る。きょうの すうじから 「なぜ この天気？」を せつめい | 天気マークの よみかた、気温・降水確率・湿度・気圧・風の いみ |
| ✋ **よそう** | あしたの 天気を 4つから えらんで よそう → **つぎの日 じどうで こたえあわせ** | 予報を じぶんで よんで かんがえる ちから |
| 🧪 **じっけん** | 太陽・風・そらの さむさを うごかして、水の たびを かんさつ | じょうはつ → 雲 → 雨/雪 → 川 → 海 の じゅんかん |
| 📖 **まなぶ** | よみかた／きせつ／クイズ の 3つ | 梅雨・台風・雪・ゆうだち・風の しくみ、5問クイズ |

### ✋ よそう と スタンプ

1. 「よそう」タブで **あしたの 天気**を ☀️/☁️/☔/⛄ から えらぶ
2. つぎの日（〜2日後まで）に ひらくと、**ほんとうの 天気と くらべて** ⭕❌ が つく
3. あたると **スタンプ ⭐ が 1こ** もらえる（クイズの 正解でも もらえます）

かみなり ⛈️ は 「あめ」の なかまとして 正解に します（`KIND_FAMILY`）。

### 🧪 じっけん（雨は どこから やってくるの？）

canvas の うえで、うみ・山・川・太陽を つかった みずの じゅんかんを シミュレーションします。

| つまみ | かわること |
| --- | --- |
| ☀️ たいようの つよさ | じょうはつする 水じょうきの りょうと のぼる はやさ |
| 🍃 かぜの つよさ | 雲が よこに ながれる。山に ぶつかると おしあげられて 雨が ふえる |
| 🌡️ そらの さむさ | 雲が できる たかさ。つよく さむくすると 雨が **雪**に かわる |

「🌤️ きょうの てんきに あわせる」を おすと、いま えらんでいる 町の
じっさいの 気温・雲の りょう・風から つまみを セットします。

## 天気データについて

- **[Open-Meteo](https://open-meteo.com/)** の むりょうAPI（APIキー不要・登録不要）から
  げんざいの 天気と 7日ぶんの 予報、そして 2日まえまでの 実績（こたえあわせ用）を とります。
- とれた データは localStorage に 30分 キャッシュします。
- **ネットに つながらない ときは**、キャッシュ →「おためし天気」（アプリの中で つくった にせもの）
  の じゅんに きりかえ、その ことを 画面に はっきり だします。オフラインでも あそべます。
- 外部ライブラリ・CDN・Webフォントは つかっていません（読みこむのは 同じフォルダの css/js だけ）。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | 画面の ほね |
| `style.css` | 見た目（たて持ち／よこ持ち 両対応） |
| `data.js` | 町のリスト・WMO天気コード表・きせつカード・クイズ |
| `weather.js` | localStorage の ほぞん、API の とりこみ、「りゆう」カードの 生成 |
| `lab.js` | じっけん（みずの じゅんかん）の シミュレーションと えがき |
| `audio.js` | WebAudio の 合成音（タップ・正解・雨・かみなり） |
| `app.js` | 画面の くみたて、よそうの こたえあわせ、クイズ、ふりがな |

## おうちの方へ

- 位置情報は **つかいません**。町は リストから えらぶ しくみです。
- 通信するのは Open-Meteo の 予報APIだけで、個人情報は 送りません。
- よそうの きろくと スタンプは その端末の ブラウザにだけ のこります。
