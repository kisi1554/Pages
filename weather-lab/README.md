# あしたの天気やさん 🌤️

**本物の天気予報**を見ながら、**雨や雲ができるしくみ**を学べる子どもむけ（小学生）の天気アプリです。
`index.html` をブラウザで開くだけで動きます（ビルドもサーバーも不要）。

- 文字は**小学4年生くらいまでの漢字**をつかい、漢字には**ふりがな**（`app.js` の `rubyize()` が自動でつけます）
- 音は **WebAudio の合成音のみ**（音声ファイルなし）。右上の 🔊 でオン/オフ
- スタンプ・予想の記録は **localStorage** に保存（読み書きは try/catch）
- たて持ちスマホ／よこ持ちタブレットのどちらでもレイアウトが崩れません

## 5つのタブ

| タブ | なにができる | なにがわかる |
| --- | --- | --- |
| 🌤️ **予報** | 日本11都市・世界10都市の天気を見る。今日の数字から「なぜこの天気？」を説明 | 天気マークの読み方、気温・降水確率・湿度・気圧・風の意味 |
| 🗺️ **地図** | 日本地図／世界地図に、今の天気マークと気温をならべて表示。ふだをタップすると予報へ | 北と南の気温の差、赤道に近い町と遠い町のちがい |
| ✋ **予想** | あしたの天気を4つからえらんで予想 → **つぎの日に自動で答え合わせ** | 予報を自分で読んで考える力 |
| 🧪 **実験** | 太陽・風・空の寒さを動かして、水の旅を観察 | 蒸発 → 雲 → 雨/雪 → 川 → 海 のじゅんかん |
| 📖 **学ぶ** | 読み方／季節／クイズの3つ | 梅雨・台風・雪・夕立ち・風・世界の時差、13問から5問クイズ |

### 🗺️ 地図

- **日本地図**：札幌・仙台・新潟・東京・横浜・名古屋・大阪・広島・高知・福岡・那覇
- **世界地図**：ニューヨーク・ロサンゼルス・リオデジャネイロ・ロンドン・パリ・モスクワ・カイロ・北京・
  シンガポール・シドニー（＋くらべる目じるしとして横浜）。赤道の線も表示します
- 名前のふだは**重ならない場所を自動でさがして**置きます（`map.js` の `place()`）
- 気温は色でもわかります（寒い青 〜 暑い赤）。ふだをタップ → その町の天気・**現地の時刻**・予報へ

### 🕒 現地の時刻

Open-Meteo が返す `utc_offset_seconds` から、その町の**今の時刻を1秒ごとに**表示します。
「日本より 13時間 おくれている」のように、日本との時差も出ます。
世界の町の予報（日づけ・日の出・1週間）も、すべてその町の現地時間で表示します。

### ✋ 予想とスタンプ

1. 「予想」タブで**あしたの天気**を ☀️/☁️/☔/⛄ からえらぶ
2. つぎの日（〜2日後まで）に開くと、**本当の天気とくらべて** ⭕❌ がつく
3. 当たると**スタンプ ⭐ が1こ**もらえます（クイズの正解でももらえます）

かみなり ⛈️ は「雨」のなかまとして正解にします（`KIND_FAMILY`）。

### 🧪 実験（雨はどこからやってくるの？）

canvas の上で、海・山・川・太陽をつかった水のじゅんかんをシミュレーションします。

| つまみ | 変わること |
| --- | --- |
| ☀️ 太陽の強さ | 蒸発する水蒸気の量と、のぼる速さ |
| 🍃 風の強さ | 雲が横に流れる。山にぶつかるとおし上げられて雨がふえる |
| 🌡️ 空の寒さ | 雲ができる高さ。強く寒くすると雨が**雪**に変わる |

「🌤️ 今日の天気に合わせる」を押すと、今えらんでいる町の実さいの気温・雲の量・風から
つまみをセットします。

## 天気データについて

- **[Open-Meteo](https://open-meteo.com/)** の無料API（APIキー不要・登録不要）から、
  今の天気と7日ぶんの予報、そして2日前までの実績（答え合わせ用）を取ります。
- 地図は**1回のお願いで全部の町**をまとめて取ります（`Weather.loadMany`）。
- 取れたデータは localStorage に30分キャッシュします。
- **ネットにつながらないときは**、キャッシュ →「おためし天気」（アプリの中で作ったにせもの）
  の順に切りかえ、そのことを画面にはっきり出します。オフラインでも遊べます。
  おためし天気は緯度と月から気温を作るので、**南半球では季節が反対**になります。
- 外部ライブラリ・CDN・Webフォントは使っていません（読みこむのは同じフォルダの css/js だけ）。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | 画面のほね |
| `style.css` | 見た目（たて持ち／よこ持ち 両対応） |
| `data.js` | 町のリスト・WMO天気コード表・季節カード・クイズ |
| `map-data.js` | **自動生成**。世界と日本まわりの海岸線（`tools/weather-map/generate_map.py`） |
| `weather.js` | localStorage の保存、APIの取りこみ、「理由」カードの生成 |
| `map.js` | 地図の描画・ふだの自動配置・タップ判定 |
| `lab.js` | 実験（水のじゅんかん）のシミュレーションと描画 |
| `audio.js` | WebAudio の合成音（タップ・正解・雨・かみなり） |
| `app.js` | 画面の組み立て、予想の答え合わせ、クイズ、ふりがな辞書 |

### 地図データの作りなおし方

```bash
python3 tools/weather-map/generate_map.py
```

Natural Earth（パブリックドメイン）の `ne_110m_land` / `ne_50m_land` をダウンロードし、
矩形で切り取り → Douglas-Peucker で間引き → `weather-lab/map-data.js` を書き出します。

## おうちの方へ

- 位置情報は**つかいません**。町はリストや地図からえらぶしくみです。
- 通信するのは Open-Meteo の予報APIだけで、個人情報は送りません。
- 予想の記録とスタンプは、その端末のブラウザにだけ残ります。
