# レインボースプリング 🌈

**にじいろの バネ（レインボースプリング）で あそぶ ゲーム。**
`index.html` をブラウザで開くだけで あそべます（外部ライブラリなし）。

## あそびかた

### 🤲 じゆうに あそぶ
- りょうはしの まるを ゆびで うごかすと、バネが びよーんと のびて ゆれます（2ほんゆび OK）。
- バネを ⭐に あてると あつまります。10こ ごとに おいわい。
- 「✋ かたほう はなす」で かたほうが ぶらーん。「🌀 びよーん」で はねます。

### 🪜 かいだん おり
- がめんを **ながおし** すると バネの さきが のびます。**はなす** と ぽとんと おちて、つぎの だんへ。
- ⭐の ある だんに おりると ほしゲット。💧みずたまりは とびこえよう（おちると ⭐が 1こ へる）。
- やさしい（8だん）／ふつう（12だん）／むずかしい（16だん・はやい）。ゲームオーバーは なし。

### そのほか
- 🎨 で バネの いろを かえられます（にじ・パステル・ゆうやけ・うみ・きんぴか）。
- 🔊 で おとの オン/オフ。おとは WebAudio の ごうせいおん のみ。
- ベストの ほしの かず・いろ・おとの せっていは localStorage（`rainbow-spring-v1`）に ほぞん。

## しくみ（メモ）
- じゆうモード: 26この ふしを バネで つないだ ぶつりシミュレーション。ふしの あいだを ほかんして コイルを かく。
- かいだんモード: ベジェきょくせんの うえに コイルを ならべる アニメーション（おりるたびに うえしたが ひっくりかえる）。
