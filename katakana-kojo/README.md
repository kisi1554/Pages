# カタカナ へんしん こうじょう 🏭

**ひらがなの ことばに カタカナの「かた」を はめて へんしん！**
ベルトコンベアで はこばれてくる え と ひらがなの ことば（れい: ぱん）に、
1もじずつ 3つの カタカナの かたから えらんで はめると「パン」に へんしんして はこに はいる。
5さい〜小学1年むけ。外部ライブラリ・CDN なし（`index.html` だけで うごく）。

公開URL: https://kisi1554.github.io/Pages/katakana-kojo/

## あそびかた

1. メニューで こうじょう（ステージ）を えらぶ。
2. コンベアに ことばが はこばれてきて とまる。オレンジに ひかっている ひらがなの カタカナを 3つの かたから えらぶ。
   - まちがえた かたは「はじかれて」うすくなる。もういちど えらべる（2かい まちがえると こたえが ひかる）。
   - まだ ならっていない もじは 🤖ロボットが さきに はめてくれる。
3. ぜんぶ はまると へんしん！ はこに はいる。5つ つくると 1かい おわり（1〜3ぷん）。
4. じかんぎれは なし。まちがいの かずで ⭐1〜3（さいごまで できれば かならず ⭐1 いじょう）。
5. つくった ことばは 📗ずかんに たまる。はめた カタカナは 50おんひょうに ひかる。

| # | なまえ | ことばの れい |
| --- | --- | --- |
| 1〜7 | ア・カ・サ・タ・ナ・ハ・マ の れつ | アイス、カメラ、スイカ、トマト、テニス、ホテル、メロン |
| 8 | ヤ・ラ・ワ・ン | リス、ワニ、ロボット、ユニコーン |
| 9 | てんてん ゛ | バス、ゴリラ、ブドウ（まちがいの かたは ハ/パ のような なかま） |
| 10 | まる ゜ | パン、ピアノ、ペンギン |
| 11 | にている じ（とくべつ） | クツ、ミシン、ソックス（シ/ツ・ソ/ン・ク/タ・ノ/メ・ユ/コ を まぜる） |

- せいおん 46もじの うち ヲ いがいは どこかの ことばで はめる。ヲ は ヤ・ラ・ワ・ン を クリアすると ひかる。
