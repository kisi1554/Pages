# きめつバトル 🗡️

鬼滅の刃の むげんじょうの たたかいを、ファイナルファンタジー7ふうの **ATB コマンドバトル** で あそぶ（**ファンメイド・非公式**）。
いまの たたかい:

| シーン | みかた | てき | ポイント |
| --- | --- | --- | --- |
| むげんじょう：アカザせん | たんじろう＋ぎゆう | じょうげんの さん・アカザ | らしん → すきとおる せかい、しゅうしきは ぼうぎょ か なぎ |
| むげんじょう：どうません その1 | しのぶ（ひとり） | じょうげんの に・どうま | しのぶは ちからが よわい。わざで **どく** を ためて たおす（どうまは どくに なれてくる） |
| むげんじょう：どうません その2 | カナヲ＋いのすけ | じょうげんの に・どうま | しのぶの どくが のこっている。HP 35% で どうまが **とけはじめる** |

その1 に かつと「▶ つぎの たたかいへ」で その2 に すすめる。

公開URL: https://kisi1554.github.io/Pages/kimetsu-battle/

## あそびかた

- したの **きいろい ゲージ（ATB）** が たまった キャラの ばん。`たたかう / わざ / どうぐ / ぼうぎょ` から えらぶ
- ダメージを うけると **ピンクの ゲージ（ひっさつ）** が たまる。まんたんで「たたかう」が「ひっさつ」に かわる
  - たんじろう: ヒノカミかぐら・れつじつこうきょう（5れんげき・かならず あたる）
  - ぎゆう: じゅういちのかた なぎ（アカザの こうげきを 3かい けして はんげき）
  - しのぶ: むしのこきゅう・ひゃくそくじゃばら（8れんげき・どく +5）
  - カナヲ: はなのこきゅう・ひがんしゅがん（3ターン みんなの こうげきが かならず あたる）
  - いのすけ: けもののこきゅう・ばくれつもうしん（おおきな とっしん）
- **どく**（しのぶの わざ）: てきの ばんの おわりに どくの かず × ダメージ。どうまは どくに なれて ききにくく なる
- **ひえ**（どうまの こなごおり）: わざを つかう たびに HP が すこし へる。「ぼうぎょ」で なおる
- ぼうぎょ: うける ダメージ はんぶん、MP が 8 もどる
- 「⏸」で ひとやすみ（おと・おんがく・じかんの とまりかた を かえられる）
- むずかしさ: やさしい / ふつう。きろくは ★3つ（かつ／だれも たおれない／そのうえ 4ふん いない）

### アカザせんの ながれ

1. HP 60% で「はかいさつ・らしん」… こうげきが かわされやすく なり、アカザの きずも なおる。
   ぎゆうの ほおに あざが でて、たんじろうが **すきとおる せかい** を おぼえる（3ターン かならず あたって クリティカル、てきの こうげきも みきる）
2. HP 25% で さらに つよく なる。4かいに 1かい「ちからを ためる」→ つぎに ぜんいん こうげき「しゅうしき」。
   **ぼうぎょ** か ぎゆうの **なぎ** で ふせぐ
3. たおすと、アカザが にんげんだった ころを おもいだして しずかに きえる おはなし（こわい ひょうげんは しない）

## しくみ（キャラ・たたかいの ふやしかた）

| ファイル | なかみ |
| --- | --- |
| `data.js` | キャラ（`CHARS`）・わざ（`SKILLS`）・どうぐ（`ITEMS`）・てき（`ENEMIES`）・セリフの なまえ（`SPEAKERS`）・シーン（`SCENES`） |
| `chars.js` | キャラの みため（`LOOKS`）。アニメふうの め・かみ・はおりの もよう（いちまつ・きっこう）・はなふだの みみかざり・アカザの あおい しま など。カットインよう の かおの アップ（`drawPortrait`） |
| `draw.js` | はいけい（`BGS`）・わざの エフェクト（`FX`）・つぶ（しぶき・ひのこ・ゆきの けっしょう）・カットイン・しゅうちゅうせん。ぜんぶ Canvas に コードで かく |
| `audio.js` | WebAudio の ごうせいおん。BGM は わふうロック（ひずんだ ギター・ベース・ツーバス・たいこ・しゃみせんふうの はやびき）。`battle`（172 BPM）→ HP 25% で `battle2`（188 BPM）、かつと `win`。オン/オフ あり |
| `game.js` | ATB バトルの しくみ・わざの ふりつけ（カメラ・ヒットストップ・スロー・ざんぞう）・コマンドの まど・セーブ（localStorage `kimetsu-battle-v1`） |

- **キャラを たす**: `CHARS` に 1つ（hp・mp・atk・wait・skills・limit）、`draw.js` の `LOOKS` に みためを 1つ、
  `SPEAKERS` に なまえと いろ。みかたは 3にんまで ならべられる（`game.js` の `homes`）
- かみの け は `hairCap()` で あたま ぜんたいを おおってから まえがみ・うしろがみを かさねる（はげて みえないように）
- **わざを たす**: `SKILLS` に たす。type は `attack` / `buff` / `cover` / `nagi`。fx は `slash` / `water` / `fire`。
  `anim` で ふりつけを えらぶ（`minamo` / `wheel` / `vortex` / `dragon` / `waterfall` / `enbu` / `firering` / `renjitsu` /
  `butterfly` / `sting` / `hexagon` / `zigzag` / `petalburst` / `petalarc` / `petalswirl` / `beastpierce` / `claw` / `rush`）。
  `fx` は あたったときの つぶ（`water` / `fire` / `poison` / `flower` / `beast`）、`poison` で どくが たまる。
  わざを つかうと かおの アップの カットインが でる（ひっさつは おおきく）
- おなじ てきを べつの シーンで つかうときは、どうまの ように きほん（`DOUMA`）を つくって `Object.assign` で HP・phases・defeat だけ かえる
- **てきを たす**: `ENEMIES` に `moves`（`cutin: true` で カットイン）・`ai`（つぎの わざを えらぶ かんすう）・
  `phases`（HP で おこる イベント。`mark` で あざ、`bgm` で きょくを かえる、`dot` で まいターン ダメージ）・`defeat`。
  どくを つかう てきには `poisonDmg`・`adapt`・`adaptMax`。わざの `frost` で ひえ
- **たたかい（シーン）を たす**: `SCENES` に `{ id, emoji, title, desc, bg, party, enemy, items, intro }` を たす
  （`next` で つぎの シーン、`enemyStart` で てきの さいしょの どく、`hint` で はじめの ヒント）。
  はいけいは `bg: "mugen"`（むげんじょう）/ `"lotus"`（こおりの はすの いけ）、BGM は `battle` / `ice` / `battle2`。
  `coming: true` の「じゅんびちゅう」カードは いらなくなったら けす
