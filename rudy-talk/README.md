# ルディと おしゃべり 🐱

ちょっと生意気で意地悪だけど憎めない、**黄色い猫「ルディ」**とおしゃべりするだけで
語彙力がついていくアプリです(未就学〜小学生むけ)。

`index.html` をブラウザで開くだけで遊べます(ビルド・サーバー・外部ライブラリ不要)。

## あそびかた

1. なまえ(入れないと「あお」になる)と、ことばの むずかしさ(やさしい / ふつう / むずかしい)を選んで「はなしに いく」。
2. 🎤 で話しかけるか、文字を打つ。下のボタン(チップ)をタップするだけでも会話が進む。
3. ルディのセリフの中で **ひかっている ことば** をタップすると、意味と例文が見られる。
4. ルディをタップすると反応する(さわられるのは嫌がるけど、なかよくなると…)。

## ごいりょくが つく しくみ

| しくみ | 中身 |
| --- | --- |
| **会話に まぜる** | ルディの返事には少し背伸びしたことば(「案外」「夢中」「絶品」など)が入る。はじめて出たことばは「…あ、『絶品』って わかる? わからない よね」と、からかいながら意味を教える |
| **いいかえ チャレンジ** | 子どもが「すごい」「たのしい」「つかれた」「しんぱい」などのふつうのことばを使うと、「また『すごい』? ルディなら もっと かっこよく いうニャ」と、言いかえを3択で出す(29種類のふつうのことば → 約140語) |
| **しゅくだい(つかって みせて)** | 教えたことばを「つぎの おしゃべりで つかうこと!」とミッションにする。会話の中で使えたら、ルディが悔しそうに認めてくれる |
| **つかえたら ほめる** | 子どもが会話の中でことばを使うと(活用形もOK)、ルディが気づいて「…ちょっとだけ 感心 したニャ」 |
| **ことばクイズ** | 「クイズ」で3択。「『〇〇』の いみは?」と「『〜』を なんて いう?」の2方向。出会ったけど覚えていないことばを多めに出す |
| **〇〇って なに?** | 収録語なら意味と例文で答える。「それ どういう いみ?」で直前のことばを説明 |
| **ことばちょう(📕)** | 🐾であった → ⭐いみが わかった → 👑じぶんで つかえた の3段階。ランク(こねこ → のらねこ → いえねこ → ものしりねこ → ボスねこ → はかせねこ → ルディきゅう → でんせつの ねこ → ことばの かみさま)も上がる |
| **みとめど(🐟)** | ことばを使えたり、クイズに正解したりするとたまる。20・40・60・80・100で、ルディがツンデレなひとことを言う |

**1ねんせいの かんじ(80じ)だけで かける ことば** は 483語 あります(一・右・雨・円・王…林・六)。
**2ねんせいの かんじ(160じ)を つかった ことば**(1・2ねんせいの かんじだけで かける)は 1012語 あります
(`words-ninen.js` に 525語。何回・曜日・東京・黒い・小刀・麦茶・毛糸・一万円 など。160じ すべてに 3語いじょう ※汽・京・才 は のぞく)。
「やさしい」を えらぶと、「ことば おしえて」と ことばクイズの 4わりを 1ねんせいの かんじの ことば、
3わりを 2ねんせいの かんじの ことばに します。

「ことば おしえて」と ことばクイズは、えらんだ むずかしさの ことばを 7わり くらい 出します
(やさしい ことばばかりに ならないように)。

ことばが多いので、ふつうの会話に たまたま まじった ことばで「つかえた!」と ならないように、
まだ教えていない ことばは「ふつう」以上で、漢字か4文字以上の形で使ったときだけ ほめます。
やさしい ことばは、2回目からは ほめずに数えるだけにしています。

## ルディの せいかく

- 一人称は「ルディ」、語尾は「〜ニャ」。笑い方は「ニャハハ」。
- 生意気で意地悪(「『絶品』も しらないの? ニャハハ」)だけど、
  子どもが悲しい・こわいと言うと「ルディが そばに いて あげるニャ」と寄りそう。
- ほめられると照れる(「べ、べつに きみの ために やったんじゃ ないニャ」)。
- ひょうじょう10種類: ふつう / ドヤ顔(片方の牙つき) / にこにこ / びっくり / むっ / てれ / ねむい(Zzz) /
  しょんぼり / かんがえ中 / ウインク。絵は SVG で描いていて、しっぽ・まばたき・口パクが動きます。

## おうちのかたへ

- **通信は一切しません。** 返事はすべてブラウザの中(`brain.js`)で組み立てています。API キーも不要です。
- 保存するのは「なまえ」「むずかしさ」「おと オン/オフ」「ことばの記録」「みとめど」だけで、
  保存先はこの端末の localStorage です(ことばちょうの下の「きろくを ぜんぶ けす」で消せます)。
- 🎤 は Web Speech API(Chrome / Edge / Safari)。使えないブラウザではマイクボタンが消え、文字入力で遊べます。
- 読み上げは端末の日本語音声を使います。🔊 で読み上げと効果音をまとめてオン/オフできます。
- 「ばか」などの言葉には、ルディが怒ってみせたあと「そういう ことば ばかり つかってると、ことばが へっちゃうニャ」と返します。
