# つくぼうと おしゃべり 🦗

かくれんぼが だいの とくいな **ツクツクボウシの「つくぼう」** と、こえで おしゃべり・かくれんぼが できる アプリです。
つくぼうは **あおくんの ともだち**。ちょっぴり いじわる（からかい）を いうけれど、
こどもが「いじわる」「やめて」と いうと すぐ あやまって なかなおり します。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリなし）。

## あそびかた

1. なまえを いれる（さいしょは「あお」→「あおくん」と よばれる）。
2. **🎤 はなす** で こえで はなしかける。もじでも、したの ボタン（チップ）でも OK。
3. 「かくれんぼ しよう」で つくぼうが かくれる／「ぼくが かくれる」で こどもが かくれる。

### えらべる ことば（チップ）

がめんの ボタン（チップ）は `chips.js` から まいかい 4つ えらびます（ぜんぶで 約510しゅるい ＋ じてんから つくる 約5,200しゅるい）。

- いまの わだいの つづき（`follow`）から 3つ ＋ ふだんの グループ（あそび・しつもん・セミ・はなし・ものしり）から 1つ
- ときどき じてんの ことばで「ペンネ しってる？」「すきな おやつは？」「どうぶつ クイズ」を まぜる
- どの チップも おすと へんじが かえる ことを テストで たしかめています（チップを たしたら `TsukuChips` の テストを まわす）

だまっていると 35びょうごとに（3かいまで）つくぼうから はなしかけて きます。

### かくれんぼ（10の ばしょ × 10の あそびかた × 3つの むずかしさ）

「かくれんぼ しよう」で メニューが ひらきます。ことばで「よるの かくれんぼ」「もりで かくれんぼ」などと いうと すぐ はじまります。

| ばしょ（10） | こうえん・もり・うみべ・おうち・ようちえん・えき・どうぶつえん・なつまつり・はたけ・ゆきやま（かくれ ばしょ ぜんぶで 141） |
| --- | --- |

| あそびかた（10） | ないよう |
| --- | --- |
| 🔎 つくぼうを さがす | ちかい🔥／とおい❄️ と ヒント（ゆれる・ばしょの いいかた・ちかくの もの・3つに しぼる） |
| 🙈 ぼくが かくれる | つくぼうが 2〜4かしょ さがしに くる（むずかしさで みつかりやすさが かわる） |
| 👫 なかま さがし | みんみん・じりじり・かなかな・くまぜみ も かくれる（3〜5ひき、それぞれの なきごえ） |
| ⏱️ タイムアタック | 45〜90びょうで なんかい みつけられるか。さいこう きろくを ほぞん |
| 🐚 ぬけがら あつめ | ぬけがら 3〜6こ と つくぼうを ぜんぶ みつける |
| 👂 おとで さがす | なきごえの おおきさ（ちかさ）と ひだり・みぎ（ステレオ）が ヒント |
| 🐾 にげる つくぼう | はずすと あしあとを のこして となりへ にげる |
| 🔦 よるの かくれんぼ | まっくら。タップした まわりを ライトで てらす。ほたる✨が ヒント |
| 🧐 じっくり さがし | ちいさく まぎれた つくぼうを けしきの なかから めで さがす |
| 🏆 かくれんぼ たいかい | さがす・かくれる を こうたいで 3かいせん。さきに 2しょう で ゆうしょう |

- **むずかしさ**: やさしい（かくれ ばしょ 8・ヒント 3かい）／ふつう（12・5かい）／むずかしい（ぜんぶ・むせいげん）
- **レベル**: みつけると けいけんち。「かくれんぼ 1ねんせい」〜「かくれんぼ でんせつ」の 10だんかい
- **ずかん**: バッジ 35しゅるい（ばしょごとの マスター・あそびかたごと・100かい はっけん・ヒントなし など）
- つくぼうは あおくんが かくれんぼ だいすき なのを しっていて、メニューや おわりに その はなしを する

ファイル: `hide-data.js`（ばしょ・あそびかた・セリフ 約250・バッジ・レベル）、`hide.js`（ゲームの しくみ）、`vocab5.js`（ことばで あそびかたを えらぶ）

## つくぼうの せってい（キャラクター）

- ツクツクボウシ。なつの おわりに でてくる。みどりと くろの もようで きに とけこむ → かくれんぼの めいじん。
- あおくんの ともだち。じしんかで ちょっと いじわる。ほめられると てれる。
- からかいは「ねぐせ」「かくれんぼ よわい」ていど。ひどい ことばは つかわない。

## おうちの方へ

- 読み上げは ブラウザの音声合成、鳴き声・効果音は Web Audio で合成しています。🔊 から個別にオフにできます。
- マイクは「はなす」を押したときだけ使います（ブラウザの音声認識。対応していない端末ではボタンが出ません）。
- 名前と かくれんぼの記録は この端末のブラウザ（localStorage）に保存されます。
