# つくぼうと おしゃべり 🦗

かくれんぼが だいの とくいな **ツクツクボウシの「つくぼう」** と、こえで おしゃべり・かくれんぼが できる アプリです。
つくぼうは **あおくんの ともだち**。ちょっぴり いじわる（からかい）を いうけれど、
こどもが「いじわる」「やめて」と いうと すぐ あやまって なかなおり します。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリなし）。

## あそびかた

1. なまえを いれる（さいしょは「あお」→「あおくん」と よばれる）。
2. **🎤 はなす** で こえで はなしかける。もじでも、したの ボタン（チップ）でも OK。
3. 「かくれんぼ しよう」で つくぼうが かくれる／「ぼくが かくれる」で こどもが かくれる。

だまっていると 35びょうごとに（3かいまで）つくぼうから はなしかけて きます。

### かくれんぼ（つくぼうを さがす）

- はずれると、ちかければ 🔥、とおければ ❄️ が でる。つくぼうは からかって くる。
- **🔊 なきごえ ヒント** で、かくれている ところが ゆれる。
- みつけた かいすうの さいしょうを きろく。

### ことば じてん

`dict-*.js` に `[よみ, かんじ/カタカナ, とくちょう]` を 1ぎょう たすと、その ことばが
かいわ・なーんだクイズ・しりとり・ききかえしの こたえ・漢字の よみかえ の ぜんぶで つかえます。
とくちょうは「〜もの なーんだ？」に つながる ように、どうし・けいようしの おわりかたで かきます
（うごき・きもちの カテゴリは `{ sentence: true }` で、つくぼうの ひとことを そのまま かく）。

わだい（`vocab*.js`）と じてんの どちらで こたえるかは `talk.js` の `useDictFor`:
わだいが あれば わだいを ゆうせんし、じてんの ことばが わだいの キーワードを ふくむ とき
（「ティラノサウルス」⊃「ティラノ」）だけ じてんで くわしく こたえます。

### ことばを ふやすには

`vocab*.js` に セリフや わだいを たすだけで ふえます（`talk.js` は さわらなくて よい）。
わだいは「いちばん ながく あった キーワード」で えらびます（「たすけて」は「たす」より ながいので たすけての わだい）。
「きょう」「つくぼう」「セミ」の ような ひろい ことばの わだいは、ほかに あわない ときだけ つかいます。
音声認識は 漢字で かえって くるので、新しい キーワードに 漢字が ありそうなら `kana` に よみかえを たします。

## つくぼうの せってい（キャラクター）

- ツクツクボウシ。なつの おわりに でてくる。みどりと くろの もようで きに とけこむ → かくれんぼの めいじん。
- あおくんの ともだち。じしんかで ちょっと いじわる。ほめられると てれる。
- からかいは「ねぐせ」「かくれんぼ よわい」ていど。ひどい ことばは つかわない。

## おうちの方へ

- 読み上げは ブラウザの音声合成、鳴き声・効果音は Web Audio で合成しています。🔊 から個別にオフにできます。
- マイクは「はなす」を押したときだけ使います（ブラウザの音声認識。対応していない端末ではボタンが出ません）。
- 名前と かくれんぼの記録は この端末のブラウザ（localStorage）に保存されます。
