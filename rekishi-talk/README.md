# れきし じんぶつ トーク 📜

ひみこ・しょうとくたいし・むらさきしきぶ・のぶなが・ひでよし・いえやす・りょうま・のぐちひでよ・
ダ・ヴィンチ・ナイチンゲール・エジソン・アインシュタイン の **12にん** に なりきった キャラクターと、
かいて（または こえで）おしゃべり できる アプリです。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・外部ライブラリ・ネットつうしん なし）。
にがおえ は この アプリの ために SVG で かいた オリジナル（しゃしんや ほんものの にがおえ は つかって いません）。

## 「リアル」に する ための きまり

- **こたえは ぜんぶ きろく（しりょう）を もとに かいた もの** だけ。その ばで ぶんしょうを つくらないので、つくりばなし を しません。
  （AI の API は つかって いません。GitHub Pages の しずかな ページ なので、かぎ を おけない／こどもの にゅうりょくを そとに おくらない ため）
- じんぶつ ごとに **いちにんしょう・ごび・こえ（たかさ・はやさ）** を かえて います。
  ひみこ「わらわ…じゃ」、むらさきしきぶ「わたくし…ですわ」、ひでよし「…だがや」、りょうま「…ぜよ」、エジソン「ぼく…さ！」など。
- **でんせつ と たしかな はなし を わける**: 「ぞうりを あたためた」「10にんの はなしを きいた」「ほととぎす」などは「…と いわれて いる」「のちの ひとが つくった」と はっきり いいます。
- **いいにくい ことも ごまかさない**: ひでよし の ちょうせん しゅっぺい、のぐちひでよ の おかねの こと や まちがった はっけん、アインシュタイン の げんばく への こうかい など。
- **いきた じだいを まもる**: 「スマホ しってる？」には その ひとらしく おどろき、ほかの じんぶつ の ことを きくと、
  いきた ねんだい から「わしより 300ねん あとの ものじゃな、しらぬ！」のように こたえます（know に かいた しりあい は とくべつな こたえ）。
- 「ほんものなの？」と きくと、なりきり で ある ことを しょうじきに いいます。

## あそびかた

1. はなしたい ひとを えらぶ（むかし じゅんに ならんで いる。🗾にほん／🌍せかい で しぼれる）。
2. したの チップ（「いちばんの しごとは？」「やすけって だれ？」「ひでよしを しってる？」…）を おすか、じぶんで しつもんを かく。🎤 で こえ でも きける（つかえる ブラウザ だけ）。
3. 📜 しらべる で プロフィール（ねんだい・やった こと 3つ）。

きける こと（だれ でも）: だれ？・しごと・こどもの ころ・たべもの・しゅみ・かぞく・なかま/ライバル・たいへん だった こと・ことば・じだいの くらし・さいご・ひとこと・スマホ（いまの もの）・なんさい？・あいさつ。
それに じんぶつ ごとの とくべつな わだい（やまたいこくは どこ？／かがみもじ／ランプの ひと／にほんの たけ／したを だした しゃしん…）。

## しくみ

- `talk.js`: しつもんを ひらがなに そろえて、キーワードの うち **いちばん ながく あった わだい** を えらぶ。じぶんの なまえ は とりのぞき、ほかの じんぶつの なまえ が あれば その ひとの はなし。
  おなじ わだいを くりかえすと つぎの こたえ。わからない ときは その ひとらしく「わからぬ」と いって、チップで きける ことを だす。
- チップは まだ きいて いない わだい から 3つ。おしていけば ぜんぶの わだいに たどりつける。
- よみあげ は speechSynthesis（ja-JP）で、じんぶつ ごとに pitch / rate を かえる。しゃべる あいだ くちが うごく。
- 🗣 よみあげ と 🎵 こうかおん（WebAudio の ごうせいおん）は べつべつに オン/オフ。しつもん した かず・せってい は localStorage（try/catch）。

## じんぶつ を ふやす

`people.js` に 1にん ぶん たす（id・name・born/died・きほんの わだい 13こ＋real・ageLine・earlier/later/same・dunno・facts・look）。
漢字には かならず `[漢字|かんじ]` の ふりがな。`node tools/rekishi-talk/test.js` が たりない もの・ふりがな を しらべます。

## たしかめかた

```bash
node tools/rekishi-talk/test.js
node tools/rekishi-talk/check.js /tmp/shots
```
