# かんじすたんしょん

首都圏の駅名を入り口にして、**同じ漢字の「べつの読み方」** をおぼえる漢字学習ゲームです。
駅名そのものは読める子（→ [えきスタンプラリー](../eki-stamp-rally/) を卒業したくらい）が、
そこから小学校で習う一般的な読みや、中学受験で頻出の読みへ進むことをねらっています。

**書き取りはやりません。読みだけに特化しています。**

## あそびかた

`index.html` をブラウザで開くだけであそべます（ビルドやサーバーは不要）。

1. **むずかしさ** を「やさしい／ふつう／ちゅうじゅ」から選ぶ。
2. **路線** を選ぶと、その路線を始発から終点まで1駅ずつ進むすごろくが始まります。
3. 駅に着くたびに 2問。
   - **第1問**：この駅なんて読む？（駅名のよみを4択）
   - **第2問**：その駅名に使われている漢字の **べつの読み** を4択
     （例：大森の「大」→「大人」はなんて読む？）
4. 第2問に正解すると、その漢字が **キャラクターとして仲間になり**、
   読みをおぼえるたびに ★ が増えてレベルアップします（★3でほっぺ、★4でぼうし、★5で王冠）。
5. 終点まで行くと完走。とちゅうでやめても進みは保存され、次にその路線を選ぶと続きから始まります
   （`⟲` ボタンで最初から）。

まちがえても止まりません。正しい読みとふりがなを見せてから次の駅へ進みます。

## キャラクターの個性（いまは小学1年の40字）

小1の40字には、1字ずつ **なまえ・せりふ・見た目** をつけています。

- **見た目**：漢字の意味に合わせた背景（川は波、山は山なみ、町はビル、学は本…）と、
  表情のちがい（目はキラキラ＋めがね、山じいは目をとじている、田んぼはねむそう…）
- **せりふ**：問題に出てきたとき／正解したとき／まちがえたときで変わります
- **ずかん**：タップするとキャラが自己紹介します

例：

| 漢字 | なまえ | 出てきたときの ひとこと |
| --- | --- | --- |
| 川 | かわたろう | ぼく、ずーっと ながれて いるよ |
| 目 | めめ | なんでも よーく みえるんだ |
| 山 | やまじい | どっしり かまえて おるぞ |
| 王 | おうさま | われこそ おうで ある！ |

小2〜中学の166字は共通デザインのままです。増やすときは `chara.js` にエントリを足すだけ
（`app.js` の変更は不要）。背景の絵は `app.js` の `SCENES`、頭のかざりは `OVERLAYS`、
目と口は `EYES` / `MOUTHS` にあるものをキーで指定します。

## 画面に出るじょうほう

- **学年バッジ**：「しょう3で ならう」「ちゅうがくで ならう」を漢字ごとに表示
- **音・訓**：その漢字のおもな読み
- **この かんじの えき**：同じ漢字を使う駅名（例：東 → 東京・東小金井・東船橋…）
- **ずかん**：集めた漢字キャラを学年別に一覧。タップすると読み一覧（未習得は `？？？`）と、
  その漢字を使う駅名がふりがな付きで見られます。

## しくみのメモ

- 出題する漢字と読みは、**まだおぼえていない読み**・**選んだむずかしさに合う読み**を優先して選びます。
  駅名と同じ読み（例：大森の「大」に対する「大きい」）は、点数を下げてなるべく避けます。
- まちがいの選択肢は、**まず同じ漢字の別の読み**（大人 → おおきい・だいがく…）から作り、
  足りない分を似た長さの読みから補います。ぜんぶ実在する読みなので、消去法だけでは解けません。
- キャラの絵は 1枚の SVG を組み立てて描いている（画像ファイルなし）。背景は漢字の下に
  うすく敷くだけなので、字が読みにくくなることはない。
- 頭にのるかざり（リボン・角帽・アホ毛）は、★4以上でぼうし・王冠に場所をゆずる。
- 音は WebAudio の合成音のみ（音声ファイルなし）。右上の「おと」でオン/オフ。
- 進みぐあいは `localStorage`（キー `kanji-station-v1`）に保存。ずかんの「きろくを けす」で消せます。
- 外部ライブラリ・CDN は使っていません。
