# ひきざん ボウリング 🎳

ボールを ころがして ピンを たおし、「のこりは いくつ？」を 目で見て 10までの ひきざんを つかむ あそび。
対象は 5才くらい。1ゲーム 5投（1〜3分）。外部ライブラリなし・`index.html` だけで完結（Canvas 描画・WebAudio 合成音）。

公開URL: https://kisi1554.github.io/Pages/hikizan-bowling/

## あそびかた

1. ピンが ならぶ。レーンを ゆびで うえに スワイプして ボールを ころがす（よこに ふると ねらいが かわる）。
2. たおれた かずと 式（`10 − 3 = ？`）が でる。
3. 0〜10 の すうじボタンで こたえる。まちがえても なんどでも やりなおせる。
4. 5投で おしまい。1かいめで せいかいした かずで ⭐（5→3こ、3〜4→2こ、ほか→1こ）。

## レベル

| レベル | なかみ | まちがえた とき |
| --- | --- | --- |
| 1 みて かぞえる | ピン10本。のこりの ピンが みえる。ピンを タッチすると 1,2,3… と ばんごうが つく | いっしょに かぞえる（ばんごうが じゅんに つく） |
| 2 かくれた ピン | ピン 5〜10本（まいかい かわる）。たおれた あと カーテンで かくれる。せいかい すると ひらいて かぞえる | ●の ならびで たおれた ぶんを ×で しめす |
| 3 なんぼん たおれた？ | 「のこり 4ほん。なんぼん たおれた？」→ `10 − ？ = 4` | たおれた ばしょを てんせんで だして かぞえる |

2かい まちがえると こたえの ボタンが ひかる。

## しくみ

- たおれる本数は スワイプの物理ではなく 出題として きめる（`pickKnock`）。
  さいきん 40問の こたえを レベルごとに おぼえ、でていない こたえほど でやすく、おなじゲーム内の かさなりや れんぞくを へらす。
  0（ストライク `10 − 10 = 0`）や ガター（`10 − 0 = 10`）も でる。
- どの ピンが たおれるかは ねらった いちに ちかい じゅん。ボールは たおれる ピンの まんなかへ むかう（0本なら ガターへ）。
- 保存（localStorage `hikizan-bowling-v1`）: おと オン/オフ、レベルごとの さいこう ⭐、あつめた ⭐、出題の りれき。
- 音は WebAudio の合成音のみ（ころがる・たおれる・せいかい・ストライク）。タイトルと ゲーム中に 🔊/🔇。
