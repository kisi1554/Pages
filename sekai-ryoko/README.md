# せかい いっしゅう りょこう ✈️

**ひこうきで せかいの くにへ（41か国 ＋ ハワイ）。あいさつ・くらし・じさ を しって、パスポートに スタンプ。**
年長〜小学生むけ。[こっき たんけん](../kokki-tanken/) の ちずデータと こっきの え を つかって
見た目を そろえています。こちらは こっきでは なく「たびと くらし」が 主役です。

`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・CDN なし、オフラインで うごく）。

公開URL: https://kisi1554.github.io/Pages/sekai-ryoko/

---

## あそびかた

1. **しゅっぱつ** … はねだ／なりた を えらび、せかいちず（たいへいようが まんなかの、にほんの がっこうと おなじ むき）で
   いきたい 国を タップ。小さい 国は 首都の ● の ちかく（30px）でも えらべます。ちいきの タブで ちずを おおきく できます。
   「しゅっぱつ！」で ひこうきが だいけん こうろ（ちきゅうの うえの いちばん ちかい みち）に そって とびます。
   じかんの めやすは きょり÷時速820km＋のりおり で だした「やく ○じかん」です（のりかえ便は もっと かかる、と ひとこと）。
2. **とうちゃく** … くうこうの チャイム → パスポートに スタンプ「ぽん」。げんちの いまの じこくも でます。
3. **まち** … その 国の まちの え（そらの いろは げんちの いまの じかんで ひる・ゆうがた・よるに かわる）。
   **？** を タップして 5つ みつける：
   - 💬 **あいさつ**「こんにちは」「ありがとう」… げんちの もじ と カタカナ。🔈で よみあげ。
     その ことばの こえ（speechSynthesis）が きかいに あれば その こえで げんちの もじを、
     なければ カタカナを にほんごの こえで よみます。
   - 🍽️ たべもの・🏛️ たてもの（SVG の オリジナルの え）・🐾 どうぶつ・🚆 のりもの（こうそく てつどう・とざん てつどう など 一般名）
   - 💡 まめちしき（ふりがな つき）
   - 5つ ぜんぶ みつけると 🎁 **おみやげ**。
4. **じさ とけい** … にほんと その国の アナログどけいを ならべて 1びょうごとに うごく。日付が ちがえば「まえの ひ／つぎの ひ」。
   ちずには **いまの じこくで けいさんした ひると よるの さかいめ**（よるの かげ）を えがき、にほんと その国の じこくを だします。
   クイズ「にほんが あさ 7じの とき、この国は なんじ？」（3たく。じさを ぎゃくに した こたえ などが まざる）。
5. **ミッション** … せきどうを こえよう／みなみはんきゅうで ペンギンに あおう／6つの しゅうに いこう／
   じさが いちばん おおきい くにへ／ひづけが ちがう くにに つこう／じさクイズ 5もん／42かしょ ぜんぶ。
   - 「6つの 大陸」は、がっこうでは ユーラシア・アフリカ・北アメリカ・南アメリカ・オーストラリア・南極 の 6つ を さします。
     南極には 行けないので、ミッションは **6つの 州（しゅう）**（アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニア）に して、
     画面で その ちがいを ひとこと 説明しています。
   - 「じさが いちばん おおきい くに」は 固定せず、**その ときの じさで** えらびます（なつじかんで かわるため）。
     いまは ハワイ（19じかん おそい。ハワイは なつじかん なし）。
6. **パスポート**（スタンプちょう）・**おみやげ ずかん**。

### せってい・ほぞん

- 🔊 おと（効果音と BGM）・🗣️ よみあげ を それぞれ オン/オフ。
- 効果音（りりく・ちゃくりく・スタンプ・くうこうの チャイム）と BGM は WebAudio の ごうせい音。
  BGM は ちいきの 音階「ふう」（5音音階・ペロッグ ふう・インドの ラーガ ふう・ヒジャーズ ふう・ドリア ふう など）で
  国の 番号から メロディを つくる オリジナル。ほんものの 曲は つかっていません。
- スタンプ・みつけた もの・おみやげ・ミッションは localStorage（`sekai-ryoko-v1`、try/catch つき）。

## えらんだ 41か国 ＋ ハワイ（42かしょ）

日本と つながりの ふかい 国を 中心に、6つの 州から。

| 州 | 国 |
| --- | --- |
| アジア（10） | 韓国・中国・インド・タイ・ベトナム・インドネシア・フィリピン・モンゴル・トルコ・ネパール |
| ヨーロッパ（12） | イギリス・フランス・ドイツ・イタリア・スペイン・オランダ・スイス・フィンランド・ノルウェー・アイスランド・ギリシャ・ロシア |
| アフリカ（7） | エジプト・モロッコ・エチオピア・タンザニア・南アフリカ・ガーナ・マダガスカル |
| 北アメリカ（5） | アメリカ・カナダ・メキシコ・キューバ・パナマ |
| 南アメリカ（5） | ブラジル・アルゼンチン・チリ・ペルー・コロンビア |
| オセアニア（2＋1） | オーストラリア・ニュージーランド・ハワイ（アメリカの 州） |

州の わけかたは こっき たんけん と おなじ（トルコは アジア、ロシアは ヨーロッパ）。

- **ハワイ** は 国では なく **アメリカの 州**。画面では「アメリカの 州」「州都 ホノルル」と 書き、はたは ハワイ州旗。
  ばしょが たいへいようの まんなか（ポリネシア）なので、ちずの タブは オセアニアに 入れた。
  地図データ（110m）では ハワイの しまは アメリカの かたちの 一部なので、ホノルルの ● の ちかくを タップすると ハワイを えらぶ。
  時刻帯は Pacific/Honolulu（なつじかん なし。日本より 19じかん おそい）。
- **アイスランド** には てつどうが ないので、のりものは バス。時刻帯は Atlantic/Reykjavik（一年中 UTC と おなじ）。

## 正確さと 出典

- **国名・首都** … 外務省「国・地域」各国 基礎データ（https://www.mofa.go.jp/mofaj/area/index.html）の 表記に あわせた。
  首都が わかりにくい 国：オランダ＝アムステルダム（政府は ハーグ）、タンザニア＝ドドマ、南アフリカ＝プレトリア
  （行政。立法・司法は べつの 都市）、インドネシア＝ジャカルタ（移転計画あり）。
  ※ この アプリを つくった 環境からは 外務省の サイトに アクセス できなかった（403）ため、
  記載は 作成時の 知識に よる。公開後に 外務省の ページで 見なおす こと。
- **あいさつ** … 公用語が 複数 ある 国は 代表的な ことばを 1つ えらび、画面に「○○ご」と 書いた
  （例：インド＝ヒンディー語、スイス＝ドイツ語（スイスの いいかた Grüezi）、南アフリカ＝ズールー語（公用語は 12）、
  カナダ＝英語（フランス語も）、ニュージーランド＝こんにちは は マオリ語 Kia ora、モロッコ＝アラビア語（アマジグ語も公用語））。
  カタカナは 日本で ふつうに 書かれる よみに した。
- **時刻** … 数字の じさは もたず、`Intl.DateTimeFormat` に **IANA の 時刻帯名**（tz database, https://www.iana.org/time-zones）を
  わたして その ときの げんち時刻を けいさん（なつじかんも 自動）。
  時刻帯が いくつも ある 国（ロシア・アメリカ・カナダ・メキシコ・ブラジル・オーストラリア・インドネシア・モンゴル・チリ・
  スペイン・フランス・オランダ・ニュージーランド）は **首都の 時刻帯** を つかい、「国の 中でも 時刻が ちがう」と ひとこと 出す。
  首都と 時刻帯名が ちがう もの：ワシントンD.C.＝America/New_York、オタワ＝America/Toronto、ブラジリア＝America/Sao_Paulo、
  キャンベラ＝Australia/Sydney、ドドマ＝Africa/Dar_es_Salaam、ウェリントン＝Pacific/Auckland、ハノイ＝Asia/Ho_Chi_Minh。
- **ひると よるの さかいめ** … たいようの まうえの 地点を かんたんな 天文の 式（太陽の 赤緯・均時差）で けいさん。誤差は 1度 ていど。
- 国境や 地名で あらそいの ある 地域は とりあげていない。国の しょうかいは「〜も 〜も ある」「ちほうで ちがう」など、
  くらしの 多様さが つたわる 書きかたに した（人の え は 国ごとに ふくの いろを かえるだけで、すがたで 国を きめつけない）。
- ちず … Natural Earth 1:110m（パブリックドメイン）。`geo.js` は `kokki-tanken/countries.js` の コピー。
