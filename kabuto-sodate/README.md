# カブトムシ そだて 🪲

ほんとうの 日にちで、カブトムシを **たまご → 1れい → 2れい → 3れい ようちゅう → さなぎ → せいちゅう** まで
そだてる アプリです。`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・画像ファイルなし）。

公開URL: https://kisi1554.github.io/Pages/kabuto-sodate/

## そだちかた

- 1日（端末の ローカル日付）に おせわを 1回 以上 すると、**つぎの日に** 成長ポイント +1。
  「経過時間」と「その日の おせわ」の りょうほうが そろって はじめて そだちます。
- ポイントで 段階が すすみます（`data.js` の `STAGES[].need` で 調整）:
  たまご 1・1れい 1・2れい 1・3れい 2・さなぎ 2 → 合計7。おせわを つづけて やく7日で せいちゅう。
- おせわを しない日は そだつのが とまるだけ。**しにません**。3日 あくと「さみしかったよ…」と でるだけです。
- 端末の 時計が もどっても こわれません（最後に みた 時刻・日付より まえは 無視）。

## おせわ

| ボタン | できる とき | こうか |
| --- | --- | --- |
| 🟫 マットこうかん | ようちゅう（1〜3れい） | ふんを ぜんぶ そうじ。ふんは 1つずつ タップでも そうじ できる |
| 💧 きりふき | いつでも | しめりけメーターが ふえる（時間で へる）。シュッと 音 |
| 🍯 ゼリー | せいちゅう | おなかメーターが ふえる。ゼリーまで あるいて もぐもぐ |

さなぎの あいだは「いまは さわらないで そっと みまもろう」と でて、マットこうかんは できません
（さなぎの へやが こわれないように、という 豆知識）。

## せいちゅうに なったら

- オス・メスは ランダム。大きさは おせわの 回数（1日 3回まで かぞえる）で すこし かわります
  （オス 50〜78mm・メス 40〜54mm。`CONFIG.size`）。
- なまえを つけて **ずかんに とうろく** → 「つぎの たまごを はじめる」が できます。
- ずかんには なまえ・オス/メス・大きさ・そだてた 日付・おせわした 日数が のこります。
- ひる（6〜18時）は きの まえで おやすみ、よるは うごきまわります（夜行性）。

## 画面

- 飼育ケースの 断面図（Canvas 描画）。土の なかを ようちゅうが ゆっくり うごきます。
- いきものを タップすると アップ表示と 豆知識。段階ごとの 豆知識カード（ふりがなつき）。
- 効果音は WebAudio 合成。右上 🔊 で オン/オフ。

## 保存

localStorage `kabuto-sodate-v1` に、開始日時・段階・成長ポイント・おせわ記録・メーター・ずかん を保存（try/catch）。

## はやおくり（動作確認用）

`index.html?hayaokuri=1` で **1日 ＝ 1分**。画面に「はやおくり中」と でます。
保存先は べつ（`kabuto-sodate-hayaokuri-v1`）なので、ほんものの そだてには 影響しません。
