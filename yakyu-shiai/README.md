# やきゅう しあい ⚾

CPU や かぞくと やきゅうの しあいを する ゲームです（年長〜小学生むけ）。
`index.html` を ブラウザで ひらくだけで あそべます（がいぶ ライブラリ なし・えは ぜんぶ Canvas で コードで かく）。

## あそびかた

| モード | ないよう |
| --- | --- |
| 🤖 1にん | CPU と しあい。さきに うつ／あとで うつ、CPU の つよさ（🐣 よわい・🐥 ふつう・🦅 つよい）を えらぶ |
| 👫 2にん | タブレット 1だいで こうたい。こうげきと しゅびが かわる たびに「タブレットを まわしてね 🔄」と あんない。ピッチャーが えらぶ ときは「バッターは みないでね 🙈」 |
| 📖 おけいこ | ストライク → ボール → フォアボール → さんしん → うって はしる（るい）→ とくてん → フライアウト・チェンジ を、ほんとうの ばめんで 1つずつ |

- イニングは 3・6・9かい。さいごの かいで どうてんなら えんちょう なしで **ひきわけ**。
- チームは どうぶつ・でんしゃ・きょうりゅう・おかし の 4つ（じつざいの きゅうだん・せんしゅでは ない）。
  せんしゅ 9にんに だりょく・ミート・あし・かた（★1〜5）。チームの「i」で みられる。
- キャラクターは `batting-center/` の くま・ねこ・ロボと おなじ かきかた（`chara.js`）。め・くち・ほっぺ・ぼうし・からだは おなじで、
  かおの しゅるい（うさぎ・りす・ライオン・ぞう・くま・きつね・さる・パンダ・ねこ／でんしゃの まえ／きょうりゅう・とり／おかし）を せんしゅ ごとに かく。
  ひょうじょうも おなじ（ヒットで よろこぶ、さんしん・アウトで しょんぼり、ファウルで あせあせ）。

### こうげき（バッティングセンターと おなじ タイミング）

- ボールが きたら がめんを タップ（スペース／Enter でも OK）。きいろい わが ちいさく なって ボールと かさなる ころが ぴったり。
- タイミングの ずれで あたりが きまる（`batting-center/` と おなじ かんがえかた）:
  タップから 0.06びょう で バットに あたり、ずれ 0.045びょう いない＝ジャスト、0.095＝ヒットせい、0.15＝ファウル、それより ずれると からぶり。
  ゆっくりの たまほど はばが ひろい。ミートの たかい せんしゅも はばが ひろい。
- はやく うつと ひっぱり（レフト）、おそいと ながし（ライト）。**がめんの ひだりを タップ → レフトへ、みぎ → ライトへ** も まざる。
- だせきの がめんは `batting-center/` と おなじ（キャッチャーの うしろ・めの たかさの カメラ、てんせんの わく、
  のこり 0.8びょう から ちぢむ きいろい わ、おなじ スイングの うごき）。うつと「ぴったり！／ちょっと はやい／ちょっと おそい」が でる。
- うった あとは **だせきの めせん** の まま カメラが うしろに さがって ボールを おいかける。やしゅが はしって
  「キャッチ！」か「とれない！」かが みえる。バッターが 1るいへ はしりだしたら **1るいの カメラ**（1るいの ななめ うしろ・たかい ところ）に
  きりかわり、1るいでの「アウト！／セーフ！」を みせる。みぎうえに うえから みた ちいさな ちず。
- ボールだまは みのがせば ボール。**バント** ボタン（タップ なしで あてる。はずれた たまは ひく）、**とうるい** ボタン（つぎの 1きゅうで はしる）。

### しゅび

- たま（まっすぐ・カーブ・スロー）を えらんで、9マスの コースを タップすると なげる。すみを ねらうと ボールに なりやすい。
- うたれたら やしゅが じどうで おいかける。ゴロを とったら「どこに なげる？」→ 1るい・2るい・3るい・ホーム・おまかせ を タップ。
  「しゅびの なげる ところも おまかせ」に チェックすると ぜんぶ じどう。

### がめん

- うえ: スコア（いま うって いる チームに わく）、B・S・O、ランナー。📋 で スコアボード（イニングごとの とくてん・ごうけい・ヒット）。
- じっきょう テキスト（「うったー！ センター まえ ヒット！」）。🗣️ で こえ（speechSynthesis が あれば）オン／オフ。
- しあいの あとに だしゃ せいせき（だすう・あんだ・だてん・ホームラン・フォアボール）。

## おと

WebAudio の ごうせいおんだけ: カキーン・パシッ（ミット）・かんせい・ブラスバンド ふう の おうえん（にんげんの チームが チャンスの とき）・ファンファーレ・ホイッスル。
🔊 で オン／オフ（ほぞん される）。

## ほぞん（localStorage `yakyu-shiai-v1`、try/catch つき）

せってい（おと・こえ・チーム・つよさ・イニング）、CPU との かち・まけ・ひきわけ（つよさ ごと）、
にんげんが つかった チームの せんしゅ つうさん（だすう・あんだ・だてん・ホームラン）。メニューの 🏆 せいせき で みられる。

### シミュレーションの しくみ（`sim.js`）

- だきゅう: タイミング・タップいち・のうりょく から はやさ・かくど・むき を だし、うえから みた 2D で とばす
  （くうきの ていこうつき の ほうぶつせん → じめんで ころがって へる → フェンス）。フェンスを こえたら ホームラン。
- やしゅ: それぞれの いち・あしの はやさ・はんのう から、いちばん はやく ボールに とどく ひとが とる。
  じめんに つく まえ なら フライ／ライナー アウト。
- ランナー: あしの はやさで はしる じかん と、やしゅが なげて とどく じかん を くらべて、すすむ るいを じぶんで きめる。
  フライでは タッチアップ（オート）。しゅびは アウトに できる いちばん まえの るいへ なげ、まにあえば ゲッツー。
- ルール: フォースアウト、3アウトで こうたい、おしだし、サヨナラ（あとこうの さいごの かいで リードした しゅんかんに おわり。
  ホームラン いがいは かちこしの 1てん まで）、さいごの かいの おもてで あとこうが かっていれば うらは しない、
  3つめの アウトが フォースアウト なら とくてん なし、ぎせいフライ・バントは だすうに いれない、たまに エラー。

```bash
node --test yakyu-shiai/tests/*.test.js
NODE_PATH=$(npm root -g) node yakyu-shiai/tests/e2e.playwright.cjs /tmp/yakyu-shots
```

フォアボール・さんしん・ゲッツー・エラーも ときどき でる ように ちょうせい して ある（テストで たしかめる）。
