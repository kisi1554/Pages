# ちょくつう ぶらり でんしゃ 🔗

1つの 電車が、とちゅうの 駅から べつの 会社の 線路に そのまま 入って 走る **「ちょくつう うんてん（のりいれ）」** を、
ろせんずを たどって 知る アプリ（5さい〜）。シリーズ「ろせんず を ふかく 知る」の 4本め（ちょくつう）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。音は WebAudio の 合成音、🔊 で オン/オフ。🗣️ で よみあげ）。

## あそびかた
| モード | なかみ |
| --- | --- |
| 🚃 たどって あてる | 元町・中華街を 出発（行き先は「？？？」）。会社の さかい目（横浜・渋谷）で「つぎは どの 線？」、小竹向原では ポイントの やじるしを 見て どっちへ 行くかを えらぶ。さいごに どこに つくかを 当てると 行き先表示が パタパタ かわる。コース1: 小川町 行き（東武東上線）／コース2: 飯能 行き（西武池袋線） |
| 🔄 ぎゃく モード | 行き先表示を 見て、とおる 線を じゅんばんに タッチ（チップか ろせんずの 線）。小川町 行き・飯能 行き・飯能 → 元町・中華街 行き・海老名 → 新宿方面 |
| 🎁 ボーナス そうてつ | 海老名から。西谷・羽沢横浜国大・日吉の ポイント、新横浜の さかい目。JR直通（新宿方面）と 東急直通（東横線 渋谷方面） |

- 線路が つながって いる ちょくつう先は 実線、のりかえが いる ほかの 線は てんせん（ヒント）。
- 会社の さかい目の 駅は 2いろの わ で かく。
- わらい（答えあわせの あと）: 運転士さんの バトンタッチ「よろしく〜」「まかせて〜」パチン／
  ねむっていた ひつじが 起きて「ここ どこ〜？」／とおくまで 走って でんしゃが おなか ぺこぺこ。
- まなび カード 3まい: ちょくつう うんてん／さかい目で こうたい／行き先表示の 読みかた。
- まちがいの かずで ⭐（0回 ⭐⭐⭐・1〜2回 ⭐⭐・それ以上 ⭐）。保存は localStorage（`chokutsu-burari-v1`）。

## データ（いちばん 大事）
- `index.html` の `/*DATA-START*/` 〜 `/*DATA-END*/` の 1か所（駅・線・てんせんの 線・さかい目・コース）。
- 2026-11 に ja.wikipedia（みなとみらい線／東急東横線／東京メトロ副都心線／西武有楽町線／西武池袋線／東武東上本線／
  相鉄新横浜線／東急新横浜線）で たしかめた（各社の 公式サイトは この 環境から 読めなかった）:
  - みなとみらい線 ⇄ 東横線は 横浜。運転は 東急に 委託で、横浜で 乗務員は 交代しない。
  - 東横線 ⇄ 副都心線は 渋谷。副都心線は 正式には 小竹向原〜渋谷（和光市〜小竹向原は 有楽町線と おなじ 線路。案内上は 和光市〜渋谷）。
  - 東武東上線とは 和光市、西武とは 小竹向原（西武有楽町線 小竹向原–新桜台–練馬 → 西武池袋線）。小竹向原で 乗務員交代。
  - 元町・中華街からの 直通先の 例として 小川町・飯能 を 使う（川越市・森林公園は 出典で 確かめきれなかったので 使わない）。
  - 相鉄: 西谷 → 相鉄新横浜線 → 羽沢横浜国大（JR 直通の わかれ目）→ 新横浜（相鉄／東急の さかい目）→ 東急新横浜線 → 日吉 → 東横線／目黒線。
    相鉄から 東横線・副都心線を とおって 東武東上線まで 行く 電車が ある（西武池袋線へは 定期列車なし）。
  - 行き先は ダイヤで かわるので 画面では「たとえば」と して あつかう。
- 運転士さんの こうたい えんしゅつは 渋谷・小竹向原・和光市。横浜は「こうたい しない」と 表示。
- チェック: `node tools/chokutsu-burari/check.js`（線の つながり、正解が 1つ、ポイントの むき、行き先と 終点）。

鉄道会社の ロゴ・マーク・公式路線図デザイン・発車メロディは 使わない。電車・ひつじ・運転士さん・ろせんずの 絵は オリジナル。
地図の かきかた（実線・とちゅう駅の ○・てんせんの ほかの線・ひらがな ラベル）は `yokohama-norikae/` に そろえた。
