# ことばの たしざん ➕

**2つの ことばが くっついて あたらしい ことばに なる（複合語）／くっつくと おとが かわる（あめ＋かさ＝あまがさ）** を あそんで しる（5さい〜）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. 2まいの え カード（🌧️ あめ ＋ 🌂 かさ）が でる。
2. くっつけた ことばを 3つから えらぶ（あめかさ・あめがさ・**あまがさ**）。
3. せいかい → 2まいが まんなかに よって「がっちゃん」と 合体し、☔ の カードに かわる。
   かわった おとは ピンクの なみせんで しめし、「あめ → あま に かわったよ」「かさ に てんてんで がさ！」と、漢字（ふりがなつき）を みせる。
4. まちがえても なんどでも えらびなおせる。2かい まちがえると こたえが ひかる。
5. 5もんで 1かい（1〜3ぷん）。1かいめで あてた かずで ⭐ が 1〜3こ。

## モード

| モード | なかみ |
| --- | --- |
| レベル1（20語） | おとが かわらない: ゆきだるま、ゆびわ、はなたば、にわとり、えほん … |
| レベル2（16語） | にごる（連濁）: てがみ、はなび、ほんだな、めぐすり、あおぞら、てぶくろ … |
| レベル3（15語） | おとが かわる: あまがさ、かざぐるま、ながぐつ、こかげ、まぶた、おりがみ、のりもの … |
| ひきざん | 「ゆきだるま」を 2つに わける。くっついた あとの おと（あま・がさ）の カードが まぎれて いて「もとの ことば」を さがす |
| じゆう | すきな 2まいを くっつけて ない ことば（ねこでんしゃ）を つくり、え と いっしょに 💾 ほぞん（🖼️ さくひん で みられる・けせる） |
| ずかん | ただしく くっつけた ことば（51語）が ならぶ |

読み・表記は 一般的な 国語辞典の 見出しに あわせて いる（辞書の 原本との 照合は まだ）。データは `index.html` の `W` 配列（`a+b`、くっついた ときの おと `sa`/`sb`、まちがいの こたえ `x`、漢字 `k`）。

## ほぞん

localStorage（`kotoba-tashizan-v1`）: あつめた ことば・モードごとの ⭐・じゆうの さくひん（さいだい 60）・おとの オン/オフ。
