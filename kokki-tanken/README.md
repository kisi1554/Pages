# こっき たんけん 🚩 〜せかいの 47か国〜

**47都道府県を ぜんぶ おぼえた 5さいの 「つぎの 47」。**
せかいの くにから 47か国を えらび、6つの たいりく（アジア・ヨーロッパ・アフリカ・
きたアメリカ・みなみアメリカ・オセアニア）に わけて、**こっき・ばしょ・おおきさ** を
あそびながら おぼえます。

`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし、オフラインで動く）。

公開URL: https://kisi1554.github.io/Pages/kokki-tanken/

---

## なぜ これが「つぎ」なのか

都道府県を ぜんぶ 言える子は、すでに つぎの 力を もっています。

- **ちずの なかで ばしょを さがす力**（どこに あるか・となりは どこか）
- **かたちや しるしを 見わける力**（県の かたち・形の ちがい）
- **47こ という かずを まとめて おぼえきる 体験**

日本の 中の つぎの 一歩（県庁所在地・地方・地形・名産）は
[日本地理たんけん](../nihon-chiri-tanken/) で、県の かたちは [しろっとクイズ](../shirotto-quiz/) で
もう あそべます。そこで このアプリは **スケールを 日本 → せかい に ひろげます**。

| 都道府県で やったこと | こっきたんけんで やること |
| --- | --- |
| 47都道府県 | せかいの **47か国**（おなじ かずに して「つぎの 47」と 感じられるように） |
| 8つの 地方 | **6つの たいりく**（くにを まとめる 上の 階層） |
| 県の かたち | **こっき**（5さいが とくい な 色・もよう・かたちの 見わけ） |
| 県の ばしょ | **せかいちずを タップ** |
| ― | **おおきさ くらべ**。小さい国は「きゅうしゅうと おなじくらい」「ほっかいどう 2こぶん」のように、**もう しっている 日本の 島や 県を ものさし** にする。大きい国は「にほんが 26こ はいる」と かずに つなげる |

字は ひらがな・カタカナ だけで よめます（タイトルの「都道府県」「国」は ふりがな つき）。

## あそびかた

### 🗺️ たいりくを えらんで たんけん

1. **おぼえる** … 1か国ずつ カードを めくる（よこスワイプでも OK）。
   こっき・なまえ（よみあげ）・ゆうめいな もの・**こっきの ひみつ**（見わけかたの ヒント）・
   ちずの どこに あるか・**にほんと ならべた シルエット**。
2. **クイズ** … 6〜8もん。4しゅるいの もんだいが まざって でます。

| もんだい | こたえかた |
| --- | --- |
| この こっきは どこの くに？ | なまえを 3つから えらぶ |
| 「〇〇」の こっきは どれ？ | こっきを 4つから えらぶ（デンマークと スイス、など にた ものが まざる） |
| この こっきの くには どこ？ | **ちずを タップ**（小さい 国は ちかくを タップしても えらべる） |
| ひかっている くにの こっきは どれ？ | こっきを 3つから えらぶ |

- まちがえても なんどでも やりなおせます。まちがえた こたえは「それは 〇〇の こっき」と おしえて くれます。
- 4つから えらぶ ときは 2かい、ちずでは 3かい まちがえると こたえが ひかります。
- **まだ おぼえていない 国ほど よく でます**（ほしが すくない 国は 最大4ばい）。
- いっぱつ せいかい ＝ ◎、やりなおして せいかい ＝ ○。けっかで ★1〜3 の メダル。

### 🎒 ほかの あそび

| あそび | ないよう |
| --- | --- |
| 📔 こっき ずかん | あつめた こっきが たまる。まだの 国は「？」。タップで カード |
| 🔍 ちずで さがす | せかい／たいりくごとの ちずで 国を タップすると、こっきと なまえ |
| 📏 どっちが おおきい？ | 2つの 国の ひろさくらべ（5もん）。こたえあわせで **にほんと 3つ ならべた シルエット** |
| 🌍 ぜんぶ ミックス | 47か国 ぜんぶから 10もん（えらぶ ものは 4つ） |

### せってい

- 🔊 おと（WebAudio の ごうせい音）・🗣️ こえ（ブラウザの よみあげ）を それぞれ オン/オフ。
- すすみぐあいは localStorage（`kokki-tanken-v1`）に ほぞん。

### こっきの え について

- たてよこの 比は できるだけ ほんものに あわせている（アメリカ 19:10、スイス 1:1、ネパールは 2まいの さんかく、など）。
- こまかい もんしょうは かんたんな え に している：メキシコ（わしと サボテン）、エジプト（わし）、
  モンゴル（ソヨンボ）、ブラジル（ほしの かず）。スペインは もんしょう なし（民間旗の かたち）。
  ペルーも もんしょう なしの 民間旗。

### ちず

- ミラー図法（たかい 緯度が のびすぎない）で SVG に えがく。国の 線は 画面上の 太さが かわらない。
- 47か国 いがいの りくは 1本の path に まとめて かるく している。
- たてながの 画面では、たいりくの 左右を 最大25% きって 大きく 見せる。
- ロシアの しるし（ひかる まる）は ヨーロッパの ちずでも 見えるよう モスクワの ちかくに おく。
