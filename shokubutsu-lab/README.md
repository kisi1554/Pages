# たねから はなまで ラボ 🌱

しょくぶつの **発芽・成長・花・たね** を、はやおくりの **じっけん** と **かんさつ** で学ぶ小学生むけ（小3〜小5 理科）アプリです。
`index.html` をブラウザで開くだけで動きます（ビルド・サーバー・外部ライブラリなし）。

- 文字は **ひらがな中心**。漢字は `{漢字|よみ}` で書いて、`app.js` の `ruby()` が ふりがな つきで表示
- 絵は **SVG をコードで描画**（`art.js`。画像ファイルなし）
- 音は **WebAudio の合成音のみ**（みずやり・にょきっ・はなが さく キラン）。右上の 🔊 でオン/オフ
- スタンプ・かんさつカードは **localStorage**（`shokubutsu-lab:v1`。読み書きは try/catch）

## 4つのモード

| モード | 学年 | なにをする | わかること |
| --- | --- | --- | --- |
| 🫘 めが でる | 小5 | インゲンマメを 5つのコップに まき、みず・くうき・おんど・ひかり・ひりょう を オン/オフ → ▶ 7日 | 発芽には **みず・くうき・てきとうな おんど** が必要。ひかり・ひりょう は いらない |
| ☀️ よく そだつ | 小5 | なえ 3つの ひかり・ひりょう を かえて ▶ 14日。1日ごとの くきの たかさ／のび／はの かず を棒グラフ | 成長には **日光と肥料** が関係する。ひかり なしは ひょろひょろ・黄色っぽい |
| 🌻 そだてる | 小3 | 7しゅるいから えらんで たね→め→ふたば→ほんば→(つる)→つぼみ→はな→み→たね を はやおくり。つちが かわくと 💧 みずやり。📝 かんさつカードに ものさしで はかった たかさ と はの かず を記録 | 育ち方の順序、たね・ふたば・ほんば・花・実の形 |
| 🌸 はな | 小5 | アサガオ・ヘチマ（おばな／めばな）の ぶぶんを タップで しらべる／クイズ。受粉じっけん（🖌️ ふで・🐝 はち で 花粉を めしべへ） | 花のつくり、受粉すると実ができ、しないと実ができない |

### 対照実験の判定（`data.js` の `compare()`）

2つのコップ（なえ）を えらぶと、条件の ちがいを数えて判定します。

- 0こ → 「じょうけんが おなじ」
- **2こ以上 → 「くらべられないよ」**（どれの せいか わからない）
- 1こ で 結果が ちがう → 「〇〇は ひつよう！」
- 1こ で どちらも めが でた → 「〇〇は いらない！」
- 1こ で どちらも めが でない → 「わからない」（ほかの条件が たりない。まちがって「いらない」と きめつけない）

じっさいに ありえない組み合わせは `fixCond()` で直します。

- 「くうき なし」＝ **みずに しずめる** なので みずは ある
- **れいぞうこの中は くらい** ので、ひかりは なしになる。へやの コップ（あかるい）と くらべると
  「おんど と ひかり の 2つが ちがう」→「へやの コップにも はこを かぶせよう」と教える（教科書の実験と同じ くふう）

### しょくぶつ（`data.js` の `PLANTS`）

アサガオ・ヒマワリ・ホウセンカ・ミニトマト・インゲンマメ・ヘチマ・ツルレイシ。
それぞれ たね・ふたば・ほんば・つる・花の色・実とたね の説明と、そだつ日数の めやす（地域・天気で かわる）を持ちます。
かんさつカードで数える「ほんばの かず」は、絵に描く まい数と同じです（テストで確認）。

## 結果表とテスト

じっけんの結果は `data.js` の表だけで決まります。

- `NEEDS` … 発芽に必要か（water/air/temp が true、light/fert が false）
- `GROWTH` … ひかり・ひりょう の組み合わせごとの 1日の のび・はの ふえかた・くきの太さ・色
- `makesFruit()` … 受粉したら実ができる。アサガオは おしべを とらないと 自分の花粉で受粉する

```bash
node --test shokubutsu-lab/tests/*.test.js          # 結果表・判定・絵（32とおり×32とおり の比較も ぜんぶ）
NODE_PATH=$(npm root -g) node shokubutsu-lab/tests/e2e.playwright.cjs [スクショ保存先]
                                                    # 390×844 と 1024×768 で 4モードを自動操作＋はみだしチェック
```

「ひかりが ないと 発芽しない」「ひりょうが ないと 発芽しない」と 判定される組み合わせが 1つも ないことを、
全組み合わせ（32×32）で確かめています。

## 正確さのメモ（出典）

| 内容 | このアプリでの表現 | 確認した資料 |
| --- | --- | --- |
| 発芽の条件 | 発芽には みず・くうき・てきとうな おんど が必要 | 京都府教育委員会「小5 植物の発芽と成長」（啓林館準拠の課題）、学習指導要領のまとめ「植物の発芽には、水、空気及び温度が関係している」 |
| 空気の実験 | 「たねを みずに しずめて くうきに ふれさせない」 | 同上（「種子を水につけ、空気にふれさせないようにする」） |
| 温度の実験 | へや（やく20℃）と れいぞうこ（やく5℃） | 長野県・香川県などの小5理科教材（「冷ぞう庫（約5℃）」）。冷蔵庫は暗いので室温側も箱で暗くするのが教科書の一般的な手順 |
| でんぷん | 発芽前の子葉は ヨウ素液で青むらさき、発芽して しばらく たつと ほとんど変わらない | 札幌市教育委員会 小5理科 学習課題、岩手県立総合教育センター 実験マニュアル（5年） |
| 成長の条件 | 日光と肥料が あると よく育つ。日光なしは ひょろ長く 葉が少なく 黄色っぽい | 香川県・大阪府教育センター・千葉県の小5理科 学力向上教材（日光・肥料の比較） |
| アサガオの つるの まきかた | うえから みて **左まき（反時計回り）** | 子ども向け解説（小学館 HugKum）など。「左まき／右まき」は 見る向きで呼び方が 逆になる流儀があるので、**「うえから見て 時計の はりと はんたい」** と 向きも そえて表示 |
| アサガオの受粉実験 | つぼみの うちに おしべを とり、ふくろを かぶせる。花粉を つけた花だけ実が できる | 宮城県総合教育センター 小5「花から実へ」授業案、千葉県 小5理科教材（めしべ1本・おしべ5本） |
| ヘチマ | おばな と めばな。めばなの下の ふくらみが 実に なる | 小5「花のつくり」の各教材 |

- 発芽の「てきとうな おんど」は、教科書では数値を決めずに「へやの温度」と「冷蔵庫」を比べるので、このアプリも同じ表現にしています
  （インゲンマメの発芽に向く温度は おおよそ 20〜25℃ が一般的な めやす）。
- そだつ日数・たかさ・成長グラフの数値は **めやす**（実際の教科書の写真や記録に近い傾向になるよう作った値）です。
