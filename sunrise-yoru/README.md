# サンライズ よるの ふたご でんしゃ 🌅

よるの 東京駅を でる ねだい とっきゅう。ふたごの でんしゃ **いずもくん**（サンライズ出雲）と **せとちゃん**（サンライズ瀬戸）に
おきゃくさん（どうぶつ）を ただしく のせて、あさの 岡山で きりはなす ゲーム（5さい〜）。
2本が 岡山で わかれて、出雲市（ひだり うえ・やまの ほう）と 高松（みぎ した・うみの むこう）へ 行く ことを 知るのが ねらい。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

公開URL: https://kisi1554.github.io/Pages/sunrise-yoru/

## あそびかた（1かい 1〜3ぷん）

1. よるの 東京駅。14りょう つながった ふたご。おきゃくさん 5にんの ねがい（「うどんを たべに 四国へ」など）を きいて、
   **まえの はんぶん（せとちゃん）** か **うしろの はんぶん（いずもくん）** に のせる。「ひとり もどす」で やりなおせる。
   こたえあわせは とうちゃく まで しない（まちがえた ままでも しゅっぱつ できる）。
2. しゅっぱつ。まどの そとが よるの けしきに なり、アナログ時計の はりが すすむ。とちゅうの 駅を じこく つきで 表示。
   くまの いびきで となりの ねずみが ねむれない。あさが くると そらが あかるく なる（⏩ はやおくり あり）。
3. 岡山駅で「きりはなし」: 7ごうしゃ と 8ごうしゃ の あいだ（かおと かおが むかいあう ところ）を タップ。
   ちがう ところは「おなじ でんしゃの なか だよ」。せいかいで「またね〜」、せとちゃんが さきに、いずもくんが あとに 出発。
4. ちず: いずもくんは やまを こえて 出雲市へ、せとちゃんは 瀬戸大橋で うみを わたって 高松へ（「うみだ〜！」と はしゃぐ）。
5. とうちゃく（こたえあわせ）: のせまちがえた おきゃくさんは ちがう まちで めを さます
   （うどんずきの たぬきが 出雲で「うどん…じゃなくて おそば？」など）。わらいは こたえあわせの あとだけ。
6. じかん くらべ: 「よる 9じ26ぷん でて あさ 7じ27ふん つく（やく 10じかん）」「あさ 10じ つく（やく 12じかん はん）」を 時計と ぼうで くらべる。
7. まなび カード 4まい（ねだい とっきゅう／れんけつ・きりはなし／瀬戸大橋で 四国へ／やまを こえて 山陰へ）と ⭐。
   ぜんいん ただしければ ほめる えんしゅつ。まちがいが あれば「おなじ おきゃくさんで もういちど」。

ほぞん（あそんだ かいすう・ぜんいん せいかいの かいすう・おとの オン/オフ）は localStorage（`sunrise-yoru:v1`）。
