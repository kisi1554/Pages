# 日本地理たんけん 🗾

都道府県パズルを 卒業した あとの 「つぎの一歩」を あそびながら 学ぶ アプリです。
**47都道府県の 位置と形は もう わかる** 子が、県庁所在地・地方区分・地形・名産・気候・新幹線を
本物の 日本地図の 上で おぼえていきます。

`index.html` をブラウザで開くだけであそべます(ビルドやサーバーは不要です)。

- 白地図を **直接タップして 答える** クイズが 中心です(4択だけで 終わらせません)。
- 正解するたびに その県の **カードが 育って**、47けん図鑑が うまっていきます。
- 漢字は **ふりがな付きで そのまま** 出します。せっていで ふりがなを 消すと 難易度が 上がります。

---

## 6つの クイズモード

| モード | 出る問題 | 答えかた |
| --- | --- | --- |
| 🏛️ 県庁所在地 | 「山梨県の 県庁所在地は?」「盛岡市が ある 県は?」 | 4択 / 地図タップ |
| 🧩 地方わけ | 「新潟県は なに地方?」「近畿地方の 県を ぜんぶ タップ」 | 8択 / 地図を ぜんぶタップ |
| ⛰️ 地形たんけん | 「最上川は どれ?」「光っている 半島の 名前は?」 | 地図の しるしタップ / 4択 |
| 🍎 名産・産業 | 「さくらんぼの しゅうかくが 日本一なのは?」 | 地図タップ |
| ☀️ 気候 | 「富山県は どの 気候?」 | 6択 |
| 🚄 新幹線 | 「金沢駅は どの県?」「この 新幹線は?」「東海道新幹線が 通る 県を ぜんぶ」 | 地図タップ / 4択 |

**県庁所在地モード**は、県名と ちがう 市(盛岡・仙台・水戸・宇都宮・前橋・横浜・金沢・甲府・
名古屋・津・大津・神戸・松江・高松・松山・那覇 など17)が **6割の 確率で 出る** ように
かたよらせてあります。ここが いちばんの やまばだからです。

また どのモードでも、**まだ おぼえていない 県ほど よく 出る** ように 重みづけしています
(カードのレベルが 低い県は 最大4倍 出やすい)。

### ヒントと とばす

- **ヒント 💡** … 4択なら 1つ消す / 地図タップなら 「◯◯地方の 中だよ」と 地方だけ 残して ズーム /
  地形なら しるしを 半分 消す / ぜんぶタップなら のこりの 1つを 教える。
- **とばす ⏭** … 答えを 見せて つぎへ。スタンプは もらえません。
- まちがえても **何回でも 挑戦できます**(4択は まちがえた ボタンが 消えていきます)。

## 47けん図鑑 📔

クイズで 正解すると、その県に **スタンプ(せいかい数)** が たまります。

| せいかい数 | レベル | カードの色 |
| --- | --- | --- |
| 0回 | ？？？(ふうじられている) | グレー |
| 1〜2回 | ★☆☆ | うすい黄 |
| 3〜5回 | ★★☆ | 黄 |
| 6回〜 | ★★★ | みどり |

カードを タップすると、その県の **形・県庁所在地・地方・気候・地形・通る新幹線・名物3つ・
ひとこと解説** が 出て、読み上げも できます。
地方ぜんぶが そろうと 🏅コンプリート、ぜんぶ ★★★ なら 👑かんぺき が つきます。

## ちずをみる 🗺️(地図帳モード)

クイズではなく、自由に しらべる モードです。上の ボタンで レイヤーを 重ねられます。

- **県名** / **地方の色**(8地方を 色分け) / **🏛️県庁所在地**
- **🚄新幹線**(10路線を 路線色で。駅も 出ます)
- **地形**を 種類ごとに: 🌊川 / ⛰️山・山脈 / 🌾平野・盆地 / 💧湖 / 🗾半島 / ⚓湾・海 / 🧭岬

県・地形・新幹線を タップすると 下に せつめいが 出て、読み上げます。
「カードを見る」から その県の 図鑑カードも ひらけます。

## 地図の そうさ

- **指で ドラッグ** … 地図を 動かす
- **2本指で つまむ** / **マウスホイール** … 拡大・縮小
- **＋ − ⤢** ボタン … 拡大・縮小・元にもどす

香川県や 大阪府のような 小さい 県は、拡大してから タップすると あてやすいです。
とくに **「九州地方の 県を ぜんぶ タップ」** は、沖縄県の わくが 左上に あるため
地図ぜんたいが 見える 引きの 表示に なります。九州のあたりを 指で 広げてから 答えてください。

## 収録データ

- **47都道府県** … 形(実際の 行政区域データ)・よみ・県庁所在地(位置つき)・地方・気候区分・名物3つ・ひとこと
- **地形 85件** … 川13 / 山・山脈15 / 平野・盆地17 / 湖9 / 半島14 / 湾・海9 / 岬8
- **新幹線 10路線** … 東海道・山陽・九州・西九州・東北・北海道・上越・北陸・秋田・山形
  (路線の 形、通る 都道府県、主な駅)
- **名産・産業クイズ 71問**

### 沖縄県の 表示について

沖縄県は 本土から とても はなれているので、教科書や 都道府県パズルと 同じく
**地図の 左上に 別わく(インセット)** を つくって **2倍の 大きさ** で 表示しています。
わくの 下に 「ほんとうは 九州の 南西の 海の 上」と 書いてあります。
わくに 入りきらない **先島諸島(宮古島・石垣島)と 大東諸島は 地図に 出していません**。
同じ理由で、東京都の **小笠原諸島・南鳥島** も 地図には 出していません(伊豆諸島は 出ます)。

### 気候区分について

気候は 6つ(北海道 / 日本海がわ / 太平洋がわ / 内陸(中央高地) / 瀬戸内 / 南西諸島)に
**ざっくり 分けたもの**です。1つの県の 中で 気候が 変わる ところ(京都府・青森県・岐阜県など)も
あるので、カードでは 代表的な ものを 出しています。
**クイズに 出るのは、はっきり している 15県だけ**です。

## せってい ⚙️

- **ふりがな** … オフにすると 漢字だけになり、難易度が 上がります
- **よみあげ** … 問題や 県名を 声で 読みます(ブラウザの 音声合成)
- **こうかおん** / **BGM** … その場で 合成しています(音源ファイルなし)
- **図鑑を リセット** … あつめた カードと せいかい数を ぜんぶ 消します

進み具合は ブラウザの localStorage に ほぞんされます。

### 地図データの つくりかた

`map-data.js` は 手で 編集せず、生成スクリプトを つかいます。

```bash
# 元データ(国土数値情報 由来の 都道府県境界 GeoJSON)を とってくる
curl -o japan.geojson https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson

# SVGパスに 変換する
python3 ../tools/japan-map/generate_map.py japan.geojson map-data.js
```

スクリプトは メルカトル図法で 投影し、小さすぎる 離島を 間引き、Douglas-Peucker で 簡略化して、
沖縄県を インセットへ 移動します。しきい値は スクリプト冒頭の 定数で 変えられます。

元データ: [dataofjapan/land](https://github.com/dataofjapan/land)(国土交通省 国土数値情報 の
行政区域データ 由来)。
