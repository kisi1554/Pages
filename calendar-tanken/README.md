# カレンダー たんけん 📅

**カレンダーの うえを すすみながら、ようび・ひづけ・つき と きせつ の ならびを おぼえる アプリ。**
対象は 5さい くらい。`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリなし）。

## あそびかた

1. レベルを えらぶ（1かい 5もん、1〜3ぷん）。
2. カレンダーに「きょう」の コマ 🐥 が のる。
3. もんだい「3にち あとは なんようび？」→ となりの マスを 1つずつ タップして コマを すすめる。
4. ついた マスの ようびを こたえる。せいかいで その ひに スタンプ。
5. 5もん おわると ほし（⭐1〜3）。まちがえても なんどでも やりなおせる。

## レベル

| レベル | なかみ |
| --- | --- |
| 1 ようびの じゅんばん | げつ→にち の ならびの「？」を あてる。合成メロディの **ようびの うた** で ようびが じゅんに ひかる |
| 2 きのう・あした | あした・きのう・あさって・おととい |
| 3 ○にち あと・まえ | 3〜10にち。かならず 7にち／14にち が でて「1しゅうかん あとは おなじ ようび」を おしえる |
| 4 つき と きせつ | ぎょうじ（おしょうがつ・ひなまつり・こどものひ・たなばた・クリスマス ほか）は なんがつ？／きせつ は？／つぎの つき は？ |

- **ほんとうの「きょう」から はじめる** スイッチ: レベル2〜4 で こんげつ と きょうの ひづけ（`Date`）を つかう。
- ようびは ひらがな＋いろわけ（げつ=きいろ、か=あか、すい=あお、もく=みどり、きん=オレンジ、ど=むらさき、にち=ピンク）。
- まちがいが 2かい つづくと ヒント（ようびの れつが ひかる・となりの マスが ひかる など）。

## しくみ

- 音は WebAudio の合成音のみ。右上の 🔊 で オン/オフ。
- localStorage（`calendar-tanken-v1`）に 音の設定・きょうモード・スタンプの数・レベルごとの ほし を保存。
- 縦スマホ: もんだい → カレンダー → こたえ の じゅん。横タブレット: 左に カレンダー、右に もんだい と こたえ。
- ズーム対策は `python3 tools/no-zoom.py calendar-tanken` で 共通ブロックを 入れてある。
