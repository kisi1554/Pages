# まなび でんしゃ

「まいにちの べんきょう ＝ 1ぽんの でんしゃを はしらせること」。
横浜市営地下鉄ブルーライン（B01 湘南台 〜 B32 あざみ野）を舞台に、駅に着くたびに1問とく学習アプリです。
企画書は [`docs/densha-manabi-concept.html`](../docs/densha-manabi-concept.html)。この版は企画書の「最初の版」にあたります。

- `index.html` 1枚で完結。外部ライブラリ・CDN・音声ファイルなし
- 効果音は WebAudio の合成音、問題の読み上げは端末の音声合成（どちらも オン/オフ あり）
- 進み具合は localStorage（`manabi-densha-v1`）に保存

## 1回の流れ（約5分）

路線をえらぶ → 発車ベル → 駅ごとに1問 × 8駅 → 終点でスタンプ → 車庫へ

## 路線

| 路線 | 内容 |
| --- | --- |
| 🔵 かず せん | 駅番号を数直線にした たし算・ひき算。「B05 おどりば から 3えき すすむと？」 |
| 🔤 ことば せん | 駅名の読み。1本の中で ひらがな（漢字の読み）→ カタカナ → 漢字 と段階的に |

1本で8駅すすみ、4本で全線（32駅）をひとまわりします。

## 取り入れた機能

| 機能 | 見せ方 |
| --- | --- |
| 1日の回数制限 | 1日3本まで。終わると「きょうの うんこうは おしまい」の車庫画面 |
| 連続日数 | 「むじこ うんてん ○にち」。1日休んでも「りんじダイヤ けん」で1回だけ切れない（7日続くと再発行） |
| 段階的ヒント | 信号機：🟢 自分で解く → 🟡 ヒント（かず線は数直線を表示）→ 🔴 一緒に解いて答えを示す。まちがえると1段すすむ／🚦ボタンでも進められる |
| 読み上げ | 問題を車掌さんの声で読み上げ。🔊 でもう一度 |
| 集めるごほうび | 終点の駅スタンプ（スタンプちょう）。🔴 以外で解けた駅は路線図に色がつき（⭐ は自分で解けた駅）、32駅そろうと「ぜんせん かいつう」 |
| おとなの設定 | ⚙️ から計算問題を解いて入る。1日の本数（1〜5）、今日の回数のリセット、全記録の消去 |

## あえて入れないもの

ガチャ・課金・広告・ランキング・アカウント登録。比べるのは昨日の自分だけ。
