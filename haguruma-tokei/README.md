# はぐるま とけいだい ⚙️

とけいだいの なかに はいって、**はぐるまを ならべて とまった とけいを うごかす** パズル（年長〜小学4年）。
おおきい はぐるまと ちいさい はぐるまで まわる はやさが かわり、となりあう はぐるまは **ぎゃくむきに まわる**。
`index.html` を ひらくだけで うごきます（外部ライブラリなし）。

公開URL: https://kisi1554.github.io/Pages/haguruma-tokei/

## あそびかた

1. したの たなから はぐるま（は 8・12・16・24・32・48）を ドラッグして ピンに さす。ちかくの ピンに かちっと すいつく。
   ばんの はぐるまは ドラッグで うごかせる／たなへ もどせる。ねじどめ（まんなかが きいろ）は うごかせない。
2. ハンドルを みぎに ぐるぐる なぞる（または「▶ まわす」）と モーターが まわる。ハンドルは みぎまわり だけ（ラチェット）。
3. モーターが 1しゅう したら はんてい。めあてと ちがう ときは「はりが ひだりまわり」「いまは 2ばい、めあては 3ばい」などと おしえる。
4. わに なって むきが むじゅん すると「ぎしぎし！」で とまり、ひっぱりあう はぐるまが あかく なる。

- **2だん はぐるま**: ささって いる ピンに もう 1まい おくと「てまえ」に かさなり、おなじ じくで いっしょに まわる。
  かみあうのは おなじ だん（おく／てまえ）どうし だけ。はぐるまを タップすると おく ⇔ てまえ を いれかえる。
  なにも ない ピンに おくと、かみあう ほうの だんを じどうで えらぶ。
- 💡 ヒント: こたえの れい から「ここに は24」「これを とりかえる」「これを はずす」を 1つ ずつ ひからせる。
- ⭐ クリア、🌟 いちばん すくない まいすうで クリア。まえの ステージを クリアすると つぎが ひらく。

## ステージ（4しょう × 6 = 24）

| しょう | おぼえる こと | ステージ |
| --- | --- | --- |
| 1. むき | となりは ぎゃく。あいだに 1こ いれると おなじ むき | はじめての はぐるま／あいだに 1こ／まがりかど／ぎしぎし とけい（3まいの わを 1こ はずして なおす）／みちは 2つ（5まいの わは ロック）／おおきさ ちがい |
| 2. はやさ | は の かずの わりあい ＝ はやさ。あいだの はぐるまは はやさを かえない | 2ばい／はんぶん／おおきな なかま（は48 の あいだ）／3ばい／4ばい みぎ／6ぶんの1 みぎ |
| 3. 2だん はぐるま | おなじ じくの 2まいで わりあいを かけざん | 4ぶんの1／4ばい／9ぶんの1／6ばい／12ぶんの1／8ぶんの1（2だんを 2つ） |
| 4. とけい | ちょうしん：たんしん ＝ 12：1 | モーターに ちょうしん／べつの くみかた／はなれた ちょうしん／ふたまた／ちょうしの わるい とけい（とりかえて なおす）／とけいだいの かね（ちょうしん 2ばい） |

4しょうは とけいが うごいたら **じこく あわせ クイズ**（「3じ はんに して」）。ハンドルは ぎゃくにも まわせて、
「5ふん」ボタンでも うごく。まちがえると「いまは 2じ 45ふん だよ。たんしん（みじかい はり）で なんじ を みるよ」と おしえる。
さいごの ステージの あと、とけいだいの かねが「ごーん」と なって まちの ひとが 大よろこび。

## しくみ（`gear.js`）

- ピッチえんの はんけい ＝ は の かず × 2.5。おなじ だんで ピンの きょりが はんけいの わ（±2）なら かみあう。
  かみあわないのに はさき どうしが とどく（わ ＋ はの たかさ×2 より ちかい）と「ぶつかる」ので おけない。
- モーターの じく ＝ +1（みぎ）。かみあうと そくど × −(は1/は2)、おなじ ピンは おなじ そくど。
  たどって いって もう きまった そくどと むじゅん したら **ロック**（きすうの わ や、わりあいの あわない わ）。
- ステージの ピンは「この ピンから は の わ 48 の きょり、60ど」の ように かく（`buildPins`）。
- `solve(stage)`: モーターに つながる はぐるまを 1まい ずつ ふやす ふかさ ゆうせん（だんだん ふかく）で、いちばん すくない こたえを さがす。
- `phases`: かみあう はぐるまの は と みぞが むかいあう ように はじめの かくどを そろえる（は の いそう）。
