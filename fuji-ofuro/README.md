# ふじさんが みえる おふろやさん（fuji-ofuro）

ほんものの富士山が見える日帰り温泉・スーパー銭湯を、子どもむけにランキングで紹介するページ。

公開URL: https://kisi1554.github.io/Pages/fuji-ofuro/

## あそびかた

`index.html` をブラウザで開くだけ（外部ライブラリなし）。

1. ちずの ばんごうを おすと、その おふろの せつめいに とぶ。
2. ランキングの カードを おすと、くわしい せつめいが ひらく。
3. 「⭐ いきたい！」「♨️ いったよ」で しるしを つけられる（localStorage に保存）。
4. 右上で おと の オン/オフ（WebAudio の合成音）。
5. いちばん下の「おうちの かたへ」に、料金・営業時間・出典をまとめている。
