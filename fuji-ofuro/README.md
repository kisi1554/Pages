# ふじさんが みえる おふろやさん（fuji-ofuro）

ほんものの富士山が見える日帰り温泉・スーパー銭湯を、子どもむけにランキングで紹介するページ。

公開URL: https://kisi1554.github.io/Pages/fuji-ofuro/

## あそびかた

`index.html` をブラウザで開くだけ（外部ライブラリなし）。

1. 地図の番号を おすと、そのお風呂の説明にとぶ。
2. ランキングの カードを おすと、くわしい せつめいが ひらく。
3. 「⭐ いきたい！」「♨️ いったよ」で しるしを つけられる（localStorage に保存）。
4. 右上で おと の オン/オフ（WebAudio の合成音）。
5. カードを ひらくと「🚃 よこはまえき から」の いきかた（でんしゃ・バスの のりつぎ と めやすの じかん）が出る。
6. 「🗺️ ちずで いきかた」で Google マップの経路検索（横浜駅→施設、公共交通）、
   「🔍 グーグルで しらべる」で Google 検索を新しいタブで開く。
7. 「🎡 ちかくの あそびスポット」に、近くの子連れスポットを Google 検索リンクつきで のせている。
8. いちばん下の「おうちの かたへ」に、料金・営業時間・車でのアクセス・出典をまとめている。

## ランキングの付けかた

お風呂から富士山がよく見えることをいちばん重く見た、独自の採点（35点満点）。公式のランキングではない。

- 🗻 富士山の見え方 ★1〜5 × 3（15点）… 紹介記事・口コミで「どの湯船から見えるか」がはっきり書かれているほど高い
- 💴 大人の値段（5点）… 〜600円=5／〜800円=4／〜1,200円=3／〜1,600円=2
- 🧒 子どもの値段（5点）… 〜400円=5／〜600円=4／〜800円=3
- 🎡 近くの遊び（5点）… 歩いて行ける・同じ施設の中ほど高い
- 🚃 行きやすさ（5点）… 横浜駅から電車・バスでの時間と乗りかえ

同点は「見え方」→「行きやすさ」の高いほうを上にしている。データ（`SPOTS`）は合計点の順に並べ、
順位はそこから休館中を除いて自動で付ける。各カードには「📊 点数」として内訳を表示している。

## 注意

- **紅富士の湯は 2026年9月28日〜2027年3月ごろまで休館**（天井板改修工事）。休館中はランキングから外し、ランキングの下の「いまはお休み中のお風呂」にまとめている（地図のピンは灰色の「休」）。再開したらデータの `closed` を消せば、点数どおり2位に戻る。
- 子ども向けの文は、漢字＋ふりがな（`<ruby>`）で書いている（このアプリだけの例外。ユーザーの指示）。

- 2026年10月10日時点の Web 公開情報にもとづく。料金・営業時間は変わることがある。
- 気楽坊の子ども料金と営業時間は確認できていない（「要確認」と表示）。
- 横浜駅からのルート・所要時間は目安。バスは季節・曜日で運行が変わるので、当日は Google マップのリンクで確認する。
- ちずの ピンの位置は だいたいの方角を示すイメージで、正確な地図ではない。
