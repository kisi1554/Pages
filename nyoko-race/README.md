# にょこすけ レース 🏁

いもむしの **にょこすけ** と、あたらしい おともだち 3びきが かけっこする レースゲーム。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリなし）。

## でてくる こ

| なまえ | どんな こ | とくいわざ（CPU） |
| --- | --- | --- |
| **にょこすけ**（いもむし・きみ） | 「わらって いもほり」「にょこにょこ えきめぐり」の いもむし。しゃくとりむしの うごきで すすむ | 🍠を たべて おならダッシュ |
| **でんきち**（かたつむり）🆕 | のんびりや。みずたまりは へっちゃら | ぬるぬる すべって びゅーん |
| **ころまる**（だんごむし）🆕 | がんばりや。いしに ぶつかると「ごつん！」 | まるまって ころころ（いしも はねて こえる） |
| **てんとちゃん**（てんとうむし）🆕 | ピンクの リボンの おんなのこ | ぱたぱた とんで いしを こえる |

## あそびかた

| そうさ | なにが おきる |
| --- | --- |
| 「にょこにょこ」ボタン（コースを タッチ・スペース・→ でも OK） | おしている あいだ すすむ。**れんだ** すると もっと はやい |
| 「ジャンプ」ボタン（↑） | いしを とびこえる。いしが ちかづくと「！」が でて ボタンが ひかる |
| 「ぷっ！」ボタン（F） | ひろった 🍠 で おならダッシュ（3こ まで もてる） |

- 🍄 キノコに のると ぼよーんと おおジャンプ ＋ かそく。
- 💧 みずたまりは のろのろ（でんきちだけ へいき）。
- いしに ぶつかると くらくら して すこし とまる。
- ぬかすと おともだちが「まって〜！」。

## コースと はやさ

| コース | ながさ | とくちょう |
| --- | --- | --- |
| 🌼 はらっぱ コース | みじかい | はじめての こ むけ |
| 🍠 いもばたけ コース | ふつう | 🍠 と みずたまりが おおい |
| 🍄 もりの こみち | ながい | いし と キノコが おおい |

はやさは **やさしい**（おしっぱなしで かてる）／ **ふつう**（れんだ・🍠で かてる）／ **はやい** の 3つ。
CPU は きみとの きょりで すこし はやさを かえる（はなれすぎない ように）。

## きろく

コース × はやさ ごとに いちばん よい じゅんい（🥇🥈🥉）と ベストタイムを ほぞん。
3コース ぜんぶで 1いに なると タイトルに 🏆 チャンピオン。
localStorage のキー: `nyoko-race.v1`

## しくみ

- `index.html` / `style.css` / `game.js` の 3ファイル。キャラクターも コースも canvas に その場で かいている。
- にょこすけ は いもほりの `nyoko()` と おなじ いろ・かおを、よこむきの しゃくとり すがたに かきなおしたもの。
- 音は WebAudio の 合成音のみ。右上の 🔊 で オン/オフ。
- 縦持ちスマホは したに ボタン、横持ちスマホは ひだり（ジャンプ・ぷっ）と みぎ（にょこにょこ）に ボタン。
- URL に `#debug` を つけると `window.__nyokoRace` から レースの じょうたいを みられる（テスト用）。
