# ふじさんが できるまで 🌋🗻

ふじさんが **なんかいもの ふんかで つみかさなって できた 火山** で、いまの かたちに なるまで
とても ながい じかんが かかったことを、だんめんず（やまを たてに きった え）で たどる あそび（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

公開URL: https://kisi1554.github.io/Pages/fujisan-dekikata/

## あそびかた（1回 2〜3分）

1. **こみたけ** … なにもない たいらな 土地で、ふんかボタンを ながおし → 山が そだつ。
2. **こふじ** … 「とき が すすむ」カードの あと、こみたけの うえに あたらしい 山が かぶさる。
3. **しんふじ** … さらに かさなって 3776m の いまの かたちへ。だんめんずで 3つの そうが 色ちがいで 見える。
4. **みずうみ** … 上から みた え に きりかえ。ようがんが 川を せきとめて みずうみが できる（富士五湖）。
5. **わきみず** … ゆきを ふらせて、山を タップして とかす。しずくが しんふじの すきまを しみこみ、
   こふじの かたい そうの うえを ながれて、ふもとで わきみずに なる（5てき で クリア）。
6. **ほうえいの ふんか** … えどじだい（1707年）。山の よこから ふんか → はいが 風で えどの まちへ。ほうえいかこうが のこる。
7. **いまの ふじさん** … めぐみ（わきみず・みずうみ・おんせん）と きをつけること（いまも いきている 火山。みまもっている ひとが いる）。
8. **じだいカード クイズ** … こみたけ → こふじ → しんふじ → ほうえいの ふんか を ふるい順に タップ。
   まちがえても カードが ゆれて もどるだけ。まちがい 0 で ⭐3、1〜2 で ⭐2、それ以上 ⭐1（かならず ほめる）。

- キーボード: スペース / Enter ＝ ながおし・ボタン。
- 🔊 で 音の オン/オフ。クリア回数と いちばんの ⭐ は localStorage（`fujisan-dekikata`）に のこる。

## 事実と つくりもの

| ないよう | 根拠・メモ |
| --- | --- |
| 小御岳 → 古富士 → 新富士 の じゅんに かさなっている | 富士山の 成り立ちの 一般的な 区分（小御岳火山・古富士火山・新富士火山）。小御岳の 頂上付近は 5合目（小御岳神社）に 顔を 出している |
| 年数（数十万年前／約10万年前から／約1万7千年前から） | 産総研 富士火山地質図（第2版）などの 区分に よる めやす。画面では「ひとが うまれる ずっと まえ」を 主に して、年数は 小さく そえるだけ |
| 1707年 宝永噴火・江戸に 降灰・宝永火口 | 富士山 さいごの 噴火。南東の 中腹に 宝永火口と 宝永山が のこる |
| 溶岩が 川を せきとめて 湖 | 富士五湖は 溶岩流が 谷を せきとめて できた |
| わきみずの しくみ | すきまの 多い 新富士の 溶岩に しみこんだ 水が、水を とおしにくい 古富士の 層の うえを ながれ、ふもと（柿田川・忍野八海 など）で わき出る。数十年 かかると いわれる |

**つくりもの**: 山の かたちと 高さの くらべ（たてに 強調）、よこの きょり（えどは ほんとうは 約100km 先）、
「上から みた え」の 川と 湖の 位置、しずくの 速さ、マグマだまりの 位置・大きさ。

火山の しくみ 全般は 別アプリ（kazan-dokkan）に まかせ、こちらは ふじさんの 歴史に しぼった。
こわく ならないよう、ゆれ・音は ひかえめ。
