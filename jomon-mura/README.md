# じょうもん むらの くらし 🏺

**縄文の むらで 1年 くらす シミュレーション。** 小6 社会「縄文のむらから古墳のくにへ」の 予習・復習用（低学年も あそべます）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/jomon-mura/

---

## あそびかた

むらの え（たてあなじゅうきょ・ひろば・もり・うみ／かわ・かいづか）の ばしょを タップすると、そこで できる しごとが ひかります。
きせつは 🌸はる → ☀️なつ → 🍁あき → ❄️ふゆ。**1きせつに しごとは 3かいまで**。

| きせつ | しごと | あそび |
| --- | --- | --- |
| はる | 🌿 さんさい とり | くさむらを タップして ぜんまい・わらびを さがす（8かい） |
| はる | 🐚 かいを ほる | すなはまを ほって ハマグリ・アサリ・カキ |
| なつ | 🛶 りょう | まるきぶねから。ほねの つりばり（やさしい）／つのの もり（むずかしい・イルカも）で タイミング あそび |
| あき | 🌰 きのみ ひろい | おちてくる どんぐり・くり・くるみを タップ（15びょう）。どんぐりは しぶい |
| あき | 💧 あくぬき | かごに いれて かわの みずに 3にち さらす（どきが あれば にる） |
| あき | 🪨 こなに する | いしざらと すりいしで ごりごり → たくわえ アップ |
| ふゆ | 🏹 かり | ゆみや（せきぞくの やじり）で シカ・イノシシを ねらう／おとしあなを ほって まつ |
| いつでも | 🏺 どき づくり | わを つみあげる → なわを ころがして もよう → のやき（ひの つよさを たもつ。つよすぎると われる） |
| いつでも | 🛖 いえ づくり | あなを ほる → はしら → かやぶき。いえが ふえると なかまが てつだう（とる しごと ＋1） |
| いつでも | 🗑️ かいづかに すてる | かいがら・ほね・われた どきなどを すてる（かいすうに かぞえない） |

- ふゆの おわりに たくわえが **24** あれば 1年 クリア。たりなくても しなない（「おなかが すいたね、らいねんは もっと あつめよう」）。
- どきが あると かい・どんぐりを にて たくさん たべられる。しぶい どんぐりは あくぬき しないと たべられない。
- 1年が おわると **⛏️ はっくつ モード**。いまの じだいから じぶんの かいづかを ほると、すてた かいがら・ほね・われた どきが でてきて
  「かいづかから むかしの くらしが わかる」ことを たいけん できます。たまに 土偶・耳飾り・ヒスイ などの たからものも。

## ずかん（33まい ＋ つぎの じだい 3まい）

- どうぐ 17・たべもの 13・いせき 3。ふりがなつき、え は ぜんぶ SVG の コード描画（`art.js`）。
- かいづかに のこる もの（かいがら・ほね・どき・いしの どうぐ など）は **はっくつで みつけると とうろく**。
  き・くさで できて のこりにくい もの（ゆみや・まるきぶね・たてあなじゅうきょ・なわ・かご・さんさい など）は しごとで つかうと とうろく。
- いせき（大森貝塚 → 称名寺貝塚 → 三内丸山遺跡）は はっくつを おえる たびに 1まいずつ。
- 「つぎの じだい」タブ: **稲作・金属器・高床倉庫 は 弥生時代** の もの。むらには でず、くらべる ためだけに のせています。

## おうちの かたへ（ねんだいと 出典）

アプリの なかでは 年代を「およそ 1まん年 いじょう つづいた」とだけ 表現し、細かい 数字は ここに まとめます。

| ことがら | 内容 | 出典 |
| --- | --- | --- |
| 縄文時代の長さ | 世界遺産「北海道・北東北の縄文遺跡群」は「1万年以上にわたって採集・漁労・狩猟により定住した人々の生活と精神文化を伝える」遺跡群と説明されている | 文化庁 報道発表（2021年7月）https://www.bunka.go.jp/koho_hodo_oshirase/hodohappyo/93257501.html |
| 縄文の終わり（弥生の始まり） | 国立歴史民俗博物館の放射性炭素年代測定により、弥生時代の始まりは従来の前5〜4世紀より約500年さかのぼる 前10〜9世紀ごろ の可能性が高いとされる（諸説あり） | 国立歴史民俗博物館の研究成果（藤尾慎一郎ほか、2003年発表） |
| 三内丸山遺跡（青森市） | 縄文時代前期〜中期、**約5,900〜4,200年前** の大規模集落。大型掘立柱建物（直径約1mのクリの木柱）、竪穴建物、土偶・ヒスイなど | 青森県「特別史跡 三内丸山遺跡」https://sannaimaruyama.pref.aomori.jp/about/iseki/ |
| 大森貝塚（品川区・大田区） | **1877年（明治10年）**、アメリカの動物学者 E.S.モースが発掘。日本初の科学的な発掘調査で「日本考古学発祥の地」。縄文時代後期〜晩期の貝塚（品川区の解説では約4,400〜2,300年前ごろ） | 品川区立品川歴史館の展示資料・多言語解説（city.shinagawa.tokyo.jp） |
| 称名寺貝塚（横浜市金沢区） | **およそ4,000年前、縄文時代後期** を中心とする貝塚。イルカや魚の骨が大量に出土し、シカの角で作った銛や釣針などの漁具も出土。「称名寺式土器」の基準となった | 横浜市歴史博物館 企画展「称名寺貝塚 土器とイルカと縄文人」（2016年）資料 https://www.rekihaku.city.yokohama.jp/ |

- 横浜市の遺跡は、市の施設（横浜市歴史博物館）の資料で確認できた **称名寺貝塚だけ** を のせています。
- 「土偶は祈りや祭りに使ったと考えられている」「三内丸山ではクリの木を管理していた」など 研究上の推定は「〜と かんがえられて いる」と書いています。
- `nippon-sugoroku/` の 縄文に関する記述は「縄文杉（屋久島の杉の大木）」だけで、縄文時代の内容とは 重なりません。
