# むしくい しんぶん 🐛

むしに たべられて **あなが あいた しんぶんや てがみ**。まえと うしろの ことばを ヒントに、あなに はいる もじを あてて うめる
ことば あそび（年長〜小学4年）。うまると むしが「ごめんね〜」と にげて いく。ぶんを よむ 力・ごい・かんじ・ことわざ を そだてる。

`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。むしの え は SVG を コードで かく。
おと は WebAudio の 合成音、よみあげ は ブラウザの おんせいごうせい。どちらも オン/オフ できる）。

## レベル

| レベル | あな | かず |
| --- | --- | --- |
| 1 ひらがな | 1もじ（3つから えらぶ） | 60もん（てがみ 12まい） |
| 2 ことば | ことば 1つ（3つから えらぶ） | 60もん |
| 3 かんじ | 1〜3ねんの かんじ 1じ。あなに よみ が でる | 60もん |
| 4 ことわざ | ことわざの 1ぶぶん。うまると いみ が でる | 60もん |
| 5 しんぶん | オリジナル こども しんぶん「むしむし タイムズ」の きじ（3〜4ぶん）に あな 3〜5こ | 20まい |

レベル4・5 は せっていの「じぶんで いれる」で **50おん パッド**（゛゜小ー つき）で こたえられる。

## あそびかた

1. あなを タップ → したの こうほ ボタンで こたえる（はじめは いちばん うえの あなが えらばれて いる）。
2. せいかい → あなが ふさがって、むしが「ごめんね〜」と にげる（ずかんに のる）。
   ちがう → むしが「むしゃむしゃ」して もう いちど（しっぱい は かぞえない）。
3. **おもしろ モード**（せってい）: ちがう ことばを いれると へんな ぶんと え が でて
   （「くまが ひひいんと なく」→ 🐻）、そのあと せいかいを おしえて くれる。
4. 1まい ぜんぶ うまると かみが ぱりっと きれいに なり、きじを よみあげる。

## ほぞん（localStorage `mushikui-shinbun-v1`）

レベルごとに クリアした かみ・むし ずかん（にがした むし 10しゅと かいすう）・せってい（おと / よみあげ / おもしろ / パッド）。
