# しんかんせん えきべん にほん じゅうだん 🍱

しんかんせんを のりついで、きたの 新青森〈しんあおもり〉から みなみの 鹿児島中央〈かごしまちゅうおう〉まで
にほんを たてに たびする クイズ。駅名の 漢字・都道府県・その とちの たべものを むすびつけて おぼえる。5さい〜。

公開URL: https://kisi1554.github.io/Pages/shinkansen-juudan/

## あそびかた

1. コースを えらぶ。でんしゃが 駅に つくと「つぎの えきは どれかな？」。漢字の 駅名カード 3まいから ただしい つぎの 駅を えらぶ。
2. 正解すると でんしゃが 地図の 上を はしり、とおった 県が 路線の 色に そまる。はじめて 来た 県では、その とちの
   えきべん・おみやげが もらえる（仙台＝ずんだもち など）。しゃしょうさんが たべて だんだん まるく なる。
3. 「おおきな えき コース」は 東京・新大阪・博多で のりかえ（東北 → 東海道 → 山陽 → 九州）。
   ちがう しんかんせんを えらぶと「あれれ？ 金沢に きちゃった」と 北陸しんかんせんで 金沢へ。🔙 で もどって やりなおし。
4. ゴールの あとは「なかま あつめ」（「島」が つく 駅を ぜんぶ タッチ など）。
5. ⭐ は まちがい＋ヒントの かず で 1〜3こ。まちがえても その場で やりなおせる。

🎁 ボーナスは おおきな えき コースを 1かい クリアすると あそべる。

- **やさしい**: カードに 県名（ふりがな つき）が 出て、地図の つぎの 県が きいろく ひかる。
- **むずかしい**: 駅名だけ。1かい まちがえると 県が ひかる。
- 💡 ヒント: つぎの 駅の よみを ひらがなで 出して 読みあげる。
- わらい どころ: 新青森では しゃしょうさんが ゆきだるま（はしりだすと とける）、えきべんを たべて まるく なる、
  鹿児島中央では あせだく。わらいの えんしゅつは ぜんぶ 答えあわせの あとに 出る。
- よく 出る 漢字（京・大・島・岡・山・福・田）は カードで 色を かえて 目立たせる。

## データ（いちばん 大事）

駅名・じゅんばん・よみ・県・座標は `index.html` の `DATA`（1か所）に まとめて ある。

- じゅんばんと 駅は JR 各社の 路線（東北・北海道・上越・北陸・東海道・山陽・九州〈鹿児島ルート〉）の 停車駅。
  Wikidata の 隣の駅（P197、路線の 修飾子つき）・所在地（P131）・かな（P1814）・座標（P625）と 1駅ずつ 照合した（2026-11）。
- 東北・上越・北陸は 東京から（東京〜大宮 は 共用区間）。上越の ガーラ湯沢（冬だけ の 支線）、
  西九州しんかんせん、山形・秋田（ミニ新幹線）は 入れて いない。
- 「川内」は「せんだい」（鹿児島県）。仙台と おなじ よみ なので、もんだいでは いっしょに 出さない。
- えきべん・おみやげは その 県の たべものの 名前だけ。お店・商品の 名前・ロゴ・発車メロディは 使わない。
  でんしゃの 絵は 色だけ 路線に あわせた オリジナル。

## しくみ

- `index.html` … 画面・ゲーム・データ ぜんぶ。外部ライブラリなし。
- `map-data.js` … 都道府県の 地図（`tonari-ken/` などと 同じ。生成元 `tools/japan-map/generate_map.py`、国土数値情報 由来）。沖縄は 使わないので 描かない。
- 音は WebAudio の 合成音（ピンポン・はしる おと・とうちゃくの チャイム・もぐもぐ・ファンファーレ）と、端末の 読みあげ。右上の 🔊 で オン/オフ。
- ほぞん: localStorage `shinkansen-juudan-v1`（`clears` コースごとの ⭐・`foods` あつめた えきべん・`lv` やさしい/むずかしい・`sound`）。
- 🍱 えきべん ずかん で あつめた たべものが 見られる。
