# どんどこ たいこ 🥁

太鼓の達人みたいな リズムゲーム。ながれてくる おんぷに あわせて たいこを たたく。

公開URL: https://kisi1554.github.io/Pages/dondoko-taiko/

## あそびかた

- あかい **ドン** … たいこの まんなかを タップ（キー F・J・スペース）
- あおい **カッ** … たいこの ふち・そとを タップ（キー D・K）
- おおきい おんぷ … とくてん 2ばい
- きいろい **れんだ** … いっぱい たたく（どこでも OK）
- 「すごい（ぴったり）／いいね／おしい」で はんてい。せいかいりつで ★1〜3、ミスなしで 👑フルコンボ

## きょく と むずかしさ

きらきらぼし・かえるのうた・メリーさんのひつじ・ロンドンばし・よろこびのうた（いずれも著作権の切れた曲）。

| むずかしさ | ないよう |
| --- | --- |
| かんたん | おんぷ すくなめ、はんてい ゆるめ、**どっちを たたいても OK** |
| ふつう | メロディの おとと おなじ かず。あか・あおを みわける |
| むずかしい | すきまに おんぷを たして 8ぶおんぷが つづく |

## しくみ

- 譜面はメロディから自動生成（音が上がる＝カッ、下がる＝ドン、同じ高さ＝前と同じ。長い音の2回に1回が大おんぷ。最後にれんだ＋大ドン）。
- 曲・ドン/カッの音はすべて WebAudio の合成音。タイミングは `AudioContext.currentTime`（`outputLatency` 補正）で取り、一時停止は `suspend()`。
- ベスト記録（スコア・★・フルコンボ）は localStorage `dondoko-taiko-v1`。
- `?auto=1` を付けると自動演奏（テスト用）。
