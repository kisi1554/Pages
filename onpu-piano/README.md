- けんばん: ド〜ド の 2オクターブ（くろけん あり）。しろけん 15こ が 52px いじょう で ならぶ はば なら 2オクターブ、
  たりない（たてもち スマホ）ときは 1オクターブ ＋「◀ ひくい / たかい ▶」きりかえ。きょく れんしゅう では つぎの おとに あわせて じどうで きりかわる。
- マルチタッチ（わおん）と なぞり（グリッサンド）に たいおう。Pointer Events で ゆび ごとに おさえて いる けんばん を おぼえる。
- PC: `a s d f g h j k` が しろけん（ド〜ド）、`w e t y u o p` が くろけん、`l ; '` で その うえ。`z` / `x` で オクターブ を さげる / あげる。
- おとは WebAudio の ごうせいおん（三角波 ＋ すこし ずらした サイン波 ＋ 2・3・4ばいおん、ローパスが だんだん くらく なる、ひくい おとほど ながく ひびく）。
  ミュート の ときは けんばん が ひかる だけ。リズムの メトロノーム は ミュートでも ●●●● が てんめつ する。

## きょく（ちょさくけん の きれた もの だけ）

きらきらぼし / かえるの うた / メリーさんの ひつじ / ちょうちょう / ゆかいな まきば（★）、
よろこびの うた / ロンドンばし / こげこげ ボート / ジングルベル（★★）。

メロディ だけ を のせて いる（かし は のせない。にほんごの かし には ちょさくけん が のこって いる ものが ある）。
ぶんぶんぶん・かっこう は メロディの せいかくさ を たしかめられなかった ので いれて いない。

データは `music.js` の `SONGS`。`["おとの なまえ", ながさ]` の はいれつ で、ながさ は 4ぶおんぷ ＝ 1（8ぶ 0.5、ふてん 4ぶ 1.5、2ぶ 2、ふてん 2ぶ 3、ぜん 4）、`"R"` は きゅうふ。
`meter` は 1しょうせつ の はく（こげこげ ボート は 6/8 を 3 で あらわす）。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `music.js` | DOM を つかわない データ と けいさん（おとの なまえ ⇄ MIDI、ごせんふ の いち、きょく、リズム、はんてい）。node でも よめる |
| `staff.js` | ごせんふ・ト音記号・おんぷ・きゅうふ・♯・かせん を SVG の パス で かく（フォント・がぞう を つかわない） |
| `audio.js` | ピアノふう ごうせいおん・メトロノーム |
| `app.js` | がめん と あそび |
| `tests/music.test.js` | `node --test onpu-piano/tests/*.test.js` |

ごせんふ の いち（`staffStep`）は、ト音記号の いちばん した の せん（ミ = E4）を 0 として、せん と かん を 1つずつ かぞえる。
したの ド（C4）は -2 で かせん 1ぽん、うえの ラ（A5）は 10 で かせん 1ぽん、たかい ド（C6）は 12 で かせん 2ほん。
