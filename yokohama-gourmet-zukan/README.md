# 横浜グルメ図鑑

Googleマップの口コミで評価が高い横浜のお店を集めた図鑑。
**★4.3以上・口コミ300件以上**のお店 217軒を、★と口コミ件数からおすすめ順に並べている。

公開URL: https://kisi1554.github.io/Pages/yokohama-gourmet-zukan/

## つかいかた

| したいこと | やりかた |
| --- | --- |
| お店を探す | エリア・ジャンルのチップ、検索ボックス（店名・料理・住所・メモ） |
| 並べかえ | おすすめ順／★が高い順／口コミが多い順／名前順 |
| くわしく見る | カードをタップ → 住所・カテゴリ・「Googleマップで見る」「口コミを読む」 |
| 記録する | 詳細で ❤️ 行きたい／✅ 行った、メモ（入力したら自動保存） |
| 迷ったら | 上の「🎲 きょうの一軒」。いまの絞りこみの中から、まだ行っていない店を1軒えらぶ |

行った店の数は上のバーに「制覇 3 / 217」と出る。

## おすすめ順のきめかた

★だけで並べると、口コミが少ない店の★4.9が上に来てしまう。
そこで「口コミ500件ぶんの★4.0」を足してから平均をとる（ベイズ平均）。

    おすすめ度 = (4.0 × 500 + ★ × 口コミ件数) ÷ (500 + 口コミ件数)

口コミが多いほど本来の★に近づき、少ない店は4.0寄りに割り引かれる。
図鑑の No. はこのおすすめ度の順位。

## データ

- `data.js` は `tools/gourmet-zukan/build.py` が書く（**てで なおさない**）。
  「エリア × ジャンル」（9 × 18 通り）で Googleマップを検索し、出てきた約1,600軒から基準をこえた店を残す。
- ★と口コミ件数は**取得日の値**（画面下に日付を出している）。ときどき取りなおす:

      python3 tools/gourmet-zukan/build.py            # 取得して data.js を書く
      python3 tools/gourmet-zukan/build.py --offline  # キャッシュだけで書きなおす（基準を変えたとき）

  キャッシュは `tools/gourmet-zukan/cache/`（git には入れない）。取りなおすときは消してから走らせる。
- 基準（`MIN_RATING` / `MIN_COUNT`）、エリア、ジャンルの振りわけは `build.py` の先頭で変えられる。
- お店の `id` は Google の place_id。記録（localStorage）はこれで紐づく。
- 営業時間・定休日・予算は入れていない。行く前に Googleマップで確認する。
- Google の★は、口コミ投稿で特典をつけている店などで高めに出ることがある。あくまで目安。

## 保存

記録は この端末の localStorage（キー: `yokohama-gourmet-zukan:v1`）。サーバには送らない。

## メモ

- 大人向けなので、`pages-root/index.html` の「あそびメニュー」には載せていない
  （`yokohama-gourmet-map` と同じあつかい）。
- 姉妹アプリ `yokohama-gourmet-map` は自分で店を記録していく地図。こちらは Google の評価で選んだ一覧。
