# にほん タイムマシン ⏳🗾

**タイムマシンの レバーを うごかすと 時が すすみ、日本列島の ちずに できごとの ピンが 1つずつ ふえていく** あそび。
大陸の はしっこ だった ころから いままで、日本の 歴史の 流れを ちずと「じだいの おび」で たどる（分野: れきし・ちり・ちきゅう）。

`rosenzu-timemachine/`（ろせんず タイムマシン）の しくみ（レバー → ワープ → 「つぎに おきるのは どれ？」クイズ → ずかん・バッジ）を つかった べつアプリ。
対象：5さい〜小学生。`index.html` を ひらくだけで あそべます（外部ライブラリなし・1ファイル）。

1. レバーを うごかすと 年が びゅーんと すすむ（とても むかしは「○まんねん まえ」を 対数で すすめる）
2. ちずに できごとの ピンが ささる。ピンを タッチすると くわしい ページ（ふりがな つき・おとなむけ メモ・関連アプリへの リンク）
3. とちゅうで ストップ →「つぎに おきるのは どれ？」。まちがえると「もう おきたよ（○○じだい）」「もっと あとで おきるよ」
4. ★「せいじの ちゅうしん」が 飛鳥 → 平城京 → 平安京 → 鎌倉 → 京都 → 江戸 → 東京 と うごく
5. パネルの したの「じだいの おび」（ちきゅう・旧石器〜令和の 17こ）で、いま どの じだいか わかる
6. いまに つくと ぜんぶの ピンが 光る。見た できごとは **できごと ずかん** に はいる。🏅 バッジ 10こ

## しくみ

- データは `index.html` の `ERAS`（じだい・色）・`EVENTS`（できごと）・`COURSES`（たびごとの できごと）・`CAPS`（★の 場所）・`APPS`（関連アプリ）
  - `EVENTS` の 文は `{漢字|よみ}` で 書く → 画面は ふりがな、こえは よみを よむ
  - `at` は [経度, 緯度]（2か所は 配列の 配列、おきなわは `'oki'`）。`P()` で ちずの 座標に する
- クイズの 場所は たびごとに `q`（もん数）から 自動で きめる。まちがいの 選択肢は「すこし まえ」と「すこし あと」の できごと
- 音は WebAudio の 合成音。🔊 おと・🗣 こえ（ブラウザの よみあげ）を オン/オフ
- 記録は localStorage `nihon-timemachine-v1`（クリア回数・さいこうの ほし・ずかん・バッジ・設定）
- たてスマホは ちずが うえ、よこタブレットは ちずが ひだり
