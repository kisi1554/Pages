# でんしゃトーク ほしぞらのたんけん(絵本)

`densha-talk` アプリのキャラクター7人(ろまんちゃん・やまのてん・ぎんじろう・まるこ・
けいきゅん・とうかいくん・うえとうくん)が、星空と地球をめぐる夜の冒険をする
絵本です。全30ページ。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ブラウザで読める絵本本体。ページめくり + **おんせいよみあげつき** |
| `densha-talk-hoshizora-ehon.pptx` | 同じ絵本の PowerPoint 版(全30ページ) |
| `generate.js` | `pptxgenjs` で pptx を生成するスクリプト |

## `index.html` について

- `index.html` をブラウザで開くだけで遊べます(ビルド・サーバー不要)。
- 各ページの本文を、端末の読み上げ機能(Web Speech API)で自動的によみあげます。
  `densha-talk` アプリと同じく **通信は一切しません**(音声はすべて端末内で合成)。
- 「🔊 きく」ボタンでいつでも読み直せます。「🔁 じどう」でページを開いたときの
  自動読み上げのオン/オフを切りかえられます(設定は端末に保存されます)。
- ← → キー、がめんのボタン、スワイプでページをめくれます。
- イラストはすべて SVG で描いていて、画像ファイルは使っていません。

GitHub Pages に置けば、そのままスマホやタブレットからも読めます
(`docs/pages-sync.md` の手順を参照)。

## `densha-talk-hoshizora-ehon.pptx` の作り直しかた

```bash
npm install
node generate.js
```

キャラクターの見た目・色・性格は、どちらの版も `densha-talk/knowledge.js` の
`CHARACTERS` 設定に合わせています。
