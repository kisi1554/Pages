# やよい こめづくり リズム 🌾

**たいこの リズムに あわせて こめを そだてる リズム ゲーム。** 10本シリーズ「じだい たんけん」の やよい じだい編（5才〜）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/yayoi-rhythm/

## あそびかた

1. きょくと はやさを えらぶ（きょく 4つ・はやさ 3だんかい）。
2. たいこの「どん」に あわせて「タップ！」ボタン（または えの どこでも／スペースキー）を おす。
   - リズムが あうと いねが ぐんぐん そだつ。ずれると いねが ふにゃっと まがる（つぎに あえば なおる）。
   - 音を けしても、まるい あいずが 光る・ボタンが きいろく 光るので あそべる。
3. きょくが おわると、こめを たかゆか そうこへ。ねずみが のぼろうとして「ねずみがえし」で しっぱいする（3しゅるいから 2つ）。
4. ひみこの「おつげ」。ほねを 1つ えらぶと、すだれの うしろから 手だけ 出して あしたの てんきを うらなう。
   あたると ほうさく（こめ ボーナス）、はずれると みんなで ずっこける（こめは へらない）。
5. けっか（★1〜3・ほめことば・まなび カード）。「もういちど」「つぎの きょく」で すぐ やりなおせる。1回 1〜2分。

| きょく | しごと | もらえる カード |
| --- | --- | --- |
| 🌱 はる たうえ | たうえ（ぽん・ぽん） | いなさく |
| 🌿 なつ くさとり | くさとり（ぴっ・ぴっ） | たかゆか そうこ |
| 🌾 あき いねかり | いねかり（ざくっ）→ だっこく（とん・とん） | むらから くにへ |
| 🔔 まつり | 4つ ぜんぶ ＋ どうたくの かね | どうたく |

「ひみこと やまたいこく」の カードは さいしょの おつげの あとに もらえます。

## れきしの あつかい

- 稲作の伝来年代は諸説あり（紀元前10世紀ごろ説／紀元前5〜4世紀ごろ説）、保護者むけの 小さい字で 併記。
- 卑弥呼・邪馬台国は『魏志』倭人伝の記述として「〜と つたわる」「〜と 書いて ある」と 書く。239年（238年説あり）。
- 卑弥呼の 姿は 分かっていないので、すだれごしの かげと 手だけ。「はずかしがり」や おつげの場面は 想像と 明記
  （倭人伝の「見た人は少ない」「骨を焼いて占う」という記述を もとにした 演出）。
- 銅鐸の 使い道は「〜と かんがえられて いる」。
