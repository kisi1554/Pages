# そろばん どうじょう 🧮

**がめんの そろばんで、かずの あらわしかたと 5・10 の こつを まなぶ アプリ。**
年長〜小学生むけ（小3 算数の そろばん、ならいごとの よしゅう）。`index.html` を ひらくだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/soroban-dojo/

## そろばん

- いまの **1・4 そろばん**（うえに 5だま 1こ、したに 1だま 4こ）。SVG で もくめ・はり・つやの ある たまを コードで かく。
- **ていいてん（てん）** は はりの うえに 3けた ごと。みぎから 2ばんめの けた（てん つき）が **いちの くらい**。
  その みぎの けたは しょうすう（0.1）として よむ。
- けたの かず: よこもち（1024px）で 13けた・けたはば 66px、たてもち（390px）は けたを へらして 7けた・けたはば 約48px。
- たまの うごかしかた:
  - **タップ** … その たまの ところまで うごく（したの 1だま 3こめを タップ → 3 に なる。あがって いる たまを タップ → さがる）
  - **スワイプ** … うえ・したに はじく
  - **ゆびの アイコン**: 1だまを あげる＝👍 おやゆび、1だまを さげる・5だま＝☝️👇 ひとさしゆび（せってい で オフ）
- **ごはさん**: したの たまを さげて、ひとさしゆびで はりを なぞるように 5だまを あげる アニメ＋ジャラッ。
  speechSynthesis が あれば「ごはさんで ねがいましては」と よみあげ。

## ステップ（それぞれ 5もん、まちがいの かずで ★1〜3）

| ステップ | ないよう |
| --- | --- |
| 1 かずを おく | 1〜9 / 10〜99 / 100〜999（ていいてんで くらいを きめる） |
| 2 かんたん | たまが たりる たしざん・ひきざん（1けた・2けた） |
| 3 5の あわせ・わかれ | 4 を たす → 5 を いれて 1 を はらう ／ 4 を ひく → 1 を いれて 5 を はらう |
| 4 10の あわせ・わかれ | 7 を たす → 3 を はらって となりに 1 ／ 7 を ひく → となりから 1 とって 3 を いれる |
| 5 5と10の くみあわせ | 6＋7、13−6 など |
| 6 みとりざん | 2けた・3けた の かずを たてに 3〜4こ（ひきざん も） |

- ステップ3〜5 は さいしょに **こつの みほん**（アニメ＋せつめい）→ おなじ かたちを れんしゅう。
- まちがえると、**ちがう ところの たまが あかく** なり、ただしい うごきを ゆっくり さいせい（けたを きいろく ひからせ、ゆびも だす）。
- 「▶ みほん」で いつでも ただしい うごきを みられる。

## てじゅんの きまり（`soroban.js`）

- たかい くらい から じゅんに うごかす。
- たしざん: いれられる → そのまま ／ 1だまが たりない → **5の あわせ**（5 を いれて あいかたを はらう）／
  10を こえる → **10の あわせ**（あいかたを はらって、となりに 1）。はらう ときに 5の わかれ が いれば **5と10**。
- ひきざん: はらえる → そのまま ／ 1だまが たりない → **5の わかれ**（あいかたを いれて 5 を はらう）／
  たりない → **10の わかれ**（となりから 1 とって、あいかたを いれる）。いれる ときに 5の あわせ が いれば **5と10**。
- くりあがり・くりさがりは となりの けたへ れんさ する（999＋1、1000−1）。
- テストでは 1けた どうし（0〜9 に 1〜9、となりの けた 0〜9）を たし・ひき ぜんぶ ためし、
  こたえ・たまの うごきが ありえるか・ゆび・しゅるい（そのまま／5／10／5と10）の かたちを たしかめる。
