# ポンコツロボの まるつけ 🤖

ロボの **ポンコツくん** が といた さんすうの テストを、子どもが **せんせい役** で まるつけ する ゲーム（5さい〜）。
こたえが あっているか じぶんで たしかめる 力（けんさん）と、まちがいの どこが へんかに 気づく 力を そだてる。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. ポンコツくんが 1もんずつ こたえを かく（かきかき…）。
2. あっていたら ○、まちがいなら ✕ を つける。
   - ○ が ただしい → ポンコツくんが まっかに なって てれる。
   - ✕ が ただしい → 「ガーン！」と あたまの ねじが とぶ。すうじボタンで **ただしい こたえ** を かいて あげる と、ねじが もどって「おぼえたよ！」。
   - つけまちがえたら ポンコツくんが「ほんとう？ りんごで かぞえて みて！」と いい、🍎 で たしかめて やりなおせる。
3. 🍎「りんごで たしかめる」は いつでも つかえる。りんごを タッチすると 1, 2, 3… と ばんごうが つく。
   ひきざんは たべた ぶんに ✕ が ついている。
4. 10もんで おわり（1〜3ぷん）。ポンコツくんの てんすうと、まちがいを なおした テストが でる。
   **まるつけを 1かいも まちがえずに おわると 🎖️ せんせいバッジ**。さいごは「せんせい ありがとう！」。

## まちがいの しゅるい

| しゅるい | れい |
| --- | --- |
| 1 ずれ | 4＋3＝8 |
| たすと ひくを とりちがえ | 5−2＝7、4＋1＝3 |
| 6 と 9 の かきまちがい | 3＋3＝9、10＋6＝19 |
| わらい用（1テストに 1もんまで） | 3＋2＝バナナ／1＋1＝おにぎり／2＋2＝9999999（かみから はみだす） |

わらいの えんしゅつ（ガーン・てれる・ねじ）は まるつけの **あと** に でる。ポンコツくんは しかられても すぐ げんきに なり、ばかに する ことばは つかわない。

## レベル

| レベル | なかみ | まちがい |
| --- | --- | --- |
| 1 | 5までの たしざん | 10もん中 4〜6もん |
