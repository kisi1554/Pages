# 平面図形 解法パターン40

中学受験の平面図形を、**サイン（図のどこを見るか）→ 型 → 例題** の形で40パターンに整理した解法集。
想定ユーザーは受験生（小4〜小6）と保護者。受験生が読む前提なので、ほかのアプリと違い
学年相応の漢字を使い、ふりがなは付けていない。

## 内容

| 分野 | 番号 | 主なパターン |
| --- | --- | --- |
| 角度 | 01〜09 | 平行線と折れ線、ブーメラン型、ちょうちょ型、星形、二等辺の連鎖、多角形、折り返し、正方形＋正三角形、半径で二等辺 |
| 面積 | 10〜21 | 底辺比、等積変形、長方形の中の点、全体から引く、寄せる、差が等しい、対角線×対角線÷2、30°の三角形、正六角形、外側の正方形、隣辺比、ピックの定理 |
| 相似と比 | 22〜31 | ピラミッド型、砂時計型、面積比は2乗、台形の4分割、面積を2通りで、角の二等分線、平行四辺形の中の砂時計、連比、平行線の補助線、かくれた合同 |
| 円・おうぎ形 | 32〜38 | おうぎ形の基本、葉っぱ形、半径×半径、三日月、回転移動の通過範囲、ひもの長さ、転がる円 |
| 移動 | 39〜40 | 平行移動と重なり、点の移動と面積 |

ほかに「5つの基本動作」「見ぬきチャート（図のサイン→パターン）」「3.14の早見表」を載せている。

## 機能

- 分野で絞りこみ・ことばで検索・未マスターだけ表示
- 各パターンの「マスターした」チェックは localStorage（`heimen-pattern-done`）に保存
- 「解答をぜんぶ開く」、印刷時は解答を展開して1パターンずつ改ページしない
- 図はすべて手書きのインライン SVG（形をつかむためのもので、長さ・角度は正確ではない）
- 音は使わない
