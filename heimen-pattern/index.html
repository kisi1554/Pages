使いかた

  1. サイン（図のどこを見たらその型を使うか）を読む
  2. 型を声に出して言えるようにする
  3. 例題を図をノートに写して解き、「解答」を開いて確かめる
  4. 何も見ずに解けたら「マスターした」にチェック（この端末に保存されます）

※ 図は形をつかむためのもので、長さ・角度は正確ではありません。

図形を解く 5つの基本動作

  1. しるしをつける … 等しい長さ・等しい角・平行・直角を図に書きこむ
  2. 補助線を引く … 平行線／垂線／中心と結ぶ／延長する、の4種類
  3. 分ける・まとめる … 知っている形（三角形・おうぎ形）に分けるか、全体から引く
  4. 移す … 等積変形・回転・寄せる で、ばらばらの部分を1か所に集める
  5. 比を書きこむ … 長さの比 → 面積の比、を図の中で順につないでいく

角度（01〜09）

「三角形の内角の和180°」「外角＝となりあわない内角の和」「平行線の錯角・同位角」の3つで、ほぼすべて解ける。

01平行線と折れ線

🔍 サイン：2本の平行線のあいだに「くの字」の折れ線

左向きの角の和 ＝ 右向きの角の和

  1. 折れ曲がる点を通る平行線（赤の点線）を引く
  2. 錯角で角を2つに分けて移す

例題 ℓとmは平行です。xは何度？

解答

折れ点を通りℓに平行な線を引くと、錯角で x は 30° と 45° に分かれる。
x＝30＋45＝75°

折れ点が2つ以上あっても「左向きの和＝右向きの和」がそのまま使える。

02ブーメラン型（へこんだ四角形）

🔍 サイン：矢じりのように1か所へこんだ四角形

へこんだ角 x ＝ 残り3つの角の和

  1. 左の頂点からへこんだ点への線を延長する
  2. 「外角＝となりあわない2つの内角の和」を2回使う

例題 xは何度？（x は へこんだ点の下側の角）

解答

延長線と右上の辺の交点で、外角は 25＋80＝105°。もう一度外角を使って x＝105＋30＝135°

公式として x＝a＋b＋c と覚えてしまってよい。

03ちょうちょ型（8の字）

🔍 サイン：2本の線分が交わって、向かい合う三角形が2つできている

a ＋ b ＝ c ＋ d（向かい合う2角の和が等しい）

  1. 交わった点の角は対頂角で等しい
  2. だから三角形の残り2角の和も等しい

例題 xは何度？

解答

50＋70＝60＋x より x＝60°

04星形の先端の角

🔍 サイン：一筆書きの星（五芒星）、先端の角を問われる

先端5つの角の和 ＝ 180°

  1. ちょうちょ型（03）で2つの角を1つの三角形の中へ移す
  2. 5つの角が1つの三角形に集まるので 180°

例題 xは何度？

解答

x＝180−(30＋35＋40＋45)＝30°

先端が7つ・9つの星は「ちょうちょ型で集める」か「外側の多角形から考える」。

05二等辺三角形の連鎖

🔍 サイン：同じ長さの線分がジグザグにつながっている

外角をつかうと、角が「20°→40°→60°…」と1つ分ずつ増える

  1. 等しい辺にしるしをつけ、二等辺三角形の底角を書く
  2. 外角＝となりあわない内角の和 で次の三角形へ

例題 ∠O＝20°、OB＝BC＝CD＝DE のとき、x（∠DEC）は何度？

解答

△OBC：∠BCO＝20° → 外角 ∠CBD＝40°。△BCD（CB＝CD）：∠CDB＝40°。
△OCD の外角 ∠DCE＝20＋40＝60°。△CDE（DC＝DE）なので x＝60°

06多角形の内角と外角

🔍 サイン：正多角形・「〇角形の内角の和」

内角の和＝180°×(N−2)　外角の和＝いつでも360°

  1. 正多角形の1つの角は「外角＝360°÷N」から出すのが速い
  2. 内角＝180°−外角

例題 (1) 正八角形の1つの内角は？ (2) 1つの内角が156°の正多角形は正何角形？

解答

(1) 外角 360÷8＝45° → 内角 180−45＝135°
(2) 外角 180−156＝24° → 360÷24＝15 → 正十五角形

対角線の本数：N×(N−3)÷2 本。

07折り返し（帯・長方形を折る）

🔍 サイン：紙を折った図。折り目がある

折り返した角は元の角と等しい ＋ 平行線の錯角 → 重なりは二等辺三角形

  1. 折り目の両側に同じ角を書く
  2. 帯の上下の辺は平行なので錯角を移す

例題 帯を図のように折りました。折り目と帯の辺のつくる角が65°のとき、xは？

解答

重なった三角形は、折り返しと錯角で2つの角がどちらも65°。
x＝180−65×2＝50°

08正方形＋正三角形

🔍 サイン：正方形・正三角形・ひし形が組み合わさっている

「同じ長さの辺」を探して二等辺三角形を見つける

  1. 正方形の辺＝正三角形の辺 にしるし
  2. 二等辺三角形の頂角 → 底角 の順に出す

例題 正方形ABCDの中に正三角形EBCがあります。x（∠AED）は？

解答

BA＝BC＝BE なので △ABE は二等辺三角形。∠ABE＝90−60＝30° → ∠BAE＝(180−30)÷2＝75° → ∠EAD＝15°。
同じく ∠EDA＝15° なので x＝180−15×2＝150°

09円の中は半径で二等辺

🔍 サイン：円の中心と円周上の点を結んだ線

半径はぜんぶ同じ長さ → 中心と結べば二等辺三角形

  1. 中心から周上の点へ補助線（半径）を引く
  2. 二等辺三角形の底角が等しいことを使う

例題 Oは円の中心。∠OAB＝25°、∠OCB＝35° のとき、x（∠ABC）は？

解答

OA＝OB より ∠OBA＝25°、OB＝OC より ∠OBC＝35°。x＝25＋35＝60°

面積（10〜21）

公式で出ない形は「分ける・引く・移す」。高さが同じなら底辺の比、が面積比の出発点。

10高さが同じ → 面積比＝底辺比

🔍 サイン：1つの頂点から向かいの辺に線が引かれ、辺の比がわかる

高さが同じ三角形の面積の比 ＝ 底辺の比

  1. 頂点が同じで底辺が一直線 → 高さは同じ
  2. 全体を比の和で割り、ほしい分だけかける

例題 BD：DC＝2：3、△ABC＝40cm² のとき △ABD は？

解答

40×2/5＝16cm²

11等積変形

🔍 サイン：平行線上に三角形の頂点がある、台形の対角線

底辺が同じで平行線上なら、頂点を動かしても面積は同じ

  1. 平行線と、共通の底辺を見つける
  2. 共通の部分を引くと「ななめの2つ」が等しいとわかる

例題 台形ABCD（AD∥BC）の対角線の交点がO。△ABO＝8cm² のとき △DCO は？

解答

△ABC と △DBC は底辺BCが同じで、AD∥BC なので高さも同じ → 面積が等しい。
どちらからも △OBC を引くと △ABO＝△DCO＝8cm²

12長方形の中の点

🔍 サイン：長方形（平行四辺形）の中の1点と、4つの頂点を結んだ図

向かい合う2つの三角形の和 ＝ 長方形の半分

  1. 上と下の三角形は底辺が同じ（横の長さ）
  2. 高さの和＝たての長さ → 面積の和は半分

例題 横10cm、たて6cmの長方形。△PAB＝12cm² のとき △PCD は？

解答

10×6÷2＝30、30−12＝18cm²

平行四辺形でも同じ。左右の2つの和も半分。

13全体から引く

🔍 サイン：長方形の中にななめの三角形。まわりは直角三角形

ほしい面積 ＝ 全体 − まわりの直角三角形

  1. まわりを公式で出せる形に分ける
  2. 全体から引く

例題 長方形ABCD（横12cm、たて8cm）。AE＝6cm、BF＝4cm。△DEF は？

解答

全体 96。△AED＝6×8÷2＝24、△EBF＝6×4÷2＝12、△FCD＝4×12÷2＝24。
96−24−12−24＝36cm²

14寄せる（道の問題）

🔍 サイン：土地に道が通っている、ばらばらの長方形

道を端に寄せると、残りは1つの長方形

  1. 道を左（上）の端へ寄せたつもりになる
  2. （横−道の幅）×（たて−道の幅）

例題 横20m、たて15mの土地に、幅2mの道がたて・横に1本ずつ。道以外の面積は？

解答

(20−2)×(15−2)＝18×13＝234m²

ななめの道でも、横に測った幅が同じなら平行四辺形として寄せられる。

15差が等しい（共通部分を足す）

🔍 サイン：「アとイの面積が等しい」「アとイの差は？」

ア＝イ なら、どちらにもウを足して（ア＋ウ）＝（イ＋ウ）

  1. アとイの「あいだ」にある共通部分ウを見つける
  2. ア＋ウ、イ＋ウ がどちらも公式で出せる形になる

例題 半径10cmの四分円と、横10cm・たて x cm の長方形。アとイの面積が等しいとき x は？

解答

ア＋ウ＝四分円＝10×10×3.14÷4＝78.5、イ＋ウ＝長方形＝10×x。
10×x＝78.5 → x＝7.85cm

16対角線×対角線÷2

🔍 サイン：正方形・ひし形・たこ形（対角線が直角に交わる四角形）

対角線が直交する四角形 ＝ 対角線×対角線÷2

  1. 円の中の正方形は、対角線＝直径
  2. 辺の長さがわからなくても面積が出る

例題 半径5cmの円にぴったり入る正方形の面積は？

解答

対角線＝直径＝10cm。10×10÷2＝50cm²

1730°の三角形（正三角形の半分）

🔍 サイン：30°・150°・15°・75° の角がある

30°・60°・90°の三角形は、いちばん短い辺 ＝ 斜辺の半分

  1. 30°の角の向かいの頂点から垂線を引く
  2. 正三角形を半分にした形が出てくる → 高さが出る

例題 AB＝AC＝8cm、頂角Aが30°の二等辺三角形の面積は？

解答

Cから AB に垂線 CH を引くと、△ACH は正三角形の半分なので CH＝8÷2＝4cm。
8×4÷2＝16cm²

「頂角30°の二等辺三角形＝等辺×等辺÷4」と覚えてもよい。

18正六角形は正三角形6つ

🔍 サイン：正六角形の中に三角形・四角形

中心と頂点を結ぶと、合同な正三角形が6つ

  1. 中心から6本の線を引く（必要なら 6等分 → 24等分）
  2. ほしい部分が正三角形いくつ分かを数える

例題 面積60cm²の正六角形。1つおきの頂点を結んだ正三角形（色の部分）の面積は？

解答

小さい正三角形1つは 60÷6＝10。はみ出た3つの三角形は、それぞれひし形（正三角形2つ）の半分＝10。
60−10×3＝30cm²（ちょうど半分）

19外側に正方形をかく

🔍 サイン：ななめに置かれた正方形、方眼の上のななめの図形

ななめの正方形 ＝ 外側の大きな正方形 − 直角三角形4つ

  1. 外側にまっすぐな正方形（長方形）をかく
  2. すみの直角三角形を引く

例題 直角をはさむ辺が3cmと4cmの直角三角形4つで、図のように正方形を囲みます。色の正方形の面積は？

解答

外側は1辺7cm → 49。三角形4つは 3×4÷2×4＝24。49−24＝25cm²

面積25 → 1辺5cm。三辺が3・4・5の直角三角形は入試の常連。

20隣辺比（1つの角を共有する三角形）

🔍 サイン：大きな三角形の2辺上に点があり、角をはさんだ小さな三角形

△ADE ÷ △ABC ＝（AD/AB）×（AE/AC）

  1. 底辺比（10）を2回つかうのと同じ
  2. 分数をかけるだけで一気に出る

例題 AD：DB＝2：1、AE：EC＝3：1、△ABC＝48cm²。△ADE は？

解答

48×2/3×3/4＝24cm²

21格子点の図形（ピックの定理）

🔍 サイン：点が等間隔にならんだ方眼の上の多角形

面積 ＝ 内部の点の数 ＋ 周上の点の数÷2 − 1

  1. 図形の内側の点と、辺の上の点を分けて数える
  2. 式に入れる（検算に便利）

例題 点の間隔が1cmのとき、図の四角形の面積は？

解答

内部の点5個、周上の点8個 → 5＋8÷2−1＝8cm²
検算：対角線4cm×4cm÷2＝8cm² ✓

記述式では「外側の正方形から引く（19）」で書くほうが安全。

相似と比（22〜31）

平行線を見たら「ピラミッド」か「砂時計」。長さの比 → 面積の比（2乗）へつなぐ。

22ピラミッド型の相似

🔍 サイン：三角形の中に、底辺と平行な線

DE∥BC なら △ADE と △ABC は相似（AD：AB＝DE：BC）

  1. 小さい三角形と大きい三角形の対応する辺を合わせる
  2. AD：DB ではなく AD：AB を使うのがコツ

例題 DE∥BC、AD：DB＝2：3、BC＝15cm。DE は？

解答

AD：AB＝2：5 → DE＝15×2/5＝6cm

23砂時計型の相似

🔍 サイン：平行な2本の線分の端をクロスに結んだ形

AB∥CD なら AO：OD ＝ BO：OC ＝ AB：DC

  1. 平行な2辺の長さの比が、そのまま交点で分けた比になる
  2. 台形の対角線の交点もこれ

例題 AB∥CD、AB＝6cm、CD＝9cm、AD＝10cm。AO は？

解答

AO：OD＝6：9＝2：3 → AO＝10×2/5＝4cm

24相似比 → 面積比は2乗

🔍 サイン：相似な図形の「面積」を問われる

相似比 a：b → 面積比 a×a：b×b

  1. まず相似比（小：大）を出す
  2. 2乗して面積比。台形部分は「大−小」

例題 DE∥BC、AD：DB＝2：1、△ABC＝45cm²。△ADE と 台形DBCE の面積は？

解答

相似比 2：3 → 面積比 4：9。△ADE＝45×4/9＝20cm²、台形＝45−20＝25cm²

25台形の対角線で4分割

🔍 サイン：台形に2本の対角線、4つの三角形の面積

上底：下底＝a：b → 上：左：右：下 ＝ a×a：a×b：a×b：b×b

  1. 砂時計（23）で対角線が a：b に分かれる
  2. 底辺比（10）で4つの面積比が決まる

例題 上底2cm、下底3cmの台形。上の三角形が8cm²のとき、台形全体は？

解答

比は 4：6：6：9。4が8cm² なので 1あたり2。
(4＋6＋6＋9)×2＝50cm²

26面積を2通りで表す

🔍 サイン：直角三角形の、斜辺への高さ（垂線）を問われる

（底辺×高さ）を、別の辺を底辺にしてもう1回書く

  1. 直角をはさむ2辺で面積を出す
  2. 斜辺を底辺と見て、高さを逆算する

例題 ∠A＝90°、AB＝3cm、AC＝4cm、BC＝5cm。AH の長さは？

解答

面積＝3×4÷2＝6。5×AH÷2＝6 → AH＝2.4cm

△ABC・△HBA・△HAC はすべて相似（直角三角形の中の相似）。BH＝1.8cm、HC＝3.2cm も出せる。

27角の二等分線と比

🔍 サイン：三角形の1つの角を半分にする線

ADが角Aの二等分線なら AB：AC ＝ BD：DC

  1. はさむ2辺の比が、向かいの辺を分ける比になる
  2. （理由：△ABD と △ACD は高さが同じで、Dから2辺までの距離も同じ）

例題 AB＝6cm、AC＝4cm、BC＝8cm。ADは角Aの二等分線。BD は？

解答

BD：DC＝6：4＝3：2 → BD＝8×3/5＝4.8cm

28平行四辺形の中の砂時計

🔍 サイン：平行四辺形の辺の中点と頂点を結んだ線＋対角線

平行四辺形の向かい合う辺は平行 → 砂時計がかくれている

  1. AE∥BC の砂時計で AF：FC を出す
  2. 面積は「大きい三角形 → 底辺比」で細かくしていく

例題 平行四辺形ABCD（面積60cm²）。EはADの中点、BEとACの交点がF。△AFE は？

解答

AF：FC＝AE：BC＝1：2。△ACD＝30、△ACE＝30÷2＝15（AEはADの半分）。
△AFE＝15×1/3＝5cm²

29連比で比をそろえる

🔍 サイン：1本の線分の上に交点が2つ以上ある

それぞれの比を出し、全体の長さを最小公倍数にそろえる

  1. 交点ごとに砂時計などで比を出す（BP：PD、BO：OD）
  2. BDの長さを両方の比の和の最小公倍数にして、BO：OP：PD を出す

例題 長方形ABCD（面積72cm²）。EはCDの中点。AEとBDの交点がP、ACとBDの交点がO。△AOP は？

解答

砂時計で BP：PD＝AB：ED＝2：1、対角線なので BO：OD＝1：1。
BDを6とすると BO＝3、BP＝4 → BO：OP：PD＝3：1：2。
△ABD＝36 → △AOP＝36×1/6＝6cm²

30平行線の補助線で相似をつくる

🔍 サイン：三角形の中で2本の線が交わり、平行線が1本もない

「平行線を1本引く」とピラミッド・砂時計が生まれる

  1. 比がわかっている点を通り、問われた線に平行な線を引く
  2. ピラミッド型で比を移し、もう一度相似を使う

例題 DはBCの中点、AE：EC＝1：2。BEとADの交点がP。AP：PD は？

解答

Dを通りBEに平行な線を引き、ACとの交点をFとする。△CBEで DはBCの中点なので、FはECの中点 → AE：EF：FC＝1：1：1。
△ADFで PE∥DF なので AP：PD＝AE：EF＝1：1

「てんびん（面積比）」や「メネラウスの考え方」でも解ける。まずは平行線の型を確実に。

31かくれた合同（正方形の中心で回す）

🔍 サイン：正方形の中心に、直角の頂点が置かれている

中心のまわりに90°回すと、合同な三角形がぴったり重なる

  1. 中心から辺へ垂直な線（点線）を引く
  2. はみ出た三角形と足りない三角形が合同 → 重なりは正方形の1/4

例題 1辺10cmの正方形の中心Oに、大きな正方形の頂点を重ねました（どの向きでも）。重なる部分の面積は？

解答

Oを中心に考えると、重なりは正方形を4等分した1つ分と同じ面積。10×10÷4＝25cm²

円・おうぎ形（32〜38）

「中心角/360」と「×3.14は最後」。半径がわからなければ「半径×半径」をまとめて求める。

32おうぎ形の面積と弧の長さ

🔍 サイン：中心角と半径がわかるおうぎ形

面積＝半径×半径×3.14×中心角/360　弧＝直径×3.14×中心角/360

  1. 中心角/360 を先に約分する（120°なら 1/3）
  2. ×3.14 は最後に1回

例題 半径6cm、中心角120°のおうぎ形の面積と周りの長さは？

解答

面積：6×6×3.14×1/3＝12×3.14＝37.68cm²
弧：12×3.14×1/3＝4×3.14＝12.56 → 周り＝12.56＋6×2＝24.56cm

「周りの長さ」は半径2本を足し忘れないこと。

33葉っぱ形

🔍 サイン：正方形の中で、2つの四分円が重なった形

葉っぱ ＝ 1辺×1辺×0.57（四分円2つ − 正方形）

  1. 四分円＋四分円 で葉っぱが2回数えられる
  2. 正方形を引けば葉っぱ1枚

例題 1辺10cmの正方形の中の葉っぱ形の面積は？

解答

10×10×3.14÷4×2−10×10＝157−100＝57cm²（＝10×10×0.57）

34半径がわからない → 半径×半径を求める

🔍 サイン：円と正方形が組み合わさり、半径が整数にならない

円の面積に必要なのは「半径×半径」だけ。半径そのものはいらない

  1. 正方形の面積＝対角線×対角線÷2（16）
  2. 対角線＝直径 なので、半径×半径＝対角線×対角線÷4

例題 面積50cm²の正方形の4つの頂点を通る円の面積は？

解答

対角線×対角線÷2＝50 → 対角線×対角線＝100 → 半径×半径＝100÷4＝25。
25×3.14＝78.5cm²

35三日月（ヒポクラテスの月）

🔍 サイン：直角三角形の3辺を直径とする半円

三日月2つの和 ＝ 直角三角形の面積

  1. （小半円＋小半円＋三角形）−大半円 ＝ 三日月
  2. 小半円2つ＝大半円 なので、残るのは三角形だけ

例題 直角をはさむ辺が3cm・4cm、斜辺5cmの直角三角形。色の三日月2つの面積の和は？

解答

小半円2つ：(1.5×1.5＋2×2)×3.14÷2＝6.25×3.14÷2、大半円：2.5×2.5×3.14÷2＝6.25×3.14÷2 で等しい。
三日月＝三角形＝3×4÷2＝6cm²

36回転移動の通過範囲

🔍 サイン：図形を1点のまわりに回転させ「通った部分」「色の部分」を問う

移動後の図形＋おうぎ形 − 移動前の図形 → 同じ図形どうしが消える

  1. 回転の中心からいちばん遠い点がえがくおうぎ形を見つける
  2. 移動前と移動後の図形は同じ面積なので相殺する

例題 直径10cmの半円を、点Aを中心に45°回転させました。色の部分の面積は？

解答

色＝半円（後）＋おうぎ形 − 半円（前）＝おうぎ形。
10×10×3.14×45/360＝39.25cm²

37円をたばねるひも

🔍 サイン：同じ大きさの円（缶・丸太）をひもでしばる

ひも ＝ 直線部分（中心どうしの距離）＋ 曲線部分（合わせてちょうど円1周）

  1. 直線部分は中心を結んだ線と同じ長さ
  2. 曲線部分のおうぎ形の中心角の合計は360°

例題 半径5cmの円3つを、図のようにひもでたばねます。ひもの長さは？

解答

直線：10×3＝30cm。曲線：円1周＝10×3.14＝31.4cm。合計 61.4cm

何個たばねても、どんな並びでも「曲線部分＝1周」は変わらない。

38図形のまわりを転がる円

🔍 サイン：円が多角形の外側（内側）をすべらずに1周する

外側を回るとき：中心の道のり ＝ 多角形の周 ＋ 半径の円1周

  1. 辺の上は、辺と同じ長さだけまっすぐ進む
  2. 角ではおうぎ形をえがく。外角の和は360°なので合わせて円1周

例題 半径1cmの円が、1辺6cmの正方形の外側を1周します。(1) 円の中心が動いた長さ (2) 円が通った部分の面積

解答

(1) 6×4＋2×3.14＝24＋6.28＝30.28cm
(2) 長方形 6×2 が4つ＝48、角の四分円（半径2）4つ＝2×2×3.14＝12.56 → 60.56cm²

内側を回るときは、すみに円が届かない部分ができる。図をかいて確かめる。

図形・点の移動（39〜40）

「形が変わる瞬間」で時間を区切る。区切りごとに図をかけば、ふつうの面積問題になる。

39平行移動と重なり

🔍 サイン：図形が一定の速さで動き、重なった部分の面積を問う

「入りはじめ・全部入る・出はじめ・出きる」で時間を区切る

  1. 区切りの時刻を先に出す（ここでは 0・4・10・14秒）
  2. 区間ごとに「重なり＝たて×動いた長さ」などの式にする

例題 1辺4cmの正方形が、横10cm・たて4cmの長方形に向かって秒速1cmで右へ動きます（ふれた時を0秒）。重なりが10cm²になるのは何秒後？（2回）

解答

0〜4秒：重なり＝4×秒 → 10÷4＝2.5秒後。4〜10秒は16cm²で一定。10〜14秒で減る → 14−2.5＝11.5秒後

グラフは「台形」の形になる。グラフから図を、図からグラフを読めるように。

40点の移動と面積

🔍 サイン：点が辺の上を動き、三角形の面積が時間で変わる

点がどの辺にいるかで場合分け。向かいの辺にいる間は面積が一定

  1. 点がいる辺ごとに、底辺と高さのどちらが変わるかを見る
  2. 変わるほうを「速さ×時間」で表す

例題 長方形ABCD（AB＝6cm、BC＝10cm）。点PはBを出て B→C→D と秒速2cmで動きます。(1) △ABPが24cm²になるのは何秒後？ (2) PがCD上にあるとき△ABPは？

解答

(1) BP＝2×秒 → 6×2×秒÷2＝6×秒＝24 → 4秒後
(2) 底辺AB＝6、高さはいつもBC＝10 → 6×10÷2＝30cm²（一定）
