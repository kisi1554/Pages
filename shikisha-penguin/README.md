# しきしゃ ペンギン 🐧🎼

どうぶつの オーケストラを しきする おんがくアプリ（5さい〜）。
タクトを ふる はやさで おんがくの **はやさ（テンポ）**、ふる 大きさで **つよさ（フォルテ・ピアノ）** が かわる。

公開URL: https://kisi1554.github.io/Pages/shikisha-penguin/

## あそびかた

- したの ピンクの ところを ゆびで よこに ふる（3かい ふると はじまる）。
  - ふりかえしの かんかく ＝ 1はく。はやく ふると はやく、ゆっくり ふると ゆっくり。
  - ふりはばが 小さいと よわく（p）、大きいと つよく（f）、まんなかは mf。
- がっきの どうぶつ（🐰バイオリン・🐘ラッパ・🦍たいこ・🐦ふえ）を タップすると おやすみ／もどる。
- ふるのを やめると えんそうも とまる（しばらくすると みんな いねむり）。

## わらい どころ

- はやすぎ（約175はく/ふん いじょう）→ どうぶつが 目を まわし 💫、おとが ずれて ぐちゃぐちゃ、
  さらに つづけると ペンギンが くるくる まわって ころん（2びょうで おきあがる）。
- ゆっくりすぎ（約42はく/ふん いか）→ みんな いねむり 💤。
- ゴリラは いつも 大きい おとで たたきたがる（たいこだけ よわく ならない。よわく ふりつづけると「ドーン！」）。
- クリアの あとに ペンギンが おじぎ しすぎて ころん、ゴリラの ドラムソロ。

## しくみ

- 曲は 4つとも この アプリの ための オリジナル（実在の 曲は つかっていない）。
  メロディ＋コードから パートごとの 音を 自動で つくる（バイオリン＝メロディと ひくい音、ラッパ＝和音、ふえ＝分散和音、たいこ＝リズム）。
- 音は すべて WebAudio の 合成音。テンポが かわっても すすめられる 先読みスケジューラ。おと オン/オフ あり。
- ふる 領域は `touch-action: none`、Pointer Events で 左右の 折りかえしを けんしゅつ。
- 記録（★・カード・おと設定）は localStorage `shikisha-penguin-v1`。
- まなび カードの 事実: テンポ（アダージョ＝ゆっくり、アレグロ＝はやく）、p＝ピアノ／f＝フォルテ／mf＝メゾフォルテ、
  ピアノは もと「ピアノフォルテ」、フルートは きんぞくでも 木管楽器、ティンパニは 音の 高さを かえられる。
