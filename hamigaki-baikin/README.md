# はみがき ばいきん バスターズ 🪥

はに はりついた ばいきんを はブラシで こちょこちょ して あわで つつみ、さいごに うがいで ながす アクションゲーム（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

公開URL: https://kisi1554.github.io/Pages/hamigaki-baikin/

## あそびかた

1. 大きな 口の 中。ばいきんたちが「へへーん」と いばっている。
2. ゆびで こすると はブラシが うごく。ばいきんを こすると「くすぐったい〜」と にげまわり、あわに つつまれて つかまる（🫧）。
   - こする むきが ばしょごとに ちがう（よこ ↔ ／ たて ↕）。むきが あうと よく おちて あわが ぶくぶく ふえる。
     ちがう むきや ゴシゴシ はやすぎると、やさしい ヒントが でる。
   - はの きいろい よごれ（はこう）も こすると きえる。よごれと ばいきんが なくなった はは ぴかっと 光る。
3. ステージ5つ: ① まえば → ② したの おくば → ③ うえの おくば（ボス）→ ④ まえばの うら → ⑤ はと はの あいだ（いとようじ）。
   - ③ では おくの おくから ボス「ガムガム キング」が でてきて、ガムを はりつけて じゃまを する（ガムも こすれば とれる）。
   - ⑤ は いとようじ（F がた フロス）で、はと はの すきまを うえ したに しゅっ しゅっ。
4. 曲に あわせて エリアが かわる。「ほんとう」は 1か所 30びょう × 5 ＝ 2ふん30びょう（じっさいの はみがきに つかえる 長さ）、
   「みじかい」は 12びょう × 5 ＝ 1ぷん。ぜんぶ きれいに なったら「つぎへ」で さきに すすめる。
5. さいごに 💧 うがいボタン → ぶくぶく → ぺっ！ で、あわの なかの ばいきんが ウォータースライダーの ように ながれていく。
6. けっか: エリアごとに ⭐1〜3（つかまえた かず 6わり＋よごれ 4わり）。かならず ほめて おわる。もういっかい できる。

## こどもの は・おとなの は（にゅうし・えいきゅうし）

タイトルの「みがく は」で えらぶと、ゲームの はならびが かわる（さいしょは こどもの は）。

| | まえば | おくば（かたがわ） |
| --- | --- | --- |
| 🧒 こどもの は | にゅうし 6ぽん（あおじろい しろ） | にゅうきゅうし 2ほん |
| 🌱 はえかわり ちゅう | したの まんなか 2ほんが はえたての おとなの は（ふちが ぎざぎざ） | にゅうきゅうし 2ほん ＋ 6さいきゅうし（はえかけ、はんぶん はぐきの なか） |
| 🧑 おとなの は | えいきゅうし 6ぽん（おおきめ、すこし きいろっぽい） | しょうきゅうし 2ほん ＋ だいきゅうし 2ほん（＋おやしらず） |

**ぐらぐらの こどもの は**: 「はえかわり ちゅう」では うえの まえば 1ぽん、「こどもの は」では ときどき（3かいに 1かい）したの まえば 1ぽんが ぐらぐら。
こすると ばねの ように ゆれて、かおが でて「ぐらぐら〜」「やさしく してね〜」と しゃべる。
しばらく みがくと「ぽろっ！」と ぬけて きらきら とんでいき（のっていた ばいきんも いっしょに つかまる）、
あとから おとなの は（ふちが ぎざぎざ）が「こんにちは！ おとなの はだよ」と かおを だす。
ヒントは「むりに ぬかないで、やさしく みがこう」、ぬけたら「うえの はは えんの したへ、したの はは やねの うえへ なげる」むかしからの いいつたえ。
けっかに「ぐらぐらの はが ぬけた！」、タイトルに ぬけた かずの ごうけい（localStorage）。

エリアの ヒントも かわる（6さいきゅうしは「せが ひくいので はブラシを よこから いれて」など）。

🦷 **はの ひみつ** ページ: うえ・したの はならびの ず（こども 20ぽん／はえかわり 24ほんの れい／おとな 28ほん＋おやしらず 4ほん）を
きりかえて みられる。「はえかわり を みる」で、こどもの はの ねっこが とけて ぬけ、したで まっていた おとなの はが はえてくる アニメ。
けっか がめんに まめちしきが 1つ でる。

🎯 れんしゅうでは 1か所だけ えらんで あそべる（スタンプは つかない）。

## たしかめた 事実（日本歯科医師会・日本小児歯科学会 ほか 公的な 資料）

- 歯ブラシは えんぴつを もつ ように（ペングリップ）軽い 力で もち、1〜2本ずつ 小きざみに うごかす。強く ゴシゴシ こすらない。
- みがき残しが 多いのは 奥歯の かみあわせの みぞ・歯と 歯ぐきの さかいめ・歯と 歯の あいだ。
- 前歯の うら側は 歯ブラシを たてに して、かかと（つま先）で かきだす ように みがく。
- 歯と 歯の あいだは 歯ブラシだけでは 落ちにくく、フロス（糸ようじ）を つかう。
- 寝ている あいだは だ液が へって むし歯に なりやすいので、寝る前の はみがきが とくに 大事。
- あまい 飲みものを だらだら・ちびちび 飲むと、口の 中が むし歯に なりやすい 状態が 長く つづく。
- フッ素入り 歯みがき粉を つかったら、うがいは 少量の 水で 1回 程度（4学会合同の 推奨, 2023）。
- 乳歯は 20本（3歳ごろまでに 生えそろう）、永久歯は 28本（親知らずを 入れて 32本、生えない 人も いる）。6歳ごろ〜12歳ごろに 生えかわる。
- 6歳ごろ、乳歯の 奥に 第一大臼歯（6歳臼歯）が 生える。乳歯と 交代せずに 生えるので 気づきにくい。かむ力が いちばん強い。
  生えかけは 背が 低く みがきにくいので、歯ブラシを 口の 横から 入れて みがく。
- 生えたての 永久歯は まだ 未熟で むし歯に なりやすい。乳歯は 永久歯より エナメル質が 薄く、むし歯が 進みやすい。
- 乳歯の むし歯は、後から 生える 永久歯の 歯ならびや 質に 影響する ことが ある。
- 乳歯は 青みがかった 白、永久歯は やや 黄みがかった 色。生えたての 前歯の ふちには ぎざぎざ（切縁結節）が ある。
- 小学校 中学年ごろ までは 保護者の 仕上げみがきが すすめられている（タイトルの「おうちの かたへ」に 記載）。

## しくみ

- デザイン座標 640×520 を 画面に フィット（たて長では くちびるの はしを すこし きって 大きく 表示）。こする canvas は `touch-action: none`。
- こすった 線分の 長さ × こうか（むき・はやさ）で、ばいきんの HP と よごれ（はこう）の こさを へらす。
- 1エリア: さいしょ 4ひき、2ひき より へると「ばぁ！」と つぎが でる（ぜんぶで 7ひき。みじかいは 3→4ひき）。
- 音: はブラシの しゃかしゃか（ノイズ）、くすぐり わらい、ぽん、きらきら、ファンファーレ、BGM（オリジナルの みじかい ループ、エリアごとに 調が かわる）。
  🔊 で オン/オフ。
- 保存: localStorage `hamigaki-baikin-v1`（おと・ながさ・スタンプ・ずかん・さいだい れんぞく）。try/catch で かこむ。
