# カスタと あそぼ 🍮

ぷるぷるの プリンの こ **「カスタ」**（プリンを ぎじんかした オリジナルキャラクター）と あそぶ、
おせわ＆ミニゲームのアプリです（未就学〜小学生むけ）。

`index.html` をブラウザで開くだけで遊べます（外部ライブラリ・音声ファイルなし）。

## あそびかた

| ボタン | できること |
| --- | --- |
| カスタを タップ | ジャンプしたり、ひとこと しゃべったり |
| カスタを なでる（ゆびで こする） | ハートが でて 💛（なかよし）が たまる |
| 🍓 ごはん | いちご・クッキー・りんご・ミルク・ホットケーキ・さくらんぼ から えらんで たべさせる |
| 🛁 おふろ | ゆびで ごしごしすると あわが でて、🫧 が いっぱいに なると カラメルまで ぴかぴか |
| ⚽ あそぶ | 6つの ミニゲームから えらぶ（下の表）。あそぶと 💛 が もらえる |
| 🌙 ねんね | よるに なって ⚡ が かいふく。カスタを タップすると おきる |
| 🎀 おしゃれ | さいしょは あたまに ホイップと さくらんぼ。💛 を あつめると りぼん(5)・ぼうし(15)・おはな(30)・おうかん(50)・めがね(80) が つかえる |

## ミニゲーム

| ゲーム | あそびかた |
| --- | --- |
| 🍓 おやつキャッチ | ゆびで カスタを うごかして、おちてくる おやつを 30びょう キャッチ |
| 🥤 かくれんぼ | カップの したに かくれた カスタを さがす。5かい、だんだん はやく まぜる |
| 🃏 おなじの さがし | しんけいすいじゃく（6ペア）。さいしょに すこし みせてくれる |
| 🔨 ぽこぽこ タッチ | あなから でてくる カスタを 25びょう タッチ。⭐ は 3てん |
| 🎵 まねっこ | ひかった ボタンの じゅんばんを まねする（レベル10で クリア） |
| ✊ じゃんけん | カスタと 5かい しょうぶ（あいこは やりなおし） |

## こえ

カスタの セリフや ゲームの かけごえは、ブラウザの よみあげ（speechSynthesis）で しゃべる。
右上の 🗣️ で こえの オン/オフ（🔊 は こうかおん の オン/オフ）。音声ファイルは つかっていない。

## そのほか

- 🍓 おなか・⚡ げんき・🫧 きれい は じかんで すこしずつ へります（るすの あいだも すこしだけ）。
- へってくると カスタが「おなか ぺこぺこ…」などと おしえてくれます。
- 進み具合は localStorage（`custa-asobo-v1`）に保存。右上 🗣️ で こえ、🔊 で こうかおん の オン/オフ。
- 音は WebAudio の合成音のみ。
