# カスタと あそぼ 🍮

ふわふわの きいろい こいぬ **「カスタ」**（オリジナルキャラクター）と あそぶ、
おせわ＆ミニゲームのアプリです（未就学〜小学生むけ）。

`index.html` をブラウザで開くだけで遊べます（外部ライブラリ・音声ファイルなし）。

## あそびかた

| ボタン | できること |
| --- | --- |
| カスタを タップ | ジャンプしたり、ひとこと しゃべったり |
| カスタを なでる（ゆびで こする） | ハートが でて 💛（なかよし）が たまる |
| 🍮 ごはん | プリン・クッキー・りんご・ミルク・おにぎり・ほね から えらんで たべさせる |
| 🛁 おふろ | ゆびで ごしごしすると あわが でて、🫧 が いっぱいに なると ぴかぴか |
| ⚽ あそぶ | ミニゲーム「おやつキャッチ」（30びょう）。キャッチした かずで 💛 が もらえる |
| 🌙 ねんね | よるに なって ⚡ が かいふく。カスタを タップすると おきる |
| 🎀 おしゃれ | 💛 を あつめると りぼん(5)・ぼうし(15)・おはな(30)・おうかん(50)・めがね(80) が つかえる |

- 🍮 おなか・⚡ げんき・🫧 きれい は じかんで すこしずつ へります（るすの あいだも すこしだけ）。
- へってくると カスタが「おなか ぺこぺこ…」などと おしえてくれます。
- 進み具合は localStorage（`custa-asobo-v1`）に保存。右上 🔊 で 音の オン/オフ。
- 音は WebAudio の合成音のみ。
