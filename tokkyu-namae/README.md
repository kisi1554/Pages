# とっきゅう なまえの なぞ 🏷️

なまえを なくして ぷんぷん おこっている とっきゅうが えきに とうちゃく。
ヒント（はしる ところの ちず・まどから みえる けしき）を みて、3まいの なまえふだから えらんで つけて あげる ゲーム（5さい〜）。
とっきゅうの なまえには、その とちに ゆかりの ある **かわ・やま・うみ・とり・むかしの くに・まち** などが
つかわれている ことを しるのが ねらい。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。
ちずは `map-data.js`（`tools/japan-map/generate_map.py` で つくった 都道府県の かたち。`shinkansen-juudan/` と おなじ もの）。

## あそびかた

1. 「えきへ いく！」で なまえの ない とっきゅうが ぷんぷん 💢 しながら とうちゃく。
2. ちず（はしる くかんが うごく せんで ひかる）・けしきの えもじ・ひとことヒントを みて、なまえふだを えらぶ。
3. まちがえると ふだが でんしゃに ついたあと「それ ぼくじゃない…」と しょんぼり。ふだは うすく なり、なんども やりなおせる。
4. せいかいすると「それそれ！」。つづいて **まにうけ モード**（なまえを ことばどおりに うけとった へんな え。
   サンダーバード → かみなりの とりが でんしゃを つかんで とぶ／ソニック → じぶんの「ガタンゴトン」に おいこされる など）、
   そのあと「ほんとうは？」で なまえの もとの せつめい。わらいは かならず こたえあわせの あとに だす。
5. 「しゅっぱつ しんこう！」で でんしゃが はしりさり、**とっきゅう ずかん** に はいる（にほんちずに はしる ところが ならぶ）。
6. 1かい 5ほん（1〜3ぷん）。さいごに ⭐ と かみふぶき。まだ ずかんに ない とっきゅうから じゅんに でる。

## なかみ

16ほん。データは `index.html` の `TRAINS` 1かしょに まとめてある（なまえ・会社・区間・ちずの みち・由来・まにうけ）。

| なかま | とっきゅう |
| --- | --- |
| 🏞️ しぜん（かわ・やま・うみ・たんぼ） | あずさ・ふじかわ・いしづち・剣山・うずしお・いなほ |
| 🐦 いきもの（とり） | こうのとり・サンダーバード・ひのとり |
| 🏯 とちの なまえ（むかしの くに・まち） | ひだ・しなの・ゆふいんの森・はこね（小田急ロマンスカー）・はしだて |
| 🔤 がいこくの ことば | ソニック（英語）・オホーツク（ロシア語由来の うみの なまえ） |

でんしゃの え・なまえふだは オリジナル（ヘッドマーク・ロゴ・発車メロディは つかわない）。色だけ すこし にせている。

## 由来・区間の たしかめかた

由来が たしかめられなかった とっきゅう（くろしお・やくも・しらさぎ・しまんと など）は のせていない。

と 地名の 事実だけを 書いた（「〜から とった」とは 書いていない）。
