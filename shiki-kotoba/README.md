# しきの ことば 🌸

はる なつ あき ふゆ の ことばを あそびで おぼえて、**季語（きご）** と **はいく** の いりぐちに する アプリ（年長〜小学校中学年むけ）。
`index.html` を ひらくだけで あそべます（がいぶ ライブラリ なし・おとは WebAudio の ごうせいおん）。

公開URL: `https://kisi1554.github.io/Pages/shiki-kotoba/`

## モード

| モード | ないよう |

## 拍（はく）の かぞえかた

- ふつうの かな は 1字 1拍。
- ちいさい「ゃ ゅ ょ ぁ ぃ ぅ ぇ ぉ ゎ」（カタカナも）は まえの 字と あわせて 1拍（「きゅう」＝2拍）。
- ちいさい「っ」、のばす「ー」、「ん」は それぞれ 1拍（「チューリップ」＝チュ・ー・リ・ッ・プ の 5拍）。
- くうはく と 「、。・！？」 は かぞえない。

## 季語の きせつ（データの きめかた）

- **季語の きせつ は 季語として 定着して いる もの だけ** に つけた。ランドセル・ハロウィン は 季語に しない（`""`）。
  ハロウィンは あたらしい 歳時記に のる ことも あるが、まだ 定着して いないと みた。
- 季語の きせつは 旧暦（二十四節気）が もと: はる＝立春（2/4ごろ）〜、なつ＝立夏（5/5ごろ）〜、あき＝立秋（8/7ごろ）〜、ふゆ＝立冬（11/7ごろ）〜。
- **くらし と ずれる ことば（20語）** は 2つの きせつを りょうほう もち、ゲームでは モードで つかいわける:
  - はる → なつ: こいのぼり・かしわもち・こどものひ（端午）・ははのひ・いちご（苺）・たけのこ（筍）・わかば
  - なつ → あき: たなばた・あまのがわ・あさがお・すいか・えだまめ・とうもろこし・ぼんおどり・おぼん（盂蘭盆）・とんぼ
  - あき → ふゆ: おちば（落葉）・しちごさん
  - ふゆ → はる: たこあげ（凧）・バレンタイン（バレンタインの日）
- **おしょうがつ の ことば**（かどまつ・おせち・かがみもち・はつひので など 13語）は 歳時記では「新年」という べつの くくり。
  データでは `shinnen` に して、くらしの きせつ は ふゆ。「はいくの きせつ」クイズと はこ（はいくルール）には だささない。
- **歳時記に よって わかれる もの**: はなび（花火）は いまの おおくの 歳時記で なつ、むかしの 歳時記（盂蘭盆の ころの もの）では あき。
  データは `natsu/aki` に して「どちらも ある」と ひょうじ。クイズ・はこ（はいくルール）には だささない。
- そのほか きを つけた もの: もみじ（紅葉）は あき／おちば は ふゆ、さつまいも は あき／やきいも は ふゆ、
  いなずま は あき／かみなり は なつ、とんぼ（蜻蛉）は あき、せつぶん・まめまき は ふゆ（立春の まえの日）。

## あそびの こまかい ところ

- はこ（くらし）: 4つの きせつから かたよらない ように 10まい。2かい まちがえると こたえの はこを おしえる。いっぱつ せいかい の かずが スコア。
- はこ（はいく）: 10まいの うち 4まいは ずれる ことば。くらしの きせつ の はこに いれると「くらしでは ○○。でも はいくでは べつの きせつ だよ」。
- カルタの CPU: よみふだの ながさ × つよさ（よわい 1.25・ふつう 0.85・つよい 0.55）＋ 0.9〜1.8びょう で とる。
- はいく: ぎょうを タップで えらぶ／ぎょうの ピースを タップで けす。拍が おおいと あかい かず。
