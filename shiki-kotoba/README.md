# しきの ことば 🌸🌻🍁⛄

年長〜小学校中学年むけ。はる・なつ・あき・ふゆ の ことばを あそびで おぼえて、季語と 俳句の 入口に する。

公開URL: https://kisi1554.github.io/Pages/shiki-kotoba/

## あそびかた

| モード | むずかしさ | なにを する |
| --- | --- | --- |
| きせつの はこ | ★ | 1まいずつ 出る ことば カードを、さくら・ひまわり・もみじ・ゆきだるま の 4つの はこへ ドラッグ（タップでも OK）。ただしいと その きせつの 音（うぐいす・せみ・すずむし・かぜ）。「くらしの きせつ／はいくの きせつ」を きりかえられる |
| きせつ カルタ | ★ | よみふだ を きいて（speechSynthesis が あれば よみあげ）、8まいの えふだ から とる。CPU（ゆっくり／はやい）と きょうそう も できる。おてつき は 1.2びょう おやすみ |
| はいくの きせつ | ★★ | 「くらし では なつ。でも はいく では？」。ずれる ことば 6もん ＋ おなじ ことば 2もん。こたえの あと、むかしの こよみ を つかって わけを せつめい |
| はいく を つくろう | ★★ | 5・7・5 の わくに ピース（季語 ＋ ほかの ことば）を はめる。音の かず を じどうで かぞえて ●で 見せる。季語が 2つ 入ると「きせつが ふたつ あるよ」。5・7・5 に なったら ほぞん（10こ まで、あふれたら いちばん ふるい ものと いれかえ） |
| ことば ずかん | | どこかの モードで であった ことばが くらしの きせつ ごとに たまる。🔁 は くらし と はいく で きせつが ちがう ことば |

## ことば データ

`data.js` の 1ぎょう = 1ご: かな・漢字（ふりがな は かな）・え・ジャンル（ぎょうじ／たべもの／いきもの／しょくぶつ／てんき／くらし）・
**くらしの きせつ**・**季語の きせつ**・よみふだ・ひとこと・ずれる わけ。

- 季語の きせつ は 季語として ていちゃく して いる もの だけ。ハロウィン・ランドセル は `''`（季語では ない あつかい）。
- 「しんねん」（おしょうがつ の ことば）は 季語の きせつ だけに ある。くらし では ふゆ。
- 歳時記 に よって わかれる **花火** は `'n/a'`（なつ と あき、どちらも ある）に して、クイズ・はこ の はいく モード には 出さない。
- 季語が ずれる ことば（37ご ＝ 4つの きせつ の ずれ 22ご ＋ しんねん 15ご）:
  - はる → なつ: こいのぼり・こどものひ・かしわもち・ははのひ・いちご・たけのこ・わかば
  - なつ → あき: すいか・とうもろこし・えだまめ・もも・あさがお・ほおずき・ひぐらし・たなばた・あまのがわ・ぼんおどり・おぼん（盂蘭盆）・とんぼ
  - あき → ふゆ: おちば・しちごさん（11/15 は 立冬の あと）
  - ふゆ → はる: たこあげ・ばれんたいん（2/14 は 立春の あと）
  - ふゆ → しんねん: おしょうがつ・おせち・ぞうに・かどまつ・はつひので・ねんがじょう・かるた・はねつき・こままわし・
    かがみもち・はつもうで・おとしだま・かきぞめ・ななくさ
- 運動会・遠足・虹 は 季語では あき／はる／なつ。ほかの きせつ にも ある ことを ひとこと に かいた。
- まちがえやすい もの: もみじ は あき／おちば は ふゆ、さつまいも は あき／やきいも は ふゆ、
  いなずま は あき／かみなり は なつ、せつぶん・まめまき は ふゆ（立春の まえの日）。
- 2026-10 に main 版（162ご）と PC 版（137ご）を あわせた。PC 版を もとに、main 版だけに あった 45ご を たした
  （にゅうがく・そつぎょう は PC 版の にゅうがくしき・そつぎょうしき と かぶるので のぞいた）。
  共通の ことば で 2つの 版の きせつが くいちがう ものは なかった。

### しらべた しりょう（季語の きせつ）

- コトバンク（精選版 日本国語大辞典・デジタル大辞泉 の《季語》表記）: 枝豆＝秋、柏餅＝夏、筍（たかむな・たかんな）＝夏、花火＝夏‐秋
- コトバンク「花火」（日本大百科全書）: 江戸の 俳書 では おおむね 秋（盂蘭盆の 景物）、いまは 夏 と する 歳時記 が 多い → 「どちらも ある」
- 角川 の 季語一覧（凧＝春、苺＝夏）、講談社『芭蕉歳時記』目次（落葉＝冬）
- 蜩・鬼灯・玉蜀黍＝秋 は 歳時記の 秋の部 の 一覧 で 確認
- [季語一覧（バレンタインの日＝初春）](https://www.tkgje.jp/entries/11000/11285_barentain.html)、[西瓜は初秋の季語](https://precious.jp/articles/-/28645)、[JapanKnowledge「季節のことば」](https://japanknowledge.com/articles/kkotoba/05.html)
- それ以外（鯉幟＝夏、七夕・朝顔・西瓜・天の川・盆踊・盂蘭盆・蜻蛉＝秋、若葉＝夏、七五三＝冬、蛙＝春、門松・御節・雑煮・歌留多・独楽・羽子つき・鏡餅・初詣・お年玉・書初・七草＝新年 など）は
  一般の 歳時記（角川『俳句歳時記』の 分類）に もとづく。かきかえる ときは 歳時記 で たしかめて から。

## テスト

```bash
python tools/check-shiki-kotoba.py      # データ ＋ 音の かず（Chromium で ためす）
node --test shiki-kotoba/tests/*.test.js   # node が ある とき（おなじ ケース）
```

音の かず の ルール: ちいさい ゃゅょ・ぁぃぅぇぉ・ゎ は まえの 字と 1つ（ちょ）、
ちいさい っ・のばす ー・ん は それぞれ 1つ。カタカナ も おなじ。
