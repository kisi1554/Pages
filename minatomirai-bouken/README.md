# あおちゃんの みなとみらい だいぼうけん

あおちゃんが よこはま・みなとみらいを じゆうに たんけんする 3D オープンワールド ゲーム。
WebGL を じぶんで かいた かんたんな 3D（外部ライブラリなし）。`index.html` ＋ `game.js`。

## できること
- **かべのぼり**: たてものに むかって すすむと よじのぼれる。スタミナ（みどりの わ）が なくなると おちる。
  のぼっている ときの ジャンプで ぐいっと うえへ（スタミナを つかう）。「はなす」で てを はなす。
- **かさ ☂️**: そらで もういちど ジャンプすると かさが ひらいて ゆっくり とべる。
- **アイテム**: 🍙 おにぎり＝スタミナ まんたん、🎈 ふうせん＝そらへ うかぶ。まちに おちている（しばらくすると また でる）。
- **ほし ⭐（17こ）**: ランドマークタワーの てっぺんの きんの ほしが さいしょの もくひょう。ほしを とるほど スタミナが のびる。
- **スタンプ 📍（13かしょ）**: ばしょに いくと たまる。🗺️ ちずで たしかめられる。
- **くもん みなとみらい きょうしつ 🏫**: みなとみらいミッドスクエア（よこはましにしく みなとみらい4ちょうめ7-1）3かい。
  みどりの いりぐちで「はいる」→ さんすうの プリント（`kumon.js`）。
  - いまは **3A**（つぎの かず〜120・かずの ならび・+1/+2/+3）。100てんの プリントが 3まいで しゅうりょうテスト（20もん）。
    **90てん いじょうで ごうかく → 2A**（+1〜+10 の たしざん）が できるように なる。
  - プリントは せんせいに みせると ○/✓ が つき、✓ を なおして 100てんで おわり（ごほうび 🍙）。テストは なおし なし。
  - しんちょくは localStorage（`minatomirai-bouken-kumon-v1`）。もんだいは この アプリの オリジナル。
  - ばしょは こくどちりいんの じゅうしょけんさくで しらべた いち（ランドマークタワーの やく110m にし・410m きた）を、
    この せかいの しゅくしゃく（やく 0.2 / m）に なおして おいた。ちかくに マークイズ（めじるし）。
- のりもの: コスモクロック21（はこの やねに のれる）、エアキャビン（ゴンドラの やね）。うみは およげる。

## そうさ
- タッチ: がめん ひだりがわで あるく（ジョイスティック）、みぎがわを なぞって カメラ。ボタンで ジャンプ／はなす／アイテム。
- キーボード: WASD・やじるし あるく / スペース ジャンプ / X はなす / E おにぎり / Q ふうせん / M ちず / Esc とめる / マウス ドラッグ カメラ

## しくみ
- せかいは ぜんぶ じくに そった はこ（AABB）。おなじ はこが あたりはんてい と のぼれる かべ になる。
- かんらんしゃの はこ・ゴンドラは「うえから だけ のれる うごく あしば」。のっていると いっしょに はこばれる。
- おとは WebAudio の ごうせいおん（BGM つき、🔊 で オン/オフ）。しんちょくは localStorage（`minatomirai-bouken-v1`）。
