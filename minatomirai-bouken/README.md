# あおちゃんの みなとみらい だいぼうけん

5さいの おとこのこ **あおちゃん** が、**ほんものの ちず（OpenStreetMap）で つくった みなとみらい** を
じゆうに たんけんする 3D ゲーム。WebGL を じぶんで かいた 3D（外部ライブラリなし）。

| ファイル | なかみ |
| --- | --- |
| `index.html` | がめん・HUD・スタイル |
| `game.js` | 3D・うごき・かべのぼり・おなら・エアキャビン・ちず |
| `map-data.js` | みなとみらいの ちずデータ（`tools/minatomirai-map.py` が つくる。てで なおさない） |
| `kumon.js` | くもん みなとみらい きょうしつ（さんすうの プリント・テスト） |
| `shops.js` | おさいふ・レジ・トイザらス・ガチャガチャ・えいがかん・エアキャビンの きっぷ |

## ちず（ほんものの ちず ベース）
- データ: © OpenStreetMap contributors（ODbL）。さくらぎちょう〜おおさんばし の はんい（北緯35.4485〜35.4635, 東経139.6255〜139.6495）。
- `python3 tools/minatomirai-map.py --fetch <キャッシュ>` で ダウンロードして つくりなおせる（`--preview out.png` で たしかめの え）。
- ランドマークタワーを まんなかに、みちの むき（-32.5°）に そろえて まわし、**1m = 0.25** の おおきさ。
- うみぞい（coastline）・さんばし・はし から りくちを つくり、たてもの 約1200けんを ほんとうの かたち と たかさ（height / かいすう）で たてる。
  みち・せんろ・こうえん・き も ちずから。
- あたりはんてい は、たてものの かたちを 0.5 たんいの ますで「じくに そった はこ」に ならべなおした もの（約1まん1せん こ、くうかん ハッシュで さがす）。
- エアキャビンは ちずの ルート どおり。コスモクロック21・にっぽんまる は ちずの ばしょ・むき に あわせて ゲームが つくる。
