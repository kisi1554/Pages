# あおちゃんの みなとみらい だいぼうけん

5さいの おとこのこ **あおちゃん** が、**ほんものの ちず（OpenStreetMap）で つくった みなとみらい** を
じゆうに たんけんする 3D ゲーム。WebGL を じぶんで かいた 3D（外部ライブラリなし）。

| ファイル | なかみ |
| --- | --- |
| `index.html` | がめん・HUD・スタイル |
| `game.js` | 3D・うごき・かべのぼり・おなら・エアキャビン・ちず |
| `map-data.js` | みなとみらいの ちずデータ（`tools/minatomirai-map.py` が つくる。てで なおさない） |
| `kumon.js` | くもん みなとみらい きょうしつ（さんすうの プリント・テスト） |
| `shops.js` | おさいふ・レジ・トイザらス・ガチャガチャ・えいがかん・エアキャビンの きっぷ |

## ちず（ほんものの ちず ベース）
- データ: © OpenStreetMap contributors（ODbL）。さくらぎちょう〜おおさんばし の はんい（北緯35.4485〜35.4635, 東経139.6255〜139.6495）。
- `python3 tools/minatomirai-map.py --fetch <キャッシュ>` で ダウンロードして つくりなおせる（`--preview out.png` で たしかめの え）。
- ランドマークタワーを まんなかに、みちの むき（-32.5°）に そろえて まわし、**1m = 0.25** の おおきさ。
- うみぞい（coastline）・さんばし・はし から りくちを つくり、たてもの 約1200けんを ほんとうの かたち と たかさ（height / かいすう）で たてる。
  みち・せんろ・こうえん・き も ちずから。
- あたりはんてい は、たてものの かたちを 0.5 たんいの ますで「じくに そった はこ」に ならべなおした もの（約1まん1せん こ、くうかん ハッシュで さがす）。
- エアキャビンは ちずの ルート どおり。コスモクロック21・にっぽんまる は ちずの ばしょ・むき に あわせて ゲームが つくる。

## できること
- **かべのぼり**: たてものに むかって すすむと よじのぼれる（スタミナの みどりの わ）。ランドマークタワーには ひとやすみ バルコニー。
- **スーパーおなら 💨**: ボタンを おしつづけると そらへ。おならは じめんで たまる。🍠 おいも で まんたん。
  そらで ジャンプ → **パラシュート 🪂** で ゆっくり おりる。
- **エアキャビン 🚡**: さくらぎちょう ⇄ うんがパーク（ワールドポーターズの ちかく）。こども かたみち 500えん。ゴンドラに のって うみの うえを わたる。
- **おさいふ 👛**: さいしょは 1000えんさつ ×5（5000えん）。レジでは おさつ・こうかを タップして はらい、おつりを もらう（「おまかせ」も ある）。
- **くもん みなとみらい きょうしつ 🏫**（みなとみらいミッドスクエア 3かい）: 3A → テスト ごうかくで 2A。**100てんの プリント 1まいで 1000えん**。
- **トイザらス 🧸**（マークイズ みなとみらい 3かい）: プラレールを ながめて（レールの うえを はしる）、かごに いれて レジで かう。
- **ワールドポーターズ 🎪**: ガチャガチャ（300えん・りょうがえき つき・12しゅるいの コレクション）と えいがかん（こども 1000えん、ポップコーン つき 1500えん）。
  えいがは この アプリで つくった オリジナルの みじかい アニメ（4ほん）。
- **コスモワールド**（ねだん は ゲームようの めやす）
  - 🎢 **ジェットコースター**（800えん）: まきあげ → 22の たかさから おちて みずの プールへ → トンネル → こぶ。
    じぶんの め で のる（スピードで しやが ひろがる・ゆれる・かぜの おと・チェーンの おと・みずしぶき）。
  - 👻 **おばけやしき**（600えん）: くらい めいろを あるいて すすむ（ちょうちんの あかり・しんぞうの おと）。
    がくぶちの め・おばけ・ていでん・がいこつ・ひつぎ・かべの て・さいごに「ばあっ！」。こわかったら「でる」。
  - 🎡 **コスモクロック21**（900えん）: はこに のって 1しゅう。たかい ほど きりが はれて、
    **ふじさん・やま・ベイブリッジ・マリンタワー・ひかわまる・よこはまえきの ビル・とうきょうの ビルと スカイツリー** が みえる
    （いち は いど・けいど から。とおい ものは ちかくに ちいさく おいて、みえる おおきさ を ほんもの と おなじに した）。
- 🏢 **ランドマークタワー を たかく**（ゲームでは 110。ほんとうの ひりつ なら 74）。バルコニー 7だん、てっぺんに **ヘリポートと ヘリコプター 🚁**（じぶんで そうじゅう）。
- 🚑 **けが と びょういん**: パラシュート なしで 14 いじょう おちると けが → きゅうきゅうしゃ（ピーポー）が きて
  **けいゆう びょういん**（みなとみらい 3ちょうめ 7-3。ちずの いち）へ。てあて の あと びょういんの まえから さいかい。
- 👩 **ママは いつも いっしょ**（じどうで ついてくる）: あおちゃんの みぎどなりを あるく。とおくに はなれたら すぐ そばへ。
  - ときどき はなしかける（ばしょ・ほし・おこづかい・のぼる・およぐ・アトラクション に あわせた ことば）。80びょう ごとに おみず（スタミナ まんたん）。
  - **そらを とぶ とき**（おなら・おちる・やね の うえ・ヘリ）は **てんしの はね と わっか** が でて とんで ついてくる 👼。
  - エアキャビン・かんらんしゃ では となりに すわり、コースター では うしろの せき、おばけやしき では うしろを あるく。
- 🪑 くもんの いりぐちの ベンチ: きょうしつ に いる あいだ ママが まつ ばしょ。ちかくに いくと おみず（スタミナ まんたん）。
  きょうしつ の なかでも ときどき「おみず のむ？」と きてくれる（「おみず ちょうだい」ボタンも）。
- 🏠 **おうち**: あおちゃんは **プラウド よこはま さくらぎちょう**（にしく はなさきちょう 5-137-1。ちずの いち、10かいだて）に すんでいる。
  さいしょ と「おうちに かえる」は おうちの まえ から。なかでは おひるね（スタミナ まんたん）と、かった プラレールを はしらせて あそべる。
- 🚌 **ようちえんバス**: おうちの ちかく、**いわかめよこちょう** の みちの「**いわかめどおり**」のりば から、**とべ ようちえん**（にしく ごしょやまちょう 10。ちずの いち）まで いきも かえりも。
  バスは ほんものの みち（OSM の どうろ）を たどって はしる（いちばん ちかい みちを ダイクストラで けいさん）。
  ※「いわかめどおり」と いう なまえの ろせんバスの バスていは ちずデータ・けんさく では みつからなかったので、ようちえんの おくりむかえバスの のりば として おいた。
- 🌸 **さくらごう**: ようちえんバスは ピンクの「さくらごう」（さくらの もよう・なまえ いた）。なかに せんせい（エプロン）と おともだち。
- 🏪 **コンビニ**（ちずの いち: OSM の shop=convenience）: バスは のりば → **セブン-イレブン**（とべちょう 4ちょうめ。「セブンイレブン 横浜戸部店 戸部町4-147」と あう）→
  **ローソン**（とべちょう 3ちょうめ）→ ようちえん の じゅんに ほんものの みちを とおる。どちらも はいれる。
  ローソンでは **からあげクン**（レギュラー・レッド・チーズ）を かって 5こ たべられる（げんき・おなら まんたん）。ねだん は ゲームの めやす。
- 🛝 **すべりだい**: ようちえんの おにわ（すなば つき）。はしごを のぼって すべる。ようちえんの なかの ボタン からも いける。
- 🌷 **とべ ようちえん**: せんせいから まいにち シール、🎨 おえかき（かいた えは かざられる）、🎵 おうた「ちょうちょう」（1881ねんの しょうか）、🍱 ママの おべんとう。
- ちずの はんいを にしへ ひろげた（とうけい 139.6175 まで: とべ・ごしょやま・のげ）。まわしの かくどは こてい（-32.5°）なので まえの いちは ずれない。
- ちずの そとの よこはまの まち（だいたいの かたち）と ビルも おいた。
- ほし ⭐ 18こ・スタンプ 📍 18かしょ・ちず 🗺️。

しょうひんの なまえ・ねだん は ゲームようの めやす（ほんものの おみせの ねだん では ない）。
エアキャビンの こども うんちん（かたみち 500えん）は こうしきの りょうきん を もとに した。

## そうさ
- タッチ: ひだりで あるく、みぎを なぞって カメラ。ボタンで ジャンプ／はなす／おなら（おしつづける）／おにぎり／はいる。
- キーボード: WASD・やじるし / スペース ジャンプ / X はなす / F（おしつづける）おなら / E おにぎり / Enter はいる / M ちず / Esc とめる
