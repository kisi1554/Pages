# きょうりゅう はっくつ 🦖

**がけの ちそうを ほって かせきを みつけ、ほねを くみたてると きょうりゅうが うごきだす！**
発掘 → くみたて → ずかん の きょうりゅう あそび（未就学〜小学生むけ）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし。絵は すべて Canvas で コード描画、音は WebAudio 合成）。

公開URL: https://kisi1554.github.io/Pages/kyoryu-hakkutsu/

## あそびかた

| モード | ないよう |
| --- | --- |
| ⛏️ はっくつ | がけの 地層（上から 白亜紀・ジュラ紀・三畳紀。**下の地層ほど むかし**）を えらんで ほる。🖌️ハケ＝なぞって すなを はらう（Canvas のマスク）、🔨ハンマー＝タップで 岩を わる（はやく たたきすぎ／出てきた骨を たたくと ひび → ★がへる）、🔍ルーペ＝すなの下の 骨が うっすら みえる |
| 🦴 くみたて | ほりだした 骨（10〜15ピース）を ドラッグして シルエットに はめる。かちっ と はまる。💡ヒントあり。完成すると 肉付け → 色 → うごいて 鳴く（「こんな こえ かも？」と ことわる） |
| 📖 ずかん | きょうりゅう 37しゅ ＋ 「きょうりゅうの なかま じゃない いきもの」6しゅ（別の棚）。時代・大きさ（全長・体重の めやす）・たべもの・見つかった国・ひとこと。時代／🗾にほん で しぼりこみ |
| 📏 おおきさ くらべ | えらんだ いきものと 電車1両（約20m）・バス・ゾウ・人を 同じ縮尺で ならべる |
| ⏳ ねんぴょう | 三畳紀 → ジュラ紀 → 白亜紀 → いんせき しょうとつ → いま を よこスクロール（実際の 時間の 長さに 比例）。人が 生まれたのは ずっと あと |

- ほった → ずかんに 骨で のる。くみたてる → 色が つく。
- 同じ 地層に まだ 見つけていない ものが あれば そちらが 優先して 出る。
- 進捗は localStorage（`kyoryu-hakkutsu-v1`）。

## 正確さの方針

- 全長・体重など 研究で かわる 数値は「やく」「〜くらい」と はばを もたせ、推定が 大きく ちがう ものは「研究で ちがう」と 書いた。
- 部分骨格しか ない 種（アルゼンチノサウルス など）は その旨を ひとことに 書いた。体重が 分かっていない 日本の種は「わかって いない」とした。
- **恐竜ではない もの**（翼竜：プテラノドン・ケツァルコアトルス・エウディモルフォドン／首長竜：フタバスズキリュウ／モササウルス／魚竜：イクチオサウルス）は 別の棚。
- **鳥は恐竜の子孫（なかま）**。羽毛のある恐竜（ヴェロキラプトル など）は 羽毛つきで 描いた。始祖鳥（アーケオプテリクス）は 恐竜の 棚に 入れた。
- 日本の恐竜: フクイラプトル・フクイサウルス・フクイティタン・フクイベナートル（福井県勝山市）、カムイサウルス（むかわ竜／北海道むかわ町）、タンバティタニス（丹波竜／兵庫県丹波市）、ヤマトサウルス（兵庫県淡路島）。
- 色・模様・鳴き声は 想像（保護者向けページに 明記）。骨の絵は 模式図。
- 年代は 国際年代層序表（三畳紀 約2億5200万〜2億100万年前、ジュラ紀 〜1億4500万年前、白亜紀 〜6600万年前）。
