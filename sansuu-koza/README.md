# 算数講座

中学受験算数（難関校クラス）の分野マップを、実際に手を動かして学べる形にしたアプリ。
**保護者（大人）向けの学習ツール**で、リポジトリの他アプリとは想定ユーザーが異なる。

## 使い方

1. トップの分野一覧から1分野を選ぶ（4系統・11分野）
2. 「典型解法」タブでその分野の道具（考え方）を確認する
3. 「演習」タブで問題を解き、「こたえを見る」で答え合わせをする
4. 「できた」にチェックを入れると進捗がブラウザに保存される（localStorage）

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（分野一覧／分野詳細の2画面） |
| `style.css` | 見た目 |
| `data.js` | コンテンツ本体。分野ごとの解説・演習データ |
| `app.js` | 画面の切り替え・進捗保存のロジック |

## 演習を追加する

`data.js` の対象分野オブジェクトの `exercises` 配列に、以下の形で1件追加するだけでよい。

```js
{
  id: "wh-6",              // 分野内で重複しないID
  level: "標準",            // 基礎 / 標準 / やや難 / 難関校レベル など
  title: "一言タイトル",
  question: "問題文",
  answer: "答え",
  solution: "考え方（xを使わない中学受験流の解き方）",
}
```

## 新しい分野を解説つきで開放する

`data.js` の対象分野オブジェクトに `explanation`（配列）と `exercises`（配列）を追加する。
未着手の分野は `core`（一言解法）だけを持ち、一覧に「準備中」と表示される。

## リポジトリ内での位置づけについて

`CLAUDE.md` の「UIはひらがな中心・未就学〜小学生むけ」という規約は、公開サイト
（`pages-root/index.html`＝子ども向けあそびメニュー）に載せるアプリのための規約であり、
本アプリは保護者の自習用のため、通常の日本語表記としている。同じ理由で、
`pages-root/index.html` へのカード追加は行っていない（あそびメニューに載せる性質のものではないため）。
公開して家族内で使いたい場合は、別途 `tools/pages-sync.sh` で同期は可能。
