# にょこすけ シューティング 🐛✨

いもむしの **にょこすけ** が そらを とんで、むしの ボスたちと たいけつする たてスクロール シューティング。
したから うえへ すすむよ。`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリなし）。

## そうさ

| そうさ | なにが おきる |
| --- | --- |
| がめんを ゆびで なぞる（どこでも OK） | にょこすけが ゆびと おなじ ほうへ うごく |
| たま | **じどうで でる**（ボタン いらず） |
| 🍠「ぷっ！」ボタン（X / スペース） | **おならボム**。てきの たまを ぜんぶ けして、てきに おおダメージ |
| ⏸ ボタン（Esc / P） | ひとやすみ |
| キーボード | やじるし / WASD で うごく |

- あたりはんていは にょこすけの **あたま**。からだや はねに たまが かすっても だいじょうぶ。
- やられると すこしの あいだ むてき ＋ まわりの たまが きえる。

## アイテム

| アイテム | こうか |
| --- | --- |
| **P** | たまが パワーアップ（1→2→3→4）。4 で ピンクの ホーミングだんも でる |
| ❤️ | げんきが 1つ ふえる |
| 🍠 | おならボムが 1つ ふえる（5こ まで） |
| ⭐ | スコア。ボムで けした たまも ほしに なる |

## ステージ と ボス

| ステージ | ばしょ | ボス | わざ |
| --- | --- | --- | --- |
| 1 | なつの もり | **ミンミン キング**（せみ・おうかん つき） | ♪ミーン リング／おしっこ シャワー／ジジジッ ねらいうち |
| 2 | きらきら いけ | **ギンヤンマ ジェット**（とんぼ・あかい マフラー） | ジェット ダッシュ／ふくがん ロックオン／ぐるぐる スパイラル |
| 3 | ざわざわ くさはら | **カマキリ しょうぐん**（かまきり・はちまき） | カマ スラッシュ／カマ ブーメラン／おいのり → つき |
| 4 | よるの じゅえきば | **ノコギリ クワガタン**（くわがた） | チョッキン はさみうち／どすこい とっしん／ガリガリ きくず |
| 5 | たいじゅの てっぺん | **ヘラクレス オオカブト** | ツノ ビーム／ツノ とっしん／ゴールデン スパイラル。HP が はんぶんに なると **ほんきモード**（なかまを よぶ） |

- とっしん・ビームの まえには あかい「！」の よこくが でる。
- ステージを クリアすると つぎの ステージが あく（🔒→⭐）。

## むずかしさ

| | げんき | ボム | てきの たま |
| --- | --- | --- | --- |
| **やさしい** | ❤️×5 | 3 | おそくて すくない、ボスの HP 75% |
| **ふつう** | ❤️×3 | 2 | ふつう |

## おと

- BGM・こうかおんは WebAudio の 合成音だけ（音声ファイルなし）。右上の 🔊 で オン/オフ。
- BGM は タイトル／ステージ（2きょく × キーちがい）／ボス／ラスボス／クリア／ゲームオーバー。
  メロディは `game.js` の `SONGS` に 16もじ＝1しょうせつ の もじれつで かいてある。

## きろく

クリアした ステージと ハイスコアを localStorage に ほぞん（キー: `nyoko-shooting.v1`）。

## しくみ

- `index.html` / `style.css` / `game.js` の 3ファイル。にょこすけ・てき・ボス・はいけいは canvas に その場で かいている。
- ゲームの せかいは 360×640 の たてながで、がめんに あわせて かくだい（よこもちでは まんなかに でる）。
- URL に `#debug` を つけると `window.__nyokoShoot` から そうさできる（`bossNow()` で すぐ ボス、`god()` で むてき、`kill()` で ボスを たおす）。
