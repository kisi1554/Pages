# だいたい いくつ？ 🦛

**ぜんぶ かぞえなくても「だいたい いくつ」を あてる（みつもり）** と、**10の まとまりで かぞえる くふう** を そだてる ゲーム（5さい〜）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. かばくんの くちの なかに あめが ぎっしり。**2びょう だけ** みえて、ぱくっと とじる。
2. 「だいたい いくつ？」を 3まいの ふだ（れい: 10ぐらい・30ぐらい・100ぐらい）から えらぶ。
3. かばくんが「あーん」と あめを 1こずつ ぽーん ぽーんと だして、**10こずつ ならべて** こたえあわせ。
   ならびが 10こ そろうと わくが きいろに なって「10」「20」…と でる。
   さいごに「10が 3つで 30、ばらが 2こ。ぜんぶで 32こ」と いう。
4. いちばん ちかい ふだ → かばくんが ダンス。とおい ふだ → かばくんが しゃっくり。
   まちがえたら「もういっかい」で おなじ おだいの べつの もんだいに ちょうせん できる。
5. 5もんで 1かい（1〜3ぷん）。おわりに 🍬（1かいめで ちかい）・🍭（やりなおして ちかい）を ならべて ほめる。

## おだい（6しゅるい）

かばの あめ 🍬／ありの ぎょうれつ 🐜（くねくね 1れつ）／にわとりの たまご 🥚／そらの ほし ⭐／バスの おきゃくさん 🧒／ゾウの はなの みず 💧（コップ なんばい ぶん）

## レベル

| レベル | ふだ |
| --- | --- |
| 1 | 5・10・20 |
| 2 | 10〜50 |
| 3 | 100まで |
| 4 | 「みほん 10こ」を みながら くらべる（ふだの かずが ちかい） |

## わらい どころ（こたえあわせの あとに だす。かんがえる じゃまは しない）

- かばくんが とちゅうで がまん できず 1こ たべる →「…いまの なし！ ぺっ」（かずは かわらない）
- あめの なかに はかせの はいれば 🦷 が まざっていて「わしの はいれば じゃ〜！（かぞえないよ）」
- 100こ ちかく はくと かばくんが ぺしゃんこに しぼむ

## ほぞん

localStorage（`daitai-ikutsu-v1`）に レベルごとの いちばん いい きろく と おとの オン/オフ。
