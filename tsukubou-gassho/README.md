# つくぼうの せみ がっしょう 🎵

セミの「つくぼう」と なかまたちが 2ひき 1くみで 木の えだから おちてくる、**おなじ セミを 4ひき つなげて とばす** 落ちもの れんさ パズル。
とばすと なきごえを あげ、**れんさ するほど なきごえが かさなって「がっしょう」に なる**。あそぶうちに セミの しゅるいと なきごえ・なく 時間を おぼえられる。
年中〜小学3年むけ。`index.html` を ひらく だけで あそべる（外部ライブラリ・CDN なし。絵は SVG、音は WebAudio の 合成音）。

## キャラクター（chara.js）

| なまえ | モデル | いろ / 見わけ マーク | なきごえ |
| --- | --- | --- | --- |
| つくぼう（しゅじんこう） | ツクツクボウシ | きみどり / ほっぺに ★ | つくつく ぼーし！（さいご じーっ） |
| みんみん | ミンミンゼミ | みずいろ / まるい めがね | みーん みんみん |
| あぶら | アブラゼミ | ちゃいろ / ギザギザ はね | じりじりじり |
| くまっち | クマゼミ | くろ＋オレンジ / ふとい まゆ | しゃんしゃんしゃん |
| かなかな | ヒグラシ | むらさき / おでこの ほし もよう | かなかなかな（ゆうがたに あらわれる） |

いろを 見なくても マークで 見わけられる。ぬけがら（はいいろ）は じゃまもの。
キャラの 見た目・せいかく・せりふは `chara.js`（と `stages.js` の せりふ）だけ なおせば かえられる。

## ルール

- ばめんは 木の みき（よこ 6 × たて 12）。2ひき 1くみが おりてくる。よこ いどう・まわす・はやく おとす。
- まわす とき かべや セミに ぶつかったら 1マス ずらす（せまい みぞでは うえ・したを いれかえる）。
- おなじ しゅるいが たて・よこで 4ひき いじょう つながると とびたつ（ななめは ×）。おちて また つながれば れんさ。
- 表示は「ふたりで がっしょう！」「さんにんで がっしょう！」…。れんさ ごとに なきごえを 1つずつ かさねて ならす。
- ぬけがら: ときどき ふってくる。となりで セミが とびたつと いっしょに きえる。
- えだの つけね（うえの まんなか、点線の マス）まで つまったら おしまい。**やさしい は おわらない**: 「ゆうだち」で うえ 4だんが ながれる。
- いちにちの ながれ: とばした かずで あさ → ひる → ゆうがた。**ゆうがたに なると かなかなが まざる**（BGM の 調も かわる）。
- がっしょう ゲージ: れんさで たまる。いっぱいで「だいがっしょう！」ぬけがらが ぜんぶ きえる。
- つくぼう ボーナス: 2れんさ いじょうの さいごに つくぼうを とばすと「つくつく ぼーし…じーっ」×1.5。

| とくてん | |
| --- | --- |
| 4ひき | 40（1ぴき ふえるごとに ＋10） |
| れんさ | 2れんさ ×2・3 ×4・4 ×8・5 いじょう ×16 |
| 2しゅるい いじょう どうじ | ×1.5 |
| ばめん からっぽ | ＋1000「しーん…ぜんぶ とんだ！」 |

むずかしさ: やさしい（3しゅ・おそい・おわらない・おちる ばしょの かげ）／ふつう（4しゅ）／むずかしい（5しゅ・はやい）。
ゆうがたは かなかなが はいり、やさしい は みんみん、ふつう は くまっち（あさの セミ）と こうたい する。

## モード

- 🌳 なつやすみ: 7/20〜8/31 の 10ステージ。めあて（12ひき とばす・2れんさ・あぶら 16ひき・ぬけがら 8こ・3れんさ・だいがっしょう など）。クリアで なかまの ひとことが ずかんに のる。
- ♾️ えんえん: スコアアタック。じかんで すこしずつ はやく なる。ベスト は むずかしさ ごとに 保存。
- 🎓 れんさ れんしゅう: きまった ならびに 1くみ おいて 2〜3れんさ を つくる 10もん。💡ヒントで おく ばしょが ひかる。
- 📖 せみ ずかん: とばすと ひらく。なく じき・なく じかん・おおきさ・なきごえ ボタン。20ぴき とばすと まめちしき。

## そうさ

- ボタン: ◀ ▶（おしっぱなしで くりかえし）・🔄 まわす・⬇ おしているあいだ はやく（れんしゅうでは おとす）。
- ばめん: よこに なぞる＝1マスずつ いどう／ちょんと さわる＝まわす／したへ さっと なぞる＝すとん。
- キーボード: ← → ／ ↑・スペース・X まわす ／ ↓ はやく ／ P・Esc いちじ ていし。
- ⏸ いちじ ていし（🎵 BGM・🔊 効果音 の オン/オフ も ここ）。アプリが うらに いくと じどうで とまる。
