# となりの けん たんけん

都道府県の なまえと ばしょを ぜんぶ おぼえた子の「つぎの一歩」。
おぼえた知識を **つながり（となりあう県）** として使い、道すじを考える地理アプリ。

## あそびかた

| モード | なにを するか |
| --- | --- |
| 🚃 となりへ たび | スタートの県から、となりの県を タッチして ゴールの県まで すすむ。いちばん ちかい みちなら ⭐3つ。21ステージ＋おまかせ |
| ❓ となり クイズ | 「となりは どれ？」「となりじゃ ないのは？」「りょうほうの となりは？」「となりは いくつ？」「うみが ない けんは？」の 10もん |
| 📖 となり ずかん | 県を タッチすると となりが ひかる。うみが ない 8県、となりが おおい県も みられる |

- **やさしい**: となりの県が きいろく ひかる／**むずかしい**: ひからない（2回 まちがえると ひかる）。
  むずかしいで まちがいなし＆最短だと 👑。
- 💡ヒントは 最短ルートの つぎの県を ひからせる（つかうと ⭐は 2つまで）。
- クリア後「👀 ちかみちを みる」で 最短ルートを アニメで みせる。
- 海を わたる道（青函トンネル・アクアライン・大鳴門橋・瀬戸大橋・しまなみ海道・関門トンネル・鹿児島⇄沖縄フェリー）も
  「となり」として すすめる。クイズと ずかんの「くっついて いる となり」は 陸続きだけを かぞえる。

## ねらい（5さい・都道府県を おぼえた子むけ）

- 暗記（なまえ⇄ばしょ）から、**位置関係を つかって 考える**段階へ。
- 最短ルートさがしは、先を よんで 計画する れんしゅうに なる。
- 「となりは いくつ？」で 地図を みながら かぞえる。

## つくり

- `index.html`（画面・CSS）／`game.js`（ゲーム本体）／`map-data.js`（`nihon-chiri-tanken/` と同じ 都道府県SVG。
  生成元は `tools/japan-map/generate_map.py`、国土数値情報 由来）。外部ライブラリなし。
- 隣接データは `game.js` の `LAND_PAIRS`（陸続き 86組）。地図の境界線の形状から 機械的に つきあわせて確認ずみ。
- 音は WebAudio の合成音と、端末の 読み上げ（speechSynthesis）。右上の 🔊 で オン/オフ。
- 進捗は localStorage `tonari-ken-v1`（⭐・👑・とおった県・クイズ最高点・設定）。
