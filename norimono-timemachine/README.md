# のりもの タイムマシン 🕰️🚂

**のりものや くらしの どうぐの カードを「ふるい じゅん」に ならべて、タイムマシンで むかしから いままでを たびする** あそび。
「むかし → いま」の じかんの ながれと、どうぐが すこしずつ かわってきた ことを しる（分野: れきし）。

対象：5さい〜。`index.html` を ひらくだけで あそべます（外部ライブラリなし・1ファイル）。

## あそびかた（1かい 1〜3ぷん）

1. たびを えらぶ（てつどう・くるま・ふね・ひこうき・でんわ・あかり・せんたく）
2. 3〜5まいの カードを **ドラッグ**で ふるい じゅんに ならべる
   （カードを 2まい じゅんに タッチしても いれかえ できる）
3. タイムマシンの **レバーを ひく**
   - まちがい → マシンが ガタガタ。あっている カードに ✓ が つき、なんどでも やりなおせる。
     2かい まちがえると「いつごろ？」の ヒントが でる（💡ボタンで いつでも だせる）
   - せいかい → ふるい じだいから じゅんに ワープ。じだいごとに え と まめちしきを 1つ
4. ゴールすると ほしと かみふぶき。カードは **ねんぴょう ずかん** に はいる（ぜんぶで 37まい）

じだいの いいかたは「100ねん いじょう まえ」「おじいちゃんが こどもの ころ」が しゅやくで、年号は そえるだけ。
