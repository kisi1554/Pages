# プログラミング うんてんし

やじるしカードを ならべて 電車を えきまで うごかす、はじめての プログラミング（年長〜小学校低学年むけ）。

## あそびかた

1. 下の カード置き場から カードを タップ → プログラム欄の さいごに ならぶ。プログラム欄の カードを タップで けす。
2. ▶ で 1まいずつ 実行。実行中の カードが 光り、電車の うしろに 線路が のびていく。
3. えきの マスで 🛑 とまる を 実行すると クリア。
4. しっぱい（マップの外・木/いけ/いえに ぶつかる・えきを とおりすぎる・とまらない など）は
   そこで 止まって「ここで こまったよ」と 場所を 赤い まるで しめす。⏪ で スタートに もどる（プログラムは のこる）。

| カード | うごき | でてくる ステージ |
| --- | --- | --- |
| ⬆ まっすぐ | 1マス すすむ | 1〜 |
| ↰ ひだり / ↱ みぎ | 向きを かえて 1マス すすむ（カーブ） | 1〜 |
| 🛑 とまる | えきで とまる（クリア判定） | 1〜 |
| 🚏 のせる | おきゃくさんの マスで のせる。全員 のせないと クリアに ならない | 6〜 |
| 🔁 くりかえし | 2〜4かい（×の ボタンで かえる）。なかに カードを いれる。入れ子は なし | 11〜 |

🔁 を おくと はこが ひらき、つぎの カードは はこの なかに はいる。「✓ とじる」で はこを とじる、「＋ いれる」で また ひらく。

- 星: クリア ★ / ヒントなし ★ / いちばん すくない まいすう ★。ステージを えらぶ 画面に 表示。
- 💡 ヒント: こたえの みちを 点線で だす（ヒントなしの ★ は つかなくなる）。
- 🐢/🐇 で はやさ、🔊 で 音 オン/オフ。進捗・星・設定は localStorage（`program-unten-v1`）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` / `style.css` | 画面。縦持ちは マップ上・カード下、横持ちは マップ左・カード右 |
| `engine.js` | うごきの きまり（実行・しっぱい判定・最少枚数ソルバー）。node でも `require` できる |
| `stages.js` | 20ステージの データ（マップ・つかえる カード・上限・最少枚数・解） |
| `app.js` | 描画（Canvas）・操作・効果音（WebAudio 合成） |

## ステージの ふやしかた / なおしかた

`stages.js` の 配列に 1つ たす。マップの 文字は `. T W H S G C X`（くさ・き・いけ・いえ・スタート・えき・おきゃくさん・ふみきり）。
`min` と `sol` は ソルバーで もとめて 書く。かならず テストを とおす:

```bash
node tools/program-unten/check.js
```

- 解 `sol` を 実行して クリアできるか、`sol` の 枚数 = `min` か、`min` ≦ `limit` か
- ソルバー（ダイクストラ）で さがした ほんとうの 最少枚数 = `min` か（★3 が ただしいか）
- 11〜15 は 🔁 なしでは `limit` に 入りきらないか、ふみきりの ある ステージは 解が ふみきりを とおるか
