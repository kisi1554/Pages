# 🚦 でんしゃ しれいしつ

まち の せんろ を みはる **しれいいん（指令員）** に なって、**ポイント（ぶんきき）と しんごう** を きりかえ、
つぎつぎ くる でんしゃ を ただしい ホーム へ みちびく リアルタイム パズル。うえ から みた ジオラマ ふう の せんろ ばん で あそぶ。
対象: 年長〜小学6年。まなび: ポイント と しんごう の しくみ（あか で とまる、ひとつ の くかん に 1ほん だけ＝へいそく）、さき を よむ・じゅんばん を きめる。

公開URL: https://kisi1554.github.io/Pages/shirei-shitsu/

## あそびかた

- でんしゃ の うえ の **まる** が いく さき（①〜④ ホーム、🏠 しゃこ、📦 かもつ、⛰️🌊🌲🏙️ でて いく トンネル。きゅうこう は 「つうか」）。
- **ポイント**（きいろ の つまみ）を タップ で きりかえ。やじるし の ほう へ すすむ。でんしゃ が のって いる／すぐ ちかく に いる ポイント は うごかない（🔒）。
- **しんごう** を タップ で あお／あか。あか の まえ で でんしゃ は ゆっくり とまる。ホーム の しゅっぱつ しんごう は でんしゃ が とおると あか に もどる。
- ホーム に つくと「とうちゃく！」→ のりおり → でて いく（いきどまり なら おりかえし）。**でて いく みち の ポイント も じぶん で つくる**（ちがうと ❓ で まつ）。
- ぶつかる ことは ない（じどう へいそく）。ぎりぎり で あか／ポイント を かえると **きゅうブレーキ＋ブザー**（おくれ ＋2）。ちがう ホーム・トンネル は「あれれ？」（＋5）。にらめっこ で うごけない ときも ブザー。
- ★ は おくれ の すくなさ（まって いた じかん。1ぽん 4びょう までは ゆとり）。3びょう いか ★★★、15びょう いか ★★。
- トンネル の まえ に「まもなく」で つぎ の でんしゃ の いく さき が でる。💡 ヒント（つぎ に さわる ところ が ひかる）、⏩ はやおくり。

| しょう | なかみ |
| --- | --- |
| 1. ちいさな えき | ポイント 1つ・ホーム 2つ。いきどまり の ターミナル と とおりぬけ えき |
| 2. しんごう が でた | たんせん で すれちがい。しゅっぱつ しんごう を あお に して だす。ふみきり |
| 3. いそがしい ターミナル | ふくせん の 4ばんせん えき（ふつう・かいそく・きゅうこう の つうか と おいこし）、いきどまり 4ばんせん の みなと ターミナル |
| 4. しゃこ と かもつ | かいそう は ホーム → しゃこ で おやすみ、かもつ は わき の せんろ で にもつ おろし |
| 5. ゆき の ひ | ポイント が こおる → ながおし で あたためて から タップ |

**じゆう モード**: ━ ╲ ╱ の せんろ・🚉 ホーム・🚦 しんごう を ばん に おいて（なぞると つづけて おける）、▶ で しれい。
ばん の はし まで のびた せんろ が トンネル に なり、でんしゃ が ランダム に でて くる。かたち は ほぞん される。

## しくみ

- `layout.js`（DOM なし）: せんろ は てん（ノード）と リンク の グラフ。リンク は かならず にし→ひがし に のびる ので でんしゃ の むき は ±1。
  かたがわ に 2ほん ある てん が ポイント（どちら に つながる か を state で もつ）。しんごう の ある てん で へいそく くかん が わかれる。
  トンネル の そと に みえない せんろ を つけて、でんしゃ は そこ から でて きて そこ へ きえる。みち さがし（findRoute）も ここ。
- `dispatch.js`（DOM なし）: でんしゃ は リンク の うえ の いち と はやさ。くかん に はいる まえ に「よやく」し、よやく できない
  （あか・ほか の でんしゃ・ポイント が ちがう）と しんごう の てまえ で とまる。よやく した ときは その さき の くかん まで
  みち を つくる（えき の なか で にらめっこ しない）。ポイント を かえて みち から はずれた よやく は とりけす。
  おくれ・あれれ・きゅうブレーキ の けいさん、ゆき（ポイント が こおる）、じどう しれい（`autopilot`／ヒント に つかう `plan`）。
- `stages.js`: 6しゅるい の せんろ ばん と 20 ステージ の ダイヤ（でんしゃ が でて くる じこく・いく さき・しゅるい）。
- `render.js`: canvas 2D。たて がめん では ばん を 90ど まわす（もじ は まっすぐ）。せんろ・ホーム・いえ は べつ の canvas に とって おく。
- `audio.js`: WebAudio の ごうせいおん だけ（かちゃん・ぴっ・がたんごとん（はやさ で テンポ）・オリジナル の とうちゃく チャイム・ブザー・ふみきり の かんかん）。🔊 で オン/オフ。
- `app.js`: がめん・タップ（ながおし で あたためる）・じゆう モード の へんしゅう・ほぞん（localStorage `shirei-shitsu-v1`、try/catch）。
