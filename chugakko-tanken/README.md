# でんしゃで ちゅうがっこう

志望校の中学校を、路線図の駅から えらんで しらべる 子どもむけページ。
[`ofuro-yasan/`](../ofuro-yasan/)（でんしゃで おふろやさん）と同じしくみで、おふろやさんの かわりに中学校が出る。

公開URL: https://kisi1554.github.io/Pages/chugakko-tanken/

- 🔵 ブルーライン・グリーンライン
- 🩵 京浜東北・根岸線（西日暮里〜大船）
- 🔷 横須賀線・東海道線（馬喰町〜逗子、大船〜平塚）
- ❤️ 東急東横線（渋谷〜横浜）
- 💚 東急田園都市線・大井町線
- 🔴 京急線（品川〜金沢八景・空港線）
- 💙 相鉄線（本線・いずみ野線）
- 🔹 小田急江ノ島線（相模大野〜片瀬江ノ島）
- 🟢 横浜線・鶴見線
- 🟣 とうきょうの でんしゃ（山手線・井の頭線・目黒線・日比谷線の一部）

## あそびかた

`index.html` をブラウザで開くだけ（外部ライブラリなし）。

1. 上の路線ボタンで ろせんを えらび、路線図の 🏫 の駅をおすと、その駅の中学校が出る
   （スマホは全画面、タブレット・PCは右がわに表示）。
2. カードには 駅からの いきかた、がっこうが はじまる じかん、おうちからの じかん（のりかえ回数・
   何時に家を出れば間に合うか）、ひとことが出る。
3. 見学・説明会・文化祭で行ったら「🏫 いったよ」で スタンプ（チャイムが鳴る）。
4. 「おとこのこの がっこう」「いっしょ（共学）」「45ふん いない」「まだ 行ってない」で しぼりこめる。

## データ

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面とスタイル（`ofuro-yasan/index.html` から作った） |
| `data.js` | `LINES`（路線と駅）、`SCHOOLS`（学校） |
| `app.js` | 表示・時刻の読み上げ表記・スタンプ・音 |

- 対象は [`tsugaku-route/`](../tsugaku-route/) に載っている、**入試のある53校**。
  地元の公立中2校（老松・横浜吉田）は電車を使わないので入れていない。
  並びは★（`DEFAULT_WISH`）の11校が先、そのあとは tsugaku-route の `SCHOOLS` の順。
- 最寄り駅・徒歩分・登校時刻・「おうちから」の出発時刻（推奨）・所要・乗換は、
  **tsugaku-route の学校カード（`vcard` の `data-dep` / `data-mins` / `data-trans` と「登校 ／ ○○駅 徒歩○分」）から写した**。
  カードの値を変えたら、ここも合わせる。**住所は載せない**（区名まで）。
- カード以外から足した駅：浅野の新子安（JR）と関東学院の黄金町は `school-route-agent/routes.json` の経路検索のめやす。
  関東学院のカードは市営バス（霞ケ丘）経路。
- 青稜は**大井町を最寄り**にしている（下神明ではなく）。
- 開智横浜国際はカードに登校時刻が無いので `school-route-agent/schools.json` の 8:15。
- 京急の弘明寺は地下鉄の弘明寺と別の駅なので、表示名を「弘明寺（けいきゅう）」にして学校が出ないようにしている。

### 学校を足すとき

`SCHOOLS` に1件足すだけ。`at` に `{ 駅名: 'いきかた' }` を書くと、その駅（どの路線でも）に出る。
駅が `LINES` に無ければ、その路線の `stations` にも足す。`home` は `school-route-agent` で経路を出してから写す。

- 音は WebAudio の合成音のみ。右上 🔊/🔇 で オン/オフ。
- 「いったよ」・音・えらんだ路線は localStorage（`chugakko-tanken:v1`）に保存。
