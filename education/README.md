# 教育・学習（保護者むけの入口）

教育・学習に関するもののうち、**親が使うもの**をまとめた入口ページ。
子ども向けの「あそびメニュー」（`pages-root/index.html`）とは別に用意している。

公開URL: <https://kisi1554.github.io/Pages/education/>

## 構成

分野ごとに `<h2 class="sec">` で見出しを立て、その下にカードを並べる。
見出しに件数は書かない（増えるたびに直す必要が出るため）。

| 見出し | カード | リンク先 |
| --- | --- | --- |
| 中学受験算数 | 保護者のための中学受験算数 | `../sapix-lesson/` |
| 中学受験算数 | 算数講座 | `../sansuu-koza/` |
| 子どもに渡すもの | あそびメニュー | `../` |

算数以外（国語・理科・英語など）が増えたら、見出しを1つ足してその下にカードを並べる。
**空の見出しは作らない**（中身ができてから足す）。

## リンクの張り方

同じ階層のフォルダを `../<フォルダ名>/` で指す。Pages 上でも Claude リポジトリ上でも
同じように動く（どちらもフォルダが横並びのため）。

ただし `../`（あそびメニューへのリンク）だけは **Pages 上でのみ** 有効。
Claude リポジトリ側でローカルに開くと、リポジトリ直下には `index.html` が無いので 404 になる。
あそびメニューの実体は `pages-root/index.html`。

## カードの色

`class="card"` / `card b` / `card c` の3種。それぞれ accent（茶）・math（青）・kid（緑）。
同じ見出しの中で色が続かないように選ぶ。

## あそびメニューには載せない

このページは大人向けなので `pages-root/index.html` にはカードを置かない。
公開は `bash tools/pages-sync.sh education` で、URL を直接ブックマークして使う。
