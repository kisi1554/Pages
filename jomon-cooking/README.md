# じょうもん クッキング 🍪

**じょうもん じだいの たべものを、りょうり ばんぐみ ふうに つくる りょうり ゲーム。**
10本シリーズ「じだい たんけん」の 1本め（じょうもん じだい）。対象は 5才〜。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/jomon-cooking/

## あそびかた

しかいは じょうもんじんの「ドキさん」。メニューを えらぶと、ざいりょう あつめ → したごしらえ → ひに かける →
むらの 人の リアクション の じゅんに すすみます（1回 1〜3分）。まちがえても その場で やりなおせます。

| きせつ | メニュー | ながれ | まなび カード |
| --- | --- | --- | --- |
| あき | 🍪 どんぐり クッキー | ひろう → 水に さらす（ぬかないと にがーい！）→ いしで つぶす → こねる → やく | じょうもん どき |
| はる | 🍲 かいの スープ | すなはまを ほる → どきに もよう（やりすぎると おもくて もてない）→ にる → かいがらを かいづかへ | かいづか |
| なつ | 🐟 やきざかな | つり（うきが しずんだら）→ やく（いぬの コロが つまみぐい。タップで おすわり） | じょうもんの いぬ |
| あき | 🌰 くりごはん ふう | いがから くりを とる → かわを むく → どきで にる | たてあな じゅうきょ |
| あき | 🍄 きのこ なべ | みほんと おなじ きのこを えらぶ → ひを おこす → ふきこぼれる まえに とめる | どぐう |
| ふゆ | 🐗 いのしし なべ | あしあとを たどる → ゆみや → にこむ | なまえが わからない（もじが まだ ない） |

- 画面の 下に 時代の ものさし（じょうもん → … → えど）。「じょうもん じだい」が 光ります。
- おわりに「つぎは どんな じだい？」で やよい じだいを 1文 予告します。
- 既存の `jomon-mura/`（むらで 1年 くらす シミュレーション）とは べつもの。こちらは「たべもの」だけに しぼっています。

## 歴史の あつかい（保護者むけの 注は アプリ内「おうちの かたへ」と 各カードに 小さく 表示）

- 縄文時代は 約1万6000年前〜約2400年前（年代は諸説あり）。
- 「縄文クッキー」は クッキー状の炭化物の呼び名。くわしい作り方は分かっておらず、手順は想像をまじえている。
- 「くりごはん ふう」は お米なしの想像メニュー（水田の米づくりが広まるのは弥生時代）。
- きのこ形土製品を「食べられるきのこの見本」とするのは説のひとつ。土偶の用途も はっきりしていない。
- ドキさん・コロは 案内役で 実在の人物ではない（文字がなく、名前の伝わる人はいない）。

## つくり
