# シャワーで あらいっこ（shower-araikko）

どろんこの でんしゃや どうぶつを シャワーで ぴかぴかに する、さわって きもちいい あそび。
未就学〜小学校低学年むけ。

公開URL: https://kisi1554.github.io/Pages/shower-araikko/

## あそびかた

1. メニュー（ぴかぴか ずかん）から ステージを えらぶ。
2. 画面を なぞると シャワーヘッドが ついてきて みずが でる。指を はなすと とまる。
3. **3ステップ**: ① みずで どろを ながす → ② 🧴 あわ ボタンで せっけんに きりかえ、なぞって ごしごし
   （しつこい よごれは あわで しか おちない）→ ③ すすぎで あわを ながす。あわが のこると「まだ あわあわ だよ」。
4. よごれが 95% きえたら ぴかぴか きらきら＋ファンファーレ。どうぶつは ブルブルッと みずを はらう。
5. 🌡️ おんど ダイヤル（つめたい／ちょうどいい／あつい）で どうぶつの かおが かわる。
   ぞう・ペンギンは つめたいのが すき、いぬ・ねこ・ブタは ぬるめが すき、あつすぎは「あちち」。
   おさらは おゆの ほうが あぶら よごれが よく おちる。
6. 💧 みずメーター: よごれに あたらない ところへ だしっぱなしに すると へって ★ が へる（エコの ひとこと）。

## ステージ（13こ）

でんしゃ（せんしゃき で 3りょう じゅんばんに）、ぞう、いぬ、くるま、ブタ、くつ、おさら、まど、
じぶんの て（ばいきんを あわで やっつける。てのひら → ゆびの あいだ → ゆびさき・つめ → おやゆび → てくび の じゅんばん）、
ねこ、ペンギン、おまけ: みずやり（3つの はなを ちょうどいい みずに。かけすぎは みずたまり）、
しょうぼうし（ホースで ひの キャラを けすと にげていく）。

## しくみ

- `index.html` / `style.css` / `app.js` だけ。外部ライブラリなし。絵は すべて Canvas で コードから かく。
- みずは Canvas の パーティクル（数百つぶ、重力と 速度）。つぶが 当たった 場所の よごれマスク
  （オフスクリーン Canvas、デザイン座標の 0.62 倍）を `destination-out` で すこしずつ けす。
  どろ・しつこい よごれ・あわ を べつべつの マスクで もつ。
- のこり率は 0.5秒ごと（と 指を はなした とき）に マスクの 画素を かぞえて 計算する。
- フレーム時間を みて パーティクル数を 自動で へらす／ふやす（低スペック端末むけ）。
- 音は WebAudio: ホワイトノイズ＋バンドパスで 水音（シャワーの いきおい・あたっている かで 音量と 音色が かわる、
  ホースは ひくい 音）。あわの ぷちぷち、ぴかぴかの キラン、ファンファーレ。右上で オン/オフ。
- 進捗（ずかん・★・音の設定）は localStorage `shower-araikko-v1`（try/catch）。
- テスト用に `window.__sa` で 状態を のぞける。
