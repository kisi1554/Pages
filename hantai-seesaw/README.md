# はんたい シーソー 🔁

**えと いっしょに はんたいことば を 40くみ おぼえる**（5さい〜）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. シーソーの ひだりに、え つきの ことば（れい: 🐘 おおきい）が のる。
2. したの 3〜4まいの カードから **はんたいの ことば** を タップすると、みぎに とんで のる。
3. **せいかい** → シーソーが まっすぐ になって キラキラ＆ほめことば。
   **まちがい** → シーソーが ぐらっと かたむいて カードが もどる（なんどでも やりなおせる。2かい まちがえると こたえの カードが ひかる）。
4. 5もんで 1かい（1〜3ぷん）。おわりに あつめた くみを いちらんで みせる（はじめて の くみには「あたらしい！」）。

## なかみ（40くみ・4だんかい）

| だんかい | れい |
| --- | --- |
| 1. ようす | おおきい/ちいさい、ながい/みじかい、あつい/さむい、あかるい/くらい …（カード 3まい） |
| 2. ようす ２ | あまい/からい、かたい/やわらかい、ちかい/とおい …（ここから カード 4まい） |
| 3. うごき | のぼる/おりる、あける/しめる、つける/けす … |
| 4. とき・ばしょ | あさ/よる、うえ/した、みぎ/ひだり、きのう/あした … |

え は 絵文字＋CSS の かざり（おおきさ・くらさ・あつい/つめたい いろ・うすさ）で、ひだりと みぎの ちがいが ひと目で わかる ように している。
1かいの 5もんは、まだ あつめて いない くみを ゆうせんして だす。

## ずかん

あつめた くみは localStorage（`hantai-seesaw-v1`）に ほぞん。📖 ずかん で おすと、まっすぐ の シーソーに のった え と ことば を もういちど みられる。

## データの なおしかた

`index.html` の `PAIRS`（`[だんかい, [ことば, え, かざり], [ことば, え, かざり]]`）を かきかえる。
かざり: `big` `small` `dark` `glow` `hot` `cold` `fade` `flip` `wide` `night` `morning`（スペースで ならべられる）。
