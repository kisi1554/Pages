# そりゅうし たんけん ラボ ⚛️

世界の3つの大きな実験装置で、**素粒子（そりゅうし）**を見つける子どもむけシミュレーターです。
`index.html` をブラウザで開くだけで動きます（外部ライブラリなし）。

| タブ | 実験装置 | あそびかた |
| --- | --- | --- |
| 🌀 LHC | CERN の大型ハドロン衝突型加速器（スイス・フランス） | 「かそく！」で陽子を光の速さ近くまで加速 → 「ぶつける！」でアトラス検出器の断面に飛び出す粒子の飛跡を表示。ミューオン・電子・光子・ジェット・見えないニュートリノ、まれにヒッグス粒子 |
| 🧊 アイスキューブ | 南極の氷の中のニュートリノ観測所 | ニュートリノが氷にぶつかり、光センサー（DOM）が光る順番を色（赤→紫）で表示。ミューオンのすじ・電子のシャワー・まれなタウの「ダブルバン」 |
| 💧 スーパーカミオカンデ | 岐阜県神岡の水タンク | 壁の光センサーに映るチェレンコフ光の「わ」を見て、**くっきり＝ミューオン／ぼやけ＝電子** を当てるクイズ |

- 見つけた粒子は 📘 **ずかん**（10種類）にたまります
- 文字はひらがな中心、タイトルの漢字にはふりがな
- 音は WebAudio の合成音のみ。右上の 🔊 でオン/オフ
- ずかん・あたりの数・最後に開いたタブは localStorage に保存（読み書きは try/catch）
- たて持ちスマホ／よこ持ちタブレットどちらでも崩れないレイアウト

※ 子どもむけに単純化した「それっぽい」表示で、実際の物理計算ではありません。
