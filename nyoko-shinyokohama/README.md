# にょこにょこ えきめぐり 🐛💨

いもむしの **にょこくん** が、しゅとけんの でんしゃの せんろぞいを にょこにょこ あるいて、
えきの スタンプを あつめる わらえる よこスクロール ゲーム。
でんしゃには のらない。のりかえも ぜんぶ あるいて いく。

- `index.html` … ゲーム ほんたい（HTML・CSS・JS）
- `net.js` … ろせんず の データ（23ろせん・のべ 532えき）

フォルダめいは むかしの なまえ（しんよこはま）の まま。

## あそびかた

| そうさ | なにが おきる |

| 🍠 を ひろって「ぷっ!」（↑ / F キー） | おならで びゅーんと ブースト |
| 「ぷっ!」の あとの たしざん（たす2・たす3、ときどき たす4） | せいかいすると スーパー（3ばい）・ハイパー（4ばい）・ウルトラ（6ばい）おなら。はでな えんしゅつつき |
| 🚉 えきメニュー（えきに ついたら みぎうえに でる） | そのえきに とまる ろせんに **のりかえ**（むきも えらべる）／ **ひきかえす**。しゅうてんでは じどうで ひらく |

## もくてき

- **📮 えきスタンプ**: はじめて とおった えきで スタンプ。おなじ なまえの えきは 1こ（ぜんぶで 433こ）。
  ろせんの えきを ぜんぶ あつめると「○○せん コンプリート!」、スタンプちょうに 👑。
- **🎯 ミッション**: 「○○えきへ いこう」。ちょっと とおい えき（まだ スタンプが ない えきを ゆうせん）が でる。
  つくと 🍠 まんたん ＆ つぎの ミッション。
- **💡 ヒント**: さいたんの みち（となりの えき = 1、のりかえ = 3 で かぞえる）を たどって、
  「このまま ○○えきまで → △△せんに のりかえ」「ぎゃくむき だよ」などを だす。
  えきメニューでは おすすめの ボタンに 💡 が つく。
- きろく（スタンプ・ミッションの かず・さいごに いた えき）は この ブラウザに ほぞん。
  タイトルの「つづきから」で さいごの えきから さいかい できる。

## ふみきり 🚃

- せんろが みちを よこぎる ところに ふみきり。ぜんぶで **233か所**（京急 47・小田急 41・南武線 26・江ノ電/京王/相鉄 20 …）。
  やまのてせんは ほんものと おなじく たばた〜こまごめ の 1か所 だけ。ちかてつには ない。
- 6びょう あく → 「カンカン」と あかい ランプ・しゃだんきが おりる → でんしゃが おくから ガタンゴトン → あがる。
- **しゃだんきが おりている あいだに はいると、でんしゃに ひかれて「アウト！」ゲームオーバー**。
  「ふみきりの まえから」で つづきから。おならで とんでいる ときは てまえで キキーッと とまる。
- ちかくで カンカンが なると にょこくんが「カンカン! とまって まとう!」と いう。

## ろせん（net.js）

そうてつせん・そうてつ いずみのせん・えのでん ／
ちかてつ: ブルーライン・グリーンライン・みなとみらいせん・ぎんざせん・まるのうちせん

- のりかえは **おなじ なまえの えき** で じどうで できる（61えき）。なまえが ちがっても あるいて のりかえる えきは `ALIAS`
  （京急川崎 → 川崎、武蔵溝ノ口 → 溝の口 など）。
- `crossing` … ふみきりの でやすさ、`sea` … うみが みえる えき（とうかいどうせんの おおいそ〜あたみ、えのでん など）。
- ろせんを ふやす ときは `net.js` に 1ぎょう たすだけ。

## せかいの しくみ

- **ブルーライン（しょうなんだい → あざみの）** は てづくりの コース。ラーメンやさん・ねこ・カラス・ダンゴムシ・
  かんじょう2ごうせんの しんごう（あかで わたると くるまに ひかれて アウト！）・よこはまスタジアム・かんらんしゃ など。
  とちゅうの えきから はいっても、もう すぎた しかけは でない。
- **ほかの ろせん（と ブルーラインの ぎゃくむき）** は じどうで つくる みち。えきと えきの あいだは 700。
  いえ・ビル・き・めいしょ（⛩️🏫🏪 など）が ならび、うしろの せんろを その ろせんの いろの でんしゃが はしる
  （ちかてつは せんろが みえない）。うみぞいの えきでは うみ・ヨット・しま。
- ふみきり・めいしょ・おいもの ばしょは ろせんと えきから きまるので、なんど いっても おなじ ばしょに ある。
