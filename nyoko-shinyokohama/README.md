# にょこにょこ しんよこはま 🐛💨

いもむしの **にょこくん** が、岸根公園（きしねこうえん）から 新横浜（しんよこはま）を とおって
ブルーラインぞいに あざみ野（あざみの）まで にょこにょこ すすむ、わらえる よこスクロール ゲーム。`index.html` だけで うごく。

## あそびかた

| そうさ | なにが おきる |
| --- | --- |
| 「にょこ にょこ」ボタンを おしつづける（画面タップ・スペースキー・→ でも OK） | しゃくとりむしの うごきで すすむ |
| 🍠 を ひろって「ぷっ!」ボタン（↑ / F キー） | おならで びゅーんと ブースト |
| 「ぷっ!」の あとの たしざんに こたえる（たす2・たす3、ときどき レアの たす4） | せいかいすると むずかしいほど はやい：たす2 → **2ばい**、たす3 → **2.5ばい**、たす4 → **3ばい**。まちがえても ふつうの おならは でる |
| にょこくんを タッチ | くすぐったがって わらう |
| 🗣️ ボタン | にょこくんの こえ（ブラウザの よみあげ）の オン/オフ |

ゲームオーバーは ない。どんなに ぶつかっても かならず ゴールできる。

## しくみ

- Canvas 2D で えがいている（がぞう・がいぶライブラリ なし）。
- こうかおんは WebAudio の ごうせいおん だけ（おならの おとも ごうせい）。🔊 で ぜんぶの おとの オン/オフ。
- にょこくんの こえは ブラウザの おんせいごうせい（speechSynthesis）で、たかい こえで よみあげる。🗣️ で オン/オフ。
- じこベスト・おと・こえの せっていは localStorage（`nyokoShinyoko.*`）に ほぞん。
- せかいの たかさを 300 に こていし、はばが せまい 縦もちスマホでは 空を ひろげて ちょうせい。
