# にょこにょこ しんよこはま 🐛💨

いもむしの **にょこすけ** が、岸根公園（きしねこうえん）から 新横浜（しんよこはま）まで
にょこにょこ すすむ、わらえる よこスクロール ゲーム。`index.html` だけで うごく。

## あそびかた

| そうさ | なにが おきる |
| --- | --- |
| 「にょこ にょこ」ボタンを おしつづける（画面タップ・スペースキー・→ でも OK） | しゃくとりむしの うごきで すすむ |
| 🍠 を ひろって「ぷっ!」ボタン（↑ / F キー） | おならで びゅーんと ブースト |
| にょこすけを タッチ | くすぐったがって わらう |

ゲームオーバーは ない。どんなに ぶつかっても かならず ゴールできる。

## しくみ

- Canvas 2D で えがいている（がぞう・がいぶライブラリ なし）。
- おとは WebAudio の ごうせいおん だけ（おならの おとも ごうせい）。🔊 で オン/オフ。
- じこベストと おとの せっていは localStorage（`nyokoShinyoko.*`）に ほぞん。
- せかいの たかさを 300 に こていし、はばが せまい 縦もちスマホでは 空を ひろげて ちょうせい。
