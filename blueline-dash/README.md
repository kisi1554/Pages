# ブルーライン ダッシュ 🚇💨

横浜市営地下鉄 ブルーライン（**B01 湘南台 → B32 あざみ野**、32えき）を ぶたいに した 2D アクションゲーム。
あざみ野からは とうきゅう でんえんとしせんに のりかえて 渋谷・中央林間 まで いける。
ブルーラインの でんしゃ「あおくん」が じどうで はしるので、ジャンプ と ファーン で すすむ。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音 ＋ えきめいの よみあげ）。

## あそびかた

- **ジャンプ**（ボタン／がめんタッチ／スペース・↑）。くうちゅうで もう1かいで **2だん ジャンプ**。
- **ファーン**（ボタン／X・→）: おとの なみで コウモリ・カラス・おじゃまムシを やっつける（1びょう クールタイム）。
- せんろの **あな**・**コーン** は とびこえる。**おじゃまムシ** は ふむと たおせる。
- 🛸 **ポイポイUFO**（そらから こうげき）: そらを とびながら ばくだんを おとす。おちる ばしょには せんろに あかい ⭕ が でるので
  ジャンプで よける。ファーンは そらの UFO にも とどく（2だんジャンプで ふんでも たおせる）。ブルーラインの 4くかんめ ごろから でてくる。
- 🎫 **きっぷ** を あつめる（ぜんぶ とると ろせんずに ★）。⭐ むてき、❤️ かいふく。
- **B20 横浜** と **B32 あざみ野** の てまえに ボス「でっかい おじゃまムシ」（ファーンで 3かい／ふつうは 5かい）。
- **ミンせんせい の むしクイズ**: ミンミンゼミの ミンせんせい（めがね・はかせぼう）が
  **湘南台（しゅっぱつ まえ）・立場・戸塚・舞岡・上永谷・上大岡・蒔田** で まっていて、むしクイズを だす。
  せいかい するまで さきに すすめない（まちがえた こたえは けされて、もういちど えらべる）。
  クイズは 20もん（`BUGQ`）から かぶらないように でる。「ミーン ミンミン」の なきごえは WebAudio の ごうせいおん。
- **ホームドア**: ぜんぶの えきの ホームに ホームドア（とびら・とぶくろ・ランプ・ばんごう）。
  しゅっぱつ するときは ドアが しまって（ランプ あか）から はしりだし、とうちゃくして とまると
  「ピンポン」と なって ドアが ひらく（ランプ みどり）。
- **おきゃくさんの のりおり**: ドアが ひらくと、とうちゃく えきでは さきに おりる ひと（2〜4にん）が でてきて ホームを あるいて いき、
  そのあと ドアの よこで まっていた ひとが のりこむ。しゅっぱつ えきでも のる ひとが のってから ドアが しまる。
  ホームには たっている ひとも いる（こども・かばん・ぼうし など みためは えきごとに きまった たねで かわる）。
  えきに とまっている あいだは でんしゃが がめんの まんなか よりに くる。
- **あなに おちると**: 「ヒューン…」と おちて（カメラも した へ ついていく）、そこで「ドカーン！」と ばくはつ。
  ハートが 1つ へって、あなの さきから ふっかつ。
- 1くかん（えき → つぎの えき）が 1ステージ。とうちゃくすると えきめい（ふりがな・えきばんごう）、のりかえ、まめちしき を ひょうじして よみあげる。

## じつざいの ろせんず

- 32えきの なまえ・よみ・えきばんごう（B01〜B32）・おもな のりかえは 実在の ブルーライン どおり。
- 🗺️ ろせんずは 各駅の だいたいの 緯度経度から かいた かたち（横浜港の うみ つき）。とうちゃくした えきから しゅっぱつ できる。
- おそと（高架）を はしる えき（上永谷・北新横浜・新羽・センター南・センター北）の くかんは そらと まちの けしき、
  それ以外は トンネル。ちかと おそとが かわる くかんでは とちゅうに トンネルの でいりぐちが ある。

## あざみので でんえんとしせんに のりかえ

- ブルーラインで **B32 あざみ野** に つくと、ゴールの がめんから **とうきゅう でんえんとしせん** に のりかえ できる
  （タイトル・ろせんずの あざみの からも のりかえ できる）。
- いきさきは 2つ: **しぶや ほうめん**（DT16 あざみ野 → DT01 渋谷、16えき）／ **ちゅうおうりんかん ほうめん**（DT16 → DT27 中央林間、12えき）。
- でんえんとしせんでは みどりの おびの でんしゃ「みどりくん」。えきめいひょう・ホームドア・トンネルの ラインも みどり いろ。
  渋谷〜用賀は トンネル、二子玉川〜つきみ野は おそと、中央林間は ちか。ボスは 二子玉川・渋谷・中央林間 の てまえ。
- ろせんずは うえの タブで ろせんを きりかえ。ほかの せんも うすく かいて ある（じっさいの いち）。
- きろくは ろせんごと（`save.lines.dts` / `save.lines.dtc`。ブルーラインは まえと おなじ ばしょ）。
