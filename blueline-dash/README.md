# ブルーライン ダッシュ 🚇💨

横浜市営地下鉄 ブルーライン（**B01 湘南台 → B32 あざみ野**、32えき）を ぶたいに した 2D アクションゲーム。
ブルーラインの でんしゃ「あおくん」が じどうで はしるので、ジャンプ と ファーン で すすむ。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音 ＋ えきめいの よみあげ）。

## あそびかた

- **ジャンプ**（ボタン／がめんタッチ／スペース・↑）。くうちゅうで もう1かいで **2だん ジャンプ**。
- **ファーン**（ボタン／X・→）: おとの なみで コウモリ・カラス・おじゃまムシを やっつける（1びょう クールタイム）。
- せんろの **あな**・**コーン** は とびこえる。**おじゃまムシ** は ふむと たおせる。
- 🎫 **きっぷ** を あつめる（ぜんぶ とると ろせんずに ★）。⭐ むてき、❤️ かいふく。
- **B20 横浜** と **B32 あざみ野** の てまえに ボス「でっかい おじゃまムシ」（ファーンで 3かい／ふつうは 5かい）。
- 1くかん（えき → つぎの えき）が 1ステージ。とうちゃくすると えきめい（ふりがな・えきばんごう）、のりかえ、まめちしき を ひょうじして よみあげる。

## じつざいの ろせんず

- 32えきの なまえ・よみ・えきばんごう（B01〜B32）・おもな のりかえは 実在の ブルーライン どおり。
- 🗺️ ろせんずは 各駅の だいたいの 緯度経度から かいた かたち（横浜港の うみ つき）。とうちゃくした えきから しゅっぱつ できる。
- おそと（高架）を はしる えき（上永谷・北新横浜・新羽・センター南・センター北）の くかんは そらと まちの けしき、
  それ以外は トンネル。ちかと おそとが かわる くかんでは とちゅうに トンネルの でいりぐちが ある。

## むずかしさ

| | はやさ | ハート |
| --- | --- | --- |
| 🐢 やさしい | ゆっくり | 5 |
| 🐇 ふつう | はやい | 3 |

ステージは えきごとに きまった たね（seed）で つくるので、なんど あそんでも おなじ コース。おくの えきほど むずかしい。

## しくみ

- 進捗は localStorage `blueline-dash.v1`（とうちゃくした くかん・きっぷの さいこう・★・むずかしさ・おと）。
- URL に `#debug` で `window.__dash`（`startStage(k)`, `bot()`, `update(dt)`）。`bot()` は デモ（タイトルの うしろで はしる）と テストに つかう じどう うんてん。
