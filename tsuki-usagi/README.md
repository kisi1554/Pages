# つきの うさぎ と かぐやひめ 🐰🌕

つきの うえで うさぎが かぐやひめと たたかう 3D アクション ゲーム（年長〜小学生むけ）。
かぐやひめに もっていかれた つきの おだんごを、おだんごを なげて とりかえそう！

`index.html` をブラウザで開くだけで遊べます。**外部ライブラリ・CDN なし**
（3D は WebGL を 手がき＝`coaster-battle/gl.js` と おなじ エンジン、おとは WebAudio の ごうせいおん）。

## あそびかた

| そうさ | タッチ | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| うごく | ひだりがわ を ドラッグ（スティック） | ← → ↑ ↓ / WASD | ひだりスティック・じゅうじキー |
| ジャンプ（くうちゅうで もう1かい） | ⬆️ | スペース / K | A |
| なげる（かぐやひめを じどうで ねらう） | 🍡（おしっぱなしで れんしゃ） | J / Z / Enter | X / B / RT |
| ていし | ⏸ | P / Esc | |

- カメラは いつも うさぎの うしろから かぐやひめの ほうを むく。まえに たおすと かぐやひめへ ちかづき、よこに たおすと まわりこむ。
- つきなので じゅうりょくが よわく、ふわっと たかく とべる。

## かぐやひめの わざ

| わざ | よけかた |
| --- | --- |
| 🟡 ひかりの たま（3つ / ほんきで 5つを 2かい） | よこへ うごいて よける |
| 🔴 たけのこ にょきにょき（あかい まるの あと たけが はえる） | すぐ まるの そとへ にげる |
| 💫 つきの わ（ひかる わっかが ひろがる） | ジャンプで とびこえる |

- げんきが はんぶんに なると **ほんき**（うごきが はやく、わざが ふえる。BGM も はやくなる）。
- ときどき でる **おつきみ だんご** を とると ハートが 1つ もどる。

## むずかしさ

| | ハート | かぐやひめの げんき |
| --- | --- | --- |
| やさしい | 7 | 16 |
| ふつう | 5 | 24 |
| むずかしい | 4 | 32 |

クリアした いちばん はやい じかんを localStorage（`tsuki-usagi-best`）に きろくする。おとの オン/オフ も おぼえる（`tsuki-usagi-sound`）。
