# つきの うさぎ と かぐやひめ 🐰🌕

つきの うえで うさぎが かぐやひめと たたかう 3D アクション ゲーム（年長〜小学生むけ）。
かぐやひめに もっていかれた つきの おだんごを、おだんごを なげて とりかえそう！

`index.html` をブラウザで開くだけで遊べます。**外部ライブラリ・CDN なし**
（3D は WebGL を 手がき＝`coaster-battle/gl.js` と おなじ エンジン、おとは WebAudio の ごうせいおん）。
