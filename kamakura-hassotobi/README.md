# よしつね はっそうとび 🏹

**ふねから ふねへ ぴょーん！ ぶしの よの はじまり「かまくら じだい」を あそんで しろう。**
10本シリーズ「じだい たんけん」の かまくら じだい編（5才〜）。あそびの 型は「ジャンプ アクション」。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/kamakura-hassotobi/

## あそびかた（1回 2〜3分）

ステージの まえに、あにの よりともから てがみが とどく（いつも まじめな かおで ハンコを ぽん）。

1. **⛵ はっそうとび** … がめんを ながく おすほど とおくへ とぶ。はなすと ジャンプ。
   おしている あいだ とぶ みちと ちゃくち てん（◎／×）が でる。8そう めの ふねで クリア。
   おちても みずしぶきだけ。すぐ おなじ ふねから やりなおせる。
   - べんけいが あとから おなじ ふねに とびのって、ふねが ぐらぐら しずみかける
   - 3そう めで かもめが よしつねの あたまに とまる
2. **🐎 いざ かまくら！** … うまで はしる。タップで ジャンプして いし・まるた・さく・ねている いぬ・みずたまりを こえる。
   ぶつかっても すこし おそく なるだけ。
3. **🧘 だいぶつ おさんぽ** … あるいて かまくらの だいぶつまで。ジャンプで みずたまりを よけ、とんでいる はっぱを あつめる。

おわりに「つぎは どんな じだい？」で むろまち じだいを 1文 予告。
クリアした ステージは タイトルから えらんで あそべる。

## 歴史の 確認メモ

- 壇ノ浦の戦い 1185年。八艘飛びは『平家物語』などに伝わる言い伝え（アプリ内でも「いいつたえ」と表記）。
- 源頼朝（1147〜1199）。1185年 守護・地頭、1192年 征夷大将軍。幕府の成立年は諸説あり、両方を併記。
- 鎌倉は三方を山、一方を海に囲まれ守りやすい地。
- 御恩と奉公。「いざ鎌倉」は謡曲『鉢木』由来とされる（のちの時代の話であることを明記）。
- 北条政子（1157〜1225）。頼朝の死後も幕府を支え、承久の乱（1221年）で御家人に呼びかけたと伝わる。
- 鎌倉大仏（高徳院・阿弥陀如来坐像、国宝）。1252年造立開始と伝わる＝頼朝の死後。像高約11.3m、現在は露座。
- たたかいは「とぶ・かわす」だけで表現（切る・血は出さない）。

## つくり

- `index.html` 1枚。キャンバスで描画、音は WebAudio の合成音（🔊／🔇）。
- 進捗（クリア・カード・おと）は localStorage `kamakura-hassotobi-v1`（try/catch）。
- ながおし・タップは pointer イベント。キャンバスは `touch-action: none`。キーボードは スペース／↑。
- ズーム防止は `tools/no-zoom.py` の共通ブロック。
