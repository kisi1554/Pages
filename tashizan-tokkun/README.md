# ケロたんの たしざん とっくん

くもん 算数 2A に すすむための たしざん とっくん アプリ。かえるの ケロたんと いっしょに れんしゅうする。

## もんだい

`14+3` `7+3` `9+3` `4+3` `15+3` `3+2` `10+2` `7+2` `10+3` の 9もん（`index.html` の `PROBLEMS`）。

## モード

| モード | ないよう |
| --- | --- |
| れんしゅう | 10もん。9もん ぜんぶ ＋ にがてな もんだいを 1もん。「ヒント」で ケロたんが すうじの せんを ぴょんぴょん すすんで かぞえかたを みせる（まちがえたら じどうで でる） |
| タイムアタック | 9もん ぜんぶを シャッフル。ノーミスの ときだけ ベストタイムに なる。めやすは 20びょう |
| マスターひょう | もんだいごとに ⭐ を つける（せいかい＝1、6びょう いない＝2、3びょう いない＝3。ヒントを つかうと タイムは のこらない） |

- こたえは テンキーで いれる。けたが そろうと じどうで まるつけ
- 5れんぞく せいかいで かみふぶき。おわると シール（30しゅるい）が もらえる
- ほぞんは localStorage（`tashizan-tokkun-v1`）。おとは WebAudio の ごうせいおんで オン/オフ できる
