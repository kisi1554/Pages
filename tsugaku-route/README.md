# 通学ルート比較

志望校ごとに「朝、家を何時に出ればよいか」を並べて比べるページ。

各校の登校時刻に間に合ういちばん遅い便から逆算し、出発時刻・所要時間・乗換回数・運賃・
ルートを一覧にしている。対象は出発が 7:05 以降になる学校のみ。

現在9校（三田国際科学学園・渋谷教育学園渋谷・広尾学園・芝国際・青稜・山手学院・
聖光学院・関東学院・浅野）。学校は少しずつ増やしていく。

## このアプリだけの決まりごと

- **住所は載せない。** 出発地は「自宅」と書き、最寄り駅までの徒歩時間だけを載せる。
  公開ページなので、丁目までの住所や地図は入れない。
- 読み手は保護者なので、ほかのアプリと違って**ひらがな中心にはしない**。
  そのかわり数字と時刻は等幅フォントで、表は横スクロールでも学校名が消えないようにしている。
- 縦持ちスマホ（44rem 以下）では、表を1行＝1カードに組み替える。

## つくり

`index.html` だけで完結。外部ライブラリ・CDN は使わない。

| しくみ | どこ |
| --- | --- |
| 学校ごとの配色 | `--c-<略号>` を `:root` に定義し、`.<略号> { --accent: ... }` で各要素へ配る |
| 表の1列目固定 | 角丸と枠は `.tw` ラッパー側。`table` に `overflow:hidden` を置くと sticky が効かない |
| 狭幅のカード化 | 6列以上の表に `.tw--cards` と各セルの `data-label`。ラベルは `td::before` で出す |
| ダークモード | `prefers-color-scheme` と `[data-theme]` の両方でトークンを再定義 |

## もとの資料

開発用の詳しい版と、追加予定の学校リストは `docs/` にある。

- `docs/commute-routes.html` … 住所入りの版（公開しない）
- `docs/commute-routes-backlog.html` … 追加予定22校と候補提案
- `docs/commute-routes-uiux-review.html` … UI/UX レビュー

**修正はこちらではなく `docs/commute-routes.html` を直してから反映する**と、
住所入りの版と公開版がずれない。
