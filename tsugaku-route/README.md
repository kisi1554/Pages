# 志望校くらべと併願プラン

志望校ごとに「朝、家を何時に出ればよいか」を並べて比べ、**同じページの下半分で併願プランを組む**。
もとは `tsugaku-route/` と `heigan-plan/` の2ページだったが、★の付け外しがその場で
日程表に効くように1枚にまとめた（`heigan-plan/` は `#plan` へ送る転送ページとして残してある）。

ページの並びは `.page > *` の `order` で決めている。
header(0) → もくじ(1) → 結論のカード(2) → 一覧表(3) → **併願プラン(4)** → 各校の詳細(10〜) →
前提(900) → footer(902)。

各校の登校時刻に間に合ういちばん遅い便から逆算し、出発時刻・所要時間・乗換回数・運賃・
ルートを一覧にしている。現在39校で、少しずつ増やしていく。

**★が未設定の学校を「候補から外した」扱いにする。** 未設定（0）だと、その学校はカード・
目次・一覧表・詳細のすべてでグレー表示になり、★を1つでも付ければ色が戻る。
以前は「出発が 7:05 以降」という線で対象／対象外を分け、対象外を末尾へ送っていたが、
それはやめて39校を同じ並びに混ぜてある。

**はじめて開いたときの★は `DEFAULT_WISH` で決める。** 空なら全校が未設定＝グレーで始まる。
ここを埋めておくと、閲覧データを消してもその値まで戻る。書き換えるときは、ページ内の
「志望度の控えと復元」→「いまの★をコピー」で出た文字列をそのまま貼り替える。

**初期値で始まったときは、その場で `localStorage` に書く。** 1枚になったいまは同じページの
下半分が読むだけだが、`heigan-plan:v1` と同じく端末に残る値なので、書いておく形は変えていない。

## このアプリだけの決まりごと

- **住所は載せない。** 出発地は「自宅」と書き、最寄り駅までの徒歩時間だけを載せる。
  公開ページなので、丁目までの住所や地図は入れない。
- 読み手は保護者なので、ほかのアプリと違って**ひらがな中心にはしない**。
  そのかわり数字と時刻は等幅フォントで、表は横スクロールでも学校名が消えないようにしている。
- 縦持ちスマホ（44rem 以下）では、表を1行＝1カードに組み替える。
- **偏差値と進学実績は腐る。** 偏差値は年度と入試回次で、実績は卒業年で変わる。
  数値を書き換えるときは、footer の年度表記（「2026年6月時点」「2026年春」）も必ず一緒に直す。
- 志望度★は**5段階**。端末のブラウザにしか残らないことを本文に明記してある。
- **★は押した数がそのまま入る。トグルしない。** 同じ★をもう一度押しても消えない
  （志望度を付け替えるときに誤って消える事故があったため）。
  未設定に戻すのは `.stars .clr`（×）だけで、★が付いているときしか表示しない。
- **★の控えと復元**は並び順ボタンの下の `<details class="wishio">`。コピー／貼り付けで復元／
  `DEFAULT_WISH` に戻す、の3つ。貼り付けは**このページにある学校キーで、値が 1〜5 のものだけ**
  を採る。読めない入力のときは既存の保存に触らない。
- 住所は `ul.facts` の先頭 `<li>` に書く。**この位置は地図リンクの生成が前提にしている**ので動かさない。
- **未設定＝グレーアウト**は `[data-wish="0"] { --accent: var(--ink-mute) }` の1行が本体。
  HTML 側にも `data-wish="0"` を書いてあるので、JS が走る前からグレーで出る。
  `paint()` が `data-wish` を同じ学校の4箇所（カード・目次・表の行・詳細）へ配るので、
  `--accent` を上書きするだけで全部が同時にグレーになる。
  **`filter: grayscale()` は使わない**（`position: sticky` の基準がずれて、表の1列目固定が壊れる）。

## 入口

保護者むけの **[教育・学習メニュー](../education/)** の「志望校えらび」から辿る。
子ども向けの「あそびメニュー」（`pages-root/index.html`）には**載せない**。
内容が大人向けで、子どもが並べて見るものではないため。

## 併願プランの同居

`heigan-plan` の中身を `<section class="planapp" id="plan">` に入れてある。混ざらないように
2つ手当てをしている。

| ぶつかるもの | どうしたか |
| --- | --- |
| クラス名（`box` `warn` `sec-note` `lbl` `sub`） | 併願プラン側を `pbox` `pwarn` `pnote` `plbl` `psub` に付け替えた |
| CSS 規則ぜんぶ | `.planapp` の下に閉じ込めた。`:root` のトークンと `*`/`html`/`body`/`.page` は本体のものを使う |

レーンの色 `--a` `--b`（と `-bg` `-on`）だけは、本体の `:root` と2つのダークブロックに足してある。

**スクリプトは2本。★を書く側（上）→ 併願プラン（下）の順に置くこと。**
初期値 `DEFAULT_WISH` の書き込みが先に済んでいないと、併願プランが★を読めない。
同じページで★が変わったときは、★側が投げる `wish-change` イベントで日程表が追随する
（別タブ用の `storage` イベントも残してある）。

## つくり

`index.html` だけで完結。外部ライブラリ・CDN は使わない。

| しくみ | どこ |
| --- | --- |
| 志望度★の保存 | `localStorage` の `tsugaku-route:wish` に `{"seiko":5,...}`（1〜5）の形で。0は書かずに落とす。キーが無ければ `DEFAULT_WISH` から始め、一度でも保存があればそちらが優先。読み書きは try/catch |
| ★とカードリンクの共存 | カードは `<div>`。校名の `<a class="stretched">` を `::after` で全面に広げ、`.stars` を `z-index:2` で上に置く |
| 学校ごとの配色 | `--c-<略号>` を `:root` に定義し、`.<略号> { --accent: ... }` で各要素へ配る。**男子校は青系・共学は赤系** |
| 表の1列目固定 | 角丸と枠は `.tw` ラッパー側。`table` に `overflow:hidden` を置くと sticky が効かない |
| 狭幅のカード化 | 6列以上の表に `.tw--cards` と各セルの `data-label`。ラベルは `td::before` で出す |
| ダークモード | `prefers-color-scheme` と `[data-theme]` の両方でトークンを再定義 |
| 検索・地図リンク | 各 `section.school` の `<header>` に `.ext`。校名は `<h2>`、住所は `ul.facts` の**先頭の `<li>`** から取って URL エンコードする。地図は `住所 + " " + 校名` で引く（住所だけだと番地のない学校が町名の中心に落ちるため） |
