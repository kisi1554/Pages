# へいせい がったい パズル 📱

**おなじ どうぐを スワイプで ぶつけて がったい！ でんわも おんがくも カメラも、しんかさせると さいごは ぜんぶ スマホに なる。**
15本シリーズ「じだい たんけん」の へいせい じだい編（⑭・5才〜）。あそびの 型は「がったい パズル」。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/heisei-gattai/

## あそびかた（1回 1〜3分）

1. 「でんわ／おんがく／しゃしん」の れつを えらぶ。マス目は 3×3（やさしい）か 4×4（むずかしい）。
2. ばんを スワイプ（または ⬅️⬆️⬇️➡️ ボタン・やじるしキー）すると、タイルが ぜんぶ すべる。
   おなじ どうぐが ぶつかると がったいして 1つ 新しい どうぐに しんか。
3. しんかの たびに「むかしは こうだった」の ひとこと（保護者むけの 年も 小さく）。
4. スマホまで しんかさせたら クリア。マスが いっぱいに なったら「↩️ もどす」（なんかいでも）。
5. 3つ ぜんぶ クリアすると フィナーレ「みんな あつまれ！」→「つぎは どんな じだい？」（れいわ）。

つまりにくい 出かた: 新しい タイルは いつも いちばん下の どうぐで、おなじ どうぐの となりに 出やすく、
出した ことで うごけなく なる ばしょには 出さない。

## わらい どころ

- かたかけ でんわを タップ →「よいしょ…… おもい〜！」で かたむく（やく3kg）
- おりたたみを タップすると ぱかぱか ひらく。4びょうに 6かい →「こら〜！ ぱかぱか しすぎ！」
- フィナーレ: スマホ「ぜんぶ ぼくに おまかせ！」→ ほかの どうぐ しょんぼり 💧 → 「みんなが いたから ぼくが うまれたんだ。ありがとう！」

## 史実メモ

- 平成は1989年1月8日〜2019年4月30日。
- 1985年 NTT「ショルダーホン」（約3kg、肩から下げる）。1991年ごろ 手のひらサイズの携帯電話。1999年 携帯電話からインターネット（iモード）、2000年 カメラ付き携帯電話。2008年 日本でiPhone発売、2010年代にスマートフォンが普及。
