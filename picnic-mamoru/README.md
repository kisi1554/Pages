# ピクニック まもりたい 🧺

こうえん の ピクニック に、**アリ・ハト・カラス・リス** が おべんとう を ねらって やって くる！
うちわ・かさ・パンくず・ふえ・みずまき を ならべて **やさしく おいかえす** まもり ゲーム（タワーディフェンス。小学1〜6年）。
いきもの は たおさない。どうぐ で「びっくり」させる と、くるっ と まわって じぶん の おうち へ かえる。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。いきもの の え は canvas に かく オリジナル の ベクター。
おと は WebAudio の 合成音で、🔊 こうかおん・🎵 おんがく を それぞれ オン/オフ）。

- まなび: さくせん（どこ に なに を おく か）、おかね の やりくり、いきもの の くらし（たべもの を さがす こと）
- ほぞん: localStorage `picnic-mamoru-v1`（ステージ ごと の ★、であった いきもの、おと の せってい）

## ルール

- シート の まんなか に おべんとう 10こ（🍙🍤🍓🥚🍅🥦）。いきもの は みち（**まいかい ちがう こうえん の かたち**）を とおって くる。
- どうぐ を しばふ に おく と、はんい に はいった いきもの の **びっくり ゲージ** が たまる。いっぱい → 「ぴゃっ！」→ くるっ と まわって かえる。
- おいかえす と 🌰 **どんぐり コイン**。コイン で どうぐ を かう。おいた どうぐ は タップ → かたづける（7わり もどる）。ウェーブ を のりきる と +5。
- 1ステージ は 3 ウェーブ。さいご に のこった おべんとう で ★（8こ いじょう ★3・5こ いじょう ★2・2こ いじょう ★1）。
  **0こ でも おわり の パーティー は ある**。おわれば つぎ の こうえん が ひらく。
- そうさ: どうぐ を タップ で えらんで しばふ を タップ、または どうぐ を ばん へ ドラッグ。⏩×2 と ⏸️ も ある。

## ステージ

15 こうえん: 🌸 はる の こうえん（1〜4）→ 🌻 なつ の かわら（5〜8）→ 🍁 あき の やま（9〜12）→ ⛄ ふゆ の ゆき の こうえん（13〜15）。
みち は 1〜3ぼん。どうぐ は はる の あいだ に 1つ ずつ ふえる（うちわ・パンくず → かさ → みずまき → ふえ）。
＋ 🌼 **じゆう モード**: きせつ と みち の かず を えらび、コイン 999 で、ボタン で すきな いきもの を よんで ためせる。

## テスト

```bash
node picnic-mamoru/test.js [シード の かず（きほん 20）]   # しくみ
node picnic-mamoru/check.js [スクショ の だしさき]         # ブラウザ（Playwright）
```

- `test.js`: こうえん の かたち（ふち → シート の 1ぽんみち、ながさ、かさならない、おなじ シード で おなじ）、
  いきもの が みち を はずれない、コイン の けいさん、どうぐ の はんい はんてい と きく あいて、
  **どの ステージ・どの こうえん でも ★3 が とれる おきかた が ある**（ソルバー）、なにも おかない と まもれない。
- `check.js`: 3 がめん（390×844・1024×768・768×1024）で ステージ1 を さいご まで（デバッグ フック で どうぐ を おく）、
  ドラッグ／タップ で おける、かたづけ、じゆう モード、カード・ずかん、よこスクロール・ズーム・ルビ なし の かんじ・JS エラー なし。
