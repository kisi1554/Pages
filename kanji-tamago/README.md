# かんじタマゴ（kanji-tamago）

タマゴを わると、漢字のモンスターが 生まれる。生まれた子は カードになって
ずかんに たまり、その漢字の **読みかた・つかいかた・何年生で習うか・その字が
使われている駅** が わかる。

小学1年で習う漢字80字ぜんぶ ＋ 馬（小2）の **81ひき、全員 1体ずつ手描き**で
そろっている（`data.js` の `hand: true/false` は 名ごりで残しているが、
いまは 全員 `true`）。

公開URL（同期後）: https://kisi1554.github.io/Pages/kanji-tamago/

## あそびかた

1. **タマゴ** … 「タマゴを わる！」で ふ化の演出（ゆれる → ヒビ → 光と紙ふぶき → 登場）。
   何回でも わっていい。まだ持っていない子が 出やすくなっている。
2. **カード** … 生まれた子の カードが出る。漢字の情報は ぜんぶ ここに載っている。
   カードを開くと、その子が じぶんで しゃべって じこしょうかいする（読みあげ）。
   下の「◆ おはなし してみよう」で、ボタンを おす（or マイクに 話しかける）と、
   じこしょうかい・つかいかた・えき の話を してくれる。声が 出ている あいだに
   もう一回 話しかけると、前の話は 止めて 新しい話をする。
3. **ずかん** … なかま別の10グループ。まだ持っていない子は シルエット。
   カードを押すと もう一度見られる。
4. **クイズ** … ことばや 駅名の 読みクイズ。正解すると **ごちそうタマゴ** が 1こ。
   ごちそうタマゴは 画数の多い（レアな）子が 出やすい。

## なかま（ずかんの並び）

ぜんいん 手描き。

| --- | --- |
| かず | 一 二 三 四 五 六 七 八 九 十 百 千 |
| そら と てんき | 日 月 天 空 雨 気 夕 年 |
| しぜん | 山 川 土 石 水 火 田 木 林 森 草 花 竹 |
| いきもの | 犬 虫 貝 生 馬 |
| からだ | 目 耳 口 手 足 力 |
| ひと | 人 男 女 子 王 名 |
| まち と がっこう | 町 村 校 学 字 文 本 車 金 玉 糸 |
| むき と おおきさ | 上 下 左 右 中 大 小 先 立 入 出 |

名前は カタカナで、〜マル／〜スケ／〜リン／〜ベエ などで そろえてある
（イチマル・ナナホシ・ハチベエ・ヤマゴン・タンボン…）。

## ファイル

```
kanji-tamago/
├── index.html    画面の骨ぐみ
├── style.css     みため（色は :root でまとめて変えられる）
├── data.js       81ひきのデータ＋絵のレシピ＋字形（自動生成。直接いじらない）
├── monsters.js   絵。81ひき ぜんいん 手描き（部品を組み合わせる しくみも
│                 のこしてあるが、いまは 使っていない）
├── speech.js     おはなし（読みあげ・ききとり）。ブラウザの Web Speech API だけを使う
└── app.js        うごき（ガチャ・演出・カード・ずかん・クイズ・おはなし・保存）
```

外部ライブラリ・CDN・画像ファイルは 使っていない。ゲームの効果音は WebAudio の
合成音、カードの読みあげは ブラウザ標準の SpeechSynthesis（どちらも 音声ファイルは
なし）。右上の 🔊 で 両方まとめて オン/オフ できる。記録は localStorage
（読み書きは try/catch）。

**おはなし機能について** … カードの「◆ おはなし してみよう」は、
`SpeechSynthesis`（読みあげ）と `SpeechRecognition`（ききとり）という、
ブラウザに もとから ある きのうだけで うごく。**サーバーには 何も 送らない**
（マイクの音も、話しかけた ことばも、どこにも 出ていかない）。対応していない
ブラウザ（読みあげ非対応の端末や、iOS Safari など ききとり非対応の環境）でも
エラーには ならず、読みあげは 静かに スキップ、マイクのボタンは そもそも
表示しない（ボタンで話しかける ことは いつでもできる）。マイクを 使うには
ブラウザの 許可が 必要。

## モンスターの 作りかた

81ひき ぜんいん 1体ずつ 手描き。さいしょは 部品を組み合わせて つくっていたが、
似たかたちが 多くなってしまったため、なかまごとに ぜんぶ 手描きへ 描きなおした。

- からだ … 6ひき全員 同じ丸型だったので 目・耳・手 を先に（目玉そのものの体、
  象みたいな大耳、開いた手のひら）
- まち と がっこう … 町・校・字・文・本・車 の6ひきが 同じしかく型だったので
  本・車・字 を先に（開いた本、小さなくるま、すみを ふくんだ ふで）
- ひと … 女・子・王・名 の4ひきが 同じ丸型だったので 4ひき まとめて
  描きなおして このなかまを 描きあげた（きものの女の子、たまごの殻をかぶった
  ひよこ、マントの王さま、なふだそのものの姿）
- むき と おおきさ … 4ひきが 同じ丸型だった中から 大 を先に。「大」の字が
  もともと 両手両足を ひろげた 人の形なので、からだ そのものを その形にした
- かず … 五・六・九・十 の4ひきが 同じ丸型だったので まとめて描きなおし、
  「一」以外は かぶりゼロに（5つの星、さいころ、うずまきの かたつむり、十字の形）
- からだ … 目・耳・手 に続いて 力 も手描きに。ちいさな からだで フレックスした
  うでと、もちあげた大きな石で ちからもちを 表現した
- いろ … 赤・青・白 の3ひきを まとめて描いて、**はじめて 1なかま まるごと
  手描きになった**（赤いりんご、青いさかな、もこもこの 白い雲）
- むき と おおきさ … 左・右 も追加。てぶくろの おやゆびが 左右で
  逆むきに とび出た、鏡あわせの ペアにした
- かず … 二・三・四・七・八・百・千 を描いて **かず なかまが まるごと 完成**。
  りんご2つ・おだんご3本・4つ葉のクローバー・虹・百円玉・折り紙の千羽づる など、
  数字そのものの形に こだわらず 1ぴきずつ ちがう モチーフにした
- いきもの … 虫・貝・生 を描いて **いきもの なかまも まるごと 完成**。
  てんとう虫、しんじゅの入った 二枚貝、ふたばの芽ばえ
- そら と てんき … 天・空・雨・気・夕・年 を描いて **そら と てんき なかまも
  まるごと 完成**。たこ、風船、あめんぼ、雷、ちょうちん、砂時計
- しぜん … 土・石・田・林・草・竹 を描いて **しぜん なかまも まるごと 完成**。
  土のもりあがり、ごつごつの岩、田んぼの田の字、寄りそう2本の林、
  ふさふさの草むら、ふしのある竹
- からだ・ひと・まち と がっこう … 口・足・人・男・町・村・校・学・文・金・玉・糸 を描いて
  **この3なかまが まるごと 完成**。口そのものの すがた、5本ゆびの あし、
  「人」の字なりの すがた、はちまきの 男の子、がいとう、わらぶきの いえ、
  ハンドベル、そつぎょうぼうし、ろうふうかんの おてがみ、きんかい、ガラス玉、
  いとまき
- むき と おおきさ・ようす … 上・下・中・小・先・立・入・出・見・休・早・正・音・円 を
  描いて **のこり2なかまも まるごと 完成し、81ひき 全員 手描きに**。ロケット、
  しずく、「中」の字なりの はこ、3つぼしの ひかり、はたのポール、はしら、
  あなから 出た/入った すがた、虫めがね、木によりかかる ひとやすみ、
  めざましどけい、正かいのハンコ、おんぷ、まんまるコイン

- `monsters.js` の `BODY`（からだ15種）・`PART`（かざり約35種）・`PAL`（いろ15種）が 部品。
- `data.js` の `ART` に 1ひき1行の レシピ:
  `{ b: 'blob', p: 'green', k: '田', f: ['bar2','armsShort','legsShort'] }`
  （b=からだ、p=いろ、k=プリントする字、f=かざり。`fc` で目の大きさ、`mo` で口の大きさも変えられる）

### ふやす・直すとき

```sh
python3 tools/gen-kanji-tamago.py
```

漢字データ（名前・読み・画数・ことば・レシピ）は `tools/gen-kanji-tamago.py` の
`TABLE` に 1行ずつ 書いてある。ここを直して 上のコマンドを走らせると `data.js` が作り直される。
駅は `eki-stamp-rally/data.js` の路線データから 自動で ひろう（足りない字は
スクリプトの `EXTRA_ST` に 手書きで 足してある）。字形は IPAゴシック
（IPA Font License 1.0）のアウトライン。フォントが無い環境では いまの `data.js` の
字形を そのまま 使う。
