# 東急線すごろく

渋谷駅から新横浜駅まで、東急電鉄の各路線(東横線・目黒線・田園都市線・大井町線・
池上線・東急多摩川線・こどもの国線・世田谷線・東急新横浜線)の実在の駅をめぐる、
大人も子どもも一緒に遊べるすごろくゲームです。クイズマスやイベントマスもあります。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルドやサーバーは不要です)。

1. プレイヤー人数(2〜6人)を選び、名前とトークンを設定してスタート。
2. 順番にサイコロをふって駒を進めます。
3. 止まったマスによって効果が変わります。
   - ❓ クイズマス: 東急線にまつわるクイズに挑戦。正解で2マス進み、不正解で1マス戻ります。
   - 🎲 イベントマス: 駅にまつわる出来事で、進んだり戻ったり、1回休みになったりします。
   - 通常マス: その駅の豆知識が表示されます。
4. 🏆新横浜駅にゴールした順にランキングが決まります。全員がゴールするとゲーム終了です。

## ファイル構成

- `index.html` - 画面構造
- `style.css` - デザイン
- `data.js` - 駅データとクイズ問題
- `game.js` - ゲームロジック
