# 中学入試 算数の難易度ランキング（nyushi-nanido）

首都圏の男子校・共学校 23 校に全国の基準点として灘を加えた 24 校を、**出題される算数そのものの難しさ**で S〜D の 5 ランクに並べた
保護者向け 1 ページ。合格の難しさ（偏差値）とは別軸で、両者がずれる学校をあえて目立たせている。

公開URL: https://kisi1554.github.io/Pages/nyushi-nanido/

## 構成

| ブロック | 中身 |
| --- | --- |
| 注意書き | 公式ランキングではないこと、試験時間・大問数はめやすであること |
| 4つの軸の読みかた | 発想 / 処理量 / 記述 / 時間 の定義と、総合ランクの重みづけ |
| ランキング | S（2校・3試験）A（5校）B（6校）C（7校）D（4校） |
| 偏差値と算数の難しさがずれる学校 | 灘・慶應3校・麻布武蔵・栄光・東邦大東邦本郷 の5ケース |
| 趣味として解くなら、この順で | 大人が読み物として楽しむ順 |
| 親としての使いかた | 軸ごとに、その子に必要な練習 |

## ランクのつけかた

**4軸の平均ではない。**「初見の受験生が、試験時間内に完答する難しさ」で並べているので、
**発想**と**時間**を重く見ている。処理量・記述は練習量で埋まる部分が大きいため軽い。

**灘は 1 日目と 2 日目を別カードにしている。**1 日目は処理 5・記述 1・時間 5、2 日目は
処理 3・記述 5・時間 4 で、同じ S ランクでも求めるものがほぼ逆。4 軸に分けないと見えない
典型例なので分けた。**同じランク内の並び順に順位の意味はない。**

D ランクは「易しい」ではなく「**難問を出さないので算数では差がつかない**」という意味。
慶應3校のように偏差値は最上位でもここに入る。ランク名がそのまま入りやすさにならない点に注意。

## 4軸メーターの作り

- 5 セグメントの離散メーター。塗り = `var(--accent)`、未塗り = **同じ色相の明るい段**
  （`--trk`）。グレーのトラックは使わない。
- セグメント間は 2px、角丸 4px（高さ 8px なのでピル形）。
- **色だけに情報を持たせない。**軸名（発想 / 処理 / 記述 / 時間）は固定位置のラベル、
  値は右に数字を併記し、`role="img"` + `aria-label="<軸> 5段階中<n>"` を付けている。
- 幅 560px 以下で 4 列 → 2 列に折り返す。

ランク記号（S/A/B/C/D）も色に依存させない。バッジはすべて同じ `--accent` の塗りで、
順序はバンド左の罫線の太さ（`--bw`: 6px→2px）と文字そのもので表している。

## 直すときの注意

- 学校データは 1 ファイルにベタ書き。**校名・試験時間・4軸・特徴文** が 1 つの
  `<article class="sch">` に入っている。順番がそのまま表示順。
- 試験時間・大問数は年度で変わる。書き換えるときは各校の募集要項を確認すること。
- 校数を変えたらバンド見出しの `<span class="bn">n校</span>`、冒頭リード文の校数、
  `education/index.html` のカード（サブタイトルと「→」の文言）も直す。
- `../sapix-lesson/` `../tsugaku-route/` `../education/` へのリンクは
  Pages 上でのみ解決する（リポジトリ内で開くと 404）。
