# 宇宙戦争（うちゅう せんそう）🛸

ガラクタ ロボットの「ギギガー ぐんだん」から、まんなかの **ぼくらの ほし** を まもる うちゅう アクション。
**わくせいの じゅうりょくで たまが まがる** 360° の うちゅうを じゆうに とびまわり、たまは じどうで ちかくの てきへ。
**ふたりで きょうりょく**（1だいの がめんを ひだり・みぎ で わけて）も できる。
`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・CDN なし。canvas 2D と WebAudio）。

ほかの シューティングとの ちがい: [わくせい シューティング](../wakusei-shooting/) は よこスクロール、
[にょこすけ シューティング](../nyoko-shooting/) は たてスクロール。こちらは **スクロール しない ひろい うちゅう** で、
すすむ のでは なく **ほしを まもる**（ぼうえい）ゲーム。たおした ロボットは スターかけらに もどる（こわい ひょうげんは しない）。

## そうさ

| そうさ | なにが おきる |
| --- | --- |
| がめんを ゆびで おして なぞる | おした ところが スティック に なり、その むきへ とぶ（ゆびが はなれすぎると スティックも ついてくる） |
| ふたり | がめんの **ひだり はんぶん＝1P**（あお）、**みぎ はんぶん＝2P**（みどり）。どうじに さわれる |
| たま | **じどう**。いちばん ちかい てきの うごく さきを よんで うつ |
| 💫 スターボム | てきの たまを ぜんぶ けして、まわりの てきに おおダメージ（さいしょ 2こ） |
| キーボード | 1P＝WASD（ひとりの ときは やじるしも）・スペースで ボム ／ 2P＝やじるし・Enter で ボム ／ P・Esc で ひとやすみ |

## ルール

- ばしょ（セクター）は 5つ。それぞれ **8ウェーブ**、さいごは ボス。ウェーブ 3 と 6 の あとに **ショップ**。
- ロボットが ぼくらの ほしに ぶつかったり、たまが あたると **バリア** が へる。ウェーブを まもりきると すこし もどる。
- **やさしい**: バリアは 1 より へらない（まけ なし）、てきの たまが おそい。**ふつう**: バリア 0 で まけ。
- じぶんが やられても 3びょうで ほしの そばに ふっかつ（ゲームオーバーは ない）。
- クリアの ★ は のこった バリア（70% より おおい ★3、35% より おおい ★2）。クリアで つぎの ばしょが ひらく。

| ばしょ | とくちょう | まめちしき（ショップ・けっかで でる） |
| --- | --- | --- |
| 🌙 つき の まえ | れんしゅう。ちいさな つき | つきは やく 27にちで ちきゅうを 1しゅう、まいとし やく 4cm はなれる |
| 🔴 かせい の ちかく | たてロボ が でる | あかいのは さびた てつ。オリンポスさん |
| 🟠 もくせい の うず | おおきな もくせいの つよい じゅうりょく。ばらまき が でる | いちばん おおきい わくせい、だいせきはん |
| 🪐 どせい の わ | ほしの まわりに いわ（たまを ふせぐ）。ボス 2たい | わは こおりと いわ、みずに うくほど かるい |
| 🕳️ ブラックホール | すいこまれると ほしへ ワープ。さいごの ボス ギギガー だいおう | ひかりも にげられない |

| てき | うごき |
| --- | --- |
| ちびドローン | まっすぐ ほしへ |
| いんせき ロボ | おそいが かたくて、ほしに ぶつかると いたい |
| くるくる | ほしの まわりを まわって ほしを うつ |
| たてロボ | プレイヤーを おいかける。**まえの たては たまを はじく**（よこ・うしろから うつ） |
| ばらまき | すこし はなれて 5ほうこうに うつ |
| ボス（こうかん・だいおう） | ほしの まわりを まわり、まるく たまを うち、ザコを よぶ |

**ショップ**（⭐ スターかけら）: ⚡ れんしゃ（Lv3）・🔱 ひろがり ショット（3→5つ）・🛸 なかま メカ（3きまで、いっしょに うつ）・
💫 スターボム ＋1・🛠️ バリア しゅうり・🗼 ほしの たいほう（ほしが じどうで うつ、2きまで）。
たおした ロボットから 🛸（なかま）と ❤️（かいふく）が でる ことも ある。

## しくみ

- `sim.js`（DOM なし）: 1/60びょう ごとの けいさん。たまは **ぜんぶの わくせいの じゅうりょく**（G×おもさ÷きょり²）で まがり、
  プレイヤー（0.25ばい）と てき（0.12ばい）も すこし ひっぱられる。じどう ねらいは あいての はやさから であう ばしょを けいさん（じゅうりょくは かんがえないので、わくせいの そばでは はずれる ことも）。
  うちゅうの はしは まるい かべ。ブラックホールに ふれると ワープ。
- `render.js`: canvas 2D。カメラは プレイヤー（ふたりなら あいだ）を おいかけて、ふたりが はいる ように ズームアウト。レーダー・がめんそとの てきの やじるし。
- `audio.js`: こうかおん と オリジナルの BGM（ボスの ときは テンポ アップ）。🎵 と 🔊 は べつべつに オン/オフ。
- `app.js`: がめん・スティック（マルチタッチ）・キーボード・ショップ・けっか・ほぞん（localStorage `uchu-sensou-v1`、try/catch）。
- `data.js`: わくせい・てき・ウェーブ・ショップ・まめちしき（漢字は ふりがな つき）。

## たしかめかた

```bash
node tools/uchu-sensou/test.js
node tools/uchu-sensou/check.js /tmp/shots
```

`test.js`: じゅうりょくで たまが まがる・わくせいで きえる、じどう ねらいで ちかい てきも まわる てきも たおせる、たてロボの まえ／うしろ、
やさしいは まけない・ふつうは バリア 0 で まけ、ボム（おしっぱなしは 1かい）、ショップの じょうげん、ブラックホールの ワープ、
**じどう そうさ（bot）で 5つの ばしょ ぜんぶを やさしい・ひとり／ふたり で クリア できる**、ふりがな。
`check.js`: Playwright で たて（390×844）・よこ（1024×768）・スマホよこ（844×390）で スティック（CDP タッチ）で うごく → ウェーブ → ショップ →
ボム → クリア → つぎが ひらく、ふたりの どうじ タッチ、ひとやすみ、はみださない、れんだで ズームしない、JS エラー なし。
