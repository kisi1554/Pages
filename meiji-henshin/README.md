# ぶんめいかいか へんしん タップ 🎩

**えどの まちで「あたらしく なる もの」を さがして タップ！ ぽんっと めいじの まちに へんしん。**
15本シリーズ「じだい たんけん」の めいじ じだい編（5才〜）。あそびの 型は「さがして へんしん」。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/meiji-henshin/

## あそびかた（1回 1〜3分）

1. まちを えらぶ（🛣️ みち／🏠 いえの なか／🚉 えき）。
2. えどふうの まちの 絵から「あたらしく なる もの」5こを さがして タップ → ぽんっと へんしん。
   ことり・ねこ・いぬ などは かわらない（タップしても「そのまま だよ」と おしえるだけ。げんてん なし）。
   12びょう うごかないと きらきら ヒント。💡ボタンでも ヒント。
3. 5こ ぜんぶ へんしんさせると、まちの はしから じょうき きかんしゃが けむりを はいて やってくる。
4. ほめる えんしゅつ（⭐・まなび カード）→「まえ」と「あと」の 絵を ならべて くらべる。
5. 3まい ぜんぶ おわると「つぎは どんな じだい？」（たいしょう じだい）。

### わらい どころ

- ちょんまげを きった おさむらいさんが あたまを さわって そわそわ「あたまが すーすー する…」
- はじめての ぎゅうなべで「うまい！」と とびあがる。
- えきで きしゃが いった あと、ホームに げたが ぽつん（「…と いう いいつたえ」と明記）。
