# ちりはかせ ただたか 🗾

日本地理に とても くわしい、ものしりキャラクター **「ただたか」** と おしゃべりする アプリです。
47都道府県の **ゆうめいな ばしょ・めいさん・ちり(地形・気候)・まめちしき** を おしえてくれます。

`index.html` をブラウザで開くだけで遊べます(ビルド・サーバー・外部ライブラリなし)。

## ただたか って だれ?

- かさを かぶり、まるメガネに しろい おひげ、ちずの まきものを もった おじいさん。
- 「わしは ちりはかせの ただたか じゃ」── 一人称は「わし」、ごびは「〜じゃ」「〜のう」。
- なまえは、むかし 日本じゅうを あるいて ちずを つくった **伊能忠敬(いのう ただたか)** から もらった という せってい。
- 表情は 4しゅるい(ふつう・にっこり・かんがえちゅう・びっくり)。しゃべっている あいだは 口が うごきます。

## モード 🧭/🎓

右上の 🧭(または 🎓)ボタンで、ただたかの はなす ないようを えらべます(えらんだ モードは ほぞん されます)。
「中学受験モード」「ものしりモード」と はなしかけても きりかわります。

| モード | ないよう |
| --- | --- |
| 🧭 ものしりモード | いままでどおり。ゆうめいな ばしょ・めいさん・まめちしき・なんどくちめいを ひらがな おおめで たのしく。 |
| 🎓 中学受験モード | 入試に でる 用語を 中心に 漢字+ふりがなで 話す。クイズも 入試むけ。 |

中学受験モードで できること(`data-juken.js`):

- **用語の せつめい**(85語): 地形(扇状地・三角州・リアス海岸・輪中・干拓…)、気候(季節風・やませ・からっ風・雨温図…)、
  農業(促成栽培・抑制栽培・近郊農業・高冷地農業・二毛作・酪農・客土・食料自給率…)、水産業(遠洋・沖合・養殖・栽培漁業・潮目・排他的経済水域…)、
  工業(太平洋ベルト・中京/阪神/京浜/北九州・各工業地域・加工貿易・伝統的工芸品…)、公害(四大公害病・足尾銅山…)、
  人口(過疎・過密・政令指定都市・ドーナツ化現象…)、交通・エネルギー(火力・水力・原子力・地熱…)、領土・地図(東西南北の端・時差・縮尺・等高線…)
- 「農業の用語」「工業の用語」のように 分野ごとに 3語ずつ(「もっと」で つづき)
- **生産量などの 上位県**(40品目): 「りんごの 生産量」「みかんは どこが 1位」「生産量ランキング」
- **6つの 気候区分**: 「気候区分」
- **県の 受験まとめ**: 県の なまえを いうと、気候区分・生産量で 上位の もの・工業地帯・関係する 用語を まとめて 話す
- **入試むけ クイズ**: 用語あて・説明えらび・生産量1位の県・工業地帯の県・気候区分(都市/特色から)・四大公害病の県・地図記号 など
- だまっていると、入試に でる 用語を ひとつ 話しかけてくる

## 地図記号 🗺️

## はなしかた

がめんは **LINEの ような おしゃべり** です。ただたかの こたえは みじかい メッセージに わかれて、
「…(かいて いるよ)」の あとに 1つずつ ながれてきます。いちばん あたらしい メッセージが いつも 見えるので、じぶんで スクロールしなくても よめます
(まえの はなしを 見たい ときだけ うえに スクロール)。ボタンは メッセージが ぜんぶ でてから あらわれます。

下の 入力らんに 文字で うつか、🎤 を おして こえで はなします(こえ入力は 対応ブラウザのみ)。
まん中の ボタンを タップするだけでも 会話が すすみます。
**「もっと」** と いうと、さっきの はなしの つづき(まだ いっていない もの)を はなします。

| きくこと | ただたかの こたえ |
| --- | --- |
| 「ほっかいどう」「ながの」「よこはま」 | その けんの しょうかい |
| 「ならの ゆうめいな ところ」「みえの めいさん」 | 名所・名産(5こずつ。「もっと」で つづき) |
| 「やまがたの ちり」「くまもとの やまと かわ」 | 地形・気候 / 山・川・湖・島 |
| 「ほっかいどうの まち」「きょうとの まつり」「ひろしまの でんしゃ」 | まち / まつり / てつどう |
| 「あおもりの ほうげん」「ながのの れきし」「とちぎの ゆかりの ひと」 | 方言 / 歴史 / 人物 |
| 「あいちの けんの とり」「とうきょうの ひろさ」 | けんの 花・木・鳥 / 面積と人口(じゅんいつき) |
| 「ほっかいどうの よめるかな」「なんどく ちめい」 | よみかたが むずかしい ちめい |
| 「ながのの となり」「ちばの けんちょう」 | となりの けん / 県庁所在地 |
| 「ふじさん」「ディズニー」「さかもとりょうま」「はちのへ」「はなてん」 | 名所・人・まち・ちめいの なまえから けんを さがす |
| 「りんごは どこ?」「かき」 | 名産から けんを さがす(日本一の けんを さきに) |
| 「かんとう」「きゅうしゅう」 | 地方の けんの いちらん |
| 「いちばん たかい やま」「いちばん きたの えき」「日本一」 | 日本一(48こ) |
| 「たかい やま ランキング」「ひとが おおい けん ランキング」 | ランキング(山・川・湖・島・広さ・人口) |
| 「せかいいさん」「ちずきごう」「しんかんせん」「日本三景」 | にっぽん ぜんたいの ちしき |
| 「かいりゅう」「さんみゃく」「へいや」「ちずの みかた」 | ちりの きほん |
| 「クイズ」 | 3択クイズ(下を 参照) |
| 「おすすめの けん」 | まだ きいていない けんを しょうかい |
| 「ただたかって だれ?」「もういちど」 | じこしょうかい / さっきの こたえを くりかえす |

けんの なまえは かんじ・ひらがな・カタカナ どれでも わかります。
「とうきょうと」の なかの「きょうと」の ような かさなりや、「なら(〜なら)」「さが(さがす)」の ような
みじかい ことばの まちがいにも 気をつけて よみとります。

45びょう だまっていると、ただたかの ほうから まめちしきを はなしかけてきます。

## クイズ(3択・20しゅるい)

ボタンで こたえても、こえ・もじで いっても OK。「ヒント」で 地方(または さいしょの もじ)を おしえてくれます。
こたえが ふたつに ならないよう、ほかの けんにも ある なまえ(りんご・ふじさん・さかもとりょうま など)は もんだいに しません。

- 🍎 めいさん / 📍 名所 / 🏙️ まち / 🏮 まつり / 🚃 てつどう / 👤 ひと / ⛰️ やま・かわ / 🗣️ ほうげん / 🐦 けんの とり → どの けん?
- 🏛️ 県庁所在地 / 🤝 となりの けん / 🗾 ちずの あかい ところ(ミニ地図つき) / 🏆 日本一 / 🌏 せかいいさん
- 🔤 この ちめい なんて よむ? / 🗺️ ちずきごう / 🚄 しんかんせん / 🥇 日本三大の のこり ひとつ

## ぼうけん ちず

右上の 🗺️ で 日本地図が ひらきます。けんを タップすると ただたかが その けんの はなしを します。
きいた けんは 色が こくなり、`0/47` の カウントが ふえていきます(localStorage に ほぞん)。

## こえと おと

- 🗣️ こえ: ブラウザの 読み上げ(SpeechSynthesis)。ふりがなの ある ことばは よみがなで よみます。
- 🎵 おと: 正解・まちがい などの こうかおん(WebAudio の 合成音)。
- どちらも ボタンで オン/オフ でき、せっていは ほぞんされます。
