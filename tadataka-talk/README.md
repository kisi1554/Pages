# ちりはかせ ただたか 🗾

日本地理に とても くわしい、ものしりキャラクター **「ただたか」** と おしゃべりする アプリです。
47都道府県の **ゆうめいな ばしょ・めいさん・ちり(地形・気候)・まめちしき** を おしえてくれます。

`index.html` をブラウザで開くだけで遊べます(ビルド・サーバー・外部ライブラリなし)。

## ただたか って だれ?

- かさを かぶり、まるメガネに しろい おひげ、ちずの まきものを もった おじいさん。
- 「わしは ちりはかせの ただたか じゃ」── 一人称は「わし」、ごびは「〜じゃ」「〜のう」。
- なまえは、むかし 日本じゅうを あるいて ちずを つくった **伊能忠敬(いのう ただたか)** から もらった という せってい。
- 表情は 4しゅるい(ふつう・にっこり・かんがえちゅう・びっくり)。しゃべっている あいだは 口が うごきます。

## はなしかた

下の 入力らんに 文字で うつか、🎤 を おして こえで はなします(こえ入力は 対応ブラウザのみ)。
まん中の ボタンを タップするだけでも 会話が すすみます。
**「もっと」** と いうと、さっきの はなしの つづき(まだ いっていない もの)を はなします。

| きくこと | ただたかの こたえ |
| --- | --- |
| 「ほっかいどう」「ながの」「よこはま」 | その けんの しょうかい |
| 「ならの ゆうめいな ところ」「みえの めいさん」 | 名所・名産(5こずつ。「もっと」で つづき) |

| 「あおもりの ほうげん」「ながのの れきし」「とちぎの ゆかりの ひと」 | 方言 / 歴史 / 人物 |

| 「たかい やま ランキング」「ひとが おおい けん ランキング」 | ランキング(山・川・湖・島・広さ・人口) |
| 「せかいいさん」「ちずきごう」「しんかんせん」「日本三景」 | にっぽん ぜんたいの ちしき |
| 「かいりゅう」「さんみゃく」「へいや」「ちずの みかた」 | ちりの きほん |
| 「クイズ」 | 3択クイズ(下を 参照) |
| 「おすすめの けん」 | まだ きいていない けんを しょうかい |
| 「ただたかって だれ?」「もういちど」 | じこしょうかい / さっきの こたえを くりかえす |

けんの なまえは かんじ・ひらがな・カタカナ どれでも わかります。
「とうきょうと」の なかの「きょうと」の ような かさなりや、「なら(〜なら)」「さが(さがす)」の ような
みじかい ことばの まちがいにも 気をつけて よみとります。

45びょう だまっていると、ただたかの ほうから まめちしきを はなしかけてきます。

## クイズ(3択・20しゅるい)

ボタンで こたえても、こえ・もじで いっても OK。「ヒント」で 地方(または さいしょの もじ)を おしえてくれます。
こたえが ふたつに ならないよう、ほかの けんにも ある なまえ(りんご・ふじさん・さかもとりょうま など)は もんだいに しません。

## ぼうけん ちず

右上の 🗺️ で 日本地図が ひらきます。けんを タップすると ただたかが その けんの はなしを します。
きいた けんは 色が こくなり、`0/47` の カウントが ふえていきます(localStorage に ほぞん)。

## こえと おと

- 🗣️ こえ: ブラウザの 読み上げ(SpeechSynthesis)。ふりがなの ある ことばは よみがなで よみます。
- 🎵 おと: 正解・まちがい などの こうかおん(WebAudio の 合成音)。
- どちらも ボタンで オン/オフ でき、せっていは ほぞんされます。
