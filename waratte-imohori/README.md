# わらって いもほり 🍠

**もんだいに こたえて、へんてこな いもを ほりだす いもほりゲーム。**
せいかい すると つるを ひっぱれて、おならを する いも・パンツを はいた いも・
アフロの いも … などの **わらえる ごほうび** が でてきます。

`index.html` をブラウザで開くだけで あそべます（外部ライブラリなし）。

## あそびかた

1. タイトルで もんだいの しゅるいを えらぶ
2. はたけの つる（6ぽん）を タッチ → もんだいが でる
3. せいかい → いもむしの **にょこすけ** が つるを くわえて ひっぱる。「ひっぱる！」ボタンを れんだ（スペースキーでも OK）
4. すっぽーん！ と いもが でてくる。なにが でるかは おたのしみ
5. 6ぽん ぜんぶ ほったら しゅうかく けっか。つぎの はたけへ

まちがえても ペナルティは なし。ミミズが「ちがうよ〜」と でてきて、もういちど えらべます
（かんじは 1かい まちがえると えもじの ヒントが でます）。

## もんだいの しゅるい

| モード | ないよう |
| --- | --- |
| たしざん | 10までの たしざん。🍠の かずで かぞえられる |
| たしざん・ひきざん | 20までの けいさん |
| かけざん | くく |
| 1ねんせいの かんじ | かんじ → よみかた（45じ） |
| 2ねんせいの かんじ | よみかた と、よみ → かんじ（45ご） |
| なぞなぞ | 「いもは いもでも たべられない いもは？」など |
| ぜんぶ まぜる | ぜんぶの なかから ランダム |

## ごほうび（いもずかん 19しゅるい）

ふつうの いも／べろべろ いも／おなら いも／パンツ いも／おしり いも／ひげの おうさま いも／
アフロ いも／ねぼすけ いも／くしゃみ いも／おどる いも／ジャンボ いも（しりもち）／
ちっちゃいも（たくさん ひっぱったのに ちいさい）／いもいも れんけつ（8こ）／
サングラス もぐら／いもむし／いもうと／おばけ いも／ロケット いも／**きんの いも**（レア）

- まだ みつけていない いもが でやすく なっています。
- 3かい れんぞくで 1かいめに せいかい すると、きんの いもが でやすく なります。

## しくみ

- `index.html` / `style.css` / `game.js` の 3ファイル。いもの え は すべて SVG を JS で くみたて。
- にょこすけ は「にょこにょこ えきめぐり」の いもむしと おなじ いろ・かおで SVG に かきなおしたもの（`nyoko()`）。ほりだした あとも よこで リアクションする。
- 音は WebAudio の 合成音のみ（おならの おとも 合成）。右上の 🔊 で オン/オフ。
- ずかん・ほった かず・えらんだ モードは localStorage（`waratte-imohori.v1`）に ほぞん。
