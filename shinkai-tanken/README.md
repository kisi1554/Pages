# しんかい たんけん 🐙

年長〜小学生むけ。潜水艇「たんけんごう」で 港 から 海溝 の そこ（やく 1万900m）まで もぐり、
深海 の いきもの を しゃしん に とって ずかん を つくる。

公開URL: https://kisi1554.github.io/Pages/shinkai-tanken/

## あそびかた

- ▲▼◀▶ ボタン（または がめん を ドラッグ／キーボード の やじるし・WASD）で うごく。ながく おすと はやく なる。
  みぎ へ いくほど うみ が ふかく なる（大陸棚 → さか → 深海平原 → 海溝）。
- 💡 ライト（L キー）: まわり を てらす。でんち が へる。ふかい ところ では ライト で てらさないと しゃしん が とれない。
- 📡 ソナー（P／スペース）: ピコーン で ちかく の いきもの を しらせ、ねっすい の ほうこう を やじるし で おしえる。
- いきもの を タップ → 📷 カシャ → ずかん に のる（はじめて の いきもの は カード が でる）。
- でんち・酸素 が 25% を きると「そろそろ もどろう」。0 に なると おもり を すてて じどう で うかぶ（しっぱい に しない）。
  うみ の 上 に でると 満タン に なり、「おかえりなさい」で こんかい の きろく を 見せる。

### 画面

- うえ: いま の ふかさ（m）、ゾーン、水温（やく）、水圧（ゆび の つめ 1cm² に かかる おもさ と たとえ）、でんち・酸素。
- みぎ: ふかさ メーター（0〜11000m）。ゾーン の いろ わけ、スカイツリー 634m・ふじさん 3776m・エベレスト 8849m を
  さかさま に した 高さ、しんかい6500 の 6500m、いま の ふかさ、さいしん きろく（てんせん）。
- ふかく なる と 色 が あか → みどり → あお の じゅん に きえて、まっくら に なる
  （ふかさ ごと の いろ を かけあわせる マスク と、ライト の まるい あかり で えがく）。マリンスノー が ふる。
- ふかさ の かわりめ（15m・80m・200m・634m・1000m・3776m・6000m・6500m・8849m・1万800m）で ひとこと。

### ゾーン と ミッション

| ゾーン | ふかさ |
| --- | --- |
| 表層 | 0〜200m |
| トワイライトゾーン | 200〜1000m |
| 深海 | 1000〜6000m |
| 超深海 | 6000m〜 |
| 海溝 の そこ | やく 1万m〜1万900m |

ミッション: チョウチンアンコウ を 3びき しゃしん に／6500m まで もぐる／マリンスノー を 見る（300m より ふかく で ライト）／
熱水 の でる ところ を 見つける（1200m・2600m の 2か所）／海溝 の そこ へ／ずかん 10しゅるい／ひかる いきもの 5しゅるい／ずかん コンプリート。

- 音（ソナー の ピコーン、あわ、しゃしん の カシャ、ふかく なる ほど ひくく しずか に なる 環境音）は WebAudio 合成。🔊 で オン/オフ。
- ずかん・最深記録・ミッション・音 の せってい は localStorage（`shinkai-tanken-v1`）。

マップ は「せかい の うみ を ぎゅっと あつめた たんけん マップ」。よこ の きょり は ゲーム よう に ちぢめて あり、
するがわん（ヨコヅナイワシ）・おきなわトラフ（ゴエモンコシオリエビ）・インドよう（スケーリーフット）・

（ほんもの の しんかい6500 は 6500m まで、と ゲーム の なか で せつめい）。
