# はこね スイッチバック のぼり ⛰️🚃

箱根登山鉄道（はこね とざん てつどう）が 急な 山を ジグザグに のぼる「スイッチバック」を、
自分で ポイントを きりかえて 体験する 5さいむけ アクションゲーム。

`index.html` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。絵は canvas、音は WebAudio の合成音）。

公開URL: https://kisi1554.github.io/Pages/hakone-switchback/

## あそびかた（1かい 1〜1ぷんはん）

1. きせつ（💠あじさい／🍁こうよう／⛄ゆき）と はやさ（🐢ゆっくり／🐇ふつう）を えらんで しゅっぱつ
2. でんしゃは 自動で 坂を のぼる。行き止まりの 手前で ポイントが 光り、「ここで とまる」の きいろい ところが でる
3. でんしゃの さきが きいろい ところに きたら 🔀 ポイント ボタン（または 画面の どこか）を タップ
   → とまって ポイントが きりかわり、運転士さんと 車掌さんが いれかわって、向きを かえて つぎの 坂へ
4. スイッチバック 3かいで 強羅へ。ついたら カメラが ひいて、ジグザグの 線路と 下の 町を 見おろす

- おそすぎ（タップしない）→ 行き止まりで「おっとっと！」と ぽよんと 止まり、少し もどって やりなおし
- はやすぎ → 🐇ふつう では おっとっと。🐢ゆっくり では「もうすこし まって」と 教えるだけ（失敗に しない）
- ゲームオーバーなし・時間切れなし。タイムは 記録だけ（はやさ ごとの ベストを 保存）
- 操作は タップ 1つだけ（キーボードなら スペース／Enter）

## わらいどころ

- 向きを かえる たびに 運転士さんが 前から うしろへ 走って いどう。1かいめ「よいしょ！」→ 2かいめ「ふう… ふう…」→ 3かいめ「へと へと〜」（あせが ふえ、走るのも おそく なる）
- 坂を のぼると おきゃくさんが ななめに かたむく。おっとっとでは まえに つんのめる
- あじさいモードでは、あじさいに はなを くすぐられて「は… は… はっくしょん！」（花びらが とぶ）
- 「散水」の ふだの ところでは しゃりんから みずを まいて はしる

- 塔ノ沢〜出山信号場の あいだの 鉄橋（早川を わたる）も 絵で だけ 入れている。

## しくみ

- 線路は 4本の「みち（run）」。スイッチバックで 向きを かえると、行き止まり がわから はかった 新しい みちに のりかえる（車両の 位置は そのまま）。
- タイミング ゾーンは「電車の しっぽが ポイントを こえた〜車止めの 手前」。ゆっくり 約2.9秒・ふつう 約1.5秒。
- 60fps を めざし requestAnimationFrame。木や 家は 画面外を かかない。devicePixelRatio は 2 まで。
- 保存キー: `hakone-switchback:v1`（音・はやさ・きせつ・カード・ベスト・クリア回数）。読み書きは try/catch。
