# ブルーライン たしざん

横浜市営地下鉄ブルーラインの駅ナンバリング **B01（湘南台）〜 B32（あざみ野）** を数直線に見立てて、
電車を指で動かしながら「3駅すすむ ＝ +3」を体で覚える、5歳向けのたし算アプリです。

- 単一ファイル（`index.html`）。ビルド不要、ダブルクリックで開けば遊べます。
- 外部CDN・外部フォント・外部画像・通信は一切なし。**機内モードでも全機能が動きます。**
- 電車・駅・路線・きっぷはすべてインラインSVGとCSSで自作（実際の路線図画像や公式ロゴは使っていません）。
- ライブラリなしの Vanilla JS。相対パスのみなので GitHub Pages のサブディレクトリでもそのまま動きます。

## あそびかた

1. タイトルで **レベルを1つえらぶ**（ロックなし。いつでもどのレベルでも遊べます）。
2. 上に「**たてば から 3えき すすもう**」とお題が出ます。起点の駅ナンバー（B03）が大きく表示されます。
3. 電車を進めます。**やりかたは2つ**、どちらでもOK。
   - **▶ すすむ** ボタンを押す（1回で1駅）／間違えたら **◀ もどる** で戻せます（起点より手前へは戻れません）。
   - **路線を指で左右にドラッグ**する（指を離すと必ずいちばん近い駅で止まります）。
4. 1駅すすむごとに、進んだ区間がオレンジ色になり **①②③…** の数字が線の上に増えていきます。
   「すすんだ かず」は画面につねに出ています。
5. ここだと思ったら **「ここで おりる」** を押す。押した時点の駅で正誤を判定します。
6. **正解**：到着駅の駅名標が大きく出て、`3 + 3 = 6` の式が1つずつ組み上がります（効果音・紙吹雪・読み上げ）。
7. **まちがい**：叱りません。「もういちど かぞえてみよう」と出て、電車が起点にもどり、
   **正しい道のりを1駅ずつゆっくり自動でなぞって数えて見せます**。そのあと同じ問題をもう一度出します。
8. **1レベル10問**でクリア。クリアすると「**◯◯ゆき きねんきっぷ**」が1枚もらえて、きっぷ帳にたまります。

### そのほかの操作

| したいこと | やりかた |
| --- | --- |
| 駅のことを知る | 路線の**駅の丸をタップ**（または画面中央の駅名標をタップ）。せつめいが出て、読み上げます |
| 音を消す／出す | タイトル画面の「おと ON / OFF」。設定は保存されます |
| 集めたきっぷを見る | タイトル画面の「きっぷ帳」 |
| 途中でやめる | プレイ画面の左上「✕」 |

## レベル設計

| レベル | たす数 | ねらい |
| --- | --- | --- |
| レベル1 | +1 〜 +3 | 1〜3駅。指で数えられる範囲で「進む＝たす」を体験する |
| レベル2 | +4 〜 +6 | 片手で数えきれる範囲。数えるスピードを上げる |
| レベル3 | +7 〜 +9 | 1桁の上限まで。数えなくても答えが出はじめる |

- **1レベル＝10問。** レベルは手動選択で、ロックや解放条件はありません。
- 進む向きは**番号がふえる方向（あざみ野ゆき）に固定**。引き算は今回は作っていません。
- 起点駅は **B01 〜 B(32 − たす数)** からランダム。**到着駅が B32 を超える問題は絶対に出ません。**
- 同じ組み合わせ（起点駅・たす数）が**連続しては出ません**。
- 記録は「クリア回数」と「10問中いっぱつ正解できた最高数」をレベルごとに保存します。

### 出題ロジックの場所（将来の拡張用）

出題は `index.html` 内の **`LEVELS` 配列と `QuestionMaker` オブジェクトだけ**にまとまっています。
引き算・繰り上がり・2桁などを足したくなったら、ここに条件を追加すれば画面側は触らずに済みます。

```js
var LEVELS=[ {id:1,label:'レベル1',min:1,max:3,...}, ... ];
var QuestionMaker={ make:function(levelId,prev){ ... } };   // ←ここだけ差し替えれば出題を変えられる
```

> **式の見え方について。** 起点は仕様どおり B01〜B(32−たす数) から選ぶので、
> `20 + 3 = 23` のように十の位のある式も出ます（子どもがやることは「駅を数える」だけで変わりません）。
> 式を1桁どうしに限定したい場合は、`QuestionMaker.make` の `start` の範囲を
> `randInt(1, Math.min(LAST-add, 9-add))` に変えるだけで切り替えられます。

## 設計の判断メモ

### 動かすのは「電車」。ただしカメラが電車を追いかける

**電車を動かす方式に統一**しました。ボタンでもドラッグでも、動かしている対象は電車です。
ただしカメラ（表示位置）が電車をつねに画面の中央に置いて追いかけるため、
見た目には**路線のほうが流れていきます**。

この方式にした理由:

- 32駅は幅375pxには入りきらないので、**現在駅を必ず画面中央**に置く必要がある。
  電車が画面内を自由に移動する方式だと、現在地が端に寄って見えなくなる。
- 中央固定なら、電車のすぐ下の「いまいる駅」と、大きな駅名標がいつも同じ位置にある。
  5歳が目線を動かさずに「いまどこ？」を確認できる。
- 実際に電車に乗って窓の外を見ている感覚に近く、進んだぶんだけ景色（駅）が後ろに流れる。

内部的には「電車の位置＝小数の駅インデックス」ひとつだけを持ち、
ボタン操作もドラッグ操作も**同じ1つの値**を書き換えます。2種類の座標系を持たないので、
どちらの操作でも必ず駅にスナップします。

### 連打しても数がズレない理由

タップした瞬間に**論理的な現在駅を先に確定**し、見た目のアニメーションは
CSS transition が追いかける形にしています。移動中に次のタップが来ても、
transition の行き先が更新されるだけなので、カウントと位置がズレることはありません。

### 文字とふりがな

- 路線帯の駅名は幅が狭いため**かな表記**にしています（ふりがなが小さくなりすぎるのを避けるため）。
- 漢字の駅名は、**画面中央の大きな駅名標・到着演出・駅のせつめい**で
  `<ruby>` を使って必ずふりがな付きで出します。
- B29 センター南・B30 センター北・B32 あざみ野は、もともとかな主体の表記のためふりがなを付けていません。
- 駅のせつめい文は読み上げ前提のため、むずかしい語だけにふりがなを付けています。

### 音・読み上げ

- 効果音はすべて **Web Audio API で合成**（音声ファイルなし）。走行音・正解ジングル・クリアファンファーレ。
  不正解のときは不快な音を鳴らさず、やさしい下降音だけにしています。
- iOS 対策として、**最初のタップで AudioContext を生成・resume** します。
- 駅名などの読み上げは Web Speech API（任意機能）。非対応の端末でも他の機能はそのまま動きます。
- `prefers-reduced-motion: reduce` の端末では、紙吹雪と揺れアニメーションを止め、
  自動でなぞるデモも速めに切り替えます。

### タッチまわり

- Pointer Events を使い、タッチでもマウスでも同じコードで動きます。
- 路線ビューは `touch-action: none`、全体は `touch-action: manipulation`（ダブルタップ拡大の抑止）。
  `user-select: none` と `-webkit-touch-callout: none` も設定済みで、ドラッグ中にページは動きません。
- タップ対象はすべて 56×56px 以上。取り返しのつかない操作（きっぷを全部消す）は
  きっぷ帳の最下部に置き、確認ダイアログを挟んでいます。

## 保存されるもの（localStorage のみ）

個人情報は保存しません。キーはすべて `blueline-tashizan.` プレフィックス付きです。

| キー | 中身 |
| --- | --- |
| `blueline-tashizan.sound` | 音の ON / OFF |
| `blueline-tashizan.stats` | レベルごとの「プレイ回数・クリア回数・いっぱつ正解の最高数」 |
| `blueline-tashizan.tickets` | 集めたきねんきっぷ（行き先の駅番号・レベル・日付） |

プライベートブラウズなどで保存できない環境でも、保存されないだけでそのまま遊べます。

## 動作環境

- iOS Safari / Android Chrome の最新版。**幅 360〜430px の縦持ち**を最優先で設計しています。
- それより広い画面では最大460pxで中央寄せになります（320×568 のような小さい画面にも縮小段階あり）。
- 1問が縦スクロールなしで完結するように、画面の高さに応じて路線ビューと文字サイズが切り替わります。

## 駅データの出典

駅名・読み・駅ナンバリング（B01〜B32）は **路線図ネット** の
横浜市営地下鉄ブルーライン路線図を参照し、依頼時にいただいた一覧表をそのまま使用しています。
（読みまちがえやすい B04 中田「なかだ」／B12 弘明寺「ぐみょうじ」／B27 新羽「にっぱ」を含め、全32駅を表と一致させています。）

駅のせつめい文は、乗り換え路線や周辺の施設など一般に知られている情報をもとに、
5歳向けにやさしく書き起こしたものです。路線図画像・公式ロゴ・写真などは一切転載していません。
