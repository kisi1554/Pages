# うく？しずむ？ 🫧

ものを みずに いれる まえに「うく？ しずむ？」を よそうして、みずそうで たしかめる 理科あそび（年長〜小学校中学年むけ）。
`index.html` を ひらくだけで うごきます（外部ライブラリなし）。

| タブ | あそびかた |
| --- | --- |
| 🔍 よそう | たなから ものを えらぶ → 「うく／しずむ」を よそう → ぽちゃん（しぶき・あわ）。あたりは ○、はずれは「おもしろい！」と ほめて ひとこと せつめい |
| 🧂 しおみず | しおを おおさじ 1ぱい（15g）ずつ みず 500mL に とかすと、たまごが だんだん おきあがり、5はいめで うく。なんばいめか よそうできる |
| 🚤 ねんどふね | ねんど 50g を ゆびで こすって（または 👆）うすく ひろげ、ふねに して うかべる。ビーだま（5g）を なんこ のせられるか |
| 📒 ノート | よそうと けっかの ひょう、しおみず・ねんどふねの きろく |

## もの（39こ）

- うく 18: きの つみき、コルク、ピンポンだま、こおり、りんご、みかん（かわつき）、ペットボトル（から・ふたつき）、はっぽうスチロール、ろうそく、ゴムの アヒル、はっぱ、わりばし、バナナ（かわつき）、スイカ、ふうせん、ココナッツ、レモン、えんぴつ
- しずむ 17: てつの くぎ、10えんだま、5えんだま、ビーだま、いし、ガラスの コップ（みずが はいる）、じゃがいも、たまご（まみず）、みかん（かわを むいた）、スプーン（ステンレス）、はさみ、かぎ、てつの ボルト、かいがら、けしゴム（プラスチック）、レンガ、ぶどう（ひとつぶ）
- かたちで かわる 4: ねんど（かたまり → しずむ／ふねの かたち → うく）、アルミホイル（ぎゅっと まるめる → しずむ／ふねの かたち → うく）
- 条件で けっかが かわる もの（にんじん、プラスチックの しゅるい、クリップ、1えんだま など）は のせていない。のせた ものは 条件を なまえに かいた

## けいさん モデル（かんたん）

- しおみず: こさ c = しお ÷（しお＋みず 500g）、みつど ≒ 1 + 0.0072 × c[%]、たまご 1.08 g/cm³ → 5はい（13%・1.094）で うく
- ねんどふね: ねんど 50g（みつど 1.8 → 約 28cm³）を あつさ t の はこ（そこ L×L、かべ h = L/3）に する。
  おしのけられる みず L²h[g] が ねんど＋ビーだまより おおきければ うく。うすさ 7だん目から うき、いちばん うすいと 21こ のる

## そのほか

- 音は WebAudio の合成音（ぽちゃん・ぶくぶく・○）。右上 🔊 で オン/オフ
- ノート・きろく・音の設定・さいごの タブは localStorage（`uku-shizumu-v1`、読み書きは try/catch）
- たて持ちスマホでは しおみず・ねんどふね の みずそうが うえに のこる（ボタンを おしながら 見られる）
