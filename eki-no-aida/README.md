# えきと えきの あいだの えき（ブルーライン）

よこはま市営地下鉄ブルーライン（B01 湘南台 〜 B32 あざみ野／全32駅）を題材に、
**2つの駅のあいだに かくれている駅名を当てる**ゲームです。
`index.html` ひとつで動きます（外部ライブラリ・CDN なし）。

あそびかた: `index.html` をブラウザで開くだけ。

## 3つの あそびかた（モード）

### 1. こすって みつける 🫧
答えの駅名標が **くもりガラス** でおおわれています。
指でこすると、こすったぶんだけ うっすら見えてきます。

- ヒントゲージは こするほど へる → **こすらずに当てるほど 高得点**（最高10点／最低2点）
- こすれるのは 全体の 34% まで。それ以上は「ヒントは ここまで！」
- こするほど濃くなる方式なので、1回なでただけでは 形がぼんやり見えるだけ

「ヒントを出すかどうか」を子ども自身が 指で決められるのが ねらいです。

### 2. とうちゃくまでに 🚇
電車が 駅と駅のあいだを 走るアニメーションが 時間制限そのものになっています（約13秒）。

- 正解 → 電車が ホームに停車し、**ドアが プシューと開く**
- 不正解・時間切れ → 「つうか〜！」で 通りすぎてしまう
- 早く答えるほど 高得点（最高10点／最低3点）

「あと何秒」ではなく「あと何メートルで着く」で 急ぐ気持ちを伝えます。

### 3. きゅうこう ちょうせん 🚄
2駅とばし・3駅とばし（後半は3駅）で、**あいだの駅を 順番に ぜんぶ**当てます。
1つめを当てると 路線ストリップに ✓ がともり、2つめの問題に進みます。
選択肢には ほかの空欄の答えも混ざるので、**順番**まで分かっていないと解けません。

## みんなのしくみ

- **みつけた えき（コレクション）**: 正解した駅が 路線図に ともります。32駅ぜんぶの点灯が目標。
- **にがて駅を 多めに出題**: まちがえた駅・まだ出ていない駅に 重みをつけて出題します（localStorage に記録）。
- **上りと下りの 両方向**で出題（あざみ野ゆき／湘南台ゆき）。
- 音は WebAudio の合成音のみ。右上で オン/オフ（保存されます）。
- 縦持ちスマホ・横持ちタブレット の 両方に対応。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | アプリ本体（駅データ・CSS・JS すべて） |

駅データは `STATIONS` 配列（`n` / `name` / `yomi` / `ruby`）にまとまっています。
ほかの路線を足したいときは、この配列を差し替えるだけで動きます。
