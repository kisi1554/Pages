# ゆうびん はいたつ 📮

ゆうびんやさんに なって、てがみの **じゅうしょ を よみ**、まちの ちずで いえを さがして とどける（年長〜小学3年）。
かばんの てがみを **どの じゅんばんで くばるか** くふうして、はやく まわる。
じゅうしょの くみたて（まち → ちょうめ → ばん → ごう）と ちずの しくみが しぜんに わかる。

`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。ちずは SVG を コードで かく。おとは WebAudio の 合成音で、ヘッダーの 🔊 で オン/オフ）。

## まち（オリジナル。実在の 地名は つかわない）

| まち | ブロック | いえ | とおれない みち | ゆうびんばんごう |
| --- | --- | --- | --- | --- |
| 🌸 さくらまち | 4×4 | 63けん | なし | 〒512-010□ |
| ⚓ みなとまち | 6×4 | 95けん | 🚧 こうじちゅう 5か所 | 〒513-010□ |
| 🌲 もりまち | 6×6 | 143けん | 🌳 もりの き 9か所 | 〒514-010□ |

- **ちょうめ**: まちを たて・よこ はんぶんに わけた 4つ（1 ひだりうえ・2 みぎうえ・3 ひだりした・4 みぎした）。ブロックと やねの いろで わかる。
- **ばん**: ブロック。ちょうめの なかで ひだりうえ から よむ じゅん。ブロックの まんなかに「3ばん」の かんばん。
- **ごう**: いえ。ほんものの まちと おなじく ひだりうえ から とけいまわり（1・2・3・4）。いえには ひょうさつ（なまえ）と ごう。
- いえの あかい しかくが ポスト（ドア）。その まえの みちで とまると とどけられる。
- まちは いつも おなじ（シード こてい）なので、あそぶ ほど ちずを おぼえられる。
- ゆうびんばんごう（□ ＝ ちょうめ）: まえの 3けた ＝ まち、うしろの 4けた ＝ ちょうめ。

## あそびかた

### まいにち はいたつ
1日（ステージ）ごとに てがみが ふえ（3→8つう）、まちが ひろがる（1〜4にちめ さくら、5〜9 みなと、10〜15 もり、そのあとは まぜて）。

1. **しわけ**: かばんの てがみを「2ちょうめ」などの ポケットへ ドラッグ（または てがみ → ポケット の じゅんに タップ）。
   ちがう ポケットは はいらない。
2. **はいたつ**: ゆうびんきょく から しゅっぱつ。バイク（🛵）から みちを **なぞる** と その とおりに すすむ。
   みちや いえを **タップ** すると そこまで じどうで はしる。いえの まえで とまると ひょうさつと ポストが でる。
   てがみを ポストへ ドラッグ（または タップ → ポスト）。ちがう いえ なら「となりの いえ みたい！」「ばんが ちがうよ」などの ヒント。
   - 🎴 はがき・✉️ ふうとう: ポストへ ことん
   - 📦 こづつみ（2にちめ〜）: ポストに はいらない → 🔔 チャイムを おして「はーい！」→ てわたし
   - そくたつ（3にちめ〜、あかい わく）: ふつうの てがみ より さきに くばると ⚡ボーナス
   - 💡 で あてさきの いえが ひかる。＋／－ と ピンチで ちずを おおきく（ブラウザの ズームは しない）
3. **おわり**: ぜんぶ くばって ゆうびんきょく に もどったら おわり。じかん・はしった マス と **さいたん ルート** を くらべる。
   ちずに きみの みち（あお）と さいたん ルート（あかの てんせん）を かさね、ゴースト バイクが さいたん ルートを はしる。
   ⭐ は きょりで きまる（さいたん ＝ 3つ、1.25ばい まで ＝ 2つ）。まけても つぎの ひへ すすめる。

### じゅうしょ クイズ
まちを えらんで 10もん。「2ちょうめ 3ばん 1ごう は どこ？」→ ちずの いえを タップ ／ ひかって いる いえ の じゅうしょを 3つから えらぶ。

### てがみを かこう
だれに（おじいちゃん・おばあちゃん・ともだち…）→ ちずで いえを えらぶ → ふうとうに **ゆうびんばんごう 7けた（3けた-4けた）** を かく
（ひょうを みて。まちがえると「まえの 3けた が ちがうよ」）→ ひらがなで みじかい てがみ（60もじ まで）→ ポストに いれて、じぶんで バイクで とどける。
かいた てがみは さいだい 20つう のこる。
