# でんしゃで おふろやさん

電車の駅から行ける 銭湯・スーパー銭湯を、路線図から えらんで しらべる 子どもむけページです。

- 🔵 ブルーライン（湘南台〜あざみ野）
- 🩵 京浜東北線・根岸線（大宮〜大船）
- ❤️ 東急東横線（渋谷〜横浜）
- 💙 相鉄線（本線 横浜〜海老名・いずみ野線・新横浜線）
- ❤️ 京急線（本線・空港線・大師線・逗子線・久里浜線）
- 🩷 都営浅草線（西馬込〜押上）

## あそびかた

`index.html` をブラウザで開くだけ（外部ライブラリなし）。

1. 上の路線ボタンで ろせんを えらび、路線図の ♨️ の駅をおすと、その駅の おふろやさんが出ます
   （スマホは全画面、タブレット・PCは右がわに表示）。
2. カードには「いま あいてるよ／きょうは おやすみ」、駅からの いきかた、あいてる じかん、
   おやすみの日、こどもの ねだん、おふろの しゅるいが出ます。
3. 行ったら「♨️ いったよ」で スタンプ（上の「行った おふろ」にたまる）。
4. 「🏠 せんとう」「🏯 スーパーせんとう」で しゅるいを、「こども OK」「今日 やってる」「あかちゃんも」で じょうけんを しぼりこめます（くみあわせOK）。
   路線ボタン・路線図の上・駅ボタンの「○けん」は、しぼりこんだ あとの けんすうになります。
5. 大人だけの施設（スカイスパYOKOHAMA、SPA EAS）は「こどもは はいれないよ」と表示し、スタンプの対象外です。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面とスタイル |
| `data.js` | `LINES`（路線と駅）、`BATHS`（おふろやさん）、`FEATURES`（おふろの しゅるい） |
| `app.js` | 表示・「きょう やってる？」判定・スタンプ・音 |

### おふろやさんを足すとき

`BATHS` に1件足すだけ。`at` に `{ 駅名: 'いきかた' }` を書くと、その駅（どの路線でも）に出ます。
同じ駅名でも路線で歩く時間が違うときは `'keikyu:弘明寺'` のように `路線ID:駅名` で書くと、その路線だけ上書きされます。
定休日は `rest` に `dow`（曜日）／`date`（日付）／`nth`（第n○曜、`months` で月指定）／`until`（臨時休業の最終日）。
24時以降の閉店は `H(25)` のように書きます。祝日・不定休は判定しません（`restText` に書く）。

- 音は WebAudio の合成音のみ。右上 🔊/🔇 で オン/オフ。
- 「いったよ」・音・えらんだ路線は localStorage（`ofuro-yasan:v1`）に保存。
