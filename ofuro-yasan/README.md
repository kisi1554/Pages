# ブルーライン おふろやさん

横浜市営地下鉄ブルーラインの駅から行ける、子どもも入れる銭湯・スーパー銭湯（12けん）を、
路線図から えらんで しらべる 子どもむけページです。

## あそびかた

`index.html` をブラウザで開くだけ（外部ライブラリなし）。

1. 路線図の ♨️ の駅をおすと、その駅の おふろやさんが出てきます
   （スマホは全画面、タブレット・PCは右がわに表示）。
2. カードには「いま あいてるよ／きょうは おやすみ」、あるいて なんぷん、
   あいてる じかん、おやすみの日、こどもの ねだん、おふろの しゅるいが出ます。
3. 行ったら「♨️ いったよ」をおすと スタンプがたまります（上の「行った おふろ」）。
4. 「今日 やってる」「あかちゃんも」で しぼりこめます。
5. 「🔍 おうちの ひとと しらべる」で Google 検索を開きます。

## しくみ

- データは `index.html` の `BATHS` 配列。`rest` に定休日（`dow` 曜日 / `date` 日付 / `firstWed` 第1水曜）を書くと
  「きょう やってる？」を自動で判定します。祝日・臨時休業・不定休は反映しません。
- 音は WebAudio の合成音のみ。右上 🔊/🔇 で オン/オフ。
- 「いったよ」と音の設定は localStorage（`ofuro-yasan:v1`）に保存。
