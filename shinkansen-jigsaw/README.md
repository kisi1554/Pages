# ぜんこく しんかんせん ジグソー 🧩

日本じゅうの しんかんせんの 線が どこから どこへ のびているか、どの 線と どの 線が つながっているかを、
地図の パズルで おぼえる。5さい〜。

公開URL: https://kisi1554.github.io/Pages/shinkansen-jigsaw/

## あそびかた

1. 白い 日本地図の 下（横もちでは 右）に、しんかんせんの 線の ピースが ばらばらに ある。
2. ピースを ドラッグして 正しい 場所に はめる。近づくと すいつき、はしの 駅名（漢字＋ふりがな）が 光る。
3. ぜんぶ はまると、北の 新函館北斗〈しんはこだてほくと〉から 南の 鹿児島中央〈かごしまちゅうおう〉まで 電車が
   つぎつぎ 走る（えだわかれの 線は、本線の 電車が わかれる 駅に ついたら 走りだす）。
4. そのあと クイズ 2〜3もん（「えだわかれする 線は？」「つながっていない 線は？」など）。答えると 地図の 線が 光る。
5. おまけ「はやさ くらべ」: しんかんせんの 絵 3つから「いちばん はやいのは？」→ かけっこ → トンネルの おまけ。

| レベル | 線 |
| --- | --- |
| 1 | 東北・東海道・山陽（うすい せんの みほん つき） |
| 2 | ＋北海道・九州・上越 |
| 3 | ＋北陸・秋田・山形・西九州（10本ぜんぶ） |

- まちがえると ピースは もどる。同じ ピースを 2回 まちがえると うすい せんの ヒントが でる。💡 でも 出せる。
- ⭐ は まちがいの かず（0〜1 → 3こ、2〜3 → 2こ、それ以上 → 1こ）。
- わらい どころ（どれも 答えあわせの あと）: うみに おくと「およげません！」と ぷかぷか／東海道と 東北を
  まちがえると 東京駅で 2本が おでこを ごっつん／はやさ くらべの あと、はなの ながい しんかんせんが トンネルに
  はなを ぶつけそうに なって「セーフ！」。

## データ（いちばん 大事）

線・駅・つながり・さいこう そくどは `index.html` の `DATA`（1か所）に まとめて ある。2026-11 時点で 走って いる 所だけ
（開業・延伸の 予定は 入れない）。

- ピースの はしは JR 各社の 公式の 区間: 東北 東京〜新青森／北海道 新青森〜新函館北斗／秋田 盛岡〜秋田／
  山形 福島〜新庄／上越 大宮〜新潟／北陸 高崎〜敦賀／東海道 東京〜新大阪／山陽 新大阪〜博多／
  九州 博多〜鹿児島中央／西九州 武雄温泉〜長崎。
- つながり（`links`）: 新青森・東京・新大阪・博多・盛岡・福島・大宮・高崎。西九州は どこにも つながって いない。
- 秋田・山形は 東北しんかんせんから わかれて、ふつうの せんろ（在来線）を はしる。
- さいこう そくど（その 線で いちばん はやい ところ）: 東北 320／山陽 300／東海道 285／上越 275／
  北陸・九州・西九州・北海道 260 km/h。秋田・山形は 在来線では 130 なので はやさ くらべに 入れない。
- 駅の よみ・座標は `shinkansen-juudan/` と おなじ（Wikidata で 照合）。秋田・山形・西九州の 駅を 足した。
- 鉄道会社の ロゴ・マーク・ヘッドマーク・発車メロディは 使わない。車両の 絵は 線の 色と はなの ながさだけ 似せた オリジナル。

## しくみ

- `index.html` … 画面・ゲーム・データ ぜんぶ。外部ライブラリなし。
- `map-data.js` … 都道府県の 地図（`shinkansen-juudan/` と 同じ。生成元 `tools/japan-map/generate_map.py`）。
- 地図・ピースの ドラッグ領域は `touch-action: none`。ピースは ゆびで かくれないよう ゆびの すこし 上に うかぶ。
- 音は WebAudio の 合成音と 端末の 読みあげ。右上の 🔊 で オン/オフ。
- ほぞん: localStorage `shinkansen-jigsaw-v1`（`stars` レベルごとの ⭐・`sound`・`speed` はやさ くらべ クリア回数）。
