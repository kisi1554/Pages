# 東急線すごろく DX 🚃

[`tokyu-sugoroku-game/`](../tokyu-sugoroku-game/)（東急線すごろく）を もとに つくりなおした すごろく。
しぶやから しんよこはま まで、**ろせんずの うえ**を すすみ、**わかれみち**を えらんで ⭐を あつめる。

`index.html` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。ちずは SVG、おとは WebAudio）。

公開URL: https://kisi1554.github.io/Pages/tokyu-sugoroku-dx/

## あそびかた

1. タイトルで だれが あそぶか えらぶ（タッチで 🙂ひと → 🤖ロボ → 💤おやすみ。1ばんめは いつも ひと）
2. 🎲 サイコロ（1〜3）を ふって すすむ。カードが あれば サイコロの かわりに つかえる
3. とまった マスで できごと:
   - ❓ クイズ（3たく）… せいかいで ⭐2
   - ⭐ … ⭐1〜3
   - 🎁 … カードを 1まい（3まい もっていたら ⭐1）
   - ⚡ … すすむ／もどる／1かい やすみ
   - しろい マス … えきの まめちしき
4. みんな ゴールしたら ⭐の おおい じゅんに じゅんい（おなじなら はやく ゴールした ほう）

進捗（スタンプ・あそんだ かいすう・さいこう⭐・おと・メンバー）は localStorage（`tokyu-sugoroku-dx:v1`）に ほぞん。

えきの ならびは じっさいの じゅんばん どおり。ちずの かたちは みやすさ ゆうせんの りゃくず。
いけがみせん・たまがわせん・せたがやせん・こどものくにせん は コースには なく、クイズに でてくる。

## つくり

- `ST`（えき）と `CHAINS`（ろせん）から グラフ（`NEXT`）と ざひょう（`POS`）を つくる。
  えきを たすときは `ST` に かいて `CHAINS` の `mid` に ならべるだけ。
- もどる できごとの ために こまごとに とおった みち（`path`）を おぼえている。
- ズーム対策は `tools/no-zoom.py` の 共通ブロック。
