# ちずきごう たからさがし 🗺️

ちずの きごう と ほうい を つかって、うまって いる たからを さがす。
小学校 低〜中学年むけ（小3 社会の 地図記号・八方位の よしゅう／ふくしゅう）。

公開URL: https://kisi1554.github.io/Pages/chizu-takara/

## あそびかた

| モード | なかみ |
| --- | --- |
| 🃏 きごう カード（★） | 10もん。「きごうを みて なまえを 4たく」と「なまえを みて きごうを 4たく」が こうごに でる。まちがえた ものは さいごに もういちど でる。こたえると「なぜ この かたち？」が でる。まぎらわしい こたえ（文 と ⊗文、⊗ と ×、はぐるま 2つ など）を わざと まぜる |
| 💎 たからさがし（★★） | 8×8〜10×10 マスの まちの ちず。ヒントが 1つずつ でる（「〒 から ひがし へ 3マス」「そこから ⛩ が みえる ほう（きた）へ 2マス」など）。ほういじしん つきの パッド（ほうい ＋ マスの かず）か、となりの マスを タップして うごく。ヒントの ばしょで「🚩 ここだ！」、さいごは「⛏️ ほる！」。ちがう マスだと「ここじゃ ないみたい」。2かい まちがえると てがかりの マスが ひかる |
| ✏️ ちず づくり（じゆう） | 10×10 マスに きごうを おいて（なぞっても おける）じぶんの まちを つくる。ちず 1〜3 の 3スロットに じどうで ほぞん。せんろは となりの せんろと つながって まがる・まじわる |

### スクロール なしで よめる くふう（スマホ）

- たからさがし: ヒントは いまの 1つ だけ おおきく だす。おわった ヒントは うえの ばんごう（✓）を タップで もういちど よめる。ちずは のこりの ばしょに あわせて ちぢむ（コンテナクエリ）。
- カード: こたえた あとは もんだい・せんたくしを ちいさく して「なぜ この かたち？」まで 1がめんに いれる。
- ずかん: きごうの タイル（5れつ）を タップすると うえに せつめいが でる。
- ステージ えらび は 3れつ、ちずづくり の きごうは 6れつ。

## しくみ

| --- | --- |

### ヒントの しゅるい（`stages.js` の `hints`）

| type | ぶん | いき先 |
| --- | --- | --- |
| `from` | 「{きごう} から {ほうい} へ n マス」 | その きごうから かぞえる（いまの ばしょに かんけい なし） |
| `goto` | 「{きごう} の マスへ いこう」 | その きごうの マス |
| `move` | 「そこから {ほうい} へ n マス」 | いまの ばしょから |
| `toward` | 「そこから {きごう} が みえる ほうへ n マス」／ `n:"until"` なら「〜の てまえで とまろう」 | いまの ばしょから きごうが まっすぐ（たて・よこ・ななめ）に ある ほうへ。テストで ほうい・とどかない ことを たしかめる |

ヒントで つかう きごうは、その ちずに 1こ だけ ある もの（たてもの・えき）に かぎる。
