# きりがみ もよう ✂️

**おりがみを おって、ゆびで なぞって きって、ひらくと もようが できる あそび。**
未就学〜小学生むけ。線対称・点対称を からだで かんじる。`index.html` を ひらくだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/kirigami-moyou/

## あそびかた

1. おりがみの いろ（8いろ）と おりかた を えらぶ。
   | おりかた | おった かたち | ひらくと |
   | --- | --- | --- |
   | 2つおり（たて） | はんぶん の ながしかく | 2まい（線対称） |
   | 4つおり | 1/4 の しかく | 4まい |
   | 8つおり | 1/8 の 三角 | 8まい |
   | ゆき（6つおり） | 6かくけい の 30° の くさび | 12まい（ゆきの けっしょう） |
2. おる アニメの あと、おった かたちが 大きく でる。てんてん の ふちが おりめ（わ）。
3. ゆびで なぞると チョキン。
   - **ぐるっと とじた せん** → その なかを きりとる
   - **ふち から ふち** → せん で わけた 2つ の うち **ちいさい ほう**（そとがわ）を きりとる。ふちの おなじ ところに もどれば くぼみ に なる
   - それ いがい → きりこみ（せん だけ）
   - ほそい せんでも きれる ように、なぞり せん は はば のある おび として きりとる
   - きった かけら は ひらひら おちる。↩ もどす は なんかい でも
4. 「ひらく！」で おった ぎゃくの じゅんに ぱっ ぱっ と ひろがって かんせい。
5. 💾 のこす で ギャラリーへ（20こ まで、ふるい じゅんに きえる）。「もっと きる」で また おって つづきから きれる。

## もんだい モード（12もん）

おてほんの ひらいた もようを みて、おなじに なるように きる。💡ヒント で、おった かみ の うえに きる せん が てんてん で でる。

まる・ハート・ひしがた・まど・ほし・ちょうちょ・よつば・はな・おひさま・くさり・ゆきの けっしょう・ゆきの はな

はんていは **ラスタ化した IoU**（きりとった ところ どうしの かさなり ÷ あわせた ひろさ）が **0.85 いじょう** で クリア。
いちばん よかった わりあいを localStorage に のこす。

## しくみ

| ファイル | ないよう |
| --- | --- |
| `geom.js` | かたちの けいさん（ブラウザ と node で きょうつう）。おりかた・きりとり・IoU・ひらいた がぞう の いろぬり |
| `puzzles.js` | もんだい 12もん。おてほん は「なぞる せん」で かいて、こどもと おなじ `makeCut` で きりとりに する |
| `app.js` | がめん・アニメ・ゆび・おと・ほぞん |
| `style.css` | みため（たて スマホ / よこ タブレット） |
| `tests/geom.test.js` | `node --test kirigami-moyou/tests/*.test.js` |
| `tests/e2e.js` | Playwright で 390×844 と 1024×768 を うごかして スクショ（`NODE_PATH=$(npm root -g) node kirigami-moyou/tests/e2e.js <でぐち>`） |

- **おる** = げんてん を とおる おりせん で、かたがわ を はんたいへ 鏡映 する ことを じゅんばんに くりかえす
  （2つおり `[90°]`、4つおり `[90°,180°]`、8つおり `[90°,180°,45°]`、ゆき `[180°,120°,60°,30°]`）。
  おりおわった かたち（ドメイン）は 6かくけい／しかく を はんめん で きりとって つくる。
- **きる** は ドメインの ざひょうで ためる（ポリゴン＋なぞり せん の おび）。ブーリアン演算は しない。
- **ひらく** = ひらいた かみ の 1てん を `foldPoint` で おって ドメインへ もどし、そこが きられて いるか を みる。
  がめんでは、おった かみ の Canvas マスク を 1かい つくり、ぜんぶ ひらいた／とちゅう まで ひらいた がぞう を
  その マスク から ひきうつす。おる・ひらく アニメ は その がぞう を おりせん で 2つ に クリップ して、
  かたがわ を おりせん の むきに つぶす（3D の かいてん を うえから みた かたち）。
- **ギャラリー** は `{おりかた, いろ, きりとり（ポリゴン列 と せん）}` を 小数3けた で ほぞん して、その つど かきなおす。
- **IoU** は ドメインで ラスタ化して くらべる。ひらいた もようは ドメインの コピー（2/4/8/12まい）なので、
  ひらいた かみ で くらべても おなじ あたい に なる（テストで たしかめている）。

テストで たしかめていること: 4つおり で 1か所 きると 4か所（2・8・12 も）あく、おりめ に かかる きりかたは
つながった 1つの あなに なる、ふち から ふち は ちいさい ほう を きる、ほぞん→よみこみ で おなじ、
12もん すべて おてほん どおり なら 100%・きらなければ 0%・すこし ずれても クリア・かみが ばらばら に ならない。
