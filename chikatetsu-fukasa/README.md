# ちかてつ ふかさ くらべ ⛏️

もぐらの **ほりほりくん** と いっしょに じめんを ほって、とちゅうで であう ちかてつの ホームが
「ビルの なんかい ぶん」ふかいかを あてる ゲーム（5さい〜）。
ちかてつは いろいろな ふかさを はしっていて、**あとから できた せんほど ふかい ことが おおい** と 知るのが ねらい。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. 「ほりはじめる」→ じめんを よこから きった だんめんず。うえには 15かいだての ビル・ひと・キリン。
2. えの なかを **したへ スワイプ**（または「⬇ ほる」ボタン）で ほりほり。
   とちゅうで すいどうかん・でんきの せんに ぶつかって「おじゃましました〜」、ふかい ところで おなかが ぺこぺこ（おにぎり）。
3. ホームに でたら「ビルの なんかい ぶん ふかい？」を 3たくで えらぶ。カメラが ひいて うえの ビルと くらべられる。
   まちがえると「もっと ふかい／そんなに ふかくない みたい」と ヒントが でて、なんども えらびなおせる。
4. せいかいすると ビルを さかさに した ものさしが 1かい ずつ のびて かぞえる。キリン なんとう ぶんと「なぜ？」カードも でる。
5. 6つめ（いちばん ふかい 六本木）の あとは、ながーい エスカレーターで ちじょうへ（とちゅうで ねて しまう）。
6. けっかでは ⭐（まちがい 0〜1:3こ／2〜3:2こ／それいじょう:1こ）と、できた とし じゅんの ふかさグラフ。

1かい 1〜3ぷん。ほぞん（あそんだ かいすう・さいこうの ⭐・おとの オン/オフ）は localStorage。

## しかけ

- だんめんずは `<canvas>`（`touch-action: none`、pointer イベントで したへの スワイプ だけを ほる りょうに する）。
- カメラは ほっている ときは もぐらに よって、クイズ中は ビルと ホームが いっしょに みえる ように ひく。
- `python3 tools/no-zoom.py chikatetsu-fukasa` で ズーム対策ブロックを いれている。
- `window.__cf` は Playwright の テスト よう。
