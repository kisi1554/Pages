# わくせい シューティング 🚀

ロケットで たいようけいを すすむ **よこスクロール** の シューティング。
すいせい から かいおうせい まで 8つの わくせいの ボスを たおすと、**わくせいカード** が もらえる。
`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・CDN なし）。

## そうさ

| そうさ | なにが おきる |
| --- | --- |
| ゲームがめんを ゆびで なぞる | ロケットが **ゆびの すこし うえ** に くる（ゆびで かくれない）。がめんの したの はしでは ずれが へる |
| たてもちの とき、したの パッドを なぞる | ゆびの うごいた ぶんだけ ロケットが うごく（ゲームがめんに ゆびを のせなくて いい） |
| たま | **じどうで れんしゃ** |
| 💥 ボム ボタン（X / スペース） | てきの たまを ぜんぶ けして ほしに かえる。**1ステージ 2かい** |
| ⏸ ボタン（Esc / P） | ひとやすみ。タブを はなれると じどうで ポーズ |
| キーボード | やじるし / WASD で うごく |

あたりは ロケットの まんなかの しろい てん だけ。

## むずかしさ

| | ハート | てきの たま |
| --- | --- | --- |
| **やさしい** | ❤️×6 | おそい・すくない、ボスの HP 75%、かぜ・うずも よわい |
| **ふつう** | ❤️×3 | ふつう |

ゲームオーバーでも **その ステージから つづけられる**（ステージを はじめた ときの ぶきで）。

| # | わくせい | しかけ | ボス |

| 2 | きんせい | あつい くもの ふきだし（よこく → ねっぷう） | もくもく くもキング（さんせいの あめ） |

## わくせいカード と ずかん

- カード: たいようから なんばんめ / ちきゅう なんこ ぶんの おおきさ（ならべた え つき）/ 1日（じてん）/ 1年（こうてん）/ えいせいの かず / ひとこと。漢字には ふりがな。
- ずかん: カードを ならべる。「おおきさ くらべ」で **たいようと わくせいを おなじ しゅくしゃく** で ならべる（わくせいだけ にも きりかえ）。
- **めいおうせい** は じゅんわくせい として ずかんの おまけ（かいおうせいを クリアで もらえる）。

## きろく

クリアした ステージ・カード・ハイスコア・むずかしさ・おとの オン/オフ を localStorage に ほぞん（キー: `wakusei-shooting.v1`。よめなくても あそべる）。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `index.html` / `style.css` | がめん（タイトル・カード・ずかん などの パネル） |
| `data.js` | わくせいの データ（カードの もじ）と ステージの せってい |
| `audio.js` | こうかおん と BGM（WebAudio の 合成音だけ） |
| `render.js` | ロケット・てき・ボス・わくせい・はいけい の え（canvas に コードで かく） |
| `game.js` | うごき・あたり・ステージの ながれ・ボスの わざ・パネルの そうさ |

- ゲームの せかいは 512×288 の よこなが。よこもちでは がめんに あわせて おおきく、たてもちでは うえに よこながに きりとって だして、したを そうさ パッドに する。
- たま・てき・こな の かずには じょうげん（`LIMIT`）が ある。
- URL に `#debug` を つけると `window.__wk` から そうさできる（`start(i)` / `boss()` / `kill()` / `god()` / `clearAll()` / `zukan('size')` など）。
