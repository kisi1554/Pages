# かみひこうき グライダー ✈️

じぶん で おった **かみひこうき** を、ゆび で スワイプ して なげる（年長〜小学6年）。
**のぼる かぜ（じょうしょう きりゅう）** に のったり、とり と いっしょ に とんだり しながら、どこまで とおく とべる か。
おりかた で とびかた が かわる。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。おと は WebAudio の 合成音。🔊 と 🎵 で オン/オフ）。

## あそびかた

1. **えらぶ**: 3しゅ の ひこうき・いろ（8）・もよう（むじ／みずたま／しましま／ほし）・そら を えらぶ。
   | ひこうき | とくちょう |
   | --- | --- |
   | へそ ひこうき | ふわっと ながく とぶ |
   | やり ひこうき | はやく まっすぐ。つよく なげる と のびる |
   | つばさ ひろ ひこうき | おそい けど のぼる かぜ に つよい |
2. **おる**: 4ステップ。やじるし の ほう へ ゆび で なぞる と かみ が おれる（とちゅう で はなす と もどる）。
   🤖 おって もらう も ある。ほんもの の おりかた を かんたん に した もの（やり＝かど を まんなか へ 2かい → はんぶん → つばさ、
   へそ＝かど → さんかく を おろす → かど → さき を おりあげて とめる、つばさ ひろ＝うえ を 2かい おりさげる → かど → はんぶん）。
3. **なげる**: スワイプ の むき＝なげる かくど、はやさ＝つよさ。🖐️ ぽいっ と なげる（スペース キー）でも なげられる。
4. **とぶ**: がめん を おさえる と はな が うえ を むく（のぼる が はやさ が おちる）、はなす と さがる。なにも しなくて も とぶ。
   こうえん → かわ → まち → うみ → くも の うえ と けしき が かわる。ゴール は なし、きょり の きろく。

## しかけ

- 🦋 **のぼる かぜ**（ちょうちょ が くるくる まう ばしょ）: うえ に もちあがる。おさえて ゆっくり とおる と たくさん のぼれる
- 🌬️ **むかいかぜ／おいかぜ**、🐦 **とり の むれ**（ぶつかる と いっしょ に とんで 6びょう おいかぜ）
- 🎈 **ふうせん**（とる と ふわっ と もちあがる）、☔ **あめ**（かみ が ぬれて おもく なる）
- 🏢 **ビル**（まえ で ビルかぜ が のぼる。かべ に ぶつかって も こわれない。やね に も おりられる）
- のぼりすぎる と **ストール**（くるっ と まわって、はな を さげて たてなおす）
- ちゃくち は ふわっ と。「○○メートル！」と じこ ベスト（🏆 の はた が けしき に でる）

## そら

- 🎲 **いろいろ な そら**: なげる たび に シード が かわる（そら No.）
- 📅 **きょう の そら**: ひづけ が シード。その ひ は みんな おなじ かぜ。きょう の きろく を べつ に ほぞん

## しくみ（`flight.js`、DOM なし）

はやさ と かくど から「うく ちから」L = K·V²·CL と「くうき の ていこう」D = K·V²·(CD0 + k·CL²) を だし、
じゅうりょく で おちる（V は かぜ を ひいた くうき に たいする はやさ）。ひこうき ごと に K・CD0・k・CL が ちがう。
CL（はな の あげぐあい）は おさえる と おおきく なり、のぼりすぎる と しぜん に さがる（かみひこうき の あんていせい）。
そら は 100m ごと の かたまり を シード つき らんすう で つくる（どこまで いっても つづく）。

おりがみ は `fold.js`: かみ を たかくけい の そう で もち、おりせん で きって かたほう を うらがえす（その がわ の そう は ぜんぶ おれる）。
