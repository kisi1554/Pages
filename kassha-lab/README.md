# かっしゃ ラボ 🏗️

滑車（かっしゃ）で おもりを もちあげて、「ちから」と「ひく ながさ」の かんけい を たいけんする 理科あそび
（小学校 低学年 〜 中学受験）。`index.html` を ひらくだけで うごきます（外部ライブラリなし）。

`korokoro-souchi/` の バケツ滑車（スクリプトで うごかす）とは べつに、こちらは 滑車の しくみ そのもの を
つりあいの けいさんで 正確に あつかいます。

| タブ | あそびかた |
| --- | --- |
| ✊ たいけん | 天井の 滑車に おもり（10・20・40・60g）。「✊」を ドラッグ して ひもを ひく。ばねばかり の はり で ちから、ものさし で ひいた ながさ・あがった たかさ が わかる。定滑車 → 動滑車 → 定＋動 → 動滑車 2こ → 3こ → 輪軸 の じゅんに 解放。さいごに「ちから × ながさ は おなじ（しごとの げんり）」の まとめ |
| 🧩 くみたて | どうぐばこ の 定滑車・動滑車 を ばん に おき、ひもで つないで ▶ ためす。ちから オーバー だと「おもくて あがらない…」、ひく ながさ オーバー だと とどかない。12ステージ（★ は つかった 滑車の かず） |
| ✏️ もんだい | 中学受験の 滑車の もんだい 23もん（滑車の おもさ・ひも 2本 いじょう・輪軸・棒・ゴンドラ・ぎゃく算 など）。図は SVG、もんだいぶん は 漢字＋ふりがな。ヒントは 3だんかい（「この 滑車を ささえて いる ひもは 何本？」から） |

## けいさん（solver.js）

- ひもは たて、まさつ なし、ひもの おもさ なし。**ひも 1本の 張力は どこでも おなじ**
- うごける もの（動滑車・おもり・棒・輪軸・て）の うごき を じゆうど q に して、ひも r の ながさ の かわりかた
  `C[r][j] = ∂L_r/∂q_j` を 図の 上下 から つくる（滑車に かけると 2本ぶん、輪軸は はんけい × かいてん）
- つりあい（仮想仕事）: `Σ_r C[r][j]·T_r = G_j`（G は おもさ による ちから）。動滑車なら
  「上向きの 張力の 合計 ＝ つるした おもさ ＋ 滑車の おもさ」、棒なら 力と モーメント の 2しき。定滑車は 天井が ささえる
- ひく ながさ（拘束）: `Σ_j C[r][j]·dq_j = 0`（ひもの 全長は 一定）
- ひもが 何本 あっても 連立方程式 として ガウスの 消去法で とく。つりあわない（ぐらぐら）・ちからが きまらない・
  ひもが たるむ（張力 < 0）・滑車の かけかたが へん は エラー
- おなじ C から ちから と ながさ を だすので「しごとの げんり」が かならず なりたつ（テストで ぜんもん たしかめ）
- もんだいの □ は `ask()` で だす（ちから・張力・天井の ささえ・あがる たかさ・ひく ながさ・ぎゃく算）。
  テストで ぜんもん の こたえを ソルバーで 検算し、だいひょう的な もんだい は 手計算の しき とも てらしあわせる

## そのほか

- 音は 右上 🔊 で オン/オフ
- 解放・★・おもり・さいごの タブ は localStorage（`kassha-lab-v1`、読み書きは try/catch）
- たて持ちスマホ では くみたて の どうぐばこ が ばん の したに はりつく（ばん を みながら タップ できる）
