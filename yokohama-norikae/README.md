# よこはま のりかえ めいろ 🧭

横浜駅を まん中に、JR・東急・京急・相鉄・みなとみらい線・ブルーラインが どう つながっているかを 知り、
**「のりかえ」が すくない 道すじ** を 考える ろせんずゲーム（5さい〜）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。音は WebAudio の 合成音、🔊 で オン/オフ。🗣️ で よみあげ）。

## あそびかた
1. おつかいカード（例:「中華街で にくまんを かってきて」、いまいる えき: 新横浜）を えらぶ。
2. 🙂 の 駅から、ひかって いる となりの 駅を ゆびで なぞる（タップでも よい）。線が かわる 駅で「のりかえ」スタンプ。
3. ゴール 🏁 に ついたら「しゅっぱつ！」。電車が すすみ、のりかえ駅では あおちゃんが 走って ホームを うつる。
4. のりかえが いちばん すくなければ ⭐⭐⭐（1かい おおいと ⭐⭐）。こたえあわせの あとに わらいの おまけ
   （のりかえ 2かい いじょうで へとへと・かみが ぼさぼさ／横浜駅で ぐるぐる まいご／おみやげで りょうてが いっぱい）。

| レベル | なかみ |

| 1 | のりかえ なしで いける 4か所 |
| 2 | のりかえ 1かいの 4か所 |
| 3 | 2つの みちを くらべて「どっちが すくない？」 4か所 |

## データ（いちばん 大事）
- 駅・路線・直通・おつかいは `index.html` の `/*DATA-START*/` 〜 `/*DATA-END*/` の 1か所。
- 駅は しぼって いる。とちゅうの 駅は `gaps`（駅の かず）で ちいさな ○ として かく。各路線の しょうりゃくした 駅名は コメントに ある。
- 駅の じゅんばんは 各社の 路線図・Wikipedia の 駅一覧で 2026-11 に たしかめた。
- **直通（のりかえに かぞえない）**: 東横線⇄みなとみらい線（横浜）、横浜線⇄根岸線（東神奈川・横浜方面）、
  相鉄新横浜線⇄相鉄本線（西谷・二俣川方面）、相鉄新横浜線⇄東急新横浜線（新横浜）。
  むきが きまって いる（例: 新横浜から 西谷で 横浜方面へ 行くのは のりかえ）。
- のりかえ回数は 駅の ならびから いちばん すくない 線の わりあてで かぞえる（`assign()`）。
- チェック: `node tools/yokohama-norikae/check.js`（レベルと いちばん すくない のりかえ回数、レベル3の 2つの みちの ちがい）。

鉄道会社の ロゴ・マーク・発車メロディは 使わない。電車・地図・キャラクターの 絵は オリジナル。
進捗（⭐）は localStorage（`yokohama-norikae-v1`）。
