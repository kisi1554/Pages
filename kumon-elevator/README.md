# くもん エレベーター

5A から F まで **10かい だての ビル**を エレベーターで のぼる、くもん さんすうの やるきアプリ。
5さいの あおちゃんが「はやく うえの かいに いきたい！＝ しんきゅう したい！」と おもえるように つくった。

## あそびかた

| すること | どうなる |
| --- | --- |
| いきたい かいを タッチ | エレベーターが うごいて、ドアが ひらく |
| いまの きょうざい までの かい | その かいの もんだいに 5もん ちょうせん。できると ⭐ と へやの かざりが 1つ もらえる（かい ごとに ★3つ） |
| つぎの かい（🔑） | 「のぞきみ」。すんで いる ひとは シルエット。ヒントつきの 3もんが できると かおを みせて くれる |
| もっと うえの かい（🔒） | どんな もんだいを するか みる だけ（こたえつき） |
| 📄 プリント できたら ながおし | きょうの くもんの プリントが おわったら ながおし。⚡が 3つ たまる（1にち 1かい） |
| ⚡ パワーが いっぱい（10こ） | エレベーターの あたらしい かざりを ゲット。エレベーターを タッチで きがえ |

## かい と もんだい

| かい | へや | もんだい |
| --- | --- | --- |
| 5A | どうぶつ ひろば | 10までの かずを かぞえる |
| 4A | おかし やさん | 50までの つぎの かず、20までを かぞえる |
| 3A | でんしゃの えき | 120までの つぎの かず、たす1・たす2・たす3 |
| 2A | うちゅう きち | たす4〜たす10 |
| A | きょうりゅう ジャングル | たしざん・ひきざん |
| B | かいてい トンネル | 2けたの たしざん・ひきざん |
| C | ロボット こうじょう | くく・わりざん |
| D | そらの おしろ | 2けた×1けた、わりざん |
| E | にじの くも | おなじ ぶんぼの ぶんすう |
| F | ほしの てんぼうだい | しょうすう、ぶんぼの ちがう ぶんすう |

もんだいは きょうざいの イメージに あわせた **アプリ どくじの もの**（くもんの こうしき きょうざい では ない）。

## おうちの ひと むけ（🔑 を ながおし）

- **いまの教材**を えらぶ（はじめは 3A）。その かい までが あそべる。
- しんきゅうテストに ごうかく したら **「進級した！」** → おいわいの あと、エレベーターが あたらしい かいへ のぼる。
- よびかたの へんこう、きろくの しょうきょ。

## そのほか

- ほぞんは localStorage（`kumon-elevator-v1`）。おとは WebAudio の ごうせいおんで オン/オフ できる。
- `index.html` だけで うごく（がいぶ ライブラリ なし）。
