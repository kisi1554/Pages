# でんごん おえかき ― かぞくで まわす おえかき でんごんゲーム 🖍️

1だいの タブレット（スマホ）を **かぞく・ともだちで じゅんばんに まわす** あそびです。
さいしょの ひとが おだいを **え** に かく → つぎの ひとは えだけ 見て **ことば** に する →
つぎの ひとは その ことばを **え** に… と まわして、さいごに みんなで はっぴょう。
「ぞう」が「すべりだい」に なっていたら おおわらい。

対象: 3〜6にん（年中〜おとな）。1かい 5〜10ぷん。
まなび: つたえる 力（え・ことば）、そうぞう、かぞくの コミュニケーション。

`index.html` を ひらくだけで あそべます（外部ライブラリ・ネット なし。音は Web Audio の 合成音）。

## あそびかた

1. **じゅんび**: にんずう（3〜6）・なまえ（あいこん＋ひらがな）・🐣 ちいさい こ・おだい（やさしい／ふつう）・まわる かず（1しゅう／2しゅう）・え の じかん（40／60びょう／なし）
2. **まわす**: 「つぎは ○○さん。ほかの ひとは 見ないでね 🙈」→ うけとった ひとが「わたしだよ」を **1びょう ながおし** で ひらく。見えるのは **すぐ まえ だけ**
3. **え の ばん**: ペン 6しょく・ふとさ 2・けしごむ・やりなおし。ゆび 1本で かく（2本めは むし、ズームしない）。さいしょの ひとは おだいの くじびき（べつの おだい に 2かい まで かえられる）
4. **ことば の ばん**: ⌨️ もじで かく か、🃏 えらぶ（4まいの 絵カード。1まいは え が あらわす ことば、のこりは ダミー）。きめた ことばは よみあげて かくにん
5. **はっぴょう**: ドラムロール → 1まいずつ めくる（おだい → え → ことば → …）。さいごは シンバルと「ええーっ！」（つたわったら「つたわった！🎉」）。まとめ で おきにいり 1まいに ❤️

🐣 ちいさい こ の ひと: おだい・かく ことばを よみあげ、うすい 絵の ヒント つき。ことば は「えらぶ」から はじまる。

## アルバム・ほぞん

- はっぴょう した ゲームを さいだい 10かい（`dengon-oekaki-album-v1`。え は 320×240 の PNG を dataURL で）。
  いっぱいなら ふるい もの から けす。「🖼️ がぞう を ほぞん」で 1まいの まとめ画像（PNG）を ダウンロード
- せってい・なまえ・さいきんの おだい は `dengon-oekaki-v1`（読み書きは try/catch）
- **ネットは つかわない**。こどもの え を そとに だす きのうは ない
