# どたばた ペット ホテル 🏨

ペットが ぜんぶ へやから にげだした ホテル！ みならい スタッフに なって **3D の ホテルの なかを はしって とんで**、
**シャボンだま** で ペットを あわに つつみ、ふわふわ ひっぱって じぶんの へやに もどす アクションゲームです（年長〜小学4年むけ。やさしい モードは 年中でも）。

`index.html` をブラウザで開くだけで遊べます。**外部ライブラリ・CDN なし**（3D は WebGL を 手で書いている）。

- てきは いない・たたかわない・ダメージや ゲームオーバーも ない。おちても ふわっと もどる。
- ペットは つかまると「きゃー♪」と たのしそう（こわがらせない）。

## あそびかた

| そうさ | タッチ | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| あるく | ひだりした の スティック（たおす りょうで はやさ） | WASD / やじるし | ひだり スティック・じゅうじキー |
| ジャンプ（ながおしで たかく） | ジャンプ | スペース | A |
| あわ（シャボンだま） | あわ | J（Z） | X / Y |
| ダッシュ（ずさーっ） | ダッシュ | K（X・左Shift） | B / RT |
| カメラ | がめんを なぞる（はなすと うしろに もどる） | マウス ドラッグ | みぎ スティック |

1. **あわ** を うつと、ちかくの ペットに すこし すいよせられる（こども むけ ねらい ほせい）。あたると ペットが あわに つつまれて ぷかぷか うく。
2. あわに **さわると ひもが つく**。ふうせんの ように ついてくる（3つ まで）。かべに つよく ぶつけると **ぱちん** と われて、ペットは また にげる。
3. ドアの いろ＋マーク（🐰🐱🐶…）が あう へやに あわを はこぶと **「ただいま！」**。ぜんぶ かえすと フロア クリア。
4. いす・つみき・ケーキ・ボール などを とばす と **めちゃくちゃ ポイント** 💥。おこられない。さいごに ロボット そうじき が ぜんぶ もとに もどす。
5. ⭐ ぜんぶ かえした ／ ⭐⭐ じかん いない ／ ⭐⭐⭐ めちゃくちゃ ポイント が めあて いじょう。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `index.html` / `style.css` | がめん・HUD（のこり ペット・じかん・イベント）・メニュー。たてもち は うえ 6わり が 3D、よこもち は ぜんめん 3D に ボタン |
| `gl.js` | WebGL2（なければ WebGL1＋ANGLE_instanced_arrays）。おなじ かたちは インスタンス びょうが で 1かいに まとめる（ドローコール 10〜20） |
| `mesh.js` | はこ・きゅう・えんちゅう・とんがり・ドーナツ と、キャラ・ペット・かぐ の ローポリ モデル、4x4 ぎょうれつ |
| `physics.js` | ぶつり（DOM・WebGL なし）。たての カプセル と はこ・さか・まわる えんちゅう・みず。固定 ステップ 1/60びょう、はやい ものは こまかく わけて すりぬけない |
| `game.js` | ルール・ペットの うごき（にげる・はねる・すべる・のぼる・かくれる・たべる）・あわ・はこぶ・イベント の かけはずし |
| `floors.js` | フロアの データ（かべ・へや・かぐ・ペット・つかえる イベント）と、いける ばしょ を しらべる BFS |
| `input.js` / `audio.js` / `app.js` | そうさ・おと（WebAudio ごうせい、BGM は オリジナル マーチ）・がめんの きりかえ／カメラ／ほぞん |

- イベントは「もとの あたい（base）＋ いまの イベント」から まいフレーム パラメータを つくるので、おわると かならず もとに もどる。
- カメラは うしろ ななめ うえ。かべが あいだに はいると ちかよる。カメラがわ の かべは ひくく かいて なかを みせる。
- おもい ときは がめんの こまかさ・かげ・つぶ の かずを じどうで へらす。
- 保存（localStorage `dotabata-hotel-v1`、よみかき は try/catch）: フロアの ★・ベスト タイム・めちゃくちゃ ポイント の さいこう・めちゃくちゃ モードの きろく・ゲスト・キャラ と いろ・せってい。
