# 横浜グルメマップ

自分用の横浜グルメ記録アプリ。地図の上にお店のピンを出して、
**行った / 行きたい**・**★5段階評価**・**訪問日**・**ひとことメモ** を記録できる。

**野毛・関内・みなとみらい** の各51件、計153件。横浜駅周辺はデータを足せば増える。

## つかいかた

| したいこと | やりかた |
| --- | --- |
| お店を見る | 地図のピン、または下（横画面では右）のリストをタップ |
| 記録する | 詳細パネルで「行きたい／行った／興味なし」「★」「訪問日」「メモ」を入力（自動保存） |
| しぼりこむ | 上の「行きたい／行った／未設定／興味なし」チップ、ジャンルチップ、検索ボックス |
| 並べかえ | 「標準の順／★が高い順／地図の中心から近い順／名前順」 |
| Googleマップで開く | 詳細パネルの「Googleマップで開く」（店名で検索）／「この地点を開く」（座標） |
| 現在地を出す | 地図右上の ◎（HTTPS のページでのみ動く） |
| バックアップ | 右上の 💾 → JSONを保存／読み込み |

## 「興味なし」について

行かないと決めた店は「興味なし」にしておくと、**「すべて」表示から消える**。
地図もリストも軽くなり、残りの店が見やすくなる。

- 見たいときは状態チップの「興味なし」を押す。件数もそこに出る
- 同じボタンをもう一度押すと未設定に戻る（★やメモは消えない）
- ヘッダーの「行った 3／48」の分母からも外れる
- **検索でも出てこない。** 名前で探しても見つからないときは「興味なし」チップを見る

## 保存について

- 記録は **この端末のブラウザの localStorage** に入る（キー: `yokohama-gourmet-map:v1`）。
  サーバには送らないので、端末をまたぐと共有されない。
- ブラウザのサイトデータを消すと記録も消える。**ときどき 💾 からJSONを書き出しておく**。
- 別の端末に移すときは、書き出したJSONを移行先で「読み込む」。
  読み込みは**置きかえ**なので、いまの記録は上書きされる。

## お店を足す

`data.js` の `SPOTS` に1行足すだけ。

```js
{ id: 'noge-052', area: 'noge', genre: 'izakaya', name: '店名',
  lat: 35.44770, lng: 139.62883, note: 'ひとこと説明' },
```

- **`id` は一度決めたら変えない。** 記録が `id` で紐づいているので、変えると記録が外れる。
- `area` は `noge` / `kannai` / `mm` / `ykhm`。`genre` は `data.js` の `GENRES` にあるどれか。
- `id` の頭はエリア名にそろえている（`noge-001`、`kannai-001`）。続きの番号を使えばよい。
- 緯度経度は Googleマップでその場所を右クリック →「35.4477, 139.6288」をコピーして貼る。
  （いま入っている座標は OpenStreetMap のデータから取った）

エリアを増やすときは `AREAS` に1行足して、そのエリアの `SPOTS` を入れれば、
上のタブが「準備中」から件数表示に変わって使えるようになる。
地図の初期位置は、そのエリアの店が全部入るように自動で決まる。

`AREAS` の `fitMin` は、その自動調整で**引きすぎない下限のズーム**。
店が狭い範囲に密集している街ほど大きく（野毛 16.3）、広く散っている街ほど
小さくする（みなとみらい 14.6）。ここを大きくしすぎると、小さい画面で
端の店が画面外から始まる（リストのカードをタップすれば地図はそこへ飛ぶ）。

## つくりの話

- 外部ライブラリ・フレームワークなし。地図は Web メルカトル投影を自前で計算して、
  OpenStreetMap のタイル画像を `<img>` で並べているだけ（ドラッグ・ホイール・ピンチ対応）。
- 地図タイルだけは外部（`tile.openstreetmap.org`）から読む。
  読めないときは注意書きを出し、リストと記録はそのまま使える。
- 地図: © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL)

## いま入っているエリア

| エリア | 件数 | 範囲 |
| --- | --- | --- |
| 野毛 | 51 | 桜木町〜日ノ出町。野毛本通り・野毛小路・都橋・ぴおシティあたり |
| 関内 | 51 | 馬車道・弁天通・関内駅前・伊勢佐木町・福富町・長者町あたり |
| みなとみらい | 51 | 桜木町東口〜新高島、赤レンガ・ハンマーヘッドまで |
| 横浜駅周辺 | 0 | 準備中 |

中華街・元町は、いまはどのエリアにも入れていない（必要になったら `AREAS` に足す）。

みなとみらいだけは事情がちがう。店の多くが商業施設のテナントなので、
**施設そのもの**（赤レンガ倉庫・ランドマークプラザ・クイーンズスクエアなど）と
**そのなかのわざわざ行く価値のある店**の両方を入れている。
同じ施設の店はピンが重なるので、リストや検索から選ぶほうが早い。

## メモ

- このアプリは大人向け（自分用）なので、`pages-root/index.html` の「あそびメニュー」には載せていない。
- お店の情報（ジャンル・ひとこと）は目安。営業時間や定休日は入れていないので、行く前に確認すること。
