# きょうの ふじさん 🗻

まどの むこうの ふじさん。**きせつ／じかん／ばしょ** の 3つの ダイヤルを まわすと けしきが かわる。
おだいの 写真カード（あかふじ・さかさふじ・ダイヤモンドふじ・ゆきげしょう など）と おなじ けしきを つくって アルバムに あつめる。
ちずモードでは ふじさんが **しずおかけん と やまなしけん の あいだ** に あることを たしかめる。

`index.html` と `map-data.js` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。え は SVG、おとは WebAudio）。

公開URL: https://kisi1554.github.io/Pages/kyou-no-fujisan/

## あそびかた（1かい 1〜3ぷん）

| モード | なにを する |
| --- | --- |
| 🖼️ おだい あそび | ダイヤルを まわして おだいの けしきを つくる。できたら なまえ と ひとこと せつめい → アルバムへ。💡ヒントで「あってる⭕／ちがう❓／どれでも🆗」が わかる。おだい いがいの けしきを みつけても アルバムに はいる |
| ❓ クイズ | 5もん。ゆきの りょうで きせつを あてる（2もん）、かさぐもが でたら てんきは？、ほか（ふじごこの かず、ダイヤモンドふじ、さかさふじ、あかふじ、どこの けん）。まちがえても えらびなおせる。さいごに ⭐ |
| 🗾 ちず | にほんちずで ふじさんを タップ（はずれると「もっと みぎ」など ヒント、2かい はずれると まるで おしえる）→ ズーム → ふじさんに くっついた 2つの けんを タップ → ふじごこ 5つが でる |
| 📒 アルバム | あつめた けしき 8まい。タップで せつめいを もういちど |

## ダイヤル

- きせつ: はる（ゆきが しまもよう・さくら）／なつ（ゆきが ない）／あき（てっぺんだけ＝はつかんせつ・もみじ）／ふゆ（まっしろ）
- じかん: あさやけ／ひる／ゆうやけ／よる
- ばしょ: みずうみ（さかさに うつる。なふだを タップで ふじごこ 5つを きりかえ）／しんかんせんの まど／ちゃばたけ／うみ（みほの まつばら）／とおくの まち

## おだい カード（8まい）

| カード | つくりかた |
| --- | --- |
| あかふじ | なつ ＋ あさやけ |
| さかさふじ | みずうみ ＋ ひる |
| ダイヤモンドふじ | ふゆ ＋ ゆうやけ ＋ みずうみ（おひさまが てっぺんに かさなる） |
| ゆきげしょう | あき ＋ ひる |
| しんかんせんの まどから | しんかんせん ＋ ひる |
| ちゃばたけと ふじ | ちゃばたけ ＋ はる |
| うみと ふじ | うみ ＋ ふゆ |
| よるの ふじ | とおくの まち ＋ よる |

「かさぐもが でると あめ」は 観天望気の 言い伝え として しょうかい している。

## ほかの アプリとの ちがい

- `shaso-tanken/`: でんしゃの まどから みえた ものの ビンゴ（ふじさんは 40しゅるいの 1つ）
- `fuji-ofuro/`: ふじさんが みえる おふろやさんの ランキング（おうち むけ）
- `fujisan-tozan/`: ふじさんに のぼる（たかさ・ごうめ）

このアプリは「**みえかた**（きせつ・じかん・ばしょ）」と「**どこに あるか**（けん・ふじごこ）」が テーマ。
