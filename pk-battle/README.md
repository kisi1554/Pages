# PK たいけつ ⚽

サッカーの PK（ペナルティキック）で、キッカーと キーパーを こうたいで あそぶ ゲームです（年長〜小学生むけ）。
`index.html` を ブラウザで ひらくだけで あそべます（がいぶ ライブラリ なし・えは ぜんぶ Canvas で コードで かく・おとは WebAudio の ごうせいおん）。

## あそびかた

| モード | ないよう |
| --- | --- |
| 🤖 1にん | CPU と PK せん。きみの チーム・あいて・さきに ける／あとで ける・CPU の つよさ（🐣 よわい・🐥 ふつう・🦅 つよい）を えらぶ |
| 🏆 たいかい | 8チームの トーナメント。じゅんじゅんけっしょう → じゅんけっしょう → けっしょう（けっしょうは CPU が 1だん つよく なる）。3かい かてば ゆうしょう、トロフィー 🏆 が たまる |
| 👫 2にん どうじ | よこもち タブレット 1だいで、キッカーと キーパーが いっしょに そうさ。ひだり はんぶん＝キッカーの スワイプ、みぎ はんぶん＝キーパーの 9つの ボタン（おした むきは がめんに でない 🤫） |
| 🔄 2にん こうたい | 1本ごとに たんまつを わたす。「つぎは ○○ チームの キッカー」→ スワイプ →「つぎは △△ チームの キーパー」→ とぶ |

### ⚽ キッカー（ける）

- キッカーの うしろ から ゴールを みる がめん（えんきんほう の 2.5D）。
- **ボールから ゆびで スワイプ**:
  - むき → ひだり・みぎ、ゆびを はなした たかさ → ボールの たかさ（ゴールまで とどかない みじかい スワイプは ひくい ゴロ）
  - はやさ → つよさ（ゆっくり → よわい、シュッ！ → つよい。はやすぎると **バーの うえ**＝ふかす）
  - まげて スワイプ → **カーブ**（さいごに まがった ほうへ まがる）
  - ずれすぎると ポストの そと。**ポスト・バーに あたると カーン！** で はねかえる（うちがわに あたって はいる ことも ある）
- **かんたん そうさ**（じゅんびで「🎯 かんたん」）: ゴールの 9マスを タップ → うごく ゲージを みどりの ところで「とめる！」
- はしって いる あいだに 1かい だけ **🌀 フェイント**（キッカーが とまって、CPU キーパーが つられて さきに とびやすく なる）

### 🧤 キーパー（まもる）

- ゴールの うしろ から キッカーを みる がめん。キッカーが はしって きて、けった しゅんかん に ボールが とんで くる。
- とぶ むきに **スワイプ**（うえ・した・ななめ も）か、**9つの ボタン**。タップ だけ なら まんなかで かまえる。
  - **はやすぎる**（けるまえ 0.3びょう より まえ に とぶ）と、CPU キッカーは みて **ぎゃくに ける**（つよい ほど よく みて いる。にんげんの キーパーには ときどき みのがす）
  - **おそい** と まにあわない（とびきる まで 0.4びょう、ボールは 0.4〜0.6びょう で ゴールに つく）
- **キッカーの くせ** が ヒント: **め**（みて いる ほう）・**からだの むき**（かたむき）・**はしって くる むき**（おおきく ななめ から → キッカーの みぎへ、まっすぐ → ひだりへ けりやすい）。
  CPU は くせを すこし みせる（よわい 85%・ふつう 60%・つよい 40% の かくりつで ほんとうの むき、のこりは でたらめ）。
  - くせが わかりやすい ように、キッカーは はしりだす まえに **1びょう じっと ゴールを みる**。そのあいだ と じょそう ちゅう に:
    きいろい てんせんの **めせん**（キッカーの め → みて いる ところ 👀）、みぎうえ の **「キッカーの ようす」**（おおきな かお と かたむいた からだ、
    👀 め・🧍 からだ・🏃 はしりかた の やじるし。● は まんなか）、パネルに「👀 め: ひだり・🧍 からだ: ひだり・🏃 はしりかた: みぎ」（キーパー から みた むき）。
- **にんげんの キーパーへの てだすけ**（\`ai.js\` の \`HUMAN_KEEPER\`。CPU どうし の バランスには かんけい しない）:
  て の とどく はんい 1.12ばい、キャッチ しやすい、CPU キッカーが「はやすぎ」を みのがす ことが ある（ぎゃくを つく かくりつ 0.6ばい）、
  ボールが すこし ゆっくり（0.85ばい。かんたん そうさ の ときは 0.6ばい）。

### しあい（PK せん の ルール）

- 先攻・後攻が 1本ずつ こうたいで 5本ずつ ける。**とちゅうで のこりを ぜんぶ いれても とどかなく なったら おわり**。
- 5本で どうてん なら **サドンデス**（1本ずつ、おなじ かず けって ちがったら おわり）。
- ルールの はんてい は `rules.js` の `status()`（テスト: `tests/rules.test.js`）。「きめたら かち」「はずしたら まけ」の ばめんも `pressure()` で しらべて じっきょうする。
- うえに スコアボード（○×、サドンデスは てんせんの わく）。じっきょう テキスト（「キーパー、とんだー！ とめたー！」）、🗣️ で こえ（speechSynthesis が あれば）オン／オフ。

### チーム（じつざいの クラブ・だいひょう・せんしゅ では ない）

| チーム | CPU キッカーの くせ | キーパーの おおきさ |
| --- | --- | --- |
| 🐻 どうぶつ | みぎした が すき | 1.00 |
| 🚃 でんしゃ | まっすぐ つよい シュート | 1.02 |
| 🦖 きょうりゅう | たかい ところ が すき | 1.08 |
| 🍰 おかし | ひだり が すき | 0.94 |
| 🚀 うちゅう | どこに くるか わからない | 1.00 |
| 🐬 うみ | ひくい ゴロ が すき | 0.98 |
| 🐞 むし | すみっこ を ねらう | 0.96 |
| 🤖 ロボット | まんなか に ドーン | 1.05 |

- キーパーの「おおきさ」は て の とどく はんい に そのまま きく（`physics.js` の `keeperPlan`）。

## ぶつり（`physics.js`）

- ざひょうは めーとる。ペナルティマーク が げんてん、ゴールライン まで **11m**、ゴールの うちがわ **7.32m × 2.44m**、ポスト・バー の ふとさ 12cm、ボール はんけい 11cm。
- ボールは じゅうりょく ＋ カーブの よこむき の ちから で 1/240びょう ずつ すすめる。じめんで はねる。
- **ポスト・バー** は えんちゅう として はねかえす（はねかえり 0.65）。**ゴール** は ボール ぜんぶが ラインを こえた とき。
- **キーパー** は「あし → て」の カプセル（はんけい 22cm）＋ て。とぶ むきに むかって からだが まわりながら、からだの まんなかが
  よこ さいだい 2.05m・うえ 0.7m・した 0.75m（× からだの おおきさ）うごく。て は まんなか から 0.95m。
  → すみの ぎりぎり（ポストから 0.5m いない）は ただしく とんでも とどかない。
- あたったら **キャッチ**（からだの ちかく・ゆるい ボール ほど）か **はじく**。ゆびさき で よこから さわった ときは いきおいが のこって、はいる ことも ある。
- にんげんの キーパーは ボールが とんで いる とちゅう でも とべる（`createShot` / `stepShot` で 1こま ずつ すすめる）。

## CPU と バランス（`ai.js`）

- **CPU キッカー**: チームの くせ（ひだり・まんなか・みぎ と うえ・まんなか・した の おもみ）＋ ランダムで マスを えらび、
  つよさ ごとの ぶれ（よわい 0.56m・ふつう 0.47m・つよい 0.38m）で ける。つよい ほど すみ ぎりぎり を ねらう（そのぶん はずれも ふえる）。
- **CPU キーパー**: つよさ ごとに「よむ かくりつ」（12%・24%・34%）・ボールを みてから とぶ までの じかん（0.26・0.17・0.10びょう）・キャッチの うまさ・
  フェイントに つられる かくりつ（60%・45%・30%）・チームの くせを しって いるか。つよい キーパーは きみの けった きろく（9マス）も おぼえて いる。

## データで みる（ちょっと さんすう）

- 📊 データ: きみが **ねらった マス** ごとに「けった かず／はいった かず」と わりあい（○本 中 ○本）を いろの こさで ひょうじ。
  「すみ は はいりやすい けど、はずれ も ○本 あったよ」など ひとこと。
- キーパーの きろくも おなじ（キーパー から みた むきで、どっちに とんだか・とめた かず）。「おなじ ほうに ばかり とぶと よまれちゃう かも？」
- 📖 まめちしき: PK は ゴールから 11m、ゴールの おおきさ、ボール ぜんぶが こえたら ゴール、キーパーは けるまで ゴールライン の うえ、
  PK せん の ルール、プロでも 4本に 3本 … など 10こ（かんじ には ふりがな）。

## えんしゅつ・おと

- ゴール: ネットが ゆれる（あたった ところが ふくらむ）、かみふぶき、かんきゃくが ぴょんぴょん、かんせい。
- セーブ: キーパーが たちあがって ガッツポーズ。はずれた キッカーは あたまを かかえて くやしがる だけ（わらいものに しない）。
- おと（WebAudio の ごうせい）: ける ドン、ネット ばさっ、ポスト カーン（きんぞくの ばいおん）、キャッチ パシッ、ホイッスル（ビブラート）、
  かんせい・ざんねん（ノイズ を かさねる）、ファンファーレ。🔊 で オン／オフ。

## ほぞん（localStorage `pk-battle-v1`、try/catch つき）
