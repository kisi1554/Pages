# でんき の ゆくえ ⚡

まち の **でんき を まかされた はつでん だいじん** に なる シミュレーション（小学2〜6年）。
あさ・ひる・よる で つかう でんき は かわり、てんき で つくれる りょう も かわる。
はつでんしょ を たてて、でんち に ためて、**まち を まっくら に しない** ように しよう。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。ちず は SVG、グラフ は canvas。
おと は WebAudio の 合成音 だけ で、オン/オフ できる）。

## あそびかた

1. **じゅんび**: はつでんしょ を ちず の ○ に ドラッグ（または えらんで タップ）。よさん と ばしょ に かぎり が ある。
   おいた もの を タップ すると とりけし。「きょう の よそう」で てんき・かぜ・つかう でんき が みえる。
2. **1にち スタート**: 1にち＝60びょう（せってい で 90びょう の「ゆっくり」も）。
   グラフ の あお が つかう でんき（うすい てんせん は この さき の よそう）、きいろ が つくる でんき。
3. **ダム の ゲート**・**かりょく の ひ** を スライダー で、**でんち** を ためる／だす で きりかえ。
   **せつでん カード** を つかう と 2じかん だけ つかう でんき が 15% へる。
4. たりない と まど が ちかちか → 3びょう つづく と **まっくら**（すぐ やりなおせる）。
5. ★ は「まっくら に しなかった」「けむり が すくない」「むだ が すくない」の 3つ。

## はつでんしょ（すうち は ゲーム よう に まるめて ある）

| しゅるい | 💰 | ばしょ | きまり |
| --- | --- | --- | --- |
| ☀️ たいようこう | 2 | どこでも | ひる だけ。はれ 100%・くもり 30%・あめ/ゆき 10%。けむり なし |
| 🌬️ ふうりょく | 3 | どこでも（うみぞい ×1.5、やま ×1.2） | かぜ しだい。よる も うごく |
| 💧 ダム | 4 | やま だけ | いつでも ちょうせつ できる。みず に かぎり（あめ で ふえる） |
| 🔥 かりょく | 3 | うみぞい・はら | いつでも ほしい だけ。けむり（CO₂）が たまる |
| 🔋 でんち | 3 | うみぞい・はら | あまり を ためて、たりない とき に だす。まんたん に なったら ためられない |

げんしりょく は ゲーム には いれず、ずかん で 1ぎょう しょうかい する だけ。

## ステージ（15）

はれ の はる → あつい なつ → くもり → うみかぜ → やま の ダム → かぜ の ない よる → あめ → ゆき の ふゆ →
おまつり の よる → まなつ の ゆうがた → たいふう いっか → みず ぶそく → けむり ゼロ → おおきな まち → ふゆ の おまつり。
まえ の ステージ を クリア すると つぎ が ひらく。

★ の めやす（`co2Max` / `wasteMax`）は `node tools/denki-yukue-tune.js --write` で ソルバー から きめる
（ひと が できそう な うごかしかた ＝ 1じかん に 1かい・10% きざみ・すこし おおめ で いちばん よかった くみあわせ の
けむり ×1.15＋2、むだ ×1.2＋3）。ステージ を かえたら かならず 走らせる。

## ほぞん（localStorage `denki-yukue-v1`）

ステージ ごと の ★・さいご に たてた くみあわせ・せってい（おと / はやさ）。
