# ラッセル ゆきかき ダッシュ ❄️🚂

よるの うちに ラッセル車で 線路の 雪を どけて、あさの いちばん電車が 走れるように する アクションゲーム（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

## あそびかた

- 画面を **ながおし** → ラッセル車が すすみ、まえの 雪を ぶわーっと 左右に はねとばす。
- ふかい 雪（ふきだまり・ふみきり・えきの ホーム）は おそくなる。**ポンポン れんだ** で ⚡パワーが たまって はやく なる。
- **ゆきの かべ**（トンネルの いりぐちにも ある）は パワーが たりないと「ぼふっ！」と ささって「ぷはっ！」と 少し もどされる。
  ぶつかる たびに かべが すこし くずれるので、なんかいでも やりなおせば かならず とおれる。
- ゴールの えきに つくと、うしろから いちばん電車が 来て「ありがとう！」。まなびカードが もらえる。
- 時間切れ・ゲームオーバーは なし。タイムは 記録だけ（じこベスト）。はやさは 🐢ゆっくり（5m/s）／🐇ふつう（8m/s）。

わらいどころ: はねとばした 雪が ゆきだるまに なって 線路わきに ならぶ／ねている きつねが とびだす／かべに ささった ラッセル車が「ぷはっ」。

## まなびカードの なかみと たしかめた 資料

- **ラッセル車**: まえの くさび形の ラッセルヘッドで 雪を 左右に かきわける。JR北海道は DE15形 ラッセル機関車で 除雪している
  （後継の キヤ291形も ラッセルヘッドの 構造は DE15と 同じ）。
  — JR北海道 2021年11月10日 発表（キヤ291形 ラッセル気動車の 導入）、北海道新聞の 石北線ラッセル 記事
- **ロータリー車**: 回転する 羽根で 線路上・線路ぎわの 雪を 遠くへ ふきとばす。ラッセルで よせた 雪の かべを とばす。
- **上越新幹線の スプリンクラー（散水消雪）**: 降雪を 検知すると 温めた 水（散水温度 8〜12℃程度）を 軌道に まき、
  集めた 水を 消雪基地に もどして 再利用する（加熱循環方式。上毛高原〜新潟の トンネル以外 約76km）。
  — JR東日本 技術レポート（https://www.jreast.co.jp/development/tech/pdf_57/tech-57-31-32.pdf ほか）
- **ポイントの 融雪**: 分岐器（ポイント）に 雪や 氷が はさまると 転換できなく なるので、電気ヒーター・温風式・マットヒーターなどで 融雪・凍結防止する。
  — JR東日本 研究開発資料（https://www.jreast.co.jp/development/theme/energy/pdf/energy12.pdf ほか）

車両の 絵は 色と 形を にせた オリジナル（ロゴ・マーク・発車メロディは つかわない）。

## しくみ

- 進捗は localStorage `russell-yukikaki.v1`（クリア・じこベスト・カード・はやさ・おと）。
- 長押し・連打は canvas（`touch-action: none`）で pointer イベントを うける。キーボードは スペース／→。
- URL に `#debug` で `window.__ry`（`startStage(k)`, `warp(x)`, `G`）。
