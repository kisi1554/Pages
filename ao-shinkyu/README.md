# あおちゃんの 2Aゆき とっきゅう

5さいの あおちゃんが **くもん さんすう 3A → 2A の しんきゅうテスト**に「ごうかく したい！」と
おもえるように する、モチベーション アプリ。たしざんの ドリルは すでに ある
（`tashizan-tokkun/` など）ので、この アプリは **「やりたく なる しかけ」** が しゅやく。

## やるきの しかけ

| しかけ | ねらい |
| --- | --- |
| 🗺️ 3Aえき → 2Aえき の ろせんず | 「2A」という みえない もくひょうを、でんしゃが すすむ **みえる たび** に する。あと なんえき かが いつも わかる |
| ❓ ひみつの 2Aでんしゃ | えきに つく たびに シルエットの でんしゃが すこしずつ みえて くる。ぜんぶ みえるのは ごうかくの とき（つづきが きに なる） |
| ⚡ きょうの ミッション（3つ・5〜10ぷん） | みじかく おわる。ぜんぶ やると ボーナス。「また あした」で きりあげる |
| 👻 じぶんと レース | あいては ともだち ではなく **まえの じぶん**。のびが グラフで みえる |
| 📄 しゅくだい スタンプ | きょうしつの プリントを やった ひに おうちの ひとが ながおし。**いちばん ⚡ が たまる**（しゅやくは プリント） |
| 📝 もぎテスト | ほんばんと おなじく まるつけは さいご。テストの ながれに なれて こわく なくする |
| 🔭 2Aせんを のぞく | 2Aの「たす4」を ヒントつきで 3もん。「もう できる！」で さきに すすみたく なる |
| 🎁 2Aに なったら なに する？ | おいわいを **じぶんで えらぶ**（ゴールの えきに かざられる） |
| 💌 おうえん メッセージ | おうちの ひとの ことばが ホームに でる |
| 🎉 2Aせん うんてん めんきょ | ほんものの テストに ごうかく したら おうちの ひとが ボタンを おす → でんしゃ かんせい・めんきょしょう |

## しくみ

- ⚡ 6こで 1えき すすむ。ミッション 1つ＝⚡1、3つ ぜんぶで ボーナス ⚡1、しゅくだい スタンプ＝⚡2、
  もぎテスト（1にち 1かい）＝⚡1、レースの しんきろく＝⚡1。ぜんぶ やると 1にち 1えき くらい。
- 8ばんめの「しけんじょう まえ」は **もぎテスト ごうかく** が ひつよう。
  さいごの「2Aえき」は ほんものの テストに ごうかく した ときだけ（おうちの ひとの ボタン）。
- もんだいは 3Aの はんい：たす1（〜99＋1）、たす2（〜20＋2）、たす3（〜17＋3）。まちがえた もんだいは でやすく なる。
- 🔑 を ながおし → おうちの ひと むけ せってい（よびかた、いま ならって いる ところ、
  もぎテストの もんだいすう・じかん、メッセージ、おいわいの なかみ、ごうかく ボタン、きろくの しょうきょ）。
- もぎテストの かず・じかんは **アプリの めやす**（くもんの こうしきの きじゅん では ない）。きょうしつの せんせいの めやすに あわせて かえる。

## そのほか

- ほぞんは localStorage（`ao-shinkyu-v1`）。おとは WebAudio の ごうせいおんで オン/オフ できる。
- `index.html` だけで うごく（がいぶ ライブラリ なし）。
