# ふえふえ マシン 🏭

**はかせの へんてこ マシンで「2ばい」「はんぶん」を 目で 見て つかむ**（5さい〜、かけざん・わりざんの はじめの 一歩）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. いれる トレーに もの（れい: りんご 3こ）が ならぶ。レバーを ひくと ホッパーに すいこまれる。
2. ガタゴト ぷしゅー！ でぐちに「？」。**いくつ でてくるか** を 4つの かずから えらんで よそう する。
3. あたり → でぐちから ならんで でてきて、1つずつ かずを かぞえる。
   ちがう → ヒントとして こたえの ならびかたが うすく でる。かぞえて えらびなおせる（なんどでも）。
4. 5かい まわすと 1かい おわり（1〜3ぷん）。**1かいめで あてた かずだけ はかせの メガネが ぴかっ**。
   けっかでは はかせの あたまに つんだ メガネ 5こが じゅんばんに ひかる。

## わらい どころ（こたえあわせの あとに でる）

- ねこ → ふえた ねこが けんか（💢）→ なかなおり 😺
- はかせの かつら → はげの はかせが ふたり！
- うっかり はかせ本人が すいこまれる → はかせが ふたり（3ばいなら さんにん）。「どれが ほんもの？」クイズ（にせものは メガネが ななめ）
- はんぶん マシンに ケーキ → はかせ しょんぼり →「はんぶんこ すれば みんなで たべられるね」
- はんぶん マシンの おまけ: りんご 3こ → マシンが こまって けむり、まんなかの 1こが まっぷたつ（1こ と はんぶん）

1かいに 1つ（1もんめ いがい）まぜる。
