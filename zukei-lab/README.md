# さわって ずけい ラボ（小学校〜中学受験の 平面図形・立体図形）

小学校で習う図形と、中学受験でよく出る図形（平面・立体）を、**さわって・まわして・ひらいて・きって・ころがして・くっつけて**
遊びながら学べるアプリです。外部ライブラリなしの自作 3D（canvas 2D）で動きます。

## あそびかた（タブ）

| タブ | できること | まなべること |
| --- | --- | --- |
| 🧊 りったい | 12種類の立体（立方体・直方体・三角柱・六角柱・円柱・三角すい・四角すい・円すい・球・正八面体・正十二面体・正二十面体）を指で360°回す。面をぬる／辺をなぞる／頂点にシールで数える。「ひらく」で展開図にアニメーション、立方体などは「べつの ひらきかた」で別の展開図 | 面・辺・頂点の数、底面・側面、面のかたち（タップで判定）、オイラーの定理（頂点−辺＋面＝2）、展開図 |
| ✂️ きる | ● を3つ選んで切断。スライダーで切る位置を平行にずらせる。切ったあとは2つに分かれ、切り口だけを正面から見られる | 立方体の切断（正三角形〜正六角形・ひし形・等脚台形・五角形）、円柱・円すい・球の切り口（円・だ円） |
| 🎲 ころがす | さいころを盤の上で転がす（あしあと＝下になった目を記録）。「よそう もんだい」で転がした後の上の目を当てる。正三角形・正方形・正六角形・円を直線上で転がし、点の通った跡を描く | 向かい合う目の和は7、図形の回転移動と軌跡、外角、サイクロイド、円周＝直径×3.14 |
| 🧱 くっつける | つみきを面にくっつけて立体をつくる（つみきの数・表面の面の数・三面図がリアルタイムで出る）。三面図の「おだい」。かたちパズル（三角形で四角形・正三角形6枚で正六角形・タングラム など10問＋じゆう） | 表面積、三面図（投影図）、図形の合成・回転・裏返し、ピースの角度 |
| 📐 かたち・かくど | 点をドラッグして三角形〜六角形・円を自由に変形。名前を自動判定し、角度・辺の長さ・等しい辺／平行／直角のしるし・対角線・面積を表示。「角を あつめる ひみつ」で三角形180°・四角形360°をアニメで確認 | 三角形・四角形の分類、角の和＝180°×(N−2)、対角線の本数、半径・直径・円周 |
| ❓ クイズ | 10問（面・辺・頂点の数、立体の名前、立方体の展開図か？→組み立てアニメ、三角形・四角形の角度、切り口のかたち、さいころ、図形の名前、知識問題） | ふりかえり |
| 📖 ことば | 面・辺・頂点・角度・直角・平行・垂直・対角線・底面と側面・展開図・見取図・切断面・三面図・半径と直径・円周率・正多面体・体積と表面積 | 用語（ふりがな付き）。「ためしてみる」で該当タブへ |

- シール（20種）を集められます。進み具合は localStorage に保存。
- 音は WebAudio の合成音のみ。右上の 🔊 でオン／オフ。
- 縦持ちスマホ・横持ちタブレットの両方に対応（タブレット横では左に図・右に操作パネル）。

## 第1弾で ふえたもの

| タブ | ついか |
| --- | --- |
| 🧊 りったい | 「かたちを かえる」スライダー（大きさ cm・角柱/角すいの かどの数 N）、N角柱・N角すいの **きまりの表**（面＝N＋2 など）、**体積・表面積** の式と答え（5・6年生〜）、**平行・垂直** モード（辺や面を1つ選ぶと平行＝みどり・垂直＝あお）、**まわして できる かたち（回転体）**：長方形→円柱、直角三角形→円すい、半円→球、台形→円すい台、はなれた長方形→あなあき円柱、L字→2段の円柱、三角形→そろばん玉、はなれた円→ドーナツ（まっぷたつ表示・体積つき） |
| ✂️ きる | **きりくち ずかん**（17種類・未発見は「？」）、**おだい**（まだ見つけていない切り口を出題・ヒントつき） |
| 🎲 ころがす | 転がす点を **かど／へんの まんなか／中心**（円は まわり／半径の まんなか／中心）から選べる |
| 🧱 くっつける | 三面図のおだいを16問に（つみきは浮かない）、**なんこ もんだい**（三面図から いちばん少ない／多い個数）、タングラムの **シルエット20種**（`tools/tangram-solve.js` で解を自動生成した `tangram.js`） |
| 📐 かたち・かくど | **おうぎ形**（半径・中心角をドラッグ、弧の長さ・面積）、**三角じょうぎ**の組み合わせ8種（15°〜180°） |
| 全体 | **学年えらび**（ようじ〜2年／3・4年／5・6年／中学受験）でクイズの出題・体積表示・まめちしきが変わる。各タブ はじめての **ガイド**（右上 ？ で もう一度）。シール 27種、クイズに体積問題 |

タングラムのシルエットを足すときは `tools/tangram-solve.js` の `FIG` に格子の多角形を書き、
`node tools/tangram-solve.js --write` で `tangram.js` を作り直す（しきつめられない形は「しきつめられない」と出る）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `core.js` | ベクトル・行列、3D ビュー（ドラッグ回転・慣性・ピンチ/ホイールズーム・塗り順描画・隠れ線の点線表示・タップ判定）、音、保存、シール、平面図形の名前判定 |
| `solids.js` | 立体データ（凸包から面を作る）、辺・頂点の抽出、展開図（面の木を作って辺のまわりに回転）、平面での切断 |
| `mode-*.js` | 各タブ（`mode-revolve.js` は りったい タブの回転体） |
| `tangram.js` | タングラムのシルエットと解（生成ファイル） |
| `main.js` | タブ切り替え・ことば図鑑・シール帳 |
