# バクダン どっかーん！ 💣

ばくだんを おして はなすと どっかーん！ ばくふうが ほかの ばくだんに とどくと **れんさ** して、
いわを ぜんぶ こわせたら クリアの パズルゲーム。年長〜小学生むけ。

公開URL: https://kisi1554.github.io/Pages/bakudan-dokkan/

外部ライブラリ・CDN なし。描画は Canvas（ばくだん・いわ・てつ・ほのお は ぜんぶ コードで かく）。
音は WebAudio の 合成音だけ（ばくはつ・いわが われる おと・ファンファーレ。オン/オフ あり）。

## あそびかた

- **ステージ（15もん）**: ばくだんを ゆびで おすと とどく ばしょが オレンジに ひかる。はなすと ばくはつ。
  ゆびを ずらせば べつの ばくだんを ねらえる／ばんの そとで はなすと やめられる。
- つかえる 🔥マッチは「いちばん すくない かず＋1」。いちばん すくない かずで クリアすると ⭐3つ。
- 💡ヒント: いまの ばんめんから とける ばくだんを ひからせる（とけない ときは「やりなおそう」）。
- **じゆうに どっかーん**: 8×10 の ばんに ばくだん・いわ・てつを すきに おいて（なぞって ぬれる）、
  🔥で つける／💥ぜんぶ で いっせいに ばくはつ。🔄 で あたらしい ばん。

| マス | とくちょう |
| --- | --- |
| じゅうじ ばくだん 1・2・3 | たて よこ に かずの ぶんだけ とどく |
| まる ばくだん（むらさき ◎） | まわり 8マス |
| よこ ばくだん（オレンジ ↔） | よこに はしまで |
| たて ばくだん（あお ↕） | たてに はしまで |
| いわ | 1かいで こわれる。ばくふうは ここで とまる |
| かたい いわ（はいいろ） | 2かい あてると こわれる（1かいめで ひびが はいる） |
| てつ | こわれない。ばくふうも とおさない |

## ファイル

- `index.html` … がめん と スタイル
- `core.js` … ルール（ばくふうの ひろがり・れんさ・ソルバー）と ステージデータ。node でも うごく
- `game.js` … 描画・音・そうさ・ほぞん（localStorage `bakudan-dokkan-v1`）

ステージの「いちばん すくない かず」は `core.js` の `solve()`（はばゆうせん たんさく）で
よみこみ時に けいさんする。ステージを かえたら たしかめる:

```bash
node -e 'const C=require("./bakudan-dokkan/core.js");C.LEVELS.forEach((L,i)=>{const s=C.solve(C.parse(L.map),8);console.log(i+1,L.name,s?s.moves:"とけない!")})'
```
