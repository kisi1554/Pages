# とまる？ とばす？ きゅうこう えらび ⏩

東急東横線（渋谷〜横浜・21駅）・横浜市営地下鉄ブルーライン（湘南台〜あざみ野・32駅）・京急本線（品川〜横浜・25駅）から 線を えらんで おつかい。ホームに くる 電車（かくてい・きゅうこう・とっきゅう）から
のる ものを えらんで、しゅべつに よって とまる 駅が ちがう ことを 体験する（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。音は WebAudio の 合成音、オン/オフ あり）。

## あそびかた

- ろせんずの 駅の よこに、しゅべつごとの ◯（とまる）と ｜（とばす）。めあての 駅に ⭐。
- のる 電車を えらぶと 走りだす。とばす 駅は ぴゅーんと 通りすぎる。
- めあての 駅を とばす 電車に のると「あっ！」→ 🦝「おりたかった〜」→ つぎの 駅で おりて かくていで もどる。
- ついたら、ぜんぶの のりかたの 時間を ぼうグラフで くらべる。いちばん はやい ⭐⭐⭐／ついたけど おそい ⭐⭐／とおりすぎ ⭐。
  「もういちど」で おなじ おつかいを やりなおせる。
- 1レベル＝おつかい 4つ（1回 1〜3分）。さいごに「ろせんずの ◯ と ｜ を 見ると わかるよ」と つぎの アプリ（ちょくつう ぶらり）の しょうかい。

タイトルで 線を えらぶ（えらんだ 線は 保存）。星の 記録は 線×レベル ごと。

| 線 | レベル1 | レベル2 | レベル3 |
| --- | --- | --- | --- |
| とうよこせん | かくてい・きゅうこう（1問目 学芸大学） | ＋とっきゅう | のりかえ（まちあわせ） |
| ブルーライン | ふつう・かいそく（1問目 上大岡） | とおくの 駅（1問目 新横浜） | なし（地下鉄に 追い越し設備が ないため） |
| けいきゅう | ふつう・とっきゅう（1問目 青物横丁） | ＋かいとく（1問目 京急川崎） | のりかえ（1問目 生麦） |

レベル3は かくていだけの 駅へ「とっきゅう（きゅうこう）→ ○○で かくていに のりかえ」。🐢「おさきに どうぞ」（ぺこり）。
長い 線（ブルーライン）は アニメを すこし はやく する。

時間の めやす: 1駅 走る＝1分、とちゅうで 1回 とまる＝1分、のりかえ＝1分、とおりすぎて もどる ときの まち＝4分。

まなび カード: しゅべつ／ていしゃえきの 表の 読みかた（◯ と ｜）／まちあわせ・おいこし。
