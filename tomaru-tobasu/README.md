# とまる？ とばす？ きゅうこう えらび ⏩

東急東横線（渋谷〜横浜・全21駅）で おつかい。ホームに くる 電車（かくてい・きゅうこう・とっきゅう）から
のる ものを えらんで、しゅべつに よって とまる 駅が ちがう ことを 体験する（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。音は WebAudio の 合成音、オン/オフ あり）。

## あそびかた

- ろせんずの 駅の よこに、しゅべつごとの ◯（とまる）と ｜（とばす）。めあての 駅に ⭐。
- のる 電車を えらぶと 走りだす。とばす 駅は ぴゅーんと 通りすぎる。
- めあての 駅を とばす 電車に のると「あっ！」→ 🦝「おりたかった〜」→ つぎの 駅で おりて かくていで もどる。
- ついたら、ぜんぶの のりかたの 時間を ぼうグラフで くらべる。いちばん はやい ⭐⭐⭐／ついたけど おそい ⭐⭐／とおりすぎ ⭐。
  「もういちど」で おなじ おつかいを やりなおせる。
- 1レベル＝おつかい 4つ（1回 1〜3分）。さいごに「ろせんずの ◯ と ｜ を 見ると わかるよ」と つぎの アプリ（ちょくつう ぶらり）の しょうかい。

| レベル | 電車 | おつかい |
| --- | --- | --- |
| 1 | かくてい・きゅうこう | 1問目は かならず 学芸大学。きゅうこうの 駅 2つ＋かくていだけの 駅 2つ |
| 2 | ＋とっきゅう | とっきゅうが いちばん／きゅうこうが いちばん（とっきゅうは とばす）／かくていだけ |
| 3 | のりかえ | かくていだけの 駅へ。「とっきゅう（きゅうこう）→ ○○で かくていに のりかえ」の まちあわせ。🐢「おさきに どうぞ」（ぺこり） |

時間の めやす: 1駅 走る＝1分、とちゅうで 1回 とまる＝1分、のりかえ＝1分、とおりすぎて もどる ときの まち＝4分。

まなび カード: しゅべつ／ていしゃえきの 表の 読みかた（◯ と ｜）／まちあわせ・おいこし。

## データ（index.html の `STATIONS`・`STOPS` 1か所）

- 駅の じゅんばん: 東急電鉄 公式「東横線 路線図」 https://www.tokyu.co.jp/railway/ty/ で 確認（2026-11-27）。
- 停車駅（2026-11-27 確認。2023-03-18 ダイヤ改正以降）: 公式サイトで 一覧表が 取れなかったため、路線図サイト rosen-zu.net の 東横線 停車駅と 照合。
  - 急行: 渋谷・中目黒・学芸大学・自由が丘・田園調布・多摩川・武蔵小杉・日吉・綱島・菊名・横浜
  - 通勤特急: 渋谷・中目黒・自由が丘・武蔵小杉・日吉・菊名・横浜（ゲームでは 使わず カードで しょうかい）
  - 特急: 渋谷・中目黒・自由が丘・武蔵小杉・菊名・横浜
- ダイヤ改正で かわったら `STOPS` を なおす。
- 東急の ロゴ・路線図デザイン・車両デザイン・発車メロディは 使っていない（色も オリジナル）。
- tokyu-sugoroku-game/ など 既存の 東急すごろくとは 内容が ちがう（すごろくは 駅めぐり、こちらは しゅべつと 停車駅）。
