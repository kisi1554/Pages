# おとの ふしぎ ラボ 🔊

音（おと）の しくみを **じっけんで たしかめる** 理科あそび（年長〜小学校中学年）。
小3 理科「光と音の性質」の 予習 と、中1「音の性質」に つながる 発展 を あつかいます。
`index.html` を ひらくだけで うごきます（外部ライブラリ・CDN なし、音は ぜんぶ WebAudio の 合成音）。

`onpu-piano/`（えんそう）・`oto-kakurenbo/`（ききわけ）・`dondoko-taiko/`（リズム）とは ちがい、
こちらは「音は なにで できて いて、どう つたわるか」に しぼって います。

## 正確さ（physics.js と 出典）

| ないよう | アプリでの あつかい | 出典 |
| --- | --- | --- |
| 小3 の 範囲 | 音が 出る・伝わる とき 物は ふるえて いる／音の 大きさが かわると ふるえ方が かわる（じっけん 1・2・4・7・8 の 中心） | 文部科学省『小学校学習指導要領（平成29年告示）解説 理科編』第3学年 A(3)「光と音の性質」 |
| 発展（中1） | 音の 高さ と ふるえ（振動数）、音の 速さ、真空では 伝わらない | 文部科学省『中学校学習指導要領（平成29年告示）解説 理科編』第1分野 (1)「身近な物理現象」音の性質 |
| 空気中の 音速 | `331.5 + 0.6 × 気温℃` m/秒。15℃ で やく 340 m/秒。けいさんは 340 を つかい、表示は「やく」 | 理科年表（国立天文台編）、コトバンク「音速」（日本大百科全書 ほか） |
| 水中の 音速 | やく 1500 m/秒（水温・塩分で かわる）。空気の 4ばい いじょう | 同上 |
| 弦（わゴム） | メルセンヌの 法則 `f = (1/2L)√(T/μ)`：**短い ほど・張りが 強い ほど 高い**。はじく 強さ は ふりはば（大きさ）だけ | 中学校理科 教科書「音の性質」（モノコード） |
| コップを たたく | `f = f0 / √(1 + α(h/H)⁴)`（f0 = 1000Hz, α = 3）：**水が 多い ほど 低い** | A. P. French, "In vino veritas: A study of wineglass acoustics", *Am. J. Phys.* 51, 688 (1983) |
| コップを ふく | 片方が 閉じた 管 `f = c / 4L`（L = 空気の 柱 ＋ 口の 補正 0.6r）：**水が 多い ほど 高い**（たたく ときと 逆） | 気柱共鳴（高校物理の 標準的な 式） |
| かみなり | 光は ほぼ 一瞬。秒 × 340m ＝ きょり。ゴロゴロが 聞こえたら すぐ 建物・車の 中へ | 気象庁「雷から身を守るには」 |
| やまびこ | おくれ ＝ 2 × きょり ÷ 340 | — |

合成音の 周波数は すべて `physics.js` の 式から 計算し、`tests/physics.test.js` で
「短い→高い」「張り↑→高い」「強さで 高さは かわらない」「たたく: 水↑→低い」「ふく: 水↑→高い（逆）」
「ドレミが 水の 量で ぜんぶ 作れる」「音速の 数値」「音量の 上限」 を たしかめて います。
わゴムの 音は カープラス・ストロング法（ほんとうに ふるえる 弦を 計算して 音に する）。

## 耳を まもる

- 音量 スライダー（0〜100）は 内部で 最大 0.5 倍まで（`OtoPhys.MAX_GAIN`）。さらに コンプレッサー（リミッター）を 通す
- ホームと せってい に「スピーカーや イヤホンを 耳に くっつけない」ひとこと。🔊 で オン/オフ

## マイク（じっけん 7）

- ⚙️ せってい の 保護者むけ 説明を 読んで 同意 チェック を した ときだけ「🎤 マイクで ためす」が 出る
- `getUserMedia` → `AnalyserNode` で 波形と 大きさを えがく だけ。**録音・保存・送信 しない**、スピーカーにも つながない
- じっけん 7 の 画面を はなれる・アプリを うらに まわす と すぐ トラックを 止めて AudioContext を 閉じる
- マイク なし でも 合成音で 同じ 体験が できる
