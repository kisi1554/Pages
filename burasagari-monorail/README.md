# ぶらさがり モノレール バランス 🚝

レールに ぶらさがって 走る「けんすい式 モノレール」に のって、カーブで かたむく 力（えんしんりょく）を 体験する アクションゲーム（5さい むけ）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

## あそびかた

- モノレールは 自動で すすむ。うしろから 見た 車両の まどに、おきゃくさんの どうぶつ（うさぎ・くま・ぞう・パンダ）。
- カーブで 車両が そとがわへ かたむく。**◀ ひだりへ／みぎへ ▶**（または 画面の 左半分・右半分、キーボードは ←／→）を おして、どうぶつを 反対がわへ あるかせる。
  - おすべき がわの ボタンが ぴかぴか ひかる。下の「まっすぐ メーター」が みどりの あいだなら OK。
- カーブを まっすぐの まま（|かたむき| < 0.26）とおれたら ⭐ ゲット。
- かたむきすぎる（0.44 こえ）と どうぶつが ころころ → ぞうが まどに ぎゅー（ぺちゃんこ）→ すぐ「よいしょ」と おきあがる。ゲームオーバーは なし。
- はやさは 🐢ゆっくり（かたむきも よわい）／🐇ふつう。タイムは 記録だけ。
- けっかの ほし: まっすぐ とおれた カーブの わりあい 8わり以上 ⭐⭐⭐、45% 以上 ⭐⭐、それいがい ⭐（ゴール すれば かならず ⭐1つ）。

わらいどころ: カーブの たびに みんなで「おっとっと〜」／ころがった ぞうが まどに ぎゅーっ／したの 道を 走る くるまの 上の 犬が「なんで ぶらさがってるの？」→ うさぎ「そういう モノレール なの〜」。

## たしかめた 事実（湘南モノレール・千葉都市モノレール 公式 ほか）

- 湘南モノレール 江の島線: 大船〜湘南江の島 8駅・6.6km の 懸垂式（サフェージュ式）。1970年3月7日 大船〜西鎌倉 開業、1971年7月 湘南江の島まで 全通。トンネルを 2つ 通る（目白山下〜湘南江の島 の トンネルが 有名）。
- 千葉都市モノレール: 1号線 千葉みなと〜県庁前 6駅・約3.2km、2号線 千葉〜千城台 13駅・12.0km。営業距離 15.2km は 懸垂型モノレールとして 世界最長で ギネス世界記録に 認定。1988年3月28日 スポーツセンター〜千城台 で 最初に 開業。
- 懸垂式（ぶらさがり）と 跨座式（またがり）。東京モノレールは 跨座式。

会社の ロゴ・公式マーク・車両の 公式デザイン・発車メロディは 使わない。車両は 色・形を にせた オリジナル（しょうなん: ミントと しろ／ちば: しろに オレンジの おび）。江の島も オリジナルの シルエット。

## しくみ

- かたむき: `a'' = 6.5 (目標 − a) − 2.3 a'`、目標 = −カーブ × (速さ/16) × 0.58 + どうぶつの いち × 0.55。
- 画面は うしろから 見た 擬似3D（カーブ・さかを サンプルして 投影）。
- 進捗は localStorage `burasagari-monorail.v1`（クリア・ほし・カード・はやさ・おと）。
- URL に `#debug` で `window.__bm`（`startCourse(k)`, `warp(s)`, `press(id, dir)`, `G`）。
