# かつどうしゃしんの べんしさん 🎬

**おとの ない しろくろ えいが（かつどうしゃしん）に、よこで おとと セリフを つける「おと あわせ」ゲーム。**
15本シリーズ「じだい たんけん」の たいしょう じだい編（5才〜）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし・音は WebAudio の合成音のみ）。

公開URL: https://kisi1554.github.io/Pages/taisho-benshi/

## あそびかた

1. えいがを 1ぽん えらぶ（5ほん・1ぽん 約50びょう）。
2. えいがの 下の フィルムを ⭐ が ながれてくる。⭐ が あかい「いま」の せんに きたら（スクリーンの右上に ❗ も出る）、
   ばめんに 合う **おとボタン**（絵＋もじ: 🚪ばたん！・🔔ちりりん…）や **セリフの ふだ**（「まてー！」…）を おす。
3. ぴったり → 🙆 スタンプ＋おきゃくさんが はくしゅ。
4. ちがう ボタン → 🙅 おきゃくさんが ひっくりかえって おおわらい、えいがの 人が こっちを 見て「？」、
   ぞう・にわとりの ボタンなら スクリーンに ぞうが のぞく。→ フィルムが まきもどって もういちど（2回目は さかさまに まわる）。
5. おさないまま すぎる → 「しーん…」→ まきもどして もういちど。2回 まちがえると 正しい ボタンが 光る。
6. おわると ★1〜3（いっぱつで ぴったりの 数）と まなび カード。「🐢 ゆっくり」で 0.72ばいそく。

タイミングの まどは きっかけの 1.3びょう前〜1.7びょう後（5才むけに ひろめ）。きっかけと 関係ない ときに おしても
ペナルティは なく、えいがの 人が あきれた顔で こっちを 見るだけ。

## シリーズ共通

- 画面下に じだいの ものさし（じょうもん〜れいわ の15）を出し、「たいしょう」を光らせる。
- けっか画面で「つぎは どんな じだい？」→ しょうわ じだいを 1文 予告。
- 実在の人物は登場させない。年号は保護者むけメモにだけ書く。

## しくみ

- えいがは `FILMS` の データ（せっと の HTML ＋ やくしゃ ごとの キーフレーム `[時刻, x%, y%, {r, o, sx, f, sc}]`）で動く。
  時刻から いつでも 同じ 絵が 出るので、まきもどしは 時刻を さかのぼるだけ。
- しろくろ・ちらつき・きずは CSS（`filter: grayscale sepia` ＋ アニメーション）。
- 保存は localStorage `taisho-benshi-v1`（★の 最高、カード、ゆっくり、おと）。読み書きは try/catch。
- ズーム対策は `python3 tools/no-zoom.py taisho-benshi` の共通ブロック。
