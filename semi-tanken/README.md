# セミたんけん 🪳

**5さい向け**の、セミの生態が学べるアプリです。
`index.html` をブラウザで開くだけであそべます（ビルドもサーバーも不要）。

- 文字は **ぜんぶ ひらがな・カタカナ**。字が読めなくても、あんない役の
  **「せみのすけ」が ぜんぶ 読み上げます**（画面が変わるたびに自動で しゃべります）。
- **なきごえは 7しゅるい ぜんぶ その場で 音を合成**しています（音源ファイルなし）。
- まちがえても おこられません。なんども やりなおせます。
- みつけたセミは **ずかんに ほぞん**されます（同じ端末のブラウザに記録）。

## 4つの あそびかた

| モード | なにが わかる | あそびかた |
| --- | --- | --- |
| 🌱 **セミの いっしょう** | たまご → ようちゅう → 土の中 → うか → 成虫 の 一生 | 8つの ばめんを タップして すすむ |
| 🔊 **なきごえクイズ** | 鳴き声と セミの すがたが むすびつく | 鳴き声を きいて 4つから えらぶ（ぜんぶで 8もん） |
| 🌳 **セミとり たんけん** | どんな セミが いるか・ぬけがら | はっぱを タップして さがす（見つけると ずかんに 登録） |
| 📔 **セミずかん** | 大きさ・鳴く時期・いる場所・土の中の年数 | カードを タップして しょうさいを みる |

### セミの いっしょう（8ばめん）

1. きの えだの なかの たまご
2. うまれて じめんへ おちる
3. **つちを タップして** もぐる
4. **ねっこを タップして** 土の中で 6年かけて そだつ
5. **タップして** 夕方 地上に でて 木に のぼる
6. **4かい タップして** うか（背中が われる）
7. はねが のびて、白い体に いろが つく（アニメーション）
8. **タップすると なく**（アブラゼミの 鳴き声）

## おうちの方へ

- **音が出ます。**端末の音量をご確認ください。右上の 🔊 ボタンで
  「よみあげ」「なきごえ」「こうかおん」を 個別にオフにできます（静かな場所でも遊べます）。
- **鳴き声は録音ではありません。**Web Audio API でセミの声に似せて合成しているため、
  本物とは少し違います。実物の声とくらべてみるのも面白いと思います。
- **読み上げ**はブラウザの音声合成（日本語）を使っています。日本語の音声が入っていない
  端末では読み上げされませんが、文章はすべて画面に表示されるので遊べます。
- 土の中で過ごす年数は種によって幅があります。代表的な年数を「だいたい」として紹介しています。
- 成虫の寿命は「1週間」とよく言われますが、近年の調査では2〜4週間ほど生きることが
  わかっています。アプリ内では「なつの あいだ」という表現にしています。
- 鳴くのはオスだけで、腹部の発音膜を震わせて音を出します。
- 進み具合（みつけたセミ・クイズの記録）は端末のブラウザに保存されます。
  別の端末やシークレットウィンドウでは引き継がれません。
