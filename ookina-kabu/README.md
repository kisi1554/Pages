# うんとこしょ！ おおきなかぶ ― ゆびで ひっぱる えほん 🌱

むかしばなし「おおきなかぶ」を、**ゆびで ひっぱって すすむ えほん** に しました。
おじいさんが まいた たねが とてつもなく おおきな かぶに なり、おばあさん・まご・いぬ・ねこ・ねずみ と
ひとりずつ なかまが ふえて、さいごに みんなで「うんとこしょ、どっこいしょ！」で ぬきます。
対象は 未就学〜小学1年。全9ページ。

`index.html` をブラウザで開くだけで あそべます（ビルドもサーバーも不要）。
絵は SVG、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。
文は ひらがなだけ（漢字なし）で、ことばの あいだを スペースで くぎっています。

## おはなし と しかけ

| ページ | おはなし | しかけ |
| --- | --- | --- |
| 1 | おじいさんが たねを まく | つちを 3かい タップ → じょうろで みず → め が でる |
| 2 | かぶが そだつ | かぶを タップ（うえに なぞっても よい）4かい → どんどん おおきく なる |
| 3 | おじいさんが ひっぱる | **みぎへ ひっぱる** 2かい →「ぬけません」 |
| 4〜7 | おばあさん → まご → いぬ → ねこ を よぶ | まって いる なかまを タップ → あるいて きて れつに ならぶ → ひっぱる →「ぬけません」 |
| 8 | ねずみを よぶ | ひっぱる → **ちから メーター が 4つ たまると すっぽーん！**（みんな すってんころりん → ばんざい） |
| 9 | かぶの スープ | おなべを タップ →「いただきます！」 |

よぶ ページの 文は「ねずみが ねこを ひっぱって、ねこが いぬを ひっぱって、…」と 1ぎょうずつ のびていく
くりかえし（つみあげうた）に なっています。文は この アプリの ために かいた オリジナルです。

## ひっぱる しくみ（`pull.js`）

- 絵の うえに ゆびを おいて **みぎへ** うごかすと、みんなが のけぞって かぶが すこし もちあがります。
  ぐいっと ひっぱりきると 1かい「うんとこしょ！」（つぎは「どっこいしょ！」）。ゆびを もどすか はなすと、もう 1かい ひっぱれます。
- **マルチタッチ**: ゆびは なんぼん おいても よく、みぎへ ひっぱって いる ゆびの かずが そのまま ちからに なります。
  さいごの ページは ちから 4 で ぬけるので、ゆび 1ぽんなら 4かい、**かぞく 2にんで 2ほんなら 2かい** で ぬけます
  （「👆×2 ちから 2ばい！」と でる）。
- パソコンでは マウスの ドラッグ か キーボードの → でも ひっぱれます。
- 絵には `touch-action: none` を つけて、ひっぱっても がめんが うごいたり 拡大したり しない ように しています。

## そのほか

- **よみあげ**: ページを ひらくと speechSynthesis で 1ぎょうずつ よみ、よんで いる ぎょうを 黄色く ひからせます。
  🔁 で もういちど。しかけを さわると よみあげは とまります。
- **🇬🇧 English ⇄ 🇯🇵 にほんご**: ほんの したの ボタン（ひょうし にも あり）で、文と よみあげを いつでも きりかえられます。
  おしたら でている 文が ぜんぶ その ことばに かわり、はじめから よみなおします（英語は en-US の こえ）。
  しかけの ヒント・ふきだし（うんとこしょ！ → Heave! / Ho!）も きりかわります。えらんだ ことばは 保存されます。
  英文は `story.js` の 各行 `{ ja, en }` の `en`（この アプリ用に かいた もの）。
- 🎵 おと（BGM・効果音）と 🗣 よみあげ は べつべつに オン/オフ できます（ひょうし と ほんの 上の バー）。
- しかけが おわるまで「🔒 つぎ」。いちど おわった ページは つぎから すぐ すすめます。
- **しおり**: とちゅうで やめても ひょうしの「🔖 つづき から」で つづきを よめます。
  しおり・おわった ページ・せってい・ぬいた かず は その端末の `localStorage` にだけ 保存します。
- たてもち は 絵の したに 文、スマホ よこもち は 絵と 文を よこに ならべます。絵は いつも 8:5。

## たしかめかた

```bash
node tools/ookina-kabu/check.js /tmp/shots
```

Playwright で たて（390×844）・よこ（1024×768）・スマホよこ（844×390）を 開き、
全ページの しかけを こなして おしまい まで すすむこと、さいごの ページを **ゆび 2ほん**（CDP の タッチ）で ひっぱると
ちからが 2ばいに なること、絵が がめんから はみださないこと、JS エラーが ないことを たしかめ、スクショを 保存します。
