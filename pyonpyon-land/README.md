うさぎの「ぴょんた」たち 3にんの なかまが はしって とんで、ゴールの はたを めざす よこスクロールの アクションゲームです（未就学〜小学生むけ）。
`index.html` をブラウザで開くだけで遊べます（外部ライブラリなし）。

## あそびかた

- ◀ ▶ で あるく、**ジャンプ** で ぴょん。ながおしすると たかく とべる。
- **？ブロック** を したから たたくと コイン、ときどき **きのこ** が でる。きのこを とると おおきくなって、レンガを こわせる。
- てき（むらさきの「もぐもぐ」）は うえから ふむと やっつけられる。よこから ぶつかると ちいさくなる／みす。
- あなに おちたり、ちいさい ときに ぶつかったりすると **みす**。ゲームオーバーは なく、さいごに たっていた ばしょから すぐ やりなおせる。
- **どかん**: ▼ の めじるしが ついた どかんの うえに のると「▼ はいる」ボタンが でる（キーボードは ↓）。
  なかは コインが いっぱいの ひみつの へや。でぐちの どかんから はいると、さきの どかんから でてくる。
- ゴールの はたに さわると クリア。みすの かずで ⭐ が きまる（0かい ⭐⭐⭐ ／ 3かいまで ⭐⭐ ／ それいじょう ⭐）。

## こえ

ブラウザの よみあげ（Web Speech API）で キャラクターが しゃべる。こえの たかさと はやさは なかまごとに ちがう。
スタート・てきに はじめて あった とき・きのこ・どかん・ボス・ゴール・みす などで しゃべる。みぎうえの 🗣 で オン／オフ。
にほんごの こえが ない ブラウザでは しゃべらない。

まえの ステージを クリアすると つぎが あそべる。クリア・⭐・コインの さいこうきろくは localStorage に ほぞん。

## スマホでの そうさ

- がめんの したに おおきな ボタン（ひだり：◀ ▶、みぎ：ジャンプ）。マルチタッチで あるきながら ジャンプできる。
- ゆびを ◀ から ▶ へ すべらせても きりかわる。いっしゅんの タップでも ジャンプする。
- ジャンプは「ちょっと はやめ／ちょっと おそめ」に おしても とべるように ゆうよが ある。
- たてもち：ゲームがめんの したに ボタン。よこもち：がめんの うえに はんとうめいの ボタン。
- キーボード：← → / A D で あるく、スペース / ↑ / Z で ジャンプ、Esc で ていし。

## おと

WebAudio の ごうせいおんのみ。みぎうえの 🔊 で オン／オフ（BGM も いっしょに きえる）。

- **BGM**: ステージごとに オリジナルの きょく（はらっぱ＝げんきな ハ長調、ゆうやけ＝のんびりした イ短調、
  どうくつ＝ふしぎな ニ短調、どかんの へや＝はやい ボーナスきょく）。`SONGS` に 8ぶんおんぷ ずつ かいて ある。
- **みすの おと**: BGM が とまって ぴたっと かたまり →「ぴょっ」→ かなしい メロディで とびあがって おちる →「ぼん・ぼーん」。
