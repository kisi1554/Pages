# しずくの だいぼうけん 💧

水の しずく「ぽた」と いっしょに、**海 → 空 → 雲 → 雨・雪 → 川・地下水・まち → 海** と
地球を めぐる 理科あそび（年長〜小学校中学年）。
小4 理科「金属、水、空気と温度」（水の すがた）・「雨水の行方と地面の様子」・「天気の様子」の 予習 に なるように 作って います。
`index.html` を ひらくだけで うごきます（外部ライブラリ・CDN なし、音は WebAudio の 合成音だけ）。

## あそびかた

### 1. 🗺️ たび（すごろく）

大きな 断面図（海・空・山・川・まち・地下水）の 上で、場面ごとの しかけを うごかして ぽたを すすめる。
カメラが 場面ごとに 寄り、「🗺️ ぜんたい」で 地図 全体と とおった みち（赤い 点線）が 見られる。

| 場面 | しかけ | わかること |
| --- | --- | --- |
| 🌊 海 | たいようを こする（タップでも OK） | あたためられた 水は 目に 見えない **水じょうき** に なる（じょうはつ）。ぽたは **点線の りんかく だけ** に なる |
| 💨 空へ | ぽたを 上へ ドラッグ（ボタン長おしでも OK）。左の 温度計が 高さと 温度を 表示 | 上へ いくほど 寒い（100m で やく 0.6℃）。ひえた 水じょうきは 小さな **水の つぶ** に もどる |
| ☁️ 雲 | 💧 水の つぶ・❄️ 氷の つぶ を ドラッグで あつめる | 雲は 小さな 水や 氷の つぶの あつまり（水じょうき では ない）。0℃ の 高さを 点線で 表示 |
| 🌧️ 雨？❄️ 雪？ | 「地面ちかくの 温度」スライダー → ふらせる | 1℃ 以下 → 雪、2〜3℃ → みぞれ、4℃ 以上 → 雨（目安）。0℃ の 高さより 下で 雪が とけて 雨に なる |
| 🏔️ 山で ふゆ | きせつ スライダーで はるへ | 山に つもった 雪は 春に とけて 川の 水に なる（雪どけ水） |
| 🛤️ ルート を えらぶ | 3つ から えらぶ | |
| 🏞️ かわ ルート | 川に そって ゆびで なぞる | 水は 高い ところ から 低い ところ へ ながれて あつまる。山の 中は はやく、たいらな ところは ゆっくり |
| 🟫 ちかすい ルート | すな／ねんど を タップ → 地下水の 層を なぞる → わき水 → 川 → 海 | つぶが 大きい（すな）ほど しみこみやすい。ねんどの 層は 水を とおしにくい |
| 🏙️ まち ルート | ダムの すいもん → 浄水場の タンク ①ちんでん ②ろか ③しょうどく（じゅんばん）→ じゃぐち → 下水処理場 → 海 | 水道の 水の 通り道。使った 水は 下水処理場で きれいに してから 川や 海へ |

海に もどると 1周。ルートごとの スタンプ（＋ 雪の みち を 通ったら ❄️ スタンプ）。

### 2. 🧪 じっけん室

ビーカーの 水 100g を 🔥 あたためる（ガスこんろ）／ ❄️ ひやす（氷＋食塩の 寒剤）。⏩ で はやおくり（1秒 ＝ 6分）。

- 温度計・「かさ」の 目盛り（90〜115mL を 拡大した ルーペ つき）・すがた・**温度の グラフ**（よこ: 加熱 時間、たて: 温度）
- **0℃ で こおる／とける**。こおって いる（とけて いる）あいだ 温度は 0℃ の まま
- **こおると かさが ふえる**（100g の 水 → やく 109mL）。びんが われる 演出は せず 目盛りで 見せる
- 40〜90℃ の 小さな あわ ＝ 水に とけて いた 空気、**100℃ ちかくで わきたつ。大きな あわの 正体は 水じょうき**
- **ふっとう 中は 温度が 100℃ で 一定**（グラフが 平らに なる）。水は へって いく
- 湯気: 水面の すぐ上の すきとおった ところ ＝ 水じょうき（見えない）、**白い 湯気 ＝ 水じょうきが 冷えて できた 小さな 水の つぶ**。
  「🥄 スプーンを かざす」と 水てきが つく（湯気 ＝ 水じょうき とは 教えない）
- 「わかった こと」6つ に ✅ が つく。5つ 以上で 🧪 じっけん はかせ スタンプ

熱の 計算（`lab.js`）: 水の 比熱 1 cal/g℃、氷 0.5、融解熱 80 cal/g、蒸発熱 540 cal/g。加熱 900 cal/分（室温への 放熱つき）、
寒剤（−15℃）との 熱の やりとり。水の 体積は 4℃ で 最小（20℃ で 100.1mL、100℃ で やく 104mL）、氷は 1.091 mL/g。
過冷却は あつかわない。

### 3. ❓ ふしぎ クイズ（10問）

コップの まわりの 水（結露）／せんたくもの（蒸発）／湯気の 正体／わきたつ あわ／こおると かさ／0℃／ふっとう中の 温度／雲／しみこみ方／地球の 水。
8問 以上 正解で 🎓 クイズ はかせ スタンプ。
