# やまのてせん ぐるぐる ドーナツ 🍩

やまのてせん（JR山手線）の **30えきの じゅんばん** と、えきめいの **かんじの よみ** を、
わっかの パズルで おぼえる アプリ（5さい〜）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

| モード | なかみ |
| --- | --- |
| レベル1 | あなは 3つ。東京・品川・渋谷・新宿・池袋・上野 は さいしょから 見える |
| レベル2 | あなは 10こ |
| レベル3 | ぜんぶ あな（30えき） |
| はやおし | でんしゃが とまった えき（？）の なまえを 3つから えらぶ・6もん。4びょう いないなら「⚡ はやい！」 |
| どっち まわり？ | ⭐から 🏁まで、そとまわり（↻）と うちまわり（↺）の どっちが はやいか あてる・5もん。えきの かずで くらべる |
| ごほうび | ふりがなを ぜんぶ かくして、とまった えきの よみを 3つから えらぶ（レベル2 か 3を クリアで ひらく） |

- カードは ドラッグでも、タップ →「？」タップ でも はめられる。おなじ カードで 2かい まちがえると、ただしい あなが ひかる。
- ぜんぶ うまると、うぐいすいろの でんしゃが オリジナルの しゅっぱつメロディで 1しゅう はしり、とまる えきを ひからせる。
- ふりがなは レベル1〜3・はやおし・どっちまわり で いつも でる。
- 🚄 = しんかんせんに のりかえ できる えき（東京・品川・上野）。

## わらい どころ（こたえあわせの あと）

- ちがう あなに はめると、おきゃくさんが まどから かおを だして「ここ どこ〜？」
- 「もう 1しゅう」で なんしゅうも まわると、でんしゃが めを まわして ふらふら（3しゅうめから @_@）
- どっちまわりの こたえあわせは、そとまわりと うちまわりの でんしゃの かけっこ。かったほうが「おさきに〜！」

## えきの データ

`index.html` の `STATIONS` 配列 1かしょだけに かいている（JY01 東京 → JY30 神田、駅ナンバーの じゅん）。
JY01 → JY02 → … の むき（ちずの うえで とけいまわり）が **そとまわり**。高輪ゲートウェイ（JY06）も はいっている。
リポジトリの `eki-song/data.js` の 山手線データと 1えきずつ くらべて 一致を たしかめた。

- ばんの ならびは ちずの むきに あわせる: 東京は みぎ（ひがし）、品川は みぎした、渋谷・新宿は ひだり、池袋は ひだりうえ、上野は みぎうえ。
- 鉄道会社の ロゴ・ラインカラーの マーク・駅ナンバーの 表示・じっさいの 発車メロディは つかわない。でんしゃの 絵は オリジナル。
- `eki-song/`・`eki-uta/` は えきめいを うたう アプリ。この アプリは わっかの じゅんばんパズル なので かぶらない。
