# やまのてせん ぐるぐる ドーナツ 🍩

やまのてせん（JR山手線）などの **えきの じゅんばん** と、えきめいの **かんじの よみ** を、
わっかの パズルで おぼえる アプリ（5さい〜）。

## えらべる せん

| せん | えき | かたち |
| --- | --- | --- |
| 山手線 | 東京（JY01）〜 神田（JY30）・30えき | わっか（どっちまわり モードあり） |
| 京浜東北線 | 大船（JK01）〜 大宮（JK47）・47えき | はしから はしまで |
| ブルーライン | 湘南台（B01）〜 あざみ野（B32）・32えき | 〃 |

わっかで ない せんは、ドーナツの うえの まんなかが 1〜2マス きれていて、そこが はしと はし。
クリアすると でんしゃが はしから はしまで はしる（もう いっかい はしると ぎゃくむき）。
はやおしでは はしに つくと おりかえす。⭐は せんごとに のこる。

## 🗣️ よみあげ

ブラウザの 音声合成（speechSynthesis・ja-JP）で えきめいを よみあげる（音声ファイルは つかわない）。
上の 🗣️ ボタンで オン/オフ（localStorage に のこる。音声合成が ない ブラウザでは ボタンを かくす）。

- えきの マスを タップ／カードを えらぶ／ただしく はめる → その えきを よむ
- ぜんぶ うまった あとの 1かいめの はしりは、でんしゃが 1えきずつ とまって よむ。よみおわってから つぎの えきへ（onend が こない ブラウザでも じかんぎれで すすむ）
- はやおし・ごほうびは こたえた あとに よむ（さきに こたえを いわない）。よみおわってから でんしゃが うごきだす
- どっちまわりは もんだいと かったほうを よむ

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## わらい どころ（こたえあわせの あと）

- ちがう あなに はめると、おきゃくさんが まどから かおを だして「ここ どこ〜？」
- 「もう 1しゅう」で なんしゅうも まわると、でんしゃが めを まわして ふらふら（3しゅうめから @_@）
- どっちまわりの こたえあわせは、そとまわりと うちまわりの でんしゃの かけっこ。かったほうが「おさきに〜！」

## えきの データ

`index.html` の `LINES` 配列 1かしょだけに かいている（駅ナンバーの じゅん）。
`'{漢字|よみ}かな'` で 一部だけに ふりがな、`\n` で マスの なかで 改行（高輪ゲートウェイ・伊勢佐木長者町 など）。
JY01 → JY02 → … の むき（ちずの うえで とけいまわり）が **そとまわり**。高輪ゲートウェイ（JY06）も はいっている。
どの せんも リポジトリの `eki-song/data.js` の データと おなじ。新幹線 🚄 は 山手線（東京・品川・上野）、京浜東北線（品川・東京・上野・大宮）、ブルーライン（新横浜）。

- ばんの ならびは ちずの むきに あわせる: 東京は みぎ（ひがし）、品川は みぎした、渋谷・新宿は ひだり、池袋は ひだりうえ、上野は みぎうえ。
- 鉄道会社の ロゴ・ラインカラーの マーク・駅ナンバーの 表示・じっさいの 発車メロディは つかわない。でんしゃの 絵は オリジナル。
- `eki-song/`・`eki-uta/` は えきめいを うたう アプリ。この アプリは わっかの じゅんばんパズル なので かぶらない。
