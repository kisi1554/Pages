# ありの す たんけん 🐜

じめんの したの **ありの す を よこから のぞく 観察ケース** ふうの シミュレーションです。
年長〜小学生（むし ずき）むけ。`index.html` を ひらく だけで あそべます（外部ライブラリ・CDN なし、Canvas 描画）。

`mushi-zukan/`・`semi-tanken/`・`kabuto-sodate/` と テーマは 近いですが、
こちらは **「むれで くらす 社会」と それを うごかす シミュレーション** が 主役です。

## あそびかた

1. はじめに そだてる しゅるい（**クロオオアリ** か **クロヤマアリ**）を えらぶ。
   さいしょは **じょおうあり 1ぴき と はたらきあり 5ひき**、じょおうの へや だけの 小さな す。
2. はたらきありは **じぶんで うごく**:
   - トンネルを **ほる**（土の つぶを 1つずつ 外へ はこんで、いりぐちの よこに すてる → 土の やまが できる）
   - **へや**を つくる（じょおう・たまご・ようちゅう・さなぎ・えさ・ふゆごし の へや。なかまが ふえると つぎの へやを ほりはじめる）
   - **えさを さがす**・**こそだて**（たまご・ようちゅう・さなぎを ちょうど よい へやへ はこぶ、ようちゅうに ごはんを あげる）
3. えさ（🍬 さとう・🍞 パンくず・🦗 むし）を えらんで **じめんの うえを タップ**。
   見つけた ありが 巣へ もどる とき **においの みち** を のこし、ほかの ありが たどって **ぎょうれつ** が できる。
   においは じかんで きえる。👃 ボタンで においの みち を ピンクで 見える化。
4. じょおうが たまごを うむ → ようちゅう（はたらきありが ごはんを あげる）→ さなぎ（まゆ）→ はたらきあり。
   えさが たくさん あると なかまが ふえる（さいだい 300ぴき）。
5. できごと: 🌧️ **あめ**（ありが いりぐちを 土で ふさぐ → やんだら ほって あける）、
   🕷️ **てき**（クモ・アリジゴク。ありは ちかづかない ように よけるだけ。たたかう 表現は しない）、
   ❄️ **ふゆ**（ふかい へやに あつまって じっと する。はるに なると また うごく）。
   きせつは じかんで めぐり（はる→なつ→あき→ふゆ）、あめ・てき も ときどき おこる。
6. ありを **タップ** すると「いま なにしてる？」（はこんでる・ほってる・せわ してる …）を ふきだしで。
   🔍 **むしめがね** を オンに して タップすると、からだの つくり（あたま・むね・はら、あし 6ぽん、しょっかく）を 大きく 見られる。
7. 📖 **ずかん**（10しゅるい）と 🏅 **きろく**（へやの かず・ありの かず・バッジ 13こ）。

す の ようすは この端末の ブラウザ（localStorage）に 保存され、つぎに ひらくと つづきから。
**とじていた じかんぶん すこし すすみます**（20びょうで 1びょうぶん、上限 150びょうぶん）。

## しくみ（シミュレーション）

| ファイル | なかみ |
| --- | --- |
| `sim.js` | せかい（100×100 の グリッド）・ありの しごと・こそだて・きせつ・できごと・保存。DOM に さわらない |
| `render.js` | Canvas 描画。土の断面は オフスクリーンに かいて ほった ところだけ かきなおす。ありは むき24×あし6コマ の えを さきに つくって drawImage |
| `app.js` | ボタン・タップ・おしらせ・保存・ループ |
| `data.js` | ずかん 10しゅるい・バッジ・からだの せつめい |
| `audio.js` | こうかおん（ほる さくさく、えさを 見つけた ぴこっ など）。WebAudio 合成、🔊 で オン/オフ |

- **だれが 何を するか**（しくみ）は 本物に あわせた。数字（ふえる はやさ・へやの 大きさ）は あそびやすさ 優先。
  - たまごを うむ のは じょおう だけ。はたらきありは みんな メスで、ほる・はこぶ・こそだて・えさあつめ を する。
  - **わかい はたらきあり ほど 巣の なか**（こそだて）、**としうえ ほど 外**（えさあつめ）を うけもつ（齢差分業）。
  - においの みち を のこすのは **えさを 見つけて 巣へ もどる あり** だけ。外へ でる ありは みちを たどる。
  - なかまが 40ぴき を こえると、はるに うまれる たまごの いくつかが **はねの ある オスと あたらしい じょおう** に なり、
    なつに **けっこんひこう** で とびたつ（巣には もどらない）。
  - クロオオアリ・クロヤマアリ（どちらも ヤマアリ亜科）は さなぎが **まゆ** に はいる。
- **あり 300ぴき でも かるい**: 「巣の いりぐち」「ほる ばしょ」「各へや」まで の きょりの ば を BFS で つくり、
  ありは となりの マスの うち きょりが ちいさい ほうへ すすむ だけ。においは グリッド上の ば（`pher`）で、3チックごとに へる。
- テスト用に `window.__ari`（`step(n)`・`spawn(n)`・`food(x, type)`）を だしている。

おもな 事実と アプリでの あつかい:

| 事実 | アプリでは |
| --- | --- |
| はたらきありは ぜんぶ メス、はねが ない | むしめがね・ずかんで せつめい |
| オスは はねが あり、結婚飛行の ころ だけ 出る | 40ぴき いじょうの 巣で はるに うまれ、なつに とびたつ |
| 女王は 結婚飛行の あと はねを おとし、長生き（10年いじょう も） | じょおうの せつめい |
| かんぜんへんたい（たまご→ようちゅう→さなぎ→成虫） | そのまま。ようちゅうは はたらきありが ごはんを あげないと そだたない |
| 道しるべフェロモン（においの みち） | 見つけた ありが かえりみちに のこし、時間で きえる。あめで ながれる |
| 冬は 巣の ふかい ところで じっと すごす | ふゆごしの へやに あつまり うごかない。たまごも うまない |
| クロオオアリは 5〜6月の 夕方に 結婚飛行、開けた 地面に 巣 | ずかん |
| クロヤマアリは サムライアリに さなぎを 奪われる ことが ある | ずかん（サムライアリ・クロヤマアリ） |
| アミメアリには 女王が いない | ずかん |

単純化している ところ: はたらきありの 寿命（本物は 1〜2年ほど）は あつかわない／すべての 種が 雨の まえに
いりぐちを ふさぐ わけでは ない／「えさの へや」は 見やすさの ため（クロオオアリは えさを そのう に ためて
なかまに くちうつし する）／ありの「むね」は 正確には はらの 1節めを ふくむ（中体節）が、こども むけに あたま・むね・はら と した。

## おうちの方へ

- 音が出ます（右上 🔊 で オフ）。
- データは この端末の ブラウザに だけ 保存されます。「きろく」→「あたらしい すを つくる」で やりなおせます（バッジは のこります）。
- 意図しない 拡大（ピンチ・ダブルタップ）は とめています（`tools/no-zoom.py`）。
