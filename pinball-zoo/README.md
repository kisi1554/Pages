# ころころ ピンボール どうぶつえん 🦁

どうぶつえん が まるごと ピンボール だい に なった！ フリッパー で ボール を はじいて、
**ゾウ の はな・キリン の くび・ペンギン の すべりだい** に あてる と、どうぶつ が うごいて ボール を とばす。
どうぶつ を ぜんぶ「おきて」もらう と よる の だい に なり、よる の どうぶつ も おこす と パレード（年長〜小学6年）。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。だい は canvas、え は 絵文字 と コード、おと は WebAudio の 合成音）。

公開URL: https://kisi1554.github.io/Pages/pinball-zoo/

## あそびかた

| そうさ | なにが おきる |
| --- | --- |
| がめん の ひだり はんぶん を タップ／おしっぱなし | ひだり の フリッパー（マルチタッチ で りょうほう どうじ も OK） |
| がめん の みぎ はんぶん | みぎ の フリッパー |
| ばね（みぎ した の レーン）を した へ ひっぱって はなす | うちだし。ひっぱる ながさ（か、おしている じかん）で つよさ が かわる。だい に ボール が ない とき は みぎ はんぶん の どこ でも ばね に なる |
| キーボード | ← / Z ＝ ひだり、→ / `/` ＝ みぎ、スペース / ↓ / Enter を おして はなす ＝ うちだし、Esc / P ＝ ひとやすみ |

## しかけ と どうぶつ

| しかけ | うごき | おきる まで |
| --- | --- | --- |
| 🐘 ゾウ の はな | はな に はいる と すくって うえ へ ぽーん（+500） | 3かい |
| 🦒 キリン の くび | した から いきおい よく はいる と、くび が レール に なって うえ の しま へ（+1000） | 2かい |
| 🐧 ペンギン すべりだい | こおり の ループ を ぐるっと。くぐる たび に ペンギン が 1わ ずつ ふえる（+800） | 3かい |
| 🐒 サル の ぶらんこ | ゆれる バンパー。あたる と よこ に とばされる（+200） | 4かい |
| 🦁 ライオン の おり | 3かい で「がおー」→ マルチボール（3こ）。おきた あと も 3かい ごと に また マルチボール | 3かい |
| 🐢 カメ の あみ | ときどき した の すきま に でて きて、おちる ボール を 1かい だけ うけとめる | 1かい |
| 🍎🍌🍉 えさ の バンパー | ぽよん（+100） | — |

- 6しゅ ぜんぶ おきる と **よる の だい**（ライト が ひかる、とくてん 2ばい）。🦉 フクロウ（えだ）と 🦇 コウモリ（とびまわる バンパー）を 3かい ずつ。
- よる の どうぶつ も おきる と **どうぶつえん パレード** → あさ に なって 2しゅうめ（ボール +1、おきる まで の かず が 1 ふえる）。

## ルール

- ボール 3こ。ぜんぶ おちたら おしまい。
- **やさしい**: うちだして から 30びょう いない に おちたら もどって くる（HUD に のこり びょう）。カメ も よく でる。
- **ふつう**: もどって くる のは 6びょう いない だけ。
- とくてん は すうじ と ひらがな の よみ（「いちまん にせんさんびゃく てん」）で だす。ハイスコア は モード ごと に ほぞん。
- とまって しまった ボール は 2びょう で 「ゆらゆら〜」と ゆらして うごかす。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `physics.js` | DOM なし の ぶつり。ボール（えん）と せんぶん・えん（うごく もの も）・フリッパー の しょうとつ。**1フレーム を 8 サブステップ** に わけて すりぬけ を ふせぐ。フリッパー の かくそくど × うで の ながさ を ボール に つたえる。かた がわ だけ の かべ（レーン の ふた）、ボール どうし |
| `table.js` | DOM なし の だい と ルール。だい は 400×700。どうぶつ・とくてん・マルチボール・よる・パレード・カメ・もどる ボール。すうじ → ひらがな の よみ（`yomi`） |
| `app.js` | canvas で かく（60fps、ひる／よる）、タッチ（Pointer Events、マルチタッチ）・キーボード、HUD・ずかん、localStorage |
| `audio.js` | WebAudio の 合成音。フリッパー の かちゃ、バンパー の ぽよん、どうぶつ の なきごえ、ファンファーレ、オリジナル の サーカス ふう BGM（よる は しずか な アレンジ） |
| `style.css` | たて がめん は うえ に スコア と ずかん、した に だい。よこ がめん は まんなか に だい、ひだり に スコア、みぎ に どうぶつ ずかん |

おと は 🔊（こうかおん）と 🎵（おんがく）で べつべつ に オン/オフ。

ほぞん（localStorage `pinball-zoo-v1`）: モード ごと の ハイスコア、おと の せってい、どうぶつ を おこした かず。

## テスト

```bash
node pinball-zoo/test.js    # ぶつり と ルール
node pinball-zoo/check.js   # ブラウザ（Playwright）。スクショ は pinball-zoo/shots/
```

- `test.js`: はやい ボール が かべ を すりぬけない（1000かい ランダム）、フリッパー を ふって も すりぬけない、
  フリッパー で うえ に かえせる かくど の はんい、まんなか の すきま、ボール が だい の そと に でない・とまらない
  （40かい × 2ふん ランダム に あそぶ）、うちだし、すうじ の よみ、とくてん・マルチボール・よる・パレード、もどる ボール、カメ。
- `check.js`: たて スマホ・よこ タブレット・よこ スマホ の 3がめん で、うちだし → りょう フリッパー の どうじ タップ（CDP マルチタッチ）、
  れんだ・ピンチ で ズーム しない、よる・パレード・おしまい、ハイスコア ほぞん、JS エラー なし、よこスクロール なし。
