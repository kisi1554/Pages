# 日本一周すごろく

実際の日本地図の上を旅しながら、**お金**・**ひみつのカード100枚**・**目的地**の
3つを追いかける学習すごろくゲーム。小学校低学年向けに、漢字にはすべて**ふりがな**が付く。

`index.html` をブラウザで開くだけで遊べる（ビルドもサーバーも不要）。

- 遊ぶ人数: 1〜4人（プレイヤー＋CPU、合計2〜4人）
- 1プレイの目安: 20〜30分
- 保存: ブラウザの localStorage に自動セーブ（「つづきから」で再開）
- 音: BGM・効果音・読み上げ。音源ファイルは不要（その場で合成する）

---

## 3つの目的

| 目的 | 集めかた | 点数 |
|---|---|---|
| 💰 お金 | クイズの正解・お使い・お店の収益 | 20円 = 1点 |
| 🃏 ひみつのカード | 止まった県で1枚見つかる（全100枚） | 1枚 = 15点 |
| 📍 目的地 | 1年ごとに変わる。一番のりで到着 | 1回 = 200点 |
| 🏪 お店 | 各県で購入。毎年収益が入る | 1軒 = 15点 |

3年（＝24ターン）遊んで、合計点の一番高い人が優勝。

## 遊びかた

1. サイコロを振り、出た数だけ**1マスずつ隣の県へ**進む。緑に光った県をタップして選ぶ
   （直前にいた県へすぐ戻ることはできない。行き止まりだけは例外）。
2. 止まった県で、順番に次のことが起きる。
   1. **ご当地情報** — 県名・県庁所在地・その県の豆知識（読み上げあり）
   2. **ひみつのカード** — その県のまだ持っていないカードを1枚（全部集めていればお金）
   3. **目的地判定** — 一番のりなら 800円＋でんせつカード。2番目以降も 250円（年1回まで）
   4. **お使い判定** — 届け先に着いていれば報酬
   5. **ご当地クイズ** — 3択。正解で 150円
   6. **アクション** — お店を買う／お使いを受ける（最大2件）
   7. **季節のできごと** — 28%の確率。冬の雪国では1回休みなど
3. 2ターンで季節が1つ進む（春→夏→秋→冬）。8ターンで1年。
4. 年の終わりに、持っているお店の収益がまとめて入る。

点線（‥‥）はフェリー・橋・飛行機で渡る道。✓ が付いた県は、カードを全部集め終えた県。
沖縄県は地図の左上の枠に拡大して描いてある。

## カードずかん

集めたカードは**ゲームをまたいで**ずかんに残る（`nippon-sugoroku-dex-v1`）。
1プレイで集まるのは20〜25枚程度なので、100枚コンプリートは長期の目標。

カードは 47都道府県 × 2枚 ＋ でんせつカード6枚 ＝ 100枚。
でんせつカード（富士山・新幹線・縄文杉 など）は、
目的地に一番のりで到着したときだけ手に入る。

## ふりがなの書きかた

データと画面の文字列は `漢字{よみ}` という書きかたをする。`game.js` の `ruby()` が
`<ruby>漢字<rt>よみ</rt></ruby>` に変換して表示し、`plain()` が読み上げ用に外す。

```js
'日本{にほん}で 一番{いちばん} 広{ひろ}い。'   // → 日本(にほん)で 一番(いちばん) 広(ひろ)い。
'高{たか}さ 634{ろくさんよん}メートル'          // 数字にもふりがなを振れる
```

ルビの土台になれるのは**漢字の並び**か**数字**だけ（`RUBY_RE`）。
「空白以外なんでも」にすると HTML のタグや属性まで巻きこんでしまうので、そこは狭めてある。
`1000年{ねん}` のように、数字はルビの外に出して書く。

## 地図について

盤面は `map-data.js`（国土数値情報由来の実際の県境データ）の上に置いている。
`data-prefs.js` の `name` で `map-data.js` の県と突き合わせるので、**県名は完全に一致させること**。

駒を置く位置は、各県の代表点（`lx`, `ly`）から始めて、次の2つを繰り返して決める
（`game.js` の `layoutNodes()`。乱数を使わないので毎回同じ配置になる）。

1. 駒どうしが `MIN_NODE_GAP`（46）より近ければ押し広げる
2. 代表点から `MAX_NODE_MOVE`（32）より離れたら引きもどす

これで最小間隔46・最大ずれ約27に収まり、駒はほぼ自分の県の中に残る。
関東・近畿のようにずれが大きくなる県には、代表点との間に引き出し線を引いている。

隣接関係（`adj`）は陸続きの県に加えて、フェリー・橋・飛行機で行き来する
7つのルート（`SEA_LINKS`）を含む。これで47都道府県が1つにつながっている
（最も遠いのは北海道↔沖縄で16県ぶん）。

### 地図データのつくりかた

`map-data.js` は手で編集せず、生成スクリプトを使う。

```bash
curl -o japan.geojson https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson
python3 ../tools/japan-map/generate_map.py japan.geojson map-data.js
```

元データ: [dataofjapan/land](https://github.com/dataofjapan/land)（国土交通省 国土数値情報の
行政区域データ由来）。メルカトル図法で投影し、沖縄県は左上のインセットへ移動している。

## 音について

`audio.js` は Web Audio API でその場で音を作るので、音源ファイルはいらない。

- **BGM**: 8曲（日本一周／北の大地／瀬戸内クルーズ など）をシャッフルして流す
- **効果音**: サイコロ・1マス進む・正解／不正解・カード入手・お金の増減・
  お店の購入・ファンファーレ・1回休み
- **読み上げ**: ブラウザの音声合成（日本語）で、県の説明・カードの説明・クイズを読む

3つは「🔊 音」ボタンから個別にオン／オフでき、`nippon-sugoroku-sound-v1` に保存される。
ブラウザの制限で、最初のタップまで音は鳴らない。

## 調整したいとき

`game.js` の先頭にまとまっている。

```js
const TURNS_PER_YEAR = 8;    // 1年のターン数
const TOTAL_YEARS    = 3;    // 何年で終わるか
const START_MONEY    = 1000;
const QUIZ_REWARD    = 150;  // クイズ正解の報酬
const DEST_REWARD    = 800;  // 目的地一番のりの報酬
const SHOP_RETURN    = 0.42; // お店の年間利回り
const SCORE = { yenPerPoint: 20, perCard: 15, perArrival: 200, perShop: 15 };
const CPU_WANDER = 0.25;     // CPUが最短ルートを選ばない確率（強さの調整）
const MIN_NODE_GAP = 46;     // 駒どうしの最小の間かく（地図の単位）
```
