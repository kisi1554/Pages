# ほしくず ダンジョン 🌟

よぞら から おちた **ほしくず** を あつめに、まいかい かたち が かわる **ふしぎ な ちか めいきゅう** へ（小学1〜6年）。
じぶん が 1て うごく と まもの も 1て うごく「かわりばんこ」の ぼうけん。たたかい は なし。
まもの の うごき の **きまり を みつけて さき を よみ**、よけたり なかよく なったり しながら 10かい の そこ を めざす。

`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。え は canvas に かく ドット ふう の オリジナル。
おと は WebAudio の 合成音で、🔊 こうかおん・🎵 BGM を それぞれ オン/オフ）。

## ルール

- ちず は まいかい じどう で つくる（へや と つうろ、シード つき）。みえる の は まわり だけ。すすむ と ちず が ひらけ、みぎうえ の ミニマップ に のこる。
- じぶん が 1て → まもの が 1て。まもの に ぶつかる と **びっくり**: ハート −1、ほしくず を 3こ おとす（ちかく に ちらばるので ひろいなおせる）。
  じぶん から ぶつかって も おなじ。びっくり の あと 2て は まもの を すりぬけられる（とおせんぼ で つまない）。
- ハート 0 → その かい の いりぐち に もどる（**ゲームオーバー なし**。みた ちず・ひろった もの は のこる）。かい を おりる と ハート は 3 に もどる。
- かいだん で した へ。**10かい** の そこ の 🌠 おおきな ながれぼし に さわる と そら へ かえして クリア。

| 🐌 のろりん | 2〜 | おなじ へや に いる と おいかける。2て に 1かい | 🍃 はっぱ を となり で わたす | ハート を 1つ かいふく |

## もちもの（5こ まで）と しかけ

🍬 あめ・🍃 はっぱ・🏮 ランタン（みえる はんい も ひろがる）・🪞 かがみ・🗺️ ちず の かけら（その かい が ぜんぶ みえる）・🪽 はね（つぎ の 1て で 2マス とぶ。まもの も こえる）。

## そうさ

じゅうじ ボタン（おしっぱなし で つづけて）・がめん を スワイプ で 1マス。いった こと の ある マス を タップ → じどう で あるく（あたらしく まもの が みえたら とまる）。
がめん を ながおし か「まつ」→ その ばで 1て まつ。キーボード は やじるし・WASD・スペース（まつ）・1〜5（もちもの）・M（ちず）。

## しくみ

- `dungeon.js`（DOM なし）: ちず の せいせい、ターン、まもの の うごき、もちもの、みちさがし、テスト よう の じどう プレイ。
  - へや を おいて つうろ で つなぎ（プリム ほう）、かいだん は いちばん とおい へや。しかけ を 1つ ずつ たし、そのつど
    **すべる ゆか・ワープ こみ の BFS** で「いりぐち から かいだん に とどく」と「とどく ところ の どこ から でも かいだん に もどれる（すべって つまない）」を たしかめ、だめ なら とりけす。
    いわ・とびら・ひび の かべ は かべ と して しらべる ので、うごかさなくて も かならず すすめる。
- `app.js`: canvas の えがき（ドット え は もじ で かいた 8×8 の オリジナル）、そうさ、ほぞん。`audio.js`: こうかおん と かい ごと に かわる BGM（じどう さっきょく）。
- ほぞん: localStorage `hoshikuzu-dungeon-v1`（つづき は いま の かい の いりぐち から、ずかん、クリア かいすう、さいこう ⭐）。
- `?seed=123` で めいきゅう の ばんごう を きめて はじめられる。
