# てんくうエレベーター 🌤️

**ちか 50かい から 500かい まで、ガラスばりの エレベーターで どこへでも。**
どの かいにも おりられて、その かいの おともだちから **ことばカード** を もらって ポケットに あつめる ごい あそび。
年長〜小学校中学年むけ。`index.html` を ひらくだけで あそべます（外部ライブラリ・CDN・画像ファイル なし）。

公開URL: https://kisi1554.github.io/Pages/tenku-elevator/

## あそびかた

1. **かごの なか**: テンキーで かいを いれて「いく！」。ちかは「ちか（B）」を おしてから。
   0・501 いじょう・B51 いかは「その かいは ないよ」。
   - よく つかう ボタン: 1かい／おくじょう（500）／いちばん した（B50）／まだ いって ない かい（ランダム）／とくべつな かい（いちらん）
   - いきさきは **いくつでも とうろく** できる（ひかる）。もう いちど おすと とりけし。のぼりの とちゅうの かいから じゅんに とまる（SCAN）。
   - ◀▶ ひらく（ながく あけて おく）／▶◀ しめる（すぐ しめる）
2. ドアが あいたら「おりる」。**ホール** で おともだちが あいさつ → その かいの ことばを つかった おはなし → ことばカードを くれる。
3. ホールの **▲▼** で エレベーターを よぶ（ドアの うえの ひょうじで いま かごが どこに いるか わかる）。
   おくじょうは ▼ だけ、B50 は ▲ だけ。おりて しばらく すると だれかが かごを よんで いって しまう ことも。
4. いっしょに のった おともだちが じぶんで いきさきを おす ことも ある（「わたしは 230かい！」）。その かいで おりて いく。
5. うごいて いる とき **まどの そとを タップ** すると、みえて いる ものの なまえ（「にゅうどうぐも」「アンモナイト」…）。これも ポケットへ。
6. 🫙 **ポケット**: なかま（ひんし）ごとの びん、ならべかえ（もらった じゅん・あいうえお・なかま べつ・★じゅん）。
   カードを ひらくと いみ・れいぶん・にた ことば／はんたいの ことば・くれた おともだちと かい・「その かいへ いく」。
7. 📝 **ふくしゅう**（ポケットの ことばだけ）: いみ あて 3たく／ぶんに はいる ことば／はんたいの ことば／にた ことば。
   あたると おぼえた ど ★（0〜3）。まちがえた ものは 3もん あとに また でる。あたった ものは あいだを あけて（10ぷん → 1にち → 3にち）。
8. 🗺️ **たてもの マップ**: 550かいの うち いった かい・ことばを もらった かい（○/550）。マスを 2かい おすと その かいへ。

- **とくべつな かい**（てづくり）: 1かい ロビー、B50 いちばん したの たからべや、500 おくじょう、ゾーンの いりぐち（B31・B30・B10・31・101・201・351）、

## しくみ

| ファイル | なにを する |
| --- | --- |
| `elevator.js` | かごの うごき（たかさを 1つの かずで もつ。かそく → さいこうそく → げんそく で ぴたっ）、ドアの ひらく・しめる、うんこう（SCAN） |
| `scenery.js` | まどの そと（Canvas・えんきんほう）、ホール、こもの |
| `floors.js` | ゾーン・とくべつな かい・550かいの 生成・たかさ くらべ |
| `friends.js` | おともだちの データと え |
| `words.js` | ことば データ（かい の ことば ＋ まどの そとの もの） |
| `pocket.js` | ならべかえ・ふくしゅうの もんだい・おぼえた ど |
| `audio.js` | ごうせいおん（チャイム・ドア・ピッ・かぜきり・しずく・とり・ゾーンごとの BGM）と こえ |
| `app.js` | がめん（かご・ホール・ポケット・ふくしゅう・マップ・せってい） |

- **うごき**: きょり D から かかる じかん T を きめる（T = 2.6 + 8.6×√(D/2200) びょう、さいだい 11.2）。
  かそくに T の 3わり、のこりで さいこうそく → げんそく。B50 → 500 でも やく 11びょう。とおい ほど さいこうそくが あがる。
  はやい ときは スピードせん と かぜきり音。うごいて いる とちゅうで まえの かいを おしても、ブレーキが まにあえば とまる。
- **けしき**: たかさに おうじて つながって かわる。
  ちか（ねっこ・みみず → すいどうかん・ケーブル → ちかがい → ちかてつの トンネル → ちかすいの じゃりの そう → いろとりどりの ちそう と かせき → がんばん。
  ライトで てらした きれいな だんめん）、ちじょう（まち → ビルの やね → みなと と うみ → くもの なか（きりで しろく なる）→ くもの うみ → とおくの ふじさん）。
  じかん（あさ・ひる・ゆうがた・よる。よるは まちの あかりと ほし）は たんまつの とけい。てんきは ときどき かわる（あめの ひは くもより したが あめ、ぬけると はれ、あがると にじ）。せっていで こてい できる。
- **ほぞん**: localStorage `tenku-elevator-v1`（いまの かい、いった かい、ポケット、なかよし ど、ふくしゅうの きろく、せってい）。
