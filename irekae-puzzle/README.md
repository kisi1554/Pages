# かもつ いれかえ パズル 🚃

かもつ えき の **いれかえ きかんしゃ** を うごかして、ばらばら に ならんだ かしゃ を
**ちゅうもん どおり の じゅんばん** に ならべかえる パズル。小学1〜6年（おとな も むちゅう に なる レベル まで）。

公開URL: https://kisi1554.github.io/Pages/irekae-puzzle/

## あそびかた

1. **ポイント**（🚩・1・2・3 の ボタン、または せんろ を タップ）で いく せんろ を えらぶ（かちゃん）。
2. **▶ すすむ**（または ボード を みぎ へ スワイプ、キーボード →）で きかんしゃ が すすみ、
   そこ の かしゃ に ぜんぶ **れんけつ**（がちゃん）。つないで いた かしゃ は さき に おしこまれる。
3. **✂ かいほう** の −／＋（または かしゃ を タップ、きかんしゃ を タップ で 0）で、
   きかんしゃ がわ から なんりょう つれて かえる か えらぶ。
4. **◀ もどる**（または ひだり へ スワイプ、キーボード ←）で えらんだ かしゃ だけ つれて
   ひきあげせん へ もどる（ぷしゅー）。のこり は その せんろ に おいて いく。
5. うえ の **ちゅうもん カード** と おなじ じゅんばん（ひだり → みぎ）で 🚩しゅっぱつ せん に
   ならんだら クリア（ぽっぽー＋ファンファーレ）。しゅっぱつ せん には ちゅうもん の かげ が うすく みえる。

- かぎり: ひきあげせん で ひける のは **H りょう まで**（2〜3）、わきせん に おける のは **ていいん まで**（2〜5、わく で みえる）。
  こえる ような えらびかた は できない（ブブー と りゆう が でる）。
- **1て** ＝ ポイント を えらんで すすみ、もどって くる まで。なにも かわらなかった ときは かぞえない。
- **↩ 1て もどる** は なんかい でも（すすんで いる とちゅう なら そのまま ひきかえす）。**🔄 さいしょ から** も ある。
- **💡 ヒント**: ソルバー が いま の じょうたい から さいたん を さがし、つぎ の 1て（どの せんろ・なんりょう）と
  「あと なんて」を おしえる。ポイント も そこ に きりかわり、すすむ と ✂ の かず も あわせて くれる。

### ★

| ★ | てかず |
| --- | --- |
| ★★★ めいじん | めやす（＝ さいたん てかず）いか |
| ★★ | めやす ＋ max(2, めやす の はんぶん) まで |
| ★ | それ より おおい |

ステージ は「クリア した いちばん うえ の ステージ ＋2」まで ひらく。

| 11〜25 | わきせん 2ほん | 4〜5 | 3〜11て |

- **まいにち もんだい**: ひづけ で きまる ランダム はいち（`Yard.makeDaily`）。ソルバー で とける こと と

- かしゃ: 🍎りんご（あか）・🐟さかな（あお）・🥬やさい（みどり）・🛢️せきゆ（きいろ の タンク）・🍇ぶどう・🪵ざいもく・📦にもつ・からっぽ・🔧こわれた かしゃ。
  いろ だけ で なく え でも わかる ように して いる。

## しくみ（`yard.js`、DOM なし）

- じょうたい は `{ loco: [きかんしゃ がわ → せんとう], tr: [[おく → てまえ], …] }`。せんろ は ぜんぶ スタック。
- 1て ＝ `apply(s, x, j)`: きかんしゃ の かしゃ と せんろ x の かしゃ を ぜんぶ つないだ れつ
  （t1…tk, sm…s1）の うち、きかんしゃ がわ j りょう を もって かえり、のこり を x に おく。
  `j` は `max(0, L − ていいん) 〜 min(L, H)`、いま と おなじ `j = k` は のぞく。
- `solve()` は はば ゆうせん たんさく。せんろ を もじれつ に して `"/"` で つないだ キー を つかい、
  ちゅうもん に でて こない しゅるい は「.」に まとめて さがす かず を へらす（ステージ 40 で 1びょう いない）。
- ステージ は `tools/irekae-puzzle-gen.js` が つくる（せってい ごと に きまった たね で はいち を ためし、
  さいたん が めあて に なる もの を えらんで `stages.js` に かきだす）。`par` は ソルバー の さいたん。
  オリジナル の もんだい（もけい てつどう の いれかえ パズル の かんがえかた を とりいれた もの）。

## おと

WebAudio の ごうせいおん だけ（`audio.js`）。れんけつ の がちゃん、かいほう の ぷしゅー、ポイント の かちゃん、
はしる ときの ことん、きかんしゃ の ぽっぽー（オリジナル の きてき：みじかく 1かい・ながく 1かい）、クリア の ファンファーレ。
右上 🔊 で オン／オフ（ほぞん される）。
