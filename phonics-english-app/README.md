# フォニックスたんけん！（未就学〜小学校低学年向け 英語発音アプリ）

英語の「文字」と「音」のつながり（フォニックス）を、音を聞いて絵を選ぶゲームで学べるアプリです。
`index.html` をブラウザで開くだけで遊べます（インストール不要・追加ファイル不要・オフラインOK）。

## あそびかた

1. `index.html` をブラウザで開く。
2. 「はじめる」を押して、やりたいステージを選ぶ（**全ステージ最初から選べます**）。
3. 🔊ボタンから英単語が読み上げられるので、あてはまる絵を3つの中からタップ。
4. 聞き取れないときは「🐢 ゆっくり」でゆっくり読み上げ、🔊で何度でも聞き直せます。
5. 正解すると、絵とつづりが出て、**注目のつづりが赤く**なり、1文字ずつ光りながらゆっくり読み上げられます。
6. 8問終わるとクリア。ミスの数でスターが★〜★★★もらえます（間違えても何度でも選び直せます）。
7. 集めたスターとトロフィーは端末に保存され、次に開いたときも残っています。

## ステージ構成（全11ステージ）

| # | ステージ | 学ぶこと | 例 |
|---|---|---|---|
| 1〜5 | a / i / e / o / u の おと | 短母音（1文字1音の基本） | cat, pig, egg, dog, sun |
| 6 | sh と ch | 2文字で1つの音になるダイグラフ | ship, chick |
| 7 | th・wh・ck | 同じくダイグラフ | thumb, whale, clock |
| 8 | ai・ee・oa | 母音が2つ並ぶと最初の文字の「名前読み」 | rain, tree, boat |
| 9 | oo の おと | 長い「ウー」 | moon, spoon |
| 10 | まほうの e | サイレントE（語末の e は読まない） | cake, bike, rose |
| 11 | e が つくと どうなる？ | cap↔cape など最小対で聞き分け | tap/tape, pin/pine, cub/cube |

ステージ11は正解の相方（cap に対する cape）が必ず選択肢に入るので、
「e がつくと音がどう変わるか」を耳で比べながら覚えられます。

## トロフィー図鑑

9種類のトロフィーを集められます（例: 初クリア、パーフェクト、10問連続正解、
短母音マスター、サイレントEマスター、全ステージ★★★など）。
未獲得のものは「？？？」で表示され、獲得条件だけが見えます。

## 工夫したポイント（未就学〜低学年向け設計）

- 文字が読めなくても遊べるよう、UIはすべてひらがな＋大きなボタン＋絵文字。
- 選択肢は「絵＋つづり」をセットで表示し、音・意味・つづりが同時に結びつくようにしています。
- 正解時はつづりを1文字ずつ光らせながらゆっくり読み上げ、注目のつづり（`sh`, `oo` など）を赤く、
  サイレントEはグレーで表示して「読まない e」を目で理解できるようにしました。
- 間違えてもペナルティはなく、もう一度聞いて選び直せます（スターの数だけが変わります）。
- ステージはロックせず全部選べるので、飽きたら好きなところへ移動できます。
- 進捗は `localStorage` に保存。図鑑画面から全記録の消去もできます。

## 動作環境

モダンブラウザ（Chrome, Safari, Edge など）で動作します。
読み上げには Web Speech API を使用しているため、対応ブラウザでのみ音が出ます
（非対応ブラウザでは、つづりを見て遊べる形にフォールバックし、その旨を画面に表示します）。
iPhone / iPad では、最初に画面を1回タップすると音が出るようになります。
