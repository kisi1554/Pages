# 横浜駅徒歩圏の大手中学受験塾 比較レポート（yokohama-juku-hikaku）

横浜駅からおおむね徒歩10分以内にある集団指導の中学受験塾（SAPIX・日能研・四谷大塚・早稲田アカデミー・
グノーブル・希学園・浜学園・啓明館、参考に TOMAS）を比較した保護者向け 1 ページ。

公開URL: https://kisi1554.github.io/Pages/yokohama-juku-hikaku/ （志望校の比較: `shiboukou.html`）

## 構成

2ページに分けている。上部のタブで行き来する。

| ページ | 中身 |
| --- | --- |
| `index.html`（塾の比較） | 結論 / 1. 校舎一覧 / 2. 塾ごとの特徴 / 3. 塾別合格者数（神奈川主要校＋東京の人気校。四谷大塚はネットワーク／直営を併記） / 4. 志望校9校で見た塾の比較 / 5. 小1から通う場合 / 6. 費用 / 7. タイプ別おすすめ / 8. 進め方 |
| `shiboukou.html`（志望校の比較・併願プラン） | 要点 / 1. 志望校9校の学校比較（偏差値・自宅からの所要時間・初年度納入金・進学実績） / 2. 2026年度入試の結果（倍率・平均点・合格最低点） / 3. 併願スケジュール案（2027年2月入試。締切の時系列、パターンA〜Jと比較表） / 4. 学校ごとの詳細（通学ルート調査より） |

自宅からの所要時間・手続締切は [`tsugaku-route/`](../tsugaku-route/)（通学ルート調査）の値を使う。住所は載せない。

「2. 学校ごとの詳細」は `tsugaku-route/index.html` の `section.school`（11校）を写したもの。
写すときに **住所（`ul.facts` の先頭 `<li>`）・地図リンク・スコアの行・「先頭へ戻る」を落とす**。
`h3` は `h4` に下げ、CSS は `.sdb` の下に閉じ込めてある。通学ルート側を直したら、こちらも同じように写しなおす。

## 注意

- 2026年9月25日時点の Web 公開情報にもとづく。住所・料金・授業曜日は年度で変わる。
- 四谷大塚は提携塾・通信生込み、早稲アカはグループ全体の集計で、直営のみの塾と単純比較できない。
- 子ども向けではないため、あそびメニュー（`pages-root/index.html`）にはカードを載せていない。
