# かず まめ ろせんず 🔢

ろせんずの えきを まわって、**かずの まめちしき** を あつめる アプリ（5さい〜小学生）。
えき 1つ ＝ まめちしき 1つ。3たくクイズに こたえると スタンプ 💮 が もらえて、
「さんすうで みてみよう」で けいさんの しかたも わかる。

`index.html` だけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## やってみよう（うごく ず）

- **やまのてせん ぐるぐる**（R01・R02）: 30えきの わっかを ±1/5/10 すすむ。30を こえると「− 30」の しきが でる。
- **えきと あいだ**（R03）: えきの かずを かえて、まっすぐ（n−1）と わっか（n）を くらべる。
- **ざせき**（R10）: 1〜6にんの すわりかた（2＋2・3＋2・3＋3）。
- **レールの つぎめ**（R12）: キロ × 40 と ガタンゴトンの おと。
- **ほんもの ⇄ ろせんず**（R15）: くねくねの せんが たて・よこ・ななめ に かわる（えきの じゅんばんは そのまま）。
- **ひとふでがき**（R16）: おうち（きすう 2こ）・リボン（0こ）・7つの はし（4こ＝できない）。🔍で せんの かずを ひょうじ。

## メモ

- 「いまから ○ねん まえ」は ひらいた ひの とし から けいさんする。
- 進捗は localStorage（`kazu-mame-rosen`）。読み書きは try/catch。
- まちがえると その せんたくしが きえて ヒントが でる（なんどでも ちょうせん できる）。
