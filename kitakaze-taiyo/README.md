# きたかぜと たいよう ― ゆびで ふいて、こすって ためす えほん 🌬️☀️

イソップの おはなし「きたかぜと たいよう」を、**こどもが きたかぜに なって ゆびで なぞり、
たいようを こすって あたためる** しかけ えほんに しました。「さわる えほん」シリーズの 2さつめ
（1さつめは [`ookina-kabu/`](../ookina-kabu/)。画面の かたち・よみあげ・ことばの きりかえ・しおりは おなじ 型）。
対象は 未就学〜小学1年。ひょうし＋8ページ＋おしまい の 全10ページ。

**イソップの おはなしを もとに した オリジナルの 文・絵** です。
日本で 出版されて いる 絵本・教科書の 訳文や 絵は つかって いません（日本語・英語の 文も 絵も この アプリの ために かいたもの）。

`index.html` を ブラウザで ひらくだけで あそべます（ビルドも サーバーも 不要。外部ライブラリなし）。
絵は SVG、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。
文は ひらがな中心で、ことばの あいだを スペースで くぎっています（漢字には ふりがな）。

## おはなし と しかけ

| ページ | おはなし | しかけ |
| --- | --- | --- |
| ひょうし | くもが ながれる | 絵か「よみはじめる」を タップ |
| 1 | きたかぜと たいようが「どっちが つよい？」と いいあう | 2人を タップで じまんの ふきだし → **よそう**「どっちが かつと おもう？」（保存して さいごに ふりかえる） |
| 2 | コートを きた たびびとが くる | たびびとを タップで あいさつ → コートを さわって ボタンを ぎゅっ、ぎゅっ、ぎゅっ |
| 3 | きたかぜの ばん「びゅーっ！」 | **ふく**: 絵の うえを なぞる。はっぱ・かかしの ぼうし・せんたくものが とぶ。たびびとは ぶるぶる |
| 4 | もっと つよく ふく けど ぬがない | **ふく** つづき。「🧥 おさえる ちから」メーターが かぜに ついて あがる → きたかぜ「はぁ はぁ… まいった」 |
| 5 | たいようの ばん | くもを タップ／スワイプで どかす → **こする**: たいようを ぐるぐる（🌡️ おんど メーター） |
| 6 | ぽかぽか、あせが でる | **こする** つづき。あせを ふく → ぼうしを とる → ボタンを はずす |
| 7 | コートを ぬいだ！ | たびびとを タップ → コートが ふわっと 木の えだに → 木かげで のびと あくび |
| 8 | なかなおり | 2人を ドラッグで ちかづけると あくしゅ「つよく するより、やさしく すると つたわるね」 |
| おしまい | よそうの ふりかえり | 「あたり！」／「たいようだったね！」どちらでも ほめる。**「もういちど ためす」で ページ 3〜6 を じゆうに あそべる** |

## ふく・こする しくみ（`wind.js`）

- **ふく（blow）**: ゆびごとに なぞった きょり（絵の はば＝1）を あつめ、毎フレーム「かぜの つよさ」に たします。
  はやく なぞる ほど・ゆびが おおい ほど つよく、時間で だんだん よわまります。つよさに おうじて
  かぜの すじ・はっぱの かず・木の ゆれ・風の 音が かわります。
  - **ゆび 2ほん** で なぞると ふく りょうが ちょうど 2ばい（「👆×2 かぜ 2ばい！」）。
  - たびびとの「コートを おさえる ちから」は いつも かぜより つよく なる ように あがるので、
    **かぜ だけでは ぜったいに コートは ぬげません**（おはなしの テーマ）。
- **こする（warm）**: たいようの まわりを まわった 角度の 合計で おんどが あがります（ぎゃく まわりでも よい）。
  おんどで 光の 輪が ひろがり、空が あたたかい 色に なり、たびびとが ほっ → あせ → あせを ふく → ぼうし → ボタン → コート の じゅんに かわります。
  コートが ぬげるか どうかは **おんどだけ** で きまります（`Wind.model.coatOff`）。
- **いきで ふく（せってい、さいしょは オフ）**: ひょうしの「🎤 いきで ふく」を オンに すると、さいしょに おうちの かた向けの
  せつめいが でます。同意すると、かぜの ページだけ マイクの **音の 大きさ** を 端末の 中で はかり（getUserMedia＋AnalyserNode）、
  ふーっと 息を ふきかけると かぜが ふきます。**録音・保存・送信は しません。音声認識も つかいません。**
  つかえない／ことわった ときは ゆびだけで あそべます。
- パソコンでは マウスの ドラッグと キーボード（→←↑↓・スペースで ふく／まわす、Enter で タップ、2人を ちかづける）でも あそべます。
- 絵には `touch-action: none` を つけ、なんぼんの ゆびで さわっても 画面が うごいたり 拡大したり しません。

## そのほか（`ookina-kabu` と おなじ）

- **よみあげ**: speechSynthesis で 1ぎょうずつ。よんで いる 行を 黄色く ひからせます。🔁 で もういちど。しかけを さわると とまります。
- **🇬🇧 English ⇄ 🇯🇵 にほんご**: ほんの したと ひょうしの ボタンで きりかえ。文・ヒント・ふきだし・メーターは ぜんぶ `{ ja, en }`。
  おすと 文が ぜんぶ かわって はじめから よみなおします（英語は en-US の こえ）。効果音は どちらも おなじ。
- 🎵 おと（BGM・効果音）と 🗣 よみあげ は べつべつに オン/オフ。
- しかけが おわるまで「🔒 つぎ」。いちど おわった ページは つぎから すぐ すすめます。
- **しおり**（🔖 つづき から）。しおり・せってい・よそうは その端末の `localStorage` にだけ 保存します。
- たてもちは 絵の したに 文、スマホ よこもちは 絵と 文を よこに。絵は いつも 8:5。

## 音

ぜんぶ Web Audio の 合成音: 風の 音（ノイズ＋フィルター、つよさで 音量と 高さが かわる）、とぶ ものの ぴゅー、
たいようの きらきら、汗の ぽたっ、ことりの さえずり（たいようの ページ）、BGM は オリジナルの ワルツ。

## たしかめかた

```bash
node tools/kitakaze-taiyo/test.js
node tools/kitakaze-taiyo/check.js /tmp/shots
```

`test.js` は story.js の 全ページ・全 行に ja と en が そろって いること、かぜを どれだけ ふいても コートは ぬげないこと、
たいようの おんどが 上限まで いくと ぬげること、ゆび 2ほんで かぜが 2ばいに なることを たしかめます。
`check.js` は それに くわえ、Playwright で たて（390×844）・よこ（1024×768）・スマホよこ（844×390）を 日本語と 英語で ひらき、
全ページの しかけを こなして おしまいまで すすむこと、ゆび 2ほん（CDP の タッチ）で かぜが 2ばいに なること、
絵が はみださないこと、JS エラーが ないことを たしかめ、スクショを 保存します。
