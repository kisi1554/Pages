# あしあと たんてい 🐾

どうぶつ が のこした **あしあと・たべあと・ふん・け や はね・すみか・なきごえ** を ルーペ で しらべて、
だれ が きた か を すいり する たんてい ゲーム（年長〜小学生）。
`index.html` を ひらく だけ で うごきます（外部ライブラリ・CDN なし。え は ぜんぶ SVG を コード で かいて、おと は WebAudio の 合成音）。

## あそびかた

1. **じけん**: 「はたけ の いちご が なくなった！」「ゆき の にわ に ふしぎ な あしあと」「くるみ が かじられて いる」など 30こ。
2. **しらべる**: げんば の え の うえ で ルーペ を ドラッグ（タップ でも OK）。ルーペ の なか は 2ばい に 見え、
   てがかり（3〜5こ）に ちかづく と「きらっ」、みつける と「ピコン」。なきごえ の てがかり は 合成音 で にせた こえ が なる。
   💡 ヒント で いちばん ちかい てがかり が ひかる。
3. **たんてい ノート**: みつけた てがかり（たて）× ようぎしゃ の どうぶつ カード（よこ）の ひょう に、
   自分 で ○（あう）／×（あわない）を つける。「しるし を たしかめる」で まちがい の マス が あかく なる。
   どうぶつ の かお を タップ すると ずかん の とくちょう が 見られる。
4. **かいけつ**: はんにん を えらぶ。まちがえる と「○○ だと『△△』が あわないよ」と りゆう を おしえる。
   せいかい なら「ジャジャーン」で どうぶつ が でて きて あいさつ（いちご どろぼう の タヌキ も にくめない）。
   ふりかえり で「どの てがかり で だれ が はずれた か」を 3つ まで ならべる。★ は まちがい・ヒント なし で 3つ。
5. **ずかん**: 12しゅるい の あしあと・ならびかた・ふん・たべもの・すみか・きせつ・なきごえ・まめちしき。
   かいけつ した どうぶつ には「であった」スタンプ。

よみあげ（speechSynthesis）と おと は ヘッダー で それぞれ オン/オフ。進み具合・ずかん は localStorage（`ashiato-tantei-v1`、try/catch つき）。

### じけん の むずかしさ

| レベル | じけん | しくみ |
| --- | --- | --- |
| かんたん | 1〜10 | あしあと（`track` / `gait`）だけ で はんにん が きまる |
| ふつう | 11〜20 | 3〜4こ の てがかり。おおく は 2つ を くみあわせ ないと きまらない |
| むずかしい | 21〜30 | ようぎしゃ 4ひき・てがかり 4〜5こ。**どの てがかり も 1つ だけ では きまらない**（かならず 2つ 以上 を くみあわせる） |

30こ の うち 17こ が「1つ だけ では きまらない」じけん。

## でて くる どうぶつ（日本 の みぢか な 12しゅるい）

タヌキ・キツネ・ノウサギ（ニホンノウサギ）・リス（ニホンリス）・ネズミ（アカネズミ）・シカ（ニホンジカ）・
イノシシ・ハクビシン・ネコ・イヌ・カラス（ハシブト／ハシボソ）・カモ（カルガモ）

## 正確さ について

- **とくちょう ひょう**: `data.js` の `CLUES` に、てがかり ごと に「その しるし を のこす かも しれない どうぶつ」（`matches`）を
  12しゅるい ぜんぶ に ついて かいて ある。あいまい な もの は ひろめ に いれて いる
  （たとえば「ジグザグ に ならぶ」は まっすぐ あるく キツネ・ネコ と、とんで すすむ ウサギ・リス・ネズミ 以外 ぜんぶ、
  「ためふん」は タヌキ と ハクビシン、「どろあび（ぬたば）」は イノシシ と シカ、「まつぼっくり の エビフライ」は リス と ネズミ）。
- **じどう テスト**: `node ashiato-tantei/tests/check-cases.js` が、`matches` だけ を つかって
  ぜんぶ の じけん で はんにん が 1ぴき に きまる こと、はんにん が ぜんぶ の てがかり に あう こと、
  ほか の ようぎしゃ は かならず どれか の てがかり で はずれる こと、むずかしい は 1つ で きまらない こと などを たしかめる。
- **あしあと の え**（`draw.js`）: イヌ・キツネ・タヌキ は ゆび 4ほん＋つめ の あと、ネコ は ゆび 4ほん で つめ なし、
  ハクビシン は ゆび 5ほん、リス・ネズミ は まえ 4ほん・うしろ 5ほん、シカ は さき の ほそい ひづめ 2つ、
  イノシシ は まるっこい ひづめ＋うしろ の ふくてい 2つ、カラス は まえ 3・うしろ 1、カモ は みずかき。
  ならび は キツネ が まっすぐ 1れつ、ノウサギ は ちいさい まえあし が たて・おおきい うしろあし が まえ で よこならび（Y じ）、
  リス・ネズミ は まえ も うしろ も よこならび。
- なきごえ は 合成音 で とくちょう を にせた もの（ほんもの の ろくおん では ない）。キツネ は「コンコン」では なく「ギャーッ」「ケーン」。
- がめん の あちこち に「やせい の どうぶつ に ちかづかない・さわらない・えさ を あげない。ふん は て で さわらない」。
