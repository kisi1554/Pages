# からだ たんけん 🍙

ちいさく なって からだの なかを たんけんし、ぶひんの なまえと はたらきを しる。
年長〜小学校中学年むけ。

公開URL: https://kisi1554.github.io/Pages/karada-tanken/

## あそびかた

ホームの からだの ず（SVG を コードで かいた、こわくない デフォルメ）の ひかる ところ、
または したの カードから コースを えらぶ。「ちいさく なあれ！」で たんけん スタート。

| コース | ばめん（ミニゲーム） |
| --- | --- |
| 🍙 おにぎりの たび（しょうか） | くち（メーターが みどりの ときに タップして かむ）→ みずを のむ？（ぶんき）→ しょくどう（わっかが ちぢむ リズムで おしすすめる）→ い（ぐるぐる なぞって かきまぜる）→ しょうちょう（えいようの つぶを タップして けつえきへ ＋ でんしゃ 1りょう と ながさくらべ）→ だいちょう（みずを すいとる → うんち → ちょっぴり おなら） |
| ❤️ しんぞう と はい | はい（ながおしで すう・はなして はく）→ しんぞう（ドクンに あわせて タップ・80）→ けっかん しらべ（タップで しらべる）→ クイズ「はしったら？」→ はしった あとの しんぞう（120） |
| 🦴 ほね と きんにく | ほね しらべ → ほね パズル（11ピース。タップ→タップ でも ドラッグ でも）→ きんにく（スライダーで うでを まげる／のばす）→ クイズ |

### いま からだの どこ？

- ばめんの うえの **からだマップ**: いまの ぶい だけ ひかって、ほかは うすく なる。コースの みちすじ は
  とおった ところが じっせん、これからは てんせん。「📍 いま ここ：」に ぶいの なまえ。マップを タップすると おおきく みられる。
- つぎの ばめんへ すすむ ときは、おおきな マップの うえを たんけんたい 🧒 が いどうする（「つぎは しょくどうへ！」）。タップで とばせる。
- ばめんの `org`（ひからせる ぶい）と `map`（マップの いち）は `data.js`。

### ぶんき（コース1）

- くちで **8かい** かむ前に「ごっくん」すると `well=false` … しょくどうで +3かい、いで ぐるぐる 3→5かい。
- みずを のまないと `water=false` … しょくどうで +2かい、だいちょうの みず 6→3こ で うんちが コロコロ。
- さいごの けっか（バナナ うんち／コロコロ うんち／ゆっくり すすんだ たび／たいへんな たび）は `data.js` の `endings`。

### ほぞん（localStorage `karada-tanken-v1`）

- `badges` … コースクリアで「からだ はかせ バッジ」（しょうか／しんぞう／ほね はかせ）。3つで 🎓 からだ はかせ。
- `words` … おぼえた ことば（31こ）。ヘッダーの 📖 ずかん で みられる。
- `sound`（おと オン／オフ）、`fart`（おならの おと オン／オフ。だいちょうの ばめんで きりかえ）。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `index.html` | がめんの くみたて |
| `style.css` | みため（たてもち は ばめん→せつめい、よこもち は ばめん ひだり／せつめい みぎ） |
| `data.js` | ことば（ずかん）・コース・ばめん（せつめいぶん、ミニゲームの しゅるい と パラメータ）・ほね パズルの いち。node でも よめる |
| `art.js` | からだ・ないぞう・ほね・うで の SVG を かく |
| `app.js` | がめん きりかえ、ミニゲーム（`GAMES[type]`）、おと（WebAudio の ごうせいおん）、ほぞん |
| `tests/data.test.js` | データの けんさ（ふりがな もれ・ことばの とうろく・すうじ など） |
| `tests/e2e.playwright.cjs` | ブラウザで 3コースを さいごまで じどうで すすめ、スクショを とる |

- ふりがなは データの なかで `{漢字|よみ}` と かき、`rb()` で `<ruby>` に する。SVG の なかの もじは ひらがな／カタカナ だけ。
- タイミングの ミニゲームは、あたる あいだ `#stage` に `data-hit="1"` が つく（じどう テスト よう）。
  なんかいも はずすと あたりの はばが ひろがる（おたすけ）。
- すうじは しょうがっこう りかの はんいで「およそ」: しょくどう 25cm・しょうちょう 6m（でんしゃ 1りょう 20m の 3ぶんの1）・
  だいちょう 1.5m・しんぱく こども 80〜100かい・ほね 200こ・けつえきは およそ 1ぷんで ひとまわり。
