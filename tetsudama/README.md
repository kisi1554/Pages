# てつだま ガタンゴトン ⚫

はこの うえに おいてある おもい てつだまを、ガタン！ゴトン！と かいだんに おとして ころがす よこスクロールの ゲーム。
まわりと まんなかに ゾンビ、とおくに おもちゃ と ゴール。未就学〜小学生むけ。
物理（円 と 線分の あたりはんてい）は じさく、描画は Canvas、音は WebAudio の ごうせいおん（外部ライブラリなし）。

公開URL: https://kisi1554.github.io/Pages/tetsudama/

## あそびかた

| そうさ | キーボード | なにが おきる |
| --- | --- | --- |
| ◀ ▶ | ← → / A D | てつだまを ころがす（おしっぱなしで かそく） |
| ジャンプ | スペース / ↑ / W | ぴょん（ちいさい ゾンビや はこを とびこえられる） |

- はこに ぶつかると「ガタン！」「ゴトン！」（こうごに ひくい おと）。はこが ゆれて、がめんも すこし ゆれる。
- **ゾンビ**: いきおい（よこの はやさ＋おちる はやさ）が たりると「ドーン！」と たおれる。おそいと「うー…」と はねかえされる（やられることは ない）。
- **まんなかの おおきい ゾンビ**（おうかん つき）は とびこえられない。てまえの さかを ころがって いきおいを つける。
  ちかづくと「いきおい」メーターが でて、いっぱいで「いまだ！」。
- とおくの **おもちゃ** を あつめて 🏁 **ゴール**。
- ⭐: ゴール ＋ ゾンビ ぜんぶ ＋ おもちゃ ぜんぶ で 3こ。ステージごとの さいこう きろくを localStorage に ほぞん。

## ステージ

1. はじめての てつだま … はこ 4だんの かいだん → ゾンビ2たい → さか → おおきい ゾンビ
2. はこの かいだん … 5だんの かいだん、はこの やま、たかい はこを ジャンプで のぼる
3. ゾンビの おしろ … いちばん たかい スタート、くぼみ、ゾンビ 7たい

4〜12 は 🔥 **むずかしい コース**（9コース）:

| # | なまえ | とくちょう |
| --- | --- | --- |
| 4 | あなぼこ みち | あなを ジャンプで こえる |
| 5 | ジャンプ ジャンプ | たかい はこ・2だんの はこを のりこえる |
| 6 | うかぶ いし | あなの うえの いしを ぴょんぴょん |
| 7 | うごく はこ | ⇔ ⇕ うごく あおい はこに のる（のっていると いっしょに うごく） |
| 8 | ゾンビ だらけ | ゾンビ 15たい |
| 9 | おおきい ゾンビ 3きょうだい | さか と おおきい ゾンビが 3かい（だんだん つよい） |
| 10 | がけっぷち | ひろい あな と いし |
| 11 | てつだま マスター | ぜんぶ まぜ |
| 12 | さいごの おしろ | いちばん ながい（やく 1まん） |

- あなに おちると「あっ！ おちた！」→ さいごに とおった 🚩 チェックポイント（とおると みどり）から やりなおし。
  いし・うごく はこの まえには かならず チェックポイントが ある。クリア がめんに おちた かい を だす。
- ジャンプは すこし はやく おしても ちゃくちした しゅんかんに とぶ（0.15びょう）。
- むずかしい コースは `buildCourse()` で ブロック（flat / pit / hill / wall / wall2 / stones / movers / check）を ならべて つくる。
  ぜんぶ じどう ボット（みぎ おしっぱなし＋がけの てまえで ジャンプ）で クリアできることを たしかめてある。

ステージは `STAGES` の データ（じめんの おれせん・はこ・ゾンビ・おもちゃ・ゴール）だけで きまる。
