# だいみょう ぎょうれつ 🏮

**とのさまの ぎょうれつで えどを めざそう！ けらいを ひろうと ぎょうれつが のびる。じぶんに ぶつからない ように すすもう。**
10本シリーズ「じだい たんけん」の えど じだい編（5才〜）。あそびの 型は「ぎょうれつ（へび）ゲーム」。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/edo-gyoretsu/

## あそびかた（1回 1〜3分）

1. コースを えらぶ（⛰️ やまみち／🌊 うみぞい／⛵ おおきな かわ）。
2. ゆびで なぞった ほうへ、とのさまの かごを せんとうに ぎょうれつが すすむ（PC は やじるしキーでも）。
3. ひかっている けらい（やりもち・はこもち・かさもち・はたもち・たいこ）を ひろうと 1人ずつ のびる。
   4人 あつめると しゅくばが ひらく。じぶんの ぎょうれつに ぶつかったら、その くかんの はじめから やりなおし。
4. しゅくばで ひとやすみ（おだんご）→ おかねの ふくろが かるく なる → しゅくば クイズ（3たく、まちがえても えらびなおせる）。
5. 3くかんめで えどじょうへ。しょうぐんに ごあいさつ →「らいねん また くにへ かえって、また きてね」で とのさまが ずっこける。
6. はなびで おいわい → 「つぎは どんな じだい？」（くろい ふね → めいじ）。

### わらい どころ

- まちの 人・こども・ねこの そばを とおると「したにー、したにー」→ みんな ぺこり（ねこも）。
- かごを かつぐ 人が ふらふら。おだんごを たべるたびに もっと ふらふら。「とのさま、おもたい〜」
- おかね（🪙5まい）が へるたびに、とのさまの かおが 😊→🙂→😢→😱。

## 史実メモ

- 1603年 徳川家康が征夷大将軍・江戸幕府。1867年 大政奉還まで約260年（15代）。
- 参勤交代：1635年 家光の武家諸法度（寛永令）で制度化。原則1年おきに江戸と領地を往復、正室と跡継ぎは江戸住まい。
- 「下に、下に」は御三家など一部の行列のみ。多くは「片寄れ」といわれる（カードの注記に明記）。
- 東海道：日本橋〜三条大橋、53宿、約490km。大井川は橋も渡し船もなく川越人足、天竜川・多摩川（六郷の渡し）は渡し船。
- 江戸城天守は1657年 明暦の大火で焼失後、再建されず → ゲームでは門と櫓で描いた。
- 町火消（いろは47組）1720年、大岡忠相。1853年 ペリー来航（浦賀）。
- `tadataka-talk/`（ちり はかせ）は地理のおしゃべりで、参勤交代・東海道の題材とは かぶらないことを確認済み。
