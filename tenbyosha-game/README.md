# てんつなぎ とっくん！（点描写ゲーム）

見本と同じ形を、格子の点をつないで描き写すゲームです。中学受験の算数で問われる
平面図形・空間認識の土台をつくるための「点描写」を、自動採点つきでデジタル化しました。

## あそびかた

1. `index.html` をブラウザで開くだけで遊べます（インストール不要・オフラインOK）。
2. ステージ（やさしい／ふつう／むずかしい）を選ぶとスタート。
3. 左の「みほん」と同じ形を、右の盤面に描きます。
   - **なぞる**: 点から点へ指をすべらせると、続けて線が引けます。
   - **タップ2回**: 点を押して → となりの点を押すと1本引けます。もう一度同じ操作で消せます。
   - 🧽 ぜんぶけす でやり直し、👉 ひとつおしえて で1本だけ引いてもらえます。
4. 「できた！」を押すと採点。全6問で、正解すると星⭐がたまります。

## 工夫したポイント（年中〜低学年向け設計）

- **紙の点描写の弱点をなくす**: 紙だと親が丸つけをしないと進みません。辺の集合を比較して
  自動採点するので、子どもひとりで回せます。1問1〜2分で、平日の短時間学習に収まります。
- **形に名前がある**: 抽象的な模様ではなく「おうち」「き」「ヨット」「でんしゃ」など
  名前のある形にしています。文字が読めなくても、読み上げが何を描くのか教えてくれます。
- **答えを見せない採点**: 足りない線が多いうちは「まだ とちゅう！ あと◯ほん」とだけ伝え、
  残り3本以下になって初めて不足箇所を点線で示します。多い線はピンクで揺らして知らせます。
- **消しゴムモードがない**: 同じ2点をもう一度押せば消えるので、モードの切り替えが要りません。
- 音声読み上げ（Web Speech API）と効果音つき。ボタンは大きく、間違えてもペナルティなしです。
- 見本を隠す 👁 ボタンつき。慣れてきたら、形を覚えてから描く練習に使えます。

## ステージ

| ステージ | 格子 | 線 | ねらい |
|---|---|---|---|
| やさしい | 3×3 | たて・よこのみ | 位置の把握、運筆 |
| ふつう | 3×3 | ななめもあり | 斜線の方向、対称な形 |
| むずかしい | 4×4 | ななめもあり | 複雑な図形の分解、線の本数の管理 |

## ファイル構成

- `index.html` - これ1つで完結（HTML・CSS・図形データ・ロジック）

## 動作環境

モダンブラウザ（Chrome, Safari, Edge など）で動作します。タッチ・マウスの両方に対応。
音声読み上げは対応ブラウザのみ有効です（非対応でも他の機能は問題なく遊べます）。
