# ころころ そうち 🎳

ぶひんを おいて ボールを ころがし、れんさで さいごに 🔔 ベルを ならす からくり そうち づくり。
年長〜小学生むけ。物理エンジンは **じさく**（外部ライブラリ・CDN なし）、描画は Canvas。

公開URL: https://kisi1554.github.io/Pages/korokoro-souchi/

## あそびかた

1. よこながの ステージ（よこから みた 2D）。スタートに ボール、ゴールに ベル。
2. したの **どうぐばこ** から ぶひんを えらんで、ステージを **タップ** で おく（どうぐばこから ドラッグでも おける）。
   おいた ぶひんは **ドラッグで いどう**、**タップで 15° かいてん**（⟲ ボタンで ぎゃくまわり）、**🗑️ へ ドラッグで さくじょ**。
3. **▶ スタート** で シミュレーション。ベルに なにかが あたると チーン＋かみふぶき で クリア。**⏹** で もとの はいちに もどる。
4. **グレー** の ぶひんは うごかせない。つかえる ぶひんの かずは ステージごとに きまっている。
5. 💡 ヒント で こたえの ぶひんを 1つ うすく みせる。

| ステージ | ないよう |
| --- | --- |
| 1〜5 | たりない ぶひんを 1つ おく（ボール・さか・ドミノ・ばね・ファン） |
| 6〜10 | 2〜3こ おく（はしを かける・ドミノ ならべ・ばね＋さか・ファン＋ジャンプだい・かべ＋いた） |
| 11〜15 | ドミノ・シーソー・バケツ（かっしゃ）を くみあわせる。15 は ドミノ → バケツ → とびら → シーソー → ベル |
| 16〜30 | **もっと ステージ**（「ころころ そうち 2」の 15ステージを この エンジンに うつした もの）。16〜20 は 1こ、21〜25 は 2〜3こ、26〜30 は シーソー・ドミノ・バケツ。30 は ドミノ → バケツ → とびら → シーソー → ベル |

- しんちょく（クリアした ステージ）・おと オン/オフ は localStorage（`korokoro-souchi-v1`）。ステージは まえを クリアすると ひらく（1 と 16 は さいしょから あそべる）。
- **じゆう モード**: ぶひん つかいほうだい。いまの はいちは じどう ほぞん、べつに **5スロット** に ほぞん／よみこみ（サムネイル つき、JSON）。

## ぶひん（`parts.js`）

| ぶひん | からだ | メモ |
| --- | --- | --- |
| てつだま / ゴムだま | えん（r=24） | てつ: みつど 3・はねかえり 0.25 / ゴム: みつど 0.5・0.6。ゴムだけ ファンで おされる |
| いた（みじかい・ふつう・ながい） | うごかない ながしかく 180/280/400 × 16 | |
| ドミノ | うごく ながしかく 18 × 80 | かいてん あり |
| シーソー | まんなかで ピン どめ（いちは こてい・かいてんだけ）±20° | ベルに あたっても クリア |
| ばね | うごかない ながしかく | あたると さいてい 620px/s で はねかえす |
| バケツ（かっしゃ） | キネマティック 3まい＋とびら | なかの おもさの ごうけいが `need`（ふつう 500。#29 は 3000 で ゴムだま だけでは さがらない）いじょうで さがり、ひもで とびらを ひっぱりあげる（スクリプトで かんい しょり）。タップで とびらの むきを はんてん |
| かべ | うごかない ながしかく 24 × 180 | |
| ファン | うごかない はこ＋かぜの はんい 380 × 120 | かるい ボールに かそくど（とおいほど よわい） |
| ベル | うごかない えん | うごく ものが ふれたら クリア |
| だい（block） | うごかない ながしかく（w × h） | ステージ よう の グレーの だい。どうぐばこ には でない |

うごかない ぶひん どうし（いた と かべ、いた と ゆか など）は かさねて おける。うごく ぶひんは めりこむ ばしょには おけない。

## ぶつりエンジン（`physics.js`）

- 剛体は「えん」と「かいてんする ながしかく」だけ。じゅうりょく 1500px/s²、はねかえり、まさつ。
- しょうとつ: えん-えん、えん-ながしかく、ながしかく-ながしかく（SAT＋めんの クリッピングで 2てん）。
- シーケンシャル インパルス（12かい）＋ ウォームスタート ＋ バウムガルテ いち ほせい。こてい タイムステップ 1/120 びょう。
- ねむり: 0.5びょう とまった ものは けいさんを やめ、うごく ものが ぶつかると おきる。おきた ものは さらに となりを おこす（シーソーに のって ねむった ボールが シーソーを とめて しまわない ため）。
- `Math.random` を つかわないので **けっていてき**（おなじ はいちなら まいかい おなじ けっか）。

## ステージ データ（`stages.js`）

`{ name, hint, fixed: [ぶひん f:1], inv: { しゅるい: かず }, sol: [こたえの れい] }`。
ぶひんは `{ t, x, y, a(°) }`（せかいは 1200×800、ゆかは y=770）。
