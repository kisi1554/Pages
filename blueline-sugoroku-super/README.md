# ブルーライン すごろく スーパー 🚇🎲

[`blueline-sugoroku/`](../blueline-sugoroku/)（ブルーライン＆でんえんとしせん すごろく）を もとに つくりなおした すごろく。
湘南台 → ブルーライン → あざみ野で のりかえ → 東急田園都市線 → 中央林間（43えき）。

`index.html` だけで うごく（外部ライブラリ・画像・音声ファイルなし。おとは WebAudio の 合成音）。

公開URL: https://kisi1554.github.io/Pages/blueline-sugoroku-super/

## あそびかた

1. タイトルで コースと メンバーを えらぶ（タッチで なまえ／🙂ひと・🤖ロボ・💤おやすみ／クイズの むずかしさ）
2. 🎲 サイコロを ふる。カードが あれば タッチして つかえる（せつめいが でてから「つかう！」）
3. とまった マスで できごと:
   - ⚔️ こうげき … あいてに クイズ。まちがえると マスに かいてある ぶん もどる／1かい やすみ（3にん いじょうは あいてを えらぶ）
   - 🧠 チャンス … じぶんが クイズ。せいかいで もう 1かい サイコロ
   - 🎁 カード … 1まい もらう（3まい もっていたら 1つ すすむ）
   - ✨ なにかな？ … えきに ちなんだ できごと（新横浜＝しんかんせんで 3つ すすむ など）
4. さきに 中央林間に ついた ひとの かち

「かいそく」マークは ブルーラインの 快速／田園都市線の 急行が とまる えき（戸塚〜湘南台は かんたんに するため 戸塚だけ）。

## つくり

- えきは `RAW`（なまえ・えきナンバー・かいそく・マス・まめちしき）。できごとは `EV`。クイズは `K1` / `K2` と えきデータから つくる。
- 進捗は localStorage `blueline-sugoroku-super.v1`（スタンプ・かちかず・せってい・とちゅうの ゲーム）。
- URL に `#debug` で `window.__sugo`（`auto(true)` で じどうプレイ、`spd(40)` で はやまわし、`force([3])` で サイコロの め）。
- ズーム対策は `tools/no-zoom.py` の 共通ブロック。
