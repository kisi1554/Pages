### ② スーパーボール すくい

### ⑤ どれが いちばん はねる？

- **くらべる**: スーパーボール・ゴムボール・テニスボール・ピンポンだま・ボウリングの たま を 100cm から ならべて どうじに おとし、

## ぶつりエンジン（`physics.js`）

- うごく からだは **えん だけ**。うごかない もの: へいめん（かべ・ゆか）、せんぶん（ふとさ つき。うごく ポイにも つかう）、ながしかく、えん。
- じゅうりょく、はねかえりけいすう（スーパーボール 0.9）、まさつ、**かいてん**（かくそくど）。
  せってんの すべりで かいてん と へいしん が やりとり する。せっせん ほうこうにも はねかえり（`et`）が あるので、
  **つくえの したに ななめに なげると、ゆか と つくえの うらで はねて なげた ほうへ もどってくる**（テストで たしかめる）。
- えん-えん は **くうかん ハッシュ**（セル 64px、おおきい ボールは いくつもの セルに はいる）で ちかい ものだけ。
- 1フレームを **6 サブステップ** に わけて すりぬけを ふせぐ。はやさの じょうげん 3200px/s × がめんの おおきさ。
- おそい しょうとつ ほど はねかえりを なめらかに よわく して、とまりかけた ボールは **ねむらせる**（けいさんを とめる）。つよく ぶつかると おきる。
- **ボールは 200こ まで**。fps が 45 を きったら、あたらしい ボールを だす かわりに ふるい ボールを ぽんっと けす。
- がめんの おおきさ・むきが かわったら かべを つくりなおし、そとに でた ボールは なかへ もどす。
- こてい タイムステップ（1/60 びょう）。`Math.random` を つかわないので けっていてき。

### ボール 200こ の ときの fps

`e2e.js` で 200こ だして 3びょう はかった あたい（Playwright の Chromium・ヘッドレス、deviceScaleFactor 2）:

| がめん | fps |
| --- | --- |
| スマホたて 390×844 | 約 60 |
| タブレットよこ 1024×768 | 約 45（42〜50） |

この かんきょうは GPU なしで Canvas を CPU で えがく ので、ほんものの たんまつ より おそめに でる。
はやく する ために: ボールは「もよう（かいてん 24だんかい）＋つや」を 1まいの スプライトに して キャッシュし、
1こ 1かいの `drawImage` で かく（つぶれる ときだけ へんけい）。ぶつりは 200こ で 1フレーム 約 0.5ms。
devicePixelRatio は 2 まで つかう。
