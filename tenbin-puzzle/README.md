# てんびん パズル ⚖️

てんびんの かたむきから おもさを すいりする、とうしき（＝）の はじめの パズル。
年長〜小学校中学年むけ。

公開URL: https://kisi1554.github.io/Pages/tenbin-puzzle/

## あそびかた（3しゅるい ＋ ボーナス）

| モード | むずかしさ | なにを する |
| --- | --- | --- |
| くらべっこ | ★ | 2〜4この ものを てんびんで くらべて、おもい じゅんに ならべる（12ステージ） |
| おきかえ すいり | ★★ | つりあった ヒントの てんびん（1〜3こ）から「🍌 は 🍊 なんこ ぶん？」を こたえる（13ステージ） |
| つりあわせ | ★★〜★★★ | 1・2・5・10 の ぶんどうで ぴったり つりあわせる。うしろの 5ステージは ひだりにも のせて よい（ひきざん）（14ステージ） |
| にせものの きんか | ボーナス | 9まいの うち 1まい だけ かるい。てんびん 2かい で みつける |

- ものや ぶんどうは **タップで のせる／おさらの うえを タップで おろす**（ドラッグ は いらない）。
- てんびんは ひだり − みぎ の おもさの さ で かたむく（さ 1 でも 5°、おおきいほど かたむき 18° で とまる）。
  ばね-ダンパ で ゆらゆら → ぴたっと とまり、つりあうと「カチッ」＋ きらきら。
- おきかえ すいり と にせものの きんか では、てんびんに **ささえ** が して あり「はかる」で はじめて うごく
  （のせて いる うちに こたえが わかって しまわない ように）。すうじボタンを おすと その かず だけ のせて はかる。

### ★ の つけかた

| モード | ⭐⭐⭐ | ⭐⭐ | ⭐ |
| --- | --- | --- | --- |
| くらべっこ | 1かいで せいかい ＆ くらべた かいすうが n−1 〜 めやす（2こ:1 / 3こ:3 / 4こ:5） | 1かいで せいかい | まちがえて から せいかい |
| おきかえ すいり | まちがい 0 | まちがい 1 | それ いじょう |
| つりあわせ | いちばん すくない ぶんどうの かずで つりあう | それ いがい | — |
| にせものの きんか | けっかから 1まいに しぼれて せいかい | — | うんで あたり |

ステージは まえの ステージを クリアすると ひらく。★ と しんちょくは localStorage（`tenbin-puzzle-v1`）。

## ステージ データ（`stages.js`）

- `KURABE`: `{ items: [{ e, w }] }` … おもさ `w` は みせない。ふうせん（かるい）と れんが（おもい）など みためと ちがう ものも。
- `OKIKAE`: `{ w, scales: [[ひだり], [みぎ]], ask: [きく もの, たんい], answer }` … 2だん すいり まで
  （A＝B＋B、C＝A＋B）。うしろの ほうは かけざん（🍉＝🍈×4、🍈＝🍋×3 → 12）や ひきざん（🍌🍊＝🍎🍎）が いる。
- `TSURIAI`: `{ e, w, inv: {ぶんどう: こすう}, show, both, lv }` … `show` で おもさを みせる、`both` で ひだりにも のせられる。
- `deduce(stage)`: こどもと おなじ「わからない ものが 1しゅるい だけの てんびん から とく」やりかたで こたえと だんすう を だす。
- `weighOptions(w, inv, both)`: ぶんどうの のせかたを ぜんぶ ためして、いちばん すくない こすう と「みぎ だけで できるか」を かえす。
- `coinCandidates(history)`: はかった けっかと むじゅん しない にせもの こうほ。
