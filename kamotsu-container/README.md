# かもつ コンテナ キャッチ 📦

貨物駅の クレーンから コンテナを おとして、したを はしる 貨車（かしゃ）に のせる アクションゲーム（5さい〜）。
やさい・おかし・本などが トラック だけでなく **貨物列車の コンテナ** でも はこばれている ことを 知るのが ねらい。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. レベルと はやさ（🐢ゆっくり／🐇ふつう）を えらぶ。
2. クレーンに つられた コンテナが、したの 貨車の うえに きたら **タップ**（がめんの どこでも よい。下半分も ぜんぶ タップ領域）。
   のる タイミングに なると ガイドの せんが オレンジに なり「いまだ！ タップ！」が でる。
3. コンテナの いろ＝行き先。おなじ いろの 貨車に のせると「ぴったり！」（✨の かず）。ちがう いろでも のる。
4. のせそこねても こわくない えんしゅつ だけ: ぽよーんと はねて 駅の 人の あたまに のる（おっとっと）／
   やさいの コンテナは なかみが ころころ ころがって 駅じゅう やさいだらけ。コンテナは ふわっと クレーンに もどって やりなおし。
5. おもい コンテナ（じゃがいも・ほん・のみもの）を のせると 貨車が「うっ」と しずむ。
6. ぜんぶ のせたら きかんしゃが しゅっぱつ → 日本地図の うえを 行き先まで はしり、とどいた にもつが でる。
7. けっか: ⭐（いろ ぴったりの わりあい）・かかった じかん（きろく だけ）・まなび カード。

時間切れ・ゲームオーバーは なし。「あと なんこ」は いつも 画面の うえに 数字で でる。1かい 1〜3ぷん。

| レベル | 貨車 | コンテナ | はやさ | 行き先 |
| --- | --- | --- | --- | --- |
| 1 | 5りょう | 5こ（いろ 1しゅるい） | ×0.85 | 札幌貨物ターミナル → 東京貨物ターミナル（たまねぎ・じゃがいも） |
| 2 | 10りょう | 10こ（2いろ） | ×1.0 | 東京貨物ターミナル → 名古屋貨物ターミナル・吹田貨物ターミナル |
| 3 | 8りょう（うち 3りょうは 2こ のる） | 11こ（3いろ） | ×1.3 | 東京貨物ターミナル → 名古屋・吹田・福岡貨物ターミナル |

ほぞん（おと・はやさ・レベルごとの ⭐と きろく・あつめた カード）は localStorage（`kamotsu-container-v1`）。

## データと 出典（まなび カード）

| カード | ないよう | 出典 |
| --- | --- | --- |
| 貨物列車は ながーい | コンテナ列車の 最長は 26両。1編成で 10トントラック 65台分 | 国土交通省 資料「貨物列車１編成（最大26両）の輸送能力は、10トントラック65台分に相当」、JR貨物 講演資料（国交省 四国運輸局 2018）「コンテナ列車の最長は26両編成（最大650トン牽引可能）＝トラック65台分」 |
| コンテナ | 12フィートコンテナは 5トン積み、コンテナ貨車 1両に 5個 | JR貨物の 12ftコンテナ（5トン積み）。26両編成で 130個（12ft換算）＝1両 5個（東京タ〜福岡タの 列車の 例） |
| 機関車が ひっぱる | 貨車には モーターが なく 先頭の 機関車が ひっぱる。電化されていない 区間は ディーゼル機関車 | JR貨物の 機関車（電気機関車・ディーゼル機関車） |
| 北海道の やさい | たまねぎ・じゃがいもは 貨物列車で 青函トンネルを とおって 本州へ。じゃがいもの 時期だけ 走る 専用列車も ある | JR貨物 2025年 帯広貨物駅→熊谷貨物ターミナル駅の 馬鈴薯 専用列車（コンテナ車20両・12ftコンテナ100個）の 報道発表 |
| トラックと いっしょに | 貨物駅から 先は トラックで はこぶ | JR貨物の 鉄道コンテナ輸送の しくみ |

- 駅名は じっさいの JR貨物の 貨物駅（札幌貨物ターミナル・東京貨物ターミナル・名古屋貨物ターミナル・吹田貨物ターミナル・福岡貨物ターミナル）。
  画面では かならず ふりがなを つけ、地図の うえは ひらがなで かく。
- **ゲームの ための かんりゃくか**: ほんものの コンテナ貨車には 12ftコンテナが 5個 のるが、ゲームでは 1りょうに 1こ（レベル3の 長い だいは 2こ）。
  1本の 列車で 行き先ごとに いろわけ するのも ゲームの ルール（じっさいも とちゅうの 貨物駅で 積みおろし する 列車は ある）。
  これは「おうちの かたへ」にも 書いた。
- 地図の みちすじ（函館・青森・盛岡・仙台・郡山／静岡・岡山・広島・下関を とおる）は だいたいの もの。島の かたちも かんたんな オリジナル。
- 貨車・機関車・コンテナ・クレーンの えは オリジナル（色は 行き先の いろ）。鉄道会社の ロゴ・マーク・発車メロディは 使っていない。

## しかけ

- ぜんぶ 1まいの `<canvas>`（`touch-action: none`、`pointerdown` で タップ）と requestAnimationFrame。はいけいは オフスクリーンに 1回だけ かいて、絵文字も キャッシュして かるく している。
- 貨車は「まだ からの だい」が クレーンの まわりを いったり きたり する ように おりかえす（とりのこしが ない）。
- 落ちる 時間は がめんの 大きさに かかわらず 0.45びょう。あたりの はば は コンテナ はば の ±0.5。
- 画面の むきが かわったら 列車の 大きさを あわせなおす（とちゅうの のせた コンテナは そのまま）。
- `python3 tools/no-zoom.py kamotsu-container` で ズーム対策ブロックを いれている。
- `window.__kc` は Playwright の テスト よう（`G`・`predict()`・`tap()`）。
