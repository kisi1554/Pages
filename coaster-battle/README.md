# ジェットコースター ロボ バトル 🎢🤖

はしる **ジェットコースターの うえ** で ロボットが 1たい1 で たたかう 3D かくとう ゲーム（年長〜小学生むけ）。
ループ・さかさま・くるりん ひねり・ふわっと うく おか・トンネル… コースが うごくたびに たたかいかたも かわる。

`index.html` をブラウザで開くだけで遊べます。**外部ライブラリ・CDN なし**（3D は WebGL を 手がき、おとは WebAudio の ごうせいおん）。

## あそびかた

| そうさ | タッチ | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| うごく | ◀ ▶ | ← → / A D | ひだりスティック・じゅうじキー |
| ガード | あいてと はんたいに うごく | おなじ | おなじ |
| ジャンプ | ⬆️ | ↑ / W / スペース | A |
| パンチ（3かいで れんぞく わざ） | 👊 | J / Z | X |
| キック（ふっとばし。くうちゅうで きゅうこうか） | 🦶 | K / X | Y |
| ひっさつ（ゲージ まんたん） | 🔥 | L / C | B / RB |
| ていし | ⏸ | P / Esc | |

- さきに **2ラウンド** かったほうの かち。KO しないまま ゴール 🏁 したら、げんきが おおいほうの かち。
- れっしゃの はしから おとすと **-15**。おちた ロボは ふうせん 🎈 で もどってくる（じぶんから あるいて おちることは ない）。
- げんきが へるほど ふっとびやすく なる。

## ジェットコースターの しかけ

- コースは 1000m あまり（のぼり → だいきな さか → ふわっと おか → かたむいた カーブ → ループ → ひねり → らせん → トンネル → ひねり → ゴール）。
- ほんとうの G を けいさんして たたかいに いれている:
  - **ふわっ！🎈** おかの てっぺんでは かるくなって たかく とべる
  - **ずっしり！💪** たにや ループでは おもくなって ひくくしか とべない
  - **ぐいーん** かそく・ブレーキで ずるずる すべる
  - **さかさま！🙃** じしゃく ブーツ で おちない
- 2ラウンドめからは そのまま のりつづける。ラウンドごとに ひる → ゆうやけ → よる（ライトが ひかる）。
- タイトルがめんの うしろでは CPU どうしが たたかう デモが ながれる。
