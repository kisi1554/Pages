# ろせんず ほんとの かたち 🫠

ろせんずは、ほんとうの 地図を「まっすぐ」「駅の あいだを おなじ ながさ」に かんたんに した 絵（デフォルメ）。
ぐにゃ〜っと へんしん させて、ろせんず ⇄ 地図 を 行ったり 来たり する（5さい むけ・1コース 1〜3分）。
`index.html` だけで うごく（外部ライブラリ・CDN なし。音は WebAudio の 合成音、オン/オフ あり）。

## あそびかた（1コース 5ステップ）

1. 🫠 **へんしん** … スライダーで ろせんず → ほんとうの 地図へ。とちゅうの ぐにゃぐにゃで 電車が 目を まわす（😵 め、めが まわる〜）。
2. ❓ **クイズ**「ほんとうの 形は どれ？」… ほんもの／ろせんずと おなじ きれいな 形／さかさま から えらぶ。
   答えあわせの あとで 電車が「ろせんずに だまされた〜！」。
3. 🧩 **パズル**「この 地図を ろせんずに すると？」… ① がめんを なぞって 線を まっすぐ（山手線は まるく）のばす
   （のばしすぎると 線が がめんから はみでて ぼよよん）② 駅を タップして てんてんの ○（おなじ あいだ）へ ぴょん。3つ タップすると「のこり ぜんぶ」ボタン。
4. 📏 **ながい あいだ さがし** … 地図モードで 駅と 駅の あいだが いちばん ながい ところを タップ
   （いちばんの 9わり いじょうなら せいかい。2回 まちがえると ヒント）。せいかいすると ろせんずに もどして「ほかと おなじ ながさ」を 見せる。
5. ⭐ **まとめ** … まなびカード 3まい・ほし（まちがい 0〜1回 ⭐3／〜3回 ⭐2／それ以上 ⭐1。コースごとに 保存）・つぎの アプリの しょうかい。

## コース

| コース | ろせんずの 形 | ほんとうの 形 |

| 山手線（30駅） | きれいな だえん | たてに ながい でこぼこの わ |
| 東海道新幹線（東京〜新大阪 17駅） | まっすぐ 1本 | 海ぞいに まがる |
| ブルーライン（湘南台〜あざみ野 32駅） | かくっと まがる 線 | 横浜の 町を くねくね |

ろせんずの 形は index.html の `COURSES[].lines[].schem`（だえん、または まがりかどの 点）。
駅は その 線の 上に おなじ あいだで ならべる。へんしんは 駅ごとに ろせんず上の 位置と 地図上の 位置を 線形補間（requestAnimationFrame）。

## データ（index.html の `COURSES` 1か所。確認日 2026-11-27）

- 駅の 位置: 国土数値情報「鉄道データ」N02-24（国土交通省）。駅（ホームの 線分）の 頂点の 平均を 1点に した もの。
  作りかたは [`tools/hontono-katachi/stations.py`](../tools/hontono-katachi/stations.py)。
  山手線の 東がわ（田端〜東京〜品川）は N02 では 東北線・東海道線 なので、そこから とる。
- 駅の じゅんばん・よみ: yamanote-guruguru / tomaru-tobasu で 確認ずみの データ（駅ナンバー順）と 同じ。
  山手線 JY01 東京→JY30 神田／東海道新幹線 東京→新大阪／ブルーライン B01 湘南台→B32 あざみ野／
  銀座線 G01 渋谷→G19 浅草／丸ノ内線 M01 荻窪→M25 池袋（方南町支線は のせない）。
  N02 の 位置で となりの 駅との きょりが 0.4〜61km に おさまる ことを たしかめた（じゅんばんの まちがいが ない ことの チェック）。
- 「ながい あいだ」は 地図の 上の まっすぐの きょり（大圏距離）。線路の 長さ（営業キロ）では ない ので「地図の 上で」と 書いている。
  いちばん: 山手線 目黒〜恵比寿 1.6km（池袋〜大塚 1.5km も せいかい）／新幹線 米原〜京都 61km／ブルーライン 新羽〜仲町台 2.2km／
  地下鉄 新大塚〜池袋 1.7km（後楽園〜茗荷谷 も せいかい）。
- 鉄道会社の ロゴ・公式マーク・路線図デザイン・発車メロディは 使っていない（電車の 絵・ろせんずの 形は オリジナル。線の 色も 近い 色を えらんだ だけ）。

## シリーズ（ろせんず を ふかく 知る 5本）

**かたち（hontono-katachi）** → きごう（rosenzu-kigou）→ とまる駅（tomaru-tobasu）→ ちょくつう（chokutsu-burari）→ むきと ホーム（nobori-kudari）

まとめでは「ろせんずの 線の じゅんばんを 見ると、つぎの 駅が わかるよ」と まとめて、公開ずみの
[とまる？ とばす？](../tomaru-tobasu/) を しょうかいする（rosenzu-kigou が できたら リンクを かえる）。
