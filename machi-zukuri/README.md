# まちづくり（machi-zukuri）

じぶんの まちを つくって あそぶ サンドボックス。まちの しせつが なにを する ところかも わかります。
対象は 年長〜小学校中学年。

## あそびかた

| どうぐ | できること |
| --- | --- |
| 👆 みる | タップすると「なにを する ところ？」「はたらく ひと」を表示（ふりがなつき）。1本指で地図を動かす |
| 🛣️ みち / 🛤️ せんろ | なぞると つながる。角・交差点・踏切（みち×せんろ）は自動。かわの上は 橋・鉄橋になる |
| 🚉 えき | せんろの上に置く（何もない所に置くと せんろごと できる） |
| 🏠 いえ 🏢 マンション 🌳 こうえん 🏫 がっこう 🏥 びょういん 🚒 しょうぼうしょ 🚓 けいさつしょ 👮 こうばん 📮 ゆうびんきょく 📚 としょかん 🛒 スーパー 🥐 パンや 🏭 こうじょう 🥬 はたけ 🌲 き | タップで置く（いえ・き・はたけ などは なぞって たくさん置ける） |
| 🌊 かわ・はし | なぞって かわを ひく。そこに みち／せんろを ひくと はし／鉄橋 |
| 🧽 けす | なぞった所を消す（たてもの → みち・せんろ → かわ の順） |

- 右の ボタン: ▶ じかん（朝・昼・夕方・夜）／×1・×2・×4 はやさ／🗺️ ちずモード／↩️ もどす／🔭 ぜんぶみる／➕ とちを ひろげる（20×20 → 最大 60×60）／💾 ほぞん
- 2本指で ズーム・移動（PC は ホイールと 右ドラッグ）
- **まちの こえ**: ときどき 住民が ふきだしで しゃべる（「びょういん が とおくて こまる」「えき まで みち が ない」など）。
  上の 😊 は にこにこメーター。しせつの 近くに いえが あるほど 上がる
- **できごと**: かじ → いちばん近い しょうぼうしょ から しょうぼうしゃ（届くまでの時間を表示。遠いと「もうすこし ちかく に しょうぼうしょ が あれば…」）。
  びょうき → きゅうきゅうしゃ（しょうぼうしょ から出て びょういんへ運ぶ）。てがみ → ゆうびんやさんが いえを まわる。パトカーの みまわり も
- **ちずモード**: 上から見た地図に切りかえて、ちずきごう（〒・文・＋・× など）と はんれい で表示。
  記号の形は `chizu-takara/` と そろえている（`kigou.js` は `chizu-takara/symbols.js` のコピー）

## しくみメモ

- マスごとに `base`（くさ／かわ）・`road`・`rail`・`obj` を持つ。みち・せんろは となり同士で つながる。
- 経路: 行き先の しせつ ごとに「みちの マスでの距離マップ」を BFS で作って キャッシュ（まちを変えたら捨てる）。
  ひと・くるまは 出発地の となりの みちから 距離が 減る方へ たどる。歩道・左側通行の ずれ を付けた 折れ線を 進む。
- ひと（最大 200人）・くるま（最大 50台）は 1回の おでかけごとに 生まれて、着いたら 消える。時間帯で 行き先と 人数が変わる。
- でんしゃ は せんろの つながり ごとに 走り、えきで とまり、行き止まりで 折り返す。でんしゃの近くの 踏切は しまり、ひと・くるまは 手前で待つ。
- 背景（じめん・たてもの）は 視点・まち・明るさが 変わったときだけ 描き直し、動くものは 前面キャンバスに 毎フレーム描く。
- 保存: localStorage に 3スロット（`machi-zukuri-slot-1`〜`3`、設定は `machi-zukuri-v1`）。
  マスを 1つの数に まとめて ランレングスで 縮めた JSON。読み書きは try/catch。
- 音は WebAudio の合成音のみ（ことん・踏切・でんしゃの チャイム・やさしい サイレン）。🔊 で オン/オフ。
