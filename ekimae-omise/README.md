# えきまえ おみせやさん 🍱

**えきの おべんとうやさん・ばいてんの 店長（てんちょう）に なる ごっこあそび。**
でんしゃで きた おきゃくさんの ちゅうもんを きいて、しなものを そろえ、
おかねを うけとったり おつりを わたしたり します。
おかね・おつり・かず の さんすうと、おみせの しくみを まなべます。

対象：5さい〜しょうがっこう ていがくねん（鉄道好きの子）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリなし・1ファイル）。

## あそびかた（1かいの ながれ）

1. 🚃 でんしゃが えきに つく → おきゃくさんが おりてくる
2. 🗣️ ちゅうもん（れい：「おにぎり ふたつと、おちゃ いっぽん ください」）。
   セリフは 端末の よみあげ（speechSynthesis）で よむ。🔈 で もういちど きける
3. 🍙 たなの しなものを **タッチ か ドラッグ** で おぼんに ならべる → 「そろった！」
4. 💴 おかねの やりとり（レベルで かわる）
   - レベル1・2：おきゃくさんの さいふから「ぜんぶで いくら？」の ぶんだけ とって おさらへ
   - レベル3：レジが ねだんを けいさん。おきゃくさんは 100えんだまで はらうので、
     レジの ひきだしから **おつり** を おさらへ
5. 🎉 はっしゃ までに わたせたら「ありがとう！」→ うりあげが ふえて、でんしゃが でていく

**はっしゃベル** は「ゆるい」せいげんじかん（90〜120びょう）。のこり 15びょうで はっしゃメロディ。
じかんぎれでも しっぱいには せず、おきゃくさんは「また こんど くるね」と のって、
つぎの でんしゃが また きます。タイトルで オフにも できます。

## レベル（3だんかい × こまかい だんかい 3つ）

| レベル | つかう たま | ないよう |
| --- | --- | --- |
| 1 | 10えんだま だけ | ごうけい 100えん まで。おつり なし |
| 2 | 10えん・100えん | ごうけい 110〜400えん。おつり なし |
| 3 | 10えん・50えん・100えん | 100えんだまで はらって もらい、おつりを だす |

レベルの なかでも ★1〜★3 で しなものの しゅるい・こすうが ふえます。
**じどう ちょうせい**：さいきん 4かいの うち 3かい いじょう、ヒントなし・まちがい なしで できて
さいごも そう なら ★が あがる。「いっしょに」や じかんぎれが 2かい つづくと ひとつ さがる。
タイトルで レベル1〜3の スタートいちを えらべます（おうちの方むけ）。

## ヒントの しんごう（トドさんすう の 3しょく）

| しんごう | いみ | でること |
| --- | --- | --- |
| 🟢 あお | じぶんで とく | ヒントなし |
| 🟡 きいろ | ヒント | たなの しなものに わく と「×2」、おかねの ときは たしざんの しき と おさらの ごうけい |
| 🔴 あか | いっしょに とく | おぼん／おさらに うすい わく（おてほん）が でて、つぎに さわる ものが ひかる。とけいは とまる |

「💡 ヒント」ボタン か しんごうを タッチで すすむ。2かい まちがえると じどうで きいろ、
さらに 2かいで あか に なる。まちがえても ペナルティは なく、おきゃくさんが
「おにぎりは ふたつ ほしいな」「すこし たりないかも」と やさしく おしえて くれます。

## ごほうび（がんばれば かならず てに はいる）

うりあげ（ねだんの ごうけい）が たまると、おみせが かざられて いきます。
タイトルの「🎀 おみせを みる」で いつでも みられます。

## しくみ

- `index.html` 1ファイル。でんしゃ・おみせの え は インライン SVG、しなもの は えもじ、
  おかねは CSS で かいた たま。
- 音は WebAudio の 合成音のみ（はっしゃメロディ・ベル・チャリン など）。🔊 で オン/オフ。
  こえ（よみあげ）も 🗣️ で べつに オン/オフ。
- うりあげ・レベル・せってい は localStorage（`ekimae-omise.v1`）に ほぞん。読み書きは try/catch。
- たて もち スマホは うえから じゅんに、よこ もち タブレット（はば 760px いじょう）は
  ひだり＝えき、みぎ＝おみせ の 2れつ。
- テスト用に `window.__ekimae`（いまの おきゃくさん・ほぞん データ）を みられる。
