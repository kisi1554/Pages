# ひらがな たんじょう 🖌️

**かんじが ふでで さらさらと くずれて、ひらがなに へんしん！ どの ひらがなに なるかな？**

`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

## あそびかた

### 🖌️ へんしん クイズ（メイン・1回 1〜2分）

1. もとの かんじ（例: 安）が かみに でる。ふでが うごいて、すみが にじむ ように くずれていく。
2. とちゅうで とまって「どの ひらがなに なる？」。3つから えらぶ（安なら あ・め・ぬ）。
   まちがいの せんたくしは、かたちが にている ひらがな。
3. まちがえても その ボタンが グレーに なるだけ。もじが もうすこし くずれて ヒントに なる。
4. せいかいすると さいごまで へんしんして、むらさきしきぶの まきものに 1もじ たまる。
5. 2もんめ・4もんめの あとに せいしょうなごんが「すてきな もの」を みせる → 「をかし！」スタンプを ぽん。
6. 5もじ たまると『げんじものがたり』の 1ページが ひらく（4ページで ひとまわり）。
   - 2ページめ: じゅうにひとえが おもくて たてない むらさきしきぶ
   - 3ページめ: ものがたりが ながすぎて かみが へやから はみ出す
7. けっか → 「つぎは どんな じだい？」で かまくら じだいを 1文 予告。

### 🔄 ぎゃく モード

ひらがなを みて、もとの かんじを 3つから えらぶ。まちがえると ひらがなが すこし かんじに もどって ヒント。

### ⚽ おまけ：けまり ぽんぽん

まりを タップして けりあげる。じめんに おちたら おしまい。かけごえは「アリ！」「ヤア！」「オウ！」。
8かいめごとに まりが きぞくの えぼしの うえに「ぽすっ」と のる（カウントは そのまま）。さいこう きろくを ほぞん。

### 📖 まなび カード（5まい）

ひらがなの たんじょう／へいあんきょう／きぞくの くらし／げんじものがたり／まくらのそうし。
あそぶと ひらく。それぞれ 保護者むけの 説明（年号など）を 小さく そえている。

## もじ（20）と もとの かんじ（字母）

あ安 い以 う宇 え衣 お於 か加 く久 こ己 さ左 た太 て天 と止 な奈 の乃 ま末 め女 も毛 ゆ由 る留 わ和
（現行ひらがなの字母として一般的なもの）

## 史実メモ

- 平安京遷都 794年（桓武天皇）。平安時代は約400年。
- ひらがな は 万葉仮名 → 草仮名 を経て成立。「女手」とも。片仮名は漢字の一部から（加→カ、伊→イ）。
  いまの1音1字に統一されたのは1900年。
- 『源氏物語』紫式部（中宮彰子に仕える）、11世紀初め、全54帖。「光る君」は作中の呼び名。紅葉賀の巻で青海波を舞う。
- 『枕草子』清少納言（中宮定子に仕える）、1000年ごろ。出てくる「すてきな もの」は本文に基づく
  （春はあけぼの／夏は夜・蛍／秋は夕暮れ・烏／冬はつとめて／うつくしきもの: 雀の子・瓜にかきたるちごの顔・塵を見つける幼児・小さな蓮の浮き葉）。
  原文の評語（をかし／あはれ／つきづきし／うつくし）を各カードに小さく書いている。
- 蹴鞠: 鹿革の鞠、掛け声「アリ」「ヤア」「オウ」。十二単は十数kgともいわれる。

## つくり

- 変身アニメ: かんじ と ひらがな を重ね、`blur` と不透明度を入れかえつつ、親要素の SVG フィルター
  （アルファのしきい値＋`feTurbulence` のゆらぎ）で すみが にじむ ように見せる。
- 音は WebAudio の合成音のみ（琴っぽい はじき音・ふでの さらさら・スタンプ）。🔊 で オン/オフ。
- 進捗は localStorage（`heian-kana-henshin-v1`）: あつめた もじ、スタンプ数、ページ、カード、けまりの さいこう。
- `?fast` を付けると演出が はやおくりに なる（テスト用）。
