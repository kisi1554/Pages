# しろっとクイズ 🗾

**都道府県の かたちが 上から おちてくる、おちものクイズ。**
おちきる前に 4つの中から えらんで こたえます。正かいすれば その かたちは きえますが、
まちがえたり 時間ぎれに なったりすると **下に つもって、もう けせません**。
つもった山が 上まで とどいたら ゲームオーバーです。

`index.html` をブラウザで開くだけで あそべます（ビルドやサーバーは 不要）。

---

## あそびかた

1. かたちが 上から ゆっくり おちてきます。
2. おちきる前に、下の **4つのボタン** から 正しい なまえを えらびます。
3. **正かい** … かたちが ぱっと きえて 点数が 入ります。
   はやく こたえるほど、また れんぞくで あてるほど 高得点です。
4. **まちがい / 時間ぎれ** … かたちが どすんと おちて つもります。
5. **つもった山が 上の 赤い線に とどいたら おしまい。**
6. 47都道府県を ぜんぶ こたえきると **1しゅう クリア**（ノーミスなら パーフェクト）。

おちる はやさ（1〜100）と むずかしさ（3モード）は タイトル画面で えらびます。

### つもりかたの しくみ

かたちは そのままの すがたで つもります。
ぶつかった とき、重心が ささえより 右か左に ずれていたら、
**しゃめんを すべり落ちて、安定したところで 止まります。**
（かたちを マス目に ドット化して あたり判定しています。1マス 7px）

### ヒント

`💡 ヒント` を おすたびに 1つずつ ふえます。使うと その問題の 点数が 20点ずつ へります。

| じゅんばん | ヒント |
| --- | --- |
| 1 | 🧭 地方（関東地方・東北地方 など） |
| 2 | 🏢 中心の まち（県庁所在地） |
| 3 | ⭐ 名産・有名なもの |
| 4 | 🗺 日本地図の どこか（ちいさな地図で 光ります） |

### おちる はやさ（1〜100）

タイトル画面の スライダーで **100段階** に 調節できます。**20 が きじゅん**（= 11マス/秒。
1つが おちきるまで やく 7秒）で、1めもりごとに 0.55マス/秒 ずつ はやくなります。

| めもり | マス/秒 | おちきるまで | 点数のばいりつ |
| ---: | ---: | ---: | ---: |
| 1 | 0.6 | やく 142びょう | 0.53ばい |
| 10 | 5.5 | やく 14びょう | 0.75ばい |
| **20** | **11** | **やく 7びょう** | **1.00ばい** |
| 40 | 22 | やく 3.5びょう | 1.50ばい |
| 70 | 38.5 | やく 2.0びょう | 2.25ばい |
| 100 | 55 | やく 1.4びょう | 3.00ばい |

- はやくするほど **点数の ばいりつが 上がります**（`0.5 + めもり ÷ 40`）。
- 正かいするたびに 3%ずつ さらに はやくなり、**えらんだ はやさの 2ばい**で うちどめです。
- えらんだ はやさは ブラウザに 保存され、つぎに ひらいたときも そのままです。

### むずかしさ

はやさとは べつに、**見た目と 4択の むずかしさ**を えらびます。

| モード | かたむき | 4択の えらばれかた | ヒント | 点数のばいりつ |
| --- | --- | --- | --- | --- |
| 🐢 やさしい | なし | ちがう地方から（見わけやすい） | 1つめは さいしょから 無料 | 1.0ばい |
| 🚶 ふつう | ±7° | 1つは おなじ地方から | 自分で おす | 1.5ばい |
| 🐇 むずかしい | ±16° | おなじ地方 or 大きさが 近いものから | 自分で おす | 2.0ばい |

ハイスコアは モードごとに ブラウザに 保存されます。

| `index.html` | 画面の わく（タイトル・ゲーム・けっか の3画面） |

## 出題テーマを ふやすには

都道府県いがい（国・電車・動物 など）も 足せるように、データと ゲームを 分けてあります。
`topics/` に ファイルを 1つ ふやして `index.html` から よみこむだけです。

```js
SHIROTTO_TOPICS.push({
  id: 'country',                       // 保存キーに つかう。ほかと かぶらないように
  name: '国',                          // タイトル画面の ボタン名
  emoji: '🌍',
  question: 'この かたちは どこの 国？',
  unit: '国',                          // けっか画面の 文に つかう
  overviewViewBox: null,               // 全体図が あれば '0 0 100 100' のような文字列
  groups: [{ id: 'asia', name: 'アジア' }],
  items: [
    {
      id: 'jp', name: '日本', kana: 'にほん', group: 'asia',
      box: { x: 0, y: 0, w: 100, h: 80 },  // shape の 外接四角形
      hints: { group: 'アジア', capital: '東京', famous: [{ e: '🗻', name: 'ふじさん' }] },
      shape: 'M...',                       // 落ちてくる かたち(SVGの d)
      path: 'M...',                        // ちずヒント用。全体図が なければ shape と同じでよい
    },
  ],
});
```

- `shape` と `path` は **おなじ座標系**にして ください（`box` は `shape` の 外接四角形）。
- ゲーム側は 大きさを 自動で そろえます（元の 大小は すこしだけ のこります）。
- `overviewViewBox` が `null` の テーマでは、4つめの「ちず」ヒントは 出ません。

## 都道府県データの 作りなおし

`topics/prefecture.js` は 手で 編集しないでください。
[日本地理たんけん](../nihon-chiri-tanken/) の データから 作っています。

```bash
node tools/shirotto-quiz/generate_topic_prefecture.js   # リポジトリのルートで
```

- 形 … `nihon-chiri-tanken/map-data.js`（国土数値情報(国土交通省)由来の 都道府県境界）
- 地方・県庁所在地・名産 … `nihon-chiri-tanken/data.js`
- 落ちてくる形は、小さい離島を はぶいた「本土のかたち」にしています
  （東京の 小笠原、鹿児島の 南西諸島 などが 入ると、ほとんど すきまの かたちに なってしまうため）。
