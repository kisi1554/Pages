# しろっとクイズ 🗾🔺🧊

**かたちが 上から おちてくる、おちものクイズ。**
おちきる前に 4つの中から えらんで こたえます。正かいすれば その かたちは きえますが、
まちがえたり 時間ぎれに なったりすると **下に つもって、もう けせません**。
つもった山が 上まで とどいたら ゲームオーバーです。

`index.html` をブラウザで開くだけで あそべます（ビルドやサーバーは 不要）。

## 出題テーマ

タイトル画面で えらびます。ハイスコアは テーマ × むずかしさ ごとに 保存されます。

| テーマ | なかみ | 出る問題 | 1ゲーム |
| --- | --- | --- | --- |
| 🗾 **都道府県** | 47都道府県の 本土のかたち | 名前 | 47問で 1しゅう |
| 🔺 **平面図形** | 三角形・四角形・多角形・円 の 14こ | 名前／辺の数／直角の数 | くりかえし（山が つもるまで） |
| 🧊 **立体図形** | 柱・すい・球 の 10こ（**見取図**・見えない辺は 点線） | 名前／面の数／辺の数／頂点の数 | くりかえし（山が つもるまで） |

図形テーマでは かたちを **かたむけません**（正方形が ひし形に 見えてしまうため）。

## あそびかた

1. かたちが 上から ゆっくり おちてきます。
2. おちきる前に、下の **4つのボタン** から 正しい こたえを えらびます。
   （図形テーマでは「名前は？」のほかに「面は いくつ？」なども 出ます）
3. **正かい** … かたちが ぱっと きえて 点数が 入ります。
   はやく こたえるほど、また れんぞくで あてるほど 高得点です。
4. **まちがい / 時間ぎれ** … かたちが どすんと おちて つもります。
5. **つもった山が 上の 赤い線に とどいたら おしまい。**
6. 都道府県テーマは 47問 こたえきると **1しゅう クリア**（ノーミスなら パーフェクト）。
   図形テーマは 数が 少ないので **くりかえし** 出ます。

おちる はやさ（1〜100）と むずかしさ（3モード）は タイトル画面で えらびます。

### つもりかたの しくみ

かたちは そのままの すがたで つもります。
ぶつかった とき、重心が ささえより 右か左に ずれていたら、
**しゃめんを すべり落ちて、安定したところで 止まります。**
（かたちを マス目に ドット化して あたり判定しています。1マス 7px）

### ヒント

`💡 ヒント` を おすたびに 1つずつ ふえます。使うと その問題の 点数が 20点ずつ へります。

| テーマ | ヒントの じゅんばん |
| --- | --- |
| 🗾 都道府県 | 🧭 地方 → 🏢 中心の まち → ⭐ 名産 → 🗺 日本地図の どこか（光ります） |
| 🔺 平面図形 | 🧭 なかま → 📏 辺や かどの とくちょう → 身近な ものの たとえ |
| 🧊 立体図形 | 🧭 なかま → 🔺 そこの 面の かたち → 身近な ものの たとえ |

**こたえが ばれる ヒントは 出しません。** たとえば「面は いくつ？」の問題では
「面が ぜんぶ 三角形」の ヒントは かくれます（データの `hide` で 指定）。

### おちる はやさ（1〜100）

タイトル画面の スライダーで **100段階** に 調節できます。**20 が きじゅん**（= 11マス/秒。
1つが おちきるまで やく 7秒）で、1めもりごとに 0.55マス/秒 ずつ はやくなります。

| めもり | マス/秒 | おちきるまで | 点数のばいりつ |
| ---: | ---: | ---: | ---: |
| 1 | 0.6 | やく 142びょう | 0.53ばい |
| 10 | 5.5 | やく 14びょう | 0.75ばい |
| **20** | **11** | **やく 7びょう** | **1.00ばい** |
| 40 | 22 | やく 3.5びょう | 1.50ばい |
| 70 | 38.5 | やく 2.0びょう | 2.25ばい |
| 100 | 55 | やく 1.4びょう | 3.00ばい |

- はやくするほど **点数の ばいりつが 上がります**（`0.5 + めもり ÷ 40`）。
- 正かいするたびに 3%ずつ さらに はやくなり、**えらんだ はやさの 2ばい**で うちどめです。
- えらんだ はやさは ブラウザに 保存され、つぎに ひらいたときも そのままです。

### むずかしさ

はやさとは べつに、**見た目と 4択の むずかしさ**を えらびます。

| モード | かたむき | 4択の えらばれかた | ヒント | 点数のばいりつ |
| --- | --- | --- | --- | --- |
| 🐢 やさしい | なし | ちがう地方から（見わけやすい） | 1つめは さいしょから 無料 | 1.0ばい |
| 🚶 ふつう | ±7° | 1つは おなじ地方から | 自分で おす | 1.5ばい |
| 🐇 むずかしい | ±16° | おなじ地方 or 大きさが 近いものから | 自分で おす | 2.0ばい |

ハイスコアは モードごとに ブラウザに 保存されます。

## 出題テーマを ふやすには

ほかの ジャンル（国・電車・動物 など）も 足せるように、データと ゲームを 分けてあります。
`topics/` に ファイルを 1つ ふやして `index.html` から よみこむだけです。

```js
SHIROTTO_TOPICS.push({
  id: 'country',                       // 保存キーに つかう。ほかと かぶらないように
  name: '国',                          // タイトル画面の ボタン名
  emoji: '🌍',
  unit: '国',                          // けっか画面の 文に つかう
  question: 'この かたちは どこの 国？',  // quizzes を 書かないときの 問題文
  overviewViewBox: null,               // 全体図が あれば '0 0 100 100' のような文字列
  allowTilt: false,                    // true(しょうりゃく時)なら モードに あわせて かたむく
  loopItems: true,                     // 数が 少ないとき。false なら 1しゅうで おわり
  quizzes: [                           // 出題タイプ。書かなければ「名前」だけ
    { id: 'name', weight: 3, question: 'この かたちは どこの 国？', field: 'name' },
    { id: 'area', weight: 1, question: 'この国の となりの国は いくつ？', field: 'neighbors', suffix: 'こ' },
  ],
  groups: [{ id: 'asia', name: 'アジア' }],
  items: [
    {
      id: 'jp', name: '日本', kana: 'にほん', group: 'asia',
      box: { x: 0, y: 0, w: 100, h: 80 },   // shape の 外接四角形
      props: { neighbors: 0 },              // せいしつの 問題に つかう 数
      hints: [                              // 上から じゅんばんに 出す
        { e: '🧭', text: 'アジアの 国' },
        { e: '🗻', text: 'ふじさんが ある', hide: ['area'] },   // この問題では 出さない
        { kind: 'map' },                    // 全体図で 場所を 光らせる
      ],
      shape: 'M...',                        // 落ちてくる かたち(SVGの d)
      lines: [{ d: 'M...', dash: true }],   // かさねて 引く 線。立体の 見えない辺など
      path: 'M...',                         // ちずヒント用。全体図が なければ いらない
    },
  ],
});
```

- `shape` `lines` `path` は **おなじ座標系**にして ください（`box` は `shape` の 外接四角形）。
- あたり判定に つかうのは `shape` だけです（`lines` は 見た目のみ）。
- `props` に 数が ない図形は、その せいしつの 問題には 出ません
  （たとえば 球の「辺の数」は 出しません）。
- 4択の にせものは、`field` が `name` なら **ほかの item**、それ以外なら
  **ほかの item の おなじ せいしつの 数**から えらばれます。
- ゲーム側は 大きさを 自動で そろえます（元の 大小は すこしだけ のこります）。
- `overviewViewBox` が `null` の テーマでは、`{ kind: 'map' }` の ヒントは 出ません。

## データの 作りなおし

`topics/*.js` は 手で 編集しないでください。作りなおしは リポジトリのルートで:

```bash
node tools/shirotto-quiz/generate_topic_prefecture.js   # → topics/prefecture.js
node tools/shirotto-quiz/generate_topic_figures.js      # → topics/plane.js, topics/solid.js
```

### 都道府県

[日本地理たんけん](../nihon-chiri-tanken/) の データから 作っています。

- 形 … `nihon-chiri-tanken/map-data.js`（国土数値情報(国土交通省)由来の 都道府県境界）
- 地方・県庁所在地・名産 … `nihon-chiri-tanken/data.js`
- 落ちてくる形は、小さい離島を はぶいた「本土のかたち」にしています
  （東京の 小笠原、鹿児島の 南西諸島 などが 入ると、ほとんど すきまの かたちに なってしまうため）。

### 図形

平面図形は 頂点の 座標から、立体図形は **3Dの 頂点と 面から 見取図を 計算**して 作ります。

- 投影は 教科書と 同じ 斜投影（おくゆきが 右上へ ずれる）。
- 面の むきから **見える辺（実線）と 見えない辺（点線）**を 分けています。
- 落ちてくる かたち（あたり判定にも つかう）は 頂点の **凸包**（シルエット）。
- 円柱・円すい・球は だ円の 弧を 手で 組み立てています。
- **まるい立体の「面・辺・頂点の 数」は 出題しません**。数え方が 学年や 教科書で
  分かれるためです（`props` を からにして あります）。
