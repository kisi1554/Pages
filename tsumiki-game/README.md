# つみきは いくつ？（立体図形・見えないブロックを数えるゲーム）

積み上げた立方体の絵を見て、全部で何個あるかを答えるゲームです。中学受験の立体図形で
最頻出の感覚である「**見えていないブロックも数える**」を、幼児から扱えるようにしました。

## あそびかた

1. `index.html` をブラウザで開くだけで遊べます（インストール不要・オフラインOK）。
2. ステージ（やさしい／ふつう／むずかしい）を選ぶとスタート。
3. 積み木の絵を見て、聞かれたことを数字ボタンで答えます。全6問。
   聞かれることは3種類あります（ステージによって出るものが変わります）。
   - **ぜんぶで なんこ？** … 見えないブロックも含めた総数
   - **かくれて みえない つみきは なんこ？** … 隠れているぶんだけを数える
   - **おなじ たかさの しかくい はこに するには あと なんこ？** … 直方体にするのに足りない数
4. わからないときは3つの道具が使えます。
   - 🔄 **まわして みる** … 視点を90度ずつ回します。裏に隠れていたブロックが見えます。
   - 🔍 **すけて みる** … 全体を透かして、隠れているブロックをピンクで浮かび上がらせます。
   - 📦 **はこに してみる** … 直方体にするのに足りないところを点線で見せます
     （「あと何個？」の問題のときだけ出ます）。
   - 👉 **いっしょに かぞえよう** … 1個ずつ光らせながら声に出して数えます。
     数え終わった分が金色で積み上がるので、二度数え・数えもれに自分で気づけます。
     **聞かれていることに合わせて数えるものが変わります**（総数／隠れているぶん／足りないぶん）。

## 工夫したポイント

- **「見えないけれど、ある」を目で見せる**: このゲームの本体は透視モードです。積み木は
  浮かないので、上に乗っているブロックの下には必ず土台があります。その理屈を言葉で
  説明する代わりに、透かして見せて納得させます。
- **一番ありがちな間違いを、わざと選択肢に入れている**: 問題の種類ごとに違います。
  総数なら「見えているブロックの数」、隠れた数なら「見えているほうの数」、直方体なら
  「いま置いてある数」。それを選んだときだけ理由を伝えて、対応するモードに自動で
  切り替えます。正解・不正解ではなく、**なぜ間違えたか**が残るようにしています。
- **段ごとに色が変わる**: 1段目は青、2段目は緑、3段目はオレンジ。「何段あるか」も
  見て分かるので、段ごとに数える解き方に自然に誘導できます。
- **視点を回すと隠れた数が変わる**: 同じ形でも向きによって見え方が変わることを、
  操作しながら体感できます。これは投影図（真上・正面・横から見た図）の準備運動です。
- 音声読み上げ（Web Speech API）と効果音つき。間違えてもペナルティはありません。

## ステージ

| ステージ | 床の形 | 高さ | 個数 | 隠れブロック | 問題の種類 | ねらい |
|---|---|---|---|---|---|---|
| やさしい | 2×2 / 2×3 / 3×2 | 2段まで | 3〜7個 | なし | 総数のみ | まず正確に数える |
| ふつう | 2×2 〜 3×3 | 3段まで | 5〜14個 | 1〜5個 | 総数・隠れた数 | 見えないブロックの存在に気づく |
| むずかしい | 3×3 〜 4×4 | 3段まで | 9〜20個 | 2個以上 | 総数・隠れた数・直方体まであと何個 | 段ごとに整理して数える |

### 形のバリエーション

同じような塊ばかりにならないよう、形は7通りの作りかたから選ばれ、
**直前と同じ作りかたは続けて出ません**。

でたらめ／かいだん（一方向に高くなる）／とう（1本だけ高い）／くりぬき（L字・コの字の土台）／
かべ（1列だけ高い）／ピラミッド（頂点の位置と高さもランダム）／はこけずり（直方体から削る）

床も正方形だけでなく長方形を使います。生成ロジックを直接検査したところ、
むずかしいでは **1718通り**、ふつうで 1281通り、やさしいで 615通りの異なる問題が出ます
（各4000問を生成して計測。1セッション6問のなかで同じ問題が重複しないことも確認済み）。

## しくみ（実装メモ）

- 等角投影を2DのSVGで描いています。3Dライブラリは使っていません。立体を平面図として
  読む練習になるほうが、入試の出題形式に近いためです。
- この投影では1つの立方体が「上・右・左」の3面を見せます。3面すべてが隣の立方体で
  ふさがれているとき、その立方体は完全に見えない＝隠れブロックと判定しています。
  視点を回すと隣接関係が変わるので、隠れる数も変わります。
