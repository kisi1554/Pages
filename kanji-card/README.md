# かんじカード 1ねんせい（kanji-card）

小学1年で習う漢字 **80字** を、暗記カードで覚えるアプリ。
1つの漢字につき **いろいろな読み方・使い方のことば** を 7〜19こ ずつ、
さらにその漢字を使う **駅名** もカードにしている。

でんしゃ好きの子むけに、例文は電車・新幹線・駅にからめてある
（電車・新幹線・駅・駅名・路線名の漢字は読める前提で、ふりがな付きで使う）。

公開URL（同期後）: https://kisi1554.github.io/Pages/kanji-card/

## あそびかた

1. **しゅっぱつ！** で きょうの カード（10まい）が はじまる。1まい＝1えき。
   でんしゃが せんろを すすんで、さいごに「しゅうてん とうちゃく！」。
2. **あたらしい ことば** … おもてで その漢字の よみが「？」に なっている。
   「めくる」と よみ・おんよみ／くんよみ／とくべつな よみ・いみ・れいぶんが でる。
   「おぼえた！」か「もう いっかい」を えらぶ。
3. **ふくしゅう** … 前に おぼえた ことばが クイズで でる。
   - なんて よむ？（4たく。まちがいの せんたくしは **おなじ漢字の べつの よみ** で つくる）
   - どの ことば？（よみと いみを 見て、4つの ことばから えらぶ）
4. まちがえた カードは その回の さいごに もう1回 でる。
5. ボタンの かわりに **よこに スライド** しても すすめる。
   ひだりへ = めくる・おぼえた・つぎへ ／ みぎへ = もう いっかい（めくった あと だけ）。
   こたえを えらぶ まえの クイズは スライドでは すすまない。

### よみの しゅるい

| | れい（一） |
| --- | --- |
| おんよみ | 一年生（いち）・一生けんめい（いっ） |
| くんよみ | 一つ（ひと）・一休み（ひと） |
| とくべつな よみ | 一人（ひとり）・一日（ついたち） |
| えきめい | 青山一丁目（銀座線）・一ノ関（東北新幹線） |

漢字の くわしいページ（ろせんずで 漢字を おす）では、ことばが この4つに わかれて ならぶ。

## つづけたくなる しかけ

| しかけ | なかみ |
| --- | --- |
| きょうの めあて | 5／10／15まい（せっていで かえられる）。リングが みどりで うまっていく |
| れんぞく にっすう 🔥 | めあてを まいにち クリアすると ふえる。1しゅうかんの カレンダーに 🚃 |
| えきスタンプ 🎫 | めあてクリアで 1日1こ。40しゅるい |
| レベル | けいけんちで あがる。みならい → えきいん → しゃしょう → うんてんし → … → かんじ そうさい |
| コンボ | 3れんぞく かいそく → 5れんぞく とっきゅう → 8れんぞく しんかんせん。おとも だんだん たかく なる |
| かんじ ろせんず 🗺️ | 80字が 9つの「せん」の えきに なっている。おぼえると えきに いろが つき、マスターで きんいろ |
| くんしょう 🏅 | 25こ（れんぞく・ことばの かず・よみの へんしん・えきめい・パーフェクト・あさの いちばん でんしゃ など） |

## おぼえかたの しくみ

- ことばごとに 6だんかいの はこ（ライトナー方式）。せいかいで 1だん あがり、
  つぎの ふくしゅうは 1・2・4・7・14・30日ご。まちがえると 1だんめに もどる。
- 3だん いじょうで「しっかり おぼえた」。漢字の ★ は
  ★1 = 1こ いじょう / ★2 = はんぶん いじょう / ★3 = ぜんぶ しっかり。
- その日の カードは、ふくしゅうが まっている ことば ＋ あたらしい ことば（さいてい3まい）。
  あたらしい ことばは **80字から ランダムに えらんだ 漢字** から だす（「かず」ばかり つづかない）。
  1かいごとに 新しい 漢字を 2こ はじめ（さいしょは 5こ）、のこりは はじめた 漢字のうち
  まだ ことばが すくない ものから 1〜2こずつ。ことばは その漢字の きほんの ものから じゅんに。
- 進みぐあいは localStorage（`kanjiCard1.v1`）。

## がめん

れんしゅう がめんは がめんの たかさ（`100dvh`）に あわせて ちぢみ、iPhone SE（Safari で 375×553）でも
スクロール なしで 1まいが ぜんぶ 見える。こたえた あとは といと せんたくしを しまって、
こたえの カードに きりかわる（けっかは 上の「なんて よむ？」の ところに でる）。

## 音

WebAudio の 合成音だけ（めくる・せいかい・まちがい・きてき・ファンファーレ・スタンプ）。
よみあげは ブラウザの 読み上げ（speechSynthesis）。右上の 🔊 で ぜんぶ オフ、
せっていで よみあげだけ オフに できる。

## データ

`data.js` の `KANJI`。1行 = `'ことば|えもじ|いみ|れいぶん'`、駅は `'駅めい|路線'`。

- `一[いち]` は 1字に ふりがな、`(一日)[ついたち]` は まとめて ふりがな（とくべつな よみ）
- `日[に:o]` のように `:o`（おん）`:k`（くん）`:t`（とくべつ）で よみの しゅるいを 手で きめられる
  （ふつうは `on` / `kun` の よみと くらべて じどうで きまる）
- ことばは 1年生の 漢字（＋電車・新幹線・駅）だけで かき、ほかは ひらがな

データを なおしたら しらべる:

```
node tools/check-kanji-card.js
```

ふりがなの ない 漢字・1年生 いがいの 漢字・おなじ ことばの かさなり・よみの しゅるいが
きめられない もの を おしえてくれる。
