# ももたろう 鬼伝（きでん） ― 10ぴきの おにと たたかう まんが えほん 👹

むかしばなし「ももたろう」を、**しょうねんまんが ふうの バトル まんが** に した えほんです。
あかい つきの よるに うまれた ももたろうが、いぬ・さる・きじ と いっしょに
**つよくて こせいてきな 10ぴきの おに** を たおしていく ダークファンタジー。
対象は 小学生くらい（すこし こわい ばめんが あります。ちが でる ような ひょうげんは ありません）。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー・がいぶ ライブラリ なし）。
え は SVG、おと は Web Audio で その場で つくっていて、がぞう・おんせい ファイルは 0こ です。
文は この アプリの ために かいた オリジナルです。

## ながれ

1. **ひょうし** → **プロローグ**（3ページ）: あかい つきの よる、かわを ながれてきた もも から うまれた ももたろう。
   おにが むらを おそい、おじいさんたちが つれさられる。
2. **なかま あつめ**: かげを タップして きびだんごを あげると、いぬ・さる・きじ が なかまに なる。
3. **ちず「おにがしまへの みち」**: 10ぴきの おにが じゅんばんに ひらく。たおした おには「たおした」の はんこ と つの が つく。
4. おにごとに **とうじょう ページ → たたかい → さいごの ことば ページ**。
5. 10ぴきめ（鬼王ラセツ）を たおすと **エンディング**（3ページ）。さいごは「完」。

まんがの ページは タップするたびに コマが 1つずつ でてきます。

## たたかいの しくみ

- おにの こうげきが 3かい くる。こうげきの ようすを よんで、たちむかう なかまを えらぶ。

| なかま | とくい |
| --- | --- |
| ももたろう | きる・うけとめる |
| いぬ | かぎつける・かむ |
| さる | よける・つかむ・ほどく |
| きじ | とぶ・みとおす・かぜ |

- まちがえると「ガキィン！」と はじかれて ヒントが でる。2かい まちがえると、せいかいの ボタンが ひかる
  （まけて おわる ことは ない）。
- 3かい やぶると **ひっさつわざ**。ボタンを 12かい れんだして ちからを ためると、みひらきの ひっさつ コマ →
  おにが たおれる。

| 6 | 影縫（かげぬ）いの クロガネ | つきの ない みやこあと | あかつき ぎり |

ぽつりと はなします。テーマは「いかりや かなしみを ひとりで かかえると おにに なる。なかまが いれば ならない」。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | がめんの わく・トーン（あみてん）などの SVG 定義 |
| `style.css` | まんがの コマ・ふきだし・こうかおん・たたかい がめん |
| `art.js` | え（ももたろう・なかま・10ぴきの おに・けしき）を SVG で かく |
| `story.js` | おはなしの データ（プロローグ・おに・エンディング） |

- きろく（たおした おに）は localStorage の `momotaro-kiden:v1` に ほぞん。ちずの「きろくを けす」で けせる。
- たてもち スマホは コマが たてに ならび、よこもち タブレットは 2れつ＋よこながの コマ に なる。
