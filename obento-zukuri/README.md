# おべんとう づくり 🍱

おべんとうばこ に おかず を つめて、**あか・きいろ・みどり**（3つ の しょくひん グループ）と
**いろどり** を そろえる 食育あそび。対象は 年長〜小学校中学年。

`index.html` を ブラウザで ひらくだけで あそべます（ビルド・サーバー 不要。外部ライブラリ・CDN なし）。
食べもの の 絵 は すべて SVG を コードで かいた もの、音 は Web Audio の 合成音 です（画像・音声ファイル 0個）。

公開URL: https://kisi1554.github.io/Pages/obento-zukuri/

## あそびかた

1. **おだい** を えらぶ（6つ）。おべんとうばこ の 大きさ・しきり は おだい ごと に ちがう。

   | おだい | はこ | しきり | ポイント |
   | --- | --- | --- | --- |
   | 🎒 あした は えんそく！ | 500mL | ごはん2＋おかず6 | きほん |
   | 🏃 うんどうかい で いっぱい はしる | 650mL | ごはん2＋おかず5 | きいろ と あか を しっかり →「げんき まんたん」 |
   | 🚃 でんしゃ の たび の えきべん ふう | 600mL（木の はこ） | たわら3＋おかず6 | でんしゃ の のり／ピック →「でんしゃ の たび」 |
   | 🧸 ちいさな 子 の おべんとう | 400mL | ごはん1＋おかず4 | まるい もの は 4つ に きる おしらせ |
   | 🧺 こうえん で パン の ピクニック | 550mL | パン2＋おかず4 | サンドイッチ・ロールパン |
   | 🌈 じゆう に つくろう | 550mL | ごはん1＋おかず6 | じゆう |

2. **つめる**: たな（ごはん・パン／おかず／やさい／くだもの／かざり）から **ドラッグ** で はこ へ。
   ドラッグ が むずかしい 子 は **タップ → タップ**（えらんで から しきり を タップ。おなじ もの を つづけて つめられる）。
   - ごはん の ばしょ（はこ の 約半分）に は 主食 だけ、おかず は ちいさい しきり（カップ）に。食べもの は しきり の 形 に あわせて はまる。
   - つめた もの を タップ すると とりだせる。
3. **メーター**: あか・きいろ・みどり が どれくらい か を 3本 の バー で。**いろどり** は 赤・黄・緑・白・茶 の 5色。
   保護者むけ に 主食・主菜・副菜 の わりあい（3:1:2 の めやす）も（「おうち の かた へ」を ひらく）。
4. **かざり**: のり（でんしゃ・ほし・ハート・にこにこ）と ピック（はた・ハート・ほし・でんしゃ）を おかず の うえ に。
5. **ふた を しめる**（パチン）。すきま が ある と「よって かたよっちゃう かも」→ もういちど おすと しめられ、はこ が ゆさゆさ。
6. **いただきます**（チャイム）→ キャラ が もぐもぐ 食べて かんそう。
   そろった ときは「からだ が ぽかぽか、げんき いっぱい！」。かたよっても しからず「つぎ は みどり を ふやして みよう」。
   バッジ（3しょく そろった・いろどり・ぎっしり・かざり・おだい ごと の とくべつ）は **とれた もの だけ** 出す（しっぱい表示 なし）。
7. **アルバム**: いただきます した おべんとう を 10こ まで のこす（あたらしい じゅん）。
8. **たべもの ずかん**: **88品目**。なまえ・グループ（りょうり は わりあい）・主食/主菜/副菜・ひとこと。タップ で よみあげ。

## 正確さ について

### 3つ の 食品グループ

小学校 の 食育（文部科学省 食生活学習教材）と 家庭科（6つ の 基礎食品群 との 対応）に あわせて います。

| グループ | はたらき | 6つの基礎食品群 | 食品 |
| --- | --- | --- | --- |
| あか | おもに 体 を つくる | 1群・2群 | 肉・魚・卵・豆（大豆製品）・牛乳・乳製品・小魚・海藻 |
| きいろ | おもに エネルギー の もと | 5群・6群 | 米・パン・めん・いも・砂糖・油脂 |
| みどり | おもに 体 の 調子 を ととのえる | 3群・4群 | 野菜・果物・きのこ |

料理 は 主な 材料 で 割合 を きめて います（例: からあげ＝あか8・きいろ2〈揚げ油〉、ぎょうざ＝あか5・きいろ3・みどり2）。

**資料 で 分かれる 食品**（アプリ内 の ずかん・「おうち の かた へ」にも 注記）
- いも類 → **きいろ**（5群）。ビタミンC から みどり と する 資料 も ある。料理 と して は 副菜（ポテトサラダ 等）。
- 海藻（ひじき・わかめ・のり）→ 家庭科 では 2群 なので **あか**。幼児向け 資料 では みどり の ことも。
- えだまめ → 食品成分表 で 野菜類 なので **みどり**（大豆 として あか に する 資料 も ある）。
- とうもろこし → スイートコーン は 野菜 として **みどり**（穀類 として きいろ に する 資料 も ある）。
- かぼちゃ・にんじん は 色 や 甘さ に かかわらず **みどり**。チーズ・ヨーグルト は **あか**。ごま は 油脂 が 多い ので **きいろ**。

### 主食・主菜・副菜 と 3・1・2弁当箱法

- 弁当箱 の 容量（mL）≒ 1食 の エネルギー（kcal）。おだい ごと に 400〜650mL。
- 主食3：主菜1：副菜2（容積）。アプリ では ごはん の 場所 が 箱 の 約半分。
- メーター の めやす は 3:1:2 を 色 に あてはめた もの（きいろ 3/6・あか 1/6・みどり 2/6）。めやす の 6割 以上 で「ちょうど いい」。
  厳密な 栄養計算 では ありません。くだもの・乳製品 は 3:1:2 の 計算 に 入れて いません（`role: other`）。
- 動かない ように つめる（→ すきま の 声かけ）、同じ 調理法（特に 油 を 多く つかう 料理）は 1品（→ 揚げ物 2品 以上 で 保護者向け に 注記）、見た目（→ いろどり）。

### 食物アレルギー

- 子ども向け に「アレルギー の ある ひと は、たべられない もの が あるよ」と ホーム・ずかん に 表示。
- 保護者向け に **アレルギー マーク**（ずかん・たな、オン/オフ）。食べもの の くわしい 画面 と 結果 の「おうち の かた へ」にも 一覧。
  - 特定原材料（表示義務）**9品目**: えび・かに・くるみ・小麦・そば・卵・乳・落花生・**カシューナッツ**（2026年4月1日施行 の 改正 で 追加、2028年3月31日 まで 経過措置）。
  - 特定原材料に準ずるもの（表示推奨）**20品目**: アーモンド・あわび・いか・いくら・オレンジ・キウイフルーツ・牛肉・ごま・さけ・さば・ゼラチン・大豆・鶏肉・バナナ・ピスタチオ・豚肉・マカダミアナッツ・もも・やまいも・りんご。
  - マーク は「よく ある 作り方」の 例（しょうゆ＝小麦・大豆、マヨネーズ＝卵 など）。実際 は 商品 の 表示 で 確認 する よう 明記。
- 「〇〇 は 体 に わるい」と いう 言い方 は しない。ずかん に「たべもの に いい・わるい は ないよ」。

### 小さな子 の 窒息予防

「ちいさな 子」の おだい で ミニトマト・ぶどう・さくらんぼ（`round: 1`）を 入れると「4つ に きって あげよう」と 声かけ（消費者庁・こども家庭庁 の 注意喚起）。
