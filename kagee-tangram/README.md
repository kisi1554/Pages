# 🧩 かげえ タングラム

くろい かげの うえに 7まいの板を ならべて、かたちを つくる パズル（分野: ずけい／5才〜）。
形を 回して 組み合わせ、大きな形を作る力（図形の合成）を そだてます。

## あそびかた

1. くろい かげの うえに、板を ドラッグで はこぶ。
2. 板を タップすると 45度ずつ 回る。「うらがえす」ボタンは 平行四辺形だけ うらがえす。
3. 正しい場所に 近づくと すいつく。
4. ぜんぶ はまると 色がついて 動きだす（でんしゃは 走り、ロケットは とび、ふねは ゆれる…）。

- 「やりなおし」で 板を ぜんぶ もどす。「ヒント」で 置く場所が 光り、置く板が ゆれる。
- はまった板も、もういちど つかんで 動かせる（まちがえても やりなおせる）。

## もんだい（20問）

| レベル | 内容 | 題材 |
| --- | --- | --- |
| ⭐ やさしい（6問） | 3〜4まい・線のヒントあり。向きが 1だん（45度）ずれていても すいつく | いえ、さかな、ねこの かお、ヨット、リボン、でんしゃ |
| ⭐⭐ ふつう（7問） | 7まい・線のヒントあり | しんかんせん、おおきな いえ、ふね、おおきな さかな、ロケット、くるま、ひこうき |
| ⭐⭐⭐ むずかしい（7問） | 7まい・線なし。かげに ぴったり はまれば、用意した答えと ちがう ならべかたでも 正解 | ねこ、きつね、きかんしゃ、ひと、ちょうちょ、やじるし、ましかく |

1もんめは「はこぶ」だけ、2もんめで「まわす」を おぼえる ならびに してあります。

## しくみ

- 正解判定: 板を はなした場所の 近くの 格子位置で、板が おおう範囲（ますを 4つの三角に わけた単位）が
  答えの わくと 一致するかを 見る。板の種類ではなく 範囲で くらべるので、同じ形の板の 入れかえや
  正方形の 向きちがいも 正解になる。位置の ゆとりは 小さい三角の 1辺の 0.8倍（線なしは 0.55倍）。
- 操作する領域（SVG）は `touch-action: none` で、Pointer Events を JS で処理。
- 音は WebAudio の合成音のみ（右上の 🔊 で オン/オフ）。進みぐあいは localStorage（`kagee-tangram-v1`）。
- 外部ライブラリなし・`index.html` だけで完結。

## 開発

```bash
node tools/kagee-tangram/gen.js           # 20問が とけるか しらべる
node tools/kagee-tangram/gen.js --write   # 解を さがして index.html の PUZZLES を かきかえる
node tools/kagee-tangram/test.js [shots]  # Playwright で 縦スマホ・横タブレット・横スマホの 全問を といてみる
python3 tools/no-zoom.py kagee-tangram    # ズーム対策ブロックを 入れなおす
```

もんだいを ふやすときは `tools/kagee-tangram/gen.js` の `FIG` に シルエット（格子の多角形）を 足す。
