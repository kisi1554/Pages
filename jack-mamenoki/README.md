# ジャックと まめのき ― ゆびで のばして、のぼる えほん 🌱

イギリスの むかしばなし「ジャックと まめのき」を、**こどもが ゆびで まめのきを のばし、ひだり・みぎ こうごの タップで
のぼり、そーっと ドラッグで きょじんの そばを とおる** しかけ えほんに しました。「さわる えほん」シリーズの 3さつめ
（[`ookina-kabu/`](../ookina-kabu/)・[`kitakaze-taiyo/`](../kitakaze-taiyo/) と 画面の かたち・よみあげ・ことばの きりかえ・しおりは おなじ 型）。
対象は 未就学〜小学1年。ひょうし＋9ページ＋おしまい の 全11ページ。

**むかしばなしを もとに した オリジナルの 文・絵** です。こわい ばめん（きょじんが たべようと する・おちて しぬ など）は 入れず、
きんの たまごを うむ にわとりは「ぬすむ」のでは なく「かごから だして あげる」おはなしに しています。
日本で 出版されて いる 絵本・教科書の 訳文や 絵は つかって いません（日本語・英語の 文も 絵も この アプリの ために かいたもの）。

`index.html` を ブラウザで ひらくだけで あそべます（ビルドも サーバーも 不要。外部ライブラリなし）。
絵は SVG、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。
文は ひらがな中心で、ことばの あいだを スペースで くぎっています（漢字には ふりがな）。

## おはなし と しかけ

| ページ | おはなし | しかけ |
| --- | --- | --- |
| ひょうし | まめのきが ゆれる | 絵か「よみはじめる」を タップ |
| 1 | うしの ミルキーを うりに いく | おじいさんを タップ → まほうの まめ 3つぶと とりかえっこ（ミルキーが あるいて いく） |
| 2 | まめを うえる | はたけの あな 3つを タップで うえる → じょうろを 3かい タップで みず → 夜に なって きらきら |
| 3 | つぎの 朝、 芽が でた | **のばす**: まめのきを したから うえへ なぞる（🌱 たかさ メーター）。くもを つきぬける |
| 4 | まめのきを のぼる | **のぼる**: 画面の ひだり・みぎを こうごに タップ（🪜 メーター）。おなじ がわを つづけると「おっとっと」。とり・くもを こえて おしろへ |
| 5 | ねむる きょじんの おしろ | **そーっと**: ジャックを ゆっくり みぎへ ドラッグ（🤫 しずか メーター）。はやいと きょじんが むにゃむにゃ → すこし もどされる |
| 6 | とりかごの にわとり | かぎを タップで あける「いっしょに つれて いって！」 |
| 7 | きょじんが おきた！ | **おりる**: ひだり・みぎ こうごの タップで いそいで おりる（うえから きょじんが のぞく） |
| 8 | まめのきを きる | ねもとを 5かい タップ → ゆらーっと たおれる。きょじんは くもの うえで ぷんぷん |
| 9 | しあわせに | にわとりを タップで きんの たまご 3こ → もんを タップで ミルキーが かえって くる |
| おしまい | ふりかえり | のぼった かず・きんの たまごの かず。**「もういちど のぼる」で ページ 3〜7 を じゆうに あそべる** |

## のばす・のぼる・そーっと の しくみ（`mame.js`）

- **のばす（grow）**: ゆびごとに うえへ なぞった きょり（絵の たかさ＝1）を あつめて まめのきの たかさに たします。
  したへ なぞっても ちぢみません。**ゆび 2ほん** で なぞると ちょうど 2ばい（「👆×2 ゆび 2ほん！」）。
- **のぼる・おりる（climb / down）**: ひだり と みぎ を **こうごに** タップした ときだけ 1だん すすみます
  （`Mame.model.climbTap`）。ゆび 2ほんで ひだりと みぎを いっしょに おすと 2だん。
- **そーっと（sneak）**: みぎへ うごいた はやさを みて、はやすぎた ぶんだけ「もの おと」が たまります。
  いっぱいに なると きょじんが むにゃむにゃ して すこし もどされます。**ゆっくり なら ぜったいに おきません**（`SAFE` より おそければ もの おとは たまらない）。
  おこられたり、おわりに なったりは しません。
- パソコンでは ↑・スペースで のばす、← → で のぼる、→ を おしつづけて ゆっくり そーっと、Enter で タップ。
- 絵には `touch-action: none` を つけ、なんぼんの ゆびで さわっても 画面が うごいたり 拡大したり しません。

## そのほか（シリーズ きょうつう）

- **よみあげ**: speechSynthesis で 1ぎょうずつ。よんで いる 行を 黄色く ひからせます。🔁 で もういちど。しかけを さわると とまります。
- **🇬🇧 English ⇄ 🇯🇵 にほんご**: ほんの したと ひょうしの ボタンで きりかえ。文・ヒント・ふきだし・メーターは ぜんぶ `{ ja, en }`。
  きょじんの「フィー ファイ フォー ファム！」は 英語では “Fee-fi-fo-fum!”。
- 🎵 おと（BGM・効果音）と 🗣 よみあげ は べつべつに オン/オフ。
- しかけが おわるまで「🔒 つぎ」。いちど おわった ページは つぎから すぐ すすめます。
- **しおり**（🔖 つづき から）。しおり・せってい・のぼった かず・たまごの かずは その端末の `localStorage` にだけ 保存します。
- たてもちは 絵の したに 文、スマホ よこもちは 絵と 文を よこに。絵は いつも 8:5。

## 音

ぜんぶ Web Audio の 合成音: うしの もー、まほうの きらきら、まめを うえる ぽこっ、みずの しゃー、のびる にょきにょき、
のぼる 足音（おりる ときは ひくい 音）、おっとっと、きょじんの いびき、かぎの カチャッ、にわとりの コッコッ、
おのの コーン、たおれる ドシーン、たまごの ぴかーん、ことりの さえずり。BGM は オリジナルの「まめのき マーチ」（4/4）。

## たしかめかた

```bash
node tools/jack-mamenoki/test.js
node tools/jack-mamenoki/check.js /tmp/shots
```

`test.js` は story.js の 全ページ・全 行に ja と en が そろって いること（漢字に ふりがな）、ゆび 2ほんで のびる りょうが 2ばいに なること、
こうごの タップ でしか のぼれないこと、ゆっくりの そーっとでは ぜったいに おきず、はやすぎると おきる ことを たしかめます。
`check.js` は Playwright で たて（390×844）・よこ（1024×768）・スマホよこ（844×390）を 日本語と 英語で ひらき、
全ページの しかけを こなして おしまいまで すすむこと、ゆび 2ほん（CDP の タッチ）で のびる りょうが 2ばいに なること、
おなじ がわの タップでは のぼれないこと、はやい ドラッグで きょじんが おきること、JS エラーが ないことを たしかめ、スクショを 保存します。
