# しりとり れっしゃ 🚂

**しりとりが つながるたびに、れっしゃが 1りょうずつ のびる ことばあそび。**
未就学〜小学校低学年むけ。`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/shiritori-ressha/

## あそびかた

1. きかんしゃに さいしょの ことば（「ん」で おわらない ことば）が のっています。
2. 下の 絵カード 4まいから、まえの ことばの **さいごの もじ** で はじまる カードを タップ。
   つながると その ことばの しゃりょうが れんけつ（ガチャン）。
   - 4まいの うち 1〜2まいが 正解。正解の 1まいが「ん」で おわる **わなカード** の ことも あります。
3. つながらない カードは「ぶぶー」。しゃりょうは つかず、正解カードが ゆれて ヒント。
4. 「ん」で おわる カードを えらぶと きてき → れっしゃが しゃこに もどって おしまい。
5. 「🚂 しゅっぱつ！」で、いまの れっしゃが はしり、しゃりょうの ことばを じゅんに よみあげます。
6. おわりに れんけつ すう と ことばの ならびを 表示。「おわる」で じぶんで おわることも できます。

## ルール（しりとり判定 … `shiritori.js`）

| ケース | あつかい |
| --- | --- |
| さいごが「ー」 | ひとつ前の もじ（ぼーる → る、まんごー → ご） |
| 小さい字 ゃゅょぁぃぅぇぉっ | 大きい字に なおす（きしゃ → や） |
| 濁点・半濁点 | そのまま。せってい「にごり ゆるす」オンなら か/が、は/ば/ぱ を 同じと みなす |
| 同じ ことば | 1回の れっしゃで 1度だけ |
| 「ん」で おわる | おしまい（でんしゃ は「や」なので セーフ） |

### 「る」「ぬ」「を」と まほうの きっぷ

- 「る」は 3語（るびー・るーぺ・るーれっと）、「ぬ」は 2語（ぬいぐるみ・ぬりえ）。
- 「を」で おわる語は データに 入れていないので、「を」が もとめられる ことは ない。
- つなげる ことば（「ん」で おわらないもの）が のこっていない もじに なったら、
  **🎫 まほうの きっぷ**（救済カード）が でます。えらぶと のこりの ことばが 多い もじへ「のりかえ」。
  きっぷの しゃりょうは れんけつ すうに かぞえません。
- 「ん」で おわらない ことばを ぜんぶ つかいきったら「ぜんぶ つないだ！」で ゴール。

## モード・きろく

- **ひとりで** / **おうちのひとと こうたい**（あお・ぴんく が こうたい。しゃりょうの 色で だれが つなげたか わかる。
  まちがえても ばんは かわらない）
- localStorage（キー `shiritori-ressha-v1`）に さいこう れんけつ すう・つかった ことば（ずかん）・せってい を ほぞん。
- 📖 **ことば ずかん** … ジャンルべつに 一覧。まだ の ことばは「？」と はじめの もじ だけ。

## 音

- 効果音は WebAudio の 合成音（ガチャン・ぶぶー・きてき・しゅっぱつ）。
- 読み上げは `speechSynthesis` が あれば 使う（音声ファイルは 置かない）。
- 右上の 🔊 / 🔇 で まとめて オン/オフ。

## テスト

```bash
node shiritori-ressha/test.js
```

さいごの もじ・「ん」判定（みかん / パン は ×、でんしゃ は ○）・にごり・データ（150語以上、
清音ごとの 語数、かさなり）と、400回の ランダム対局で「つづけられる カードが かならず ある」ことを 確かめます。
