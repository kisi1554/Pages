# ケーキ わけっこ 🍰

ケーキを きって、どうぶつたちに おなじだけ くばる ゲーム。
わりざん と ぶんすうの はじめの いっぽ。年長〜小学校中学年むけ。

公開URL: https://kisi1554.github.io/Pages/cake-wakekko/

## あそびかた

1. どうぶつ（🐻🐰🐱🐶🐼🦊）が 2〜6ぴき、おさらを もって まっている。
2. 🔪 きる で たべものの うえを まっすぐ なぞると、そこで きれる（なんかいでも）。↩ もどす あり。
   - まんなか から そとへ なぞると、まるい ケーキを まんなかから きれる（3とうぶん に つかう）。
   - いたチョコ は いつも みぞに そって われる。
3. ✋ はこぶ で かけらを どうぶつの おさらへ。おさらから テーブルや ほかの おさらへ もどすことも できる。
4. 「どうぞ！」で はんてい。ずれが **かんたん 10%／ふつう 5%** いないなら みんな にっこり＋ファンファーレ。
   ふこうへい だと「ずるい〜！」と おこって、だれが おおい／すくないか を ぼうグラフで みせる。
5. クリアすると「4つに わけた 1つ ＝ 1/4（よんぶんの いち）」や「12 ÷ 3 = 4」の ように ことばと ぶんすう・しき を ひょうじ。

### ★ の つけかた（ステージごとに さいだい 3こ）

- ★ みんなに くばれた
- ★ ぴったり（ずれが ゆるす はばの はんぶん いない）
- ★ いちご が ある ステージ: いちごも おなじ かず ずつ／ない ステージ: いっかいで できた

| --- | --- | --- |

## しくみ

- 図形は ぜんぶ ポリゴン。まるは 96かくけい で ちかい。めんせきは ガウスの こうしき。
- `Geom.splitByLine` は へこんだ かたち でも きれる（こうてんを せんに そって ならべ、0-1, 2-3 … を はしで むすんで たどる）。
- まるい ケーキは「おうぎがた」の じょうほう（a0, a1）を もつ。まんなか から の きりこみ は 1ぽんめ では きれめ だけ、
  2ほんめ で はじめて わかれる（ほんものの ケーキと おなじ）。
- ぜんたいの 1% みまんの かけらが できる きりかた は、きらずに もとの まま にする（ほそすぎる かけら は つくらない）。
- おさらの うえの かけらは、ぜんぶの おさらで おなじ しゅくしゃく で ならべる（おおきさを みくらべ られる）。
- おとは WebAudio の ごうせいおん（ナイフ・ぽとん・にっこり・ぶー・ファンファーレ）。🔊 で オン／オフ。
