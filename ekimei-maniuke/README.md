# えきめい まにうけ くん 🤔

なんでも ことばどおりに うけとる **まにうけくん** が えきに つくと、えきの なまえを かんじ どおりに
かんちがい（池袋 → いけの なかに おおきな ふくろ！）。子どもが「ちがうよ！」と ほんとうの すがた
（むかしの ちけい・くらし）を おしえて あげる ゲーム（5さい〜）。

えきめいの かんじには、むかしの ちけいや くらし（谷・坂・橋・川・池・島・田・山・台・浜）が
かくれていることに 気づき、よく でる かんじの いみを おぼえる のが ねらい。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. 「しゅっぱつ！」で でんしゃが えきに つく。えきめい（ふりがな つき）が でる。
2. まにうけくんが かんじ どおりの へんてこな そうぞうを する（💭 の なかに え）。
3. 「✋ ちがうよ！」を おして、ほんとうの すがたを 3まいの えから えらぶ。
   まちがえても その カードが うすく なるだけで、なんども やりなおせる。
4. せいかいすると まにうけくんが **ずっこける**（わらいは こたえあわせの あと）。
   つづいて「むかし → いま」の はやおくり アニメと、ゆらいの せつめい。
5. その えきの かんじが **かんじ ずかん** に はいり、おなじ かんじの えきが つぎつぎ ひかる
   （例: 池 → 池袋・溜池山王・池尻大橋・池上・池ノ上）。
6. 1かい 5えき（1〜3ぷん）。さいごに ⭐ と かみふぶきで ほめる。まだ いっていない えきから じゅんに でる。

## なかみ

- 30えき（とうきょう・よこはま・かわさき）。かんじ 10しゅ: 谷・坂・橋・川・池・島・田・山・台・浜。
- ずかんでは、たずねた えき と「ほかにも あるよ」の えき（23えき）を ふりがな つきで みられる。
- データは `index.html` の `KANJI` / `STATIONS` / `MORE` の 1かしょに まとめてある。

### ゆらいの たしかめかた

えきめいの ゆらいは せつが いくつも ある ことが おおい。区・市の 公式の 地名の せつめいや 辞典で
たしかめ、はっきり しない ものは「〜と いわれているよ」と かいた。たしかめられなかった えきは のせていない
（例: 大島・浜町 は ゆらいを 公式資料で かくにん できなかったので、問題には せず ずかんの「ほかにも あるよ」だけ）。

| えき | せつめいの もと |
| --- | --- |
| 四ツ谷 | 新宿区の 観光資料（4けんの 茶屋の 説。4つの 谷の 説も ある と書いた） |
| 赤坂 | 港区「地名の歴史（赤坂地区）」（あかね の 説） |
| 日比谷 | 国土交通省 関東地方整備局の 資料（日比谷入江・のりの ひび） |
| 品川 | 品川区の 資料（目黒川の 河口付近を 品川と よんだ） |
| 白金台 | 港区「地名の歴史（高輪地区）」（白金長者の 伝承） |
| 池袋 | 新編武蔵風土記稿の 説（袋状の くぼ地）＋ 丸池の 説 |
| 千駄ケ谷・神楽坂・川崎 など | 諸説あり → すべて「〜と いわれているよ」 |

## 実在の 駅を あつかう ときの きまり

- 駅名・よみは 1えきずつ たしかめた（駅名の 表記は 駅の 正式表記: 四ツ谷・千駄ケ谷・池ノ上 など）。
- 鉄道会社の ロゴ・マーク・発車メロディ・路線カラーは つかわない。でんしゃの えは オリジナル。
- わらいは やさしく。えきや まちを ばかに しない。まにうけくんが じぶんで ずっこける だけ。
