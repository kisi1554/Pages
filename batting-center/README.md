# バッティングセンター ⚾

ピッチングマシンから くる ボールを、タイミングよく タップして うつ バッティングゲームです（未就学〜小学生むけ）。
`index.html` をブラウザで開くだけで遊べます（外部ライブラリなし）。

## あそびかた

- はやさを えらぶ（🐢 ゆっくり 50キロ ／ ⚾ ふつう 70キロ ／ 🔥 はやい 100キロ）。1ゲーム 15きゅう。
- マシンの ランプが ちかちか → **あお** に なったら ボールが くる。ホームベースの きいろい わが ボールと かさなるころに **タップ**（スペース / Enter でも OK）。
- タイミングで けっかが きまる:

| タイミング | けっか | てん |
| --- | --- | --- |
| ぴったり（**きょうだ**） | ホームラン！ おくの「ホームラン」かんばんへ とぶ | 100 |
| ホームランのなかでも ど まんなか | かんばんの **ベル** に あたって **チーン！** | 100 + 200 |
| すこし ずれた | ヒット | 30 |
| だいぶ ずれた | ファウル（はやいと ひだり、おそいと みぎへ） | 5 |
| はずれ／うたない | からぶり／みのがし | 0 |

- うったあとに「ちょっと はやい／おそい／ぴったり！」が でるので、つぎの ボールで なおせる。
- ゆっくりモードほど タイミングの ゆうよが ひろい。
- さいこうてんは はやさごとに localStorage に ほぞん。
