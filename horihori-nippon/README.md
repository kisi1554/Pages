# ほりほり にっぽん ⛏️ 〜ちけいと めいさんの ひみつ〜

**「どこで なにが とれるか」は もう しっている 子が、「どうして そこで とれるのか」を ほりさげる** アプリ。
にほんちずの ⛏️ を タップして つちを 4かい ほると、その ばしょの ひみつが 1だんずつ でてきます。

`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/horihori-nippon/

---

## ねらい

47都道府県と めいさんの くみあわせ（「さくらんぼ → やまがた」）は
[日本地理たんけん](../nihon-chiri-tanken/) の 🍎名産・⛰️地形 モードで おぼえられます。
このアプリは その **1だん した** を ほります。

> もも・ぶどうが やまなしで とれるのは、**扇状地**で みずはけが よくて、**盆地**で ひると よるの きおんの さが おおきいから。

めいさん（けっか）と ちけい・きこう（りゆう）を **「⬇ だから」で つなぐ** ことが いちばんの ねらいです。
おなじ ちけいが べつの ばしょにも でてくる（扇状地 → やまなしの もも／となみの チューリップ、
台地 → かごしまの さつまいも／しずおかの おちゃ／ほっかいどうの ぎゅうにゅう）ので、
「この ちけいなら こういう ものが そだつ」という きまりに じぶんで きづけるように しています。

---

## あそびかた

### ⛏️ ほる（23かしょ）

ちずの ⛏️ か、したの リストから ばしょを えらぶと、つちが 4だん かさなった 画面に なります。
うえから じゅんに タップして ほります。

| だん | でてくる もの |
| --- | --- |
| 1 📍 どこ？ | ちずで 県が ひかり、ばしょの なまえ（例: 山梨県の 甲府盆地） |
| 2 ⛰️ どんな ちけい？ | **ちけいの え（だんめん図・みおろし図）** と なまえ・せつめい |
| 3 🎁 なにが とれる？ | めいさんと「日本一」などの すごさ |
| 4 💡 どうして？ | **ちけい → どうなる → だから とれる** の 3ステップ |

ほりおわると たからばこが ひらいて「もっと ほりさげ まめちしき」が でます。
ほった ばしょは ちずの ピンが めいさんの えもじに かわります。

### 🧠 なぜなに クイズ（8もん）

| もんだい | こたえかた |
| --- | --- |
| 〇〇県で △△が たくさん とれるのは どうして？ | りゆうを 3つから えらぶ |
| この ちけいの なまえは なに？（え だけ） | 3つから えらぶ |
| 〇〇は △△（ちけい）。ここで とれる ものは どれ？ | めいさんを 3つから えらぶ |
| △△の ひみつの ばしょは どこ？ | ちずで 県を タップ |

- まちがいの せんたくしは **ちがう ちけいの もの** から だす（りゆうで 見わけられるように）。
- せいかいすると、かならず「どうして？」の 3ステップを みせて よみあげる。
- ほった ばしょが 4つ いじょう あれば、ほった ところから でる。

### 📦 たからばこ / 📚 ちけい ずかん

- たからばこ … ほりあてた めいさん 23こ。タップで もういちど みられる。
- ちけい ずかん … 19しゅるいの ちけい・きこうを え つきで ならべ、その ちけいの ばしょへ とべる。

### せってい

🔊 おと（WebAudio の ごうせい音）・🗣️ こえ（ブラウザの よみあげ）を それぞれ オン/オフ。
すすみぐあいは localStorage（`horihori-nippon-v1`）に ほぞん。
