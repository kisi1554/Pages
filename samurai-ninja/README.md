### 3すくみ（どちらにも かちめ）

- かまえ は れんげき に つよい（くない は ぜんぶ とまる。かまえ ゲージが すこし へる）
- しゅりけん は かまえ を けずる（ゲージ 0 で「かまえが くずれた！」）。うしろ から の こうげきは かまえ で とめられない
- いあい は せの たかい あたりはんい で、ジャンプちゅう の あいてに 1.3ばい
- かわりみ は いあい を まるた で うけて うしろに まわりこむ
- れんぞくで 4かい いじょう あたったら、たちなおる あいだ 20フレーム むてき（はめ が つづかない）
- れんげき の さいごを からぶり すると すこし よろける

## モード

- **ストーリー**: さむらい の みち／しのび の にんむ を 5せん ずつ（あいては よわい→つよい）。かつと ずかん カード 1まい（ぜんぶで 10まい）
- **CPU と たいせん**: じぶん・あいて の キャラ、つよさ（よわい／ふつう／つよい）、ステージ を えらぶ
- **2人 たいせん**: よこもち タブレット で ひだり半分＝1P、みぎ半分＝2P の ボタン（マルチタッチ）
- **ずかん**: 「おはなし の なか では…」と「ほんとうは…」を わけて かく。漢字に ふりがな。じつざいの ぶしょう・りゅうは・さくひん の なまえは つかわない

ステージ: じょうかまち（ひる／ゆうやけ）・たけばやし・やねの うえ（つきよ）・おしろの てんしゅ。3まいの レイヤーを カメラの 0.15 / 0.45 / 1 ばいで うごかす パララックス。

## そうさ

- がめんの ボタン（64px いじょう）。たてスマホ は ステージ が うえ、ボタン が した。よこの ひくい がめん では ボタンを ステージに かさねる
- PC: 1P は A D（いどう）W（ジャンプ）F（こうげき）G（ガード／しゅりけん）H（ひっさつ）R（けむり）。1人の ときは ← → ↑ Space と Z X C V でも うごく。2P は ← → ↑ と J K L I。Esc／P で ちょっと まって

## CPU（ai.js）

- あいての ようすは「はんのう じかん」ぶん むかしの すがたしか みえない（よわい 30±14、ふつう 18±8、つよい 11±5 フレーム。さいしょうでも 7）
- ステートマシン: あるく・さがる・きる・かまえる・とぶ・しゅりけん・いあい・かわりみ… の「よてい」を きまった フレーム つづける
- れんだ して くる あいてには まあいを とって すきを うつ（あいての こうげきの はやさ を かぞえて みぬく）
- つよい でも ときどき ぼんやり したり（7%）まちがえたり（7%）する
