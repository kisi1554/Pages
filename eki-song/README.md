## 📱 えきめい あんきモード

YouTube ショートの「駅名暗記」どうがの ような たてながの がめん。
うえに「【えきめい あんき】〇〇せん」、まんなかに いま うたっている えきめいひょう、
したに えきの リストが ながれて、うたった えきには ✔ が つく。
「🙈 つぎを かくす」で まだ うたっていない えきが「？？？」に なるので、つぎの えきを あてながら おぼえられる。

## あそびかた

1. ホームで きょく → せん を えらぶ。
2. ▶ で スタート（イントロ →「〇〇せん いくよー」→ えきめい →「ぜんぶで 〇えき」「また のってね」）。
3. いま うたっている えきが **えきナンバー つきの えきめいひょう** で でて、よみが カラオケのように ひかる。
4. したの ろせんずの えきを タッチすると、そこから うたう。▶・⏮ は がめんの いちばん したに いつも でている（スクロールしなくても おせる）。
5. さいしょから さいごまで うたうと 🏅（せんごとに かいすうを きろく）。

## しくみ（おうちの方・開発者むけ）

- `data.js` … 路線データ（漢字・よみ・駅ナンバー）と曲の設定（テンポ・16分/8分・コード進行・リズム）。
- `voice.js` … 歌声エンジン。`eki-uta`（ぷっぴの えきうた）の合成ボイスをもとに、フォルマントを少し高くして明るい声にしたもの。
  よみをモーラに分け、8コマ単位で譜割りし、強拍はコードの音にそろえる。伴奏はキック・クラップ・ハイハット・のこぎり波ベースなど。
- `app.js` … 画面・レーナの口パク（母音ごと）とダンス・保存（localStorage `eki-song-lena-v1`、try/catch 済み）。
- 🔊 で おと オン/オフ。縦持ちスマホは1列、横持ちタブレットは レーナ と えきめいひょう が 左右に並ぶ。
