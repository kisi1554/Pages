## れきしの あつかい

- 涙の鼠は 江戸時代の『本朝画史』（1693年）などに伝わる **言い伝え**（宝福寺・足の指で描いた）。動いて縄をかじるのは創作。
- 一休（1394〜1481年）と雪舟（1420〜1506年ごろ）は同時代の禅僧だが、出会う場面は創作。びょうぶのとらは『一休咄』などの とんち話。
- 金閣: 足利義満、1397年ごろ造営、2・3層に金箔（1層は白木）、1950年焼失・1955年再建。
- 銀閣: 足利義政、1489年ごろ上棟。2007年の調査で銀箔の痕跡なし。
- 書院造: 東求堂 同仁斎（1486年ごろ）が現存最古の書院造座敷とされる。
- 能: 観阿弥・世阿弥、1374年（75年説あり）今熊野で義満が観覧。わび茶 村田珠光、いけばな 池坊専慶（1462年）。
- 年号は カード下の 保護者むけ欄だけ。

## つくり

- `index.html` 1枚。え は インライン SVG と canvas（すみえ）、音は WebAudio の 合成音（右上 🔊 で オン/オフ）。
- 保存は localStorage `muromachi-sumie-v1`（音・できた・カード）と `muromachi-sumie-gallery-v1`（かざった え、JPEG 縮小）。
- かく 領域（おはなしの ゆか・すみえの かみ・きんかく）は `touch-action: none`。
- 画面の 下に シリーズ共通「じだいの ものさし」（むろまち が 光る）。おわりに 次の「あづちももやま じだい」を 1文で 予告。
