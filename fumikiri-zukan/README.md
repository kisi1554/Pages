# ふみきり ずかん（いろんな踏切の見た目と音）

ボタンを押すと警報が鳴り、遮断機が下りきってから電車が通ります。
国や時代のちがう 17 種類の踏切を、見た目・光りかた・音で見くらべられます。

## あそびかた

- ⬅️ ひだりへ ／ ⇆ すれちがい ／ ➡️ みぎへ … 電車をよぶ（絵をタッチしても来る）
- 🚃 でんしゃ … おまかせ／つうきん／しんかんせん／かもつ／SL
- 🔊 音オンオフ、🌙 夜（ランプや窓が光る）、🔁 じどう（つぎつぎ電車が来る）
- 踏切ごとに「見た電車の数」を記録（localStorage）

左側通行の国（日本・イギリス・フランス・イタリア・スイス・オーストラリア）と
右側通行の国（アメリカ・カナダ・ドイツ・オランダ・ロシア）で、
右へ行く電車が奥／手前どちらの線路を走るかが変わります。

## しくみメモ

- 種類ごとの違いは `TYPES` の設定（`sign` / `lamp` / `light` / `arm` / `sound` / `scene` など）で切りかえる。
- `index.html` 1 枚。外部ライブラリなし。絵は Canvas、音は WebAudio の合成音のみ。
- 1000×700 の論理座標で描いて拡大。夜は「レイヤーを描く → そのレイヤーだけ暗くする
  (`source-atop`) → ランプや窓を上から光らせる」順で重ねている。
- 電車は車軸ごとの位置が踏切の中心をまたいだ瞬間に「ガタン」を鳴らす。
- 警報が鳴る → `pre` 秒後に遮断機が下りる → 下りきったら電車を出す →
  すべての電車が踏切を抜けたら警報停止・遮断機が上がる。
