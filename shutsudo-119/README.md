# しゅつどう！ 119（shutsudo-119）

しょうぼうしゃ・きゅうきゅうしゃ・パトカー の しごと を たいけん して、**119ばん・110ばん の かけかた** を れんしゅう する アプリ。
対象は 年長〜小学校中学年。`machi-zukuri/`（まちづくり）の まち を「つくる がわ」から、こちらは「乗りこんで 出動する がわ」。

## あそびかた

| メニュー | 中身 |
| --- | --- |
| 🚨 しゅつどう！ | 5つの 出動（家の火事・マンション5階の火事・公園でけが・胸が苦しい おじいちゃん・駅前の まいご） |
| 📞 でんわ れんしゅう | 子どもが 通報する側。火事（119）・救急（119）・交通事故（110）の 3つ |
| 📖 はたらく くるま ずかん | ポンプ車・はしご車・救助工作車・救急車・パトカー・白バイ。サイレン（合成音）を 聞ける。乗った車には「のった！」 |
| 🦺 あんぜん の おやくそく | サイレンが 聞こえたら どうするか（子ども向け）＋ おうちの方へ（通報の流れ・救急車を呼ぶめやす・#7119 / #8000 / #9110） |

### 出動 の ながれ

1. **しれいセンター**: 電話が鳴る → でる →「119ばん、しょうぼう です。かじ ですか、きゅうきゅう ですか？」。
   「ばしょ を きく」「なにが あったか きく」（救急は「なんさい か きく」）「なまえ を きく」の順に ボタンで質問し、
   メモ欄が うまっていく。最後に 出す車を えらぶ（まちがえると「5かい は たかくて とどかない かも」など やさしいヒント）。
   110番（まいご）は「110ばん、けいさつ です。じけん ですか、じこ ですか？」→ パトカー。出動指令の チャイム。
2. **しゅつどう**（上から見た まちの地図）: 「サイレン ON で しゅっぱつ！」で出発。
   - ⏩ アクセルを おしている間 すすむ（はなすとブレーキ）。◀ ▶（または地図を横になぞる）で 次の交差点で曲がる（ウインカーが点滅）。
   - 道順は 黄色の点線と「つぎ は ◀ ひだり に まがる」で案内。曲がり角が近づくと ボタンが光る。行き先が画面外なら 端に矢印。
   - **交差点は ゆっくり**: 交差点の手前に「ゆっくり」の黄色い枠。速いまま入ると いったん止まって「みぎ・ひだり かくにん」（時間が かかる）。
     ゆっくり入ると「かくにん よし！」。
   - ほかの車は サイレンに気づくと、交差点の中なら 交差点を出てから、**道の左に寄って止まる**（ハザード点滅）。歩行者は 歩道で ✋ 待つ。
     サイレンを OFF にすると よけてくれず、前の車に つかえる（「サイレン を ならそう！」）。
   - 到着までの時間で ★1〜3（最短経路の めやす時間との比）。救急は 病院までの2区間の平均。
3. **げんば**
   - 火事: ゆびで なぞって ホースの水を かける。火は かわいい顔の キャラで、水が当たると「> <」の顔、消えると「ひゃ〜！ にげろ〜」と にげていく。
   - はしご車: 5階は ホースが とどかない（点線より上は 水が落ちる）→「はしご を のばす」→ バスケットから 上の窓をねらう。
   - 救急: 声かけ → あしを クッションで そっと まもる／酸素マスク → 担架 → 救急車の中（モニター・酸素マスク・声かけ）→ 病院へ運転 → 医師に引きつぎ。
     けがの様子は描かない（ことばだけ）。
   - まいご: 泣いている子を見つけてタップ → ママの ぼうしの色を聞く → その色の ぼうしの人をタップして 会わせる（色は毎回かわる）。

### でんわ れんしゅう

- 画面の上に いつも「**これは れんしゅう。ほんとう の でんわ は かからない**」「**いたずら でんわ は ぜったい ダメ**（ほんとうに困っている人の電話が つながらなくなる）」と
  「あわてなくて だいじょうぶ。ゆっくり で いいよ。」を表示。
- 状況カード → ダイヤル（119 / 110 を自分で押す。ちがう番号は ⌫ で消して やりなおし）→ 「プルル…」（実際には発信しない）→
  種別 → 場所 → 何があったか →（救急は年齢）→ 名前 の順に ボタンで答える。答えの並びは毎回まぜる。
- 住所が「わかりません」でも OK。「ちかく に なにが みえますか？」と聞かれて **目印** を答える分岐がある。
  「あっち です」「ここ です」は「でんわ だと みえないよ」と やさしく教える。
- 名前は 一覧画面で入れておくと答えのボタンに入る（入れなくても進める）。
- 最後に「できた！」と、伝えた順番のふりかえり。
- アプリは `tel:` リンクや 電話の機能を いっさい使わない。

## 正確さ（調べたこと と 出典）

| 内容 | アプリでの扱い | 出典 |
| --- | --- | --- |
| 119番では まず「火事ですか、救急ですか」と聞かれ、住所（市町村名から。わからなければ近くの大きな建物・交差点などの目印）→ 症状（誰がどうなったか）→ 年齢 → 通報者の名前・連絡先の順に聞かれる。緊急性が高ければ聞き終える前に出動。「あわてず、ゆっくりと答えてください」 | しれいセンター・でんわ れんしゅう の質問の順番と、「ゆっくり で いいよ」の表示 | 総務省消防庁「救急車を上手に使いましょう」（救急車利用マニュアル, 令和7年12月発行）<https://www.fdma.go.jp/publication/portal/post2.html> |
| 「火事ですか、救急ですか」→ 住所（マンションは建物名・部屋番号も）→ 何が燃えているか／誰がどうしたか → 名前。携帯からは住所が言えなければ建物名・交差点名・店名 | マンションの部屋番号の答え、目印の答え | 東京消防庁「119番通報」<https://www.tfd.metro.tokyo.lg.jp/lfe/119/119.html> |
| 横浜市でも 119番は「火事ですか、救急ですか？」から始まる | 同上 | 横浜市「110番・119番」<https://www.city.yokohama.lg.jp/lang/residents/living-guide/emergency/110-119.html> |
| 110番は「事件ですか、事故ですか」→ いつ → どこで（交差点・バス停などの目標物）→ どうなっているか → 通報者の名前など。緊急でない相談は #9110 | 110番の れんしゅう（交通事故）と まいご出動の電話 | 福岡県警察「110番通報のしかた」<https://www.police.pref.fukuoka.jp/data/open/cnt/3/22206/1/110.pdf>、山梨県警察 <https://www.pref.yamanashi.jp/police/p_tiiki/110info/kakekata.html>、滋賀県警察 <https://www.pref.shiga.lg.jp/police/seikatu/chiiki/305650.html> |
| 緊急自動車が近づいたら、交差点やその付近では 交差点を避けて道路の左側に寄って一時停止、それ以外では左側に寄って進路をゆずる（道路交通法第40条） | 運転画面の ほかの車の よけ方（交差点の中では止まらず、出てから左へ）、あんぜん画面 | 道路交通法第40条（e-Gov法令検索 <https://laws.e-gov.go.jp/law/335AC0000000105>）、名古屋市消防局の解説 <https://www.city.nagoya.jp/bousai/shoubou/1012732/1034504/1034505/1013317.html> |
| こどもで ためらわず救急車を呼んでほしい症状の例（くちびるが紫色で呼吸が弱い、けいれんが止まらない、広範囲のやけど、3か月未満の乳児の様子がおかしい など） | おうちの方へ（抜粋） | 消防庁マニュアルの紹介（栃木県）<https://www.pref.tochigi.lg.jp/e02/kyuukyuusha.html> |
| #7119（救急安心センター事業）は救急車を呼ぶか迷うときの電話相談。実施地域は限られる（令和7年12月時点で神奈川県・東京都など）。#8000 は子ども医療電話相談（各都道府県）。全国版救急受診アプリ「Q助」 | おうちの方へ のみ（子ども向け画面には出さない） | 上記 消防庁マニュアル p.6 |
| 救急隊は 3人で 救急車に乗る | ずかん の説明 | 消防庁マニュアル・各消防本部の説明に基づく一般的な編成 |

- 歩行者が緊急車両に道をゆずる法的義務については解釈が分かれるため、アプリでは「サイレンが聞こえたら わたらずに 歩道で待つ」を
  **安全のための おやくそく** として出している（法律の説明はしていない）。
- サイレン音は本物の録音ではなく、WebAudio で にせた合成音（救急車は 960Hz / 770Hz の交互「ピーポー」、消防は ゆっくり上下する「ウー」＋カンカン、
  パトカーは はやめに上下する「ウー ウー」）。音量は ひかえめ（`audio.js` の `SIREN_VOL`）。
- 住所・人名・まちの名前（さくらまち・ひかりがおか など）は すべて架空。車両の絵は コードで描いた オリジナルで、
  文字は「しょうぼう」「きゅうきゅう」「けいさつ」だけ（実在の自治体のロゴ・制服デザインは使わない。救急車のマークも オリジナルの星形）。

## しくみメモ

- 保存は localStorage `shutsudo-119-v1`（★・乗った車・れんしゅう済み・名前・音の設定）。読み書きは try/catch。
- 音は 🔊 全体 / 🚨 サイレンの音 / 🗣️ よみあげ を それぞれ オン/オフ。サイレンを消しても ランプは光る。
- 運転画面・げんば画面は `touch-action: none` で スクロール・ズームしない。ほかは `tools/no-zoom.py` の共通ブロック。
- テスト用に `window.S119`（`screen()`・`drive()`・`scene()`・`autoDrive`）を出している。`autoDrive = true` で 道案内どおりに自動運転
  （交差点の手前で ゆっくりになる）。Playwright で 390×844・1024×768 の両方で 5つの出動を自動クリア、でんわ れんしゅう 3つを最後まで進めて確認。
