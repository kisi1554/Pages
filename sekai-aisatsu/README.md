# せかいの あいさつ ハイタッチ 🤝

**空港の とうちゃくロビーに、せかいから どうぶつの おきゃくさんが やってくる。
その 国の「こんにちは」を きいて、よく ある あいさつの しかたで おむかえ しよう。**
5さい むけ。1回 1〜3分（おきゃくさん 5にん ＋ カードあわせ）。

`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・CDN なし、オフラインで うごく）。

公開URL: https://kisi1554.github.io/Pages/sekai-aisatsu/

## あそびかた

1. おきゃくさん（はた と 国の 名前つき）が あるいてきて、ふきだしで あいさつ（げんちの 文字 ＋ カタカナ）。
2. あいさつの しかたを 3つから えらぶ：🙇 おじぎ／🤝 あくしゅ／🤗 ハグ／🙏 手を あわせる／😚 ほっぺを よせる。
   - まちがえると おきゃくさんが「？？？」。その ボタンは うすくなり、のこりから もういちど えらべる。
   - ぴったりだと わらいの えんしゅつ（**答えあわせの あと**に だす）：
     おじぎ どうしで 頭が ごっつん／ハグで あおちゃんが ぺちゃんこ → ぽよーん／あくしゅ ぶんぶん／ほっぺ ちょん ちょん。
   - ロビーに その 国の はたが ふえ、ひとこと せつめいが でる。
3. 5にん むかえたら「こんにちは」の ことば と 国（はた）を つなぐ カードあわせ（4くみ）。
4. さいごに ほめる がめん（紙ふぶき・ファンファーレ）。タイトルの「あいさつ できた 国」に はたが たまる。

## 10か国と あいさつ

| 国 | ことば | カタカナ | よく ある しかた | せんたくしから はずしている（それも ふつうに ある）もの |
| --- | --- | --- | --- | --- |
| にほん | こんにちは | コンニチハ | おじぎ | あくしゅ |
| アメリカ | Hello | ハロー | あくしゅ | ハグ |
| 中国 | 你好 | ニーハオ | あくしゅ（かるく うなずく） | おじぎ |
| 韓国 | 안녕하세요 | アンニョンハセヨ | おじぎ | あくしゅ |
| フランス | Bonjour | ボンジュール | ほっぺを よせる（ビズ） | あくしゅ・ハグ |
| インド | नमस्ते | ナマステ | 手を あわせる | おじぎ |
| タイ | สวัสดี | サワッディー | 手を あわせる（ワイ） | おじぎ |
| スペイン | ¡Hola! | オラ | ほっぺを よせる（2かい） | あくしゅ・ハグ |
| ブラジル | Oi! | オイ | ハグ（アブラッソ） | ほっぺ・あくしゅ |
| ケニア | Jambo! | ジャンボ | あくしゅ（みぎ手） | — |

- **きめつけない**: あいさつは 地域・年齢・あいて・場面で ちがう。アプリ内でも 毎回
  「おなじ 国でも ひとや ばしょで いろいろ。これは『よく ある あいさつ』の ひとつ」と そえる。
  その国で ふつうに 見られる ほかの しかたは、まちがいの せんたくしに 出さない（上の表の右の列）。
- ケニアの「ジャンボ」は 旅行者むけに よく つかわれ、ケニアの 人どうしでは「ハバリ？」なども よく つかう、と せつめいに 入れた。
- タイは「サワディー」と 書かれる ことも 多いが、のばす 音を いかして「サワッディー」に した。
  男性は「クラップ」、女性は「カー」を つけると ていねい、と ひとこと そえた。
- 発音は 合成音で 鳴らさない（録音も つかわない）。文字と カタカナだけ。
- 参考: SBS Cultural Atlas（Kenyan / Thai / Brazilian culture – Greetings）、各国の あいさつに ついての 一般的な 資料。

## ほかの アプリとの ちがい

- [せかい いっしゅう りょこう](../sekai-ryoko/) にも 各国の「こんにちは」が あるが、こちらは
  **あいさつの しかた（からだの うごき）** が 主役で、ことばは 文字だけ。
- [こっき たんけん](../kokki-tanken/) の はたの え（SVG）を ベースに、10か国ぶんを index.html に 入れた（ケニアは あらたに かいた）。
- [えいご みみ](../eigo-mimi/) の ような 音声の 学習は しない。

## しくみ

- 1ファイル（`index.html`）。おとは WebAudio の 合成音だけ。🔊/🔇 で オン/オフ（保存される）。
- localStorage キー `sekai-aisatsu-v1`: `{ met: [国id...], plays, sound }`。読み書きは try/catch。
- 縦スマホは 上に ロビー・下に ボタン、横タブレットは 左右 2れつ。
- ズーム対策は `python3 tools/no-zoom.py sekai-aisatsu` の 共通ブロック。
