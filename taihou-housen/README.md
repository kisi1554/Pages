- **ボスせん**: ⚠️ けいほうと いっしょに ボスが あらわれる。HP の かいすう あてると たおせる
  （あたると あかく ひかって ゆれる・HP バーが へる）。たおすと れんぞく だいばくはつ ＆「やっつけた！」。
- **💡 ヒント**（ステージだけ）: おすたびに くわしく なる 3だんかい。
  1. 「ななめ 45°くらいで・いきおいは ふつう」のような ことば
  2. かくどを おしえて、みどりの せんで むきを みせる
  3. こたえ（かくど・いきおい）と、とぶ みちを みどりの てんせんで みせる（⭐ は 2つまで）

  こたえは その まとに あたる くみあわせを ぜんぶ ためして、すこし ずれても あたる ものを えらぶ。
  3かい つづけて はずすと「こまったら 💡ヒント を おしてね」と でる。

- 🔬 **じっけん**: まとなし。めもり つきの そらに なんぱつでも うてる。
  「30°と60°」「45°は？」「15°と75°」ボタンで おなじ いきおいの ボールを いっしょに うって くらべられる。
  みぎうえに とんだ きょり・いちばん たかい ところ・じかんの きろくが でる。
- 📖 **ほうぶつせんの ひみつ**: ①まがった みち ②よこは おなじ・たては かわる ③45°が いちばん とおい
  ④30°と60°は おなじ ところに おちる ⑤いきおい 2ばいで きょり 4ばい。

## まなびの しかけ

- ボールの **あしあと**（0.25びょう ごとの てん）。よこの あいだは いつも おなじ、たての あいだは かわる。
- **➡️ やじるし**: あしあとに よこ（あお）と たて（あか）の はやさの やじるしを かく。よこは かわらず、たては へって ぎゃくむきに。
- **✨ よそくせん**: ステージでは とちゅうまで、じっけんでは さいごまで、とぶ みちを てんてんで みせる。
- じめんの ものさし（たいほうからの きょり m）、たいほうの ぶんどき（かくど）。
- ぶつりは じっさいの しき（g = 9.8 m/s²、はっしゃてんは じめんの たかさ）なので、30°と60°は ぴったり おなじ きょりに なる。
  すべての ステージの すべての まとが せいすうの かくど・いきおいで クリアできることを けいさんで たしかめてある。
