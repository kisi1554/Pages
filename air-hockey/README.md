# エアホッケー 🏒

タブレット（スマホでも）を テーブルに おいて、むかいあった 2にんで たいせん する エアホッケーです（年長〜大人むけ）。
`index.html` を ブラウザで ひらくだけで あそべます（がいぶ ライブラリ なし・え は Canvas・おと は WebAudio の ごうせいおん）。

## あそびかた

| モード | ないよう |
| --- | --- |
| 👫 2にん たいせん | じぶんの じんち（テーブルの はんぶん）を ゆびで さわって マレットを うごかす。マルチタッチで 2にん どうじ |
| 🤖 1にん | CPU と たいせん。つよさ 🐣 よわい・🐥 ふつう・🦅 つよい・🐉 めっちゃ つよい |
| 👀 CPU どうし | CPU どうしの しあいを みる |

- たてもち は たてながの テーブル（あお が した、あか が うえ）、よこもち は よこながの テーブル（あお が ひだり、あか が みぎ）。
- さきに 3／5／7／10 てん（せってい）とった ほうが かち。いれられた ほうの じんち から さいかい。
- **10びょう ルール**: パックが 10びょう ずっと かたほうの じんちに あると、あいての じんちから さいかい（かどに はさまって うごかない とき も これで なおる）。
- とくてん・「ゴール！」・ひとやすみ・けっか は、どちらの ひと からも よめる むき で りょうがわに でる。
  メニューは 「🔄 むきを かえる」 で 180ど まわせる。
- ⏸ ボタン（それぞれの ひとの みぎて がわ）で ひとやすみ。

### アイテム（せってい で あり／なし）

まんなか ふきんに ときどき でて、パックが あたると はつどう（10びょう）。「とった ひと」は さいごに パックを うった ひと。

| | こうか |
| --- | --- |
| 🎱 | パックが 3つに（どれが はいっても 1てん。ぜんぶ はいる か 12びょう で もとに もどる） |
| 🍄 | とった ひとの マレットが 1.45ばい に |
| 🥅 | **とった ひとの ゴール** が せまく なる（あいて から みると ねらう ゴールが せまい → まもりやすい） |
| 🧊 | こおり: まさつ なし・かべで へらない・パックが とまらない |
| 🧱 | まんなかに かべ |

### テーブル

ふつう・こおり・ネオン（ひかる せん。てんめつ は しない）・でんしゃ（せんろ もよう、まんなかは ふみきり）。

## ぶつり（`physics.js`）

- パック と マレット は えん。ざひょう は テーブルの はば = 1、ながさ = 1.7。
- **こてい タイムステップ**: 1ティック = 1/120びょう を **8サブステップ** に わける（60Hz の がめん なら 1フレーム 16サブステップ）。
  フレームの ながさ は ためて おいて ティック に わけるので、120Hz・144Hz の たんまつ でも はやさ は かわらない。
- **れんぞく しょうとつ はんてい**: サブステップ ごとに、かべ・ゴールの かど・まんなかの かべ・うごいて いる マレット（あいて から みた はやさ）と
  ぶつかる じかん を とき、いちばん はやい ところ まで すすめて はねかえす（1サブステップ で 8かい まで）。
- マレット は ゆび の ところ へ さいこう そくど（4.5/びょう）まで で おいかける。その はやさ（ちょっきん の ゆびの うごき）が パックに つたわる（はねかえり 0.9）。
- パックの さいこう そくど 5/びょう、まさつ すくなめ（1びょう で やく 22%）、かべの はねかえり 0.88。
- **はさみこみ**: マレットで パックを かべ に おしつけた ときは、パックを かべの なか に のこし、マレット の ほうを さげる（その ティック は マレットが とまり、パックの いきおい も へらす）。
- かべぎわ（ゴールの あな いがい）で とまりかけた パックは くうき で そっと うちがわ に うく（かどで うごけなく ならない）。
- パックの まんなか が ゴールラインを こえたら ゴール。

## CPU（`ai.js`）

| つよさ | マレットの はやさ | みなおす かんかく | うちかた |
| --- | --- | --- | --- |
| 🐣 よわい | 1.5 | 0.32びょう | ゆっくり まもる だけ（とまった パックを おす くらい） |
| 🐥 ふつう | 2.5 | 0.18びょう | まっすぐ ゴールへ |
| 🦅 つよい | 3.4 | 0.09びょう | かくど を つける・かべ あて・パックの すすむ さき を よむ |
| 🐉 めっちゃ つよい | 4.3 | 0.04びょう | おなじ。ぶれ が すくない |

パックの うしろ に はいれない（かべぎわ）ときは おしつけず に まつ。

## えんしゅつ・おと・ぶるっ

- パックの ざんぞう、うった ときの しょうげき リング、ゴールで かみふぶき と「ゴール！」（りょうがわ）、がめんの ゆれ（せってい で オフ）。大きな てんめつ は しない。
- おと: カン！（うつ。はやい ほど たかい）・コン（かべ）・キン（ゴールの かど）・ゴールの ブザー と かんせい・アイテム。🔊 で オン／オフ。
- `navigator.vibrate` が つかえる たんまつ では ぶつかった ときに みじかく ぶるっ（📳 で オフ）。
- あそぶ がめん は `touch-action: none` で スクロール・ズーム・ひっぱって こうしん を ふせぐ。
