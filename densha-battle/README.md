# でんしゃバトル 🚃⚔️💥🎃 〜でんしゃの勇者と やさい四天王の クイズバトル〜

**でんしゃが擬人化した勇者**を操作して、おそいかかる**野菜モンスター**をクイズで撃退する**リアルタイム**バトルゲームです。

勇者は見た目こそ人間ですが、みんな**自分の路線をもつ電車の化身**。
よろい・マント・ぶき・ブーツは**その路線のカラー**、胸には**路線記号のバッジ**、
足もとの札と名前の上には**路線名**が出ます。

ターン制ではありません。**正解するたびに、その場ですぐ攻撃が飛びます。**
早く解けば解くほど攻撃が途切れず、モンスターはあっという間に吹き飛びます。

全10ウェーブ。ウェーブ 3・5・7・9 には画面いっぱいの**やさい四天王**、
最後のウェーブには**大魔王 ベジタゴン**が立ちはだかります。

`index.html` をブラウザで開くだけで遊べます（ビルドもサーバーも音源ファイルも不要・オフラインOK）。

## あそびかた

1. **はじめる** → **ジャンル**を選ぶ → **レベル**を選ぶ → **勇者（路線）**を選ぶ。
2. 画面の下にずっと問題が出ています。4つのボタンから答えをタップ。
3. **正解** → その瞬間に光の弾が飛んで、先頭のモンスターにヒット。
   すぐ次の問題が出るので、**手を止めずに連続攻撃**できます。
4. **速く答えるとクリティカル**（ダメージ 1.6倍）。上のバーが青いうちが
   クリティカルの時間です。
5. **まちがえる** → 正しい答えが表示され、0.75秒だけ手が止まって少しダメージ。
6. モンスターは**それぞれ自分のタイミングで勝手に攻撃してきます**。
   足元の小さなゲージがたまると突っこんでくるので、その前に倒しましょう。
7. 全部倒すと次のウェーブへ（体力が 25 回復）。**全10ウェーブ**でクリア。

キーボードの **1〜4** でも答えられます。

## 3つの ジャンル

最初にジャンルを選びます。どのジャンルにも かんたん／ふつう／つよい の3レベルがあります。

### 🔢 さんすう

| レベル | 出る問題 |
| --- | --- |
| かんたん | 1けた + 1けた のたし算（答えは 10 → 18 まで、ウェーブが進むと増える） |
| ふつう | 20までの たし算・ひき算 |
| つよい | かけ算（九九）と 2けたの たし算・ひき算 |

「かんたん」では 🚃 と 🚋 を並べた**かぞえられるヒント**が出ます。
まちがえた選択肢は「ありそうなまちがい」（±1、くり上がり忘れ、九九の1列ずれ）から作っています。

### 🈳 かんじ（駅名の読み）

**529駅**から出題します。データは同じリポジトリの
[`../densha-talk`](../densha-talk)（路線と駅の一覧）から生成しました。

| レベル | 出る駅 | 駅数 |
| --- | --- | --- |
| かんたん | のりかえの多い有名駅（山手線・主要ターミナル） | 131駅 |
| ふつう | かんたん＋ふつうの駅 | 333駅 |
| つよい | 難読駅（鶯谷・弘明寺・等々力・九品仏・雑色 など） | 196駅 |

出題は 2種類。「**渋谷** なんて よむ?」（漢字→よみ・75%）と
「**しぶや** かんじは どれ?」（よみ→漢字・25%）。
まちがいの選択肢は、**よみの長さが近い駅**から選ぶので当てずっぽうが効きません。

### 🗾 にほんちず（都道府県）

**47都道府県**から出題します。データは
[`../nippon-sugoroku`](../nippon-sugoroku) の都道府県データから生成しました。

| レベル | 出る問題 |
| --- | --- |
| かんたん | 県名のよみ／なに地方か |
| ふつう | 県名のよみ／地方／県庁所在地／名物クイズ |
| つよい | 県庁所在地（両方向）／となりの県／名物クイズ |

「となりの県」は実際の隣接データを使っているので、まちがいの選択肢は**必ず隣ではない県**になります。

### 見た目のつくり

立ち絵はすべてCSSで組み立てています。

- **よろい・マント**：路線カラー
- **胸の白いライン**：電車の帯（ライン）に見立てた白帯
- **胸のバッジ**：路線記号（JY / KK / G …）を駅ナンバリング風の丸バッジで
- **ブーツ**：つま先が路線カラー
- **足もとの札**：電車の行き先表示ふうに路線名を表示
- かみの色・はだの色・ぶき・かぶりものは 人間らしく バラバラ

バトル開始と必殺技のときに**口ぐせをしゃべります**。

## 野菜モンスター

14種類。大きさで強さが決まります。

| 大きさ | 例 | HP | こうげき | ためる時間 |
| --- | --- | --- | --- | --- |
| ざこ | 🥕ニンジーン / 🍅トマトン / 🥒キューリー / 🧄ニンニクー / 🫑ピーマング | 30 | 4 | 5.6秒 |
| ふつう | 🥦ブロッコリン / 🌽コーンガー / 🍆ナスビーム / 🧅タマネギング / 🌶️トウガラシー | 62 | 6 | 6.2秒 |
| おおもの | 🥔ジャガイモス / 🥬ハクサイダー / 🍠サツマイモン / 🥑アボガドン | 100 | 9 | 7.0秒 |

### 英語で名乗る

攻撃するとき、野菜は**自分の英語名を叫びます**。画面に大きく出て、音声合成（英語）でも
読み上げます。`Carrot!` `Broccoli!` `Eggplant!` `Chinese cabbage!` …
遊んでいるうちに野菜の英語が耳に残ります。

### 意外な うごき

野菜はそれぞれ**ちがう動き方**をします（`data-move`）。

ぴょんぴょん跳ねる（トマトン）／ころころ転がる（コーンガー）／ふわふわ浮く（ナスビーム）／
くるくる回る（ハクサイダー）／横にスーッとすべる（キューリー）／さかさまになる（ピーマング）／
ぐにゃぐにゃ伸び縮み（タマネギング）／**ふっと消えてワープ**（ニンニクー）／
ジグザグ（サツマイモン）／どっしり地響き（ジャガイモス）／振り子（アボガドン）／
急に突っこんで戻る（トウガラシー）／ドリル回転（ニンジーン）

さらに **2.4〜5.2秒ごとに1体が「きまぐれアクション」**をします。
大ジャンプ／2回転／一瞬巨大化／ワープして反対側から出現／ぐっと前に出て覗きこむ／
ころころ転がって戻る の6種類からランダムです。

## やさい四天王と大魔王

| ウェーブ | ボス | HP | こうげき | 大きさ |
| --- | --- | --- | --- | --- |
| 3 | 🎃 カボチャだいまおう（ほのおの四天王） | 190 | 11 | 3.0倍 |
| 5 | 🥬 ハクサイ・ブリザード（こおりの四天王） | 250 | 13 | 3.15倍 |
| 7 | 🌽 コーン・サンダーガ（かみなりの四天王） | 310 | 15 | 3.3倍 |
| 9 | 🍆 ナス・ドクロン（やみの四天王） | 370 | 17 | 3.45倍 |
| 10 | 🥦👑 ベジタゴン（やさいの大魔王） | 470 | 19 | 3.9倍 |

ボスはどれも **HP が半分を切ると「だい2けいたい」**になり、攻撃力 1.35〜1.5倍・

| しくみ | なにが おきる |
| --- | --- |
| **ひっさつゲージ** | 正解 5回でゲージが満タン。次に正解した瞬間、画面を貫くビームで**全モンスターに大ダメージ**。 |
| **ハイパーモード** | **8連続正解**で発動。ダメージ 1.3倍、画面が燃えて、BGMも速いトラックに。まちがえると解除。 |

## えんしゅつ

- **ボス登場カットイン**: 画面が暗転し、ひび割れが走り、四天王の巨大な絵文字と
  「ほのおの四天王／カボチャだいまおう」の名乗りがドンと出る（約1.9秒）
- **でかい四天王**: ふつうのモンスターの 3倍以上。足元に禍々しい影、目が光る
- **だい2けいたい**: 赤い全画面フラッシュ＋画面のひび割れ＋赤いビネット
- 光の弾＋**ビーム**の軌跡、着弾で**衝撃波の輪**・火花・野菜のかけらが飛び散る
- クリティカルで**斬撃**・**集中線**・画面ズーム・フラッシュ
- 倒すと大爆発／ボスは4〜6連続爆発＋ひび割れ＋紙ふぶき
- ひっさつわざは画面を横切る極太ビーム＋全体に稲妻

**演出は「アリーナ（戦場）の中だけ」に描いています。** 下の答えボタンの上には
パーティクルが被らないので、どんなに派手でも問題は読めて、ボタンも押せます。
画面の揺れもアリーナだけで、ボタンは揺れません。

`prefers-reduced-motion: reduce` の端末では、粒子の数を減らし画面の揺れを止めます。

## 音

- **BGM** は Web Audio API でその場で合成しています（音源ファイル不要）。全11トラック。
  **場面ごとに曲が切りかわり、1回の通しプレイで 16回ほど曲が変わります。**

  | 場面 | 曲 |
  | --- | --- |
  | メニュー | はっしゃ ベル |
  | ざこの波 | バトル トレイン → こうそく しんこう → ラッシュアワー → やさいばたけ しんげき（ウェーブごとに次の曲へ） |
  | ハイパーモード中 | ハイパー ドライブ（BPM 196） |
  | 四天王戦 | 四天王 とうじょう / ひょうが / らいめい / さいご（四天王ごとに専用曲） |
  | 四天王 だい2けいたい | 四天王 かくせい / きょうらん |
  | 大魔王戦 | 大魔王 ベジタゴン（BPM 174・和声的短音階） |
  | 大魔王 だい2けいたい | 大魔王 しんのすがた（BPM 212） |

- **効果音**：発射／ヒット／クリティカル／ひっさつ／被弾／野菜がつぶれる音／
  ウェーブクリア／ハイパー突入／ボス登場の警笛 など。
- **読み上げ**：問題文は日本語で読み上げます（さんすうの「つよい」だけはテンポ優先で
  読み上げません）。野菜の英語名は**英語の声**で読み上げます。
- 右上の 🎵（BGM）／🔊（読み上げ）ボタンでそれぞれオン・オフできます。

音はブラウザの制限により**最初のタップのあと**に鳴りはじめます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |

## 動作環境

モダンブラウザ（Chrome / Safari / Edge）。音声合成は対応ブラウザのみ有効です
（英語の声が入っていない端末では、英語名は画面表示のみになります）。
