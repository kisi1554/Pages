# でんしゃバトル 🚄💥 〜さんすうで ひっさつわざ〜

「でんしゃトーク」のキャラクターたちが**バトル**するゲームです。
算数の問題に正解すると、自分の電車が相手に突っ込んで**ド派手に**ダメージを与えます。
6ステージ勝ち抜いてチャンピオンを目指します。

`index.html` をブラウザで開くだけで遊べます（ビルドもサーバーも音源ファイルも不要・オフラインOK）。

## あそびかた

1. **はじめる** → **レベル**を選ぶ → **あいぼう（電車キャラ）**を選ぶ。
2. 算数の問題が出るので、4つのボタンから答えをタップ。
3. **正解** → 自分の電車が突撃してこうげき。**はやく答えると クリティカル**（ダメージ 1.6倍）。
4. **まちがい・じかんぎれ** → 正しい答えが表示され、相手の攻撃を受ける。
5. 正解を続けると**ひっさつゲージ**がたまり、MAXで**ひっさつわざ**（ダメージ 2.6倍＋大爆発）。
6. 相手のHPを 0 にすると次のステージへ（体力が 30 回復）。6人目は**ラスボス**。

キーボードの **1〜4** でも答えを選べます。

## レベル

| レベル | 出る問題 | だいたいの学年 |
| --- | --- | --- |
| かんたん | 1けた + 1けた のたし算（答えは 10 → 18 まで、ステージが進むと増える） | 年中〜年長 |
| ふつう | 20までの たし算・ひき算 | 小1 |
| つよい | かけ算（九九）と 2けたの たし算・ひき算 | 小2 |

- 「かんたん」では、たし算のときに 🚃 と 🚋 を並べた**かぞえられるヒント**が出ます。
- まちがえた選択肢は「ありそうなまちがい」（±1、くり上がり忘れ、九九の1列ずれ など）から作っています。
- ステージが進むほど、同じレベルの中でも数がすこしずつ大きくなります。

## とうじょうキャラクター

- 遊べる電車は 16 人。名前・色・路線は [`../densha-talk`](../densha-talk) の設定と同じです
  （やまのてん / けいきゅん / とうよこくん / ぎんじろう / まるこ / ろまんちゃん …）。
- キャラごとに **こうげき力** と **ひっさつわざの名前** がちがいます。
- ラスボス **ヤミカゲごう**（あんこく とっきゅう）はこのゲームだけのオリジナル。
  まっ黒な車体・赤く光る目で、HP 170・攻撃力 1.6倍。

## えんしゅつ（ド派手ポイント）

- 突撃アニメーション、**しゅうちゅうせん**、スピードせん、いなずま、しょうげきは（ひろがる輪）
- がめん全体の**フラッシュ**と**シェイク**、とびちる火花とキャラ絵文字
- ダメージ数字がドンと出る／「どっかーん!」などのかけ声／ひっさつわざのバナー
- 勝つと紙ふぶき

`prefers-reduced-motion: reduce` の端末では、粒子の数を減らし画面の揺れを止めます。

## 音

- **BGM** は Web Audio API でその場で合成しています（音源ファイル不要）。
  「メニュー」「バトル」「ボス」の3種類の雰囲気があり、場面に合わせて曲が切りかわります。
  8小節ごとに同じ雰囲気の別トラックへ移るので、同じ曲が続きません。
- **効果音**：ため／ヒット／クリティカル／ひっさつ／被弾／KO／ファンファーレ／警笛 など。
- **読み上げ**：問題文とセリフをブラウザの音声合成（日本語）で読み上げます。
- 右上の 🎵（BGM）／🔊（読み上げ）ボタンでそれぞれオン・オフできます。

音はブラウザの制限により**最初のタップのあと**に鳴りはじめます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（タイトル / レベル / キャラ選び / バトル / けっか） |
| `style.css` | 見た目・電車のCSSスプライト・アニメーション |
| `data.js` | キャラクター、ラスボス、ステージの組み立て |
| `quiz.js` | 算数の問題と選択肢を作る |
| `audio.js` | BGM合成・効果音・読み上げ |
| `effects.js` | canvas のパーティクル、画面の揺れ・フラッシュ・ダメージ表示 |
| `game.js` | ゲーム本体（ターン進行・ダメージ計算・演出の組み立て） |

## 動作環境

モダンブラウザ（Chrome / Safari / Edge）。音声合成は対応ブラウザのみ有効です（非対応でも他はふつうに遊べます）。
