# でんしゃバトル 🚄💥🥦 〜やさいモンスターを けいさんで たおせ〜

「でんしゃトーク」の電車キャラクターを操作して、おそいかかる**野菜モンスター**を
算数で撃退する**リアルタイム**バトルゲームです。

ターン制ではありません。**正解するたびに、その場ですぐ攻撃が飛びます。**
早く解けば解くほど攻撃が途切れず、モンスターはあっという間に吹き飛びます。

`index.html` をブラウザで開くだけで遊べます（ビルドもサーバーも音源ファイルも不要・オフラインOK）。

## あそびかた

1. **はじめる** → **レベル**を選ぶ → **あいぼう（電車キャラ）**を選ぶ。
2. 画面の下にずっと算数の問題が出ています。4つのボタンから答えをタップ。
3. **正解** → その瞬間に光の弾が飛んで、先頭のモンスターにヒット。
   すぐ次の問題が出るので、**手を止めずに連続攻撃**できます。
4. **速く答えるとクリティカル**（ダメージ 1.6倍）。上のバーが青いうちが
   クリティカルの時間です。
5. **まちがえる** → 正しい答えが表示され、0.6秒だけ手が止まって少しダメージ。
6. モンスターは**それぞれ自分のタイミングで勝手に攻撃してきます**。
   足元の小さなゲージがたまると突っこんでくるので、その前に倒しましょう。
7. 全部倒すと次のウェーブへ（体力が 25 回復）。**全8ウェーブ**でクリア。

キーボードの **1〜4** でも答えられます。

## もりあがる しくみ

| しくみ | なにが おきる |
| --- | --- |
| **ひっさつゲージ** | 正解 5回でゲージが満タン。次に正解した瞬間、画面を貫くビームで**画面上の全モンスターに大ダメージ**。 |
| **ハイパーモード** | **8連続正解**で発動。ダメージ 1.3倍、画面が燃えて、BGMも速いトラックに切りかわる。まちがえると解除。 |
| **クリティカル** | 制限時間内に答えると 1.6倍＋斬撃・集中線・画面ズーム。 |
| **コンボ** | 連続正解でダメージが上乗せ（最大 +9.6）。 |

## レベル

| レベル | 出る問題 | クリティカルの時間 | だいたいの学年 |
| --- | --- | --- | --- |
| かんたん | 1けた + 1けた のたし算（答えは 10 → 18 まで、ウェーブが進むと増える） | 2.8秒 | 年中〜年長 |
| ふつう | 20までの たし算・ひき算 | 2.4秒 | 小1 |
| つよい | かけ算（九九）と 2けたの たし算・ひき算 | 2.6秒 | 小2 |

- 「かんたん」では、たし算のときに 🚃 と 🚋 を並べた**かぞえられるヒント**が出ます。
- まちがえた選択肢は「ありそうなまちがい」（±1、くり上がり忘れ、九九の1列ずれ など）から作っています。
- ウェーブが進むほど、同じレベルの中でも数がすこしずつ大きくなります。

## とうじょう キャラクター

**あいぼう（自分）**: 16人の電車。名前・色・路線は [`../densha-talk`](../densha-talk) の設定と同じです
（やまのてん / けいきゅん / とうよこくん / ぎんじろう / まるこ / ろまんちゃん …）。
キャラごとに**こうげき力**と**ひっさつわざの名前**がちがいます。

**てき**: 14種類の野菜モンスター。大きさで強さが決まります。

| 大きさ | 例 | HP | こうげき | ためる時間 |
| --- | --- | --- | --- | --- |
| ざこ | 🥕ニンジーン / 🍅トマトン / 🥒キューリー / 🧄ニンニクー / 🫑ピーマング | 30 | 4 | 5.6秒 |
| ふつう | 🥦ブロッコリン / 🌽コーンガー / 🍆ナスビーム / 🧅タマネギング / 🌶️トウガラシー | 62 | 6 | 6.2秒 |
| おおもの | 🥔ジャガイモス / 🥬ハクサイダー / 🍠サツマイモン / 🥑アボガドン | 100 | 9 | 7.0秒 |

**ボス**: ウェーブ4 に **🎃 カボチャだいまおう**（HP 210）、ウェーブ8 に
**🥦👑 ベジタゴン**（やさいの王さま・HP 330）。ボス戦は背景もBGMも変わります。

## えんしゅつ（ド派手ポイント）

- 光の弾＋**ビーム**の軌跡、着弾で**衝撃波の輪**・火花・野菜のかけらが飛び散る
- クリティカルで**斬撃**・**集中線**・画面ズーム・フラッシュ
- 倒すと大爆発＋その野菜の絵文字が飛び散る／ボスは4連続爆発＋紙ふぶき
- ひっさつわざは画面を横切る極太ビーム＋全体に稲妻
- ハイパーモードは画面の色が波打ち、ふちが金色に光る

**演出は「アリーナ（戦場）の中だけ」に描いています。** 下の答えボタンの上には
パーティクルが被らないので、どんなに派手でも問題は読めて、ボタンも押せます。
画面の揺れもアリーナだけで、ボタンは揺れません。

`prefers-reduced-motion: reduce` の端末では、粒子の数を減らし画面の揺れを止めます。

## 音

- **BGM** は Web Audio API でその場で合成しています（音源ファイル不要）。
  「メニュー」「バトル」「ハイパー」「ボス」の4種類の雰囲気があり、場面で切りかわります。
  8小節ごとに同じ雰囲気の別トラックへ移るので、同じ曲が続きません。
- **効果音**：発射／ヒット／クリティカル／ひっさつ／被弾／野菜がつぶれる音／
  ウェーブクリア／ハイパー突入／警笛 など。
- **読み上げ**：**かんたん・ふつう**では問題を音声合成（日本語）で読み上げます。
  **つよい**はテンポを優先して読み上げません。ボスのセリフはどのレベルでも読み上げます。
- 右上の 🎵（BGM）／🔊（読み上げ）ボタンでそれぞれオン・オフできます。

音はブラウザの制限により**最初のタップのあと**に鳴りはじめます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（タイトル / レベル / キャラ選び / バトル / けっか） |
| `style.css` | 見た目・電車と野菜モンスター・アニメーション |
| `data.js` | 電車キャラ、野菜モンスター、ボス、ウェーブの組み立て |
| `quiz.js` | 算数の問題と選択肢を作る |
| `audio.js` | BGM合成・効果音・読み上げ |
| `effects.js` | canvas のパーティクル（火花・輪・稲妻・ビーム・斬撃・集中線・紙ふぶき）、画面の揺れ・ズーム・フラッシュ・ダメージ表示 |
| `game.js` | ゲーム本体（リアルタイムのループ・ウェーブ進行・ダメージ計算・演出の組み立て） |

## 動作環境

モダンブラウザ（Chrome / Safari / Edge）。音声合成は対応ブラウザのみ有効です（非対応でも他はふつうに遊べます）。
