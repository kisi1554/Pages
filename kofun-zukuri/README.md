# こふん どっこいしょ 🗝️

**おうさまの おおきな おはか（こふん）を つくって、はにわで かざる ゲーム。**
10本シリーズ「じだい たんけん」の 1本（こふん じだい／あそびの 型: つくる・かざる）。対象は 5才〜。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/kofun-zukuri/

## あそびかた（1回 1〜3分）

1. **かたちを えらぶ** … まる（円墳）・しかく（方墳）・かぎあな（前方後円墳）
2. **つちを はこぶ** … 「ひとを ふやす」（または えを タップ）で はたらく ひとが ふえ、やまが はやく 高くなる。
   「はやおくり」で きせつが ぐるぐる かわり、ひげが のびる。
   おうさまの ちゅうもんは 3だんかいで どんどん 大きくなり、さいごは がめんから はみだす。
3. **はにわを ならべる** … 10しゅるい（つつ・よろいの ひと・みこさん・おどる ひと・うま・いえ・ふね・にわとり・いぬ・しか）を 8かしょに。
   はにわを タッチすると とれる（やりなおし）。となりどうしで ポーズが かわる（7しゅるい、みつけた かずを ほぞん）。
   - めを はなす（2.6びょう さわらない／「めを かくす」）と はにわが おどり、見ると「ぴたっ！」と 止まる。
4. **うえから みる** … ぐーんと 上がって、はじめて かたちが 分かる。かみふぶきと ファンファーレ。
5. **おおきさ くらべ** … だいせん こふん 486m／しんかんせん 16りょう 約400m／でんしゃ 10りょう 約200m／プール 25m。
6. **まなび カード** 3まい（ぜんぽうこうえんふん・はにわ・おおきみ）と、つぎの じだい（あすか）の よこく。

画面の 下に じだいの ものさし（じょうもん → … → えど）を 出し、「こふん」を 光らせています。

## しらべた こと（保護者むけ表示の もと）

- 大仙古墳（仁徳天皇陵古墳・大阪府堺市）: 墳丘の長さ 約486m、5世紀ごろ。1日最大2000人が働いても15年以上という試算（堺市の資料）。
  測量方法によっては500mを超えるという調査もある。宮内庁は仁徳天皇陵として管理しているが、被葬者は学問的には確定していない。
- 「前方後円墳」の名は江戸時代の蒲生君平による。できた当時の墳丘は葺石で覆われていた（ゲームの 完成した こふんも 石の色）。
- 埴輪は円筒埴輪が最も多く、家・器財・動物・人物は後から現れたと考えられている。並べた理由は諸説。
- すいていの 内容は 画面でも「〜と かんがえられている」と 書いています。

## つくり
