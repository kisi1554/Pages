# あかずきん ― ゆびで みちを たどって、おおかみを みやぶる えほん 🧺

グリム童話「あかずきん」を、**こどもが ゆびで もりの みちを たどり、「おばあさん、どうして そんなに おおきな みみ？」と
さわって たしかめ、おおかみの へんそうを みやぶる** しかけ えほんに しました。「さわる えほん」シリーズの 4さつめ
（[`ookina-kabu/`](../ookina-kabu/)・[`kitakaze-taiyo/`](../kitakaze-taiyo/)・[`jack-mamenoki/`](../jack-mamenoki/) と
画面の かたち・よみあげ・ことばの きりかえ・しおりは おなじ 型）。
対象は 未就学〜小学1年。ひょうし＋10ページ＋おしまい の 全12画面。

テーマは「より道を しない」「しらない ひとに いきさきを おしえない」「へんだな？と おもったら よく みる」。

**グリム童話を もとに した オリジナルの 文・絵** です。日本で 出版されて いる 絵本・教科書の 訳文や 絵は つかって いません
（日本語・英語の 文も 絵も この アプリの ために かいたもの）。

`index.html` を ブラウザで ひらくだけで あそべます（ビルドも サーバーも 不要。外部ライブラリなし）。
絵は SVG、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。
文は ひらがな中心で、ことばの あいだを スペースで くぎっています（漢字には ふりがな）。

## こわさ の ちょうせい

- **だれも たべられません。** おばあさんは おおかみが くる まえに、こどもの ゆびで クローゼットへ かくれます。
- おおかみは きこりの おじさんの「こらーっ！」に びっくりして にげ、さいごは とおくから「もう しませーん！」。
- ち・はさみで おなかを きる 場面は ありません。おおかみは ちょっと まぬけな かお（まるい め・でっぱ 1ぽん・きば なし）。
- 「おおきな くち」の こたえは「それは おまえを…… おっと！」（英語 “All the better to… (oops!)”）で きって、たべるとは いわせません。

| 8 | 「…おっと！」 | **みやぶる**: ふとんを したへ スワイプで めくる → しっぽが でて「おおかみだ！」。あかずきんは まどへ |

| 10 | おちゃかい | クローゼットを タップで あける → ケーキを 3にんの おさらへ ドラッグで くばる →「いただきます！」 |
| おしまい | やくそく | 「みちから はずれない」「しらない ひとに いきさきを おしえない」を タップで ✅。3ページの こたえ（どちらでも ほめる）と つんだ おはなの かずを ふりかえる。**「もういちど もりへ」で 2・4・7・8・9 ページを じゆうに あそべる** |

## しくみ（`mori.js`）

- **みちを たどる（path）**: みちは SVG の 折れ線（`art.js` の `POS.path`）。ゆびに いちばん ちかい みちの 位置（0〜1）を もとめ、
  **みちから ゆるし はば（絵の はば 0.06）いない** で、いまの 位置より まえ（＋0.08 まで）の ときだけ すすみます。
  とびこし・ぎゃくもどりは しません（`Mori.model.pathStep(st, point)` → `{ progress, off }`）。
- **より道（flowers）**: つむ たびに `sun += 1/12`。12で「もう いかなきゃ」と じどうで つぎへ。
- **ひろげて たしかめる（zoom）**: タップ 1かい、または ゆび 2ほんの きょりが 1.4ばいで「おおきく なった」。
  **画面は ズームしません**（SVG の なかの みみ・め・て・くち の `<g>` だけ `transform: scale()` で 大きく する）。
- **おおごえ（shout）**: タップ 1かい ＝ ＋0.1、ゆび 2ほん どうじなら ＋0.2。じかんで すこし へります（1びょう 0.04）。
- **ドラッグで くばる（drop）**: かご・クローゼット・おさら の あたりは 大きめ（絵の はば 0.12）。
- パソコンでは ← → ↑ ↓ で みちを すすむ／えらぶ、Enter で タップ、スペースで おおごえ。
- 絵には `touch-action: none` を つけ、なんぼんの ゆびで さわっても 画面が うごいたり 拡大したり しません。

## そのほか（シリーズ きょうつう）

- **よみあげ**: speechSynthesis（ja-JP / en-US）で 1ぎょうずつ。よんで いる 行を 黄色く ひからせます。
  おおかみの せりふは こえを ひくく（pitch 0.7）。🔁 で もういちど。しかけを さわると とまります。
- **🇬🇧 English ⇄ 🇯🇵 にほんご**: ほんの したと ひょうしの ボタンで きりかえ。文・ヒント・ふきだし・メーター・ボタンは ぜんぶ `{ ja, en }`。
  英語では Little Red Riding Hood・the wolf・Grandma・the woodcutter。
- 🎵 おと（BGM・効果音）と 🗣 よみあげ は べつべつに オン/オフ。
- しかけが おわるまで「🔒 つぎ」。いちど おわった ページは つぎから すぐ すすめます。
- **しおり**（🔖 つづき から）。しおり・せってい・こたえ・つんだ おはなの かず・やくそくの ✅ は その端末の `localStorage` にだけ 保存します。
- たてもちは 絵の したに 文、スマホ よこもちは 絵と 文を よこに。絵は いつも 8:5。

## 音

ぜんぶ Web Audio の 合成音: ことりの さえずり、あしおと（みちの うえ）、くさを ふむ がさがさ（みちの そと）、おはなを つむ ぽんっ、
ノック トントン、へんな こえ（ひくい ブザー）、みみが のびる びよーん、ふとん ばさっ、おおごえ「こらーっ」（のこぎり波＋ビブラート、
ことばは よみあげで）、おおかみが にげる ぴゅーん、ケーキ ことん、おしまいの ファンファーレ。
BGM は オリジナルの「もりの おさんぽ」（6/8、かるい スキップ）。

## たしかめかた

```bash
node tools/akazukin/test.js
node tools/akazukin/check.js /tmp/shots
```

`test.js` は story.js の 全ページ・全 行・ヒント・ふきだしに ja と en が そろって いること（ja の 漢字に ふりがな、en に かな なし）、
しかけの しゅるいが ぜんぶ あること、みちから はずれると すすまない／みちに そうと 1 まで いく／とびこし できない こと、
おおごえは ゆび 2ほんで 2ばい、より道は 上限で とまる こと、こわい ことばが でて こない ことを たしかめます。
`check.js` は Playwright で たて（390×844）・よこ（1024×768）・スマホよこ（844×390）を 日本語と 英語で ひらき、
全ページの しかけを こなして おしまいまで すすむこと、みちの そとを なぞっても すすまないこと、
ピンチアウト（CDP の 2ほん タッチ）で みみが 大きく なるが 画面は ズームしない（`visualViewport.scale` が 1 の まま）こと、
「もういちど もりへ」、JS エラーが ないことを たしかめ、スクショを 保存します。
