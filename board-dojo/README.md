# かんがえる ボードゲーム ♟️

**むかし から ある ばん の ゲーム を、かぞく と、または CPU と たいせん する アプリ。**
年長〜大人むけ。ヒント と ふりかえり で「なぜ その て が よい か」が わかる。
`index.html` を ひらくだけで あそべます（外部ライブラリ・CDN なし。ばん と コマ は SVG で コード描画）。

公開URL: https://kisi1554.github.io/Pages/board-dojo/

## ゲーム（5つ）

| ゲーム | ばん | ルール |
| --- | --- | --- |
| ⚫ リバーシ | 8×8 / 6×6 | はさんで ひっくりかえす。おけない とき は じどう で パス、ふたり とも おけない（または うまる）と おしまい |
| ⚪ ごもくならべ | 15×15 / 9×9 | 5つ いじょう ならべたら かち（かんたん ルール）。せってい で **三三 禁止**（どちら の ひと にも。5つ に なる て は OK、おけない ところ に ✕） |
| ⭕ まるばつ | 3×3 | 3つ ならべたら かち。🐉 つよい CPU は かんぜん よみ で ぜったい まけない |
| 🔴 おとして 4つならべ | 7れつ×6だん | れつ を えらぶ と いちばん した まで おちる。4つ で かち、まんぱい で ひきわけ |
| 🟦 はこ とり | 2×2 / 3×3 / 4×4 | てん と てん を せん で つなぐ。4へんめ を ひいた ひと が はこ を とって もう いちど |

※ 商標 の ある ゲーム名 は つかって いません。

## あそびかた

- **あいて**: 🤖 ひとり（CPU）／ 👨‍👩‍👧 ふたり（おなじ たんまつ で こうたい。「テーブル で むかいあう」に すると うえ がわ の ボタン と メッセージ が さかさま に でる）／ 👀 CPU どうし を みる
- **CPU の つよさ**: 🐣 はじめて（ほぼ ランダム。かてる て も わざと みのがす）、🐥 やさしい（2て よみ ＋ ときどき 2〜3ばんめ の て）、🦊 ふつう（αβ たんさく 〜4て）、🐉 つよい（はんぷく しんか αβ ＋ ひょうか かんすう、0.8びょう。まるばつ は かんぜん よみ）
- CPU の ばん は「🤔 うーん…」と すこし まつ（さいだい 1びょう）。けいさん は **Web Worker**（つかえない とき は じかん を みじかく して メイン で）
- **💡 ヒント**: いちばん よい て を ひからせ、りゆう を いう（「ここ に おくと 3まい かえせる」「ここ を ふさがない と 5つ ならぶ よ」「どこ に ひいても あげちゃう… ここ なら いちばん すくない」など）
- **↩️ まった**: 1て もどす（CPU せん では じぶん の ばん まで もどる）。せってい で OFF に できる
- **🔍 ふりかえり**: たいきょく の あと、ぜんぶ の きょくめん を CPU が ひょうか し、ひょうかち が おおきく さがった て を 1〜2か しょ「ここ が わかれめ だった ね、みどり なら よかった かも」と おしえる（あか＝うった て、みどり＝よかった て）。⏮ ◀ ▶ ⏭ と スライダー・さいせい で 1て ずつ
- **ごもく 15×15 を スマホ で**: ます が ちいさい とき は「🔍 おおきく」で 2ばい ズーム（ゆび で ずらせる）。ちいさい ます は 2かい タップ で おく（1かいめ は うすい いし で かくにん）
- **せんせき と おび**: ゲーム ごと・あいて ごと に かち／まけ／ひきわけ。🐣→しろおび、🐥→きいろおび、🦊→みどりおび、🐉→**くろおび**（まるばつ は ひきわけ で くろおび）。5つ ぜんぶ くろおび で 🏆 めいじん
- とちゅう の きょくめん は じどう で ほぞん（ホーム の「つづき から」）
- おと（WebAudio の ごうせい おん）: おく パチッ、ひっくりかえす くるっ、おちる コトン、せん シュッ、かち の ファンファーレ。🔊 で オン/オフ

## テスト

```bash
node --test board-dojo/tests/*.test.js
```

- ルール: リバーシ の パス と りょうしゃ パス で しゅうきょく、ごもく の たて よこ ななめ・6つ・三三、4つならべ の まんぱい ひきわけ、はこ とり の れんぞく てばん・2こ どうじ
- まるばつ の つよい CPU が どんな あいて にも まけない こと を **そうあたり**（CPU が えらぶ かもしれない て ぜんぶ）
- **ランダム たいきょく 1まん きょく**（5ゲーム × つよさ 4だんかい × ランダム あいて）で CPU が はんそく しない
- つよい CPU が 1て 1びょう いない、ヒント・ふりかえり が ただしい て を さす

```bash
NODE_PATH=$(npm root -g) node board-dojo/tests/e2e.js
```

Playwright で スマホ たて（390×844）・タブレット よこ（1024×768）を ひらき、5つ の ゲーム を CPU どうし で さいご まで、
タップ・ヒント・まった・ズーム・むかいあう・ふりかえり・せんせき の ほぞん を ためして スクショ を とる。
