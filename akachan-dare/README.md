# あかちゃん だあれ？ 🐣

いきものの あかちゃんの えを みて「おとなに なったら だれ？」を あて、
そだつ じゅんばんに カードを ならべる アプリ。ならべると 成長アニメが ながれます。
親と 形が ちがう あかちゃん（変態）や、さなぎに なる虫・ならない虫を しる。

`index.html` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。え は SVG、おとは WebAudio）。

公開URL: https://kisi1554.github.io/Pages/akachan-dare/

## あそびかた（1かい 1〜3ぷん）

| モード | なかみ |
| --- | --- |
| 🐣 だれの あかちゃん？ | 3しゅるい × ①あかちゃん → おとなを 3つから えらぶ ②そだつ カードを ならべる ③成長アニメ＋ひとこと解説 |
| 🥚 なかまわけ | 8もん。「たまごで うまれる／あかちゃんで うまれる」5もん＋「さなぎに なる／ならない」3もん |
| 📖 ずかん | 1かいでも そだちを みた いきものが のる（12しゅるい）。タップで アニメを もういちど |

- まちがえると カードが ゆれて「もういちど」。なんどでも やりなおせる。ならべは あっている カードは みどりで のこる。
- さいごに はなまる＋ほし（ミス0で ⭐3、2かいまで ⭐2）。
- 🔊 オン/オフ は 右上。せってい・ずかんは localStorage（`akachan-dare:v1`）。

## いきもの（12しゅるい）

| いきもの | そだつ じゅんばん | うまれかた | さなぎ |

| カエル | たまご → おたまじゃくし → あしが はえる → カエル | たまご | — |
| チョウ（モンシロチョウ） | たまご → あおむし → さなぎ → チョウ | たまご | なる |
| トンボ | たまご → ヤゴ → からを ぬぐ（うか） → トンボ | たまご | ならない |
| セミ | たまご → ようちゅう → からを ぬぐ（うか） → セミ | たまご | ならない |
| カブトムシ | たまご → ようちゅう → さなぎ → カブトムシ | たまご | なる |
| テントウムシ（ナナホシ） | たまご → ようちゅう → さなぎ → テントウムシ | たまご | なる |
| ニワトリ | たまご → ひよこ → ニワトリ | たまご | — |
| ペンギン（コウテイ） | たまご → ひな → ペンギン | たまご | — |
| サケ | たまご → あかちゃん（さいのう つき） → こども → サケ | たまご | — |
| ウミガメ | たまご → こガメ → ウミガメ | たまご | — |

なかまわけ だけの なかま: イヌ・ネコ・イルカ・ウシ（あかちゃん）、ワニ（たまご）、
ミツバチ・アリ（さなぎに なる）、コオロギ（ならない）。

## じじつ メモ（図鑑で ふつうに のっている ことだけ）

- 完全変態（さなぎに なる）: チョウ・カブトムシ・テントウムシ・ハチ・アリ。
  不完全変態（ならない）: トンボ・セミ・コオロギ。
- カエルは うしろあし → まえあし の じゅんに はえ、しっぽは きゅうしゅうされる。
- ニワトリの たまごは あたためて やく21にちで かえる。ひよこは すぐ あるける。
- コウテイペンギンは オスが あしの うえで たまごを あたためる。ひなは はいいろの 綿羽。
- サケは かわで うまれ、仔魚は さいのうの えいようで そだつ。うみで そだち、うまれた かわに もどって さんらん。
- ウミガメは よる すなはまに あなを ほって さんらん。
- カンガルー（アカカンガルー）の しんせいじは やく2cm。じぶんで ふくろに はいって そだつ。
- イルカは ほにゅうるい（たいせい）。ヘビ・トカゲは たいせいの しゅるいも いるので つかって いない。
