# ことばの せんたくき 🫧

**ことばを せんたくきに いれて 1もじだけ かえると、べつの ことばに へんしん！**
「いぬ」→「いま」→「くま」のように 1もじずつ かえて、ゴールの ことばまで たどりつく
ことばパズル（ワードラダーの ひらがな版）。年長〜小学3年むけ。外部ライブラリ・CDN なし。

公開URL: https://kisi1554.github.io/Pages/kotoba-sentakki/

## あそびかた

1. うえに「スタート」と「ゴール」の ことば（えもじつき）。
2. せんたくきの まどの なかの、かえたい もじを タップ → 50おんの まるい ボタン（行ごとに いろ）から えらぶ。
   - タブは「あ〜の」「は〜ん」「が・ぱ・ゃ」（だくおん・はんだくおん・ちいさい ゃゅょっ）。
3. 「🌀 まわす」を おすか、**まどを ぐるっと なぞる**と せんたく（ごうんごうん・あわ ぽこぽこ）。
4. じしょに ある ことばなら えもじが ぽんっと でて「へんしん！」。
   ない ことばなら あわが はじけて「ぷしゅー」と もとに もどる（しっぱい カウントは しない）。
   いちど とおった ことばにも もどれない（↩️「ひとつ もどる」で もどる）。
5. ゴールに つくと、とおった ことばが **ものほしざおに せんたくもの** みたいに ならぶ。さいたん てすうなら 🌟。

## モード

| モード | ないよう |
| --- | --- |
| 🧺 もんだい | 2もじ 20もん・3もじ 20もん・4もじ 10もん（さいたん 2〜5て）。✔️ と 🌟 を きろく |
| 🌀 じゆう せんたく | すきな ことば（えもじつきから 8こ。🔀で いれかえ）から はじめて、いくつ へんしん できるか。「✅ おわる」で ふりかえり |
| 📗 ずかん | つくった ことば・とおった ことばが あつまる（となりの ことばが ある ことばだけ かぞえる） |
| 💡 ヒント | 1かいめ: かえる もじの ばしょが ひかる → 2かいめ: こたえの もじが 50おんで ひかる（じゆう では まだ ずかんに ない ことばを ゆうせん） |

## じしょ と もんだい

- もと データは [`tools/kotoba-sentakki/words.txt`](../tools/kotoba-sentakki/words.txt)（「ことば えもじ」）。
  2もじ 274・3もじ 239・4もじ 180 = 693ご。ぜんぶ ひらがな、えもじが ない ことばは もじだけ。
  だくおん・はんだくおん・ちいさい「ゃゅょっ」も 1もじ。「ー」は つかわない。
- `python3 tools/kotoba-sentakki/build.py` で `words.js`（`WORDS`・`PUZZLES`）を つくりなおす。
  1もじ ちがいの グラフを つくり、BFS で さいたん てすうを けいさんして もんだいを えらぶ
  （スタート・ゴールは えもじつきを ゆうせん。さいしょの もんだいは「いぬ → くま」）。
- `words.js` は てで なおさない。
