# えきスタンプラリー

鉄道会社のスタンプラリーのように、路線を端の駅から順にすすみながら、
駅名の漢字の読みをおぼえていく、5歳児むけの学習アプリです。
1駅よめるたびに、手押しスタンプ風の絵柄がスタンプ帳にたまっていきます。

## あそびかた

`index.html` をブラウザで開くだけであそべます(ビルドやサーバーは不要です)。

1. 「はじめる」→ のりたい路線をえらびます。
2. 駅名標に漢字が大きく出るので、よみを4つの中からえらびます。
   - 選択肢の 🔊 をおすと、その読みを声で読んでくれます(まだひらがなが読めなくても大丈夫)。
   - まちがえても、そのボタンが消えるだけで何度でも挑戦できます。1回まちがえると最初の1文字がヒントに出ます。
   - 「ヒント 💡」で選択肢を1つ消す、「とばす ⏭」でその駅を後回しにできます。
3. 正解すると **スタンプがドンと押されて**、駅名を声で読み上げます。
4. 「つぎのえきへ 🚃」で となりの駅へ。**発車メロディが鳴って電車が走りだし**、つぎの駅に着きます
   (いそぐときは画面をタップすると すぐ着きます)。終点までいくと 完走きねんスタンプ がもらえます。
5. **5駅すすむごとに「さんすうえき 🧮」**に止まり、たし算の確認問題が出ます(下記)。
6. 「スタンプちょう 📔」で、集めたスタンプを路線ごとに見られます。スタンプをタップすると読み上げます。

## ろせんず 🗺️

タイトル画面の「ろせんず」から、駅にはってあるような路線図が見られます。

- 駅名は**たて書き**、路線は色つきの帯、駅は丸で、実物の路線図とおなじ見た目です。横にスクロールします。
- **スタンプを取った駅は丸が色でうまり**、まだの駅は白丸のままです。いま進んでいる駅はオレンジで光ります。
- 乗り換えできる駅は**大きい丸**になり、その下に乗り換え路線の色が点で並びます。
- **駅をタップすると読み方を読み上げて**、「◯◯から あそぶ?」と聞いてきます。えらぶとその駅からラリーを始められます。
- 下の「この ろせんで あそぶ」で、いつもの続きから遊べます。

**収録している49路線すべて**の路線図が見られます。会社ごとに分かれたメニューからえらんでください。
路線図の中身は駅データから自動で作られるので、路線を足せば路線図も自動で増えます。
駅名が長い駅(南町田グランベリーパークなど)は、文字の大きさが自動で縮んでおさまります。

## のりかえ案内

駅名標の下に、その駅で乗り換えられる路線が本物の案内板のように出ます。

- **色つきのチップ**はこのアプリに入っている路線です。**タップするとその路線に乗り換えて**、
  同じ駅からラリーを続けられます(「◯◯線に のりかえる?」と確認が出ます)。
  もとの路線の進み具合はそのまま残るので、あとで戻ってこられます。
- **灰色の点線チップ**はこのアプリに入っていない路線(JR他線・新幹線・私鉄・都営地下鉄など)で、
  見るだけの案内です。
- 乗り換えのない駅は「この えきは のりかえ なし」と出ます。

色つきチップは駅データから自動で作っているので、収録路線ぶんは全704駅で漏れがありません
(路線を足せば自動で増えます)。灰色チップは主要駅のみ手で用意したもので、すべての駅・
すべての他社線を網羅してはいません。

## さんすうえき 🧮(たし算)

5駅すすむごとに、電車にちなんだたし算の文章題が出ます。

> 上野から 4えき すすんで、そこから もう 2えき すすんだよ。ぜんぶで なんえき すすんだ?

- 問題は 進んだ駅数 / スタンプの数 / 車両の数 / きっぷの枚数 / 乗った人数 の5種類。
  数字だけでなく 🚃🚃🚃 ＋ 🚃🚃 と**絵が並ぶ**ので、読めなくても数えて答えられます。
- 「かぞえる 👆」をおすと、絵がひとつずつ光りながら「いち、に、さん…」と数えてくれます。
  まちがえたときも「かぞえて みよう!」と出ます。
- 答えは大きな数字の4択。まちがえてもそのボタンが消えるだけで、何度でも挑戦できます。
- 正解数がふえると、たす数がすこしずつ大きくなります(答え10まで → 15まで → 20まで)。
- 右下の 🧮 ボタンで、さんすうえきに止まらないように切りかえられます。
- 正解した数はタイトル画面に出ます。

すすみ具合と集めたスタンプは、そのブラウザに自動で保存されます(`localStorage`)。

## 音について

画面右下のボタンで切りかえられます。

| ボタン | はたらき |
| --- | --- |
| 🎵 | BGMの入/切 🔒 |
| ⏭ | BGMを次の曲へ 🔒 |
| 🧮 | さんすうえきの入/切 🔒 |
| 🗣️ | 読み上げの入/切 |
| 🔔 | 効果音の入/切 |

🔒 のついたものは**おうちのかた確認**が入ります。「57 ＋ 64 ＝ ?」のような
**2けたどうしのたし算**が出て、正解しないと切りかえられません。子どもが勝手に
さんすうえきを止めたりBGMをいじったりできないようにするためです。
まちがえると新しい問題が出ます。読み上げと効果音は確認なしで切りかえられます。

BGMは音源ファイルを持たず、Web Audio API でその場で鳴らしています。
テンポの速い**24曲**(ラッシュアワー / とっきゅうダッシュ / てつどうロック / ちかてつテクノ /
まつりばやし / しんかんせん / よこはまナイト / かいそくとくきゅう / あさのラッシュ / ちかてつダンス /
てっきょうロック / こうそくつうか / ゆきのとっきゅう / よこはまベイ / やまのてループ / ふみきりビート /
サンダーバード / ホームのかぜ / ナイトエクスプレス / てつどうマーチ / うみぞいライン / やまごえロック /
カーブでキーッ / ゴールインダッシュ)をシャッフルし、8小節ごとに切りかわるので、同じ曲が続きません。

### 発車メロディ

つぎの駅へ進むとき、**路線ごとにきまった発車メロディ**が鳴って、電車が画面を走りぬけます。
メロディは16種類あり、路線idから決まるので**同じ路線ならいつも同じ曲**です(山手線と銀座線では別の曲)。
ベルとマリンバを重ねた音をその場で合成していて、走行中は「ガタン ゴトン」とレールのつなぎ目の音が鳴ります。
すべてこのアプリのオリジナルです。効果音(🔔)を切ると鳴りません。

読み上げはブラウザの音声合成(`SpeechSynthesis`)を使います。日本語の音声が入っていない環境では
読み上げだけが鳴りませんが、そのほかの機能はそのまま使えます。

音声に渡す文は、駅名も路線名も**かなに置きかえてから**読ませています(画面には漢字のまま出ます)。
漢字のまま渡すと音声合成が読み違えることがあるためです。

## ファイル構成

- `index.html` - 画面構造
- `style.css` - デザイン(駅名標・スタンプ・スタンプ帳)
- `data.js` - 路線と駅のデータ、スタンプの絵柄、のりかえ表
- `audio.js` - BGM生成・効果音・読み上げ
- `game.js` - 出題と進行、セーブ

## 出題のしくみ(おうちのかたへ)

4つの選択肢は、毎回その場で作っています。

- 1つは、正解とよく似た読み(同じ文字が多い・最初の文字が同じ)の実在の駅
- のこり2つは、**正解と文字数がちかい**実在の駅

こうすることで「長いのが答え」のような、読まずに当てられる手がかりを減らしています。
選択肢はすべて実在の駅名なので、まちがえて覚えることがありません。
