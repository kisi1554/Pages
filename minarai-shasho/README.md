# みならい しゃしょう ポポ

**じぶんより ちょっとだけ できない ロボット「ポポ」に おしえる** ことで おぼえる、
ブラウザだけで あそべる 子ども向け 学習アプリ。

いまの きょうざいは **でんしゃ・ろせん**（47もん）だけれど、
きょうざいと ゲームの しくみが 分かれているので、`data.js` を 差し替えると
ひらがなでも けいさんでも きょうりゅうでも おなじ ゲームで あそべる。

👉 `index.html` を ブラウザで ひらくだけ。ビルドも サーバーも いらない。

---

## 1. なにが 「あたらしい」か

よくある 学習アプリは「毎日やらないと連続日数が切れる」で 子どもを ひっぱる。
これは 1日 とぎれた しゅんかんに やめる 理由に なるし、
親が かわりに 解く「ズル」も おきやすい。

このアプリは **ストリークを 一切 表示しない**。かわりに、
**もどってくる理由が むこうから やってくる** しくみを 3つ かさねている。

| しくみ | なにが おきるか | ねらい |
|---|---|---|
| **① でし（ポポ）** | おしえた ぶんだけ ポポが かしこくなる。ポポは るすの あいだに ひとりで うんこうに 出かけ、**おみやげ**と**「ここが わからなかった」という しつもん**を もって かえる | 学習の どうきを 「かしこくなりたい」ではなく **「ポポが まっている」** に おきかえる。人に教えると 自分が いちばん おぼえる（プロテジェ効果）も ねらう |
| **② モヤモヤずかん** | まちがえた もんだいが「モヤモヤ」という 生きものに なって ずかんに すむ。たおす方法は **後日 その もんだいに 正解すること だけ** | 間隔反復（SRS）の 復習キューを **「しゅうらい カレンダー」** として 見せる。ふくしゅう＝義務 だが たいじ＝イベント。おなじ データで 気もちが 反転する |
| **③ きょうの いちばん でんしゃ** | 日づけから きまる 5もん。だれが やっても その日は おなじ もんだい | 習慣は 意志ではなく **時間の やくそく** で できる。毎日 きまった タイミングの 小さな 山場 |

### わざと 入れていない もの

- **れんぞく日数（ストリーク）** … とぎれた しゅんかんに やめる 理由に なるので おかない
- **ペナルティ** … 何日 あそばなくても ポポは 元気。まっている ぶん おみやげが たまるだけ
- **減る 数字** … 出す数字は「おしえた かず」「なかよしの かず」「スタンプの かず」など **へらないもの だけ**
- **パーセント表示** … 5さいには つたわらないので「これから／すこし／いいかんじ／ばっちり」の ことばで 出す

## 2. あそびかた（がめん）

```
ホーム ─┬─ ポポに おしえる ──→ 6もん ──→ まとめ ──→ ポポを おくりだす
        │                                        （うんこう ちゅう）
        ├─ きょうの いちばん でんしゃ（5もん・日がわり）      ↓
        ├─ モヤモヤずかん ──→ でてきた モヤモヤを たおす   じかんが たつと
        ├─ ポポを おくりだす ─────────────────────→ かえってくる
        └─ おみやげスタンプ                              ↓
                                              ほうこく（すすんだ えき数・
                                              スタンプ・ポポの しつもん）
                                                        ↓
                                                「いま おしえる」に もどる
```

うんこうは **げんじつ時間**で すすむ（3ふん／15ふん／1じかん）。
アプリを とじても よくて、つぎに ひらいた ときに かえってきている。
**「あそんでいない あいだに 世界が すすむ」** ことで、ひらく りゆうが 生まれる。

### とく／まるつけ の 2モード

おなじ もんだいから、エンジンが 2しゅるいの 出しかたを つくる。

- **とく（solve）** … ふつうの 3たく
- **まるつけ（judge）** … ポポが「◯◯だと おもう！」と こたえ、子どもが ○/× を つける

judge は **一度 おぼえた もんだい（ボックス1いじょう）だけ**、1セッション 2もんまで。
教材には 3たく問題を 1しゅるい 書くだけで よく、教える側の れんしゅうは エンジンが つくる。

## 3. きょうざいの 差し替えかた

`data.js` の `PACK` を まるごと 書きかえるだけ。エンジンと がめんは この形しか 知らない。

```js
const PACK = {
  id: 'densha',              // セーブデータの なまえに つかう
  name: 'でんしゃ・ろせん',
  words: { step: 'えき', run: 'うんこう', skill: 'しゃしょうスキル' },  // がめんの ことばづかい

  routes: [{                 // ポポを おくりだす コース
    id: 'yamanote',
    name: 'やまのてせん おてつだい',
    emoji: '🟢', color: '#59a94a',
    tags: ['となり', 'いろ'], // このコースで つかう ちしき（= 成績の もとに なる tag）
    length: 6,               // すすむ ステップ数
    minutes: 3,              // げんじつ時間で かかる 時間
    minLevel: 0,             // ポポの レベル制限
    desc: '…',
    stamps: ['とうきょう', 'うえの', …],   // かえるたびに 1こ もらえる
  }],

  items: [{
    id: 'c-yamanote',        // ユニーク。セーブデータの キーなので あとから 変えない
    tags: ['いろ'],           // ポポの スキルと コースに つかう
    q: 'やまのてせんの いろは なにいろ？',
    choices: ['みどり', 'あか', 'きいろ'],  // 3つ。出すときに シャッフルされる
    a: 0,                    // choices の中の せいかいの ばんごう
    hint: 'うぐいすと おなじ いろだよ',      // まちがえた ときに 出る
    fact: 'やまのてせんは うぐいすいろ…',    // せいかいの あとの まめちしき（なくてもよい）
  }],
};
```

あわせて `art.js` の `TAG_COLOR` に tag の いろを 足すと、モヤモヤの いろが 分かれる。
（書かなくても はいいろで うごく）

**つまり 新しい きょうざいを つくる = 3たく問題を ならべる だけ。**

## 4. しくみ（設計メモ）

### 4.1 ふくしゅうの 間隔（`engine.js`）

ライトナー方式の ボックス。せいかいで 1つ 上がり、まちがえると 0 に もどる。

| ボックス | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| つぎに 出るまで | 10ぷん | 1にち | 2にち | 4にち | 7にち | 14にち | 30にち |

- ボックス0 が **10ぷん** なのは、おなじ日の うちに もう一度 出して すぐ 定着させるため
- **ボックス3（4にち間隔）に とどくと 「なかよし」** に なって コレクションに 入る
- なかよしに なった モヤモヤは **二度と へらない**。あとで まちがえても コレクションからは 消えない
  （へる数字を つくらない、という 方針）

### 4.2 出題の ゆうせん順（`Engine.pickSession`）

```
ポポの もちかえり → でてきた モヤモヤ → きげんの きた ふくしゅう → あたらしい もんだい
```

ただし **あたらしい もんだいを かならず 1もんは 混ぜる**（`n - 1` で 止めている）。
ふくしゅうだけの セッションは つまらなく、続かないため。

### 4.3 ポポの できぐあい（`Engine.mastery` / `confidence` / `runResult`）

```
mastery    = Σ min(ボックス, 4) / 4  ÷  そのtagの もんだい数     … 0〜1
confidence = mastery ^ 0.6                                      … 序盤の のびを 見えやすく
reach      = round(コースの長さ × (0.4 + 0.6 × confidence))      … 最低でも 4わりは すすむ
```

- しっぱいしても **かならず 前に すすむ**（子ども向けなので 全滅を つくらない）
- すすめなかった ぶんは **「わからなかった もんだい」**として 1〜2もん もちかえる
  → それが つぎの セッションの 先頭に 出る＝**うんこうと 学習が 円で つながる**
- ポポの レベル ＝ `1 + floor(せいかい数 / 5)`。レベルで 遠い コースが ひらく

### 4.4 セーブデータ

`localStorage` の `minarai-shasho-v1` ひとつだけ。サーバーには 何も 送らない。

```js
{
  srs:   { もんだいid: { b: ボックス, due: つぎに出る時刻, ok, ng, moya, tamed } },
  popo:  { exp, taught },
  run:   { routeId, startAt, endAt } | null,   // うんこうちゅう
  report:{ … } | null,                          // まだ 見ていない かえりの ほうこく
  bring: [もんだいid],                           // ポポが もちかえった しつもん
  stamps:{ routeId: { n, golds } },
  daily: { date, best, done, score }, bestDaily,
  settings: { voice, se }
}
```

こわれた JSON が 入っていても 例外を にぎりつぶして 最初から はじまる（あそべなく なるより よい）。

## 5. ファイル

| ファイル | やくわり |
|---|---|
| `index.html` | がわ（スクリプトの よみこみ順が だいじ: data → engine → art → audio → app） |
| `data.js` | **きょうざいパック**。ここだけ 差し替えれば べつジャンルに なる |
| `engine.js` | SRS・出題えらび・しゅうじゅく度。**きょうざいに 依存しない** |
| `art.js` | ポポ／モヤモヤ／スタンプの SVG。モヤモヤの かたちは もんだいidから 決まるので いつも おなじ すがた |
| `audio.js` | こうかおん（Web Audio でその場生成）と よみあげ（音声合成） |
| `app.js` | がめんと セーブデータ |
| `style.css` | 5さいでも おせる 大きさ・丸ゴシック |

がぞうファイルも 音源ファイルも 外部ライブラリも **ゼロ**。

## 6. うごかしかた

```
minarai-shasho/index.html を ブラウザで ひらく
```

GitHub Pages に おく ばあいは フォルダごと おいて `…/minarai-shasho/` を ひらく。

**おうちの方へ**
- 音が出ます（読み上げ・効果音）。右上の 🔊 から どちらも 切れます
- 読み上げは ブラウザの 音声合成。iOS/Android の ブラウザでは 日本語の 声が 入っていないと 鳴りません
- 成績は 端末の ブラウザ内 だけに 保存されます。同じ画面の いちばん下から リセットできます

## 7. これから 足すなら

- **出題者に なる モード** … 子どもが 問題を つくり、ポポ（や 家族）が 解く。
  「自分の つくった ものが 外で 動いている」は いちばん つよい 継続の 引力。
  ただし 子ども向け UGC は モデレーションが 必要なので、
  自由入力を させず **テンプレート＋既存の 素材の 組みあわせ** に 限るのが 安全
- **兄弟・親子の 非対称プレイ** … 親の 端末に 出題側の 画面を 出す
- **毎晩 きまった 時刻の 一斉イベント** … いまは 日がわり問題で 代用（サーバーなしで 同じ体験に なるよう 日づけを たねに している）
