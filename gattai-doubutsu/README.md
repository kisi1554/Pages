# がったい どうぶつ ラボ 🦁

あたま・からだ・あし・しっぽ（はね）を べつべつの どうぶつから えらんで **オリジナルの へんてこ どうぶつ** を つくり、
**のはら・うみ・そら・やま・さばく・こおりの くに・よるの もり** の コースを はしらせる（年中〜小学3年）。
チーターの あしは はやい、アヒルの あしは およげる、ペンギンの からだは さむさに つよい…
どこが どう やくに たつかが レースで わかる（どうぶつの からだの しくみ ＝ てきおう を まなぶ）。

`index.html` を ひらく だけで うごく（外部ライブラリ・CDN なし。え は ぜんぶ SVG を コードで かいて、おと は WebAudio の 合成音。ヘッダーで オン/オフ）。

## あそびかた

1. **ラボ**: 4つの ぶいを スロットマシン ふうに えらぶ（◀ ▶ / スワイプ / 🎰 ぐるぐる で ぜんぶ ランダム）。
   くっつくと なまえが じどうで できる（チー＋ペン＋アヒ＋ワシ →「チーペンアヒワシ」。ぜんぶ おなじ どうぶつなら ほんものの なまえ）。
   のうりょくは 5つの ほし（はしる・およぐ・とぶ・のぼる・たえる）と、とくせい（🔥あつさに つよい・❄️さむさに つよい・🌙くらくても わかる・👃はなが いい・🦘はねる・⛏️ほれる）で 見える。
2. **コース**: ばしょが 3つ つながった コース（🔀 で かわる）。くぎり ごとに いちばん たかい のうりょくで すすむ。
   はやさ ＝ 1 ＋ のうりょく なので、のうりょく 0 でも おそいけど とまらない（ぜったい ゴール できる）。
3. **ゴール** したら タイムと くぎり ごとの すすみかた、「うみで はやかった のは アヒルの あし の おかげ！」と まめちしき 1つ。
4. **おだい**: 「こおりの うみを わたれる どうぶつを つくって」など 30もん。ゴールタイム いないで クリア。
5. **ずかん**: ほんものの 20しゅ（ぜんぶ おなじ どうぶつの ぶいで くみたてた え・せつめい・ぶい ごとの まめちしき）と、
   つくった がったい どうぶつ（さいだい 30。タップで ラボに よびだせる）。

## どうぶつ（20しゅ）

チーター・ペンギン・アヒル・ワシ・ラクダ・シロクマ・カエル・ヤモリ・カンガルー・イルカ・ゾウ・モグラ・コウモリ・カメ・ウサギ・ヘビ（あし なし）・タコ・ハチドリ・ヤギ・ナマケモノ。
カエル・タコは しっぽ なし、イルカの あしは むなびれ。

## しくみ

| ファイル | なかみ |
| --- | --- |
| `parts.js` | 20しゅ × 4ぶい の のうりょく・とくせい・おもさ・まめちしき と SVG。DOM なし |
| `lab.js` | のうりょく けいさん（おもさ ペナルティ）・ばしょ ごとの すすみかた・タイム・なまえ・おだい 30もん。DOM なし |
| `app.js` | がめん（ラボ・レース・おだい・ずかん） |
| `audio.js` | からから・ぼわん・あしおと（あし ごと）・しぶき・はばたき・ファンファーレ |

- **え**: viewBox 200×160・みぎむき。くび (132,78)・こし (64,84)・せなか (100,68)・あしの ねもと y=100・じめん y=150 を
  ぜんぶの ぶいで そろえて いるので、どの くみあわせでも つながって 見える。あしが じめんに とどかない（ヘビ・イルカ・ハチドリ）ときは
  からだごと じめんまで さげる。
- **のうりょく**: ぶいの すうじを たして 0〜5。おもさ（w）の ごうけいが おおいと とぶ・のぼる・はしる が へる
  （ぜんぶ 満点の さいきょうは つくれない）。
- **ばしょ**: のはら=はしる（はねると ＋）／うみ=およぐ（とぶ×0.6）／そら=とぶ（はねる・のぼる すこし）／やま=のぼる（とぶ×0.8・ほる）／
  さばく=はしる・たえる（あつさに つよくないと ×0.4）／こおり=はしる・およぐ・たえる（さむさに つよくないと ×0.4）／
  よるの もり=はしる・のぼる（くらくても わかる か はなが いい でないと ×0.4）。
- **ほぞん**: localStorage `gattai-doubutsu-v1`（つくった どうぶつ・クリアした おだい・おと。try/catch つき）。

## テスト

```bash
node gattai-doubutsu/test.js    # 20×20×20×20 ぜんぶで ゴール・ぜんぶ 満点なし・ぜんぶの おだいに こたえ・ふりがな
node gattai-doubutsu/check.js   # ブラウザ（スマホ たて／タブレット よこ）で がったい → レース → ずかん → おだい、JS エラー なし
```
