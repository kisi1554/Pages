# ブルーライン＆でんえんとしせん すごろく

横浜市営地下鉄ブルーラインの 湘南台駅から あざみ野駅で 東急田園都市線に のりかえて、
中央林間駅まで すすむ ふたりようの すごろく。

- あおちゃん と パパ が じゅんばんに サイコロを ふる
- とまった えきで あいてに かんじクイズ（2たく）。まちがえると マスに かいてある こうげき
  （1〜3つ もどす／1かい やすみ）が あたる
- 音は WebAudio の合成音のみ。右上の 🔊 で オン/オフ

`index.html` だけで完結（外部ライブラリなし）。
