# きょうふの エレベーター 🛗

**よるの ホテル「よぞら」の エレベーターに のって、てっぺんから ストーン！と おちる ドキドキ たいけん。**
未就学〜小学生むけ。`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/kyofu-elevator/

## あそびかた

1. のる キャラ（🐻🐰🐱🐶🐼🦊）と こわさを えらんで「🛗 のる！」。
2. ドアが しまって うえへ。とちゅうで でんきが チカチカ、かみなり、そして てっぺんで まっくらに…おばけ が でる。
3. ドアが ひらくと よるの まちが いちぼう。…そのあと とつぜん **おちる**！ あがって また おちる。
4. おちている あいだ「🙌 ばんざい」ボタンを おしつづけると ゆうき ポイント（★1〜3）。
5. さいしょに おちる とちゅうで **ライド フォト** を パシャ！ ばんざい していれば ばんざい ポーズで うつる。
6. こわくなったら いつでも「🛑 おりる」で ゆっくり 1かいへ もどれる。

## こわさ

| こわさ | ないよう |
| --- | --- |
| 🌙 やさしい | 7かいまで。ゆっくり おちて 1かい あがって おわり |
| 👻 ふつう | 13かいまで。おちる → あがる を 2かい くりかえして 1かいへ |
| 💀 こわい | 13かいまで。フェイント（ガタッ！）、なんども おちる、てっぺんで おばけが「ばあっ！」 |

おちる たかさ・まつ じかんは まいかい ランダム。

## しくみ

- **うごき**: たかさを 1つの かずで もち、おちる／あがる は「かそく → げんそく」の 2だんかい
  （おちる ときは じゅうりょくで かそく、あがる ときは さいごに じゅうりょくで げんそく → ふわっと うく）。
  かそくどから「むじゅうりょく」を けいさんし、ゆかの 🧸🎩🍬🧳 が うきあがる。
- **けしき**: Canvas に えんきんほう（とおいものほど ゆっくり うごく）で、やま・まち・いえ・がいとう・き・
  エレベーターの はしら を かく。はしらは はやさに おうじて ぶれる。
- **おと**: WebAudio の ごうせいおん だけ（かぜ・モーター・ひくい うなり・オルゴール・かみなり・ドア・
  わらいごえ・しんぞうの おと・シャッター）。オン／オフ あり。
- **ゆれ ひかえめ**: がめんの ゆれを よわめ、しんどう（vibrate）を とめる。`prefers-reduced-motion` なら さいしょから オン。
- **ほぞん**: localStorage `kyofu-elevator-v1`（のった かいすう、こわさごとの さいこう★、しゃしん 12まい）。
  しゃしんは がぞうではなく パラメータ（キャラ・ばんざい・ひづけ・たね）を ほぞんして かきなおす。
