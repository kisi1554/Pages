# さんすう どうじょう 🥋

**たぬき の ぽんた しはん に まなんで、年長〜小学2年 の さんすう を 単元 順 に すすめる「本道」アプリ。**
1単元 ごと に **しはん の おてほん → やってみる（道具 を さわる）→ れんしゅう**、おび ごと に **しょうきゅう しけん**。
`index.html` を ひらく だけ で あそべます（外部ライブラリ・CDN なし、道具 も キャラ も SVG を コード で かく）。

公開URL: https://kisi1554.github.io/Pages/sansuu-dojo/

## おび と 単元

| おび | めやす | 単元 |
| --- | --- | --- |
| しろおび | 年長 | 10 まで の かず（かぞえる・すうじ と あわせる・じゅんばん）／ どっち が おおい？（ならべて 1たい1）／ なんばんめ（まえ から・うしろ から、「3ばんめ」と「3びき」）／ すうじ の かきかた（0〜9 を ゆび で なぞる・かがみもじ を みわける） |
| きいろおび | 年長〜小1 | いくつ と いくつ（5 と 10 の まとまり）／ たしざん（10 まで。あわせて・ふえると）／ ひきざん（10 まで。のこりは・ちがいは）／ 0（れい） |
| オレンジおび | 小1 | 20 まで の 数（10 と いくつ）／ くりあがり の たしざん（10 を つくる・さくらんぼ）／ くりさがり の ひきざん（**減加法 と 減減法 の 両方** を 見せる）／ 3つ の 数 の けいさん／ 長さ・かさ・広さ（そろえて くらべる → クリップ・コップ・ます の いくつぶん）／ なんじ・なんじはん |
| みどりおび〜くろおび | 小1〜小2 | つぎ の アップデート（PR 2）で 追加 |

- 単元 は 前 から 順 に 開く（★1 で つぎ が 開く。おび の 単元 が ぜんぶ ★1 で しょうきゅう しけん が 開く）。
  保護者 画面 で「どの 単元 から でも 選べる」に 切りかえ られ、「◯◯おび から はじめる」で 学年 に あわせて 途中 から すすめられる。
- **しょうきゅう しけん**: その おび の 単元 を まぜた 10問。8問 以上 で 合格 → 道着 の おび の 色 が かわる 演出 と、しはん から **めんじょう**。
  不合格 でも「あと すこし！ まちがえた ところ を もう 一度 けいこ しよう」→ まちがえた 問題 だけ の けいこ。

## 1単元 の すすめかた

1. **① おてほん**（30秒 ほど）: しはん が 道具 を うごかして 見せる。こえ は speechSynthesis、文字 も ふきだし に 出す。「とばす」あり。
2. **② やってみる**: 子ども が 道具 を さわって おだい を こなす（「できた！」で はんてい）。
3. **③ れんしゅう**（6問）: 前半 3問 は 道具 つき、後半 3問 は 道具 なし。まちがえる と 原因 に あわせた ヒント → もう 一度。
   2回 まちがえる と こたえ と ときかた（さくらんぼ 計算・2つ の ひきかた など）を 見せて、同じ 問題 を さいご に もう 一度。

道具 の 上 は `touch-action: none`（ページ の スクロール・ズーム を ふせぐ）。

## 出題・記録（engine.js）

- 単元 ごと の **生成関数**（`gen(rng, lv)` → `build(params)`）で 毎回 ちがう 数。学年 の 範囲 を こえない 条件 つき
  （年長 は 10 まで、きいろおび の たしざん は 和 10 以下、くりあがり は 1けた＋1けた で 和 11〜18、くりさがり は 11〜18 − 1けた で ばら から ひけない もの だけ、3つ の 数 は とちゅう も 0〜20）。
- **まちがえ方 の 見立て**（`SD.diagnose`）: たし算 で 差 を 答えた → ひき算 と まちがえた かも ／ 12 を 102 → 位取り ／
  くりあがり の 1 を わすれた ／ くりさがり で 大きい 方 から ひいた ／ 10 から ひいた あと ばら を たし わすれ ／ 1 ちがい → かぞえ まちがい ／
  なんじはん で 次 の 時 を 読んだ ／「3ばんめ」と「3びき」の とりちがえ など。ヒント に 出し、保護者 画面 に 回数 を のこす。
- **ライトナー方式**: まちがえた 問題 は 1ばん の 箱（あした また 出る）。正解 の たび に 箱 が すすみ 間隔 が 1→2→4→7→14日。5ばん で 正解 → 卒業。
- **きょう の けいこ**（5分 ≒ 8問）: 苦手 箱 の 期限 が きた 問題（最大 3）＋ 復習 2 ＋ いま すすめて いる 単元 3。おわる と **けいこ帳** に はんこ。
- 記録 は localStorage（`sansuu-dojo-v1`、読み書き は try/catch）。**3人 まで** 名前 ごと に 分ける（ヘッダー の 名前 から 切りかえ）。

## 保護者 画面（👪 おうち の ひと）

かけ算 の 問題 に 答えて 入る。

- 学年 の めやす（年長／1年 1〜3学期／2年 1〜3学期）と、いま の おび の くらべ。学年 を 年長 に する と 答え は「えらぶ」方式。
- おび ごと の すすみ、単元 ごと の 回数・正答率（バー）・1問 の 平均 時間・★。
- 苦手 な 型（「くりさがり の ひきざん」など 3問 以上 で 9割 未満）と、よく ある まちがえ方。
- さいきん 14日 の 問題数 グラフ（一発正解 と まちがい、はんこ の 日）。
- どこ から でも 選べる 切りかえ、「◯◯おび から はじめる」、きょうだい の 名前 の 追加・変更・削除、記録 の 消去。

## 学習指導要領 との 対応

文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」（[PDF](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)、
図1「小学校算数科の内容の構成」と 第1学年・第2学年 の 内容）を 確認 して そろえた。年長 は 幼稚園教育要領 の
「数量 や 図形 など への 関心・感覚」を 育てる あそび として、えらぶ 方式・10 まで に とどめた。

| 単元 | おび | 学習指導要領 の 内容 |
| --- | --- | --- |
| 10 まで の かず・どっち が おおい？・なんばんめ・すうじ の かきかた | しろ | 幼稚園教育要領（数量 への 関心・感覚）。小1 A(1) 個数 を 比べる こと／個数 や 順番 を 数える こと の 前段階 |
| いくつ と いくつ | きいろ | 第1学年 A(1) 数 の 構成 と 表し方（一つ の 数 を ほか の 数 の 和 や 差 と して みる） |
| たしざん・ひきざん（10 まで）、0 | きいろ | 第1学年 A(2) 加法・減法 が 用いられる 場合 と 意味、1位数 と 1位数 との 加法（和 が 10 以下）と その 逆 の 減法 |
| 20 まで の 数 | オレンジ | 第1学年 A(1) 2位数 の 表し方、十 を 単位 と した 数 の 見方 |
| くりあがり・くりさがり | オレンジ | 第1学年 A(2) 1位数 と 1位数 との 加法（和 が 10 より 大きい）と その 逆 の 減法（減加法・減減法） |
| 3つ の 数 の けいさん | オレンジ | 第1学年 A(2) 簡単 な 場合 の 3口 の 加法・減法（解説 で 扱う 内容） |
| 長さ・かさ・広さ | オレンジ | 第1学年 C(1) 量 の 大きさ の 直接比較・間接比較、任意単位 を 用いた 大きさ の 比べ方 |

| 100 まで の 数・何十 の 計算・かたち あそび・絵 と 式 | みどり（PR 2） | 第1学年 A(1)(2)・B(1)・D(1) |

| かけ算・図形・はこ の 形 | むらさき（PR 2） | 第2学年 A(3)・B(1) |
| 3けた の ひっ算・分数・時こく と 時間・テープ図 | ちゃ（PR 2） | 第2学年 A(1)(2)・C(2) |
