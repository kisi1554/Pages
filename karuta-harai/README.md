# かるた はらい 🎴

**競技（きょうぎ）かるたの「はらい」で、札（ふだ）を どこまで 遠（とお）くへ とばせるかを きそうゲーム。**
iPhone（Safari・縦持ち）むけ。`index.html` を ひらくだけで あそべます（ビルド・サーバー 不要）。

公開URL: `https://kisi1554.github.io/Pages/karuta-harai/`

## あそびかた

1. 「はじめる」を おすと 読手（どくしゅ）が 前の歌の 下の句 → 上の句（かみのく）の 順に 声で 読みあげます（画面上にも 1もじずつ 出る）。
2. **決まり字（きまりじ・あかい もじ）**まで 読まれたら 「はらえ！」。札が 金色に 光ります。
3. 札の **外（そと）から** 指を いきおいよく すべらせて、札を はらいます。
4. 札は たたみの 上を とんで すべり、止まった ところまでの **きょり（m）** が その札の 点数。
5. 1ゲーム **3まい**。3まいの **ごうけい きょり** が スコアです。
6. 「はらえ！」より 前に 札に さわると **おてつき**（その札は 0m）。

### よみあげ（こえ）

競技かるたの 読み方に 近づけて、読手（どくしゅ）の こえで 読みあげます（🗣️ で オン/オフ）。

1. **前の歌の 下の句**（1まいめは 序歌「なにわづに」の 下の句「いまははるべと さくやこのはな」）
2. **間（ま）**（1〜2.2秒。長さを ばらつかせて、はじまりを 読めないように）
3. **上の句**。決まり字まで 読まれた ところで「はらえ！」
4. **余韻（よいん）** のあと、はらって いる あいだも **下の句** を 読みつづける
5. 次の札では、その 下の句を もう一度 読んでから 次の 上の句へ（競技かるたの「下の句 → 上の句」の つなぎ）

- 声は ブラウザの **読みあげ機能（Web Speech API）**。音声ファイルは 使っていません。
  iPhone では Kyoko / O-ren などの 日本語の声を 自動で えらびます。
- 句ごとに 区切って 読み、句の 終わりを「ー」で のばして 読みあげらしく しています（速さ 0.78）。
- 札の 表記は 歴史的かなづかい（`いにしへの`・`けふ`）、読みは 今の 発音（`いにしえの`・`きょう`、
  助詞の「は」→「わ」、「らむ」→「らん」）で、歌ごとに 別に 持っています（`ky` / `sy`）。
- 画面の 文字は、声の 進み方に あわせて 1字ずつ 出ます。1字あたりの 時間は 実際に しゃべった
  長さから 毎回 学びなおすので、声の 速さが 端末で ちがっても 「はらえ！」が 声と ずれにくい。
- 日本語の 声が ない・声が 出ない（1.2秒 はじまらない）ときは、文字と 効果音だけで おなじ 流れに なります。
- iPhone は タップの 中で 一度 しゃべらせないと 声が 出ないため、「はじめる」「つぎの ふだへ」で 準備しています。

札の 下の句（しものく）は 本物の 取り札（とりふだ）と おなじ ひらがなの たてがき 3行です。
読まれる歌は、一字決まりの「**むすめふさほせ**」7首 ＋ 有名な 8首 から ランダムに 3首。

## とばしかた（払い方で きょりが かわる）

| 要素 | 見ている もの | きょりへの 効き |
| --- | --- | --- |
| はやさ | 札に ふれた 瞬間の 指の 速さ（直前 60ms） | いちばん 大きい。ほぼ 比例 |
| まっすぐ | 直前 150ms の 指の 軌跡の まっすぐさ | 曲がると 最大 3割 ダウン |
| 札の まんなか | 指の 線が 札の 中心から どれだけ ずれたか | 端（はし）を はらうと 最大 5割 ダウン。札が 回転して 曲がって とぶ |
| おさえ | 指を 札の 上から 置いて 押した | 「はらい」では ないので 0.45倍 |

結果画面で それぞれ ★1〜3 で 表示し、いちばん 弱い ところの アドバイスを 出します。

### ぶつりモデル

- 指の速さ（px/s）× 0.0032 = 札の 初速（m/s）。9000px/s で うちどめ。
- はじめの 最大 0.55秒 は **空中**（空気抵抗 `0.15·v²`）。影が はなれて 札が 大きく 見えます。
- 着地後は たたみの 上を **一定の 減速（3.4 m/s²）** で すべって 止まります。
- 札の 大きさは 本物と おなじ 5.3cm × 7.3cm、たたみは 88cm × 176cm。
- きょりは スタート地点から 止まった 地点までの **直線きょり**（どの 方向に はらっても よい）。
  速く はらえた ときは カメラが ひいて、1m ごとの 同心円で きょりが わかります。赤い 点線は 自分の 最高記録。

目安: ふつうの 速さで 2〜4m、すばやく まっすぐ まんなかを はらうと 10m 以上。

## ランキング

- `ranking.html`。ゲーム画面の 🏆 から ひらけます。
- 記録は **スコアの 高い 順に 100件まで** `localStorage` に 保存（101件目以降は 低い ものから 消える）。
- 「ごうけい」順と「1まいの さいこう」順を 切りかえ可能。今回の 記録は 光って 表示されます。
- 名前（10文字まで）は 次回も おぼえています。
- 「ぜんぶ けす」で 記録を リセット。

保存キー: `karuta-harai.scores.v1`（記録）、`karuta-harai.name`、`karuta-harai.sound`、`karuta-harai.voice`、`karuta-harai.rankTab`。
記録は その 端末・その ブラウザの 中だけに 保存されます（他の 端末とは 共有されません）。

## iPhone むけの 工夫

- `touch-action: none`・`gesturestart` の 無効化で、スワイプ中に 画面が スクロール・ズーム しない。
- Pointer Events で 指を 追跡し、前回の 点との **線分** で 当たり判定（速い スワイプでも すりぬけない）。
- ノッチ・ホームバーを `env(safe-area-inset-*)` で よける。ホーム画面に 追加すると 全画面で あそべます。
- 音は WebAudio の 合成音のみ（読みあげ音・「はらえ」の 合図・はらう音・すべる音・止まる音）。
  🔊/🔇 で オン/オフ。**iPhone の マナーモード（消音スイッチ）中は 音が 出ません。**
- 名前入力欄は 20px（16px 未満だと iPhone が 自動ズーム するため）。
