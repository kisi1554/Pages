# かるた はらい 🎴

**競技（きょうぎ）かるたの「はらい」で あそぶ ゲーム。**
札（ふだ）を 遠（とお）くへ とばす「とばし」と、読まれた 札を さがして はらう「ふださがし」の 2モード。
百人一首 100首 すべてを 収録し、はらった 歌は「ふだずかん」に 集まります。
iPhone（Safari・縦持ち）むけ。`index.html` を ひらくだけで あそべます（ビルド・サーバー 不要）。

公開URL: `https://kisi1554.github.io/Pages/karuta-harai/`

## モード

### 🎴 とばし（3まい）

1. 読手（どくしゅ）が 前の歌の 下の句 → 上の句（かみのく）の 順に 声で 読みあげます（画面上にも 1もじずつ 出る）。
2. **決まり字（きまりじ・あかい もじ）**まで 読まれたら 「はらえ！」。札が 金色に 光ります。
3. 札の **外（そと）から** 指を いきおいよく すべらせて、札を はらいます。
4. 札は たたみの 上を とんで すべり、止まった ところまでの **きょり（m）** が その札の 点数。
5. 3まいの **ごうけい きょり** が スコア。「はらえ！」より 前に 札に さわると **おてつき**（その札は 0m）。

### 🔍 ふださがし（5かい・空札あり）

1. たたみに 4まいの 取り札を 2×2 で ならべます。
2. 5回 読むうち 4回は 場の 札、**1回は 場に ない 札（からふだ）**。どこで 空札が くるかは ランダム。
3. 読まれた 歌の 札を さがして はらいます。「はらえ！」の 合図は ありません。
4. **おてつき**: 前の歌の 下の句の あいだに さわる／ちがう 札に さわる／空札の ときに どれかに さわる。
   おてつきした 読みの 正しい 札は「死に札」として 場から 消えます。
5. 点数（1回ごと）

   | できごと | 点 |
   | --- | --- |
   | 正しい 札を とった | 100 |
   | はやさ（決まり字を 読み終えてから はらうまで） | 0.3秒 以内 +100 → 3秒で +0（直線で へる）。決まり字の 前に とれたら +100 |
   | とばし（とった 札の とんだ きょり） | 1m ごとに +10 |
   | 空札で さわらずに がまん できた | 50 |
   | おてつき | 0 |

6. **ヒント**（タイトルで オン/オフ。はじめは オン）: 各札の 上に 決まり字を 赤く 表示。
   ヒントなしは ごうけい点が **1.5倍**。
7. 上の句を 読みおわって 4秒 たっても とれないときは、正しい 札が 光って 教えてくれます。

## よみあげ（こえ）

競技かるたの 読み方に 近づけて、読手の こえで 読みあげます（🗣️ で オン/オフ）。

1. **前の歌の 下の句**（1回めは 序歌「なにわづに」の 下の句「いまははるべと さくやこのはな」）
2. **間（ま）**（1〜2.2秒。長さを ばらつかせて、はじまりを 読めないように）
3. **上の句**。決まり字まで 読まれた ところで、とばしは「はらえ！」
4. **余韻（よいん）** のあと、はらって いる あいだも **下の句** を 読みつづける
5. 次の 読みでは、その 下の句を もう一度 読んでから 次の 上の句へ

- 声は ブラウザの **読みあげ機能（Web Speech API）**。音声ファイルは 使っていません。
  iPhone では Kyoko / O-ren などの 日本語の声を 自動で えらびます。
- 句ごとに 区切って 読み、句の 終わりを「ー」で のばして 読みあげらしく しています（速さ 0.78）。
- 画面の 文字は、声の 進み方に あわせて 1字ずつ 出ます。1字あたりの 時間は 実際に しゃべった
  長さから 毎回 学びなおすので、声の 速さが 端末で ちがっても 決まり字の タイミングが ずれにくい。
- 日本語の 声が ない・声が 出ない（1.2秒 はじまらない）ときは、文字と 効果音だけで おなじ 流れに なります。
- iPhone は タップの 中で 一度 しゃべらせないと 声が 出ないため、開始ボタン・「つぎへ」で 準備しています。

## 百人一首 100首（`poems.js`）

歌ごとに 次を 持っています。

| 項目 | 例（61番） |
| --- | --- |
| 上の句・下の句（札の 表記・歴史的かなづかい） | `いにしへの ならのみやこの やへざくら` / `けふここのへに にほひぬるかな` |
| 読み（声 用・今の 発音） | `いにしえの ならのみやこの やえざくら` / `きょうここのえに においぬるかな` |
| 作者（漢字 ＋ ふりがな） | 伊勢大輔（いせのたいふ） |
| いみ（こども むけ・ひらがな） | むかしの ならの みやこの やえざくらが、きょうは この きゅうちゅうで きれいに さいて いるよ |

- 読みの 表記: 助詞の「は」→「わ」、「を」→「お」、「らむ」→「らん」、「けふ」→「きょう」、「てふ」→「ちょう」など。
  ことばの 頭の「は」（葉・端・花）は 声が「わ」と 読まないよう かたかなの「ハ」に しています。
- **決まり字は 手で 書かず、読みから 自動で 計算**（ほかの 99首と 区別できる 最初の ところまで）。
  競技かるたの 数（1字7・2字42・3字37・4字6・5字2・6字6）と 一致することを 確認済み。
  計算だけでは 合わない 44番「あふこ」（3字決まり）だけ 上書きしています。

## とばしかた（払い方で きょりが かわる）

| 要素 | 見ている もの | きょりへの 効き |
| --- | --- | --- |
| はやさ | 札に ふれた 瞬間の 指の 速さ（直前 60ms） | いちばん 大きい。ほぼ 比例 |
| まっすぐ | 直前 150ms の 指の 軌跡の まっすぐさ | 曲がると 最大 3割 ダウン |
| 札の まんなか | 指の 線が 札の 中心から どれだけ ずれたか | 端（はし）を はらうと 最大 5割 ダウン。札が 回転して 曲がって とぶ |
| おさえ | 指を 札の 上から 置いて 押した | 「はらい」では ないので 0.45倍 |

### ぶつりモデル

- 指の速さ（px/s）× 0.0032 = 札の 初速（m/s）。9000px/s で うちどめ。
- はじめの 最大 0.55秒 は **空中**（空気抵抗 `0.15·v²`）。着地後は **一定の 減速（3.4 m/s²）** で すべって 止まる。
- 札の 大きさは 本物と おなじ 5.3cm × 7.3cm、たたみは 88cm × 176cm。
- きょりは その札の もとの 場所から 止まった 地点までの **直線きょり**。

## ふだずかん（`zukan.html`）

- はらえた 歌（とばしは おてつき 以外、ふださがしは 正しく とった とき）が 集まります。100首で コンプリート。
- 1回の 結果画面にも 歌の 番号・作者・上の句（決まり字は 赤）・下の句・いみ を 表示。はじめて 集めた 歌には「📖 ずかんに ついか！」。
- ずかんでは「とった／まだ」と 決まり字の 字数（1字＝むすめふさほせ 〜 4字以上）で しぼりこみ。
  札を タップすると 歌・いみ・はらった 回数・最長きょり。🗣️ で 読みあげ（まだの 歌は 上の句だけ）。

## ランキング（`ranking.html`）

- モード（とばし／ふださがし）ごとに **スコアの 高い 順に 100件まで** `localStorage` に 保存。
- とばしは「ごうけい」順と「1まいの さいこう」順、ふださがしは「ごうけい」順と「1かいの さいこう」順。
- 名前の 横に その回の 段位。今回の 記録は 光って 表示されます。「この モードを けす」で リセット。

保存キー: `karuta-harai.scores.v1`（記録）、`karuta-harai.dan.v1`（名前ごとの 段位）、`karuta-harai.zukan.v1`（ずかん）、
`karuta-harai.name`、`karuta-harai.sound`、`karuta-harai.voice`、`karuta-harai.hint`、`karuta-harai.rankTab`、`karuta-harai.rankMode`。
記録は その 端末・その ブラウザの 中だけに 保存されます（他の 端末とは 共有されません）。

## 結果の がぞうシェア

結果画面の「🖼 がぞうで シェア」で、スコア・段位・1回ごとの 結果・名前・日付を 1080×1350 の 画像に して、
iPhone の 共有シート（`navigator.share`）から LINE・写真などへ 送れます。
共有シートが つかえない ブラウザでは 画像を 表示するので、ながおしで 保存します。
（iPhone では タップの 直後に 共有を よぶ 必要が あるため、画像は 結果画面を 出した 時点で 先に 作っています）

## ホーム画面アプリ（PWA）

- `manifest.webmanifest` と アイコン（`icons/`）で、Safari の「共有 → ホーム画面に 追加」から アプリのように 起動。
- `sw.js`（service worker）で オフラインでも 起動できます。**ネットワーク優先**（つながる ときは いつも 最新を 取り、
  取れた ものを キャッシュ）なので、更新しても 古い 画面が 出つづける ことは ありません。オフライン時だけ キャッシュを 使います。
- `file://` で 開いた ときは service worker を 登録しません。

## iPhone むけの 工夫

- `touch-action: none`・`gesturestart` の 無効化で、スワイプ中に 画面が スクロール・ズーム しない。
- Pointer Events で 指を 追跡し、前回の 点との **線分** で 当たり判定（速い スワイプでも すりぬけない）。
  ふださがしでは、線分が 最初に 入った 札を 「さわった 札」と します。
- ノッチ・ホームバーを `env(safe-area-inset-*)` で よける。
- 音は WebAudio の 合成音のみ。🔊/🔇 で オン/オフ。**iPhone の マナーモード中は 効果音が 出ません。**
- 名前入力欄は 20px（16px 未満だと iPhone が 自動ズーム するため）。
