# ぷっぴの えきうた 🎫🎵

きっぷの こども **ぷっぴ** が、えきの なまえを じゅんばんに うたって くれる アプリ。
`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・音声ファイルなし）。

## うたう せん

| せん | えき | パンチ |
| --- | --- | --- |
| 横浜市営地下鉄 ブルーライン | しょうなんだい（B01）〜 あざみの（B32）・32えき | ★ ほし |
| 東急東横線 | しぶや（TY01）〜 よこはま（TY21）・21えき | ♥ ハート |
| 東急田園都市線 | しぶや（DT01）〜 ちゅうおうりんかん（DT27）・27えき | 🍃 はっぱ |

どの せんも「⇄ はんたいむき」で ぎゃくからも うたえます。
よこはま・しぶや・あざみの では「ここで ○○せんにも のれるよ！」と のりかえを おしえてくれます。

## ぷっぴ（あたらしい キャラ）

- きっぷの こども。しゃしょうさんに もらった ぼうしが じまん。
- まいごに ならないように、えきの なまえを ぜんぶ **うた** で おぼえている。
- ひとつの せんを さいしょから さいごまで いっしょに うたうと、からだに **パンチの あな**（★・♥・🍃）が あく。たからもの。
- **なでる**（ぷっぴを タッチ）と「えへへ」と わらう。ホームで しばらく ほうっておくと ねむって しまう。
- なまえを おしえると、なまえで よんでくれる。ひさしぶりに あうと「あいたかったよ〜！」。
- **なかよしど**（うたった えき＋1、さいごまで うたう＋5、なでる＋1／1にち5かいまで）で レベルアップ。
  Lv.2 ぼうしの リボン → Lv.3 ちょうネクタイ → Lv.4 きらきら → Lv.5 ちいさな おうかん。

## あそびかた

1. ホームで せんを えらぶ → ▶ で うたいはじめる（ベル → 「しゅっぱつ しんこう」→ えきめい → 「また うたおうね」）。
2. いま うたっている えきの えきめいひょうと、カラオケの もじ（いま うたっている おとが ひかる）が でる。
3. したの えきの ならびを タッチすると、そのえきから うたう。
4. 🐢 / 🚃 / 🐇 で はやさ、⏮ で はじめから。
5. うたった えきは 📒 スタンプちょう に のこる。

## しくみ（おうちの方・開発者むけ）

- `data.js` … 駅データ（漢字・よみ・駅ナンバー）。乗り換え駅は駅名の一致で自動判定。
- `voice.js` … 歌声エンジン。よみをモーラに分け、1駅＝1〜2小節に割り付けてペンタトニックのメロディを作る。
  声は WebAudio の **のこぎり波＋3つのフォルマント（母音ごとの共鳴）＋子音のノイズ** で合成（音声ファイルなし）。
  伴奏はベース・和音・「ガタンゴトン」のリズム。
  せっていで「よみあげ＋メロディ」にすると、端末の読み上げ機能（speechSynthesis）で駅名を読み、メロディはおもちゃのピアノ音になる。
- `app.js` … 画面・ぷっぴの反応・保存（localStorage `eki-uta-puppi-v1`、try/catch 済み）。
- 🔊 ボタンで おと オン/オフ。縦持ちスマホは1列、横持ちタブレットは ぷっぴ と えきめいひょうが 左右に並ぶ。
