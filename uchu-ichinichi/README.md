# うちゅう ステーション の いちにち 🛰️

うちゅう ひこうし に なって、**ちきゅう の まわり を まわる うちゅう ステーション** で 1にち を すごす（年長〜小学6年）。
みず は まるい たま に なって うき、ねる とき は かべ の ねぶくろ、ごはん は ふくろ から。
**むじゅうりょく（ふわふわ）** と **かんせい（いちど うごくと すすみ つづける）** を、ゆび で さわって たいけん する。

`index.html` を ひらく だけ で うごく（外部ライブラリ・CDN なし。え は ぜんぶ SVG を コード で かき、
おと は WebAudio の 合成音。ヘッダー の 🔊 で オン/オフ）。

## あそびかた

1. **ステーション**: 5つ の へや（ねむる へや・キッチン・じっけん しつ・うんどう の へや・まど の へや）が よこ に つながって いる。
   - かべ を **スワイプ** すると その むき に ういて すすむ。ちから を くわえない と すすみ つづける（かんせい）。
   - ういて いる とちゅう は けれない（かべ・てすり の ちかく か、とまって いる とき だけ）。
   - **✋ つかまる**（または きいろ の てすり を タップ）で とまる。ハッチ の あな から はずれる と かべ で はねかえる。
   - キーボード: やじるし で ける、スペース で つかまる。
2. **ミッション**（あさ〜よる の 7つ。へや に はいる と ボタン が でる）

   | じかん | ミッション | さわって わかる こと |
   | --- | --- | --- |
   | あさ ⏰ | おきる・はみがき | ねぶくろ の ジッパー を ゆび で ひく → のみこめる はみがきこ で ごしごし → ぬれタオル で かお を なでる |
   | あさごはん 🥄 | ふくろ の ごはん | おゆ を 3かい いれて もどす → てを はなした スプーン が ただよう ので タップ で つかまえる |
   | しごと 🧪 | じっけん | ストロー から みず（おしつづける）→ まるい たま を つつく と ぷるぷる → ほのお の かたち（ちきゅう／うちゅう）→ しょくぶつ は ひかり の ほう へ |
   | いどう 🧗 | へや を ぜんぶ まわる | スワイプ で 5つ の へや を まわって、さいご に てすり に つかまる |
   | うんどう 🏃 | ランニング | ひだり・みぎ を こうご に 16かい（＝ 120ぷん。ゴム で からだ を おさえる） |
   | まど 🌏 | ちきゅう を みる | きた から みた ちきゅう と ステーション。⏩ はやおくり。ひので 2かい ＋ にほん の うえ を とおる で クリア |
   | よる 🌙 | ねぶくろ で ねる | ほか が ぜんぶ おわる と ねられる。ねると うで が ふわっと うく |

   ぜんぶ おわる と「おつかれさま！」と ちきゅう の よる の まち の あかり。📋 で リスト と「あたらしい いちにち（やりなおす）」。
3. **🌏 ちきゅう と くらべる**: みず を こぼす／ボール を はなす を、うちゅう と ちきゅう で ならべて うごかす（おなじ しくみ に じゅうりょく を たす だけ）。
4. **📇 まめちしき カード**（12まい）: ミッション で 10まい、へや の「？」（🚽 トイレ・♻️ みず の リサイクル）で 2まい。

## しらべた こと（じじつ）

- ISS は やく 90ぷん で ちきゅう を 1しゅう（じそく やく 28,000km ＝ 1びょう やく 7.7km）→ 1にち に ひので・ひのいり を やく 16かい。たかさ は やく 400km。
- うちゅう ひこうし は きんにく と ほね の ため に まいにち やく 2じかん うんどう する。ランニングマシン は ハーネス と ゴム で からだ を おさえる。
- ねぶくろ は かべ に ゆわえて ねる。
- はみがきこ は のみこむ か、タオル・ティッシュ に はきだす（ひと に よる。JAXA の ひこうし の こえ を まとめた しりょう でも、はきだして いた という こえ が ある）。
- ごはん は ふくろ・かん。かわかした もの は おゆ・みず で もどす。
- みず は ひょうめん ちょうりょく で まるい たま に なる。ほのお は たいりゅう が ない ので まるく あおっぽく なる。
- トイレ は くうき の ながれ で すいこむ。あせ（すいじょうき）や おしっこ を きれい に して のみみず に もどす しくみ が ある。

参考: JAXA 宇宙ステーション・きぼう 広報・情報センター（https://iss.jaxa.jp/ 、Space Life Story Book など）、
NASA の ISS 解説（https://www.nasa.gov/international-space-station/ ）。

**かんたん に した ところ**: まど の ず は きた から みた もの で、ステーション の きどう の かたむき（やく 51.6°）は はぶいて いる。
「にほん の うえ」は にほん の けいど と ステーション の かく が ちかい とき に した。
ステーション の かたち・ひこうし・ワッペン は オリジナル（じつざい の ひこうし や ミッション の ロゴ は つかわない）。
