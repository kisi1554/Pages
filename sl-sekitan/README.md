# SL せきたん リズム 🚂

SL（じょうき きかんしゃ）の **機関助士（きかんじょし）** に なって、かまに 石炭を くべる アクションゲーム（5さい むけ）。
石炭を もやす → 水が わいて じょうき → ピストンが 動いて 車輪が 回る、を あそびながら 体験する。
`index.html` だけで うごく（外部ライブラリ・CDN なし。絵は canvas、音は WebAudio の 合成音）。

公開URL: https://kisi1554.github.io/Pages/sl-sekitan/

## あそびかた（1回 1〜3分）

- 合成音の「シュッ シュッ ポッ ポッ」に あわせて **がめんを タップ** → スコップで 石炭を くべる。
  かまの まわりの 金の わが 小さく なって かさなった ときが「ぴったり！」（すこし 多く くべられる）。
- 「じょうきの ちから」メーターの **みどり** を たもつと ぐんぐん 走る。たりないと のろのろ、
  くべすぎると くろい けむりが もくもく → あんぜんべんが プシューッ → 機関士さんの かおが すすで まっくろ（目だけ ぱちぱち）。
  えきを とおると かおを ふいて ぴかぴか。
- のぼりざかは ちからが どんどん へる（たくさん くべる）、くだりざかは へらない（おやすみ）。
- トンネルでは けむりが 車内に 入って「けほけほ」→ 🪟「まどを しめて！」ボタンで あいず。
- 📯 きてき ボタン: ふみきりの まえで ならすと こどもが 手を ふる。うしの そばで ならすと いっせいに ふりむく。
- 終点で 汽笛「ポーーッ」。みどりを たもてた わりあいで ⭐1〜3（かならず ほめる）。タイムは 記録だけ。
- ゲームオーバー・時間切れ なし。はやさは 🐢ゆっくり（テンポ 0.8びょう）／🐇ふつう（0.6びょう）。
- キーボード: スペース＝くべる、↑ または K＝きてき、↓ または M＝まど。

## たしかめた 資料（2026年11月）

- 大井川鐵道 公式サイト SL のページ（https://daitetsu.jp/sl/）:
  急行は「下り：金谷 発 家山・川根温泉笹間渡 行き／上り：川根温泉笹間渡・家山 発 新金谷・金谷 行き」。
  「2022年台風15号の被害により、川根温泉笹間渡〜千頭間が現在も不通」、千頭方面は 家山駅で 町営バスに 乗りかえ。
  → ゲームの 終点は 家山。カードで 不通のことを 書いた。
- 鉄道コム 2025年12月13日（https://www.tetsudo.com/news/3877/）: C10形8号機は 車両改造工事の ため 2026年1月13日から 当面 運転休止。
  → カードに「くろい SLの 1だいは かいぞうで おやすみちゅう」と 書いた。
- 秩父鉄道「2026年SLパレオエクスプレス運行スケジュールについて」（https://www.chichibu-railway.co.jp/blog/news/sl2026/）:
  2026年3月20日〜12月6日の 土日祝日中心、熊谷駅〜三峰口駅間 1日1往復。C58363号機は 1944年 製造。EL が ひく 日も ある。
- 日本で 最初の 鉄道（1872年 新橋〜横浜）は `meiji-henshin/`・`rosenzu-timemachine/` と 同じ 説明に そろえた。

列車名の 愛称・会社の ロゴ・ヘッドマーク・キャラクター列車は つかわない。SL・客車の 絵は 色と 形を にせた オリジナル。

## まなび カード（5まい）

コースを クリアすると その コースの カード、さらに クリアの たびに 「SLが はしる しくみ（図）」「ふたりで うんてん（機関士と 機関助士）」「むかしの しゅやく」を 1まいずつ。

## しくみ

- 進捗は localStorage `sl-sekitan.v1`（おと・はやさ・クリアの ⭐とベスト・カード）。
- canvas は `touch-action: none`、タップは pointerdown。`python3 tools/no-zoom.py sl-sekitan` 済み。
- URL に `#debug` で `window.__sl`（`start(id)`, `G`, `warp(わりあい)`, `setP(ちから)`）。
