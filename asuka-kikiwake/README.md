# しょうとくたいしの ききわけ 👂

**みんなが いっぺんに 言う おねがいを おぼえて、「だれが 言った？」に 答える きおく ゲーム。**
10本シリーズ「じだい たんけん」の あすか じだい編（5才〜）。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/asuka-kikiwake/

## あそびかた

### 👂 ききわけ（メイン・1回 1〜2分）

1. たいしの まえに 人が ならび、いっせいに おねがいの ふきだしを 出す（3びょうで きえる。「ゆっくり」は 5びょう）。
2. 「🐟『さかなが ほしい』と いったのは だれ？」に、その人を タップして 答える。
3. 2人から はじまり、正解すると 3人、4人…と ふえて、さいごは 10 いっぺん（10人めは ねこ）。
4. まちがえても だいじょうぶ。その人が「わたしは『◯◯』だよ〜」と 教えてくれて、もういちど 聞ける
   （「👂 もういちど きく」ボタンは 何回でも つかえる）。
5. ぜんぶ 聞きわけると たいしが どやがおで ポーズ → けっか（★1〜3）。

わらい どころ: おねがいが だんだん へんに なる（「ねむい」「くつしたが かたほう ない」）／
4人・7人の あとに たいしが 聞きまちがえて てれる（「さかだちが したい、じゃな！…えっ ちがう？」）。

### 🎩 ぼうしの いろ（ミニゲーム）

くらいの じゅんに ならんだ 6人の ぼうしの 色を おぼえる → かぜで とんだ ぼうしを 1ばんの 人から かぶせる。
2回 まちがえると 正しい ぼうしが 光る。「👀 みほんを みる」も あり。

### ⛵ おてがみ とどけて（ミニゲーム）

おののいもこの ふねを 3つの レーンで うごかし（レーンを タップ／⬆⬇ボタン／矢印キー）、なみや くじらを よけて
ずいの くにへ。ぶつかっても しっぱいには ならない（「ざぶーん！ でも 手紙は ぶじ！」）。

## れきしの あつかい

- 「10人の話を一度に聞き分けた」は『日本書紀』などの **言い伝え** と明記（『上宮聖徳法王帝説』では8人）。
  お願いの中身・ねこ・聞きまちがいは 創作と 保護者むけに 書いている。
- 「聖徳太子」は後世の呼び名。厩戸王（574〜622年）と 保護者むけに 併記。
- 冠位十二階（603年）は 6色に 簡略化。冠の色（紫・青・赤・黄・白・黒）は『日本書紀』に 明記がなく
  推定なので「〜と かんがえられて いる」と 書く。
- 遣隋使（607年）の 国書と 煬帝の 反応は『隋書』倭国伝の 記述として「〜と つたわる」。
- 法隆寺は「いま のこって いる 木の たてものでは せかいで いちばん 古い」。670年焼失・再建説を 保護者むけに 併記。
- 年号は カードの 下の 小さい字（保護者むけ）だけ。
