# よーいドン ピストル 🔫

うんどうかいの「いちに ついて、よーい…ドン！」を ならす スターター ピストル。
くもんの しゅくだいなど、なにかを はじめる ときの あいずに つかう。
ドンの あとは タイマーが うごき、「おわった！」で かかった じかんを きろくする。

`index.html` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。おとは WebAudio の ごうせいおん、
「いちについて」「よーい」の こえは ブラウザの よみあげ。よみあげが ない ときは もじ＋ピッの おと）。

## せってい（localStorage に ほぞん）

- 「よーい」から「ドン」まで: はやい／ふつう／どきどき（どきどきは まちじかんが ながく ばらばら）
- ドンの あとに タイマー: つかう／つかわない
- なにを する？: さんすう／こくご／えいご／そのほか（きろくに のこる）
- 🔊 おと・🗣️ こえ の オン/オフ

## タイマーと きろく

- ドンの あと タイマー（ふん:びょう）。タイマー中は がめんが きえないように する（Wake Lock が つかえる ブラウザ）
- とちゅうで ページを とじても、ひらきなおすと つづきから
- 「おわった！」で ファンファーレ。おなじ もくの これまでで いちばん はやいと 🏆 じこベスト（30びょう いじょうの きろくだけ くらべる）
- きろくは さいしん 60けん まで ほぞん、15けん ひょうじ

## おとが きこえない とき

- iPhone の マナーモード（消音スイッチ）でも なるように、むおんの `<audio>` を ながして「メディアの おと」に きりかえている
  （`navigator.audioSession.type = 'playback'` も せってい）。それでも ならない ときは 本体の 音量ボタンで おおきく する
- ドンの ときに よみあげを とめない（iPhone で とめると その しゅんかんの おとが きえることが ある）
- コンプレッサー＋メイクアップ＋リミッターで おとを おおきく している

## 30びょうは とめられない ロック

あそびで スタート → とめる を くりかえさないように、**ドンから 30びょうは「やめる」「おわった！」「とじる」を おせない**
（ボタンに「🔒 あと ◯びょう」と でる）。「いちに ついて」「よーい」の あいだも おせない。
ページを よみなおしても ロックは つづく（`lockUntil` を localStorage に ほぞん）。タイマーを つかわない ときも おなじ。

## おわったら あおちゃんを ほめる（ランダム）

「おわった！」を おすと、まいかい ちがう ことばで あおちゃんを ほめる（🗣️こえ オンなら よみあげる）。
- ほめことば 45しゅるい＋ じょうけんつき（もくの なまえ・かかった じかん・あさ／よる・きょう なんかいめ）
- じこベストの ときは とくべつな ほめことば と 🏆
- さいきん でた 12こは でにくく する（`praiseHist`）
- スタンプ（💮🏅👑🌟🥇💯 など）・ファンファーレ（5しゅるい）・えんしゅつ（かみふぶき／はなび／ばくちく／ほし／ハート）も ランダム
