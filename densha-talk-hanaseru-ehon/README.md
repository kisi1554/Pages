# でんしゃトーク はなせる えほん 🎤📖

`densha-talk` の でんしゃキャラクターが 登場する、**こえで こたえながら 読みすすめる 絵本**です。
BGM・効果音・キャラクターの 読み上げ声つき。全12ページ。

`index.html` をブラウザで開くだけで あそべます(ビルドもサーバーも不要)。
絵も 音も 声も、すべて 端末の中で 作っています(画像ファイル・音源ファイルは 0個)。
外部のサーバーへ 送るデータは ありません(音声認識だけは ブラウザの機能に まかせます。
くわしくは いちばん下の「おうちの方へ」)。

## ふつうの絵本との ちがい

ページごとに キャラクターが **子どもに 質問します**。
マイクに 答えると、その答えに 合わせて 返事が かわり、つぎのページへ すすみます。

| ページ | ばめん | きかれること |
| --- | --- | --- |
| 1 | あさの えき(やまのてん) | **なまえ** を おしえる → 以降ずっと 名前で 呼ばれる |
| 2 | きっぷうりば(ぎんじろう) | **いきさき** を えらぶ(うみ / やま / ゆめのくに) |
| 3 | ホーム(けいきゅん) | 「**しゅっぱつ しんこう!**」と かけ声を かける |
| 4 | しゃない(まるこ) | でんしゃは **なんりょう**?(3 / 6 / 10 どれでも 正解) |
| 5 | ふみきり(むさしくん) | カンカンが なったら **とまる? わたる?** |
| 6 | のりかえ駅(うえとうくん) | いきさきは **1ばんせん? 2ばんせん?** |
| 7 | トンネル(りんかくん・ぶるくん) | まっくら…… **こわい? へいき?** |
| 8 | しゃない(みやちゃん) | **しゃしょうさん ごっこ**「つぎは、ゆめがおか です」 |
| 9 | しゃそう(とうかいくん) | まどから **なにが みえる?**(なんと答えてもOK) |
| 10 | とうちゃく | みんなで「**ばんざーい!**」 |
| 11 | おわかれ(4人集合) | 「**ありがとう**」を つたえる |
| 12 | よるの しゃこ(でんちゃん) | 「**おやすみ**」の あいさつ |

- **2ページめの こたえで おはなしが 分かれます。** うみ / やま / ゆめのくに で
  10〜11ページめの 絵・登場キャラクター・セリフが かわります。
- こたえられた ことは **バッジ**になり、さいごに 「きねん きっぷ」に まとまります。
- 声が うまく 聞きとれなくても、**2回で 先へ すすみます**(こまらせない)。
  「⏭ とばす」で いつでも 先へ いけます。

## こえが つかえない ときも あそべます

3つの こたえかたが つねに ならんでいます。

1. 🎤 **はなす** — 音声認識(Web Speech API)
2. **えらぶボタン** — 字が読めなくても タップだけで OK
3. **もじで こたえる** — キーボード入力

`https://` か `localhost` で開くと マイクが つかえます。
`file://` で開いた ときや、マイクを つかえない ブラウザでは、
自動で ボタン・文字入力の 案内に きりかわります。

## おと 🎵

音源ファイルは 1つも つかっていません。すべて **Web Audio API で その場で 合成**しています。

- **BGM**: ばめんに あわせて 5種類(あさ / はしる / トンネル / うみ / よる)。
  和音・ベース・メロディを その場で 鳴らしています。メロディは ペンタトニックから
  えらぶので、毎回 ちがう ながれでも はずれません。
  読み上げの あいだは 自動で 音量が 下がります。
- **こうかおん**: はっしゃベル・ドア・ふみきりの カンカン・ピンポン・はくしゅ・きらきら。
- **はしる おと**: 走行中のページでは「ガタン ゴトン」が ずっと 鳴ります。
- **こえ**: キャラクターごとに 高さ(pitch)と 速さ(rate)が ちがいます。
  設定は `densha-talk/knowledge.js` の `CHARACTERS` に そろえてあります。

BGM と こえは、タイトル画面と 上のバー(🎵 / 🔊)から いつでも オン・オフできます。

## おはなしを ふやす・なおす

`scenes.js` の `SCENES` に 1つ オブジェクトを 足すだけで ページが 増えます。

```js
{
  id: 'atarashii-page',
  bg: 'platformDay',        // art.js の BG から えらぶ
  bgm: 'run',               // morning / run / tunnel / sea / night
  run: 'slow',              // ガタンゴトンを ならす(いらなければ 消す)
  sfx: 'bell',              // ページを ひらいた ときの こうかおん
  cast: [{ id: 'maruko', x: 0.5, s: 1.25, emo: 'smile' }],
  narr: 'ちのぶん。',
  line: { who: 'maruko', text: 'セリフ' },
  ask: {
    text: 'しつもん',
    hint: 'こたえかたの ヒント',
    kind: 'pick',
    options: [
      { key: 'a', label: 'ボタンの もじ', words: ['きこえたら あたり', 'べつの いいかた'],
        reply: 'へんじ', emo: 'proud', sfx: 'ok', badge: 'バッジの なまえ' },
    ],
    miss: '1回 はずれた ときの ことば',
    give: '2回 はずれたら みとめて すすむ ときの ことば',
  },
}
```

- `{name}`(こどもの なまえ)、`{destWord}`(いきさき)、`{answer}`(こどもが 言ったこと)は
  文の 中で つかえます。
- ひょうじょうは `smile` / `star` / `sleepy` / `wink` / `surprise` / `proud` / `think` の 7種類。
- はいけいは `art.js` の `Art.BG` に 足せます(`paint()` で SVG を かえし、`groundY` で
  キャラクターの 立つ 高さを きめる)。

## おうちの方へ

- 音が出ます。はじめに 端末の音量を たしかめてください。
- マイクの 許可を 1回 きかれます。**声のデータは どこにも 送られません**
  (音声認識はブラウザの機能を使います。ブラウザによっては ブラウザ側の 処理で
  サーバーを 経由することがあります)。
- 名前・いきさき・バッジ・つづきの ページは、その端末の `localStorage` にだけ 保存されます。
