# ことわざ どうじょう 🐒

小学校 低学年（アニメで たのしむ）〜 高学年・中学受験（クイズ）むけ。
ことわざ を「ことば どおり」に アニメで 見て わらって、そのあと ほんとうの いみ を おぼえる。

公開URL: https://kisi1554.github.io/Pages/kotowaza-dojo/

## あそびかた

| モード | むずかしさ | なにを する |
| --- | --- | --- |
| ことば どおり げきじょう | ★ | 30この ことわざ から えらぶと、ことば どおり の ばめん が SVG アニメで おきる（さる が 木から すべりおちる、ねこ が こばんを ふしぎそうに 見る、ちり が つもって 山に なる など）。「ほんとうの いみは？」で いみ・れいぶん・由来 を 見て はんこ |
| いみ あて | ★★ | 4択。⚠️ まちがえやすい ことば は、よく ある まちがった いみ も えらびに 入れて、どこが ちがうか せつめい する。まちがえた ものは ノートへ |
| なかま あつめ | ★★ | 8まいの カードから「にた いみ」「はんたい の いみ」の 2まいを つなぐ。1ボード 4ペア × 3ボード |
| □に 入る ことば | ★★〜★★★ | 「□の耳に念仏」→ 馬。ステージ: いきもの／かず／からだ の 慣用句（目・耳・口・手・足・首・腹 など）／ごちゃまぜ。いみ が ヒント |
| つかって みよう | ★★★ | れいぶん の『？』に いちばん あう ことわざ を えらぶ（受験 の 文脈 問題 ふう） |
| まちがい ノート | | まちがえた ことば と 回数。ふくしゅう で せいかい すると けえる |
| ことわざ ずかん | | ことわざ／故事成語／慣用句／まちがえやすい ことば。おぼえた ものに「おぼえた」はんこ。にた いみ・はんたい は タップで とべる |

- レベル（低学年／高学年／受験 よく でる）で 出る ことば が かわる。高学年・受験 では バーの「字」で ふりがな オン/オフ。
- 音（ぽこっ・和太鼓 ふう の せいかい・はんこ ぺたっ・アニメ の こうかおん）は WebAudio の 合成。🔊 で オン/オフ。
- しんちょく・ノート・ずかん・せってい は localStorage（`kotowaza-dojo-v1`）。

## データ（`data.js`）

| しゅるい | かず |
| --- | --- |
| ことわざ | 111 |
| 故事成語 | 30 |
| 慣用句 | 69（からだ の 慣用句 46） |
| まちがえやすい ことば | 10 |

- 1こ ずつ: ことば（漢字＋ふりがな）、よみ、子ども むけ の いみ、れいぶん、レベル。
  にた いみ（`SYN`）・はんたい（`ANT`）は べつの 表で まとめて 持つ。
- いみ は 国語辞典 の いみ を 子ども むけ に 言いかえた もの。
  ふたつ いみ が ある もの（犬も歩けば棒に当たる・鉄は熱いうちに打て）は 両方 書く。
- まちがえやすい もの（`miss` / `why`）19こ: 情けは人のためならず、気が置けない、役不足、流れに棹さす、確信犯、
  敷居が高い、煮詰まる、姑息、他山の石、枯れ木も山の賑わい、一姫二太郎、檄を飛ばす、失笑、潮時、破天荒、
  おもむろに、世間ずれ、天地無用、浮き足立つ。
- 由来（`yu`）は 出どころ が はっきり して いる もの だけ（推敲・蛇足・矛盾・漁夫の利・塞翁が馬 など）。
  あいまい な 由来 は 書かない。
- `NEAR` は いみ が ちかい ことば の なかま。クイズ の まちがい えらび に いっしょに 出さない ために つかう。
- □ の えらび は `BLANK_POOL` から。入れると べつの 慣用句 に なって しまう もの（目が高い ⇔ 鼻が高い など）は
  じどう で はずし、辞書に ある べつの 言いかた（腹をくくる ⇔ 首をくくる など）は `nx` で はずす。
