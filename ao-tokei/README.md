# 青ちゃんの とけい

5さいの あおちゃん専用の **ストップウォッチ** と **タイマー**、そして **とけいの よみかたを まなぶ** モード。
ブラウザだけで うごきます（インストール不要・外部ライブラリなし）。

## ストップウォッチ ⏱️

- 「スタート」「ストップ」の 大きな ボタン 1つで うごかす
- まるい とけいの まわりを 🐳 が 1ぷんで 1しゅう する
- 1ぷん たつごとに おしらせの おと
- ストップした じかんは「きろく」に のこる（さいしんの 5こ）

## タイマー ⏳

- えで えらべる じかん: 🐣10びょう / 🐰30びょう / 🦊1ぷん / 🍜3ぷん / 🪥5ぷん / 🧸10ぷん
- ＋1ぷん・−1ぷん・＋10びょう・−10びょう で こまかく あわせられる（10びょう〜60ぷん）
- のこりは あおい まるが へっていく（はんぶんを きると きいろ、さいごは あか）
- のこり 5びょうから ピッ ピッ と カウントダウン
- おわると アラーム＋ほしが ふる。「わかった」を おすまで ならす（さいだい やく30びょう）
- 「ちょっと まって」で いちじ ていし できる

- うごいている あいだは「○じ○ふんに おわるよ」と おわる じかんを とけいの ことばで おしえる

## とけいを まなぼう 🕰️

| メニュー | できること |
| --- | --- |
| 🕰️ いま なんじ？ | ほんとうの じかんの アナログ とけい（びょうしん つき）＋デジタル。「ひるの 12じ54ぷん」と ことばで ひょうじ・よみあげ。「つぎは 🍪おやつ まで あと 2じかん6ぷん」 |
| ✋ はりを うごかそう | はりを ゆびで まわせる とけい。ながい はりを まわすと みじかい はりも いっしょに すすむ。±5ふん・±1じかん、「⏩1じかん すすめる」で ながい はり1しゅう＝1じかん を みせる |
| ❓ とけい クイズ | とけいを みて 3たくから こたえる。レベル: ちょうど／はん／5ふん／1ぷん。まちがいの せんたくしは よくある まちがい（みじかい はりの よみまちがい、はりの とりちがえ、「3」を 3ぷんと よむ など）から つくる |
| 🎯 はりを あわせよう | 「3じはん に してね」→ はりを うごかして「できた！」。どちらの はりが ちがうか おしえる |
| 🌞 あおちゃんの いちにち | おきる・ごはん・ようちえん・おふろ・ねる などの じかんを とけいで みる。±5ふんで あおちゃんの じかんに かえられる（ほぞん） |
| 💡 とけいの ひみつ | みじかい はり＝なんじ、ながい はり＝なんぷん、すうじ1つ＝5ふん、1しゅう＝1じかん、6で「はん」など |
| 📒 シールちょう | クイズを 5もん さいごまで やると シールが 1まい（ぜんぶで 30しゅ） |

- 💡ヒント: みじかい はりが いる「すうじと すうじの あいだ」を いろで しめし、ことばで よみかたを せつめい
- 🔢「ふんの すうじ」（0・5・10…55）は ひょうじ／ひひょうじ を きりかえ（なれてきたら けして チャレンジ）
- 🔴 みじかい はり ＝ あか、🔵 ながい はり ＝ あお で いろわけ
- 1・3・4・6・8・10 は「ぷん」、2・5・7・9 は「ふん」と ただしく よみわける

## おとを えらぼう 🎵

みぎうえの 🎵 で ひらく。おすと その おとが ためしに なり、えらんだ おとは ほぞんされる。

「はじめの おとに もどす」で ぜんぶ もとどおり。

## ファイル

- `index.html` … ストップウォッチ・タイマー・タブ
- `learn.js` / `learn.css` … とけいを まなぼう
- `sounds.js` / `sounds.css` … おとの しゅるい（WebAudio で ごうせい）と おとを えらぶ がめん

## おうちの方へ

- 音は WebAudio の合成音のみ。右上の 🔊 で オン/オフ。時刻の読み上げはブラウザの音声合成（speechSynthesis）で、🔊 オフのときは読み上げません。
- 動いている間は画面が暗くならないようにします（Wake Lock 対応ブラウザのみ）。
- 時刻ベースで計測するので、別のタブを見ていてもずれません。
- 設定・記録・途中の状態は localStorage に保存。
