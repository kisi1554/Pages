# 青ちゃんの とけい

5さいの あおちゃん専用の **ストップウォッチ** と **タイマー**。
ブラウザだけで うごきます（インストール不要・外部ライブラリなし）。

## ストップウォッチ ⏱️

- 「スタート」「ストップ」の 大きな ボタン 1つで うごかす
- まるい とけいの まわりを 🐳 が 1ぷんで 1しゅう する
- 1ぷん たつごとに おしらせの おと
- ストップした じかんは「きろく」に のこる（さいしんの 5こ）

## タイマー ⏳

- えで えらべる じかん: 🐣10びょう / 🐰30びょう / 🦊1ぷん / 🍜3ぷん / 🪥5ぷん / 🧸10ぷん
- ＋1ぷん・−1ぷん・＋10びょう・−10びょう で こまかく あわせられる（10びょう〜60ぷん）
- のこりは あおい まるが へっていく（はんぶんを きると きいろ、さいごは あか）
- のこり 5びょうから ピッ ピッ と カウントダウン
- おわると アラーム＋ほしが ふる。「わかった」を おすまで ならす（さいだい やく30びょう）
- 「ちょっと まって」で いちじ ていし できる

## おうちの方へ

- 音は WebAudio の合成音のみ。右上の 🔊 で オン/オフ。
- 動いている間は画面が暗くならないようにします（Wake Lock 対応ブラウザのみ）。
- 時刻ベースで計測するので、別のタブを見ていてもずれません。
- 設定・記録・途中の状態は localStorage に保存。
