# リズムで たしざん 🥁

ドン・パンのリズムにのせて、ひとけたの たし算を九九のように「うたって」覚えるアプリ。

公開URL: https://kisi1554.github.io/Pages/rhythm-tashizan/

## あそびかた

1. 「〇の だん」をえらぶ（`3の だん` なら 3＋1 〜 3＋9）。🎲「ぜんぶ まぜて」もある。
   - **➕ たす１・２・３・４ シリーズ** … うしろの かずを そろえた れんしゅう
     （`たす 2` なら 1＋2 〜 9＋2）。★3で たす1 → たす2 → たす3 → たす4 と すすむ。
   - **✨ とくべつ：🔟 10の ともだち** … 1＋9 〜 9＋1。答えはいつも10なので、
     かくす／クイズでは **うしろの かず** を「？」にする（`3＋？＝10`）。
     ●は まえの かずだけ出し、10のわくの あいている数が答えになる。
2. **🎵 うたって おぼえる** … 1行＝8拍。
   `さん(ドン) たす(チッ) よん(ドン) は(チッ) なな〜(ドン) ・ パン パン` のリズムで、
   式・ことば・テンフレーム（10のまとまり）の●が拍にあわせて出てくる。
   - **👏 パン！** ボタンを パンパンに あわせて たたくと「ぴったり！（±0.07秒）」「いいね！（±0.15秒）」。
     結果画面に たたけた回数が出る。
3. **🙈 こたえを かくして うたう** … 答えが「？」になり、パンパンのところで答え合わせ。
4. **🥁 リズム クイズ** … 1問＝12拍。式がリズムで出たあと、3つの答えから選んでタップ。
   - **🎤 こえで こたえる**（だんメニューで オン、音声認識に対応したブラウザだけ）…
     「なな」「7」「じゅういち」などを聞きとって答えにする。ボタンでも答えられる。
     問題の読み上げ（「たす」を含む）は答えとして使わない。
   - 拍ぴったりでタップすると「🎯 リズム ぴったり！」
   - 時間切れになったら、つぎの行で「🔁 もういちど うたおう」と正しい答えを歌ってから次へ。
   - 1回目で正解した数で ★1〜3。★3で次の だんへ進める。

## しくみ

- 音は WebAudio の合成音（キック・ハイハット・クラップ・メロディ）。🔊でオン/オフ。
- 読み上げは Web Speech API（対応ブラウザのみ）。🗣️でオン/オフ。なくても遊べる。
- リズムは AudioContext の時刻で先読みスケジュールし、表示も同じ時刻に合わせている。
- はやさは 1〜100 の100段階（スライダーと －／＋ ボタン）。BPM ＝ 40 ＋ はやさ × 1.4（1→約41、100→180）。
  🐢ゆっくり＝26（約76）／🐇ふつう＝40（96）／🚀はやい＝57（約120）のボタンで すぐ切りかえられる。
- 🎛️ おとの せってい
  - 🥁 ビート：ドンパン／マーチ／ラップ／わだいこ（どれも さいごの2拍は「パン パン」）
  - 🎵 メロディ：ドミソ／ドレミ／きらきら／わらべ（「さん たす よん は なな」の5音）
  - 🗣️ こえの はやさ（×0.75／×1／×1.3）・たかさ（0.8／1.2／1.7）
  - 「▶ ためしに きく」で 1行ぶん ならせる
- 進捗（だんごとの★・うたったしるし🎵・設定）は localStorage `rhythm-tashizan-v1`。
