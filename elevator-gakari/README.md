## あそびかた

| モード | すること |
| --- | --- |
| 🧑‍✈️ おしごと | ①「3かいで うさぎさんが よんでいるよ」→ 3 を おして むかえに いく。<br>②「2かい うえに いきたいな」→ **3 + 2 = ?** の こたえの かいを おす。<br>あっていれば ⭐。ちがう かいに つくと、あんないばんに「+1 +2…」の ヒントが でる |
| 🎈 じゆう | すきな かいへ いくだけ。うえに いくと「2 + 3 = 5」と しきが でる。いくつも よやく できる |

- **◀▶ ひらく / ▶◀ しめる**: ドアは じかんが たつと かってに しまる。しめるを おすと すぐ しゅっぱつ。しまりかけを ひらくで あけなおせる。
- **💡**: いまの かいから かぞえる ヒント（あんないばん＝たての すうじの はしご）。
- **レベル**: ★ 5かいだて（こたえ 5まで）／★★ 10かいだて（10まで）／★★★ 20かいだて（くりあがり）。
- **🔊**: おと（モーター・ドア・チャイム・アナウンス）の オン/オフ。

## リアルさの くふう

- ドアの まどから、とおりすぎる かいと シャフトの かべが ながれて みえる
- かそく・げんそくで かごが すこし ゆれる。モーターおんは はやさで たかさが かわる
- かいすう ひょうじ（▲▼ つき）、とうちゃく チャイム、「うえへ まいります」「3かいです」の アナウンス（ブラウザの よみあげ）
- うえに うごく あいだ「+1、+2、+3…」と かぞえが でる（かぞえたしの れんしゅう）
