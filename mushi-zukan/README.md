# むしずかん 🔍

**小学生むけ**の むしの ずかんアプリです。`index.html` をブラウザで開くだけで あそべます
（ビルド・サーバー・外部ライブラリ なし）。

まずは **セミの なかま（6しゅるい）** と **カマキリの なかま（4しゅるい）** から。

## できること

| ページ | なにが わかる |
| --- | --- |
| 🏠 ホーム | なかまを えらぶ。みつけた かず・きょうの まめちしき |
| 🌿 なかまの ページ | しゅるいの いちらん、からだの ひみつ、いっしょう（たまご → ようちゅう → せいちゅう） |
| 🐛 しゅるいの ページ | え・大きさ（ものさし）・みられる月・すむところ・たべもの・とくちょう・まめちしき |
| 🔍 ここが めじるし！ | 絵の上の 赤い ばんごうで、しゅるいを みわける ポイントを しめす |
| 💬 おはなし | むし ひとりひとりが あいしょうつきの キャラクター。ボタン・文字・🎤こえ で はなしかけられる |
| 🔊 なきごえ | セミ 6しゅるいの なきごえを WebAudio で その場で 合成（音声ファイルなし） |
| 🖐 みつけた！ | ほんものを みつけたら タップ。ホームの メーターが ふえる |
| ❓ むしクイズ | え・なきごえ・大きさくらべ・なかまの ひみつ から 10もん。じこベストを ほぞん |

- 文字は ひらがな中心。漢字には ふりがな（`<ruby>`）。
- 🔊 ボタンで 音の オン/オフ（オフのときは なきごえクイズが でません）。
- 進捗（みつけた むし・じこベスト・音の設定）は localStorage に保存。

## おはなしの しくみ

- インターネットの AI は つかわず、`talk.js` が キーワード（なまえ・たべもの・すみか・なきごえ・めじるし・てき・かいかた など
  16しゅるい）で ききたい ことを みわけ、`data.js` の データと `chara.js` の セリフで こたえる。
- キャラの くちぐせ（`tail`）と いいかえ（`rep`、たとえば「だよ」→「やで」）で、きまった いいかたの こたえも その むしらしく なる。
- ほかの むしの なまえを いうと しょうかいして、「〇〇と はなす」ボタンが でる。
- こたえは ブラウザの よみあげで、キャラごとに こえの 高さ・はやさを かえて よむ（🔊 オフで とまる）。
- はなすほど「なかよし」の ハートが ふえる（localStorage に保存）。
- 🎤 は ブラウザの 音声認識（つかえる ブラウザだけ ボタンが でる）。

## 絵

`art.js` が SVG を その場で くみたてる（画像ファイルなし）。

- **セミ**: せなかから みた すがた。ふくがん・たんがん3つ・前胸の えり・中胸の X もよう・はねの みゃく（8つの 先たんの へや）を かく。
  しゅるいごとに もよう（`type`）・はねの タイプ（すきとおり / 茶色 / まだら）・からだの はば と ながさ を かえる。
- **カマキリ**: よこから みた、むねを もちあげた ポーズ。にせの ひとみ・トゲの ある かま・あみめの はね。
  つけねの いろ・おなかの はば・白い 点・黄色い つぶ・黒白の もよう・うしろばねの いろ で かきわける。
- `data.js` の `marks` に「めじるし」の いちと せつめいを かく（絵の上に ばんごうで でる）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の わく |
| `data.js` | なかま（`GROUPS`）・しゅるい（`BUGS`、めじるし `marks` つき）・クイズ（`FACTS`）の データ |
| `chara.js` | キャラクター（あいしょう・くちぐせ・こえ・セリフ） |
| `talk.js` | おしゃべりの あたま（キーワードで みわけて こたえる） |
| `art.js` | むしの え（SVG を パラメータから くみたてる） |
| `audio.js` | なきごえ と こうかおん（`semi-tanken` と おなじ 合成方法） |
| `app.js` | 画面の きりかえ（`#/`, `#/g/<なかま>`, `#/b/<しゅるい>`, `#/t/<しゅるい>` おはなし, `#/quiz`） |
| `style.css` | 見た目 |

## なかまを ふやすには

1. `data.js` の `GROUPS` に なかまを 1つ たす（名前・色・いっしょう・からだの ひみつ）
2. `BUGS` に しゅるいを たす（`group` に なかまの id、`marks` に めじるし）
3. `chara.js` に キャラクターを たす（あいしょう・くちぐせ・セリフ）
4. え は `art.js` に `kind` を 1つ たして かく
5. `COMING`（これから ふえる なかま）から けす
