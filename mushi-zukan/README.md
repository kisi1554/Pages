# むしずかん 🔍

**小学生むけ**の むしの ずかんアプリです。`index.html` をブラウザで開くだけで あそべます
（ビルド・サーバー・外部ライブラリ なし）。

まずは **セミの なかま（6しゅるい）** と **カマキリの なかま（4しゅるい）** から。

## できること

| ページ | なにが わかる |
| --- | --- |
| 🏠 ホーム | なかまを えらぶ。みつけた かず・きょうの まめちしき |
| 🌿 なかまの ページ | しゅるいの いちらん、からだの ひみつ、いっしょう（たまご → ようちゅう → せいちゅう） |
| 🐛 しゅるいの ページ | え・大きさ（ものさし）・みられる月・すむところ・たべもの・とくちょう・まめちしき |
| 🔊 なきごえ | セミ 6しゅるいの なきごえを WebAudio で その場で 合成（音声ファイルなし） |
| 🖐 みつけた！ | ほんものを みつけたら タップ。ホームの メーターが ふえる |
| ❓ むしクイズ | え・なきごえ・大きさくらべ・なかまの ひみつ から 10もん。じこベストを ほぞん |

- 文字は ひらがな中心。漢字には ふりがな（`<ruby>`）。
- 🔊 ボタンで 音の オン/オフ（オフのときは なきごえクイズが でません）。
- 進捗（みつけた むし・じこベスト・音の設定）は localStorage に保存。

## しゅるい

- **セミ**: アブラゼミ / ミンミンゼミ / ニイニイゼミ / ツクツクボウシ / ヒグラシ / クマゼミ
- **カマキリ**: オオカマキリ / チョウセンカマキリ / ハラビロカマキリ / コカマキリ

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の わく |
| `data.js` | なかま（`GROUPS`）・しゅるい（`BUGS`）・クイズ（`FACTS`）の データ |
| `art.js` | むしの え（SVG を パラメータから くみたてる） |
| `audio.js` | なきごえ と こうかおん（`semi-tanken` と おなじ 合成方法） |
| `app.js` | 画面の きりかえ（`#/`, `#/g/<なかま>`, `#/b/<しゅるい>`, `#/quiz`） |
| `style.css` | 見た目 |

## なかまを ふやすには

1. `data.js` の `GROUPS` に なかまを 1つ たす（名前・色・いっしょう・からだの ひみつ）
2. `BUGS` に しゅるいを たす（`group` に なかまの id）
3. え は `art.js` に `kind` を 1つ たして かく
4. `COMING`（これから ふえる なかま）から けす
