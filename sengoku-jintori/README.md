# なかぬなら てんか とり 🐦

**ホトトギスが なかない… 3にんは どうする？ えらんだ ぶしょうで にほんを 1つの いろに しよう！**
10本シリーズ「じだい たんけん」の あづち ももやま じだい（せんごく）編（5才〜）。あそびの 型は「じんとり ボード」。
`index.html` をブラウザで開くだけで あそべます（外部ライブラリ・CDN なし）。

公開URL: https://kisi1554.github.io/Pages/sengoku-jintori/

## あそびかた（1回 1〜3分）

1. **ホトトギスの がめん**: 3にんを タップすると はんのうが みられる。
   - のぶなが「おこるぞ！ ぷんぷん」（ホトトギスは びっくり）
   - ひでよし「くふうして なかせよう」→ おどったら「キョッ キョ キョキョキョ！」
   - いえやす「なくまで まとう」→ まちすぎて ねてしまう。その あいだに ホトトギスが なく
2. 「この ひとで じんとり」で スタート。にほんの かたちの 27マス。
   ひかって いる（じぶんの いろの となりの）マスを タップして ぬる。すこし ずれても いちばん ちかい マスを とる。
3. ぶしょうの わざ
   - **のぶなが**: 1ばんに 2マス
   - **ひでよし**: あいて（あお）の マスを とると、となりの あいての マスも なかまに
   - **いえやす**: ⏳まつ で ちから ⭐ が たまり、つぎに 1＋⭐ マス とれる。⭐3 で さらに まつと ねてしまう（わらい）
4. あいて（コンピュータ）は 1ばんに 1マス、まだ だれの ものでもない マスだけ とる（じぶんの マスは とられない）。
5. イベント マス: ⛵ てっぽうが つたわる（つぎの ばん +1）／🏮 らくいち らくざ（まわりが なかまに）／🏯 おおさかじょう（まわりの あいても なかまに）。
6. はんぶん とると ひとやすみ「ほかほか ぞうり」（※いいつたえ と ひょうじ）。
7. ぜんぶ 1色で「てんか とういつ！」→ 3にんを じゅんばんに ならべる（まちがえると ヒント、2かいめは てんか もちの うた）→ けっか ＋「つぎは えど じだい」。

たたかいは マスの 色が かわる だけで あらわす（ぶきや きずの 絵は ださない）。

## まなび カード（8まい）

おだ のぶなが／とよとみ ひでよし／とくがわ いえやす／てっぽうが つたわる／らくいち らくざ／おおさかじょう／ホトトギスの たとえばなし／てんか もち の うた。
それぞれ 保護者むけの 説明（年号など）を 小さく そえている。
