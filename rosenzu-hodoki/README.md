# こんがらがり ろせんず 🧶

**せんの ならびかたは かわっても「どの えきと どの えきが つながっているか」は かわらない** ことに きづく
ろせんずパズル（5さい〜、トポロジーの はじめの 一歩）。

`index.html` を ひらくだけで うごく（外部ライブラリ・CDN なし。おとは WebAudio の 合成音、🔊 で オン/オフ）。

## あそびかた

1. ねこの ちずやさんが けいとだまで あそんでいたら、ろせんずが こんがらがった！
2. えき（まる）を ゆびで ドラッグ。せんは えきに くっついたまま のびちぢみする。
3. こうさ（ばってん）は あかい ✕ が ちかちか。のこりの かずは いつも うえに でる。
4. ばってん 0 で クリア →「ぷはーっ！」→ でんしゃが はしる → ねこが「みやすーい！」と ごろごろ。
