# ミツバチの いちにち 🐝

**はたらきバチに なって 1にちを すごし、ミツバチの 社会と 受粉を 体験する** アプリです。
年長〜小学生（むし ずき）むけ。`index.html` を ひらく だけで あそべます（外部ライブラリ・CDN なし。ハチ・花・実・巣は Canvas に コードで 描画）。

`ari-no-su/`（アリの 巣）・`mushi-zukan/`・`kabuto-sodate/` と 見た目（うえの バー・大きい ボタン・ずかんの カード）を そろえ、
アリと ちがう 点 ── **ダンスで 場所を つたえる** ことと **花との 関係（受粉）** ── を 主役に しています。

## あそびかた

1. **🌼 はなばたけ**（うえから 見た 地図。きた が うえ、まんなかが すばこ）
   - 指で ハチを ドラッグ して 花に とまると 蜜を すう（**みつ ゲージ**、「ちゅー」）。からだに **花粉** が つく。
   - **おなじ しゅるいの べつの 花** へ 行くと 花粉が うつり、3びょう ほどで **実** に なる（いちご・りんご・きゅうり・かぼちゃ・メロン・ブルーベリー・なし・さくらんぼ）。
     ちがう しゅるいの 花粉では 実は ならない（ひとこと で おしえる）。はじめて できた 実は ずかんに のる。
   - 花畑ごとに 蜜の 多さ（★1〜3）が ある。ゲージが いっぱいに なったら すばこへ もどる。
   - 1にちは **あさ（8じ）・おひる（12じ）・ゆうがた（16じ）** の 3かい。たいようの 方位が かわる。
2. **💃 8のじダンス**（いちばんの あそび）
   - 巣の 中の たての 巣板の うえ。**巣板の 真上 ＝ 太陽の 方向**。みぎうえに 外の 地図（太陽の 線・花畑の 線・その あいだの 角度）。
   - 指で **まっすぐ すーっと なぞる ＝ 尻振り走行**。なぞった **むき** が「太陽から 見た 花の 方向」、
     指が 動いていた **時間** が おしりを ふる 時間 ＝ **距離**（1びょう ≒ 1キロ）。
     **とても ちかい（100m 未満）花畑は、ぐるっと まるを かく 円形ダンス**。
   - なぞった あと ハチが その ダンスを 8の字で 2かい くりかえし、なかま 3びきが 外へ 飛ぶ。
     正しい 花畑に 着けば せいこう。むきや 時間が ずれると ちがう 場所へ 行く（「みぎへ 35ど ずれていたよ」「ながすぎて とおくへ」など）。
   - 💡ヒントで 正しい 線を 巣板に うすく 表示。
3. **💃 ダンス クイズ**: なかまの ダンス（8の字 or 円形）を 見て、地図の 3つの 花畑 から 正しい 場所を タップ。5もん。
   まちがいの 選択肢は「むきが ちがう」「距離が ちがう」ように つくる（どちらも ダンスでは 着かない ことを たしかめて から 出す）。
4. **🏠 すの なかの しごと**（日が すすむと 仕事が かわる）
   | 仕事 | アプリでの 日齢 | あそび |
   | --- | --- | --- |
   | 🧹 へやの そうじ | 1〜3にちめ ぐらい | よごれた 部屋を タップ → きれいに なると 女王が 卵を 産みに くる |
   | 🍼 ようちゅうの おせわ | 4〜11にちめ ぐらい | 🍯 を 出している 幼虫に えさ |
   | ⬡ ろうで すづくり | 12〜17にちめ ぐらい | となりに くっつく ように 六角形を つなげる パズル |
   | 🍯 はちみつづくり | 12〜18にちめ ぐらい | 画面を こすって 羽で あおぐ → 水分 20% 前後で ろうの ふた |
   | 🛡️ もんばん | 18〜21にちめ ぐらい | においで なかま（とおす）と よその 巣の ハチ（かえってね）を 見わける |
   | 🌼 はなあつめ | 3しゅうかんめ ぐらい から | はなばたけへ |

   仕事を おえると 日齢が つぎの 仕事の 日まで すすむ。外勤に なった あとは 1にち（3かいの 花あつめ）ごとに 1にち すすむ。
5. **じょおうバチ・オスバチ**: 巣の 中を 歩いている。タップすると ひとこと（女王は 卵を 産む・ロイヤルゼリーで 育つ・何年も 生きる／オスは 針が なく 蜜も あつめない・よその 巣の 女王と 結婚する・目が 大きい）。
6. **📖 ずかん**: はなと み（受粉で できる 野菜・果物）／ミツバチの からだ（番号つき：触角・複眼・はね 4まい・あし 6ぽん・**花粉だんご**・ろうを 出す ところ・針）／
   なかま（はたらきバチ・じょおうバチ・オスバチ・**ニホンミツバチ と セイヨウミツバチ の ちがい**）／しごと／ダンスの しくみ（図）。
7. ホームと ずかんに「**さわったり、おどかしたり しなければ、ほとんど ささない**」を ひとこと。刺される 演出は ない（もんばんも においで 見わけて「かえってね」と 押しかえす だけ）。

進み（日齢・おわった 仕事・できた 実・ダンス/クイズの 回数・音の 設定）は localStorage（`mitsubachi.v1`、読み書きは try/catch）。

### ダンスの 計算（`dance.js`）

- 方位は 北 0°・東 90°・南 180°・西 270° の 時計回り。巣板の 角度は 真上から 時計回り。
- **巣板の 角度 ＝ 花の 方位 − 太陽の 方位**（`danceAngle`）。逆は `flowerAzFromDance`。
- **尻振りの 時間（秒）＝ 距離（km）× 1.0**（`waggleSec` / `distFromWaggle`）。**100m 未満は 円形ダンス**（`isRound`）。
- 太陽の 方位は「6時 ≒ 東、12時 ≒ 南、18時 ≒ 西」で 1時間 15° の 近似（`sunAzimuth`）。
- 指の 線（`analyzeStroke`）: ぐるっと 260° 以上 まわって もとの 近くに もどれば 円形、それ以外は はじめ→おわり の むきと「指が 動いていた 時間」。
- 着地点（`landing`）: ダンスを 方位・距離に もどし、いちばん 近い 花畑（とどく 範囲 = max(140m, 距離×45%)）に 着く。円形ダンスは 巣から 160m 以内を さがす。
- テスト: `node tools/mitsubachi/test-dance.js`（向き・逆計算・時間⇄距離・指の線・3つの 太陽で 正しい ダンスが 正しい 花畑に 着く・ずれると 着かない など 213 項目）

### ブラウザでの 確認

`node tools/mitsubachi/check.js [スクショの 出る フォルダ]`（Playwright・導入済み Chromium）

- 390×844（縦持ち スマホ）と 1024×768（横持ち タブレット）
- はなばたけで ほんとうに ドラッグして 蜜を すい、受粉して 実が できる
- **自動の ダンス**: 太陽 3つ（あさ・おひる・ゆうがた）× 花畑 5つ（近い 花畑＝円形ダンス を ふくむ）で、なかまが **正しい 花畑に 着く**
- 指（マウス）で ダンス: 正しい むき → 着く、90° まちがい → 着かない
- クイズ・巣の 仕事 5つ・ずかん 5タブ、エラー・横はみだし なし

## 正確さ・出典

アプリ内の 説明は 次の 資料で たしかめた（子ども むけに ことばを やさしく している）。数字は「だいたい」で はばを もたせている。

- North Carolina State University Extension「Honey Bee Dance Language」
  https://content.ces.ncsu.edu/honey-bee-dance-language
  — 尻振り走行の 向き（巣板の 鉛直に 対する 角度 ＝ 太陽に 対する 花の 角度）、太陽が 動くと ダンスの 角度も かわる、
  尻振りの 継続時間が 距離の いちばん 確かな 手がかり（ほぼ 比例）、近い とき は 円形ダンス（円形〜移行型〜尻振りダンス は 連続）。
- Wikipedia「Waggle dance」（K. von Frisch の 解読、1秒 ≒ 約1km の 目安、イタリアン種で 円形ダンスは 約10m まで 等の 文献まとめ）
  https://en.wikipedia.org/wiki/Waggle_dance
  — 円形 と 尻振り の 境目は 種・系統で ちがう（数十m〜100m ほど）。ゲームでは 100m と した。1回ごとの ダンスにも ±15° ていどの ばらつきが ある。
- American Bee Journal「Division of Labor in a Colony: Who Does What? Part 2」(2024)
  https://americanbeejournal.mydigitalpublication.com/articles/division-of-labor-in-a-colony-who-does-what-part-2-adulthood-and-old-age
  — 日齢分業: 巣房の 掃除（0〜4日）→ 育児（4〜12日）→ 巣づくり・蜜の 貯蔵/ふたがけ（12〜21日。ろう腺が 最大）→ 門番（いちばん 年上の 内勤、外勤の 直前）→ 外勤（だいたい 20日〜）。
  時期は 群れの 状態で 前後し、門番を しない 個体も いる。
- 農林水産省 畜産局「養蜂について」「花粉交配用 蜜蜂」関連資料
  https://www.maff.go.jp/j/chikusan/gijutu/mitubati/attach/pdf/index-66.pdf
  — いちご などの 施設園芸で ミツバチが 花粉交配に 使われ、良品率が 上がった。ミツバチの 訪花が 足りないと 不稔そう果（いびつな 実）が ふえる。
- 静岡県「ミツバチの 巣別れ」資料 https://www.pref.shizuoka.jp/_res/projects/default_project/_page_/001/027/723/bee-suwakare.pdf
  — 働きバチの 体長 ニホンミツバチ 10〜13mm / セイヨウミツバチ 12〜14mm、群れの 大きさ 数千〜2万 / 2万〜4万。
- 名古屋市「ミツバチについて」 https://www.city.nagoya.jp/kenkofukushi/eisei/1015269/1034848/1015298/1034489/1034408/1015369.html
  — ニホンミツバチは 全体に 黒っぽく、樹洞・壁の すきま・床下などに 巣を つくる。刺激しなければ おとなしい。
- 吉田忠晴「ニホンミツバチと セイヨウミツバチ」ミツバチ科学 18(1)（玉川大学ミツバチ科学研究センター）
  https://tamagawa.repo.nii.ac.jp/record/848/files/18-1_1997_001-008_Yoshida.pdf — 2種の 形態・生態の ちがい。
- 浜松市「はちみつ」（はままつ食のパーク） https://www.city.hamamatsu.shizuoka.jp/foodpark/hamamatsu-foods/honey.html
  — 花の 蜜を ハチの 酵素で 分解し、羽で 風を 送って 水分を とばし（約20%）、ろうで ふたを する。

おもな 事実と アプリでの あつかい:

| 事実 | アプリでは |
| --- | --- |
| 尻振り走行の 向き ＝ 太陽に 対する 花の 方向（巣板の 真上が 太陽） | `danceAngle`。地図カードに 太陽の 線・花の 線・角度の 弧 |
| 尻振りの 時間 ∝ 距離 | 1びょう ≒ 1キロ。指が 動いていた 時間で はかる |
| 近い 餌場は 円形ダンス | 100m 未満は 円形。まるを かくと「すぐ ちかく」 |
| 太陽が 動くと 同じ 花畑でも ダンスの 角度が かわる | あさ・おひる・ゆうがた で 太陽の 方位が かわる |
| 日齢で 仕事が かわる（内勤 → 外勤） | 仕事を おえると 日齢が すすむ。日数は「ぐらい」と 表示 |
| ろうは 腹の 下の ろう腺から。巣房は 六角形 | すづくり パズル・からだの 図 |
| 蜜は 酵素と 羽の 風で 水分が へって はちみつに → ふた | はちみつづくり（水分 % → 20% 前後で ふた） |
| 受粉には 同じ 種の 花粉が いる。いちご は 受粉不足で いびつに | 同じ 種類の 別の 花で 実。りんご・なし・さくらんぼ は 別品種の 花粉が いる ことを ずかんで 説明 |
| 花粉は 後ろ足の 花粉かごで だんごに して はこぶ | 花粉の 色の だんごを 足に つけて 飛ぶ |
| 女王は 1群に 1匹で 産卵、オスは 針が なく 採餌しない | 巣の 中で タップすると ひとこと |
| 刺激しなければ ほとんど 刺さない | ホーム・ずかんに ひとこと。刺される 演出なし |

ゲームとしての 単純化: 地図は 近い ところを 広げた √ スケール（距離の 輪 100m・500m・1km・2km を 表示）。
実が なるまでの 時間（3びょう）、花畑の 蜜の 量、仕事ごとの 回数は あそびやすさ 優先。
