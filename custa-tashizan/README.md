# カスタの たしざん とっくん 🍮🏁

プリンの こ **カスタ**（[カスタと あそぼ](../custa-asobo/) の キャラクター）が、おともだちと たしざんで
かけっこ きょうそう しながら いっしょに せいちょうする アプリ（未就学〜小学1年むけ）。

`index.html` を ブラウザで ひらくだけで あそべます（外部ライブラリ・音声ファイルなし）。

## レベル（くもん算数 2A・A 相当）

| とっくん | ないよう |
| --- | --- |
| 1〜5（2A） | +1（10まで / 20まで）、+2、+3、+1〜+3 まとめ |
| 6〜10（A） | +4 +5、+6 +7、+8 +9、+10、+1〜+10 まとめ（こたえは 20まで） |

- とっくん 2 から、ときどき かんたんな ひきざん（-1〜-3。A まとめは -5 まで、10 いかの かず）が まざる（1かい 3もん まで）
- まえの とっくんで ⭐ を とると つぎが ひらく（せっていで ぜんぶ ひらくことも できる）

## あそびかた

1. とっくんを えらぶ → きょうそうする おともだちを えらぶ
   - 🍓 **モモ**（いちごプリン・ゆっくり） / 🍵 **マッチャ**（まっちゃプリン・ふつう） / 🍫 **ショコ**（チョコプリン・はやい）
2. 「よーい どん！」で 10もんの かけっこ。せいかいすると カスタが 1ます すすむ。おともだちは じぶんの ペースで すすむ
3. まちがえると 💡 ヒント（●の かず）が でる。3かい まちがえると こたえを おしえてくれる
4. さきに ゴールした ほうの かち

- こたえは テンキーで いれる。けたが そろうと じどうで まるつけ
- ⭐ は かち＝1、ノーミス＝2、ノーミスで 1もん 5びょう いない＝3

## いっしょに せいちょう

- **カスタ**：けいけんち（せいかい＋かち・ノーミス ボーナス）で レベルアップ。すこし おおきく なり、
  Lv3 はちまき・Lv5 メダル・Lv7 マント・Lv10 おうかん が つく
- **おともだち**：おともだちの はやさは、その とっくんでの こどもの さいきんの 1もん あたりの じかん × おともだちごとの けいすう。
  かつと おともだちが 5% はやく、まけると 5% ゆっくりに なるので、いつも ちょうど いい しょうぶに なる。
  きょうそうするたびに おともだちの Lv も 1 あがる
