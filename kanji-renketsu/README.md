# かんじ れんけつ（kanji-renketsu）

漢字の **へん（左）と つくり（右）を 電車の車両** にみたてて、ガチャンと連結すると漢字ができるパズル。
へんの名前クイズと、駅名づくり（駅名標を完成させてスタンプ）もある。

- 対象: 年長〜小学3年（漢字を少し知っている でんしゃずきの子）
- 公開URL: https://kisi1554.github.io/Pages/kanji-renketsu/
- 「読み」のアプリ（[かんじすたんしょん](../kanji-station/)・[えきスタンプラリー](../eki-stamp-rally/)・
  [かんじカード](../kanji-card/)・[かんじガチャ](../kanji-gacha/)）とちがい、こちらは **「形のくみたて」** にしぼっている。

## あそびかた

| モード | なかみ |
| --- | --- |
| 🔗 れんけつ パズル | **おだい**：「『校』を つくろう」→ 4〜6両の中から正しい2両を選んで連結。ステージは 1ねんせい → 2ねんせい → 3ねんせい → えきめいの字。<br>**はっけん**：へん3両・つくり4両で つくれる漢字を ぜんぶさがす（答えの数はデータから自動で数え、「のこり N こ」を表示）。ヒントつき |
| 🏷️ へんの なまえ クイズ | 10問。①へんを見て名前を3択 ②名前を聞いて へんをえらぶ ③「さんずいの なかまは どれ？」 ④「この漢字の へんは なに？」 ⑤知らない漢字でも へんの いみ から「なにに かんけい ありそう？」を考える |
| 🚉 えきめいを つくろう | 路線を選ぶと、次の駅の駅名標が出る（漢字はかくれて よみだけ）。1字ずつ へんとつくりを連結（横＝木＋黄、浜＝氵＋兵）。へんとつくりに分けられない字（中・大・山・川…）は「そのまま 1りょう」。駅名がそろうと発車ベル→電車がとうちゃく→スタンプ。終点まで行くと路線クリア |
| 🚌 2かいだて しゃりょう | おまけ。かんむり（上）の車両を あし（下）の車両に のせて漢字をつくる（艹＋化＝花、宀＋子＝字、竹＋合＝答） |

- 車両は **ドラッグ** でも **タップ → タップ** でも連結できる。まちがった組み合わせは連結器がはまらず「ぷしゅー」と もどる（ありえない字は できない）。
- 連結すると 2両が1両の大きな漢字の車両にかわり、漢字・よみ・いみ・例のことば（ふりがなつき・よみあげ）・部首が出る。
- 📖 **ずかん**：つくった漢字が へんごとに ならぶ（さんずいの列、きへんの列…）。列が全部うまると「さんずい マスター」などのバッジ。
- 🎫 **スタンプちょう**：路線ごとの駅名スタンプ（見た目は えきスタンプラリーと そろえている）。
- クイズで まちがえた へんは、あとで間隔をあけて また出る（3 → 5 → 9 → 15問あと。4回つづけて正解で卒業）。

| 上下（2かいだて） | 50字（くさかんむり・うかんむり・たけかんむり・あめかんむり・ひとやね・あなかんむり・はつがしら・あみがしら ／ こころ・れんが・ひとあし・かい・ころも など） |
| 路線（`data-stations.js`） | 14路線 254駅（ブルーライン・グリーンライン・東横線・目黒線・田園都市線・大井町線・池上線・東急多摩川線・世田谷線・東急新横浜線・こどもの国線・相鉄本線・山手線・京浜東北・根岸線）。えきスタンプラリーの路線データから `tools/kanji-renketsu/gen-stations.js` でつくる |

1字 = `'漢字|左|右|部首|よみ|いみ|ことば|学年'`。

- 学年は文部科学省「学年別漢字配当表」（2020年度〜）。1〜3年は かんじガチャの表、4〜6年はチェックの表（字数 202/193/191 も確認）とあわせる。
  かんじすたんしょんは 2020年より前の表なので 城 が6年になっている（こちらは4年）。
- 部首は その字の辞書上の部首。へんと ちがう字もある（和＝口、相＝目、畑＝田、鳴＝鳥、化＝匕、初＝刀、料＝斗、酒＝酉、所＝戸 …）。
- 部品は **1文字で表示できる字だけ**（亻 氵 扌 忄 礻 衤 犭 阝 刂 攵 などの部首形はOK。拡張漢字・部首補助の字は使わない）。
  竹かんむりの ⺮ は入っていないフォントがあるので「竹」で表示する。
  左右どちらかが単独の字にならない漢字（新・数・場・陽・福・緑・練・船・別 など）はデータからはずし、駅名では「そのまま 1りょう」になる。
- 1つの へん と 1つの つくり から できる漢字は1つにきまる（チェックで確認）。

## チェック

```bash
node tools/kanji-renketsu/check.js
```

全字に へん・つくり・部首・よみ・いみ・ことば・学年がそろう／学年が配当表とあう／組み合わせから漢字が1つにきまる／
部品が IPAゴシック（JIS の字）にある／全14路線254駅で駅名が完成できる／おだい・はっけん・2かいだての問題がつくれる。

```bash
node tools/kanji-renketsu/e2e.js [スクショの出力先]
```

Playwright（Chromium）で 390×844 と 1024×768 の両方で、おだい・はっけん・クイズ・駅名（こどもの国線を終点まで）・2かいだて を
自動で1回ずつクリアし、豆腐（□）チェック・はみだしチェック・スクショを とる。

## ファイル

| ファイル | なかみ |
| --- | --- |
| `index.html` | 画面のわく |
| `style.css` | みため（車両の色、駅名標、スタンプ） |
| `data-parts.js` | へん・つくり・漢字のくみたてデータ |
| `data-stations.js` | 路線と駅（自動生成） |
| `train.js` | 車両のSVG描画、置き場（ドラッグ／タップ→タップ）、ガチャン！のアニメ |
| `game.js` | おだい・はっけん・2かいだて・駅名づくり |
| `quiz.js` | へんの なまえ クイズ（まちがえた へんの くりかえし） |
| `app.js` | 画面のきりかえ・きろく（localStorage `kanjiRenketsu.v1`）・ずかん・スタンプちょう |
| `audio.js` | WebAudio の効果音（ガチャン・ぷしゅー・発車ベル・とうちゃくチャイム・スタンプのぽん）と speechSynthesis のよみあげ |

音は WebAudio の合成音だけ。🔊 おと と 🗣️ よみあげ は タイトルで それぞれ オン/オフ できる。
車両を動かす画面は `touch-action: none` で スクロール・ズームしない（共通のズーム対策ブロックも入れている）。
