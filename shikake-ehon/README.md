# まいごの ぼうし ― さわって すすむ しかけ えほん 📖👒

こぐまの「ぽっけ」が、かぜで とばされた あかい ぼうしを おいかける **しかけ えほん**です。
ページの 絵を さわると しかけが うごき、さわらないと すすめない ページも あります。
対象は 未就学〜小学1年。全19ページ（ひとつの 読みかたで 12ページ）。

`index.html` をブラウザで開くだけで あそべます（ビルドもサーバーも不要）。
絵は SVG / Canvas、音は Web Audio で その場で つくっていて、画像・音声ファイルは 0個です。

## ほかの えほん との ちがい

| アプリ | たいけん |
| --- | --- |
| `densha-talk-ehon/` | よみあげ を きく えほん |
| `densha-talk-hanaseru-ehon/` | こえで こたえて すすむ えほん |
| **`shikake-ehon/`（これ）** | **さわる しかけ・分かれ道・かくれもの** で すすむ えほん |

## おはなし

こうえん → おちばの みち → パンやさん → えき → ホーム（ぼうしは でんしゃの やねに！）→
**わかれみち①**「でんしゃで おいかける？ ふねで おいかける？」→ みなと → うみの うえ →
**わかれみち②**「かもめに たのむ？ じぶんで まつ？」→ けつまつ

| けつまつ | とおりかた | おわり |
| --- | --- | --- |
| ① 👒 もどって きた ぼうし | ふね → かもめに たのむ | かもめが ぼうしを とってきて くれる |
| ② 🐣 ひなの おうちに なった ぼうし | でんしゃ → かもめに たのむ | ぼうしは とりの すに。ひなの ために あげる |
| ③ ⭐ よぞらで ひかる ぼうし | じぶんで まつ | ぼうしは ほしの そばで ひかる |

ふねは はやく つくので「まにあう」、でんしゃは ゆうがたに つくので「すに なっていた」、という すじです。
じかんたいは ページごとに 朝 → 昼 → 夕 → 夜 と うつります（うみの ページは きた みちで 変わる）。

## しかけ

| しかけ | ページ |
| --- | --- |
| タップ（はなが ひらく・ことりが とぶ・さかなが はねる…） | ほぼ ぜんぶの ページ |
| なぞる（かぜを おこす） | ふうせんと ぼうしが とぶ／かもめを おうえん |
| めくる | おちばの した／パンの かご／マット／ぼうしの なか |
| ひっぱる | でんしゃが はしりだす／はしが のびる |
| こする | くもった まどの むこうに ぼうし |
| てらす | まっくらな とうだい・いそ（ゆびが かいちゅうでんとう） |
| かたむける／ゆらす | ふねが ゆれて すすむ（DeviceOrientation。iPhone は ボタンで 許可。つかえない ときは よこに スワイプ） |

- しかけの ばしょは うっすら 光ります。**3びょう さわらないと きらきら** の ヒントが でます。
- さわらないと すすめない ページでは「🔒 つぎ」に なり、しかけが おわると「つぎ ▶」が 光ります。
- マイクは つかいません。

## 読みたくなる しくみ

- **かくれねこ「みけ」**: 全19ページの どこかに ちいさな ねこが かくれています。みつけると 🐱 しおりに スタンプ。
- **けつまつ コレクション**: さいごに「みつけた けつまつ 1/3」。ひょうしの「📑 もくじ」から
  わかれみちへ ジャンプできます（みつけた けつまつ にも とべる）。
- **よみかた 2つ**
  - 🔊 **よんで** … speechSynthesis で よみあげ、よんでいる ことばを ハイライト。しかけの 前で とまり、
    しかけが おわると つづきを よみます。
  - 👆 **じぶんで よむ** … よみあげ なし。ことばを タップすると その ことば だけ よみます。
- **しおり**: とちゅうで やめても「🔖 つづき から」で つづきを よめます。
- 🎵 おんがく（オルゴールふうの BGM）と 🗣 よみあげ は べつべつに オン/オフ できます。

しおり・かくれねこ・けつまつ・せってい は その端末の `localStorage` にだけ 保存します。

## ページを ふやす・なおす

`story.js` の `PAGES` に オブジェクトを 1つ 足します。

```js
{
  id: 'p99',
  place: 'ばしょの なまえ',
  time: 'hiru',                       // asa / hiru / hiru2 / yu1 / yu / yugure / yoru
  text: ['ことば は スペース で くぎる。', '[漢字|かんじ] で ふりがな。'],
  hint: 'しかけ の あそびかた',
  after: ['しかけ が おわったら でる ぶん'],
  tease: 'すると…？',
  shikake: { kind: 'flip', target: 'atari' },   // しかけ の しゅるい と せってい
  mike: [x, y, おおきさ],                        // かくれねこ（絵の <!--MIKE--> の いちに はいる）
  next: 'p100',
  draw: (st) => `${Art.sky('hiru')} ... ${M} ...`,
}
```

## たしかめかた

```bash
node tools/shikake-ehon/check.js /tmp/shots
```

Playwright で たて（390×844）と よこ（1024×768）の 両方を 開き、全ページ・全分岐を
自動で めくって 3つの けつまつ に とどくこと、かくれねこ 19ひき を ぜんぶ みつけられることを
たしかめ、スクショを 保存します。
