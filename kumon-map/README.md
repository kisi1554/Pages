# くもん きょうしつ マップ

神奈川県の公文式の教室を地図にのせ、**いちばん近い駅・路線・歩く時間のめやす**がわかるようにしたアプリ。
子ども向け（ひらがな中心・駅名はふりがなつき）。

## つかいかた

| したいこと | やりかた |
| --- | --- |
| 教室を見る | 地図のオレンジの まる をタップ → 教室名・住所・近くの駅（最大3つ）と路線・歩く時間 |
| 駅から探す | 地図の白い まる（駅）をタップ → その駅がいちばん近い教室と、1.2km 以内の教室 |
| 路線で探す | 下の「ろせん」→ 路線をえらぶ → 駅ごとに教室の数。駅をタップで教室一覧 |
| 名前で探す | 「さがす」→ 駅名（ひらがなでも可）・教室名・住所 |
| 市区町村で探す | 「まち」→ 市・区をえらぶ |
| 教室をふやす | 「ふやす」→ CSV を貼りつけ／ファイル選択（おうちの人むけ。この端末の localStorage に保存） |

### ふやす（CSV）の形式

```
なまえ,じゅうしょ,いど,けいど
公文式 ○○教室,神奈川県横浜市西区高島2丁目1-1
○○教室,,35.4658,139.6223
```

- 緯度・経度がなければ住所から国土地理院の住所検索で場所を調べる（ネット接続が必要）。
- 神奈川県のまわり以外の場所は読みこまない。ふやした教室は紫のまるで出る。CSV で書き出し・全部消去ができる。

## データ

- 教室: [ダイヤモンド教育ラボ「公文式（神奈川県）」](https://diamond.jp/educate/brand/kumon/list/kanagawaken/) の一覧
  （教室名・住所）。座標は [国土地理院の住所検索](https://msearch.gsi.go.jp/) でつけた（丁目くらいまでのめやす）。
  公式サイト（kumon.ne.jp）はプログラムからの取得を受けつけていないため。
- 近くの駅: 座標から直線距離で近い順に最大3駅（2.5km 以内）。歩く時間は「直線距離 × 1.3 ÷ 80m/分」のめやす。
- 駅・線路・県境: 国土数値情報 鉄道データ N02-24（国土交通省）、駅名のよみ: Wikidata（`tetsudo-chizucho/data.js` から切りだし）。
- 作りかた: [`tools/kumon-map/README.md`](../tools/kumon-map/README.md)

教室の開設・閉鎖や曜日・時間は変わるので、最新情報は公式サイトで確認すること。
