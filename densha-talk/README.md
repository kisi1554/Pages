# でんしゃトーク 🚃

電車が大好きな子ども(5歳くらい〜)が、電車のキャラクターと**声でおしゃべり**できるアプリです。
路線図と駅名の話題を中心に、駅のクイズ・駅名しりとり・行き方(のりかえ)案内などができます。

`index.html` をブラウザで開くだけで遊べます(ビルドもサーバーも不要)。
GitHub Pages に置けば、そのままスマホやタブレットからも遊べます。

## あそびかた

1. なまえを入れて(入れなくてもOK)、はなす相手の**でんしゃキャラクター**をえらぶ。
2. 下の **🎤 はなす** ボタンをおして話しかける。文字で打つこともできる。
3. まん中のボタン(チップ)をタップするだけでも会話が進む。
4. **🗺️** をおすと路線図が開き、駅をタップするとその駅の話をしてくれる。
5. **🔊** で読み上げのオン/オフ。

## できること

| きくこと | こたえ |
| --- | --- |
| 「しぶやって どんなえき?」 | 読み・名物・とまる路線・となりの駅 |
| 「しぶやから よこはままで」 | 何駅か・どこでのりかえるか(経路さがし) |
| 「〇〇の となりは?」 | 路線ごとのとなりの駅 |
| 「銀座線って なにいろ?」「なんえき ある?」 | 路線の色・駅数・始発と終点 |
| 「のりかえが おおい えきは?」 | 乗り入れ路線数の多い駅ランキング |
| 「クイズ だして」 | となりの駅 / 路線の色 / どの路線か / 終点 / 駅数 / 順番 / 鉄道会社 / 名物なぞなぞ の8種類。**3択** |
| 「えきめい しりとり」 | 駅名だけでしりとり(「ん」で終わったらおしまい)。**3択** |
| 「えきあて」「なぞなぞ」 | 3つのヒントで駅を当てるゲーム |
| 「しゃしょうさん ごっこ」 | 子どもが車掌になって車内アナウンスをする(5問) |
| 「でんしゃは なんで うごくの?」 | パンタグラフ・線路・踏切など、電車のふしぎ28種類 |
| 「なんさい?」「いま なんじ?」 | 路線の開業年から計算した年齢、いまの時刻 |
| 「うたって」「ものまね して」「じまん きかせて」 | 走行音・車内放送・キャラの自慢話 |
| 「たのしい」「かなしい」「けんかした」 | 気持ちに寄りそう返事 |
| 「もういちど いって」 | 直前の返事をくり返す(聞きのがし用) |
| 聞きとれなかったとき | 「もしかして この えき?」と、にた駅名を3つ出して選べる |
| 「侮るって なに?」 | ことばの意味と、電車の場面での使い方 |
| 「ことばクイズ」 | 3択のことばクイズ(意味あて / ことばあて) |
| 「きょうの ことば」 | ことばを1つ、意味と例文つきで紹介 |

そのほか、あいさつ・ありがとう・好きな電車・きょうの出来事・家族・お友だち・
おもちゃ・お誕生日・体調など、25種類の話題に返事をします。
どれにも当てはまらないときは、あいづちを打って25種類の質問から1つ聞き返します。
30秒くらい黙っていると、キャラクターのほうから話しかけてきます。

**同じことを聞いても毎回ちがう返事になります。** あいさつ・あいづち・ほめことば・
別れのことば・はげましは、キャラクターごとに専用のセリフを持っていて、
そこからランダムに選ばれます(ぎんじろうは「ふむ、なるほどのう」、
まるこは「えー! そうなの?」というように)。
下のボタン(チップ)も毎回入れかわります。

## ごいりょくを のばす しくみ 📕

「あからさま」「侮る」「あらかじめ」「案外」「遺憾」「違和感」のような、
少し背伸びしたことばを **110語** 収録しています。
例文はすべて電車・駅の場面なので、好きなものと結びつけて覚えられます。

- **意味を聞ける**: 「侮るって なに?」→ 意味と、電車の場面の例文で答えます。
- **ことばクイズ**: 3択。「『侮る』はどういう意味?」と、
  「『あいてをかるくみること』をなんて言う?」の2方向から出題します。
- **きょうの ことば**: 1語を意味と例文つきで紹介。
- **ふつうの会話の合間に出てくる**: 駅の話をしているあいだにも、
  だいたい**5ターンに1回**くらい「ことばのおまけ」がそっと付きます。
  電車の話が主役なので出しすぎないよう、
  (1)クイズ・しりとり・えきあての最中は入れない、
  (2)返事がすでに長いときは入れない、
  (3)前回から3ターン以上あける、という条件をつけています。
  黙っているときにキャラクターから話しかける場面でも、2回に1回はことばの紹介になります。
- **使えたらほめる**: 子どもが会話の中でそのことばを使うと
  (「案外 すいてたよ」など、動詞の活用形もOK)、キャラクターが気づいてほめ、
  意味をもう一度そえます。
- **ことばちょう(📕ボタン)**: 出会ったことばがたまっていきます。
  タップすればいつでも意味を読み直せます。記録はこの端末に保存されます。
- **むずかしさの切りかえ**: タイトル画面で「やさしい(13語)/ふつう(67語)/ぜんぶ(110語)」
  を選べます。ことばクイズと「きょうの ことば」に出る範囲が変わります。

### ひょうじょう(11種類)

にこにこ / かんがえ中 / びっくり / **ウインク** / **目がハート** / **ガーン(ぶるぶる震える)** /
**ねむねむ(あくび)** / **むっ** / **てへへ(ほっぺ赤く)** / **目がぐるぐる** / **ドヤ顔**

- 場面に合わせて変わります。「だいすき」と言われたら目がハート、
  クイズに正解したらドヤ顔、「ん」で終わってしまったらガーン、
  「ねむい」にはあくび、「ばいばい」にはウインク、というふうに。
- **話しおわったあと、3回に1回くらい、ちらっと別の顔をします**(意味はありません。おまけです)。
- **キャラクターをタップすると顔が変わります**。ぷにっとつぶれる動きつき。
- キャラえらび画面のカードにも、おはなし画面と**まったく同じ顔**が
  そのまま小さく出ます(動きも同じ)。選ぶ前から誰なのか分かります。
絵は画像ファイルではなくCSSで描いているので、増やすのも直すのも `style.css` だけで済みます。

## しゃしょうさん ごっこ 🎫

子どもが**車掌さん**になって、キャラクターの電車に乗せたお客さんへ
車内アナウンスをします。**声で言うのがいちばん楽しい遊び**です。

```
🎫 しゃしょうさん ごっこを しよう! ぼくが でんしゃで、きみが しゃしょうさん だよ
   いまは 山手線の 目白だよ
📢 つぎの えきを あんないして! 「つぎは ○○です」って いってみよう
   ① 高田馬場   ② 品川   ③ 新大久保
```

- お題は4種類 —**つぎの駅の案内 / ドアの案内 / 乗り換えの案内 / ごあいさつ**。
  乗り換え駅にいるときだけ乗り換え案内が出るなど、その場面に合ったものが出ます。
- 案内するたびに電車が1駅ずつ進み、**5問で「しゃしょう めんきょ しょう」**がもらえます。
- 字が読めなくても3択のボタンで参加できます。「わからない」でお手本を教えてくれます。

## ほかの キャラが 乱入します 🎩

たまに(**4ターン以上あけて3割くらい**、12ターン出なければ必ず)、
**別のキャラクターが横から口を挟みます**。だいたい6ターンに1回です。
「**ほかの でんしゃ よんで**」と言えば(下のボタンでも)、いつでも呼べます。
乱入した子のふきだしはその子の色になり、名前が付き、**声も変わります**。
そのあと、いま話している子がツッコミを入れます。

```
🎩 ぎんじろう
   やっほー! やまのてんと なかよく してくれて ありがとう。ぎんじろうです
   もう、とつぜん でてくるんだから!    ← やまのてん
```

**画面のキャラクター表示にも本当に割り込んできます。** 乱入した子が右から
すべりこんできて、いま話している子は左へよけ、びっくり顔になります。
セリフが終わると、そのまま画面の外へ帰っていきます。

遊びの最中(クイズ・しりとり・えきあて・しゃしょうごっこ)には出てこないので、
じゃまになりません。

## 聞きまちがえても大丈夫 🤔

音声認識は子どもの声をよくまちがえます(「しぶや」が「しふや」、
「ひよし」が「ひよ市」など)。そんなときは会話を止めずに、
**にている駅名を3つ出して選べる**ようにしています。

```
👦 しんじく
🚃 🤔 ちょっと きこえにくかった! この どれか かな?
   ① 新宿   ② 新橋   ③ 新木場
```

- ボタンでも「1」と声でも選べます。「どれも ちがう」も選べます。
- しりとり・えきあての最中も同じように出るので、
  聞きまちがいでゲームが止まりません。
- ふつうのおしゃべり(「たのしかった」「わかんない」など)を
  駅名とまちがえないよう、会話中はきびしめ・ゲーム中はゆるめに判定を分けています。

## 3択で答えられます

駅名クイズと駅名しりとりは、**①②③の3択**から選べます。
ボタンをタップしても、「1」「に」「③」と声で言っても、駅名をそのまま言ってもOKです。
まだ字が読めなくても、キャラクターが選択肢を読み上げるので耳だけで遊べます。
(しりとりの3択は、正しい頭文字の駅がかならず1つだけ入っています)

## おうちのかたへ

- **通信は一切しません。** 会話の文も、マイクで話した内容も、どこにも送信されません。
  返事はすべてブラウザの中(`brain.js`)で組み立てています。API キーも不要です。
- 記録されるのは「なまえ」「最後にえらんだキャラ」「音声オン/オフ」だけで、
  保存先はその端末のブラウザ(localStorage)です。
- **マイク**は Web Speech API を使います。Chrome / Edge / Safari で動きます
  (Firefox は音声認識に未対応なので、文字入力でお使いください)。
  マイクを使うにはブラウザの許可が必要です。許可しない場合も、文字入力で全機能が使えます。
- **読み上げ**は端末に入っている日本語音声を使います。音声が入っていない端末では無音になります。
  画面に「浦賀(うらが)」のようにふりがなが出ているところは、読み上げでは
  ふりがなの側だけを読みます(同じことばを2回言わないため。難読駅の読みまちがいも防げます)。
- iOS では、最初に画面を1回タップするまで音が出ない仕様です(キャラ選択のタップで解除されます)。

## ファイル

| ファイル | やくわり |
| --- | --- |
| `index.html` | 画面のかたち |
| `style.css` | 見た目(電車の顔もCSSで描いています) |
| `data.js` | 路線と駅のデータ |
| `knowledge.js` | 駅の索引・のりかえ・経路さがし・路線の色・キャラクター設定 |
| `words.js` | ことばのデータ(意味・電車の例文・むずかしさ)。ここを増やすと語彙が増える |
| `talk.js` | セリフ集(キャラ別の口ぐせ、質問、電車のふしぎ、話題)。ここを増やすと会話が増える |
| `brain.js` | 会話エンジン(意図の判定、返事づくり、クイズ、しりとり、えきあて) |
| `speech.js` | 読み上げ・音声認識・効果音 |
| `app.js` | 画面の組み立てと操作 |
