# アニメ視聴管理（anime-tracker）

おうちの方むけの、アニメの視聴きろくアプリ。クール（放送の季節）ごとの新作一覧から、
作品ごとに **ステータス・★評価・メモ** をつけて管理する。

- 公開URL: https://kisi1554.github.io/Pages/anime-tracker/
- 組み込みクール: 2019年冬〜2026年秋の32クール・約2,200作品（アニメイトタイムズの各期まとめから。再放送を除いた新作）
- 🔥話題: 2026年秋は、セレクトラ「2026年秋アニメ」で検索数が多い注目作として紹介された15作品を強調表示

## できること

| 機能 | 内容 |
| --- | --- |
| クール切り替え | 1クールずつ表示、または「すべてのクール（横断）」 |
| ステータス | 未視聴 / 気になる / 視聴中 / 完走 / 断念 |
| 話題作 | クール定義の `hot` にある作品に 🔥話題 バッジと色付け。「🔥 話題」チップで絞り込み、「話題作を先に」で並び替え |
| ★評価・メモ | ★1〜5（同じ★をもう一度押すと解除）、作品ごとの感想メモ |
| 絞り込み・並び替え | 作品名検索、ステータスのチップで絞り込み、掲載順・作品名順・評価順・ステータス順 |
| 進み具合 | 完走・視聴中の本数とバー |
| データ | JSON の書き出し / 読み込み、自動バックアップ（パソコンの Chrome / Edge のみ）、クール定義 JSON の追加・上書き |
| 音 | WebAudio の合成音。右上の 🔊 で オン/オフ |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目（ライト/ダーク、縦持ちスマホ用レイアウト） |

## メモ

- 保存は localStorage のキー `anime-tracker-v1`（元の単体HTML版と同じ形式）。元の版で「書き出し」た JSON をそのまま「読み込み」できる。
- 作品を操作したときだけ保存データに入る（見ただけの作品は保存しない）。
- 新しいクールは「データ → クールを追加 / 更新」に JSON を貼るか、`cours.js` に追記する。
  `{"id":"2027-winter","label":"2027年 冬","order":20271,"source":"https://...","note":"","hot":["作品A"],"hotSource":"https://...","titles":["作品A","作品B"]}`
  （`hot` / `hotSource` は省略可）
- 「すべてのクール」は2,000本以上あるので150本ずつ表示し、「つづきを表示」で増やす。
- 作品一覧には大人向けの作品名も含まれるので、カードは「おうちの方むけ」として出している。
