# アニメ視聴管理（anime-tracker）

おうちの方むけの、アニメの視聴きろくアプリ。クール（放送の季節）ごとの新作一覧から、
作品ごとに **ステータス・★評価・メモ** をつけて管理する。

- 公開URL: https://kisi1554.github.io/Pages/anime-tracker/
- 組み込みクール: 2019年冬〜2026年秋の32クール・約2,200作品（アニメイトタイムズの各期まとめから。再放送を除いた新作）
- 🔥話題: 2026年春・夏はアニメイトタイムズ「みんなの覇権おすすめ作品ランキング」の上位15作品、2026年秋はセレクトラ「2026年秋アニメ」で検索数が多い注目作として紹介された15作品を強調表示
- ガイド: 2026年春・夏・秋。視聴管理でそのクールを選ぶと、上に「📖 ガイド」ボタンが出る。ガイドは13ジャンル（異世界・転生／ファンタジー／バトル・アクション／SF・ロボット／恋愛・ラブコメ／日常・コメディ／スポーツ・競技／ミステリー・サスペンス／ホラー・怪奇／ドラマ・青春／歴史・時代／アイドル・音楽／キッズ・ファミリー）ごとに見出しを付けて並べ、ジャンルで絞り込める

## できること

| 機能 | 内容 |
| --- | --- |
| クール切り替え | 1クールずつ表示、または「すべてのクール（横断）」 |
| ステータス | 未視聴 / 気になる / 視聴中 / 完走 / 断念 |
| 話題作 | クール定義の `hot` にある作品に 🔥話題 バッジと色付け。「🔥 話題」チップで絞り込み、「話題作を先に」で並び替え |
| ★評価・メモ | ★1〜5（同じ★をもう一度押すと解除）、作品ごとの感想メモ |
| 絞り込み・並び替え | 作品名検索、ステータスのチップで絞り込み、掲載順・作品名順・評価順・ステータス順 |
| 進み具合 | 完走・視聴中の本数とバー |
| データ | JSON の書き出し / 読み込み、自動バックアップ（パソコンの Chrome / Edge のみ）、クール定義 JSON の追加・上書き |
| 音 | WebAudio の合成音。右上の 🔊 で オン/オフ |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目（ライト/ダーク、縦持ちスマホ用レイアウト） |
| `cours.js` | 組み込みクール一覧 `BUILTIN_COURS` |

## メモ

- 保存は localStorage のキー `anime-tracker-v1`（元の単体HTML版と同じ形式）。元の版で「書き出し」た JSON をそのまま「読み込み」できる。
- 作品を操作したときだけ保存データに入る（見ただけの作品は保存しない）。
- 新しいクールは「データ → クールを追加 / 更新」に JSON を貼るか、`cours.js` に追記する。
  `{"id":"2027-winter","label":"2027年 冬","order":20271,"source":"https://...","note":"","hot":["作品A"],"hotSource":"https://...","titles":["作品A","作品B"]}`
  （`hot` / `hotSource` は省略可）
- 「すべてのクール」は2,000本以上あるので150本ずつ表示し、「つづきを表示」で増やす。
- 作品一覧には大人向けの作品名も含まれるので、カードは「おうちの方むけ」として出している。

## ガイドの作りかた

```bash
python3 tools/anime-guide/build.py --all          # 全クール
python3 tools/anime-guide/build.py 2026-fall      # 1クールだけ
```

- 作品名と 🔥話題 は `cours.js` の `titles` / `hot` が正。ガイドを足すときは `cours.js` に `guide` を書き、
  `tools/anime-guide/seasons.json` に出典（アニメイトタイムズのクールまとめ・放送日順まとめ・話題作の出典）を足す。
- ジャンルは `tools/anime-guide/genres.json`（作品ごとに [メイン, サブ]）。まとめページにジャンル欄がないので、ストーリーから人が決める。未設定の作品があると build.py が知らせる。
- 取得したページは `tools/anime-guide/.cache/` にためる（git には入れない）。最新にしたいときは消してから実行。
- アニメイトタイムズの春・夏・秋・冬のまとめページ（例: 春は `tag id=5228`）は毎年使い回されるので、
  過去のクールは年号付きのアーカイブ（例: 2026春は `tag id=29141`）を使う。
