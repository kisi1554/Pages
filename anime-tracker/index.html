自動バックアップ

保存先ファイルを一度選ぶと、ステータス・評価・メモを変更するたびに自動でそのファイルへ上書き保存します。

お使いのブラウザは自動ファイル保存に対応していません（パソコンの Chrome / Edge で利用できます）。上の「書き出し」ボタンで手動保存してください。

クールを追加 / 更新

クール定義の JSON をここに貼り付けて「取り込む」。同じ id のクールは上書きされます（視聴データは作品名で保持）。配列でまとめて貼ることもできます。

おうちの方むけの アニメ視聴メモです。データはこのブラウザの中（localStorage）に保存されます。
「データ」から書き出し・自動バックアップができます。
