# でんしゃ うんてんし 🚆

運転士の視点で電車を運転するシミュレータ。ゲーム性より「ほんものに近い運転」を優先している。
最初の路線は **東急東横線 各駅停車 渋谷 → 横浜**（5050系8両相当）。

公開URL: https://kisi1554.github.io/Pages/densha-unten/

## あそびかた

- 右のレバー（マスコン）を **下に引くと力行（P1〜P5）**、**上に押すとブレーキ（B1〜B7・非常）**。
  PC は <kbd>↓</kbd>（力行側）/ <kbd>↑</kbd>（ブレーキ側）、<kbd>Esc</kbd> で一時停止。
- ドアが閉まって「知らせ灯」が点くまで力行は効かない（戸閉インターロック）。
- ホームの黄色い「8」（停止位置目標）に先頭を合わせて止める。±3m でドアが開く。
- 速度計の外周の ▲ が ATC 信号。超えると ATC 常用ブレーキが自動で掛かる。
- 上り坂でブレーキを緩めると後ろに下がる（転動）。
- 横浜でドアが開くと結果画面（駅ごとの定刻・実際の着時刻・停止位置のずれ）。

## つくり

ビルド不要。ブラウザでそのまま動く ES モジュールで、外部ライブラリは使っていない
（3D 描画は WebGL2 を直接使う小さなエンジン `render/gl.js`）。フォントは他のアプリと同じく Google Fonts。

| 場所 | 内容 |
| --- | --- |
| `main.js` | 起動・画面遷移・ゲームの進行 |
| `core/physics.js` | 車両の運動計算（引張力・ブレーキ・応答遅れ・走行/勾配/曲線抵抗・転動・インターロック）。1/60 秒以下の刻み |
| `core/atc.js` | ATC 信号（閉そく 200m、制限・減速パターン 0.65m/s²・先行列車） |
| `core/timetable.js` | 自動運転で基準運転時分を出し、時刻表・先行列車の走行記録・対向列車をつくる |
| `core/station.js` | 停車とドア扱いの状態機械 |
| `core/clock.js` | ゲーム内時刻と表示 |
| `route/loader.js` | 路線 JSON・車両 JSON の読み込みと検証 |
| `route/alignment.js` | 平面線形（緩和曲線つき）・縦断線形の生成、距離 s → 座標 |
| `render/*.js` | WebGL2 エンジン、軌道・構造物の押し出し、駅、沿線、他列車、運転席カメラ |
| `ui/*.js` | 速度計・ノッチ表示・ランプ・バー、マスコン、スタフ、HUD、開始/結果画面 |
| `audio/sound.js` | Web Audio の合成音（VVVF・走行音・継ぎ目・ATC ベル・ドアチャイム・ブザー・空気音） |
| `data/routes/*.json` | 路線データ。`index.json` が開始画面に出す一覧 |
| `data/vehicles/*.json` | 車両性能データ |
| `tests/*.test.js` | ロジックのテスト（`npm test` = `node --test`。依存パッケージなし） |

動作確認用の URL パラメータ: `?autostart`（開始画面を飛ばす）、`?autopilot`（自動運転）、`?speed=10`（時間を速める）。

## 路線を追加する

1. `data/routes/<id>.json` を書く（下の書き方）。
2. `data/routes/index.json` の `routes` にファイル名を1行足す。
   （GitHub Pages ではフォルダの中身を一覧できないので、この1行だけは必要）
3. `npm test` で検証が通ることを確かめる（`tests/route.test.js` が一覧の全ファイルを検証する）。

コードは変えなくてよい。開始画面に路線が並び、選んで運転できる。

### 路線 JSON の書き方

距離はすべて **起点（最初の駅の停止位置）からの距離 m**。`note` はどこに書いてもよく、
推定値には「推定値」と書き、調べた値は `sources` に出典を残す。
区間のリストは `[ ... ]` のままでも `{ "note": "...", "list": [ ... ] }` でもよい。

```jsonc
{
  "meta": {
    "id": "toyoko", "name": "東急東横線", "kana": "とうきゅう とうよこせん",
    "service": "各駅停車 渋谷 → 横浜", "lineColor": "#DA0442", "symbol": "TY",
    "gauge": 1067, "direction": "down", "maxSpeed": 110,
    "startBearing": 225,      // 起点での進行方向（北=0° 時計回り）
    "trackSpacing": 3.8,      // 線路中心の間隔 m
    "vehicle": "5050"         // data/vehicles/5050.json
  },
  "sources": ["出典…"],
  "stations": [
    // 駅番号, 駅名, かな, ローマ字, 停止位置 m, 停車時間 s, ホーム side(相対式)/island(島式), ホームの長さ m
    { "id": "TY01", "name": "渋谷", "kana": "しぶや", "roman": "Shibuya", "stop": 0, "dwell": 20, "platform": "island", "length": 210 }
  ],
  "curves": { "transition": 50, "list": [[300, 520, 400, "L"]] },          // [始点, 終点, 半径, 左右]。両端 transition m は緩和曲線
  "structures": { "list": [[-400, 600, "tunnel", -20]] },                  // [始点, 終点, tunnel/cut/ground/elev/bridge, 目標の高さ m]
  "rivers": { "list": [[9420, 9690, "多摩川"]] },                          // 橋の下に水面を描く（省略可）
  "speedLimits": { "list": [[250, 680, 65]] },                             // [始点, 終点, km/h]。値は atc.steps のどれか
  "atc": { "steps": [0, 25, 45, 55, 65, 75, 90, 100, 110], "blockLength": 200, "patternDecel": 0.65, "brakeDecel": 3.2 },
  "timetable": { "type": "各停", "firstDeparture": "14:00:00", "startTime": "13:59:30", "headway": 180,
                 "oncoming": { "speed": 70, "interval": 300 } },
  "scenery": { "dense": [[-400, 1600, "渋谷"]] }                           // 高い建物を置く区間（省略可）
}
```

- 制限速度のない区間は `meta.maxSpeed`。曲線の制限は、編成長（160m）ぶん後ろまでのばしておく。
- 縦断線形は構造物の目標高さから作る。前後から勾配 35‰ を超えないよう制限し、移動平均で縦曲線にする。
- 島式ホームの駅では線路の間隔が自動で広がる。
- 検証で落ちると、その路線は開始画面に出ない（コンソールに理由が出る）。

## 東横線データについて

- 駅の停止位置は依頼仕様の値（営業キロを 100m 単位にしたもの）。Wikipedia の営業キロとは
  綱島・白楽・東白楽・反町で最大 0.9km ちがう。
- 地下・高架・掘割・橋の区間、最急勾配 35‰、最高速度 110km/h は Wikipedia による。
- **曲線半径・制限速度・構造物の高さは推定値**（公開資料に一覧が見つからなかったため、地図の線形から近似）。
  JSON の `note` に明記してある。
- 基準運転時分から作ったダイヤで、渋谷 14:00:00 発 → 横浜 14:40:55 着（約41分）。

## 依頼仕様からの変更点

このリポジトリの決まり（1アプリ1フォルダ・外部ライブラリなし・ビルドなしで Pages に出す）に合わせた。

- Vite + TypeScript + Three.js → **ビルド不要の JavaScript（ES モジュール）＋自作の WebGL2 描画**。
  ディレクトリ構成と役割分担は仕様どおり（`.ts` を `.js` にしたもの）。
- Vitest → **Node.js 標準の `node --test`**（依存パッケージなし）。テスト項目は仕様 13 章どおり。
- 子ども向けに、表示はひらがな中心・漢字にふりがな。

## テスト

```
cd densha-unten && npm test
```

線形（座標の連続・35‰以下）、車両（P5 0→40km/h 約13秒、B7 70km/h→停止 約20秒、転動、インターロック）、
ATC（隣の区間に先行列車で 0、制限の手前で段階的に下がる）、ダイヤ（約40〜45分）、
停車判定（3m 手前／±3m／10m 行き過ぎの境界）、ドア扱いの時刻を確かめる。
