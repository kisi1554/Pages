# ふじさん とざん 🗻

もんだいに こたえて、ふじさんを **5ごうめ → 6 → 7 → 8 → 9 → ちょうじょう** と のぼる アプリ。
のぼるたびに けしき（もり → ひくい き → いわと すな → くもの うえ）と おんどけいが かわり、
たかさ（3776メートル）・「ごうめ」の じゅんばん・たかいほど さむく なり き が なくなることを しる。

`index.html` だけで うごきます（外部ライブラリ・画像・音声ファイルなし。え は SVG、おとは WebAudio）。

公開URL: https://kisi1554.github.io/Pages/fujisan-tozan/

## あそびかた（1かい 1〜3ぷん）

1. レベルを えらぶ（🔢 かぞえる ／ 🪜 じゅんばん・たしざん ／ 📏 くらべる・ちしき）
2. 🎒 もちもの えらび: 10こ から やまで いる 5こ（うわぎ・みず・ライト・ぼうし・てぶくろ）を えらぶ。
   まちがえると「うきわは うみで つかうね」など りゆうが でる
3. 5ごうめから しゅっぱつ。正解すると 1ごうめ ぶん のぼる（5もん）
4. 8ごうめで 🛖 やまごやで ひとやすみ（やきいんの スタンプ）
5. ちょうじょうで ごらいこう（ひので）→ ほし・まめちしき・スタンプ

- まちがえると ボタンが ゆれて ヒント。なんどでも えらびなおせる。
- ミス0で ⭐3、2かいまで ⭐2。レベルごとの ベストと ちょうじょうの かいすうを localStorage（`fujisan-tozan:v1`）に ほぞん。
- 🔊 オン/オフ は 右上。
